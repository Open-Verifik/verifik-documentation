# Mensajería WhatsApp

**Mensajería WhatsApp** es **POST** `https://api.verifik.co/v2/communication/whatsapp`, no GET. El cuerpo exige `phone` y `countryCode`. La ruta fija `phoneGateway` en `whatsapp`. `whatsappTemplate` opcional es `authentication` (el predeterminado) o `flow2`. Con `flow2`, `language` elige `flow2_es` o `flow2_en`, y `title` opcional (1 a 15 caracteres) es la sección de marca.

## Qué devuelve la llamada

- `phone` y `countryCode`
- `phoneGateway` en `whatsapp`
- `status`

## Casos de uso

- Envíe un código de acceso por WhatsApp.
- Elija flow2 si necesita una plantilla de marca.
- Deje authentication como plantilla predeterminada.

---

## Referencia de la API

### Endpoint

```http
POST https://api.verifik.co/v2/communication/whatsapp
```

Un envío correcto devuelve `phoneGateway` `whatsapp` y estado `sent`.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `phone` | string | **Sí** | `3001234567` | Solo el número nacional. |
| `countryCode` | string | **Sí** | `+57` | Indicativo que empieza por `+`. |
| `whatsappTemplate` | string | No | `authentication` | Opcional. `authentication` (predeterminado) o `flow2`. |
| `language` | string | No | `es` | Opcional. Con `flow2`, elige `flow2_es` o `flow2_en`. |

### Notas

- Esta ruta es POST, no GET.
- `whatsappTemplate` es opcional: `authentication` o `flow2`.
- La ruta fija `phoneGateway` en `whatsapp`.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.

## Sandbox

| Escenario | Parámetros | Resultado |
| :--- | :--- | :--- |
| Registro en la fuente | `phone: "3001234567"`, `countryCode: "+57"` | 200 cuando se envía el OTP de WhatsApp. |
| Falta un valor obligatorio | Omit `countryCode` | 409 MissingParameter. |
| Valor desconocido | `whatsappTemplate: "flow2"`, `language: "es"` | 200 con la plantilla flow2 si language es es. |

401 when the bearer token is missing or rejected.
