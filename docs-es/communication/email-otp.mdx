# OTP por correo

**OTP por correo** envía un código de un solo uso. El método real es **POST** `https://api.verifik.co/v2/communication/email`, no GET. El cuerpo exige `project`, `validationMethod` (`manual` o `verificationCode`), `email` y `type` (`validation`, `login`, `onboarding` o `oneTimeLink`). Campos opcionales: `expiresAt`, `redirectUrl`, `webhookUrl`, `identityUrl`, `requires2FA`, `ipAddress` y `language`.

## Qué devuelve la llamada

- `email` y `status`
- `type` y `validationMethod`

## Casos de uso

- Envíe un código de acceso a un buzón.
- Inicie un alta que sigue por correo.
- Adjunte un webhook del estado de entrega.

---

## Referencia de la API

### Endpoint

```http
POST https://api.verifik.co/v2/communication/email
```

Un envío correcto devuelve la validación de correo con estado `sent`. Confirme el código con el endpoint de validación de correo que ya usa su proyecto.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `project` | string | **Sí** | `project_id` | Id del proyecto dueño del OTP de correo. |
| `validationMethod` | string | **Sí** | `verificationCode` | `manual` o `verificationCode`. |
| `email` | string | **Sí** | `person@example.com` | Buzón que recibe el código. Una dirección inválida es 409. |
| `type` | string | **Sí** | `validation` | `validation`, `login`, `onboarding` o `oneTimeLink`. |

### Request

<TabItem value="javascript" label="Node.js / JavaScript">

```javascript
import axios from "axios";

const options = {
  method: "POST",
  url: "https://api.verifik.co/v2/communication/email",
  headers: {
    "Content-Type": "application/json",
    Accept: "application/json",
    Authorization: "Bearer <your_token>",
  },
  data: {
    "project": "project_id",
    "validationMethod": "verificationCode",
    "email": "person@example.com",
    "type": "validation"
  },
};

try {
  const { data } = await axios.request(options);
  console.log(data);
} catch (error) {
  console.error(error.response ? error.response.data : error.message);
}
```

### Notas

- Esta ruta es POST, no GET.
- `project`, `validationMethod`, `email` y `type` son obligatorios.
- Una dirección que no es correo es 409.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.

## Sandbox

| Escenario | Parámetros | Resultado |
| :--- | :--- | :--- |
| Registro en la fuente | the example body | 200 cuando se envía el código. |
| Falta un valor obligatorio | Omit `project` | 409 MissingParameter. |
| Valor desconocido | `email: "not-an-email"` | 409 si el formato del correo es inválido. |

401 when the bearer token is missing or rejected.
