# Colombia - Registro Empresarial RUES

**`GET /v2/co/rues`** es un alias del feature público **Colombia — Consulta RUES (v3)** ([`GET /v3/co/rues`](/verifik-es/business-validation/colombia-rues-v3)). No es una API distinta que reciba solo `nit`. Envía los mismos parámetros obligatorios que v3. Nombre en catálogo: **Colombia — Consulta RUES (v3)**. Precio de lista **$0,30** por consulta.

Para el expediente completo usa [RUES completo (v3)](/verifik-es/business-validation/rues-complete-v3) (`GET /v3/co/rues-complete`, precio de lista **$0,40**). `GET /v2/co/rues/complete` no está en el catálogo público actual.

## ¿Cuál endpoint usar?

| | **`GET /v2/co/rues`** (alias de v3 básico) | **`GET /v3/co/rues-complete`** |
| --- | --- | --- |
| **Uso** | Resumen por categoría | Expediente **completo** |
| **Parámetros** | `documentType`=`NIT`, `category` obligatoria, `documentNumber` | **Los mismos** |
| **Precio de lista** | **$0,30** por consulta | **$0,40** por consulta |

### Endpoint

```
GET https://api.verifik.co/v2/co/rues
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

### Parámetros

| Name | Type | Required | Description | Example |
| ---- | ---- | -------- | ----------- | ------- |
| `documentType` | string | **Sí** | Debe ser **`NIT`**. | `NIT` |
| `documentNumber` | string | **Sí** | NIT, sin espacios ni puntos. | `900265177` |
| `category` | string | **Sí** | Obligatoria. Una de **`RM`**, **`PROP`**, **`RUNEOL`**, **`RNT`**, **`ESAL`**, **`RESAL`**, **`JUEGOS`**, **`EXTRANJERAS`**. | `RM` |
