# 🇨🇱 Chile - Bloqueo de Licencia de Conducir (Registro Civil)

Consulta el registro nacional de bloqueo de licencias de conducir del **Servicio de Registro Civil e Identificación** de Chile mediante el RUN del conductor.

A diferencia de las consultas municipales que solo abarcan una comuna específica, este servicio ofrece **cobertura nacional** sobre suspensiones o bloqueos de licencias ordenados por juzgados de policía local o autoridades judiciales en todo Chile.

### Endpoint

```
GET https://api.verifik.co/v2/cl/driver-license/block
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parámetros

| Name | Type | Required | Description | Example |
| ---- | ---- | -------- | ----------- | ------- |
| `documentNumber` | string | **Sí** | RUN chileno con dígito verificador (DV). Puntos y guión son opcionales (`18.347.440-5` o `18347440-5`). El dígito verificador debe ser válido. | `18347440-5` |
| `force` | boolean | No | Opcional booleano o `1`/`true` para omitir la caché y consultar en tiempo real al Registro Civil. | `false` |

## Características

- **Registro Nacional Oficial**: Fuente directa del Registro Civil e Identificación de Chile.
- **Detección Inmediata de Bloqueos**: Indica de forma binaria (`hasBlock: true/false`) el estado de la licencia.
- **Identificación del Titular**: Devuelve el nombre legal asociado a la credencial de conductor.
- **Metadatos de la Medida**: Detalla fecha de la orden, tipo y motivo judicial cuando existe restricción.
- **Validación Automática de Módulo 11**: Evita llamadas innecesarias y consumo de créditos si el dígito verificador es incorrecto.
