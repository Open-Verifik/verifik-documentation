# Panamá — Idoneidad de ingenieros y arquitectos (JTIA)

La consulta de **licencia JTIA** lee la idoneidad de ingenieros, arquitectos y técnicos. Envíe `documentNumber` (o `cedula`), `licenseNumber` (o `idoneidad`) o `fullName`. Una cédula que no se puede normalizar responde 409. Sin fila en la junta es 404 `NotFound`.

## Qué devuelve la llamada

- Cédula normalizada
- `licenseNumber` y `fullName`
- `status`

## Casos de uso

- Verifique un ingeniero antes de un permiso de construcción.
- Busque por cédula si no tiene la matrícula.
- Busque por nombre si solo tiene el contrato.

---

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/pa/professional/jtia
```

Un acierto incluye la cédula normalizada, el nombre, la matrícula y el estado.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `8-224-2444` | Cédula panameña, también como `cedula`. La API la normaliza (por ejemplo `8-224-2444`). |
| `licenseNumber` | string | **Condicional** | `JTIA-100` | Idoneidad o matrícula. Alias: `idoneidad`. |
| `fullName` | string | **Condicional** | `ANA RUIZ` | Nombre, de 3 a 160 caracteres. Basta por sí solo. |

### Notas

- Envíe una cédula, una matrícula o un nombre.
- Una cédula con forma inválida es 409.
- Sin fila JTIA es 404 `NotFound`.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.

| Registro en la fuente | `documentNumber: "8-224-2444"` | 200 con la cédula normalizada y la matrícula. |
