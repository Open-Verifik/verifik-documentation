# México — Cédula profesional

Confirma que una persona tiene una cédula profesional en el registro oficial de profesionistas. Es una verificación de credencial, no una prueba de identidad.

Envía **un documento** o **un nombre**:

- **CURP** (recomendado). Primero se consulta el registro en busca de cédulas ligadas a esa CURP.
- **Número de cédula.** Coincidencia exacta con el número de cédula.
- **Nombre.** Coincidencia exacta, sin distinguir acentos, de los nombres de pila más ambos apellidos.

Una persona puede tener varias cédulas, así que `cedulas` es un arreglo. Para el registro civil del titular de la CURP, consulta [Ciudadano mexicano (CURP)](/identity/mexico). Para una credencial de elector, consulta [Validación INE](/identity/mexico-ine). Para cédulas solo de salud, consulta [Licencia de profesionista de salud](/identity/mexico-health-worker).

## API reference

### Endpoint

```
https://api.verifik.co/v2/mx/cedula-profesional
```

Una coincidencia devuelve `fullName`, `matchMethod`, `ambiguous` y `cedulas[]` con `licenseNumber`, `title`, `profession`, `institution` y `registrationYear`.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

Envía `documentType` + `documentNumber`, o `firstName` + `lastName`. No mezcles los dos modos.

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `documentType` | string | Modo documento | `CURP` o `CEDULA` (sin distinguir mayúsculas). | `CURP` |
| `documentNumber` | string | Con `documentType` | Una CURP de 17–18 caracteres (se pasa a mayúsculas automáticamente) o un número de cédula. | `LOPE900501HDFGRN01` |
| `firstName` | string | Modo nombre | Nombres de pila. De 2 a 80 caracteres. | `ANA` |
| `lastName` | string | Modo nombre | Ambos apellidos, el paterno primero. De 2 a 80 caracteres. | `LOPEZ RUIZ` |

### How matching works

- **CURP.** Primero se devuelven las cédulas ligadas a esa CURP (`matchMethod: "curp"`). Si ninguna está ligada de forma directa, Verifik resuelve el nombre oficial del titular de la CURP y busca una coincidencia exacta del nombre completo. Ese paso no tiene costo adicional (`matchMethod: "curp_to_name"`, con `matchNote`). Prevalecen las filas que traen la misma CURP. Si no las hay, se devuelven las filas sin CURP que coinciden con el nombre exacto.
- **`ambiguous: true`** significa que esas filas pertenecen a más de un grupo de institución y año de registro, así que puede haber un homónimo. Revisa las filas o pide el número de cédula.
- **CEDULA.** Coincidencia exacta del número de cédula (`matchMethod: "license"`).
- **Nombre.** Coincidencia exacta del nombre completo, sin distinguir acentos ni mayúsculas (`matchMethod: "name"`). `ambiguous` usa la misma regla de institución y año. Prefiere la CURP.

### Notes

- Una CURP válida cuyo titular no tiene cédula responde **404**, también en sandbox. Un arreglo `cedulas` vacío no es una respuesta de éxito.
- `ambiguous: true` significa que las filas abarcan más de una institución y año de registro. Revísalas o consulta el número de cédula.
- Los resultados se almacenan en caché hasta 7 días, así que una consulta repetida es rápida.
- Persona de sandbox `ANA LOPEZ RUIZ`. Cualquier CURP, salvo los disparadores de abajo, devuelve una coincidencia directa con dos cédulas.
- Una CURP que contiene `000003` (por ejemplo `LOPE000003MDFRRN03`) devuelve `matchMethod: "curp_to_name"` y `cedulas[].curp: null`.
- Una CURP que contiene `000002` (por ejemplo `LOPE000002MDFRRN02`) responde **404** (CURP válida, sin cédula).
- La CURP `LOPE900404HDFNTF01`, la cédula `90040401` o `lastName=NOTFOUND` responden **404**.
- `documentType=CEDULA` y `documentNumber=10000001` devuelven una cédula de derecho. `firstName=ANA` y `lastName=AMBIGUA` devuelven `ambiguous: true`.
- Una CURP de menos de 17 o más de 18 caracteres, o un `documentType` no válido, responde **409** `MissingParameter`.
- Cuando no se puede alcanzar el registro, la respuesta es **409** `Endpoint_out_of_service`. Reintenta más tarde.
- Relacionado: [Ciudadano mexicano (CURP)](/identity/mexico), [Validación INE](/identity/mexico-ine), [Licencia de profesionista de salud](/identity/mexico-health-worker), [Certificado de estudios (folio)](/identity/mexico-siged-certificado).
