# Panamá — Verificación de Profesionales de la Salud y Médicos (MINSA / Consejo Técnico de Salud)

Permite consultar y certificar el registro profesional de médicos generales, médicos especialistas, odontólogos, enfermeros, farmacéuticos y personal técnico de la salud en la República de Panamá. Las consultas pueden realizarse mediante **Cédula (`documentNumber` o `cedula`)** o por **Nombre Completo (`fullName`)**.

La verificación consulta los registros oficiales del Ministerio de Salud (*MINSA*) y del Consejo Técnico de Salud, acreditando la condición laboral, cargo, categoría profesional e institución sanitaria de adscripción.

- **Cobertura Sanitaria Nacional:** Abarca personal activo y permanente de la red hospitalaria y de salud de la República de Panamá.
- **Multicategoría Profesional:** Detecta idoneidad y cargos para médicos especialistas, odontólogos, enfermeros y tecnólogos médicos.
- **Homologación de Cédula:** Compatible con el formato tradicional (`8-224-2444`) y el formato computarizado ampliado (`8-0224-02444`).

---

## Referencia de API

### Punto de acceso

```http
GET https://api.verifik.co/v2/pa/health-worker
```

*(También disponible mediante el alias `https://api.verifik.co/v2/pa/medical-professional`)*

### Encabezados

| Nombre | Valor |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parámetros

| Nombre | Tipo | Obligatorio | Descripción |
| :--- | :--- | :--- | :--- |
| `cedula` | string | Condicional | Cédula de identidad panameña (ej. `8-224-2444` o `8-0224-02444`). Obligatorio si no se envía `fullName`. |
| `documentNumber` | string | Condicional | Sinónimo de `cedula`. |
| `documentType` | string | No | Tipo de documento: `CEDULA` (predeterminado) o `CCPA`. |
| `fullName` | string | Condicional | Nombre completo del profesional (mínimo 3 caracteres). Obligatorio si se omite la cédula. |
| `force` | boolean | No | Omite el caché reciente y fuerza una consulta en tiempo real. |

### Notas

- Utilice `cedula` o `fullName` en cada consulta.
- Se aceptan cédulas panameñas en formato con guiones (`8-224-2444`), con ceros de relleno (`8-0224-02444`) o solo números.
- En modo Sandbox, utilice las cédulas de prueba `8-224-2444` (Médico Especialista) o `8-222-1461` (Odontólogo).
