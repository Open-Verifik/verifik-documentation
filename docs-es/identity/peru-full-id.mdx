# 🇵🇪 Perú - ID Completo

Esta llamada API realiza una verificación extendida de identidad para un ciudadano peruano usando su número de DNI (Documento Nacional de Identidad). Recupera información personal detallada: nombre completo, estado civil, fecha de nacimiento, desglose de dirección (provincia, área, distrito) y campos de identidad relacionados.

**El header de Authorization es requerido para autenticación para acceder a esta información de forma segura.**

## ¿Qué valida esta API?

Nuestra API se conecta directamente con registros oficiales peruanos para validar:

-   **Nombre completo y número de DNI**: admite documentos *Documento Nacional de Identidad* (DNI).
-   **Coincidencia de identidad**: confirma que el nombre proporcionado coincide con el número de DNI.
-   **Datos personales extendidos**: devuelve estado civil, fecha de nacimiento, sexo, dirección, provincia, área y distrito.
-   **Componentes del nombre**: devuelve `firstName`, `lastName`, `paternalLastName`, `maternalLastName` y `arrayName`.
-   **Información del documento**: devuelve tipo y número de documento.

Algunos campos siempre están presentes en la respuesta pero actualmente devuelven la cadena `not_available` (no se omiten): `photo`, `expeditionDate`, `expirationDate`, `ubigeoReniec` y `verificationDigit`. La foto no se ofrece actualmente en este endpoint.

### Endpoint

```
GET https://api.verifik.co/v3/pe/cedula/extra
```

Devuelve **datos extendidos de DNI RENIEC** para ciudadanos peruanos: nombre completo, estado civil, fecha de nacimiento, dirección (provincia, área, distrito) y campos de identidad relacionados. Envíe `documentType=DNI` y el `documentNumber` de 8 dígitos.

`photo`, `expeditionDate`, `expirationDate`, `ubigeoReniec` y `verificationDigit` están incluidos en la forma de la respuesta pero actualmente devuelven `not_available`.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

### Parámetros

| Name | Type | Required | Description | Example |
| ---- | ---- | -------- | ----------- | ------- |
| `documentType` | string | **Sí** | Tipo de documento. Valor permitido: DNI. | `DNI` |
| `documentNumber` | string | **Sí** | Número de DNI de 8 dígitos (sin espacios). | `44868598` |

### Campos de respuesta

| Campo | Valor típico | Notas |
| ----- | ------------ | ----- |
| `address`, `province`, `area`, `homeDistrict` | Cadenas con datos | Desglose de dirección desde registros RENIEC. |
| `arrayName`, `firstName`, `lastName`, `paternalLastName`, `maternalLastName`, `fullName` | Cadenas con datos | Componentes del nombre. |
| `civilStatus`, `dateOfBirth`, `sex` | Cadenas con datos | Datos demográficos. |
| `documentType`, `documentNumber` | Cadenas con datos | Identificador DNI. |
| `photo`, `expeditionDate`, `expirationDate`, `ubigeoReniec`, `verificationDigit` | `not_available` | Presentes en la respuesta pero no poblados en el producto actual. |

## Características

- **Verificación extendida de identidad**: verificación integral de identidad para ciudadanos peruanos usando DNI
- **Información personal detallada**: nombre completo, componentes del nombre y `arrayName`
- **Datos demográficos**: estado civil, sexo, fecha de nacimiento e información de dirección (provincia, área, distrito)
- **Detalles del documento**: tipo y número de documento
- **Campos no disponibles**: `photo`, `expeditionDate`, `expirationDate`, `ubigeoReniec` y `verificationDigit` devuelven `not_available` en el producto actual
- **Múltiples lenguajes de programación**: soporte para JavaScript, Python, Ruby y cURL
- **Datos en tiempo real**: información de ciudadanos actual y actualizada
- **Manejo completo de errores**: respuestas de error detalladas para varios escenarios
- **Integración con registro peruano**: acceso directo a base de datos oficial de ciudadanos peruanos
- **Autenticación segura**: header de Authorization requerido para acceso seguro
