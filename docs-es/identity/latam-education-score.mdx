# LATAM — Score unificado de educación y licencia

El **score de educación** reúne grados universitarios y licencias profesionales en un puntaje para `CO`, `PE`, `PA`, `MX` o `CL` (se aceptan los nombres de país en inglés). `country` es obligatorio. También debe enviar una identidad: `documentNumber`, `licenseNumber`, `fullName`, o `firstName` y `lastName`. Un 409 trae `{ "validationError": "..." }`, no `MissingParameter`. Un país no soportado también es 409.

## Qué devuelve la llamada

- `educationScore` y `educationTier`
- `highestLevel` y `hasActiveLicense`
- `credentials` y `checkedSources`

## Casos de uso

- Ordene una contratación entre fuentes de grado y licencia.
- Exija un país antes de puntuar.
- Lea las sanciones como una baja del puntaje.

---

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/score/education
```

La respuesta incluye `educationScore` de 0 a 100, `educationTier`, `highestLevel`, `hasActiveLicense`, `hasSanctions` y `credentials`.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `country` | string | **Sí** | `CO` | Obligatorio. `CO`, `PE`, `PA`, `MX`, `CL`, o el nombre en inglés `COLOMBIA`, `PERU`, `PANAMA`, `MEXICO`, `CHILE`. |
| `documentNumber` | string | **Condicional** | `80123456` | Se requiere una identidad: este número, `licenseNumber`, `fullName`, o `firstName` y `lastName` juntos. |
| `licenseNumber` | string | **Condicional** | `AN205-27910` | Matrícula profesional. Cuenta como la identidad obligatoria. |
| `fullName` | string | **Condicional** | `ANA PEREZ` | Nombre completo. Cuenta como la identidad obligatoria. |

### Notas

- `country` es obligatorio.
- El 409 usa `validationError`, no `MissingParameter`.
- Los países soportados son CO, PE, PA, MX y CL.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.

## Sandbox

| Escenario | Parámetros | Resultado |
| :--- | :--- | :--- |
| Registro en la fuente | `country: "CO"`, `documentNumber: "80123456"` | 200 con educationScore y nivel. |
| Falta un valor obligatorio | Omit `country` | 409 `{ validationError }` si falta country o la identidad. |
| Valor desconocido | `country: "US"`, `documentNumber: "1"` | 409 si el código de país no está soportado. |

401 when the bearer token is missing or rejected.
