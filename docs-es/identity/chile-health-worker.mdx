# Chile — Verificación de Prestadores Individuales de Salud y Médicos (SIS / RNPI)

Permite consultar y acreditar la habilitación profesional de médicos cirujanos, cirujanos dentistas, enfermeros, matronas, tecnólogos médicos y especialistas en salud en la República de Chile por **RUT (`documentNumber` o `rut`)** o por **Nombre Completo (`fullName`)**.

La verificación consulta el **Registro Nacional de Prestadores Individuales de Salud (RNPI)** administrado por la **Superintendencia de Salud (SIS)**, certificando el título profesional, especialidades acreditadas, entidad emisora y estado de habilitación para el ejercicio de la profesión médica.

- **Acreditación Profesional Oficial:** Valida títulos emitidos por universidades chilenas o revalidados ante la Universidad de Chile.
- **Especialidades Médicas Certificadas:** Confirma especialidades médicas y subespecialidades inscritas y certificadas (CONACEM / CONACEO).
- **Cumplimiento y Telemedicina:** Indispensable para clínicas, centros médicos, plataformas de salud digital y aseguradoras (FONASA / ISAPRE).

## Referencia de API

### Punto de acceso

```http
GET https://api.verifik.co/v2/cl/health-worker
```

*(También disponible mediante el alias `https://api.verifik.co/v2/cl/medical-professional`)*

### Encabezados

| Nombre | Valor |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parámetros

| Nombre | Tipo | Obligatorio | Descripción |
| :--- | :--- | :--- | :--- |
| `rut` | string | Condicional | RUT del profesional de salud (ej. `4738039-1` o `12443604-4`). Obligatorio si se omite `fullName`. |
| `documentNumber` | string | Condicional | Sinónimo de `rut`. |
| `documentType` | string | No | Tipo de documento: `RUT` (predeterminado). |
| `fullName` | string | Condicional | Nombre completo del profesional (mínimo 3 caracteres). Obligatorio si se omite el RUT. |
| `force` | boolean | No | Omite el caché reciente y fuerza una consulta en tiempo real. |

### Notas

- Envíe `rut` o `fullName` en cada consulta.
- El RUT se acepta con o sin puntos y guión (ej. `4.738.039-1` o `4738039-1`).
- En modo Sandbox, los identificadores de prueba incluyen `4738039-1` (Médico Cirujano - Cirugía General) y `12443604-4` (Médico Cirujano - Traumatología).
