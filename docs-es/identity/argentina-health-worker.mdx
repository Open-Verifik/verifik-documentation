# Argentina — Verificación de Profesionales de la Salud y Médicos (SISA / REFEPS)

Permite consultar y validar el estado de habilitación profesional y matrículas de médicos, odontólogos, psicólogos, enfermeros y profesionales sanitarios en toda la República Argentina por **DNI (`documentNumber`)** o **Nombre Completo (`fullName`)**, con opción de filtrar por número de **matrícula (`matricula`)**.

La verificación consulta el **Registro Federal de Profesionales de la Salud (REFEPS)** integrado en el **Sistema de Información Sanitaria Argentino (SISA)** del **Ministerio de Salud de la Nación (MSAL)**, certificando matrículas nacionales o provinciales, títulos universitarios, especialidades y vigencia para el ejercicio profesional.

- **Cobertura Federal Consolidada:** Unifica datos de colegios profesionales y ministerios de salud de las 23 provincias y CABA.
- **Múltiples Disciplinas Sanitarias:** Médicos, cirujanos, odontólogos, psicólogos, farmacéuticos y enfermeros universitarios.
- **Especialidades Médicas Registradas:** Consulta especialidades clínicas y quirúrgicas certificadas y registradas ante la autoridad sanitaria.

## Referencia de API

### Punto de acceso

```http
GET https://api.verifik.co/v2/ar/health-worker
```

*(También disponible mediante el alias `https://api.verifik.co/v2/ar/cedula/medico-profesional`)*

### Encabezados

| Nombre | Valor |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parámetros

| Nombre | Tipo | Obligatorio | Descripción |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | Condicional | DNI argentino del profesional (ej. `20123456` o `28456789`). Obligatorio si se omite `fullName`. |
| `documentType` | string | No | Tipo de documento: `DNI` (predeterminado). |
| `fullName` | string | Condicional | Nombre completo del profesional de salud. Obligatorio si se omite el DNI. |
| `matricula` | string | No | Número de matrícula provincial o nacional (opcional para acotar búsqueda). |
| `force` | boolean | No | Omite el caché reciente y fuerza una consulta en tiempo real. |

### Notas

- Envíe `documentNumber` (DNI) o `fullName` en cada consulta.
- Se puede especificar opcionalmente `matricula` para validar o filtrar la matrícula profesional concreta.
- En modo Sandbox, los identificadores de prueba incluyen `20123456` (Médico - Cardiología) y `28456789` (Médico - Pediatría).
