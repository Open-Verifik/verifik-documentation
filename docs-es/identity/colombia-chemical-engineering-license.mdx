# Colombia — Matrícula de ingeniería química (CPIQ)

La consulta de **matrícula CPIQ** lee el Consejo Profesional de Ingeniería Química. Envíe `documentNumber` o `licenseNumber`. El módulo no busca por nombre: solo `fullName` responde HTTP 409 con `MissingParameter` y el mensaje `Either documentNumber or licenseNumber must be provided`. Un acierto incluye matrícula, resolución, estado y sanciones.

## Qué devuelve la llamada

- `licenseNumber` y `resolutionNumber`
- `status` e `isActive`
- `sanctionType` y `hasSanctions`

## Casos de uso

- Verifique un ingeniero químico por cédula o matrícula CPIQ.
- Rechace búsquedas solo por nombre antes de llegar al consejo.
- Lea fechas de sanción cuando el consejo las publica.

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpiq
```

Una coincidencia incluye `fullName`, `licenseNumber`, `resolutionNumber`, `status`, `sanctionType`, `isRegistered` y `hasSanctions`. Sin fila en el CPIQ es 404 `NotFound`.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `79876543` | Número de identidad. Obligatorio si omite `licenseNumber`. Una solicitud solo con `fullName` responde 409. |
| `licenseNumber` | string | **Condicional** | `PQ-10293` | Número de matrícula profesional del CPIQ. Obligatorio si omite `documentNumber`. |

### Notas

- `fullName` no es clave de búsqueda en esta ruta. Solo el nombre responde 409.
- Envíe `documentNumber` o `licenseNumber`.
- Una fila ausente en el CPIQ es HTTP 404.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.

## Sandbox

| Escenario | Parámetros | Resultado |
| :--- | :--- | :--- |
| Registro en la fuente | `documentNumber: "79876543"` | 200 con matrícula y campos de sanción. |

401 when the bearer token is missing or rejected.
