# México — Certificado SIGED

Comprueba un certificado escolar electrónico en [SIGED](https://siged.sep.gob.mx/SIGED/documentos.html). La consulta es **solo por folio**. No busca por nombre.

La SEP marca el resultado como informativo. El documento oficial es el que entrega la escuela.

## Referencia

```
GET https://api.verifik.co/v2/mx/siged/certificado
```

| Parámetro | Obligatorio | Descripción |
| --- | --- | --- |
| `folio` | Sí | Folio impreso en el certificado. |
| `fullName` | No | Nombre esperado. Si no coincide, responde `409` `name_mismatch`. |
| `curp` | No | Obtiene el nombre oficial de la CURP y lo compara con el certificado. |

Un folio desconocido responde **404**.

Usa solo dominios `*.sep.gob.mx`.
