# México — Certificado de estudios (folio)

Valida un certificado electrónico de estudios mexicano por folio contra el registro oficial de certificados. Opcionalmente envía `fullName` o `curp` para confirmar que el certificado pertenece a esa persona. Cuando se envían ambos, gana `curp`. Una discrepancia responde **409** `name_mismatch`.

Esto comprueba el registro del certificado. No prueba la identidad por sí solo. Para el registro civil por CURP, consulta [Ciudadano mexicano (CURP)](/identity/mexico). Para una cédula profesional, consulta [Cédula profesional](/identity/mexico-cedula-profesional).

## API reference

### Endpoint

```
https://api.verifik.co/v2/mx/siged/certificado
```

Una coincidencia devuelve `folio`, `fullName`, `status`, `certificateType`, `career`, `institution`, `level`, `studyType`, `average`, `averageText`, `periodStart`, `periodEnd`, `registrationDate`, `laborTraining`, `federalEntity` e `issueDate`. Los campos vacíos son `null`.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `folio` | string | Sí | Folio impreso en el certificado electrónico. De 4 a 64 caracteres. | `SIGED10000001` |
| `fullName` | string | No | Nombre completo esperado. Una discrepancia responde 409 `name_mismatch`. Se ignora cuando también se envía `curp`. De 3 a 160 caracteres. | `Ana Lopez Ruiz` |
| `curp` | string | No | CURP de la persona. Cuando se envía, prevalece sobre `fullName`. De 17 a 18 caracteres. | `LOPE900501HDFGRN01` |

### Request

  <TabItem value="node" label="Node.js">

import axios from "axios";

const { data } = await axios.get("https://api.verifik.co/v2/mx/siged/certificado", {

  },

### Notes

- `folio` es obligatorio. `fullName` y `curp` son comprobaciones opcionales del titular. Cuando se envían ambos, se usa `curp` y se ignora `fullName`.
- Un folio que no está en el registro responde **404**. Un nombre o una CURP que no pertenece a ese certificado responde **409** `name_mismatch`.
- Los resultados se almacenan en caché hasta 7 días.
- El folio de sandbox `SIGED10000001` devuelve el certificado de ejemplo de `ANA LOPEZ RUIZ`. `fullName=Ana Lopez Ruiz` también responde 200.
- `fullName=Maria Perez` en ese folio responde **409** `name_mismatch`.
- El folio `FOLIO90040401` responde **404**.
- `curp=LOPE900501HDFGRN01` con cualquier `fullName` responde 200, porque gana la CURP. `curp=LOPE900404HDFNTF01` responde **404**.
- Un `folio` ausente responde **409** `MissingParameter`.
- Cuando no se puede alcanzar el registro, la respuesta es **409** `Endpoint_out_of_service`. Reintenta más tarde.
- Relacionado: [Ciudadano mexicano (CURP)](/identity/mexico), [Cédula profesional](/identity/mexico-cedula-profesional), [Licencia de profesionista de salud](/identity/mexico-health-worker).
