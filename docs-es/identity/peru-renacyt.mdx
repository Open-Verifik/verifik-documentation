# Perú — Grados SUNEDU y RENACYT de CONCYTEC

La consulta **RENACYT** lee grados SUNEDU y el registro de investigadores de CONCYTEC. Envíe al menos uno de `documentNumber` (alias `dni`), `codigoRegistro`, `orcid` o `fullName`. Si envía un número, `documentType` por defecto es `DNI`.

## Qué devuelve la llamada

- Campos de grado e investigador
- `codigoRegistro` y `orcid` si existen
- `fullName` y `documentNumber`

## Casos de uso

- Confirme un investigador antes de una beca.
- Cruce un ORCID con un DNI.
- Lea el código RENACYT para un expediente de contratación.

---

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/pe/education/renacyt
```

Un acierto puede incluir el grado, el código RENACYT y el ORCID. Sin fila es 404 `NotFound`.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `12345678` | DNI u otro número. Alias: `dni`. `documentType` por defecto es `DNI`. También `CE`, `PASAPORTE`, `PTP`. |
| `codigoRegistro` | string | **Condicional** | `REN-100` | Código de registro RENACYT. Basta por sí solo. |
| `orcid` | string | **Condicional** | `0000-0002-1825-0097` | ORCID, de 10 a 30 caracteres. Basta por sí solo. |
| `fullName` | string | **Condicional** | `LUCIA QUISPE` | Nombre del investigador. Basta por sí solo. |

### Notas

- Envíe un documento, un código RENACYT, un ORCID o un nombre.
- Los números de documento usan por defecto el tipo `DNI`.
- Sin fila en el registro es 404 `NotFound`.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.
