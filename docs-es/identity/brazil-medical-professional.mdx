# Brasil — Profesional Médico (CRM)

Valida y consulta los datos de inscripción de médicos registrados en Brasil en cualquiera de las 27 jurisdicciones estatales (*Unidades Federativas* — `UF`). Permite consultar por **número de CRM y Estado (`uf`)** o por **Nombre Completo (`fullName`)**.

Cuando se consulta por número de CRM y `uf`, también se puede enviar opcionalmente el `cpf` (11 dígitos) y `dateOfBirth` (`DD/MM/YYYY`) del médico para validar si dichos datos de identidad corresponden al titular del registro (`identityValidated: true | false`).

## Referencia de la API

### Endpoint

```
https://api.verifik.co/v2/br/medical-professional
```

*(También disponible mediante el alias `https://api.verifik.co/v2/br/health-worker`)*

### Encabezados

| Nombre | Valor |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parámetros

Envía **`documentNumber` (o `crm`) + `uf`**, o bien **`fullName`**.

| Nombre | Tipo | Requerido | Descripción | Ejemplo |
| --- | --- | --- | --- | --- |
| `documentType` | string | Opcional | Establecer en `CRM` cuando se consulta por número de inscripción CRM. | `CRM` |
| `documentNumber` | string | Modo CRM | Número de inscripción CRM del médico (hasta 7 dígitos). Alias: `crm`. | `123456` |
| `uf` | string | Modo CRM (Opcional en Modo Nombre) | Código de estado brasileño de 2 letras (`AC`, `AL`, `AM`, `AP`, `BA`, `CE`, `DF`, `ES`, `GO`, `MA`, `MG`, `MS`, `MT`, `PA`, `PB`, `PE`, `PI`, `PR`, `RJ`, `RN`, `RO`, `RR`, `RS`, `SC`, `SE`, `SP`, `TO`). | `SP` |
| `cpf` | string | Opcional | CPF brasileño de 11 dígitos (con o sin formato) para validar identidad junto con `dateOfBirth`. | `12345678909` |
| `dateOfBirth` | string | Opcional | Fecha de nacimiento en formato `DD/MM/YYYY` para validar identidad junto con `cpf`. | `15/05/1980` |
| `fullName` | string | Modo Nombre | Nombre completo del profesional médico (mínimo 3 caracteres). | `CARLOS EDUARDO SILVA` |

### Códigos de Situación (`statusCode` / `status`)

| Código | Situación (`status`) | `isActive` | Descripción Reglamentaria |
| :---: | :--- | :---: | :--- |
| `A` | `Regular` | `true` | Médico regularmente inscrito y apto para el ejercicio de la medicina. |
| `B` | `Suspensão parcial permanente` | `false` | Suspensión parcial permanente por enfermedad incapacitante. |
| `C` | `Cassado` | `false` | Ejercicio profesional revocado por sentencia firme en proceso ético-profesional. |
| `E` | `Inoperante` | `false` | Inactivo por más de cinco años o con paradero desconocido. |
| `F` | `Falecido` | `false` | Médico fallecido. |
| `G` | `Sem o exercício da profissão na UF` | `false` | Sin ejercicio de la profesión en la UF consultada. |
| `I` | `Interdição cautelar - total` | `false` | Interdicción cautelar total para el ejercicio profesional. |
| `J` | `Suspenso por ordem judicial - parcial` | `false` | Suspensión parcial por decisión judicial. |
| `L` | `Cancelado` | `false` | Inscripción cancelada a pedido propio o por plazo administrativo. |
| `M` | `Suspensão total temporária` | `false` | Suspensión total temporal del ejercicio de la medicina. |
| `N` | `Interdição cautelar - parcial` | `false` | Interdicción cautelar parcial por decisión administrativa. |
| `O` | `Suspenso por ordem judicial - total` | `false` | Suspensión total por orden judicial. |
| `P` | `Aposentado` | `false` | Inscripción cancelada por jubilación. |
| `R` | `Suspensão temporária` | `false` | Suspensión temporal (hasta 30 días) por sanción disciplinaria. |
| `S` | `Suspenso - total` | `false` | Suspensión total por decisión administrativa. |
| `T` | `Transferido` | `false` | Médico transferido a otra jurisdicción estatal (`UF`). |
| `X` | `Suspenso - parcial` | `false` | Suspensión parcial por decisión administrativa. |

### Tipos de Inscripción (`registrationTypeCode` / `registrationType`)

| Código | Tipo de Inscripción |
| :---: | :--- |
| `P` | `Principal` |
| `S` | `Secundária` |
| `V` | `Provisória` |
| `T` | `Temporária` |
| `E` | `Estudante Médico Estrangeiro` |

### Datos de Prueba (Sandbox)

Utilice los siguientes identificadores deterministas en entornos de pruebas (`sandbox`):

| `documentNumber` (`crm`) | `uf` | `fullName` | Escenario |
| :--- | :---: | :--- | :--- |
| `123456` | `SP` | `CARLOS EDUARDO SILVA` | Médico activo (`statusCode: "A"`, `status: "Regular"`, `isActive: true`, especialidades en Cardiología y Clínica Médica). Envíe `cpf=12345678909` y `dateOfBirth=15/05/1980` para obtener `identityValidated: true`. |
| `654321` | `RJ` | `MARIANA COSTA OLIVEIRA` | Médico con suspensión temporal (`statusCode: "R"`, `status: "Suspensão temporária"`, `isActive: false`). |
| `777777` | `MG` | `ROBERTO ALMEIDA SANTOS` | Médico jubilado (`statusCode: "P"`, `status: "Aposentado"`, `isActive: false`). |
| `999999` o `90040401` | `SP` | — | Simulación de error `404 NotFound`. |
