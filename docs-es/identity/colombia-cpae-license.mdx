# Colombia — Matrícula de administración de empresas (CPAE)

La consulta de **matrícula CPAE** lee el Consejo Profesional de Administración de Empresas. `documentNumber` es obligatorio. `documentType` opcional acepta `CC`, `CE`, `TI`, `PEP` o `PPT`. Un acierto devuelve el nombre, la profesión y si la tarjeta está registrada y activa.

## Qué devuelve la llamada

- `fullName` y `profession`
- `entity` — CPAE
- `status`, `isRegistered` e `isActive`

## Casos de uso

- Revise la tarjeta de administración al contratar.
- Confirme que la tarjeta sigue activa.
- Guarde el texto de profesión del CPAE en el expediente KYC.

---

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpae
```

La respuesta incluye `fullName`, `profession`, `entity`, `status`, `isRegistered` e `isActive`. Un número desconocido es 404 `NotFound`.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Sí** | `80123456` | Número de identidad colombiano, de 5 a 15 caracteres. `documentType` puede ser `CC`, `CE`, `TI`, `PEP` o `PPT`. |

### Notas

- `documentNumber` es obligatorio.
- El CPAE responde 404 si el número no tiene tarjeta profesional.
- No envíe un nombre en lugar del número de documento.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.

## Sandbox

| Escenario | Parámetros | Resultado |
| :--- | :--- | :--- |
| Registro en la fuente | `documentNumber: "52987654"` | 200 con profesión y bandera activa. |
| Falta un valor obligatorio | Omit `documentNumber` | 409 MissingParameter. |
| Valor desconocido | `documentNumber: "000000000"` | 404 NotFound si el CPAE no tiene tarjeta. |

401 when the bearer token is missing or rejected.
