# Panamá — Idoneidad de abogado

La consulta de **idoneidad de abogado** lee el certificado del foro panameño por número. Envíe `idoneidad` o el alias `licenseNumber` con 1 a 10 dígitos. `issueDate` opcional usa `DD-MM-YYYY`. Sin número es 409 `MissingParameter`.

## Qué devuelve la llamada

- Número de idoneidad y nombre
- `status`

## Casos de uso

- Confirme un abogado antes de un escrito.
- Cruce la fecha de expedición si la tiene.
- Rechace una idoneidad no numérica.

---

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/pa/lawyer/idoneidad
```

Un acierto incluye el nombre, el número de idoneidad y el estado. Un número desconocido es 404 `NotFound`.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `idoneidad` | string | **Condicional** | `12345` | Número de idoneidad del abogado, de 1 a 10 dígitos. Alias: `licenseNumber`. Uno de los dos es obligatorio. |
| `issueDate` | string | No | `01-02-2010` | Fecha de expedición opcional en `DD-MM-YYYY`. |

### Notas

- Envíe `idoneidad` o `licenseNumber`.
- Solo dígitos, de 1 a 10.
- Los números desconocidos son 404 `NotFound`.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.
