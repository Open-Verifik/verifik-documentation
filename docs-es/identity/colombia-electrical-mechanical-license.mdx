# Colombia — Matrícula de ingeniería eléctrica y mecánica

La consulta de **matrícula de ingeniería eléctrica y mecánica** lee el Consejo Profesional Nacional de Ingenierías Eléctrica, Mecánica y Profesiones Afines. Envíe `documentNumber`, `licenseNumber` o `fullName`. La respuesta incluye la matrícula, la especialidad, el estado y si el consejo reporta sanciones.

## Qué devuelve la llamada

- `licenseNumber` y `specialty`
- `status`, por ejemplo VIGENTE
- `isRegistered` y `hasSanctions`
- `registrations` si la persona tiene más de una fila

## Casos de uso

- Confirme un ingeniero eléctrico o mecánico antes de una obra.
- Lea sanciones disciplinarias junto a la matrícula.
- Cruce el nombre del contrato con la fila del consejo.

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/co/consejo-profesional
```

Una coincidencia incluye `fullName`, `licenseNumber`, `specialty`, `status`, `isRegistered` y `hasSanctions`. Si el consejo no tiene fila, la API responde 404 `NotFound`.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `80123456` | Número de identidad colombiano, de 5 a 15 caracteres. `documentType` puede ser `CC`, `CE`, `TI`, `PEP` o `PPT`. |
| `licenseNumber` | string | **Condicional** | `AN205-27910` | Matrícula profesional, por ejemplo AN205-27910. Basta por sí sola. |
| `fullName` | string | **Condicional** | `ANA PEREZ` | Nombre o apellidos del ingeniero, de 3 a 160 caracteres. Basta por sí solo. |

### Notas

- Envíe al menos uno de `documentNumber`, `licenseNumber` o `fullName`.
- Una fila ausente en el consejo es HTTP 404, no un 200 vacío.
- `documentType` es opcional.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.
