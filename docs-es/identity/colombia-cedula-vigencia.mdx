# Colombia — Estado de cédula (CC)

La consulta de **estado de cédula en Colombia** lee la vigencia de la Registraduría. Envíe `documentNumber`. La respuesta indica si el número existe y si el titular figura como vivo, junto con el texto de estado que publica el registro. Úsela cuando el alta necesita el estado vigente de la CC antes de una consulta de identidad más amplia.

## Qué devuelve la llamada

- `documentType` — CC
- `documentNumber` — la cédula enviada
- `exists` — si el registro tiene el número
- `isAlive` — true, false o null
- `documentStatus` — el texto de vigencia del registro

## Casos de uso

- Confirme que la CC está en el registro antes de abrir una cuenta.
- Separe un registro de persona fallecida de una cédula vigente en el KYC.
- Guarde el texto de estado junto al número de documento.

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/co/cedula/vigencia
```

Una respuesta correcta incluye `documentType` (CC), `documentNumber`, `exists`, `isAlive` y `documentStatus`. `exists` es false cuando el registro indica que el número no está. `isAlive` es true, false o null si la fuente no resuelve esa pregunta. Úsela en un expediente KYC que necesite la vigencia actual.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Sí** | `1121329661` | Cédula de ciudadanía colombiana, de 5 a 10 dígitos, sin espacios ni puntuación. |

### Notas

- `documentNumber` es obligatorio y debe tener de 5 a 10 caracteres.
- `isAlive` puede ser null si el registro devuelve un estado que no define vida o muerte.
- Esta ruta es la consulta de vigencia. No sustituye un perfil completo del ciudadano.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.
