### Endpoint

**GET** `https://api.verifik.co/v2/cost-centers`

Devuelve los centros de costo de tu cuenta. El orden es por país y luego por nombre.

#### encabezados

| Nombre        | Valor              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### parámetros de consulta

#### `active`

**Tipo:** boolean  
**Requerido:** No

`true` devuelve solo los activos. `false` devuelve los inactivos. Si lo omites, devuelve ambos.

#### `country`

**Tipo:** string  
**Requerido:** No

Código de país ISO-2, por ejemplo `ES`.

#### `page`

**Tipo:** number  
**Requerido:** No

Número de página, desde 1.

#### `limit`

**Tipo:** number  
**Requerido:** No

Elementos por página. 50 por defecto, hasta 100.

## Respuestas de error

Una consulta inválida, por ejemplo `limit` mayor que 100 o un `country` que no tiene dos letras:

```json
{
  "message": "\"limit\" must be less than or equal to 100",
  "code": "MissingParameter"
}
```
