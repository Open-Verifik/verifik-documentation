### Descripción

El objeto centro de costo es el registro que Verifik guarda para un equipo, un país o una unidad de negocio. Las solicitudes lo referencian por `_id`. Envías `code` en el header `x-cost-center`.

```json
{
  "_id": "6acfbdda92451bac5d0a7ebe",
  "client": "69c2b824295cd7d276e478ad",
  "name": "Operación España",
  "code": "SPAIN-OPS",
  "country": "ES",
  "active": true,
  "createdAt": "2026-10-14T17:37:30.469Z",
  "updatedAt": "2026-10-14T17:37:30.469Z"
}
```

### Atributos

#### `_id`

**Tipo:** string  
**Requerido:** Sí

Identificador único. Úsalo para consultar, actualizar y desactivar, y al definir el valor por defecto de un proyecto.

#### `client`

**Tipo:** string  
**Requerido:** Sí

La cuenta dueña de este centro de costo.

#### `name`

**Tipo:** string  
**Requerido:** Sí

Nombre visible, hasta 120 caracteres.

#### `code`

**Tipo:** string  
**Requerido:** Sí

El valor que envías en `x-cost-center`. Letras, números, `.`, `-` y `_`, hasta 60 caracteres. Único por cuenta.

#### `country`

**Tipo:** string  
**Requerido:** Sí

País ISO-2 que atiende normalmente este centro de costo, en mayúsculas.

#### `active`

**Tipo:** boolean  
**Requerido:** Sí

Los centros inactivos conservan su historial pero no se asignan a nuevas solicitudes. Por defecto, `true`.

#### `createdAt`

**Tipo:** string  
**Requerido:** Sí

Cuándo se creó el centro de costo, en ISO-8601.

#### `updatedAt`

**Tipo:** string  
**Requerido:** Sí

Cuándo cambió por última vez, en ISO-8601.
