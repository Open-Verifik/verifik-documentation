# Actualizar un centro de costo

```
PUT https://api.verifik.co/v2/cost-centers/{id}
```

Envía cualquiera de `name`, `code`, `country` o `active`. Usa `active: true` para reactivar un centro de costo. Las solicitudes ya registradas conservan el centro de costo que tenían.
