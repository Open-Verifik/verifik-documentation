### Endpoint

**PUT** `https://api.verifik.co/v2/cost-centers/{id}`

Actualiza un centro de costo. Envía solo los campos que quieres cambiar. Las solicitudes ya registradas conservan el centro de costo que tenían.

#### encabezados

| Nombre        | Valor              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### parámetros de ruta

#### `id`

**Tipo:** string  
**Requerido:** Sí

El id del centro de costo.

#### parámetros del cuerpo

#### `name`

**Tipo:** string  
**Requerido:** No

Nombre visible, hasta 120 caracteres.

#### `code`

**Tipo:** string  
**Requerido:** No

Nuevo valor del header. Letras, números, `.`, `-` y `_`, hasta 60 caracteres. Único por cuenta.

#### `country`

**Tipo:** string  
**Requerido:** No

Código de país ISO-2.

#### `active`

**Tipo:** boolean  
**Requerido:** No

Usa `true` para reactivar un centro, o `false` para que no se asigne a nuevas solicitudes.

### Ejemplo de solicitud

## Respuestas de error

Id desconocido:

```json
{
  "message": "cost_center_not_found",
  "code": "NotFound"
}
```

Un `code` que otro centro de la cuenta ya usa:

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```
