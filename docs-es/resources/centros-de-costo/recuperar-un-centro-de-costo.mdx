# Consultar un centro de costo

```
GET https://api.verifik.co/v2/cost-centers/{id}
```

Devuelve el [objeto centro de costo](/verifik-es/resources/centros-de-costo/el-objeto-centro-de-costo), o `404` con `cost_center_not_found`.
