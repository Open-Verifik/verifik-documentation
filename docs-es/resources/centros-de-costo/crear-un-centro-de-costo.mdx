# Crear un centro de costo

```
POST https://api.verifik.co/v2/cost-centers
```

| Nombre    | Tipo    | Requerido | Descripción                        |
| --------- | ------- | --------- | ---------------------------------- |
| `name`    | string  | Sí        | Nombre visible.                    |
| `code`    | string  | Sí        | Valor del header. Único por cuenta. |
| `country` | string  | Sí        | Código de país ISO-2.              |
| `active`  | boolean | No        | Por defecto, `true`.               |

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X POST "https://api.verifik.co/v2/cost-centers" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Operación España","code":"SPAIN-OPS","country":"ES"}'
```

</TabItem>
<TabItem value="nodejs" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.post(
	"https://api.verifik.co/v2/cost-centers",
	{ name: "Operación España", code: "SPAIN-OPS", country: "ES" },
	{ headers: { Authorization: `Bearer ${process.env.VERIFIK_TOKEN}` } }
);

console.log(data.data._id);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.post(
    "https://api.verifik.co/v2/cost-centers",
    headers={"Authorization": f"Bearer {os.environ['VERIFIK_TOKEN']}"},
    json={"name": "Operación España", "code": "SPAIN-OPS", "country": "ES"},
)

print(response.json()["data"]["_id"])
```

</TabItem>
</Tabs>

La respuesta es el nuevo [objeto centro de costo](/verifik-es/resources/centros-de-costo/el-objeto-centro-de-costo) dentro de `data`. Si el código ya existe, la respuesta es:

```json
{
	"code": "Conflict",
	"message": "cost_center_code_taken"
}
```
