### Endpoint

**POST** `https://api.verifik.co/v2/cost-centers`

Crea un centro de costo en tu cuenta. Administrar centros de costo no consume créditos.

#### encabezados

| Nombre        | Valor              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### parámetros del cuerpo

#### `name`

**Tipo:** string  
**Requerido:** Sí

Nombre visible, hasta 120 caracteres.

#### `code`

**Tipo:** string  
**Requerido:** Sí

Valor que enviarás en `x-cost-center`. Letras, números, `.`, `-` y `_`, hasta 60 caracteres. Único por cuenta.

#### `country`

**Tipo:** string  
**Requerido:** Sí

Código de país ISO-2, por ejemplo `ES`.

#### `active`

**Tipo:** boolean  
**Requerido:** No

Por defecto, `true`.

### Ejemplo de solicitud

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X POST "https://api.verifik.co/v2/cost-centers" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Operación España","code":"SPAIN-OPS","country":"ES"}'
```

</TabItem>

## Respuestas de error

Un código que ya existe en la cuenta:

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```

Un campo ausente o inválido, como `name`, `code` o `country`:

```json
{
  "message": "\"name\" is required",
  "code": "MissingParameter"
}
```
