### Endpoint

**DELETE** `https://api.verifik.co/v2/cost-centers/{id}`

Desactiva un centro de costo. El registro no se borra: `active` pasa a `false` y el historial de uso sigue ligado a él. Las solicitudes nuevas ya no pueden usar este centro.

#### encabezados

| Nombre        | Valor              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### parámetros de ruta

#### `id`

**Tipo:** string  
**Requerido:** Sí

El id del centro de costo que quieres desactivar.
