# Chile - Certificado de Antecedentes

El **Certificado de Antecedentes** es el certificado de registros penales que emite el Registro Civil de Chile (SRCEI). Las plataformas de transporte y reparto suelen pedirlo a los conductores durante el registro.

Verifik lo valida con el endpoint de [Verificación de Certificado del Registro Civil](/verifik-es/verificacion-antecendentes/verificacion-antecendentes-chile-certificado-registro-civil). No necesitas un producto aparte.

## Qué pedirle al postulante

| Campo              | Dónde aparece en el certificado      | Ejemplo        |
| ------------------ | ------------------------------------ | -------------- |
| `folio`            | Número de folio, de 10 a 15 caracteres | `50070080804`  |
| `verificationCode` | Código Verificador                   | `2aacbb9a636a` |

## Solicitud

```bash
curl -G "https://api.verifik.co/v2/cl/registro-civil/certificado" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  --data-urlencode "folio=50070080804" \
  --data-urlencode "verificationCode=2aacbb9a636a"
```

La respuesta confirma que el Registro Civil emitió el certificado. Devuelve `name`, `run` y `dateOfBirth` del titular, cada registro de condenas con su campo `fines` (por ejemplo `No registra anotaciones`) y el PDF oficial en `urlPDF` y `pdfBase64`. Consulta la [referencia completa](/verifik-es/verificacion-antecendentes/verificacion-antecendentes-chile-certificado-registro-civil) para ver todos los campos y errores.

## Validaciones de onboarding

- **Confirma el titular.** Compara `details.run` con el documento del postulante.
- **Revisa la fecha de emisión.** Muchos programas solo aceptan certificados emitidos en los últimos 60 días. La fecha de emisión aparece en el PDF devuelto.
- **Revisa los registros.** Cada elemento de `details.registers` indica un registro y lo que contiene. Define cuáles impiden el registro según tu política.

La consulta de antecedentes solo con el RUN requiere la ClaveÚnica del postulante, así que el folio del certificado es la forma de validarlo con Verifik.
