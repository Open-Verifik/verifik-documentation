# Chile - Vehículo en el registro de transporte (D80)

Las plataformas de transporte en Chile preguntan a los conductores si usan auto particular, taxi o **D80**. Los taxis y los vehículos D80 deben estar inscritos en el Ministerio de Transportes y Telecomunicaciones (MTT).

Verifik valida esa inscripción por patente con el endpoint de [Vehículo de transporte en Chile](/verifik-es/validacion-vehiculos/chile/transport-vehicle). No necesitas un producto aparte.

## Solicitud

```bash
curl -G "https://api.verifik.co/v2/cl/transport-vehicle" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  --data-urlencode "plate=BBCC12"
```

Envía la patente sin espacios, puntos ni guiones.

## Qué revisar en la respuesta

| Campo                    | Úsalo para                                                                                 |
| ------------------------ | ------------------------------------------------------------------------------------------ |
| `serviceType`            | Confirmar la categoría inscrita, como `TRANSPORTE URBANO DE PASAJEROS`. Compárala con las categorías que acepta tu programa. |
| `vehicleStatus`          | Aceptar solo vehículos con estado `VIGENTE`.                                               |
| `serviceExpiryDate`      | Rechazar o marcar inscripciones que vencen antes de tu próxima revisión.                   |
| `serviceResponsibleName` | Comparar con el conductor o el dueño de la flota registrado.                               |
| `brand`, `model`, `plate` | Confirmar el vehículo que declaró el conductor.                                           |

Una patente que no está en el registro del MTT devuelve `404`. Eso indica que el vehículo no está inscrito para transporte de pasajeros, que es el resultado esperado para un auto particular.

Consulta la [referencia completa](/verifik-es/validacion-vehiculos/chile/transport-vehicle) para ver todos los campos y errores.
