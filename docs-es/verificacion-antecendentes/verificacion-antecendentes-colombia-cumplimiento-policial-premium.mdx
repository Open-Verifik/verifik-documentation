# RNMC de la Policía premium

El mismo resultado de medidas correctivas que [Cumplimiento policial](/verifik-es/verificacion-antecendentes/verificacion-antecendentes-colombia-cumplimiento-policial). Envías el número de la cédula de ciudadanía. Verifik resuelve la fecha de expedición. No envías `date`.

## Qué consulta usar

| | RNMC estándar | RNMC premium |
| --- | --- | --- |
| Endpoint | `GET /v2/co/policia/rnmc` | `GET /v2/co/policia/rnmc/premium` |
| Créditos | **0.30** | **1.20** |
| Tipos de documento | `CC`, `CE`, `PPT`, `PA` | Solo `CC` |
| Fecha de expedición | Tú envías `date` (`DD/MM/YYYY`) | No es un parámetro. Verifik la resuelve |
| Resultado | Medidas correctivas pendientes | Los mismos campos |

Usa la consulta estándar cuando ya tienes la fecha de expedición, o cuando el documento es `CE`, `PPT` o `PA`. Usa premium cuando solo tienes el número de `CC` y quieres que Verifik resuelva la fecha. Premium cuesta más porque esa resolución va incluida.

## Referencia de API

### Endpoint

```
https://api.verifik.co/v2/co/policia/rnmc/premium
```

### Headers

| Nombre        | Valor              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

### Parámetros

| Nombre           | Tipo   | Requerido | Descripción                                              |
| ---------------- | ------ | --------- | -------------------------------------------------------- |
| `documentType`   | string | Sí        | Debe ser `CC`.                                           |
| `documentNumber` | string | Sí        | Número de cédula, sin espacios ni puntos.                |

No envíes `date`. Si ya tienes la fecha de expedición, llama el [endpoint RNMC estándar](/verifik-es/verificacion-antecendentes/verificacion-antecendentes-colombia-cumplimiento-policial).

### Request

<Tabs>
<TabItem value="javascript" label="JavaScript">

```javascript
import axios from 'axios';

const options = {
  method: 'GET',
  url: 'https://api.verifik.co/v2/co/policia/rnmc/premium',
  params: {
    documentType: 'CC',
    documentNumber: '123456789',
  },
  headers: {
    Accept: 'application/json',
    Authorization: 'Bearer <tu_token>',
  },
};

const { data } = await axios.request(options);
console.log(data);
```

</TabItem>

### Respuesta

El objeto `data` usa los mismos campos que la consulta RNMC estándar: `documentType`, `documentNumber`, `fullName`, `firstName`, `lastName`, `arrayName`, `date`, `legend`, `records` y `correctiveMeasures`. `date` es la fecha de expedición usada en la consulta, en formato `DD/MM/YYYY`.
