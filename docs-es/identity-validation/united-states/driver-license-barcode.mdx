# Estados Unidos — Código de Barras de Licencia de Conducir (AAMVA PDF417)

La API de **Código de Barras de Licencia de Conducir de EE. UU.** de Verifik procesa, decodifica y audita códigos bidimensionales **PDF417** presentes en el reverso de licencias de conducir e identificaciones estatales emitidas en los 50 estados de Estados Unidos, Washington D.C., territorios estadounidenses y provincias de Canadá.

Compatible con las versiones **01 a la 10 del estándar ANSI/AAMVA**, la API extrae más de 30 elementos de datos normalizados, mapea el código de emisor (IIN de 6 dígitos) contra la jurisdicción oficial, calcula flags de mayoría de edad (`age`, `isUnder18`, `isUnder21`), detecta fechas de vencimiento y audita el cumplimiento normativo **REAL ID**.

---

## Casos de Uso

- **Onboarding Digital Móvil y Web:** Extracción automática de nombres, dirección, fecha de nacimiento y número de licencia a partir de la captura del reverso del documento, eliminando la digitación manual.
- **Verificación de Edad en Comercios Regulados:** Comprobación rigurosa de mayoría de edad para plataformas de apuestas en línea, alcohol o servicios restringidos.
- **Validación Normativa REAL ID:** Confirmación de identificaciones certificadas bajo la ley federal REAL ID para acreditación de identidad.

---

### Endpoint

```http
POST https://api.verifik.co/v2/usa/driver-license/barcode
```

### Headers

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Content-Type` | `application/json` | Sí | Formato de envío JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parameters

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `rawBarcode` | string | **Condicional** | Contenido en texto sin formato del código de barras PDF417 (con encabezado ANSI/AAMVA). Requerido si no se envía `backImage`. |
| `backImage` | string | **Condicional** | Imagen del reverso de la licencia con el código de barras legible en formato Base64 o URL HTTPS. Requerido si no se envía `rawBarcode`. |
| `licenseNumber` | string | No | Número de licencia para comprobación adicional de consistencia. |
| `state` | string | No | Código postal de 2 letras del estado emisor (ej. `CA`, `FL`, `TX`, `NY`). |

```javascript
import axios from "axios";

const options = {
  method: "POST",
  url: "https://api.verifik.co/v2/usa/driver-license/barcode",
  headers: {
    Accept: "application/json",
    "Content-Type": "application/json",
    Authorization: "Bearer <tu_token>",
  },
  data: {
    backImage: "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
    state: "CA",
  },
};

try {
  const { data } = await axios.request(options);
  console.log(JSON.stringify(data, null, 2));
} catch (error) {
  console.error("Error al decodificar código AAMVA:", error.response?.data || error.message);
}
```

## Perfiles de Prueba Sandbox

| Parámetro | Valor de Entrada | Resultado Esperado |
| :--- | :--- | :--- |
| `rawBarcode` | Cadena AAMVA estándar con IIN `636014` | Decodificación 200 OK (`issuerName: "California"`, `isRealIdCompliant: true`) |
| `backImage` | Imagen sintética de prueba AAMVA válida | Extracción óptica de código PDF417 y resolución de campos demográficos |
| `rawBarcode` | Cadena aleatoria no AAMVA | 400 InvalidBarcode |

## Datos de Prueba (Sandbox Probes)

Utilice los siguientes parámetros de prueba en modo Sandbox para simular cada escenario de respuesta sin consumir créditos de producción:

| Escenario | Parámetros a Enviar | Estado HTTP y Resultado Esperado |
| :--- | :--- | :--- |
| **Licencia REAL ID de California Válida** | `licenseNumber: "D1234567"`, `state: "CA"` (o `rawBarcode` de ejemplo) | `200 OK` — `verdict: "decoded"`, `firstName: "JOHN"`, `lastName: "DOE"`, `iin: "636014"`, `issuerName: "California"`, `isRealIdCompliant: true` |
| **Código de Barras Ilegible / Inválido** | `licenseNumber: "UNREADABLE"` o `rawBarcode: "INVALID"` | `404 Not Found` — `code: "NotFound"`, `message: "unreadable_barcode"` |
| **Parámetros Faltantes** | Omitir `rawBarcode`, `backImage` y `licenseNumber` | `409 Conflict` — `code: "MissingParameter"` |
