# Estados Unidos — Verificación Cruzada de Licencia (Frente vs Reverso)

La API de **Verificación Cruzada de Licencia de Conducir de EE. UU.** de Verifik implementa una defensa anti-fraude de dos factores documentales. Compara de forma estricta los datos demográficos y de identificación visualizados en el anverso de la credencial contra la carga de datos cifrada y codificada en el código de barras bidimensional **AAMVA PDF417** del reverso.

Esta técnica detecta de inmediato intentos comunes de falsificación (tampering), tales como la superposición de fotografías o alteración de nombres y fechas de nacimiento en el frente mientras el código de barras conserva los datos del titular original o de otra tarjeta.

---

## Casos de Uso

- **Prevención de Suplantación de Identidad:** Detección de identificaciones manipuladas donde el nombre o fecha de nacimiento visible fue modificado digitalmente o mediante pegatinas.
- **Auditoría Forense de Documentos KYC:** Acreditación de autenticidad documental previa a la apertura de cuentas bancarias o transacciones de alto valor.
- **Automatización de Decisiones de Riesgo:** Generación de un veredicto definitivo (`confirmed` o `mismatch`) con puntaje ponderado de coincidencia (`matchScore`).

---

### Endpoint

```http
POST https://api.verifik.co/v2/usa/driver-license/cross-check
```

### Headers

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Content-Type` | `application/json` | Sí | Formato de envío JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parameters

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `licenseNumber` | string | Sí | Número de licencia extraído u observado en el frente de la credencial (ej. `D1234567`). |
| `firstName` | string | Sí | Nombre(s) de pila del titular tal como aparece en el frente de la credencial (ej. `JOHN`). |
| `lastName` | string | Sí | Apellido(s) del titular tal como aparece en el frente de la credencial (ej. `DOE`). |
| `backImage` | string | **Condicional** | Imagen del reverso de la licencia con el código de barras PDF417 en Base64 o URL HTTPS. Requerido si no se envía `rawBarcode`. |
| `rawBarcode` | string | **Condicional** | Cadena de texto del código de barras si ya fue decodificada previamente. Requerido si no se envía `backImage`. |
| `dateOfBirth` | string | No | Fecha de nacimiento en formato `YYYY-MM-DD` (ej. `1990-05-15`). |
| `state` | string | No | Código de 2 letras del estado emisor (ej. `CA`, `FL`, `TX`). |

```javascript
import axios from "axios";

const options = {
  method: "POST",
  url: "https://api.verifik.co/v2/usa/driver-license/cross-check",
  headers: {
    Accept: "application/json",
    "Content-Type": "application/json",
    Authorization: "Bearer <tu_token>",
  },
  data: {
    licenseNumber: "D1234567",
    firstName: "JOHN",
    lastName: "DOE",
    dateOfBirth: "1990-05-15",
    state: "CA",
    backImage: "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
  },
};

try {
  const { data } = await axios.request(options);
  console.log(JSON.stringify(data, null, 2));
} catch (error) {
  console.error("Error al verificar concordancia de licencia:", error.response?.data || error.message);
}
```
