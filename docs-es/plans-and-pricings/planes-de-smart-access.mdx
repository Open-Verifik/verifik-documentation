# Planes de Smart Access

Smart Access (Acceso Inteligente) ofrece planes diseñados para empresas que requieren soluciones de autenticación sin contraseña escalables, seguras y altamente personalizadas.

## Características

- ✅ **Autenticación Sin Contraseña**: Múltiples métodos de autenticación (email, teléfono, biométrica)
- ✅ **Personalización Completa**: Logo, imágenes, esquema de colores y branding completo
- ✅ **Integración de Base de Datos**: Conexión API y carga CSV para gestión de usuarios
- ✅ **Gestión de Equipo Avanzada**: Control granular de roles y permisos
- ✅ **Webhooks Configurables**: Integración en tiempo real con tu backend

## Planes smartCHECK (consultas a registros oficiales)

Estos precios son del catálogo de **smartCHECK** (cruce con registros oficiales). No son los planes de Smart Access.

| Plan | Mensual | Anual |
| --- | ---: | ---: |
| Starter | $49 | $490 |
| Basic | $129 | $1,290 |
| Plus | $299 | $2,990 |
| Business | $649 | $6,490 |

Los planes bajan el precio por llamada en **la mayoría** de las APIs. No hay un descuento fijo que aplique a todas. Algunas APIs mantienen el mismo precio por llamada en todos los planes.

Las consultas a registros oficiales del catálogo público empiezan en **$0,05** por llamada. La mediana del precio de lista es **$0,30**. El catálogo público de esta sincronización tiene **409** APIs en **51** países.

Precios vigentes: [verifik.co/precios](https://verifik.co/precios/) y [verifik.co/en/pricing](https://verifik.co/en/pricing/).
