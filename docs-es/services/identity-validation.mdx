# Validación de Identidad

:::info Integración con SmartCheck
La validación de identidad es un pilar fundamental de **SmartCheck**, la plataforma unificada de verificación de Verifik. Puedes probar los endpoints de identidad interactivamente en la consola de SmartCheck en [ai.verifik.co](https://ai.verifik.co) o automatizar validaciones masivas mediante [SmartBatch](/verifik-es/smart-batch).
:::

Verifik proporciona APIs en tiempo real de **Validación de Identidad** para verificar credenciales personales, documentos oficiales de identificación y datos biométricos en más de 20 países de América Latina, Norteamérica y Europa.

Nuestros servicios de identidad se conectan de forma segura con la fuente oficial y registros gubernamentales autorizados para confirmar la validez documental, autenticidad y estado de ciudadanía en milisegundos.

---

## Capacidades Principales

La suite de validación de identidad de Verifik cubre el ciclo completo de verificación de identidad:

### 1. Verificación de Autenticidad Documental
Confirma la existencia y vigencia de documentos oficiales de identificación:
- **Cédulas y Documentos Nacionales de Identidad**: Cédula de Ciudadanía, DNI, RG, CURP/INE, cédula de identidad civil.
- **Identificación para Extranjeros**: Cédula de extranjería, permisos por protección temporal y tarjetas de residencia.
- **Pasaportes y Visas**: Documentos internacionales de viaje y vigencia de visados.
- **Licencias de Conducción**: Validación ante autoridades de tránsito y registros oficiales.
- **Identificadores Tributarios y de Seguridad Social**: SSN, SIN, CPF, RUT y registros ciudadanos.

### 2. Cotejo de Datos Demográficos y Biográficos
Garantiza que la información suministrada coincida con los registros oficiales:
- Nombres y apellidos completos (primer nombre, segundo nombre, primer apellido, segundo apellido).
- Fecha de nacimiento y edad calculada.
- Género y estado civil.
- Fecha de expedición del documento y municipio o departamento emisor.
- Estado del documento (vigente, cancelado por muerte, suspendido o no expedido).

### 3. Detección de Vivacidad Biométrica y Cotejo Facial
Previene la suplantación de identidad y ataques de presentación mediante biometría avanzada:
- Detección de vivacidad pasiva y activa (certificación ISO 30107-3).
- Cotejo facial 1:1 entre una selfie en vivo y la fotografía del documento oficial.
- Algoritmos antifraude para detectar fotos impresas, pantallas y deepfakes.

## Cobertura Geográfica

Verifik ofrece soporte de verificación de identidad en más de 20 países:

| Región | Países Disponibles | Tipos de Documento Principales |
|---|---|---|

| **Sudamérica** | Colombia, Brasil, Argentina, Chile, Perú, Ecuador, Bolivia, Paraguay, Uruguay, Venezuela | Cédula, DNI, RG, CPF, RUT, Cédula de Extranjería |

| **Europa** | España | DNI, NIE, CIF |

## Integración de la API

Puedes integrar la validación de identidad directamente en tu flujo de registro o incorporación de usuarios utilizando nuestra API REST.

### Autenticación
Incluye tu token JSON Web Token (JWT) en el encabezado `Authorization`:

```http
Authorization: Bearer <tu_token_jwt>
```

### Ejemplo de Solicitud

<Tabs>
<TabItem value="curl" label="cURL">

```bash
curl -X POST https://api.verifik.co/v2/identity \
  -H "Authorization: Bearer <tu_token_jwt>" \
  -H "Content-Type: application/json" \
  -d '{
    "documentType": "CC",
    "documentNumber": "1234567890",
    "country": "CO"
  }'
```

</TabItem>
<TabItem value="nodejs" label="Node.js">

```javascript
const axios = require('axios');

async function validarIdentidad() {
  try {
    const respuesta = await axios.post(
      'https://api.verifik.co/v2/identity',
      {
        documentType: 'CC',
        documentNumber: '1234567890',
        country: 'CO'
      },
      {
        headers: {
          'Authorization': `Bearer ${process.env.VERIFIK_API_KEY}`,
          'Content-Type': 'application/json'
        }
      }
    );

    console.log('Resultado de la validación:', respuesta.data);
  } catch (error) {
    console.error('Error al validar identidad:', error.response?.data || error.message);
  }
}

validarIdentidad();
```

## Códigos de Estado HTTP

| Código HTTP | Descripción | Acción Requerida |
|---|---|---|
| `200 OK` | Validación completada exitosamente | Procesar el payload verificado |
| `400 Bad Request` | Parámetros faltantes o formato incorrecto | Validar que `documentType` y `documentNumber` sean válidos |
| `401 Unauthorized` | Token de API inválido o expirado | Generar un nuevo token en el panel de control |
| `404 Not Found` | Documento no encontrado en el registro oficial | Verificar datos con el usuario final |
| `422 Unprocessable` | Estado documental inactivo o cancelado | Evaluar alertas de validación |
| `500 Server Error` | Servicio oficial temporalmente no disponible | Implementar reintentos con espera exponencial |

## Procesamiento Masivo con SmartBatch

Para procesar miles de identidades en lotes:
1. Accede a **SmartBatch** en [ai.verifik.co/smart-batch](https://ai.verifik.co/smart-batch).
2. Crea o selecciona una configuración de lote apuntando al servicio de validación de identidad.
3. Carga un archivo CSV o Excel mapeando las columnas requeridas (`documentNumber`, `documentType`).
4. Ejecuta de forma síncrona o asíncrona recibiendo alertas mediante webhook al finalizar.

## Seguridad y Cumplimiento

- **Privacidad de Datos**: Verifik no almacena copias de documentos confidenciales sin autorización explícita y configuración de retención de datos.
- **Marcos Regulatorios**: Cumplimiento riguroso con RGPD (GDPR), Ley 1581 de protección de datos personales en Colombia y LGPD en Brasil.
- **Cifrado en Tránsito**: Todo el tráfico viaja bajo protocolos TLS 1.3 con firmas criptográficas SHA-256 en las respuestas.
