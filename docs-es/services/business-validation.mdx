# Validación Empresarial

:::info Integración con SmartCheck
Automatiza procesos de conocimiento de empresas (KYB) y auditorías corporativas desde el panel de **SmartCheck** en [ai.verifik.co](https://ai.verifik.co) o ejecuta revisiones masivas de proveedores con [SmartBatch](/verifik-es/smart-batch).
:::

Las APIs de **Validación Empresarial** de Verifik ofrecen acceso programático a registros mercantiles oficiales, bases de datos de autoridades tributarias y sistemas de supervisión societaria en América Latina, Norteamérica y Europa.

Diseñadas para pasarelas de pago, entidades financieras, marketplaces B2B y departamentos de compras, nuestras soluciones agilizan la vinculación de comercios, evaluación de riesgo crediticio y cumplimiento normativo corporativo.

## Capacidades de Validación

Nuestra plataforma cubre cinco dimensiones clave de análisis empresarial:

### 1. Estado Jurídico y Registro Mercantil
Verifica la existencia legal, datos de constitución y vigencia operativa de personas jurídicas:
- **Identidad Corporativa**: Razón social inscrita, nombre comercial o de fantasía, y tipo societario (SAS, SA, SRL, LLC).
- **Datos de Matrícula**: Jurisdicción registral, número de matrícula mercantil y fecha de constitución.
- **Estado Operativo**: Activa, disuelta, en liquidación judicial o cancelada.
- **Vigencia y Renovación**: Fecha de última renovación de la matrícula mercantil y cumplimiento de obligaciones registrales.

### 2. Identificación Tributaria y Régimen Fiscal
Valida números de identificación fiscal y estado ante la autoridad tributaria:
- **Número de Identificación Tributaria**: Validación de NIT, RFC, RUC, CNPJ, CUIT, CIF o EIN.
- **Dígito de Verificación**: Validación matemática y oficial del dígito de control del número tributario.
- **Clasificación Tributaria**: Régimen común, régimen simplificado, responsabilidades fiscales y agentes de retención.
- **Facturación Electrónica**: Estado de habilitación como facturador electrónico ante la autoridad tributaria competente.

### 3. Representación Legal y Gobierno Corporativo
Identifica a los representantes legales y beneficiarios finales:
- Representantes legales principales y suplentes.
- Tipos y números de documento de identidad de los apoderados y directivos.
- Composición de la junta directiva y designación de revisores fiscales.
- Facultades y límites estatutarios de contratación y firma.

### 4. Clasificación de Actividades Económicas
Determina el modelo de negocio y sector productivo:
- Códigos de Clasificación Industrial Internacional Uniforme (CIIU / NAICS) principal y secundarios.
- Descripción de actividades comerciales registradas en el objeto social.
- Tamaño empresarial (micro, pequeña, mediana o gran empresa) según activos e ingresos declarados.

### 5. Control de Cumplimiento y Listas Restrictivas
Coteja la empresa y sus administradores contra bases de datos de cumplimiento:
- Tamizaje en listas de sanciones internacionales, control de lavado de activos y listas PEP.
- Inhabilidades para contratación pública y registros de sanciones administrativas.
- Estado de deudores morosos y boletines de responsabilidad fiscal.

## Cobertura Geográfica

| Región | Identificador Principal | Registros Oficiales Consultados |
|---|---|---|
| **Colombia** | NIT, Razón Social | Registro Único Empresarial y Social (RUES), Autoridad Tributaria Nacional |
| **México** | RFC, Razón Social | Servicio de Administración Tributaria (SAT), Registro Público de Comercio |
| **Brasil** | CNPJ, Razão Social | Receita Federal do Brasil, Juntas Comerciais |
| **Chile** | RUT Empresa | Servicio de Impuestos Internos (SII), Registro de Empresas y Sociedades |
| **Perú** | RUC Empresa | SUNAT, Superintendencia Nacional de los Registros Públicos (SUNARP) |
| **Argentina** | CUIT Empresa | AFIP, Inspección General de Justicia (IGJ) |
| **Estados Unidos** | EIN, Número Estatal | Archivos comerciales de Secretarías de Estado, Validación IRS EIN |
| **España** | CIF, NIF | Registro Mercantil Central, Agencia Tributaria (AEAT) |

## Integración de la API

Consulta información corporativa mediante el número de identificación tributaria (`taxId`) y el código del país:

### Autenticación
Incluye tu token Bearer en el encabezado de la petición:

```http
Authorization: Bearer <tu_token_jwt>
```

### Ejemplo de Solicitud

<Tabs>
<TabItem value="curl" label="cURL">

```bash
curl -X POST https://api.verifik.co/v2/business \
  -H "Authorization: Bearer <tu_token_jwt>" \
  -H "Content-Type: application/json" \
  -d '{
    "taxId": "900123456",
    "verificationDigit": "7",
    "country": "CO"
  }'
```

</TabItem>
<TabItem value="nodejs" label="Node.js">

```javascript
const axios = require('axios');

async function validarEmpresa() {
  try {
    const respuesta = await axios.post(
      'https://api.verifik.co/v2/business',
      {
        taxId: '900123456',
        verificationDigit: '7',
        country: 'CO'
      },
      {
        headers: {
          'Authorization': `Bearer ${process.env.VERIFIK_API_KEY}`,
          'Content-Type': 'application/json'
        }
      }
    );

    console.log('Información Corporativa:', respuesta.data);
  } catch (error) {
    console.error('Error al validar empresa:', error.response?.data || error.message);
  }
}

validarEmpresa();
```

## Códigos de Estado HTTP

| Código HTTP | Descripción | Acción Requerida |
|---|---|---|
| `200 OK` | Empresa validada correctamente | Procesar los datos corporativos obtenidos |
| `400 Bad Request` | Parámetros o formato de número tributario no válido | Verificar número de identificación y dígito |
| `401 Unauthorized` | Token de autorización expirado | Renovar credenciales de API |
| `404 Not Found` | Empresa no registrada en la base de datos oficial | Confirmar información con el solicitante |
| `500 Server Error` | Servicio oficial de registro temporalmente no disponible | Reintentar la solicitud con espera exponencial |

## Casos de Uso Empresariales

- **Vinculación de Comercios (KYB)**: Validación inmediata de registro mercantil, régimen tributario y facturación para adquirencia y pasarelas de pago.
- **Homologación de Proveedores**: Automatización de revisiones periódicas de certificados de existencia, representantes legales y vigencia de matrículas.
- **Evaluación Crediticia B2B**: Verificación de antigüedad empresarial, capital suscrito y sector económico antes del otorgamiento de cupos de crédito.
