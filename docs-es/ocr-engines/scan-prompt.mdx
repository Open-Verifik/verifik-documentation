### Endpoint

```
https://api.verifik.co/v2/ocr/scan-prompt
```

Escaneo Prompt con Integración de IA es una herramienta poderosa diseñada para optimizar la extracción de texto de documentos legales, apoyando tu proceso de Conoce a tu Cliente (KYC). Este servicio utiliza IA avanzada para detectar automáticamente tipos de documentos y emplea tecnología propietaria para una extracción de datos precisa.

### Headers

| Name | Value |
| --- | --- |
| Content-Type | `application/json` |
| Authorization | `Bearer <token>` |

### Parámetros

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `image` | string | Yes | Imagen en formato Base64 codificado o una URL donde está alojada la imagen. |
| `cropFace` | boolean | No | Si quieres recortar la cara del documento, pasa esto como `true`. |
| `documentType` | string | No | Puedes especificar el documentType para que la IA no tenga que adivinar qué tipo de documento estamos extrayendo. |

### Características

1. **Extracción de Tipo de Documento con IA**: Identifica automáticamente el tipo de documento legal.
2. **Extracción de datos precisa**: Emplea tecnología personalizada para extraer información relevante con alta precisión.
3. **Plantillas de prompts flexibles**: Utiliza prompts del sistema pre-diseñados para una extracción eficiente lista para usar. También permite a los usuarios crear plantillas personalizadas para refinar la lógica, ajustar campos extraídos, o mejorar el proceso agregando/eliminando puntos de datos.

### Coincidencia del documento

Cuando `documentType` es `CC` (cédula colombiana) o `DRCC` (licencia de conducción colombiana), `OCRExtraction` incluye `documentClassification`:

```json
"documentClassification": {
  "requestedDocumentType": "CC",
  "detectedDocumentType": "DRCC",
  "detectedDocumentName": "Licencia de Conducción",
  "isMatch": false,
  "confidence": 1,
  "reason": "El documento es una licencia de conducción del Ministerio de Transporte."
}
```

- `detectedDocumentType` es `CC`, `DRCC` o `UNKNOWN`.
- `isMatch` es true solo cuando la foto es el documento que pediste.
- Una licencia enviada como `CC` sigue respondiendo HTTP 200, y `documentType` permanece `CC`. `isMatch` es false. Rechaza esa foto en tu aplicación.
- Una cédula enviada como `DRCC` funciona igual en el otro sentido.
- Un pasaporte, una tarjeta de vehículo (`TLCC`) o una clasificación que no pudo ejecutarse es `UNKNOWN`, con `isMatch` en false.

El mismo escaneo puede continuar en un SmartCheck desde [Smart Agent](https://ai.verifik.co). Se lee la foto, y una verificación configurada en ese tipo de documento, como la consulta de cédula colombiana, puede ejecutarse con el número que extrajo el OCR.

### Retención de datos

Una llamada que no está ligada a un proyecto sigue estas reglas. La respuesta de ejemplo de arriba muestra una `url` alojada de un escaneo guardado. Un escaneo sin proyecto no sube un archivo alojado.

| | Respuesta inmediata | Fila guardada del escaneo |
| --- | --- | --- |
| `url`, `backUrl` | URI `data:` de las imágenes de esta petición. Consérvalas con esta respuesta. Son valores de imagen en línea, y no son enlaces duraderos a archivos. | No se sube ningún archivo alojado. |
| `OCRExtraction`, `fullName` | Valores completos, tal como se leyeron. | Enmascarados. |
| `documentNumber` | Valor completo. | Valor completo. La fila guardada lo conserva en claro. |

Una copia cifrada de la extracción completa se elimina 30 días después del escaneo. Un cambio de política aplica a los escaneos creados después del cambio.

Un escaneo de SmartEnroll ligado a un registro de aplicación usa la política de cuenta, proyecto y flujo. La respuesta sigue incluyendo la extracción sin enmascarar. La extracción guardada se enmascara cuando `ocrExtraction` es `none`. En `none` y `ephemeral`, esa respuesta omite las URL alojadas y puede incluir `hasFrontImage` y `hasBackImage`.

Consulta [Retención de datos](/verifik-es/getting-started/data-retention) y [Escaneo Agent](/verifik-es/ocr-engines/escaneo-agente).

### Notas

- Usa imágenes codificadas en Base64 o URLs directas para el parámetro `image`.
- El parámetro `cropFace` ayuda a mejorar la precisión enfocándose en el contenido del documento.
- Especifica `documentType` cuando conozcas el tipo de documento para mejores resultados.
