# Scan Agent

**Scan Agent** extrae campos estructurados de la imagen de un documento. Llame **POST** `https://api.verifik.co/v2/ocr/scan-gpt`. `image` es obligatoria. `documentType`, `backImage` y `template` son opcionales. Este cuerpo no tiene un campo `country`. La extracción guardada pone `validationMethod` en `SCAN_AGENT`.

## Qué devuelve la llamada

- `documentType`, `documentNumber` y nombre extraídos
- `validationMethod` — `SCAN_AGENT`

## Casos de uso

- Lea un documento de identidad desde una imagen.
- Agregue la imagen posterior si la tarjeta tiene reverso.
- Fije una plantilla si el formato es conocido.

---

## Referencia de la API

### Endpoint

```http
POST https://api.verifik.co/v2/ocr/scan-gpt
```

Un acierto incluye los campos extraídos y `validationMethod` `SCAN_AGENT`. La URL sigue siendo `/v2/ocr/scan-gpt`.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `image` | string | **Sí** | `data:image/jpeg;base64,AAAA` | Imagen frontal en base64 o data URI. Obligatoria. |
| `documentType` | string | No | `CC` | Familia de documento opcional, como `CC` o `DNI`. |
| `backImage` | string | No | `data:image/jpeg;base64,BBBB` | Imagen posterior opcional. |
| `template` | string | No | `template_id` | Id de plantilla opcional. |

### Notas

- `image` es obligatoria. `documentType`, `backImage` y `template` son opcionales.
- No envíe un campo de país. Este cuerpo no lo acepta.
- El método registrado es `SCAN_AGENT` y la URL sigue siendo `/v2/ocr/scan-gpt`.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.

## Sandbox

| Escenario | Parámetros | Resultado |
| :--- | :--- | :--- |
| Registro en la fuente | `image` plus `documentType: "CC"` | 200 con campos extraídos y validationMethod SCAN_AGENT. |
| Falta un valor obligatorio | Omit `image` | 409 MissingParameter. |
| Valor desconocido | `image` and `backImage` | 200 si también envía la imagen posterior. |

401 when the bearer token is missing or rejected.
