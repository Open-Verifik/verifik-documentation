### Endpoint

```
https://api.verifik.co/v2/ocr/scan-agent
```

Escaneo Agent lee la imagen de un documento y devuelve los campos extraídos en la respuesta. Es la misma llamada que usa Smart Scan. La retención de una llamada sin proyecto se describe abajo. Un escaneo de SmartEnroll ligado a un registro de aplicación sigue [Retención de datos](/verifik-es/getting-started/data-retention).

### Encabezados

| Nombre | Valor |
| --- | --- |
| Content-Type | `application/json` |
| Authorization | `Bearer <token>` |

### Parámetros

| Nombre | Tipo | Requerido | Descripción |
| --- | --- | --- | --- |
| `image` | string | Sí | Imagen frontal en Base64 o como URI `data:`. |
| `documentType` | string | Sí | Tipo de documento a leer, por ejemplo `CC`. |
| `backImage` | string | No | Imagen del reverso, en el mismo formato que `image`. |
| `promptTemplateId` | string | No | Plantilla de prompt guardada. |
| `includeCost` | string | No | Envía `"true"` para incluir el costo en la respuesta. |

### Respuesta

La respuesta HTTP trae la extracción sin enmascarar. En una llamada sin proyecto, `url` y `backUrl` son URI `data:` de las imágenes que enviaste.

### Registro guardado y `url` / `backUrl`

Esta sección es la llamada **sin proyecto**.

| | Respuesta inmediata | Fila guardada del escaneo |
| --- | --- | --- |
| `url`, `backUrl` | URI `data:` de las imágenes de esta petición. No son enlaces a archivos alojados. | No se sube ningún archivo alojado. |
| `OCRExtraction`, `fullName` | Valores completos, tal como se leyeron. | Enmascarados. |
| `documentNumber` | Valor completo. | Valor completo. La fila guardada lo conserva en claro. |

Guarda tu propia copia de la imagen si vas a necesitar la foto. Una copia cifrada de la extracción completa se elimina 30 días después del escaneo.

Un escaneo de SmartEnroll que pertenece a un registro de aplicación usa la política de cuenta, proyecto y flujo. En `none` y `ephemeral`, esa respuesta omite las URL alojadas y puede incluir `hasFrontImage` y `hasBackImage`. La extracción de la respuesta sigue sin enmascarar. La extracción guardada se enmascara cuando `ocrExtraction` es `none`.

Consulta [Retención de datos](/verifik-es/getting-started/data-retention) y [Escaneo Prompt](/verifik-es/escaneo-prompt).

### Notas

- Envía el frente en `image` y el reverso en `backImage` cuando el documento tiene dos caras.
- `includeCost` es la cadena `"true"` cuando quieres el costo en la respuesta.
- Un cambio de política aplica a los escaneos creados después del cambio. Las filas anteriores conservan el sello de retención que recibieron, y las filas sin sello permanecen como están.
