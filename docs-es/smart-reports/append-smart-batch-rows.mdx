Agrega nuevas filas de entrada a un `SmartBatch` existente sin sobrescribir las filas existentes ni los resultados almacenados. Se aceptan tanto filas envueltas (`{ rowIndex?, inputData }`) como filas planas (`{ rowIndex?, ...inputFields }`), y el servidor asigna índices de fila secuenciales a partir de `maxExisting + 1`.

Agregar filas está prohibido mientras el lote está en `"processing"` (`400 batch_append_not_allowed_while_processing`). Si el lote estaba previamente en `"completed"` o `"failed"`, agregar filas restablece `status` a `"pending"` y borra `completedAt` para que las nuevas filas puedan ejecutarse.

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/{id}/rows/append
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batches/{id}/rows/append` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                         |
| --------------- | ---------------------- | --------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato de carga útil de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT delimitado al cliente (`authUser.clientId`).    |

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                                        |
| ------ | ------ | --------- | -------------------------------------------------- |
| `id`   | string | Sí        | ObjectId de `SmartBatch` al que agregar filas.     |

### Cuerpo

| Nombre | Tipo     | Requerido | Descripción |
| ------ | -------- | --------- | ----------- |
| `rows` | object[] | Sí        | Arreglo no vacío (`min 1`) de filas de entrada envueltas (`{ rowIndex?, inputData }`) o planas (`{ rowIndex?, ...inputFields }`). El servidor asigna secuencialmente `rowIndex = maxExisting + 1`. |

Las claves desconocidas en el cuerpo o los arreglos `rows` vacíos son rechazados por la validación Joi con `409 MissingParameter`.

package main

import (
	"bytes"

	"fmt"
	"net/http"
	"os"

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	body, _ := json.Marshal(map[string]interface{}{
		"rows": []map[string]interface{}{
			{

					"documentNumber": "1020304050",
				},
			},
			{
				"documentType":   "CC",
				"documentNumber": "1098765432",
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-batches/"+batchID+"/rows/append", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notas

- Agregar filas no ejecuta comprobaciones ni consume créditos; inicia el lote después con [Iniciar un Smart Batch](/verifik-es/smart-reports/start-a-smart-batch).
- Cualquier `rowIndex` enviado por el cliente se ignora en favor de una numeración secuencial asignada por el servidor a partir de `maxExisting + 1`.
- Si el lote estaba en `"completed"` o `"failed"`, su `status` se restablece a `"pending"` y se borra `completedAt`.
