Lista las plantillas de Smart Report disponibles para el cliente autenticado. De forma predeterminada, este endpoint devuelve tanto las plantillas personalizadas propiedad de tu cliente como las plantillas integradas `"System"` de Verifik para que puedas descubrir IDs de plantillas reutilizables (`_id`), inspeccionar configuraciones de diseño y tema y elegir una plantilla antes de lanzar ejecuciones de `SmartBatch` o renderizados de muestra.

En pipelines de verificación headless y flujos de agentes de IA, llama primero a este endpoint para localizar una plantilla existente vinculada a una `batchConfiguration`, filtrar plantillas `"System"` integradas por `country`, `category` o `tier`, o verificar si una plantilla personalizada está activa antes de clonarla o actualizarla. Listar plantillas no renderiza PDFs ni consume créditos.

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates
```

El proxy de Smart-Agent (`https://ai.verifik.co`) expone las mismas rutas `/v2/...` y requiere tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>`.

Las respuestas pueblan `batchConfiguration` y `client` y seleccionan `+thumbnail.image` para que los paneles y vistas previas headless puedan inspeccionar miniaturas de plantillas sin una solicitud adicional.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parámetros

Todos los parámetros de consulta son opcionales.

| Nombre               | Tipo    | Requerido | Descripción                                                                                                                                      |
| -------------------- | ------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `batchConfiguration` | string  | No        | Filtra plantillas vinculadas a un ObjectId de configuración de `SmartBatch` específico.                                                          |
| `type`               | string  | No        | Filtra por origen: `"client"` o `"System"`. Cuando se omite, devuelve las plantillas de tu cliente junto con las plantillas integradas `"System"`. |
| `country`            | string  | No        | Filtro de país. Se convierte automáticamente a mayúsculas en el servidor (por ejemplo `CO`, `MX` o `COLOMBIA`).                                  |
| `category`           | string  | No        | Filtro de categoría de dominio: `"citizen"`, `"company"` o `"vehicle"`.                                                                          |
| `tier`               | string  | No        | Filtro de nivel de plantilla: `"essential"` o `"comprehensive"`.                                                                                 |
| `isActive`           | boolean | No        | Filtra por estado activo (`true` o `false`).                                                                                                     |
| `search`             | string  | No        | Búsqueda regex sin distinción entre mayúsculas y minúsculas sobre `name` y `systemKey`. Al enviarse sin `type`, busca tanto en tus plantillas como en plantillas `"System"`. |
| `page`               | integer | No        | Número de página (base 1). Deben enviarse tanto `page` como `limit` juntos para habilitar la paginación en este módulo.                          |
| `limit`              | integer | No        | Tamaño de página. Debe enviarse junto con `page` para paginar los resultados.                                                                    |
| `sort`               | string  | No        | Especificación de ordenamiento. Toma por defecto `type: 1, createdAt: -1` (ordenado por tipo de plantilla y más reciente primero).                |

### Notas

- Deben enviarse tanto `page` como `limit` juntos para paginar los resultados. Enviar solo un parámetro sin el otro no activa la paginación.
- Las plantillas `"System"` integradas devueltas en la lista son de solo lectura. Intentar modificarlas o eliminarlas devuelve `403` (`system_template_readonly`). Para personalizar una plantilla inicial, pasa su diseño a [Crear una plantilla de reporte](/verifik-es/smart-reports/create-a-report-template).
- Usa [Listar temas iniciales](/verifik-es/smart-reports/list-theme-starters) cuando quieras esquemas iniciales limpios agrupados por `reportTheme`.
