Renderiza una plantilla guardada de Smart Report (`{id}`) con `sampleData` y envía por correo electrónico el PDF resultante directamente a uno o más destinatarios (`recipients`). Opcionalmente puedes suministrar `printHtml` para omitir la generación de HTML o `pdfBase64` para adjuntar un buffer PDF prerrenderizado.

En pipelines de CI/CD headless, flujos de aprobación de plantillas y automatizaciones de agentes de IA, usa este endpoint para distribuir vistas previas de reporte formateadas a revisores de cumplimiento o interesados de producto sin montar tu propia infraestructura de correo. Se aceptan cuerpos de solicitud JSON de hasta `64MB` para admitir fuentes incrustadas, logotipos, HTML prerrenderizado o PDFs en base64.

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates/{id}/send-sample
```

El proxy de Smart-Agent (`https://ai.verifik.co`) expone las mismas rutas `/v2/...` y requiere tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                            |
| ------ | ------ | --------- | -------------------------------------- |
| `id`   | string | Sí        | ObjectId de plantilla de Smart Report. |

### Cuerpo

Admite payloads JSON de hasta `64MB`.

| Nombre       | Tipo     | Requerido | Descripción                                                                                                                        |
| ------------ | -------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `recipients` | string[] | Sí        | Arreglo de direcciones de correo válidas de destinatarios (mínimo `1`).                                                            |
| `sampleData` | object   | Sí        | Payload de muestra que contiene `inputData`, `results`, `batchName` y `rowIndex`.                                                  |
| `subject`    | string   | No        | Línea de asunto personalizada del correo. Toma por defecto `` `Sample Report: <name>` `` usando el `name` de la plantilla.         |
| `language`   | string   | No        | Idioma del texto del correo: `"en"` o `"es"`. Toma por defecto `"es"`.                                                             |
| `printHtml`  | string   | No        | Documento HTML prerrenderizado opcional para convertir a PDF en lugar de renderizar desde las `sections` de la plantilla.          |
| `pdfBase64`  | string   | No        | Adjunto PDF codificado en base64 opcional para enviar directamente sin generación de PDF en el servidor.                           |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"

func main() {
	id := "67c1f94b2d8a1c0012a4b301"
	body, _ := json.Marshal(map[string]interface{}{
		"recipients": []string{"compliance@acme.example"},
		"subject":    "Sample Report: Colombia Driver Onboarding",
		"language":   "es",
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding Sample",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{
					"fullName": "Mateo Rojas",
					"status":   "active",
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/"+id+"/send-sample", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notas

- A diferencia de otros endpoints de plantillas que envuelven los payloads en `{ "data": ... }`, `send-sample` devuelve en el nivel superior los campos `success`, `message`, `recipients`, `messageId` y `delivery`.
- Si se omite `language`, el correo usa `"es"` por defecto. Pasa `"en"` para notificaciones en inglés.
- Para guardar localmente el PDF renderizado en lugar de enviarlo por correo, utiliza [Descargar muestra de plantilla](/verifik-es/smart-reports/download-template-sample).
