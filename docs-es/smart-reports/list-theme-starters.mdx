Recupera las plantillas iniciales integradas con tema visual de Verifik, filtradas opcionalmente por `theme`. Cada plantilla inicial incluye `sections`, `reportTheme`, `sampleData`, propiedades de diseño de página y colores preconfigurados para que puedas lanzar diseños de reporte listos para producción sin armar árboles de secciones desde cero.

En flujos de onboarding headless y agentes de IA, llama a este endpoint para elegir un punto de partida visual curado, previsualízalo de inmediato mediante [Previsualizar HTML de plantilla](/verifik-es/smart-reports/preview-template-html), personaliza colores de marca o logotipos y guarda tu propia plantilla editable mediante [Crear una plantilla de reporte](/verifik-es/smart-reports/create-a-report-template).

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/theme-starters
```

El proxy de Smart-Agent (`https://ai.verifik.co`) expone las mismas rutas `/v2/...` y requiere tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parámetros

| Nombre  | Tipo   | Requerido | Descripción                                                                                                                                                     |
| ------- | ------ | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `theme` | string | No        | Filtro de tema opcional: `"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"` o `"smart_enroll_v2"` (alias de `"light_cards"`; se recomienda usar el identificador canónico `"light_cards"`). |

### Notas

- `"smart_enroll_v2"` se acepta como alias de `"light_cards"`, aunque se recomienda filtrar por el ID de tema canónico `"light_cards"`.
- Los elementos iniciales devueltos aquí tienen `type: "System"` como referencia. Al guardar una copia personalizada mediante [Crear una plantilla de reporte](/verifik-es/smart-reports/create-a-report-template), envía únicamente tu `name` y los campos de diseño (`sections`, `reportTheme`, `sampleData`, colores y ajustes de PDF).
