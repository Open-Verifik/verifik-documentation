Clona un preset del sistema seleccionado de Smart Report en tu cuenta de cliente. La operación devuelve tanto una `BatchConfiguration` como una `SmartReportTemplate` vinculada, listas para ejecutarse de inmediato o personalizarse aún más.

Este endpoint es **idempotente** para cuentas de cliente. Si ya existe una plantilla de cliente activa clonada desde `{systemKey}`, el servidor reutiliza esa configuración y plantilla (reasignando secuencias de pasos si es necesario) y devuelve `reused: true`. De lo contrario, crea una nueva `BatchConfiguration` (con `inputFormat: "csv"`, `outputFormat: "csv"`, `mergeStrategy: "sequential"`) y una nueva `SmartReportTemplate` de cliente (con `clonedFromSystemKey` establecido en `{systemKey}`) vinculada mediante `preferredReportTemplate` con `reused: false`. Este endpoint también está expuesto como la herramienta MCP `smart_report_clone_preset`.

### Endpoint

```
POST https://api.verifik.co/v2/smart-batch-presets/{systemKey}/clone
```

También es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batch-presets/{systemKey}/clone` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

El token debe ser un **JWT de cliente**. Las credenciales faltantes o inválidas devuelven `401 Unauthorized`.

### Parámetros

| Nombre      | Tipo   | Requerido | Descripción                                                                                                                                    |
| ----------- | ------ | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `systemKey` | string | Sí        | Clave del preset obtenida de [Listar presets de reportes](/verifik-es/smart-reports/list-report-presets). Recortada, máximo `120` caracteres, debe coincidir con `/^[a-z0-9][a-z0-9._-]{1,118}$/i`. |

### Cuerpo

No se requiere cuerpo de solicitud para este endpoint.

### Notas

- Clonar un preset no ejecuta consultas y no consume créditos.
- Llamar repetidamente a este endpoint con el mismo `{systemKey}` es seguro e idempotente para una cuenta de cliente: se devuelven la configuración y la plantilla clonadas existentes con `reused: true`.
- Se devuelve `409 MissingParameter` cuando `{systemKey}` falla la validación de ruta de Joi (por ejemplo, si supera los `120` caracteres o contiene caracteres no permitidos). Se devuelve `409` con `preset_has_no_steps` si el preset coincidente no tiene pasos configurados.
- Puede ocurrir `500 InternalServerError` si una funcionalidad requerida por el preset no está disponible en tu cuenta.
- Una vez clonado, llama a [Recuperar el esquema de entrada de una configuración](/verifik-es/smart-reports/retrieve-configuration-input-schema) con `batchConfiguration._id` antes de enviar filas, o usa la herramienta MCP `smart_report_clone_preset`.
