Lista los endpoints del catálogo de Verifik que disponen de respuestas simuladas de sandbox preconstruidas en el inventario de diseño de plantillas. Filtra por `country` o consulta de búsqueda (`q`) para descubrir los identificadores `code` de endpoint y los `inputs` esperados.

En constructores de reportes headless y pipelines de agentes de IA, usa este endpoint de descubrimiento del catálogo para seleccionar conjuntos de datos simulados realistas sin ejecutar consultas en vivo facturables ni manipular PII de producción. Pasa cualquier `code` devuelto a [Recuperar una respuesta simulada](/verifik-es/smart-reports/retrieve-simulated-response) para obtener payloads de muestra para [Introspeccionar datos de muestra](/verifik-es/smart-reports/introspect-sample-data), [Generar diseño de plantilla](/verifik-es/smart-reports/generate-template-layout) o [Previsualizar HTML de plantilla](/verifik-es/smart-reports/preview-template-html).

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses
```

El proxy de Smart-Agent (`https://ai.verifik.co`) expone las mismas rutas `/v2/...` y requiere tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parámetros

| Nombre    | Tipo   | Requerido | Descripción                                                             |
| --------- | ------ | --------- | ----------------------------------------------------------------------- |
| `country` | string | No        | Filtra los endpoints simulados por país.                                |
| `q`       | string | No        | Cadena de búsqueda para filtrar endpoints por nombre, código o metadatos. |

### Notas

- Consultar respuestas simuladas no ejecuta consultas en vivo del catálogo ni consume créditos.
- Usa el `code` de cada elemento con [Recuperar una respuesta simulada](/verifik-es/smart-reports/retrieve-simulated-response) para obtener los payloads completos `dataSample` y `emptySample`.
