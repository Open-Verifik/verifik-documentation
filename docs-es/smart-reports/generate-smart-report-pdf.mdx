Renderiza un PDF para un `SmartReport` existente usando `"puppeteer"` o `"pdfkit"`, calcula opcionalmente `verificationScore` y recibe el buffer del PDF codificado en base64 junto con `downloadUrl` y `htmlUrl`.

Cuando tiene éxito, este endpoint marca el reporte como `status: "generated"`, guarda `verificationScoreSummary` si la puntuación está habilitada y emite el webhook `smart_batch_report_generated`. Si la generación del PDF falla, el reporte se marca como `status: "failed"` y se emite el webhook `smart_batch_report_generation_failed`.

### Endpoint

```
POST https://api.verifik.co/v2/smart-reports/{id}/generate
```

Este endpoint acepta payloads JSON de hasta **64 MB** (para admitir documentos `printHtml` personalizados). También es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-reports/{id}/generate` usando tu propio encabezado por cliente `Authorization: Bearer <VERIFIK_JWT>`. La ejecución compartida mediante x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                         |
| --------------- | ---------------------- | --------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato del payload de solicitud (límite de 64 MB). |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT con alcance de cliente (`authUser.clientId`).   |

### Parámetros

| Nombre | Tipo   | Requerido | Descripción |
| ------ | ------ | --------- | ----------- |
| `id`   | string | **Sí**    | ObjectId de `SmartReport`. |

### Cuerpo

| Nombre         | Tipo    | Requerido | Descripción |
| -------------- | ------- | --------- | ----------- |
| `engine`       | string  | No        | Motor de renderizado PDF: `"pdfkit"` o `"puppeteer"`. |
| `rowIndex`     | number  | No        | Índice de fila base cero del `SmartBatch` vinculado. Usa por defecto la fila `0`. |
| `printHtml`    | string  | No        | Cadena HTML completa (máx. `64000000` caracteres) usada para plantillas sin tema que contienen `<html`. |
| `score`        | boolean | No        | Indica si se debe calcular `verificationScore` y almacenar `verificationScoreSummary` en el reporte. |
| `scoreProfile` | string  | No        | Identificador de perfil de puntaje usado cuando `score` está habilitado. Máx. `64` caracteres. |

#### Comportamiento de renderizado y puntuación

- **Selección de fila por defecto**: Cuando se omite `rowIndex`, la generación toma la fila `0`. Solicitar una fila fuera de rango devuelve `409 Conflict` (`row_not_found`).
- **HTML personalizado (`printHtml`)**: Al trabajar con plantillas sin tema que proporcionan marcado `<html` completo, pasa `printHtml` (hasta `64000000` caracteres).
- **Puntaje de verificación**: Establece `score: true` (y opcionalmente `scoreProfile`) para calcular `verificationScore`, devolverlo en el nivel superior de la respuesta y guardar `verificationScoreSummary` en el `SmartReport`. Los perfiles desconocidos fallan con `409 Conflict` (`unknown_score_profile`).

#### Códigos de error

| Estado | Código / Tipo de error | Causa |
| ------ | ---------------------- | ----- |
| `401` | `Unauthorized` | JWT ausente o inválido. |
| `403` | `Forbidden` | Se intentó ejecución compartida x402; utiliza tu propio JWT por cliente. |
| `404` | `not_found` | El ID del reporte no existe o pertenece a otro cliente. |
| `404` | `template_not_found` | No se encontró la plantilla vinculada. |
| `404` | `batch_not_found` | No se encontró el `SmartBatch` vinculado. |
| `409` | `MissingParameter` | Falló la validación Joi en uno o más campos. |
| `409` | `row_not_found` | El `rowIndex` solicitado no existe en el lote. |
| `409` | `unknown_score_profile` | No se reconoce el `scoreProfile` solicitado. |
| `422` | `UnprocessableEntity` | Error de validación de Mongoose. |
| `500` | `InternalServerError` | Fallo interno de procesamiento o renderizado PDF (marca el reporte como `"failed"` y emite `smart_batch_report_generation_failed`). |

### Integración con Webhooks y MCP

- **Webhooks**: Emite `smart_batch_report_generated` al crear el PDF con éxito, o `smart_batch_report_generation_failed` si ocurren errores de renderizado (y actualiza `status` a `"failed"`). Consulta [Webhooks de SmartReports](/verifik-es/resources/smart-reports-webhooks).
- **Equivalente MCP**: Los agentes de IA pueden renderizar el PDF de un reporte directamente mediante la herramienta MCP `smart_report_generate_pdf`. Consulta [MCP y Agentes de IA](/verifik-es/smart-reports/mcp-and-ai-agents).

### Notas

- `pdf.buffer` contiene los bytes del PDF codificados en base64 directamente en la respuesta JSON; si prefieres un flujo binario de PDF, llama a [Descargar PDF de Smart Report](/verifik-es/smart-reports/download-smart-report-pdf).
- `verificationScore` se incluye en la respuesta cuando `score` está habilitado.
