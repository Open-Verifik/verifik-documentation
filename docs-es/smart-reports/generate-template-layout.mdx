Genera, añade o edita definiciones estructuradas de `ReportSection` a partir de un `prompt` en lenguaje natural utilizando Gemini (temperatura `0.2`). Pasa datos de verificación de muestra en `previewData` para que el modelo alinee los enlaces `dataPath` de las secciones y los diseños de columnas con la estructura real de tu payload.

En constructores de reportes headless y pipelines de agentes de IA, usa este endpoint para crear el esqueleto completo de diseños (`"create"`), añadir secciones adicionales a una plantilla existente (`"append"`) o refinar una única sección (`"edit"`) sin escribir el JSON de secciones a mano. Combina esta llamada con [Previsualizar HTML de plantilla](/verifik-es/smart-reports/preview-template-html) para inspeccionar la salida renderizada antes de guardarla con [Crear una plantilla de reporte](/verifik-es/smart-reports/create-a-report-template) o [Actualizar una plantilla de reporte](/verifik-es/smart-reports/update-a-report-template).

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates/generate-layout
```

El proxy de Smart-Agent (`https://ai.verifik.co`) expone las mismas rutas `/v2/...` y requiere tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Cuerpo

| Nombre            | Tipo          | Requerido | Descripción                                                                                                                               |
| ----------------- | ------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`          | string        | Sí        | Instrucciones en lenguaje natural que describen el diseño a crear, las secciones a añadir o los cambios a aplicar en modo edición.        |
| `mode`            | string        | Sí        | Modo de generación: `"create"`, `"edit"` o `"append"`.                                                                                    |
| `previewData`     | object        | No        | JSON de verificación de muestra (por ejemplo `inputData`, `results`, `batchName`) usado para fundamentar las expresiones `dataPath` y columnas generadas. |
| `currentSections` | object[]      | No        | Arreglo existente de `ReportSection`. Recomendado en modo `"append"` para que las nuevas secciones continúen la secuencia `order` actual. |
| `selectedSection` | object / null | No        | Objeto `ReportSection` objetivo a modificar cuando `mode` es `"edit"`. Si es `null` o se omite en modo `"edit"`, el comportamiento vuelve a `"create"`. |

		"mode":   "create",

				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/generate-layout", bytes.NewReader(body))

### Notas

- Los modos `"create"` y `"append"` devuelven `{ "data": [ ...ReportSection ] }` (un arreglo), mientras que el modo `"edit"` con un `selectedSection` no nulo devuelve `{ "data": { ...ReportSection } }` (un único objeto).
- Llamar a `"edit"` con `selectedSection: null` u omitiendo `selectedSection` vuelve al modo `"create"` y devuelve un arreglo.
- Este endpoint no escribe en la base de datos. Pasa las `sections` devueltas a [Previsualizar HTML de plantilla](/verifik-es/smart-reports/preview-template-html) para inspeccionar el HTML o a [Crear una plantilla de reporte](/verifik-es/smart-reports/create-a-report-template) para guardarlas.
