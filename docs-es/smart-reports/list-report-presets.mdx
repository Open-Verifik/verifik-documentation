Lista los presets del sistema seleccionados de Smart Report disponibles para tu cuenta. Cada preset incluye su `systemKey`, metadatos (`country`, `category`, `tier`), disponibilidad en la cuenta (`available`), `presetSteps` ordenados y un `inputSchema` resuelto con `exampleInput` listo para ejecución headless o agentes de IA.

El `inputSchema` resuelto excluye automáticamente los parámetros internos de ejecución y las entradas de pasos ya suministradas mediante dependencias encadenadas de `visitaFlow`, dejando únicamente los campos que tu cliente llamante debe proporcionar. Listar presets es una llamada de descubrimiento de solo lectura y no consume créditos. Este endpoint también está expuesto como la herramienta MCP `smart_report_list_presets`.

### Endpoint

```
GET https://api.verifik.co/v2/smart-batch-presets
```

También es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batch-presets` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada en esta ruta con `403 Forbidden`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

El token debe ser un **JWT de cliente**. Las credenciales faltantes o inválidas devuelven `401 Unauthorized`.

### Parámetros

Todos los parámetros de consulta son opcionales. Combínalos para filtrar presets por jurisdicción, categoría de entidad, nivel o palabra clave.

| Nombre     | Tipo   | Requerido | Descripción                                                                                           |
| ---------- | ------ | --------- | ----------------------------------------------------------------------------------------------------- |
| `country`  | string | No        | Filtro de código de país. El servidor recorta espacios y convierte a mayúsculas (por ejemplo, `CO`).   |
| `category` | string | No        | Filtro de categoría del preset. Valores permitidos: `citizen`, `company` o `vehicle`.                 |
| `tier`     | string | No        | Filtro de profundidad del preset. Valores permitidos: `essential` o `comprehensive`.                  |
| `search`   | string | No        | Coincidencia por expresión regular sin distinción de mayúsculas en `name`, `description` y `systemKey`. |
| `text`     | string | No        | Alias para `search`.                                                                                  |

package main

import (
    "encoding/json"
    "fmt"
    "net/http"
    "net/url"
    "os"
)

func main() {
    u, _ := url.Parse("https://api.verifik.co/v2/smart-batch-presets")
    q := u.Query()
    q.Set("country", "CO")
    q.Set("category", "citizen")
    q.Set("tier", "essential")
    u.RawQuery = q.Encode()

    req, _ := http.NewRequest("GET", u.String(), nil)
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

    resp, _ := http.DefaultClient.Do(req)
    defer resp.Body.Close()

    var out map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&out)
    fmt.Println(out)
}

### Notas

- `country` se recorta y convierte a mayúsculas antes de filtrar (por ejemplo, `co` coincide con `CO`).
- `search` y `text` ejecutan la misma coincidencia por expresión regular sin distinción de mayúsculas sobre `name`, `description` y `systemKey`.
- `inputSchema.estimatedCreditsPerRow` estima el costo en créditos por fila entre los pasos habilitados del preset.
- Cuando `available` es `true`, todas las funcionalidades en `presetSteps` están activas en el entorno y listas para clonar con [Clonar un preset de reporte](/verifik-es/smart-reports/clone-a-report-preset).
- Para integraciones con agentes de IA, este endpoint corresponde a la herramienta MCP `smart_report_list_presets`.
