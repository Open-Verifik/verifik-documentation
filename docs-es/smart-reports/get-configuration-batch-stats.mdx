Recupera estadísticas agregadas de ejecución en todos los registros `SmartBatch` que pertenecen a una `BatchConfiguration` específica en la cuenta de cliente autenticada. La respuesta devuelve conteos de lotes, totales de finalización de filas y un desglose por estado entre `"draft"`, `"pending"`, `"processing"`, `"completed"`, `"failed"` y `"cancelled"`.

Consultar las estadísticas de configuración no ejecuta comprobaciones y no consume créditos.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/stats/{configId}
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batches/stats/{configId}` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                         |
| --------------- | ---------------------- | --------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato de carga útil de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT delimitado al cliente (`authUser.clientId`).    |

### Parámetros

| Nombre     | Tipo   | Requerido | Descripción                                                              |
| ---------- | ------ | --------- | ------------------------------------------------------------------------ |
| `configId` | string | Sí        | ObjectId de `BatchConfiguration` para agregar estadísticas de lotes.     |

### Notas

- Las estadísticas están delimitadas al cliente autenticado (`clientId` en tu JWT).
- `pendingRows` se calcula como `totalRows - completedRows - failedRows - partialRows`.
- Para inspeccionar lotes individuales pertenecientes a esta configuración, pasa `batchConfiguration` a [Listar Smart Batches](/verifik-es/smart-reports/list-smart-batches).
