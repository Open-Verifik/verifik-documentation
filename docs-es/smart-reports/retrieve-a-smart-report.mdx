Recupera un único `SmartReport` por su ID. La respuesta puebla `template`, `smartBatch` y `client`, y adjunta las rutas listas para usar `downloadUrl` (`/v2/smart-reports/{id}/download`) y `htmlUrl` (`/v2/smart-reports/{id}/html`).

Este endpoint también es el destino de sondeo (`pollUrl`) devuelto cuando `POST /v2/smart-reports/run` se ejecuta en modo `"async"` o cambia automáticamente a `202 Accepted` tras el límite síncrono de 90 segundos. Si el ID del reporte no existe o pertenece a otro cliente, el endpoint devuelve HTTP `200 OK` con `{ "data": null }`.

### Endpoint

```
GET https://api.verifik.co/v2/smart-reports/{id}
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-reports/{id}` usando tu propio encabezado por cliente `Authorization: Bearer <VERIFIK_JWT>`. La ejecución compartida mediante x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                       |
| --------------- | ---------------------- | ------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato del payload de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT con alcance de cliente (`authUser.clientId`). |

### Parámetros

| Nombre | Tipo   | Requerido | Descripción |
| ------ | ------ | --------- | ----------- |
| `id`   | string | **Sí**    | ObjectId de `SmartReport` devuelto por `POST /v2/smart-reports/run`, `POST /v2/smart-reports` o `GET /v2/smart-reports`. |

### Integración con Webhooks y MCP

- **Polling vs Webhooks**: Para ejecuciones asíncronas, puedes consultar `GET /v2/smart-reports/{id}` hasta que `data.status` llegue a un estado final (`"generated"`, `"sent"` o `"failed"`), o suscribirte a eventos webhook (`smart_batch_report_generated`, `smart_batch_report_generation_failed`, `smart_batch_report_sent`, `smart_batch_report_delivery_failed`). Consulta [Webhooks de SmartReports](/verifik-es/resources/smart-reports-webhooks).
- **Equivalente MCP**: Los agentes de IA pueden recuperar un registro de reporte mediante la herramienta MCP `smart_report_get`. Consulta [MCP y Agentes de IA](/verifik-es/smart-reports/mcp-and-ai-agents).

### Notas

- Los reportes inexistentes o pertenecientes a otro cliente devuelven `200 OK` con `{ "data": null }` en lugar de `404`.
- `downloadUrl` y `htmlUrl` son rutas API relativas que pueden agregarse a `https://api.verifik.co` (o `https://ai.verifik.co`).
