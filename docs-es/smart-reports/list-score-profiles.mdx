Lista todos los perfiles de puntaje de verificación compatibles que pueden vincularse a una plantilla de Smart Report (`reportTheme.scoreProfile`) o pasarse a [Previsualizar HTML de plantilla](/verifik-es/smart-reports/preview-template-html) (`scoreProfile`).

En interfaces de configuración headless y flujos de agentes de IA, consulta este endpoint antes de habilitar la puntuación para que tu aplicación valide dinámicamente los identificadores `scoreProfile` y evite errores `409` (`unknown_score_profile`) durante la vista previa HTML o el renderizado del reporte. Los perfiles disponibles cubren flujos de conductores, identidad, empresas, flotas, vehículos, crédito, salud y biometría:

- `cabify_driver`
- `kyc`
- `kyb`
- `fleet`
- `vehicle_purchase`
- `identity_lookup`
- `background_check`
- `lending`
- `healthcare_professional`
- `biometrics`

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/score-profiles
```

El proxy de Smart-Agent (`https://ai.verifik.co`) expone las mismas rutas `/v2/...` y requiere tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parámetros

No se requieren parámetros de consulta ni de ruta.

### Notas

- Usa el valor `id` devuelto en `reportTheme.scoreProfile` al crear o actualizar una plantilla, o como `scoreProfile` en [Previsualizar HTML de plantilla](/verifik-es/smart-reports/preview-template-html).
- Enviar un `scoreProfile` no reconocido a `POST /v2/smart-report-templates/preview-html` devuelve `409` (`unknown_score_profile`).
