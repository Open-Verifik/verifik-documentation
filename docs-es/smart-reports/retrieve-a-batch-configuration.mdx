Recupera una única `BatchConfiguration` por su ObjectId (`{id}`). La consulta está delimitada al JWT de cliente autenticado y devuelve los detalles de `steps.appFeature` populados y enriquecidos con los precios `ClientFeature` de tu cuenta.

Si no existe ninguna configuración coincidente o el ID pertenece a otra cuenta de cliente, el endpoint devuelve HTTP `200` con `data: null`. Leer una configuración no ejecuta consultas y no consume créditos.

### Endpoint

```
GET https://api.verifik.co/v2/batch-configurations/{id}
```

También es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/batch-configurations/{id}` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

El token debe ser un **JWT de cliente**. Las credenciales faltantes o inválidas devuelven `401 Unauthorized`.

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                                                              |
| ------ | ------ | --------- | ------------------------------------------------------------------------ |
| `id`   | string | Sí        | ObjectId de `BatchConfiguration` obtenido al crear, clonar o listar.     |

### Notas

- Si `{id}` no existe o pertenece a otra cuenta de cliente, este endpoint devuelve HTTP `200` con `{ "data": null }`.
- Verifica `data !== null` en tu integración antes de leer propiedades de `data`.
- Para inspeccionar las entradas requeridas y opcionales resueltas y una carga útil `exampleInput` para una configuración, llama a [Recuperar el esquema de entrada de una configuración](/verifik-es/smart-reports/retrieve-configuration-input-schema).
