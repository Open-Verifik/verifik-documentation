Inspecciona un payload de verificación `sampleData` y recibe un mapa estructurado de rutas de campos, formas de valores, opciones recomendadas de `sectionType`, tipos de sección alternativos, columnas de tabla sugeridas y sugerencias de enlace de datos.

En la creación de reportes headless y pipelines de agentes de IA, llama a este endpoint inmediatamente después de obtener un payload de [Recuperar una respuesta simulada](/verifik-es/smart-reports/retrieve-simulated-response) o capturar una fila de `SmartBatch`. En lugar de adivinar cadenas `dataPath` o escribir lógica frágil de recorrido JSON, tu UI o agente puede utilizar los metadatos `nodes` y `batch` introspeccionados para construir `sections` válidas directamente o enriquecer el contexto del `prompt` para [Generar diseño de plantilla](/verifik-es/smart-reports/generate-template-layout). El analizador recorre hasta una profundidad de `5` y hasta `600` nodos.

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates/introspect
```

El proxy de Smart-Agent (`https://ai.verifik.co`) expone las mismas rutas `/v2/...` y requiere tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Cuerpo

| Nombre       | Tipo   | Requerido | Descripción                                                                                                                         |
| ------------ | ------ | --------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `sampleData` | object | Sí        | Payload de verificación de muestra con `batchName` (string), `rowIndex` (number), `inputData` (object) y `results` (object) opcionales. |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"

func main() {
	body, _ := json.Marshal(map[string]interface{}{
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{
					"fullName": "Mateo Rojas",
					"status":   "active",
				},
				"fines": []map[string]interface{}{
					{"code": "C02", "amount": 580000, "status": "pending"},
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/introspect", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notas

- El recorrido se detiene a una profundidad de `5` y tiene un tope de `600` nodos. Cuando un payload muy grande alcanza el límite, `truncated` es `true`.
- Este endpoint es de solo lectura y sin estado; no guarda ninguna plantilla ni consume créditos de verificación.
