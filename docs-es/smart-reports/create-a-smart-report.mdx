Crea un registro `SmartReport` en estado borrador (`status: "draft"`) vinculado a una plantilla (`template`) y un `smartBatch` existentes. Usa este endpoint cuando ya tengas un `SmartBatch` completado o en curso y quieras gestionar la creación del reporte, la generación del PDF, la obtención del HTML y el envío por correo electrónico como pasos independientes.

Crear un registro en borrador devuelve HTTP **`200 OK`** con el nuevo `SmartReport` dentro de `{ data }`. No ejecuta pasos de verificación ni renderiza un PDF por sí solo — continúa con [Generar PDF de Smart Report](/verifik-es/smart-reports/generate-smart-report-pdf) o [Enviar Smart Report por correo electrónico](/verifik-es/smart-reports/send-smart-report-email). Si deseas ejecutar pasos de verificación y producir un reporte en una sola solicitud, utiliza [Ejecutar un Smart Report](/verifik-es/smart-reports/run-a-smart-report).

### Endpoint

```
POST https://api.verifik.co/v2/smart-reports
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-reports` usando tu propio encabezado por cliente `Authorization: Bearer <VERIFIK_JWT>`. La ejecución compartida mediante x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                       |
| --------------- | ---------------------- | ------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato del payload de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT con alcance de cliente (`authUser.clientId`). |

### Cuerpo

| Nombre             | Tipo    | Requerido | Descripción |
| ------------------ | ------- | --------- | ----------- |
| `template`         | string  | **Sí**    | ObjectId de la plantilla contra la cual renderizar este reporte. |
| `smartBatch`       | string  | **Sí**    | ObjectId del `SmartBatch` que suministra los resultados de las filas de verificación. |
| `name`             | string  | No        | Nombre visible para el reporte. Máx. `150` caracteres. |
| `externalRefId`    | string  | No        | Identificador de correlación del llamador. Máx. `200` caracteres. |
| `webhookUrl`       | string  | No        | URL webhook `http` o `https` de sobrescritura por reporte. Máx. `2048` caracteres. |
| `rowIndex`         | integer | No        | Índice de fila base cero (`>= 0`) del `SmartBatch` vinculado. |
| `createdByChannel` | string  | No        | Canal de origen: `"portal"`, `"api"`, `"mcp"`, `"x402"` o `"webhook"`. Predeterminado `"portal"`. |

#### Flujo paso a paso vs ejecución headless

- Usa `POST /v2/smart-reports` cuando tu flujo ya haya ejecutado un `SmartBatch` (por ejemplo desde la interfaz de SmartBatch o la API de cola) y quieras crear primero un `SmartReport` en borrador (`status: "draft"`), previsualizar el HTML con [Recuperar HTML de Smart Report](/verifik-es/smart-reports/retrieve-smart-report-html), renderizar el PDF con [Generar PDF de Smart Report](/verifik-es/smart-reports/generate-smart-report-pdf) y enviarlo con [Enviar Smart Report por correo electrónico](/verifik-es/smart-reports/send-smart-report-email).
- Ten en cuenta que `createdByChannel` toma el valor `"portal"` por defecto en esta ruta, por lo que las integraciones por API deberían enviar `createdByChannel: "api"` cuando rastreen la atribución del canal.

### Integración con Webhooks y MCP

- **Webhooks**: Almacenar `webhookUrl` y `externalRefId` en el `SmartReport` en borrador garantiza que las llamadas posteriores de generación (`smart_batch_report_generated`, `smart_batch_report_generation_failed`) y envío por correo (`smart_batch_report_sent`, `smart_batch_report_delivery_failed`) hereden tu destino de callback por reporte e identificador de correlación. Consulta [Webhooks de SmartReports](/verifik-es/resources/smart-reports-webhooks).
- **Integración MCP**: Para ejecutar reportes headless en una sola llamada desde agentes de IA, utiliza `smart_report_run`. Consulta [MCP y Agentes de IA](/verifik-es/smart-reports/mcp-and-ai-agents).

### Notas

- La creación exitosa devuelve HTTP `200` (no `201`) con `status: "draft"`.
- Guarda `data._id` para llamadas posteriores a [Recuperar un Smart Report](/verifik-es/smart-reports/retrieve-a-smart-report), [Generar PDF de Smart Report](/verifik-es/smart-reports/generate-smart-report-pdf), [Descargar PDF de Smart Report](/verifik-es/smart-reports/download-smart-report-pdf), [Recuperar HTML de Smart Report](/verifik-es/smart-reports/retrieve-smart-report-html) y [Enviar Smart Report por correo electrónico](/verifik-es/smart-reports/send-smart-report-email).
