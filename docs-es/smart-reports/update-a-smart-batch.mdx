Actualiza campos en un `SmartBatch` existente propiedad del cliente autenticado. Puedes actualizar `name`, `status`, `executor` o reemplazar `rows`. Cuando se proporciona `rows`, el servidor recalcula `totalRows`, `completedRows`, `failedRows` y `partialRows`, y sincroniza las instantáneas externas de filas.

Usa el endpoint dedicado [Pausar un Smart Batch](/verifik-es/smart-reports/pause-a-smart-batch) para pasar un lote a `"paused"`. Cambiar `executor` solo tiene efecto cuando el lote se encuentra actualmente en estado `"draft"`, `"pending"` o `"cancelled"`.

### Endpoint

```text
PUT https://api.verifik.co/v2/smart-batches/{id}
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batches/{id}` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                         |
| --------------- | ---------------------- | --------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato de carga útil de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT delimitado al cliente (`authUser.clientId`).    |

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                              |
| ------ | ------ | --------- | ---------------------------------------- |
| `id`   | string | Sí        | ObjectId de `SmartBatch` a actualizar.   |

### Cuerpo

| Nombre     | Tipo     | Requerido | Descripción |
| ---------- | -------- | --------- | ----------- |
| `name`     | string   | No        | Nombre visible actualizado del lote. Máximo `150` caracteres. |
| `status`   | string   | No        | Valores permitidos: `"draft"`, `"pending"`, `"processing"`, `"completed"`, `"failed"` o `"cancelled"`. Usa `POST /v2/smart-batches/{id}/pause` para `"paused"`. |
| `executor` | string   | No        | Valores permitidos: `"queue"`, `"featureRunner"` o `"browser"`. Solo surte efecto cuando el estado actual del lote es `"draft"`, `"pending"` o `"cancelled"`. |
| `rows`     | object[] | No        | Lista de filas de reemplazo. El formato envuelto requiere `rowIndex` e `inputData` y acepta opcionalmente `status`, `results`, `errors` y `processedAt`; las filas planas se normalizan automáticamente. |

Las claves desconocidas en el cuerpo son rechazadas por la validación Joi con `409 MissingParameter`.

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	body, _ := json.Marshal(map[string]interface{}{
		"name":     "Colombia Onboarding — Updated",
		"executor": "queue",
		"rows": []map[string]interface{}{
			{
				"rowIndex": 0,
				"inputData": map[string]string{
					"documentType":   "CC",
					"documentNumber": "1032386359",
				},
				"status": "pending",
			},
		},
	})

	req, _ := http.NewRequest("PUT", "https://api.verifik.co/v2/smart-batches/"+batchID, bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notas

- `"paused"` no se acepta en `PUT /v2/smart-batches/{id}`; en su lugar llama a [Pausar un Smart Batch](/verifik-es/smart-reports/pause-a-smart-batch).
- Actualizar `executor` se ignora a menos que el lote se encuentre actualmente en estado `"draft"`, `"pending"` o `"cancelled"`.
- Para añadir nuevas filas a un lote existente sin reemplazar las actuales, usa [Agregar filas a un Smart Batch](/verifik-es/smart-reports/append-smart-batch-rows).
