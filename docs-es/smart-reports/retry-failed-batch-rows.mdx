Vuelve a encolar las filas en estado `"failed"` o `"partial"` de un `SmartBatch` sin afectar las filas que ya se completaron. Opcionalmente pasa `rowIndexes` para reintentar solo un subconjunto específico de filas; omite `rowIndexes` para reintentar todas las filas `"failed"` y `"partial"` del lote.

La solicitud falla con `409 Conflict` (`batch_is_processing`) si el lote se encuentra actualmente en estado `"processing"`. Devolver `retried: 0` indica que no coincidió ninguna fila fallida o parcial elegible.

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/{id}/retry-failed
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batches/{id}/retry-failed` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                         |
| --------------- | ---------------------- | --------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato de carga útil de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT delimitado al cliente (`authUser.clientId`).    |

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                |
| ------ | ------ | --------- | -------------------------- |
| `id`   | string | Sí        | ObjectId de `SmartBatch`.  |

### Cuerpo

| Nombre       | Tipo      | Requerido | Descripción |
| ------------ | --------- | --------- | ----------- |
| `rowIndexes` | integer[] | No        | Índices de fila específicos en base `0` (`>= 0`, máximo `10000` elementos) a reintentar. Omítelo para reintentar todas las filas `"failed"` y `"partial"`. |

Las claves desconocidas en el cuerpo son rechazadas por la validación Joi con `409 MissingParameter`.

### Notas

- Envía `{}` (u omite `rowIndexes`) para reintentar todas las filas `"failed"` y `"partial"` a la vez.
- Cuando se proporciona `rowIndexes`, las filas en estado `"completed"` o `"pending"` se ignoran aunque su índice esté incluido.
- Para volver a ejecutar únicamente secuencias de pasos específicas en una sola fila conservando los resultados de los demás pasos, usa [Reintentar pasos de fila de Smart Batch](/verifik-es/smart-reports/retry-batch-row-steps).
