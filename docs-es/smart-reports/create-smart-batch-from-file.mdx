Ingesta una carga útil CSV, XLSX o JSONL en un nuevo `SmartBatch`. El servidor decodifica texto sin formato o URLs de datos base64, aplica `MAX_ROWS` (`20000` por defecto), resuelve encabezados de columnas y alias en camelCase contra las dependencias de pasos de tu `BatchConfiguration`, y calcula una estimación de costo en créditos.

Las filas aceptadas se guardan en el lote en estado `pending`, mientras que las filas malformadas se devuelven en `rejectedRows`. Pasa `autoStart: true` para verificar los permisos de endpoints de la cuenta y comenzar el procesamiento de inmediato; de lo contrario, no se ejecuta ninguna comprobación ni se consumen créditos.

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/from-file
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batches/from-file` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                         |
| --------------- | ---------------------- | --------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato de carga útil de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT delimitado al cliente (`authUser.clientId`).    |

### Cuerpo

| Nombre               | Tipo    | Requerido | Descripción |
| -------------------- | ------- | --------- | ----------- |
| `batchConfiguration` | string  | Sí        | ObjectId de `BatchConfiguration` propiedad del cliente autenticado. |
| `name`               | string  | Sí        | Nombre visible del lote. Máximo `150` caracteres. |
| `content`            | string  | Sí        | Texto CSV/JSONL sin formato o una URL de datos base64 (`data:<mime>;base64,<payload>`). |
| `format`             | string  | No        | Formato de entrada: `"csv"`, `"xlsx"` o `"jsonl"`. Por defecto `batchConfiguration.inputFormat` o `"csv"`. |
| `autoStart`          | boolean | No        | Establece `true` para iniciar el lote creado inmediatamente después de la ingesta. |

Las claves desconocidas en el cuerpo son rechazadas por la validación Joi con `409 MissingParameter`.

### Notas

- El análisis del archivo aplica `MAX_ROWS` (`20000` por defecto) y genera alias de encabezados en camelCase automáticamente para que columnas como `Document Number` se resuelvan a `documentNumber`.
- Para libros `.xlsx`, pasa una URL de datos base64 (`data:application/vnd.openxmlformats-officedocument.spreadsheetml.sheet;base64,<payload>`) con `format: "xlsx"`.
- Los errores `409 Conflict` incluyen `batch_file_has_no_sheets`, `batch_file_is_empty`, `batch_file_has_no_rows`, `batch_file_has_no_usable_rows`, `batch_jsonl_parse_failed_on_line_<N>`, `batch_configuration_has_no_steps` y `endpoints_not_in_account`.
- La validación de filas inválidas (`0` filas válidas), los errores de formato no compatible y los errores de límite `MAX_ROWS` devuelven HTTP `500`.
