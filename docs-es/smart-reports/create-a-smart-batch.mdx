Crea un `SmartBatch` vinculado a una `BatchConfiguration` existente. Debes proporcionar un `name` visible y al menos una fila de entrada en `rows`. Crear el lote persiste las filas de entrada con `status: "draft"` y no ejecuta pasos del catálogo ni consume créditos hasta que inicie la ejecución.

Cada entrada en `rows` acepta un objeto envuelto (`{ rowIndex?, inputData }`) o un objeto plano (`{ rowIndex?, ...inputFields }`), que la capa de validación normaliza en `{ rowIndex, inputData }`. **No** incluyas `status`, `results` ni `errors` al crear.

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batches` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                         |
| --------------- | ---------------------- | --------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato de carga útil de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT delimitado al cliente (`authUser.clientId`).    |

### Cuerpo

| Nombre               | Tipo     | Requerido | Descripción |
| -------------------- | -------- | --------- | ----------- |
| `batchConfiguration` | string   | Sí        | ObjectId de `BatchConfiguration` que define los pasos del flujo. |
| `name`               | string   | Sí        | Nombre visible del lote. Máximo `150` caracteres. |
| `executor`           | string   | No        | Modo de ejecución: `"queue"`, `"featureRunner"` o `"browser"`. Cuando se deriva de `batchConfiguration`, se normaliza a `"queue"` o `"browser"`. |
| `source`             | string   | No        | Identificador del producto de origen: `"smart_batch"` (predeterminado) o `"smart_fleet"`. |
| `rows`               | object[] | Sí        | Arreglo de al menos `1` fila (`min 1`). Acepta `{ rowIndex?, inputData }` envuelto o `{ rowIndex?, ...inputFields }` plano. **No** envíes `status`, `results` ni `errors` al crear. |

Las claves desconocidas y las propiedades de fila no permitidas (`status`, `results`, `errors`) son rechazadas por la validación Joi con `409 MissingParameter`.

### Notas

- Nunca pases `status`, `results` ni `errors` dentro de `rows` al crear un lote; las filas recién creadas siempre comienzan en estado `pending`.
- Si se omite `executor`, se resuelve desde `batchConfiguration.executor` y se normaliza a `"queue"` o `"browser"`.
- Después de crearlo, llama a [Estimar costo de Smart Batch](/verifik-es/smart-reports/estimate-smart-batch-cost) para previsualizar los cargos de créditos y a [Iniciar un Smart Batch](/verifik-es/smart-reports/start-a-smart-batch) para comenzar el procesamiento.
- Para importaciones masivas en CSV, XLSX o JSONL con validación de dependencias y ejecución inmediata opcional, usa [Crear un Smart Batch desde un archivo](/verifik-es/smart-reports/create-smart-batch-from-file).
