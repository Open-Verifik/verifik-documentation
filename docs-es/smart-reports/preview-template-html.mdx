Renderiza cualquier definición de plantilla de Smart Report en un documento HTML independiente completamente en memoria. No se crea ni actualiza ningún registro en la base de datos y no se inicia Chromium durante el renderizado de vista previa, manteniendo tiempos de respuesta rápidos para editores interactivos de plantillas, comprobaciones de verificación en CI y ciclos de diseño con IA.

En pipelines headless y de IA, usa este endpoint para iterar sobre `sections`, `reportTheme`, márgenes y ajustes del puntaje de verificación (`score`, `scoreProfile`, `scoreScale`) antes de persistir la plantilla con [Crear una plantilla de reporte](/verifik-es/smart-reports/create-a-report-template) o [Actualizar una plantilla de reporte](/verifik-es/smart-reports/update-a-report-template). Si renderizas una plantilla con tema o puntuación sin proporcionar `steps` ni `results` dentro de `sampleData`, el renderizador inyecta automáticamente datos sintéticos de muestra de conductor para que tu vista previa se muestre completa.

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates/preview-html
```

El proxy de Smart-Agent (`https://ai.verifik.co`) expone las mismas rutas `/v2/...` y requiere tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Cuerpo

Este endpoint acepta campos auxiliares de vista previa y puntuación además de todos los campos públicos de diseño de plantilla (`sections`, `reportTheme`, `sampleData`, `margins`, `pageSize`, `orientation`, `pdfEngine`, `primaryColor`, `identityColor`, `pageBackgroundColor`, `logo`, `header`, `footer`, `legend`, `termsAndConditions`, `watermark`, `showPageNumbers`, `customFonts`, etc.).

| Nombre          | Tipo            | Requerido | Descripción                                                                                                                                    |
| --------------- | --------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`          | string          | No        | Título opcional del reporte mostrado en el encabezado o metadatos de la vista previa.                                                          |
| `preview`       | boolean         | No        | Indicador de modo vista previa. Toma por defecto `true`.                                                                                       |
| `score`         | boolean         | No        | Habilita el cálculo del puntaje de verificación e incluye `verificationScore` en la respuesta.                                                 |
| `scoreProfile`  | string          | No        | ID de perfil de puntaje de [Listar perfiles de puntaje](/verifik-es/smart-reports/list-score-profiles). Máximo `64` caracteres.                |
| `scoreScale`    | string          | No        | Escala de visualización del puntaje: `"unit"` o `"percent"`. Auxiliar de nivel superior para vista previa; guárdalo en `reportTheme.scoreScale` al persistir. |
| `themeTokens`   | object          | No        | Sobrescrituras personalizadas de tokens del tema. Auxiliar de nivel superior para vista previa; guárdalo en `reportTheme.tokens` al persistir. |
| `scoreSettings` | object          | No        | Ajustes de presentación del puntaje. Auxiliar de nivel superior para vista previa; guárdalo en `reportTheme` (`scoreEnabled`, `scoreProfile`) al persistir. |
| `sections`      | object[]        | No        | Arreglo de bloques `ReportSection` a renderizar.                                                                                               |
| `reportTheme`   | string / object | No        | ID de preset de tema (`"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"`) u objeto completo de configuración `reportTheme`.          |
| `sampleData`    | object          | No        | Payload de muestra de verificación (`inputData`, `results`, `batchName`, `rowIndex`). Si se omite en vistas previas con tema o puntaje, se inyecta una muestra sintética de conductor. |
| `pageSize`      | string          | No        | `"A4"`, `"Letter"` o `"Legal"`. Toma por defecto `"A4"`.                                                                                       |
| `orientation`   | string          | No        | `"portrait"` o `"landscape"`. Toma por defecto `"portrait"`.                                                                                   |
| `margins`       | object          | No        | Objeto de márgenes `{ "top": 40, "right": 40, "bottom": 40, "left": 40 }`.                                                                     |

import (

		"preview":      true,
		"score":        true,
		"scoreProfile": "cabify_driver",
		"scoreScale":   "percent",

		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/preview-html", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)

### Notas

- `verificationScore` se incluye en `data` únicamente cuando la puntuación de verificación está activa (`score: true` o habilitada en `reportTheme`).
- Debido a que este endpoint renderiza puramente en memoria sin escrituras en base de datos ni lanzamiento de Chromium, resulta ideal para iterar rápidamente el diseño antes de llamar a [Descargar muestra de plantilla](/verifik-es/smart-reports/download-template-sample) para la inspección final de paginación del PDF.
- Al persistir un diseño previsualizado mediante [Crear una plantilla de reporte](/verifik-es/smart-reports/create-a-report-template) o [Actualizar una plantilla de reporte](/verifik-es/smart-reports/update-a-report-template), ubica los campos auxiliares de vista previa de nivel superior (`scoreScale`, `themeTokens`, `scoreSettings`) dentro de `reportTheme` (`reportTheme.scoreScale`, `reportTheme.tokens`, `reportTheme.scoreEnabled`/`reportTheme.scoreProfile`).
