Elimina una plantilla personalizada de Smart Report perteneciente al cliente autenticado. El documento de la plantilla eliminada se devuelve dentro de `{ "data": ... }`.

En flujos de trabajo headless y pipelines de pruebas automatizadas, usa este endpoint para limpiar plantillas temporales o retirar diseños de reporte obsoletos. Las plantillas `"System"` integradas no pueden eliminarse y devuelven `403` (`system_template_readonly`). Eliminar una plantilla no consume créditos ni elimina reportes de `SmartBatch` generados previamente.

### Endpoint

```
DELETE https://api.verifik.co/v2/smart-report-templates/{id}
```

El proxy de Smart-Agent (`https://ai.verifik.co`) expone las mismas rutas `/v2/...` y requiere tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                            |
| ------ | ------ | --------- | -------------------------------------- |
| `id`   | string | Sí        | ObjectId de plantilla de Smart Report. |

### Notas

- Las plantillas `"System"` integradas no se pueden eliminar (`403` `system_template_readonly`).
- Una vez eliminada, las solicitudes posteriores `GET`, `PUT` o `DELETE` dirigidas al mismo `{id}` devuelven `{ "data": null }` (en `GET`) o `404` `not_found` (en `PUT`/`DELETE`).
