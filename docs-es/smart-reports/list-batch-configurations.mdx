Lista las `BatchConfiguration` propiedad de tu cuenta de cliente autenticada. Los resultados están delimitados al cliente de tu JWT, ordenados de más reciente a más antiguo (`createdAt` descendente) y devueltos con metadatos `steps.appFeature` populados y precios `ClientFeature` específicos del cliente.

Pasa `page` cuando necesites resultados paginados con los metadatos `total`, `limit`, `page` y `pages`. Omite `page` para recibir directamente en `data` el arreglo coincidente. Listar configuraciones no ejecuta consultas y no consume créditos.

### Endpoint

```
GET https://api.verifik.co/v2/batch-configurations
```

También es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/batch-configurations` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

El token debe ser un **JWT de cliente**. Las credenciales faltantes o inválidas devuelven `401 Unauthorized`.

### Parámetros

Todos los parámetros de consulta son opcionales.

| Nombre    | Tipo    | Requerido | Descripción                                                                                                     |
| --------- | ------- | --------- | --------------------------------------------------------------------------------------------------------------- |
| `search`  | string  | No        | Filtro de nombre sin distinción de mayúsculas aplicado a las configuraciones guardadas.                         |
| `text`    | string  | No        | Alias para `search`.                                                                                            |
| `page`    | integer | No        | Número de página (base `1`). Cuando se proporciona, habilita los metadatos de paginación (`total`, `limit`, `page`, `pages`) en la respuesta. |
| `limit`   | integer | No        | Número máximo de configuraciones a devolver por página.                                                         |
| `perPage` | integer | No        | Alias para `limit`.                                                                                             |

package main

import (
    "encoding/json"

func main() {

    q.Set("page", "1")

    resp, _ := http.DefaultClient.Do(req)
    defer resp.Body.Close()

    var out map[string]interface{}

    fmt.Println(out)
}

### Notas

- Los resultados se limitan automáticamente al JWT de cliente autenticado y se ordenan del más reciente al más antiguo (`-createdAt`).
- El campo `steps.appFeature` de cada paso se popula y enriquece con los precios `ClientFeature` de tu cuenta cuando están configurados.
- `perPage` es un alias para `limit`, y `text` es un alias para `search`.
- Los metadatos de paginación (`total`, `limit`, `page`, `pages`) solo se incluyen cuando se proporciona `page` en la cadena de consulta.
