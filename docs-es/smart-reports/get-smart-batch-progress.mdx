Obtén un resumen ligero de progreso para un `SmartBatch` sin transferir todo el arreglo `rows`. La respuesta incluye contadores de filas (`totalRows`, `completedRows`, `failedRows`, `partialRows`, `pendingRows`), marcas de tiempo de ejecución, `creditsSpent` y —cuando está respaldado por una ejecución de `FeatureRunner`— los detalles anidados de `run` y el libro mayor de gasto (`spend`).

Las ejecuciones de `FeatureRunner` del lado del servidor también emiten un evento webhook `smart_batch_batch_completed` (incluyendo `runId` y `creditsSpent`) al finalizar cuando está configurado `batchConfiguration.notification.webhookUrl`. Consultar este endpoint no consume créditos.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/{id}/progress
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batches/{id}/progress` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                         |
| --------------- | ---------------------- | --------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato de carga útil de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT delimitado al cliente (`authUser.clientId`).    |

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                             |
| ------ | ------ | --------- | --------------------------------------- |
| `id`   | string | Sí        | ObjectId de `SmartBatch` a consultar.   |

### Notas

- `run` y `spend` se incluyen cuando el lote tiene una ejecución de `FeatureRunner` asociada (`run` es `null` si el registro de ejecución referenciado no se devuelve).
- Las ejecuciones de `FeatureRunner` del lado del servidor emiten el evento webhook `smart_batch_batch_completed` (con `runId` y `creditsSpent`) al finalizar si está configurado `batchConfiguration.notification.webhookUrl`. Consulta [Webhooks de Smart Reports](/verifik-es/resources/smart-reports-webhooks).
- Una vez que el lote alcance un estado terminal, usa [Recuperar un Smart Batch](/verifik-es/smart-reports/retrieve-a-smart-batch) para inspeccionar `results` y `errors` por fila.
