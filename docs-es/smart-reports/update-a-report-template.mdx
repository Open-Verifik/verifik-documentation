Actualiza una plantilla personalizada de Smart Report perteneciente a tu cuenta cliente. Envía cualquier subconjunto de metadatos actualizables, `sections` de diseño, `reportTheme`, `sampleData` u opciones de renderizado PDF; los campos omitidos en el payload conservan sus valores existentes.

En pipelines headless y de IA, usa este endpoint para iterar sobre diseños generados por [Generar diseño de plantilla](/verifik-es/smart-reports/generate-template-layout), actualizar recursos de marca (`logo`, `primaryColor`, `customFonts`), actualizar vinculaciones con `SmartBatch` o alternar `isActive`. Las plantillas `"System"` integradas son de solo lectura y devuelven `403` (`system_template_readonly`) si intentas modificarlas.

### Endpoint

```
PUT https://api.verifik.co/v2/smart-report-templates/{id}
```

El proxy de Smart-Agent (`https://ai.verifik.co`) expone las mismas rutas `/v2/...` y requiere tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                            |
| ------ | ------ | --------- | -------------------------------------- |
| `id`   | string | Sí        | ObjectId de plantilla de Smart Report. |

### Cuerpo

Todos los campos del cuerpo son opcionales al actualizar.

| Nombre                | Tipo             | Requerido | Descripción                                                                                                                                      |
| --------------------- | ---------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `name`                | string           | No        | Nombre visible actualizado de la plantilla. Máximo `150` caracteres.                                                                             |
| `description`         | string           | No        | Descripción actualizada de la plantilla. Máximo `500` caracteres.                                                                                |
| `batchConfiguration`  | string           | No        | ObjectId de una configuración de `SmartBatch` asociada.                                                                                          |
| `country`             | string           | No        | Identificador o etiqueta del país. Máximo `60` caracteres.                                                                                       |
| `category`            | string           | No        | Dominio de verificación: `"citizen"`, `"company"` o `"vehicle"`.                                                                                 |
| `isActive`            | boolean          | No        | Activa o desactiva la plantilla.                                                                                                                 |
| `logo`                | string           | No        | URL del logotipo de marca o URI de datos en base64.                                                                                              |
| `primaryColor`        | string           | No        | Color hexadecimal principal de acento de marca.                                                                                                  |
| `identityColor`       | string           | No        | Color hexadecimal secundario/de identidad.                                                                                                       |
| `pageBackgroundColor` | string           | No        | Color hexadecimal de fondo de página.                                                                                                            |
| `header`              | object           | No        | Configuración personalizada de diseño y contenido del encabezado.                                                                                |
| `footer`              | object           | No        | Configuración personalizada de diseño y contenido del pie de página.                                                                             |
| `legend`              | string           | No        | Texto de leyenda o aviso de cumplimiento al pie. Máximo `2000` caracteres.                                                                       |
| `legendPosition`      | string           | No        | Alineación de la leyenda: `"left"`, `"center"` o `"right"`.                                                                                      |
| `termsAndConditions`  | string           | No        | Texto legal de términos y condiciones. Máximo `4000` caracteres.                                                                                 |
| `termsPosition`       | string           | No        | Alineación de términos: `"left"`, `"center"` o `"right"`.                                                                                        |
| `sections`            | object[]         | No        | Arreglo de objetos `ReportSection` (`id`, `type`, `order`, `dataPath`, `label`, `staticContent`, `columns`, `columnsPerRow`, `keyOverrides`, `valueRules`, `chartKind`, `style`, `condition`, `frame`, etc.). |
| `pageSize`            | string           | No        | Tamaño de papel PDF: `"A4"`, `"Letter"` o `"Legal"`.                                                                                             |
| `layoutVersion`       | integer          | No        | Versión del renderizador de diseño: `1` o `2`.                                                                                                   |
| `orientation`         | string           | No        | Orientación de página: `"portrait"` o `"landscape"`.                                                                                             |
| `margins`             | object           | No        | Objeto de márgenes `{ "top": 40, "right": 40, "bottom": 40, "left": 40 }`.                                                                       |
| `pdfEngine`           | string           | No        | Motor de renderizado PDF: `"puppeteer"` o `"pdfkit"`.                                                                                            |
| `showPageNumbers`     | boolean          | No        | Mostrar números de página en los PDFs renderizados.                                                                                              |
| `pageNumberPosition`  | string           | No        | Posición de número de página: `"top-left"`, `"top-center"`, `"top-right"`, `"bottom-left"`, `"bottom-center"` o `"bottom-right"`.                |
| `pageNumberDivider`   | boolean / string | No        | Configuración del separador de número de página.                                                                                                 |
| `watermark`           | object           | No        | Ajustes de superposición de marca de agua.                                                                                                       |
| `security`            | object           | No        | Ajustes de protección de PDF `{ "enabled": true, "password": "..." }`. Pasar `"******"` u omitir `password` conserva la contraseña cifrada existente. |
| `signature`           | object           | No        | Configuración del bloque de firma.                                                                                                               |
| `logoSettings`        | object           | No        | Configuración de tamaño y ubicación del logotipo.                                                                                                |
| `sheetImages`         | object[]         | No        | Recursos de imagen incrustados en la plantilla. Máximo `12` elementos.                                                                           |
| `customFonts`         | object[]         | No        | Declaraciones de fuentes personalizadas (Google Fonts, URL externa o archivo subido). Máximo `6` elementos.                                      |
| `headerLogos`         | object[]         | No        | Logotipos adicionales mostrados en el encabezado. Máximo `16` elementos.                                                                         |
| `bodyTopPadding`      | number           | No        | Relleno superior aplicado al cuerpo del documento, de `0` a `600`.                                                                               |
| `sampleData`          | object           | No        | Payload de verificación de muestra almacenado en la plantilla para vistas previas y descargas de muestra.                                       |
| `endpointDesign`      | object           | No        | Metadatos de presentación específicos de endpoint.                                                                                               |
| `reportTheme`         | string / object  | No        | ID de preset de tema (`"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"`) u objeto (`id`, `scoreScale`, `scoreEnabled`, `scoreProfile`, `locale`, `density`, `eyebrow`, `coverTitle`, `headlines`, `legalNote`, `showVerifiedBadge`, `showWeights`, `showDeductions`, `showFields`, `showHowItWorks`, `blocks`, `tokens`). |

### Notas

- Pasar `security.password: "******"` u omitir `security.password` conserva la contraseña cifrada existente de la plantilla en lugar de sobrescribirla.
- Las plantillas `"System"` integradas no se pueden actualizar (`403` `system_template_readonly`). Crea una copia personalizada mediante [Crear una plantilla de reporte](/verifik-es/smart-reports/create-a-report-template) cuando personalices una plantilla inicial del sistema.
- Guarda los campos auxiliares de vista previa (`scoreScale`, `themeTokens`, `scoreSettings`) bajo `reportTheme` (`scoreScale`, `tokens`, `scoreEnabled`/`scoreProfile`) al persistir cambios.
