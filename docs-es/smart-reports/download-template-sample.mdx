Renderiza una plantilla de Smart Report guardada (`{id}`) en un archivo PDF binario y transmítelo directamente en la respuesta HTTP (`Content-Type: application/pdf`). Puedes proporcionar `sampleData` en el cuerpo de la solicitud, omitirlo para usar el `sampleData` guardado en la plantilla, o enviar un `printHtml` prerrenderizado.

En pipelines headless y suites de verificación de CI, usa este endpoint después de iterar con [Previsualizar HTML de plantilla](/verifik-es/smart-reports/preview-template-html) para inspeccionar en disco la paginación real de Chromium o PDFKit, fuentes personalizadas, marcas de agua, encabezados/pies de página y márgenes de página antes de promover la plantilla a ejecuciones de `SmartBatch` en producción. Se admiten cuerpos de solicitud JSON de hasta `64MB`.

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates/{id}/download-sample
```

El proxy de Smart-Agent (`https://ai.verifik.co`) expone las mismas rutas `/v2/...` y requiere tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>`.

### Encabezados

| Nombre        | Valor                    |
| ------------- | ------------------------ |
| Content-Type  | `application/json`       |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

Nota: En una respuesta `200`, el servidor devuelve `Content-Type: application/pdf` con `Content-Disposition: attachment; filename="SmartReport_TemplateSample_<id>.pdf"`. Las respuestas de error (`401`, `404`, `409`) devuelven JSON.

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                             |
| ------ | ------ | --------- | --------------------------------------- |
| `id`   | string | Sí        | ObjectId de la plantilla de Smart Report. |

### Cuerpo

Admite cargas útiles JSON de hasta `64MB`. Todos los campos del cuerpo son opcionales.

| Nombre       | Tipo   | Requerido | Descripción                                                                                                     |
| ------------ | ------ | --------- | --------------------------------------------------------------------------------------------------------------- |
| `sampleData` | object | No        | Datos de muestra (`inputData`, `results`, `batchName`, `rowIndex`). Usa `template.sampleData` si se omite.      |
| `printHtml`  | string | No        | Cadena HTML prerrenderizada opcional para generar el PDF directamente.                                          |

### Solicitud

Debido a que una respuesta exitosa devuelve bytes binarios de PDF sin procesar en lugar de JSON, configura tu cliente HTTP para salida binaria (`responseType: "arraybuffer"` / `Buffer` en Node.js, bytes de respuesta sin procesar en PHP/Python/Go, o `-o sample.pdf` en cURL).

```javascript
const fs = require("fs");
const axios = require("axios");

async function run() {
  const id = "67c1f94b2d8a1c0012a4b301";
  const res = await axios.post(
    `https://api.verifik.co/v2/smart-report-templates/${id}/download-sample`,

        rowIndex: 0,
        inputData: {

          documentNumber: "1020304050",
        },
        results: {
          identity: {
            fullName: "Mateo Rojas",
            status: "active",
          },
        },
      },
    },
    {
      responseType: "arraybuffer",
      headers: {
        "Content-Type": "application/json",
        Accept: "application/json",
        Authorization: `Bearer ${process.env.VERIFIK_JWT}`,
      },
    }
  );

  const pdfBuffer = Buffer.from(res.data);
  fs.writeFileSync("sample.pdf", pdfBuffer);
  console.log(`Saved sample.pdf (${pdfBuffer.length} bytes)`);
```

```python
import os
import requests

template_id = "67c1f94b2d8a1c0012a4b301"
url = f"https://api.verifik.co/v2/smart-report-templates/{template_id}/download-sample"
headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
    "Authorization": f"Bearer {os.getenv('VERIFIK_JWT')}",
}
payload = {
    "sampleData": {
        "batchName": "Driver Onboarding Sample",
        "rowIndex": 0,
        "inputData": {
            "documentType": "CC",
            "documentNumber": "1020304050",
        },
        "results": {
            "identity": {
                "fullName": "Mateo Rojas",
                "status": "active",
            }
        },
    }
}

r = requests.post(url, json=payload, headers=headers)
r.raise_for_status()

with open("sample.pdf", "wb") as f:
    f.write(r.content)

print(f"Saved sample.pdf ({len(r.content)} bytes)")
```

```go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"os"
)

func main() {
	id := "67c1f94b2d8a1c0012a4b301"
	body, _ := json.Marshal(map[string]interface{}{
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding Sample",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{
					"fullName": "Mateo Rojas",
					"status":   "active",
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/"+id+"/download-sample", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		errBytes, _ := io.ReadAll(resp.Body)
		panic(fmt.Sprintf("status %d: %s", resp.StatusCode, string(errBytes)))
	}

	outFile, err := os.Create("sample.pdf")
	if err != nil {
		panic(err)
	}
	defer outFile.Close()

	n, err := io.Copy(outFile, resp.Body)
	if err != nil {
		panic(err)
	}
	fmt.Printf("Saved sample.pdf (%d bytes)\n", n)
}
```

### Notas

- No llames a `res.json()` en una respuesta `200` de este endpoint; lee la respuesta como un búfer binario (`arraybuffer` / `bytes` / `io.Copy`) y guárdala en disco o en almacenamiento de objetos.
- Si omites `sampleData` y `printHtml` (por ejemplo, enviando `{}`), el endpoint usa el campo `sampleData` guardado en la propia plantilla.
- Para comprobaciones rápidas e iterativas del diseño sin generar el PDF completo, usa [Previsualizar HTML de plantilla](/verifik-es/smart-reports/preview-template-html).
