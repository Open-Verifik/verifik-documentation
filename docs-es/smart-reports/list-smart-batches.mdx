Lista los registros `SmartBatch` pertenecientes a la cuenta de cliente autenticada. Por defecto, los resultados se devuelven de más reciente a más antiguo (`-createdAt`) y excluyen el arreglo `rows` a menos que pases explícitamente `includeRows=true`, manteniendo compactas las respuestas de listado.

Envía `page` para habilitar la salida paginada con los metadatos `total`, `limit`, `page` y `pages`. Omite `page` para recibir `{ data }` con el arreglo de lotes coincidente sin campos de paginación. Listar lotes no ejecuta comprobaciones y no consume créditos.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batches` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                         |
| --------------- | ---------------------- | --------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato de carga útil de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT delimitado al cliente (`authUser.clientId`).    |

### Parámetros

| Nombre               | Tipo    | Requerido | Descripción |
| -------------------- | ------- | --------- | ----------- |
| `batchConfiguration` | string  | No        | Filtra los lotes por ObjectId de `BatchConfiguration`. |
| `status`             | string  | No        | Filtra por estado del lote: `"draft"`, `"pending"`, `"processing"`, `"paused"`, `"completed"`, `"failed"` o `"cancelled"`. |
| `page`               | number  | No        | Número de página (`>= 1`). Habilita la paginación y agrega `total`, `limit`, `page` y `pages` a la respuesta. |
| `limit`              | number  | No        | Número máximo de elementos por respuesta (`1` a `200`). |
| `perPage`            | number  | No        | Tamaño de página (`1` a `200`) cuando `page` está definido. Por defecto `20`. |
| `includeRows`        | boolean | No        | Establece `true` para incluir `rows` en cada lote devuelto. Si se omite o es `false`, `rows` se excluye. |
| `search`             | string  | No        | Búsqueda por expresión regular sin distinción de mayúsculas sobre el campo `name` del lote. |
| `sort`               | string  | No        | Campo y dirección de ordenamiento. Por defecto `"-createdAt"`. |
| `sortBy`             | string  | No        | Nombre del campo de ordenamiento cuando se combina con `sortOrder`. |
| `sortOrder`          | string  | No        | Dirección de ordenamiento para `sortBy`: `"asc"` o `"desc"`. |

Los parámetros de consulta desconocidos son rechazados por la validación Joi con `409 MissingParameter`.

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	params := url.Values{}
	params.Set("status", "processing")
	params.Set("page", "1")
	params.Set("perPage", "20")
	params.Set("search", "Colombia")
	params.Set("sort", "-createdAt")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-batches?"+params.Encode(), nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notas

- Los resultados están delimitados al cliente autenticado (`clientId` en tu JWT).
- Omitir `includeRows` o establecerlo en `false` mantiene las respuestas de listado pequeñas; obtén el detalle completo de `rows` para un lote usando [Recuperar un Smart Batch](/verifik-es/smart-reports/retrieve-a-smart-batch).
- Los valores de consulta inválidos o claves desconocidas fallan la validación Joi con `409 MissingParameter`.
- Cuando se proporciona `page` (`>= 1`), `perPage` toma por defecto `20` y admite de `1` a `200`.
