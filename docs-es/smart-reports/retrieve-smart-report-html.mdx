Recupera el HTML renderizado para un `SmartReport`, junto con su `batchId`, `templateId`, `rowIndex`, `verificationScore` opcional y el payload correspondiente de `row` (`rowIndex`, `status`, `inputData`, `results`, `errors`).

**Importante**: Este endpoint responde con `Content-Type: application/json` y devuelve la cadena HTML dentro de `data.html`, **no** como un documento `text/html` sin formato.

### Endpoint

```
GET https://api.verifik.co/v2/smart-reports/{id}/html
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-reports/{id}/html` usando tu propio encabezado por cliente `Authorization: Bearer <VERIFIK_JWT>`. La ejecución compartida mediante x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                       |
| --------------- | ---------------------- | ------------------------------------------------- |
| `Accept`        | `application/json`     | Formato de respuesta de sobre JSON.               |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT con alcance de cliente (`authUser.clientId`). |

### Parámetros

| Nombre         | Ubicación | Tipo    | Requerido | Descripción |
| -------------- | --------- | ------- | --------- | ----------- |
| `id`           | path      | string  | **Sí**    | ObjectId de `SmartReport`. |
| `rowIndex`     | query     | integer | No        | Índice de fila base cero (`>= 0`). |
| `preview`      | query     | boolean | No        | Renderiza en modo vista previa cuando es `true`. |
| `score`        | query     | boolean | No        | Indica si se debe calcular e incluir `verificationScore` en `data`. |
| `scoreProfile` | query     | string  | No        | Identificador de perfil de puntaje usado cuando `score` está habilitado (máx. `64` caracteres). |

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	id := "6801a2b3c4d5e6f7a8b9c0d1"
	params := url.Values{}
	params.Set("rowIndex", "0")
	params.Set("preview", "false")
	params.Set("score", "true")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-reports/"+id+"/html?"+params.Encode(), nil)
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

#### Códigos de error

| Estado | Código / Tipo de error | Causa |
| ------ | ---------------------- | ----- |
| `401` | `Unauthorized` | JWT ausente o inválido. |
| `403` | `Forbidden` | Se intentó ejecución compartida x402; utiliza tu propio JWT por cliente. |
| `404` | `not_found` | El ID del reporte no existe o pertenece a otro cliente. |
| `404` | `template_not_found` | No se encontró la plantilla vinculada. |
| `409` | `MissingParameter` | Falló la validación Joi en parámetros de ruta o consulta. |
| `409` | `row_not_found` | El `rowIndex` solicitado no existe en el lote. |
| `409` | `unknown_score_profile` | No se reconoce el `scoreProfile` suministrado. |
| `422` | `UnprocessableEntity` | Error de validación de Mongoose. |

### Integración con Webhooks y MCP

- **Equivalente MCP**: Los agentes de IA pueden recuperar el HTML renderizado del reporte y la estructura de la fila mediante la herramienta MCP `smart_report_get_html`. Consulta [MCP y Agentes de IA](/verifik-es/smart-reports/mcp-and-ai-agents).
- **Webhooks**: La ruta `htmlUrl` (`/v2/smart-reports/{id}/html`) se incluye en las respuestas de [Ejecutar un Smart Report](/verifik-es/smart-reports/run-a-smart-report), [Recuperar un Smart Report](/verifik-es/smart-reports/retrieve-a-smart-report) y [Generar PDF de Smart Report](/verifik-es/smart-reports/generate-smart-report-pdf). Consulta [Webhooks de SmartReports](/verifik-es/resources/smart-reports-webhooks).

### Notas

- Dado que la respuesta HTTP usa `application/json`, extrae `data.html` del payload JSON antes de incrustarlo en un webview, iframe o renderizador de PDF.
- `data.verificationScore` está presente cuando se pasa `score=true`.
- `data.row` es `null` si no hay ningún objeto de fila de lote adjunto para el contexto.
