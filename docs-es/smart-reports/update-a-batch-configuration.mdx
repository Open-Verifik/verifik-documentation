Actualiza una `BatchConfiguration` existente propiedad de tu cuenta de cliente. Envía solo los campos que desees cambiar; los campos omitidos conservan sus valores actuales.

Cuando se proporciona `steps`, el servidor normaliza los valores `sequence` faltantes a `index + 1` y acota `retryDelayBaseSeconds` (`>= 1`) y `timeoutSeconds` (`>= 5`). Actualizar `notification` sincroniza automáticamente el Webhook de Verifik asociado, y cambiar `executor` propaga el nuevo ejecutor a los lotes secundarios no terminales. Actualizar una configuración no ejecuta consultas y no consume créditos.

### Endpoint

```
PUT https://api.verifik.co/v2/batch-configurations/{id}
```

También es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/batch-configurations/{id}` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

El token debe ser un **JWT de cliente**. Las credenciales faltantes o inválidas devuelven `401 Unauthorized`.

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                                   |
| ------ | ------ | --------- | --------------------------------------------- |
| `id`   | string | Sí        | ObjectId de `BatchConfiguration` a actualizar. |

### Cuerpo

Todos los campos del cuerpo son opcionales. Incluye solo las propiedades que deseas actualizar.

| Nombre                    | Tipo     | Requerido | Descripción                                                                                                                                                   |
| ------------------------- | -------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`                    | string   | No        | Nombre visible de la configuración. Recortado, máximo `150` caracteres.                                                                                       |
| `description`             | string   | No        | Resumen opcional del flujo de trabajo. Máximo `800` caracteres.                                                                                               |
| `country`                 | string   | No        | Alcance de país. El servidor recorta espacios y convierte a mayúsculas.                                                                                       |
| `steps`                   | object[] | No        | Reemplaza el arreglo ordenado de pasos. Si falta `sequence`, toma por defecto `index + 1`; `retryDelayBaseSeconds` se ajusta a `>= 1` y `timeoutSeconds` a `>= 5`. |
| `inputFormat`             | string   | No        | Formato de entrada predeterminado: `csv`, `jsonl` o `xlsx`.                                                                                                 |
| `outputFormat`            | string   | No        | Formato de salida predeterminado: `csv`, `jsonl` o `xlsx`.                                                                                                  |
| `mergeStrategy`           | string   | No        | Estrategia de ejecución de pasos: `sequential`, `parallel-independent` o `parallel-with-fallback`.                                                            |
| `notification`            | object   | No        | Configuración de notificaciones de finalización (`webhookUrl` y `emailOnCompletion`). Sincroniza automáticamente un Webhook de Verifik activo cuando se establece `webhookUrl`. |
| `scheduleExpression`      | string   | No        | Expresión de programación para ejecuciones automatizadas.                                                                                                     |
| `preferredReportTemplate` | string   | No        | ObjectId de `SmartReportTemplate` vinculado a esta configuración.                                                                                             |
| `visitaFlow`              | object   | No        | Grafo visual de nodos que define el encadenamiento de pasos (las expresiones `{{results.N.field}}` se excluyen de las entradas manuales en el esquema derivado). |
| `isActive`                | boolean  | No        | Indica si la configuración está activa.                                                                                                                       |
| `executor`                | string   | No        | Destino de ejecución: `queue`, `featureRunner` o `browser` (`featureRunner` se persiste como `browser`). Sincroniza los lotes secundarios no terminales cuando cambia. |

### Notas

- Enviar `steps` reemplaza todo el arreglo `steps` de la configuración; no modifica pasos individuales parcialmente.
- Los valores `sequence` faltantes dentro de `steps` se normalizan a `index + 1`, `retryDelayBaseSeconds` se acota a `>= 1` y `timeoutSeconds` se acota a `>= 5`.
- Cambiar `executor` sincroniza cualquier lote secundario no terminal que pertenezca a esta configuración.
- Los IDs faltantes o de otro cliente devuelven `404` (`not_found`), mientras que los errores de validación de esquema de Mongoose devuelven `422` (`UnprocessableEntity`).
