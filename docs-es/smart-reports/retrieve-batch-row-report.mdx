Compone el modelo estructurado de reporte de fila para una sola fila (`rowIndex`) de un `SmartBatch`. Este endpoint ejecuta el compositor de reportes integrado de Verifik (`colombia_vehicle`) sobre las salidas de pasos almacenadas de la fila y adjunta opcionalmente un `verificationScore` cuando se pasa `score` o `scoreProfile`.

Si la `BatchConfiguration` del lote no coincide con un compositor integrado, este endpoint devuelve `409 Conflict` (`no_report_composer_for_configuration`). Para plantillas de reporte personalizadas arbitrarias, usa en su lugar `POST /v2/smart-reports/run`, `GET /v2/smart-reports/{id}/html` o `/generate`. Consultar este endpoint no consume créditos.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                         |
| --------------- | ---------------------- | --------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato de carga útil de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT delimitado al cliente (`authUser.clientId`).    |

### Parámetros de ruta

| Nombre     | Tipo   | Requerido | Descripción                                    |
| ---------- | ------ | --------- | ---------------------------------------------- |
| `id`       | string | Sí        | ObjectId de `SmartBatch`.                      |
| `rowIndex` | number | Sí        | Índice en base `0` de la fila dentro del lote. |

### Parámetros de consulta

| Nombre         | Tipo               | Requerido | Descripción |
| -------------- | ------------------ | --------- | ----------- |
| `score`        | boolean o string   | No        | Pasa `true` o `"1"` para calcular e incluir `verificationScore` en la respuesta. |
| `scoreProfile` | string             | No        | Identificador del perfil de puntuación. Proporcionar `scoreProfile` también habilita `score`. |

  <TabItem value="go" label="Go">

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	rowIndex := "0"
	params := url.Values{}
	params.Set("score", "true")
	params.Set("scoreProfile", "fleet_standard")

	endpoint := fmt.Sprintf("https://api.verifik.co/v2/smart-batches/%s/rows/%s/report?%s", batchID, rowIndex, params.Encode())
	req, _ := http.NewRequest("GET", endpoint, nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}
```

### Notas

- Este endpoint solo sirve reportes de fila compuestos integrados (`colombia_vehicle`). Cualquier otra configuración devuelve `409 Conflict` (`no_report_composer_for_configuration`).
- Para plantillas personalizadas, renderizado HTML temático o expedientes PDF en cualquier configuración, usa `POST /v2/smart-reports/run`, `GET /v2/smart-reports/{id}/html` o `/generate` (consulta [Ejecutar un Smart Report](/verifik-es/smart-reports/run-a-smart-report)).
- `verificationScore` se omite a menos que se proporcione `score=true`, `score=1` o `scoreProfile`.
