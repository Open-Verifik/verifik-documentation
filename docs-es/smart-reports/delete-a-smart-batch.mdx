Elimina un `SmartBatch` propiedad del cliente autenticado. Si el lote existe y pertenece a tu cuenta de cliente, el servidor lo elimina y devuelve el documento `SmartBatch` eliminado en `data`.

Si el ID del lote no existe o pertenece a otro cliente, el endpoint devuelve `404` (`not_found`). Eliminar un lote no reembolsa los créditos consumidos previamente.

### Endpoint

```text
DELETE https://api.verifik.co/v2/smart-batches/{id}
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batches/{id}` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                         |
| --------------- | ---------------------- | --------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato de carga útil de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT delimitado al cliente (`authUser.clientId`).    |

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                            |
| ------ | ------ | --------- | -------------------------------------- |
| `id`   | string | Sí        | ObjectId de `SmartBatch` a eliminar.   |

### Notas

- Para detener un lote activo conservando su historial de filas y resultados, usa [Cancelar un Smart Batch](/verifik-es/smart-reports/cancel-a-smart-batch) en lugar de eliminarlo.
- Los lotes pertenecientes a otra cuenta de cliente devuelven `404` (`not_found`).
