Lista los registros `SmartReport` pertenecientes al cliente autenticado. Los resultados incluyen las referencias pobladas de `template`, `smartBatch` y `client`, y pueden filtrarse por `smartBatch`, `template`, `externalRefId` y `createdByChannel`, con paginación y ordenamiento opcionales.

Cuando pasas `page`, la respuesta incluye metadatos de paginación (`total`, `limit`, `page` y `pages`). Omite `page` para recibir la lista coincidente dentro de `{ data: [...] }` sin metadatos de paginación.

### Endpoint

```
GET https://api.verifik.co/v2/smart-reports
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-reports` usando tu propio encabezado por cliente `Authorization: Bearer <VERIFIK_JWT>`. La ejecución compartida mediante x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                       |
| --------------- | ---------------------- | ------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato del payload de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT con alcance de cliente (`authUser.clientId`). |

### Parámetros

| Nombre             | Tipo   | Requerido | Descripción |
| ------------------ | ------ | --------- | ----------- |
| `smartBatch`       | string | No        | Filtra los reportes vinculados a un ObjectId de `SmartBatch` específico. |
| `template`         | string | No        | Filtra los reportes vinculados a un ObjectId de plantilla específico. |
| `status`           | string | No        | Valores permitidos: `"draft"`, `"pending"`, `"generating"`, `"generated"`, `"failed"`, `"sent"`. Aceptado por la validación Joi por compatibilidad futura; el filtrado actual de lista opera sobre `smartBatch`, `template`, `externalRefId` y `createdByChannel`. |
| `externalRefId`    | string | No        | Filtra por tu identificador externo de correlación. Máx. `200` caracteres. |
| `createdByChannel` | string | No        | Filtra por canal de origen: `"portal"`, `"api"`, `"mcp"`, `"x402"` o `"webhook"`. |
| `page`             | number | No        | Número de página a recuperar. Indicar `page` habilita la salida paginada con `total`, `limit`, `page` y `pages`. |
| `limit`            | number | No        | Cantidad máxima de elementos por página. Predeterminado `20` cuando se define `page`. |
| `sort`             | string | No        | Campo y dirección de ordenamiento. Predeterminado `"-updatedAt"` cuando se define `page`. |

#### Notas sobre filtrado y paginación

- **Parámetro `status` compatible a futuro**: Joi valida `status` contra `"draft"`, `"pending"`, `"generating"`, `"generated"`, `"failed"` y `"sent"`, mientras que la consulta subyacente filtra actualmente por `smartBatch`, `template`, `externalRefId` y `createdByChannel`.
- **Dos formas de respuesta `200`**: Envía `page` siempre que tu panel o tarea de sincronización necesite `total` y `pages`; omite `page` para obtener un payload `{ data: [...] }` más simple.

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	params := url.Values{}
	params.Set("createdByChannel", "api")
	params.Set("externalRefId", "applicant-42")
	params.Set("page", "1")
	params.Set("limit", "20")
	params.Set("sort", "-updatedAt")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-reports?"+params.Encode(), nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notas

- `GET /v2/smart-reports` incluye las referencias `template`, `smartBatch` y `client` en cada `SmartReport` devuelto.
- Los valores de parámetros de consulta inválidos fallan la validación Joi con `409 MissingParameter`.
- Para inspeccionar un único reporte con los campos `downloadUrl` y `htmlUrl` listos para usar, utiliza [Recuperar un Smart Report](/verifik-es/smart-reports/retrieve-a-smart-report).
- Para ejecutar un nuevo reporte de extremo a extremo sin gestionar registros de `SmartBatch` y `SmartReport` por separado, utiliza [Ejecutar un Smart Report](/verifik-es/smart-reports/run-a-smart-report).
