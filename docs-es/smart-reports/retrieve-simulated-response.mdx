Recupera la respuesta simulada de sandbox, el esquema de campos (`outline`), `dataSample` y `emptySample` para un código (`code`) de endpoint del catálogo descubierto mediante [Listar respuestas simuladas](/verifik-es/smart-reports/list-simulated-responses). Puedes alternar el estado `sample` devuelto entre registros poblados (`"data"`), coincidencias vacías (`"empty"`) o datos faltantes (`"missing"`), y controlar la cantidad de filas de arreglo con `listSize`.

En diseño de plantillas headless y flujos automatizados de QA, este endpoint te permite validar cómo renderiza tu plantilla casos límite —como tablas vacías, campos opcionales faltantes o arreglos multipágina (`listSize` de `2` a `30`)— antes de guardar o enviar una plantilla a pipelines de producción de `SmartBatch`.

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses/{code}
```

El proxy de Smart-Agent (`https://ai.verifik.co`) expone las mismas rutas `/v2/...` y requiere tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parámetros

| Nombre         | Tipo    | Ubicación | Requerido | Descripción                                                                                                             |
| -------------- | ------- | --------- | --------- | ----------------------------------------------------------------------------------------------------------------------- |
| `code`         | string  | Path      | Sí        | Código del endpoint del catálogo obtenido de [Listar respuestas simuladas](/verifik-es/smart-reports/list-simulated-responses). |
| `availability` | string  | Query     | No        | Estado simulado a incluir en `sample`: `"data"`, `"empty"` o `"missing"`. Toma por defecto `"data"`.                    |
| `listSize`     | integer | Query     | No        | Cantidad de elementos sintéticos a generar para campos de arreglo/lista. Rango válido: `2` a `30`.                      |

### Notas

- Si `{code}` no está presente en el inventario de sandbox, el endpoint devuelve HTTP `200` con `found: false`, objetos `outline` y `sample` vacíos y una `note` explicativa.
- `listSize` acepta enteros de `2` a `30` y resulta útil para probar paginación PDF multipágina mediante [Descargar muestra de plantilla](/verifik-es/smart-reports/download-template-sample).
- Este endpoint no ejecuta verificaciones en vivo ni consume créditos.
