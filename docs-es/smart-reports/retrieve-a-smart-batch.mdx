Recupera un único documento `SmartBatch` por ID para el cliente autenticado. Antes de devolver la carga útil, el servidor fusiona las salidas almacenadas externamente en `smartbatchrows` dentro de `rows[].results` y ejecuta `healIncompleteRows()` para reabrir las filas marcadas como `completed` a las que les falten pasos de configuración habilitados.

Si el lote no existe o pertenece a otra cuenta de cliente, el endpoint devuelve `200` con `{ "data": null }`. Leer un lote no ejecuta comprobaciones ni consume créditos.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/{id}
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-batches/{id}` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                         |
| --------------- | ---------------------- | --------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato de carga útil de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT delimitado al cliente (`authUser.clientId`).    |

### Parámetros de ruta

| Nombre | Tipo   | Requerido | Descripción                 |
| ------ | ------ | --------- | --------------------------- |
| `id`   | string | Sí        | ObjectId de `SmartBatch`.   |

### Parámetros de consulta

| Nombre        | Tipo     | Requerido | Descripción |
| ------------- | -------- | --------- | ----------- |
| `select`      | string   | No        | Expresión de proyección de campos (por ejemplo `"-rows"` para excluir las cargas útiles de filas). |
| `columns`     | string   | No        | Subconjunto de campos a incluir en el documento devuelto. |
| `populates[]` | string[] | No        | Documentos relacionados a popular: `"batchConfiguration"` y/o `"client"`. |

### Notas

- Los resultados de pasos externos de `smartbatchrows` se fusionan automáticamente en `rows[].results` al leer el lote.
- `healIncompleteRows()` inspecciona cada fila `completed` frente a los pasos habilitados de `batchConfiguration` y reabre a `pending` cualquier fila a la que le falte salida o errores de un paso.
- Para sondeos frecuentes de estado, prefiere [Obtener progreso de Smart Batch](/verifik-es/smart-reports/get-smart-batch-progress) para evitar descargar repetidamente cargas útiles completas de filas.
