Elimina un registro `SmartReport` perteneciente al cliente autenticado. En caso de éxito, la API devuelve el documento `SmartReport` eliminado dentro de `{ "data": ... }`.

Si el ID del reporte no existe o pertenece a otro cliente, el endpoint devuelve `404 Not Found` (`{ "message": "not_found", "code": "NotFound" }`). Eliminar un reporte borra el documento `SmartReport` sin eliminar los datos subyacentes de verificación del `SmartBatch`.

### Endpoint

```
DELETE https://api.verifik.co/v2/smart-reports/{id}
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-reports/{id}` usando tu propio encabezado por cliente `Authorization: Bearer <VERIFIK_JWT>`. La ejecución compartida mediante x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                       |
| --------------- | ---------------------- | ------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato del payload de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT con alcance de cliente (`authUser.clientId`). |

### Parámetros

| Nombre | Tipo   | Requerido | Descripción |
| ------ | ------ | --------- | ----------- |
| `id`   | string | **Sí**    | ObjectId de `SmartReport` a eliminar. |

### Notas

- Las llamadas posteriores a `GET /v2/smart-reports/{id}` devuelven `{ "data": null }`, mientras que `PUT`, `DELETE`, `/generate`, `/download`, `/html` y `/send-email` devuelven `404` (`not_found`).
- Eliminar un `SmartReport` no emite webhooks de entrega ni de generación de reporte; consulta [Webhooks de SmartReports](/verifik-es/resources/smart-reports-webhooks) y [MCP y Agentes de IA](/verifik-es/smart-reports/mcp-and-ai-agents) para conocer los detalles de automatización del ciclo de vida.
