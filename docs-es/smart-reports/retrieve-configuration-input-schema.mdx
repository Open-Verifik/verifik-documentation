Resuelve el contrato exacto de entrada para una `BatchConfiguration` guardada antes de enviar filas. Este endpoint devuelve `preferredReportTemplate` (recurriendo a la última `SmartReportTemplate` activa vinculada a la configuración), `webhookUrl`, `stepCount`, `estimatedCreditsPerRow`, `requiredFields`, `optionalFields`, un `jsonSchema` estándar y una carga útil `exampleInput` lista para enviar.

El resolvedor omite automáticamente pasos deshabilitados, opciones de `dependencyGroup` inactivas, indicadores internos y campos ya suministrados mediante `parameterDefaults` o encadenamiento de pasos en `visitaFlow` (`{{results.N.field}}`), mientras reasigna los nombres de columnas según `inputFieldMapping`. Esta ruta está registrada antes de `/{id}` para que `/input-schema` se resuelva directamente, y también está disponible como la herramienta MCP `smart_report_get_input_schema`.

### Endpoint

```
GET https://api.verifik.co/v2/batch-configurations/{id}/input-schema
```

También es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/batch-configurations/{id}/input-schema` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

El token debe ser un **JWT de cliente**. Las credenciales faltantes o inválidas devuelven `401 Unauthorized`.

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                                        |
| ------ | ------ | --------- | -------------------------------------------------- |
| `id`   | string | Sí        | ObjectId de `BatchConfiguration` a inspeccionar.   |

### Notas

- Inspeccionar el esquema de entrada no ejecuta consultas y no consume créditos.
- Si `preferredReportTemplate` no está configurado en la configuración, el servidor recurre a la última `SmartReportTemplate` activa vinculada a `{id}` (o `null` si no existe ninguna).
- Cuando `inputFieldMapping` mapea una columna de entrada a un parámetro de API, `requiredFields`, `optionalFields`, `jsonSchema` y `exampleInput` exponen el nombre de columna de entrada mapeado en lugar del nombre de parámetro sin procesar de la API.
- Los valores `{id}` faltantes o pertenecientes a otro cliente devuelven `404` (`not_found`), a diferencia de [Recuperar una configuración de lote](/verifik-es/smart-reports/retrieve-a-batch-configuration) que devuelve `200` con `data: null`.
- Para agentes de IA y pipelines headless, este endpoint corresponde a la herramienta MCP `smart_report_get_input_schema`.
