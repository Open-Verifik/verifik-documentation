Elimina una `BatchConfiguration` propiedad de tu cuenta de cliente. El endpoint elimina el documento de configuración y devuelve el documento eliminado en `data`.

Si `{id}` no existe o pertenece a otra cuenta de cliente, el endpoint devuelve `404` (`not_found`). Eliminar una configuración no ejecuta consultas y no consume créditos.

### Endpoint

```
DELETE https://api.verifik.co/v2/batch-configurations/{id}
```

También es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/batch-configurations/{id}` usando tu propio encabezado `Authorization: Bearer <VERIFIK_JWT>` por cliente. La ejecución compartida x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre        | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

El token debe ser un **JWT de cliente**. Las credenciales faltantes o inválidas devuelven `401 Unauthorized`.

### Parámetros

| Nombre | Tipo   | Requerido | Descripción                                  |
| ------ | ------ | --------- | -------------------------------------------- |
| `id`   | string | Sí        | ObjectId de `BatchConfiguration` a eliminar. |

### Notas

- Eliminar una configuración devuelve el documento eliminado dentro de `data`. Las solicitudes posteriores de `GET`, `PUT` o `DELETE` usando el mismo `{id}` ya no encontrarán el registro (`GET` devuelve `data: null`; `GET /input-schema`, `PUT` y `DELETE` devuelven `404` `not_found`).
- Eliminar una configuración no consume créditos.
