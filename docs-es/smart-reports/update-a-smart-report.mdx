Actualiza un `SmartReport` existente perteneciente al cliente autenticado. Envía únicamente los campos que deseas modificar; los campos omitidos en la solicitud permanecen sin cambios.

Si el ID del reporte no existe o pertenece a otro cliente, el endpoint devuelve `404 Not Found` (`{ "message": "not_found", "code": "NotFound" }`).

### Endpoint

```
PUT https://api.verifik.co/v2/smart-reports/{id}
```

Este endpoint también es accesible a través del proxy de Smart-Agent en `https://ai.verifik.co/v2/smart-reports/{id}` usando tu propio encabezado por cliente `Authorization: Bearer <VERIFIK_JWT>`. La ejecución compartida mediante x402 está bloqueada con `403 Forbidden`.

### Encabezados

| Nombre          | Valor                  | Descripción                                       |
| --------------- | ---------------------- | ------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato del payload de la solicitud.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT con alcance de cliente (`authUser.clientId`). |

### Parámetros

| Nombre | Tipo   | Requerido | Descripción |
| ------ | ------ | --------- | ----------- |
| `id`   | string | **Sí**    | ObjectId de `SmartReport` a actualizar. |

### Cuerpo

Todos los campos del cuerpo son opcionales; proporciona únicamente los atributos que quieras actualizar.

| Nombre                     | Tipo             | Requerido | Descripción |
| -------------------------- | ---------------- | --------- | ----------- |
| `name`                     | string           | No        | Nombre visible para el reporte. |
| `status`                   | string           | No        | Estado del reporte: `"draft"`, `"generating"`, `"generated"`, `"sent"` o `"failed"`. |
| `pdfUrl`                   | string           | No        | URL almacenada del artefacto PDF generado. |
| `pdfSize`                  | number           | No        | Tamaño del PDF generado en bytes. |
| `htmlSnapshot`             | string           | No        | Instantánea HTML guardada del reporte renderizado. |
| `pageCount`                | number           | No        | Cantidad de páginas del PDF generado. |
| `pdfEngine`                | string           | No        | Motor de renderizado: `"pdfkit"` o `"puppeteer"`. |
| `generatedAt`              | string           | No        | Marca de tiempo ISO 8601 de cuando se generó el reporte. |
| `generationDurationMs`     | number           | No        | Duración de la generación del PDF en milisegundos. |
| `dataSnapshot`             | object           | No        | Instantánea de datos de fila o de entrada usados para el reporte. |
| `externalRefId`            | string           | No        | Identificador de correlación del llamador. |
| `webhookUrl`               | string           | No        | URL webhook `http` o `https` de sobrescritura por reporte. |
| `rowIndex`                 | number           | No        | Índice de fila base cero asociado con este reporte. |
| `createdByChannel`         | string           | No        | Canal de origen: `"portal"`, `"api"`, `"mcp"`, `"x402"` o `"webhook"`. |
| `verificationScoreSummary` | object           | No        | Metadatos de resumen de la puntuación de verificación. |
| `error`                    | object o string  | No        | Payload o mensaje de error registrado para estados fallidos. |

package main

import (

### Integración con Webhooks y MCP

- Actualizar `webhookUrl` o `externalRefId` actualiza la URL de callback destino y el ID de correlación usados por llamadas posteriores de [Generar PDF de Smart Report](/verifik-es/smart-reports/generate-smart-report-pdf) y [Enviar Smart Report por correo electrónico](/verifik-es/smart-reports/send-smart-report-email). Consulta [Webhooks de SmartReports](/verifik-es/resources/smart-reports-webhooks).
- Para inspeccionar el registro actualizado o ejecutar operaciones de reporte headless mediante un agente de IA, consulta [MCP y Agentes de IA](/verifik-es/smart-reports/mcp-and-ai-agents).

### Notas

- Actualizar un `SmartReport` solo modifica los campos guardados en el reporte; no regenera automáticamente un PDF ni envía correos. Llama a [Generar PDF de Smart Report](/verifik-es/smart-reports/generate-smart-report-pdf) o [Enviar Smart Report por correo electrónico](/verifik-es/smart-reports/send-smart-report-email) cuando quieras volver a renderizar o enviar.
