# Panamá — Consulta de Personas Expuestas Políticamente (PEP / Ley 23 de 2015 y SBP 10-2015)

Permite consultar y verificar si un ciudadano o residente panameño ostenta la condición de **Persona Expuesta Políticamente (PEP)** por **Cédula (`documentNumber` o `cedula`)** o por **Nombre Completo (`fullName`)** conforme al marco regulatorio de prevención de blanqueo de capitales:

- **Ley N° 23 de 2015** (*Prevención del blanqueo de capitales y financiamiento del terrorismo*)
- **Acuerdo SBP N° 10-2015** de la Superintendencia de Bancos de Panamá
- Período reglamentario de carencia de **2 años posteriores a la culminación del mandato o función pública** (*ex-PEP*).

---

## Referencia de API

### Punto de acceso

```http
GET https://api.verifik.co/v2/pa/politically-exposed-persons
```

### Encabezados

| Nombre | Valor |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parámetros

| Nombre | Tipo | Obligatorio | Descripción |
| :--- | :--- | :--- | :--- |
| `cedula` | string | Condicional | Cédula panameña (ej. `8-204-1062` o `8-0204-01062`). Obligatorio si se omite `fullName`. |
| `documentNumber` | string | Condicional | Sinónimo de `cedula`. |
| `documentType` | string | No | Tipo de documento: `CEDULA` (predeterminado) o `CCPA`. |
| `fullName` | string | Condicional | Nombre completo de la persona a consultar. Obligatorio si se omite la cédula. |
| `includeFormer` | boolean | No | Incluye ex-funcionarios dentro de la ventana de 2 años tras cesar funciones. Predeterminado: `true`. |
| `force` | boolean | No | Omite el caché reciente y fuerza una consulta en tiempo real. |

### Notas

- Herramienta de debida diligencia reforzada para sujetos obligados financieros y no financieros (APNFD) en Panamá.
- Cuando `includeFormer=true`, los ex-funcionarios dentro de los 2 años posteriores al cese se retornan con `isFormerPep: true` e `isPep: true`.
- En modo Sandbox, las cédulas de prueba incluyen `8-204-1062` (Poder Ejecutivo), `8-161-172` (Diputado Asamblea Nacional) y `8-712-901` (Sin antecedentes PEP).
