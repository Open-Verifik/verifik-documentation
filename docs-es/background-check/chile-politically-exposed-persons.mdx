# Chile — Consulta de Personas Expuestas Políticamente (PEP / Ley 19.913 y UAF)

Permite consultar y verificar si un ciudadano o residente chileno ostenta la condición de **Persona Expuesta Políticamente (PEP)** por **RUT (`documentNumber` o `rut`)** o por **Nombre Completo (`fullName`)** conforme al marco legal chileno de prevención del lavado de activos y financiamiento del terrorismo:

- **Ley N° 19.913** (*Crea la Unidad de Análisis Financiero y regula el sistema antilavado de activos*)
- **Circular UAF N° 49/2012** (Instrucciones para la debida diligencia de Personas Expuestas Políticamente)
- Período legal de carencia de **2 años posteriores a la dejación del cargo público** (*ex-PEP*).

---

## Referencia de API

### Punto de acceso

```http
GET https://api.verifik.co/v2/cl/politically-exposed-persons
```

### Encabezados

| Nombre | Valor |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parámetros

| Nombre | Tipo | Obligatorio | Descripción |
| :--- | :--- | :--- | :--- |
| `rut` | string | Condicional | RUT chileno (ej. `16152235-6` o `7012456-8`). Obligatorio si se omite `fullName`. |
| `documentNumber` | string | Condicional | Sinónimo de `rut`. |
| `documentType` | string | No | Tipo de documento: `RUT` (predeterminado). |
| `fullName` | string | Condicional | Nombre completo de la persona a consultar. Obligatorio si se omite el RUT. |
| `includeFormer` | boolean | No | Incluye ex-funcionarios dentro de la ventana de 2 años tras cesar en el cargo. Predeterminado: `true`. |
| `force` | boolean | No | Omite el caché reciente y fuerza una consulta en tiempo real. |

### Notas

- Herramienta de cumplimiento para bancos, corredoras de bolsa, fintechs y sujetos obligados ante la UAF Chile.
- Si `includeFormer=true`, los ex-funcionarios dentro de la ventana de 2 años se retornan con `isFormerPep: true` e `isPep: true`.
- En modo Sandbox, los identificadores de prueba incluyen `16152235-6` (Poder Ejecutivo), `7012456-8` (Ministro de Hacienda) y `18945612-3` (Sin registros PEP).
