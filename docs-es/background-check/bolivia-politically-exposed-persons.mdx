# Bolivia — Consulta de Personas Expuestas Políticamente (PEP)

Consulta si una persona en **Bolivia** figura como persona expuesta políticamente (PEP) a partir del **cédula de identidad (CI)** (`documentNumber`) o del **nombre legal completo** (`fullName`). La consulta aplica la **Recomendación 12 del GAFI** y el marco antilavado nacional, con una **ventana de 5 años** para quienes cesaron en el cargo público.

- **Marco normativo:** Instructivo UIF-Bolivia sobre Personas Expuestas Políticamente (PEP) y Ley N° 1178 (SAFCO)
- **Autoridad:** Unidad de Investigaciones Financieras (UIF) / Contraloría General del Estado (CGE)
- **Fuente principal:** Asamblea Legislativa Plurinacional / Contraloría General del Estado / OpenSanctions PEP (BO) (`https://djbr.contraloria.gob.bo/`)

- Alta de clientes y debida diligencia reforzada de PEP nacionales.
- Recribado periódico cuando un mandato empieza, cambia o termina.
- Búsqueda por nombre cuando el documento nacional aún no está en el expediente.

---

## Referencia de API

### Punto de acceso

```http
GET https://api.verifik.co/v2/bo/politically-exposed-persons
```

Una respuesta correcta devuelve `country`, `jurisdiction`, `documentType`, `documentNumber`, `fullName`, `isPEP`, `isActivePep`, `isFormerPep`, `totalMatches`, `matchCount`, `categories`, `includeFormer`, `lookbackYears` (5), `matches`, `checkedSources`, `regulation` y `dateTime`. Cada coincidencia incluye `position`, `entity`, `category`, `categoryDescription`, `status` (`ACTIVE` o `FORMER_PEP`), `source` y `sourceUrl`. La bandera de decisión en la raíz es `isPEP`. Cada coincidencia usa `isPep`. Quien no es PEP también responde HTTP 200, con `isPEP` en false y `totalMatches` en 0.

### Encabezados

| Nombre | Valor |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <su_token>` |

### Parámetros

| Nombre | Tipo | Obligatorio | Descripción |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | Condicional | Cédula de identidad (CI). De 3 a 40 caracteres. Obligatorio si se omite `fullName`. Alias: `id`, `dni`, `cedula`. Ejemplo: `BO-CI-2845123`. |
| `fullName` | string | Condicional | Nombre legal completo, de 3 a 160 caracteres. Obligatorio si se omite `documentNumber`. Alias: `name`. Ejemplo: `LUIS ALBERTO ARCE CATACORA`. |
| `documentType` | string | No | Tipo de documento, de 2 a 20 caracteres. El valor predeterminado es `CI` y se devuelve en la respuesta. |
| `includeFormer` | boolean | No | Incluye a quienes cesaron en el cargo dentro de la ventana de 5 años. Predeterminado: `true`. Envíe `false` para conservar solo cargos `ACTIVE`. Si el único hallazgo es un ex-PEP, `isPEP` pasa a false y `matches` queda vacío. |

---

## Categorías PEP

Cada coincidencia se clasifica según el cargo en una de estas categorías:

| Categoría | Descripción |
| :--- | :--- |
| `HEAD_OF_STATE_OR_GOVERNMENT` | Jefe de Estado, jefe de Gobierno o autoridad del gabinete ejecutivo |
| `SENIOR_EXECUTIVE` | Alto funcionario del poder ejecutivo o ministro del gabinete |
| `LEGISLATIVE` | Integrante del parlamento nacional o de la asamblea legislativa |
| `JUDICIAL_OR_OVERSIGHT` | Alta autoridad judicial, constitucional o de fiscalización superior |
| `DIPLOMATIC_MILITARY_OR_CENTRAL_BANK` | Alto funcionario diplomático, militar o del banco central |
| `PUBLIC_OFFICIAL_PEP` | Persona expuesta políticamente según la Recomendación 12 del GAFI |

## Pruebas de sandbox

Con la cuenta en modo sandbox, estos valores son deterministas:

| Número de documento | Nombre completo | includeFormer | Resultado |
| :--- | :--- | :--- | :--- |
| `BO-CI-2845123` | `LUIS ALBERTO ARCE CATACORA` | `true` | PEP activa (`isPEP` true, categoría `HEAD_OF_STATE_OR_GOVERNMENT`) |
| `10000001` | `LUIS ALBERTO ARCE CATACORA` | `true` | PEP activa (el mismo fixture que el documento `10000001`) |
| `10000002` | `PEP FORMER MINISTER` | `true` | Ex-PEP (`isFormerPep` true) cuando `includeFormer` es true |
| `10000002` | `PEP FORMER MINISTER` | `false` | Resultado limpio cuando `includeFormer` es false |
| `55555555` | `JUAN CARLOS CIUDADANO NO PEP` | `true` | No PEP (`isPEP` false, `totalMatches` 0) |
| `99999404` | `—` | `true` | 404 `NotFound` (solo sonda de sandbox) |

### Notas

- Envíe `documentNumber` o `fullName`. Los alias del documento son `id`, `dni` y `cedula`. El alias del nombre es `name`. Si no hay ninguno, la API responde 409 `MissingParameter` con el mensaje `Either documentNumber or fullName must be provided.`
- `includeFormer` es true de forma predeterminada. Los exfuncionarios dentro de la ventana de 5 años vuelven con `status` `FORMER_PEP`, `isFormerPep` true e `isPEP` true. `false` descarta esas filas y deja solo cargos activos.
- `documentType` toma el valor predeterminado `CI`. `jurisdiction` en la carga es la etiqueta del registro `Bolivia`. `regulation.lookbackYears` es 5.
- Acierto activo en sandbox: documento `BO-CI-2845123` o nombre `LUIS ALBERTO ARCE CATACORA`, y también el documento `10000001`. Acierto de ex-PEP: documento `10000002` o un nombre que contenga `PEP FORMER`, `EX MINISTRO` o `FORMER MINISTER`. Limpio: documento `55555555` con nombre `JUAN CARLOS CIUDADANO NO PEP`. Un documento que contenga `99999404`, o un nombre que contenga `NOTFOUND`, responde 404 en sandbox. Una ausencia en vivo es HTTP 200 con `isPEP` false, no 404.
- Esta ruta consulta solo Bolivia (`BO`). Para una búsqueda transfronteriza use [PEP global](/verifik-es/background-check/world-politically-exposed-persons).
- `checkedSources` enumera las claves de registro consultadas para esta jurisdicción. `regulation.framework` y `regulation.authority` identifican la base ALA que acompaña el resultado.
