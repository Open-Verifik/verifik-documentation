# Lista Otkhozoria–Tatunashvili de Georgia

Consulte si una persona u organización figura en **Lista Otkhozoria–Tatunashvili de Georgia**. El Gobierno de Georgia publica esta lista para Georgia.

Georgia publica la lista Otkhozoria–Tatunashvili de personas nombradas en ese régimen nacional de designación. Cribé los nombres publicados antes de una relación vinculada a Georgia.

Envíe `fullName`, `documentNumber` o ambos. Al menos uno de los dos es obligatorio. La respuesta establece `foundInGeorgiaOtkhozoriaTatunashvili` en `true` cuando la consulta coincide con un registro publicado y en `false` cuando no coincide. Si hay coincidencia, `details` incluye el nombre listado, el tipo de entidad, el régimen o programa, las medidas, el país, los identificadores y las observaciones. Use el resultado en KYC, ALA/CFT, alta de proveedores y filtrado de pagos. Revise cada coincidencia antes de depender de ella. Esta llamada no sustituye la lista oficial y no es una determinación legal.

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/georgia-otkhozoria-tatunashvili
```

Una respuesta correcta devuelve `data.fullName`, `data.firstName` y `data.lastName` cuando el registro de origen separa el nombre, `data.documentNumber` si usted lo envió, `data.foundInGeorgiaOtkhozoriaTatunashvili` y `data.details`. Si hay coincidencia, `details` incluye el nombre listado, el tipo de entidad, el régimen o programa, las medidas, el país, los identificadores y las observaciones. El objeto `signature` incluye `dateTime` y el mensaje `Certified by Verifik.co`. Cuando `foundInGeorgiaOtkhozoriaTatunashvili` es `false`, `details` es un objeto vacío.

### Headers

| Nombre        | Valor              | Descripción             |
| ------------- | ------------------ | ----------------------- |
| Content-Type  | `application/json` | Formato de la solicitud |
| Accept        | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <token>`   | JWT de Verifik          |

### Parameters

| Parámetro        | Tipo   | Requerido   | Ejemplo                  | Descripción                                                                                                      |
| ---------------- | ------ | ----------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| `fullName`       | string | Condicional | `SAMPLE DESIGNATED NAME` | Nombre legal completo de la persona o razón social de la organización. Obligatorio si no envía `documentNumber`. |
| `documentNumber` | string | Condicional | `A1234567`               | Número de identificación o de registro societario, sin espacios. Obligatorio si no envía `fullName`.             |

### Casos de uso

- **Cribado de sanciones:** Verifique clientes, contrapartes y beneficiarios antes del alta o de liberar un pago.
- **Revisiones ALA/CFT:** Deje constancia de la consulta frente a las medidas publicadas de esta jurisdicción.
- **Pista de auditoría:** Conserve la respuesta certificada en el expediente.

### Notes

- Envíe `fullName` o `documentNumber`. Al menos uno es obligatorio. Si faltan ambos, la API responde HTTP 409 con código `MissingParameter` y el mensaje `Either fullName or documentNumber must be provided`.
- `foundInGeorgiaOtkhozoriaTatunashvili` es `true` cuando la consulta coincide con un registro de esta lista y `false` cuando no coincide. `details` es un objeto vacío si no hay coincidencia.
- El ejemplo de coincidencia muestra la forma de la respuesta. Una coincidencia real devuelve los atributos publicados para ese registro en esta lista.
- Una coincidencia es un resultado de cribado para revisión de cumplimiento. No es una determinación legal y no sustituye la fuente oficial.
- Autentique con un JWT Bearer en el encabezado `Authorization`. Cree o renueve el JWT con la [API de autenticación](/verifik-es/autenticacion/renovar-tu-token-jwt).
- El resultado refleja la lista en el momento de la llamada. Haga una nueva solicitud cuando necesite un resultado posterior.
