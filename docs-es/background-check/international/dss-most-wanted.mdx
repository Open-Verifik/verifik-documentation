# Estados Unidos — Más Buscados DSS (Rewards for Justice)

El **Diplomatic Security Service (DSS)** es el brazo de seguridad y aplicación de la ley del **Departamento de Estado de los Estados Unidos**. Investiga delitos transnacionales que amenazan la seguridad diplomática, tales como falsificación de pasaportes y visados, tráfico ilícito de personas, contraespionaje y terrorismo internacional.

A través del programa oficial **Rewards for Justice (RFJ)**, el gobierno estadounidense ofrece recompensas monetarias sustanciales por información que conduzca a la captura de fugitivos de alto perfil a nivel mundial.

---

## Casos de Uso

- **Verificación de Identidad y Control Migratorio:** Identificación de personas sospechosas de adulteración de documentos de viaje o suplantación de identidad.
- **Debida Diligencia de Alto Perfil:** Comprobación de candidatos y contrapartes frente a listas de fugitivos con recompensas federales activas.
- **Cumplimiento y Gestión de Riesgo Reputacional:** Detección oportuna de sujetos requeridos por agencias de seguridad diplomática internacional.

---

### Endpoint

```http
GET https://api.verifik.co/v2/dss-most-wanted
```

### Headers

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parameters

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Condicional** | Nombre completo de la persona a consultar. Requerido si no se envían datos de documento. |
| `documentNumber` | string | **Condicional** | Número de documento de identidad o pasaporte. Requerido si no se envía fullName. |
| `documentType` | string | No | Tipo de documento (ej. `PAS`, `CC`, `DNI`). Predeterminado: `CC`. |
