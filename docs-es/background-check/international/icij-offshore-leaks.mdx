# ICIJ — Base de Datos de Filtraciones Offshore Leaks

El endpoint de **Offshore Leaks (ICIJ)** conecta con la base de datos pública global coordinada por el **Consorcio Internacional de Periodistas de Investigación (ICIJ)**, la cual abarca más de 810,000 entidades corporativas, fideicomisos, fundaciones de interés privado, intermediarios financieros y accionistas incorporados en más de 50 jurisdicciones de secreto financiero y baja o nula tributación.

Esta base de datos integra las mayores filtraciones documentales financieras de la historia moderna:
- **Panama Papers** (Mossack Fonseca)
- **Pandora Papers** (14 firmas proveedoras de servicios corporativos)
- **Paradise Papers** (Appleby y Asiaciti Trust)
- **Bahamas Leaks** y **Offshore Leaks** original.

---

## Casos de Uso

- **Detección de Estructuras Corporativas Opacas y UBO:** Identificación de accionistas ocultos, testaferros y directores nominales en sociedades extraterritoriales.
- **Debida Diligencia Fiscal y Tributaria:** Mitigación de riesgos de evasión fiscal, transferencias artificiales de precios y ocultamiento patrimonial.
- **Monitoreo de Reputación y Cumplimiento:** Identificación de clientes o ejecutivos expuestos en investigaciones periodísticas de alto impacto mediático y judicial.

---

### Endpoint

```http
GET https://api.verifik.co/v2/offshore-leaks
```

### Headers

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parameters

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Sí** | Nombre completo de la persona natural, firma intermediaria o sociedad offshore a verificar (ej. `"Mossack Fonseca & Co"` o `"Vladimir Putin"`). |

## Perfiles de Prueba Sandbox

En ambiente Sandbox (`sandbox.verifik.co` o modo sandbox activo), puedes utilizar los siguientes perfiles de prueba:

| Nombre | Comportamiento en Sandbox |
| :--- | :--- |
| `"Mossack Fonseca & Co"` | Retorna coincidencia en la base de datos de intermediarios offshore (`foundInOffshoreLeaks: true`). |
| `"Mateo Verifik"` | Retorna sin coincidencias en registros o filtraciones offshore (`foundInOffshoreLeaks: false`). |
