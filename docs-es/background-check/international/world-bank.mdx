# Banco Mundial — Empresas e Individuos Inhabilitados

La **Lista de Empresas e Individuos No Elegibles del Banco Mundial** contiene personas naturales y jurídicas que han sido sancionadas e inhabilitadas para licitar o adjudicarse contratos financiados por el Grupo Banco Mundial. Las inhabilitaciones responden a prácticas corruptas, fraudulentas, colusorias, coercitivas u obstructivas.

En virtud del **Acuerdo de Reconocimiento Mutuo de Decisiones de Inhabilitación de 2010 (Acuerdo Multilateral de Inhabilitación Cruzada)**, las sanciones superiores a un año son ejecutadas de manera recíproca por los principales bancos multilaterales (BID, Banco Asiático de Desarrollo, BERD y Banco Africano de Desarrollo).

---

## Casos de Uso

- **Licitaciones y Contratación Pública Internacional:** Comprobación de firmas de ingeniería, consultores y contratistas antes de adjudicar licitaciones públicas.
- **Cumplimiento en Financiación Multilateral:** Verificación obligatoria de cadenas de subcontratación en programas de desarrollo con fondos internacionales.
- **Debida Diligencia Empresarial (KYB):** Prevención de riesgos legales y contractuales al formar consorcios para megaobras de infraestructura.

### Endpoint

```http
GET https://api.verifik.co/v2/world-bank
```

### Headers

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parameters

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Condicional** | Nombre completo o razón social de la empresa a consultar. Requerido si no se envían datos de documento. |
| `documentNumber` | string | **Condicional** | Número de identificación tributaria o cédula. Requerido si no se envía fullName. |
| `documentType` | string | No | Tipo de documento (ej. `NIT`, `EIN`, `CC`, `PAS`). Predeterminado: `CC`. |
