# Estados Unidos — Lista Consolidada de Selección (CSL)

El endpoint de la **Lista Consolidada de Selección (Consolidated Screening List - CSL)** agrupa y unifica las listas oficiales de restricciones de exportación, transferencias y comercio internacional mantenidas por las principales agencias del Gobierno Federal de los Estados Unidos:
- **Departamento de Comercio (BIS):** Entity List, Denied Persons List (DPL), Unverified List (UVL) y Military End User (MEU) List.
- **Departamento de Estado (ISN & PM/DDTC):** Nonproliferation Sanctions, AECA Debarred / ITAR Debarred List.
- **Departamento del Tesoro (OFAC):** Sectoral Sanctions Identifications (SSI), Non-SDN Menu-Based Sanctions (NS-MBS), Non-SDN Chinese Military-Industrial Complex Companies (NS-CMIC), y Foreign Sanctions Evaders (FSE).

Permite a empresas de comercio exterior, logística, banca, tecnología y manufactura evaluar de forma inmediata si una persona física o jurídica está sujeta a **prohibiciones de exportación, embargos o denegación de privilegios comerciales con EE. UU.**

---

## Casos de Uso

- **Control de Exportaciones y Re-exportaciones:** Verificación obligatoria para compañías que comercializan productos o componentes regulados bajo la normativa EAR (*Export Administration Regulations*).
- **Validación de Cadena de Suministro (Supply Chain Compliance):** Evaluación de proveedores, fabricantes y distribuidores internacionales frente a listas negras de defensa y tecnología.
- **Cumplimiento Financiero y Financiamiento de Comercio Exterior:** Prevención de operaciones de crédito o comercio vinculadas a entidades de la lista de usuarios finales militares o empresas bloqueadas.

## Endpoint

```http
GET https://api.verifik.co/v2/csl
```

### Encabezados (Headers)

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parámetros de Consulta (Query Params)

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `fullName` | string | Condicional | Nombre completo o razón social de la entidad a consultar (ej. `"Aeroflot Russian Airlines"`). Obligatorio si no se incluye `documentNumber`. |
| `documentNumber` | string | Condicional | Identificador fiscal, registro mercantil o número de pasaporte de la contraparte. Obligatorio si no se incluye `fullName`. |

```javascript
import axios from "axios";

const options = {
  method: "GET",
  url: "https://api.verifik.co/v2/csl",
  params: {
    fullName: "Aeroflot Russian Airlines",
  },
  headers: {
    Accept: "application/json",
    Authorization: "Bearer <tu_token>",
  },
};

try {
  const { data } = await axios.request(options);
  console.log(JSON.stringify(data, null, 2));
} catch (error) {
  console.error("Error al consultar CSL:", error.response?.data || error.message);
}
```

## Perfiles de Prueba Sandbox

En ambiente Sandbox (`sandbox.verifik.co` o modo sandbox activo), puedes utilizar los siguientes perfiles de prueba:

| Nombre | Comportamiento en Sandbox |
| :--- | :--- |
| `"Aeroflot Russian Airlines"` | Retorna coincidencia en la lista de denegación comercial de EE. UU. (`foundInCSL: true`). |
| `"Mateo Verifik"` | Retorna sin restricciones de exportación ni comercio (`foundInCSL: false`). |
