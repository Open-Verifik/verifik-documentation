# Estados Unidos — Más Buscados DSS y Servicio Secreto

Verifik proporciona endpoints dedicados para la consulta programática contra los registros oficiales de fugitivos más buscados de dos de las agencias de investigación y seguridad más especializadas de los Estados Unidos:

1. **Diplomatic Security Service (DSS / Rewards for Justice):** Registro de fugitivos buscados por el Servicio de Seguridad Diplomática del Departamento de Estado por delitos de terrorismo transnacional, espionaje cibernético, sabotaje a infraestructuras críticas y atentados contra intereses diplomáticos.
2. **United States Secret Service (USSS):** Registro de fugitivos buscados por el Servicio Secreto por delincuencia organizada transnacional, grandes fraudes financieros electrónicos, falsificación de moneda, clonación de activos y ciberdelitos bancarios de gran escala.

---

## Casos de Uso

- **Prevención de Fraude Bancario y Ciberdelincuencia:** Detección de actores de amenazas cibernéticas y cabecillas de redes de fraude electrónico financiero.
- **Debida Diligencia de Alto Perfil y Seguridad Física:** Verificación de antecedentes en operaciones de fusiones y adquisiciones, custodia de activos críticos o contratación de personal clave.
- **Investigaciones Especiales de Cumplimiento:** Identificación de individuos con recompensas federales activas por violaciones de seguridad nacional.

---

## Endpoints

### 1. Servicio de Seguridad Diplomática (DSS / Rewards for Justice)

```http
GET https://api.verifik.co/v2/dss-most-wanted
```

### 2. Servicio Secreto de los Estados Unidos (Secret Service)

```http
GET https://api.verifik.co/v2/secret-service
```

### Encabezados (Headers)

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parámetros de Consulta (Query Params)

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Sí** | Nombre completo del sospechoso o persona a verificar (ej. `"Alexander Petrov"`). Soporta algoritmos de coincidencia fonética y de similitud de nombres. |

  <TabItem value="javascript" label="Node.js (JavaScript)">

```javascript
import axios from "axios";

// Ejemplo: Consulta en DSS / Rewards for Justice
const options = {
  method: "GET",
  url: "https://api.verifik.co/v2/dss-most-wanted",
  params: {
    fullName: "Alexander Petrov",
  },
  headers: {
    Accept: "application/json",
    Authorization: "Bearer <tu_token>",
  },

try {
  const { data } = await axios.request(options);
  console.log(JSON.stringify(data, null, 2));
} catch (error) {
  console.error("Error al consultar fugitivos DSS:", error.response?.data || error.message);
}
```

## Perfiles de Prueba Sandbox

En ambiente Sandbox (`sandbox.verifik.co` o modo sandbox activo), puedes probar con los siguientes nombres:

| Nombre | Endpoint | Comportamiento en Sandbox |
| :--- | :--- | :--- |
| `"Alexander Petrov"` | `/v2/dss-most-wanted` | Retorna alerta de fugitivo buscado (`foundInDSS: true`). |
| `"Alexander Petrov"` | `/v2/secret-service` | Retorna alerta en el listado del Servicio Secreto (`foundInSecretService: true`). |
| `"Mateo Verifik"` | Ambos | Retorna registro sin órdenes de captura (`foundInDSS: false`, `foundInSecretService: false`). |
