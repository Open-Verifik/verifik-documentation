# Prófugos buscados por el BKA de Alemania

Consulte si una persona u organización figura en **Prófugos buscados por el BKA de Alemania**. La Oficina Federal de Investigación Criminal (BKA) publica esta lista para Alemania.

La Oficina Federal de Investigación Criminal publica personas buscadas por la policía alemana. Una coincidencia significa que el nombre consultado aparece en esa lista pública.

Envíe `fullName`, `documentNumber` o ambos. Al menos uno de los dos es obligatorio. La respuesta establece `foundInBkaWanted` en `true` cuando la consulta coincide con un registro publicado y en `false` cuando no coincide. Si hay coincidencia, `details` incluye el nombre listado, la autoridad que publica, el tipo de aviso y las observaciones. Use el resultado en KYC, ALA/CFT, alta de proveedores y filtrado de pagos. Revise cada coincidencia antes de depender de ella. Esta llamada no sustituye la lista oficial y no es una determinación legal.

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/bka-wanted
```

Una respuesta correcta devuelve `data.fullName`, `data.firstName` y `data.lastName` cuando el registro de origen separa el nombre, `data.documentNumber` si usted lo envió, `data.foundInBkaWanted` y `data.details`. Si hay coincidencia, `details` incluye el nombre listado, la autoridad que publica, el tipo de aviso y las observaciones. El objeto `signature` incluye `dateTime` y el mensaje `Certified by Verifik.co`. Cuando `foundInBkaWanted` es `false`, `details` es un objeto vacío.

### Headers

| Nombre        | Valor              | Descripción             |
| ------------- | ------------------ | ----------------------- |
| Content-Type  | `application/json` | Formato de la solicitud |
| Accept        | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <token>`   | JWT de Verifik          |

### Parameters

| Parámetro        | Tipo   | Requerido   | Ejemplo                  | Descripción                                                                                                      |
| ---------------- | ------ | ----------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| `fullName`       | string | Condicional | `SAMPLE DESIGNATED NAME` | Nombre legal completo de la persona o razón social de la organización. Obligatorio si no envía `documentNumber`. |
| `documentNumber` | string | Condicional | `A1234567`               | Número de identificación o de registro societario, sin espacios. Obligatorio si no envía `fullName`.             |

### Casos de uso

- **Cribado policial:** Compruebe si un sujeto figura como buscado por esta autoridad.
- **Debida diligencia reforzada:** Revise un nombre que coincida con un aviso público de búsqueda antes de continuar.
- **Expediente:** Guarde la respuesta certificada con el archivo de cribado.

### Notes

- Envíe `fullName` o `documentNumber`. Al menos uno es obligatorio. Si faltan ambos, la API responde HTTP 409 con código `MissingParameter` y el mensaje `Either fullName or documentNumber must be provided`.
- `foundInBkaWanted` es `true` cuando la consulta coincide con un registro de esta lista y `false` cuando no coincide. `details` es un objeto vacío si no hay coincidencia.
- El ejemplo de coincidencia muestra la forma de la respuesta. Una coincidencia real devuelve los atributos publicados para ese registro en esta lista.
- Una coincidencia es un resultado de cribado para revisión de cumplimiento. No es una determinación legal y no sustituye la fuente oficial.
- Autentique con un JWT Bearer en el encabezado `Authorization`. Cree o renueve el JWT con la [API de autenticación](/verifik-es/autenticacion/renovar-tu-token-jwt).
- El resultado refleja la lista en el momento de la llamada. Haga una nueva solicitud cuando necesite un resultado posterior.
