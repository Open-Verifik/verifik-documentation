# Lista restrictiva — Billeteras cripto Lazarus del FBI

Criba una dirección de billetera contra la lista de billeteras cripto del grupo Lazarus del FBI. Ponga la dirección en fullName.

## Qué devuelve la llamada

- `foundInCryptoFbiLazarus`
- `details` en una coincidencia
- `fullName`

## Casos de uso

- Criba antes de pagar o dar de alta.
- Trate una bandera false como un 200 limpio.
- Envíe un nombre, o tipo y número de documento.

---

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/crypto/fbi-lazarus
```

Una coincidencia pone `foundInCryptoFbiLazarus` en true y llena `details`. Quien no está en la lista es HTTP 200 con `foundInCryptoFbiLazarus` en false y `details` vacío.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **Condicional** | `SAMPLE NAME` | Nombre o, en una lista de billeteras, la dirección. Basta por sí solo. |
| `documentType` | string | **Condicional** | `CPF` | Obligatorio con `documentNumber` si omite `fullName`. Un CPF sin nombre también exige `dateOfBirth`. |
| `documentNumber` | string | **Condicional** | `12345678901` | Identificador de al menos 5 caracteres, con `documentType`, si omite `fullName`. |
| `dateOfBirth` | string | **Condicional** | `1990-01-15` | Obligatoria para CPF, CI, CCPA, DUI o CCUY si omite `fullName`. |

### Notas

- Envíe `fullName`, o `documentType` y `documentNumber`.
- Quien no está listado es HTTP 200 con `foundInCryptoFbiLazarus` en false.
- Un CPF sin nombre también exige `dateOfBirth`.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.

## Sandbox

| Escenario | Parámetros | Resultado |
| :--- | :--- | :--- |
| Registro en la fuente | `fullName: "0x1111111111111111111111111111111111111111"` | 200 con foundInCryptoFbiLazarus en true si la lista coincide. |
| Falta un valor obligatorio | Omit fullName and the document pair | 409 si faltan fullName y el par de documento. |
| Valor desconocido | `fullName: "CLEAN SAMPLE"` | 200 con foundInCryptoFbiLazarus en false si el sujeto simplemente no está. |

401 when the bearer token is missing or rejected.
