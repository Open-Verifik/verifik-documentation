# Estados Unidos — Servicio Secreto Más Buscados

El **Servicio Secreto de los Estados Unidos (USSS)**, agencia federal dependiente del **Departamento de Seguridad Nacional (DHS)**, investiga delitos financieros transnacionales de gran escala, delincuencia organizada cibernética, fraudes a procesadores de pago, ataques de ransomware y falsificación de activos monetarios.

El registro de fugitivos más buscados del Servicio Secreto incluye a individuos procesados por tribunales federales con órdenes de captura vigentes y recompensas activas.

---

## Casos de Uso

- **Prevención de Fraude Bancario y Ciberdelincuencia:** Detección de cabecillas de redes de fraude electrónico financiero y compromiso de sistemas de pago.
- **Debida Diligencia Tecnológica y Corporativa:** Evaluación de personal técnico clave y proveedores con acceso privilegiado a infraestructura crítica.
- **Investigaciones Especiales de Cumplimiento (AML):** Cotejo de transacciones atípicas frente a actores requeridos por autoridades federales.

### Endpoint

```http
GET https://api.verifik.co/v2/secret-service
```

### Headers

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parameters

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Condicional** | Nombre completo de la persona a consultar. Requerido si no se envían datos de documento. |
| `documentNumber` | string | **Condicional** | Número de documento de identidad o pasaporte. Requerido si no se envía fullName. |
| `documentType` | string | No | Tipo de documento (ej. `PAS`, `CC`, `DNI`). Predeterminado: `CC`. |
