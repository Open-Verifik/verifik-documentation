# Argentina — Consulta de Personas Expuestas Políticamente (PEP / UIF Res. 35/2023)

Permite consultar y verificar si un ciudadano o residente argentino ostenta la condición de **Persona Expuesta Políticamente (PEP)** por **DNI, CUIT o CUIL (`documentNumber` o `dni`)** o por **Nombre Completo (`fullName`)** conforme al marco regulatorio de la Unidad de Información Financiera:

- **Resolución UIF N° 35/2023** (*Nómina oficial de Personas Expuestas Políticamente de la República Argentina*)
- **Decreto N° 823/2021** (Régimen de Transparencia e Integridad de la APN)
- Período reglamentario de carencia de **2 años posteriores al cese de funciones públicas** (*ex-PEP*).

---

## Referencia de API

### Punto de acceso

```http
GET https://api.verifik.co/v2/ar/politically-exposed-persons
```

### Encabezados

| Nombre | Valor |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parámetros

| Nombre | Tipo | Obligatorio | Descripción |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | Condicional | DNI, CUIT o CUIL argentino (ej. `12063372` o `22195694`). Obligatorio si se omite `fullName`. |
| `dni` | string | Condicional | Sinónimo de `documentNumber`. |
| `documentType` | string | No | Tipo de documento: `DNI` (predeterminado), `CUIT` o `CUIL`. |
| `fullName` | string | Condicional | Nombre completo de la persona a consultar. Obligatorio si se omite el DNI. |
| `includeFormer` | boolean | No | Incluye ex-funcionarios dentro de la ventana de 2 años tras cesar en funciones. Predeterminado: `true`. |
| `force` | boolean | No | Omite el caché reciente y fuerza una consulta en tiempo real. |

### Notas

- Herramienta reglamentaria de debida diligencia para bancos, fintechs, compañías de seguros y sujetos obligados ante la UIF Argentina.
- Si `includeFormer=true`, los ex-funcionarios dentro de la ventana de 2 años se retornan con `isFormerPep: true` e `isPep: true`.
- En modo Sandbox, los identificadores de prueba incluyen `12063372` (Poder Ejecutivo Nacional), `22195694` (Ministro de Economía) y `35123456` (Sin antecedentes PEP).
