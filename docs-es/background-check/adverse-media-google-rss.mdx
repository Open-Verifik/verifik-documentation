# Búsqueda en Medios Adversos — Google News RSS

El endpoint de **Medios Adversos (Adverse Media)** de Verifik proporciona una solución automatizada para el escaneo y detección en tiempo real de noticias negativas, investigaciones judiciales, acusaciones de fraude, corrupción, narcotráfico o lavado de activos vinculadas a una persona natural o entidad corporativa.

A través de la indexación de noticias públicas y medios de comunicación oficiales y de alta reputación, este servicio procesa el contenido, calcula un **Puntaje de Riesgo Reputacional (Risk Score de 0 a 100)** y clasifica el nivel de severidad del hallazgo (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`).

---

## Casos de Uso

- **Debida Diligencia Intensificada (EDD - Enhanced Due Diligence):** Requisito fundamental en normativas internacionales GAFI / FATF y normativas locales (SAGRILAFT, SARLAFT, SIPLAFT) para clientes, contrapartes o PEPs con factores de riesgo reputacional.
- **Onboarding de Personas Expuestas Políticamente (PEPs):** Identificación temprana de investigaciones en curso por parte de autoridades fiscales, penales o disciplinarias antes de que exista una condena formal.
- **Prevención de Fraude y Riesgo de Contraparte:** Detección de investigaciones preliminares de la Fiscalía o autoridades judiciales reportadas en medios de comunicación.

---

## Endpoint

```http
GET https://api.verifik.co/v2/co/media/adverse
```

*Ruta alterna global:* `GET https://api.verifik.co/v2/media/google-rss`

### Encabezados (Headers)

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parámetros de Consulta (Query Params)

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `name` / `fullName` | string | **Sí** | Nombre completo de la persona natural o razón social de la entidad (ej. `"MAICOL ANGELO GARZON DIAZ"`). |
| `country` | string | No | Código de país ISO de 2 letras (por defecto `co`). Configura el alcance geográfico de los medios de prensa a consultar. |
| `keywords` | string | No | Palabras clave negativas adicionales o personalizadas separadas por operadores booleanos. Si se omite, se aplica el filtro estándar de riesgo: `fraude OR captura OR fiscalia OR delito OR corrupcion OR lavado`. |
| `limit` | number | No | Número máximo de artículos adversos a retornar (valor predeterminado: `20`, máximo: `100`). |

  <TabItem value="javascript" label="Node.js (JavaScript)">

```javascript
import axios from "axios";

const options = {
  method: "GET",
  url: "https://api.verifik.co/v2/co/media/adverse",
  params: {
    fullName: "MAICOL ANGELO GARZON DIAZ",
    country: "co",
    limit: 10,
  },
  headers: {
    Accept: "application/json",
    Authorization: "Bearer <tu_token>",
  },
};

try {
  const { data } = await axios.request(options);
  console.log(JSON.stringify(data, null, 2));
} catch (error) {
  console.error("Error al consultar Medios Adversos:", error.response?.data || error.message);
}
```

## Perfiles de Prueba Sandbox

En ambiente Sandbox (`sandbox.verifik.co` o modo sandbox activo), puedes utilizar los siguientes nombres de prueba:

| Nombre de Consulta | Comportamiento en Sandbox |
| :--- | :--- |
| `"MAICOL ANGELO GARZON DIAZ"` | Retorna noticias adversas detectadas (`hasAdverseMedia: true`, `riskScore: 85`, nivel `HIGH`). |
| `"PEDRO PABLO PEREZ LIMPIO"` | Retorna perfil limpio sin noticias adversas (`hasAdverseMedia: false`, `riskScore: 0`, nivel `LOW`). |
