# Colombia — Rama Judicial JEPMS (Ejecución de Penas y Medidas de Seguridad)

Verifik permite consultar directamente los registros oficiales de los **Juzgados de Ejecución de Penas y Medidas de Seguridad (JEPMS)** de la Rama Judicial de la República de Colombia.

A diferencia de los antecedentes judiciales ordinarios, los Juzgados de Ejecución de Penas conocen de las **condenas penales en firme con sentencia ejecutoriada**, el cumplimiento de penas de prisión, libertad condicional, prisión domiciliaria y medidas de seguridad.

Este endpoint es esencial para procesos de debida diligencia legal y verificación de antecedentes penales de alta criticidad, identificando de manera concluyente si una persona se encuentra cumpliendo una condena judicial o privada de la libertad.

---

## Casos de Uso

- **Verificación de Seguridad y Confianza (Background Check de Alto Riesgo):** Detección de condenas penales firmes y estado de cumplimiento de penas privativas de libertad.
- **Contratación en Sectores Regulados:** Validación obligatoria en entidades bancarias, valores, defensa, transporte de valores y seguridad privada.
- **Monitoreo Judicial y Procesal:** Seguimiento a radicados y despachos judiciales asignados a la ejecución de sentencias condenatorias.

---

### Endpoint

```http
GET https://api.verifik.co/v2/co/rama/jepms
```

*Ruta alterna:* `GET https://api.verifik.co/v2/co/rama/juzgado/expedientes`

### Headers

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parameters

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `documentType` | string | No | Tipo de documento de identidad: `CC` (predeterminado), `CE`, `TI`, `PAS`. |
| `documentNumber` | string | **Sí** | Número de documento de identidad del sujeto a consultar (sin puntos ni espacios, ej. `2373969`). |
| `city` | string | No | Distrito judicial o ciudad a consultar. Valor por defecto: `bogota`. Admite las principales cabeceras de distrito judicial (ej. `medellin`, `cali`, `barranquilla`, `bucaramanga`, etc.). |

const options = {
  method: "GET",

    documentNumber: "2373969",

  headers: {

    Authorization: "Bearer <tu_token>",
  },

  const { data } = await axios.request(options);

}

| Documento | Tipo | Ciudad | Comportamiento en Sandbox |
