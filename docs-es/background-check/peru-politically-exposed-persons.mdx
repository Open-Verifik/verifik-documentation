# Perú — Personas Expuestas Políticamente (PEP / SBS PLAFT)

Verifik ofrece acceso programático al directorio consolidado de **Personas Expuestas Políticamente (PEP)** en la República del Perú, permitiendo a los sujetos obligados ante la **UIF-Perú / SBS** realizar la debida diligencia en el conocimiento del cliente, beneficiario final, directores y proveedores conforme a:

- **Resolución SBS N° 2660-2015** (*Reglamento de Gestión de Riesgos de Lavado de Activos y del Financiamiento del Terrorismo*)
- **Resolución SBS N° 4349-2016** (modificada por **Resolución SBS N° 00199-2025** y **Resolución SBS N° 02868-2025**), incluyendo las categorías `a` a `m` del **Anexo Numeral 2** y la ventana regulatoria de **2 años posteriores al cese en el cargo** (*ex-PEP*).

---

## Casos de Uso

- **Cumplimiento PLAFT / UIF-Perú:** Identificación automatizada de clientes o contrapartes bajo régimen reforzado de debida diligencia conforme a la normativa de la Superintendencia de Banca, Seguros y AFP (SBS).
- **Onboarding Financiero, Fintech y Seguros:** Validación por **DNI**, **Carné de Extranjería (CE)** o **nombre completo** durante procesos de vinculación digital.
- **Debida Diligencia de Proveedores y Contratación:** Detección de altos funcionarios, congresistas, alcaldes, gobernadores regionales, magistrados y responsables de logística/contrataciones del Estado.

---

### Endpoint

```http
GET https://api.verifik.co/v2/pe/politically-exposed-persons
```

### Headers

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parámetros

| Nombre | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | Condicional | Número de DNI peruano (8 dígitos) o Carné de Extranjería (`CE`, 9 a 12 caracteres). Requerido si no se envía `fullName`. |
| `documentType` | string | No | Tipo de documento: `DNI` (predeterminado) o `CE`. |
| `fullName` | string | Condicional | Nombre completo de la persona a consultar (ej. `DINA ERCILIA BOLUARTE ZEGARRA`). Requerido si no se envía `documentNumber`. |
| `includeFormer` | boolean | No | Incluye ex-funcionarios (*ex-PEP*) dentro de la ventana de 2 años posteriores al cese establecida por la Res. SBS 4349-2016 / 02868-2025. Valor predeterminado: `true`. Envíe `false` para filtrar únicamente cargos vigentes. |
| `force` | boolean | No | Si es `true`, omite el caché reciente y fuerza una consulta fresca. |

---

## Categorías SBS Anexo Numeral 2 (`a` – `m`)

Cada coincidencia es clasificada automáticamente según el **Anexo Numeral 2 de la Resolución SBS N° 4349-2016 / 02868-2025**:

| Categoría | Descripción (Anexo Numeral 2 SBS) |
| :--- | :--- |
| `a` | Presidente de la República, Vicepresidentes, Congresistas de la República y Parlamentarios Andinos |
| `b` | Ministros, Viceministros, Secretarios Generales y Titulares de Organismos Públicos del Poder Ejecutivo |
| `c` | Gobernadores, Vicegobernadores, Consejeros Regionales, Alcaldes y Regidores Municipales |
| `d` | Jueces Supremos y Superiores, Magistrados del Tribunal Constitucional, JNJ y Fiscales Supremos / Superiores |
| `e` | Titulares y Miembros de Directorio de Organismos Constitucionalmente Autónomos (BCRP, SBS, JNE, ONPE, RENIEC, Contraloría, Defensoría) |
| `f` | Oficiales Generales y Almirantes de las Fuerzas Armadas y de la Policía Nacional del Perú (PNP) |
| `g` | Embajadores, Cónsules y Representantes Diplomáticos del Perú |
| `h` | Directores, Gerentes Generales y Ejecutivos de Empresas del Estado (FONAFE, Petroperú, Banco de la Nación) |
| `i` | Fundadores, Miembros de Directivas Nacionales (CEN) y Representantes Legales de Partidos Políticos |
| `j` | Altos Directivos de Organismos Internacionales acreditados en el Perú |
| `k` | Funcionarios responsables de Administración, Presupuesto, Finanzas, Logística, Tesorería y Contrataciones del Estado |
| `l` | Colaboradores directos, asociados cercanos y parientes hasta el segundo grado de consanguinidad o afinidad |
| `m` | Otros altos funcionarios públicos y directivos obligados a presentar Declaración Jurada de Ingresos, Bienes y Rentas (DDJJ) o de Intereses (DJI) |

  <TabItem value="javascript" label="Node.js (JavaScript)">

```javascript
import axios from "axios";

const options = {
  method: "GET",
  url: "https://api.verifik.co/v2/pe/politically-exposed-persons",
  params: {
    documentType: "DNI",
    documentNumber: "06256217",
    includeFormer: true,
  },
  headers: {
    Accept: "application/json",
    Authorization: "Bearer <tu_token>",
  },
};

try {
  const { data } = await axios.request(options);
  console.log(JSON.stringify(data, null, 2));
} catch (error) {
  console.error("Error al consultar PEP Perú:", error.response?.data || error.message);
}
```
