# Colombia — PEP candidatos electorales

Criba candidatos electorales que son personas expuestas políticamente en Colombia.

## Qué devuelve la llamada

- `isPEP`
- `isCandidate`
- `fullName` y `documentNumber`
- `matches` vacío en una ausencia limpia

## Casos de uso

- Criba un directorio PEP de Colombia antes del alta.
- Guarde a quien no está listado como HTTP 200.
- Busque por nombre o por número de documento.

---

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/co/pep/candidatos
```

Un acierto pone `isPEP` en true y `isCandidate` en true. Quien simplemente no está en este directorio es HTTP 200 con `isPEP` en false y `matches` vacío. Esa ausencia no es 404.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **Condicional** | `MARIA LOPEZ` | Nombre. Basta por sí solo. También se aceptan `partyName`, `entityName` o `country` cuando el directorio los tiene. |
| `documentNumber` | string | **Condicional** | `80123456` | Identificador de 4 a 30 caracteres. |
| `documentType` | string | No | `CC` | Opcional: `CC`, `NIT`, `CE`, `PAS`, `TI`, `CD`. |

### Notas

- Una ausencia limpia es HTTP 200 con `isPEP` en false.
- Envíe al menos un valor de búsqueda.
- No mapee ese 200 a 404.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.

## Sandbox

| Escenario | Parámetros | Resultado |
| :--- | :--- | :--- |
| Registro en la fuente | `fullName: "MARIA LOPEZ"` | 200 con isPEP en true si hay acierto. |
| Falta un valor obligatorio | Omit every search value | 409 si no hay valor de búsqueda. |
| Valor desconocido | `fullName: "CLEAN NAME"` | 200 con isPEP en false. La ausencia limpia no es 404. |

401 when the bearer token is missing or rejected.
