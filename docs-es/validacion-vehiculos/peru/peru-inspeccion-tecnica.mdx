# Perú - Certificado de Inspección Técnica Vehicular

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/inspeccion-tecnica
```

Consulta los certificados de inspección técnica vehicular (**CITV**) registrados en el Ministerio de Transportes (**MTC**) de Perú para una **`placa`**. La respuesta indica si hay certificado (`found`), si alguno está vigente (`hasValidCertificate`), el certificado más reciente (`latestCertificate`) y todos los certificados que devuelve la fuente (`certificates`).

### Encabezados

| Nombre          | Valor              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parámetros

| Nombre    | Tipo   | Requerido | Descripción                                                                 | Ejemplo  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | Sí      | Placa del vehículo, de 5 a 8 letras o dígitos, sin espacios. Ejemplo: `V0R660`.  | `V0R660` |
| `force` | boolean | No      | Opcional. Envía `true` o `1` para omitir el resultado guardado y consultar de nuevo al MTC.  | `true` |

### Notas

- Envía `plate` sin espacios ni guiones (de 5 a 8 caracteres alfanuméricos).
- `hasValidCertificate` es `true` cuando al menos un certificado tiene estado `VIGENTE`.
- `latestCertificate` es el primer certificado que devuelve el MTC. `certificates` lista todos los registros de esa placa. `V0R660` tiene hoy dos certificados vigentes.
- Una placa sin certificado, o una placa que no tenga de 5 a 8 letras o dígitos, responde **404**.
- Si la fuente del MTC no está disponible, la API responde **409** con `Endpoint_out_of_service`.
- En **modo sandbox**, `ABC10001` devuelve un certificado vigente (`VIGENTE`) y `ABC10002` devuelve un certificado vencido (`VENCIDO`).
