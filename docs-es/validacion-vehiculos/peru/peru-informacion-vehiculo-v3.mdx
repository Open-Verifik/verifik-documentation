# Perú - Información de Vehículo (v3)

### Endpoint

```
GET https://api.verifik.co/v3/pe/vehiculo/placa
```

El servicio v3 de Información de Vehículos Peruanos devuelve los datos registrados para una placa (**`plate`**): marca, modelo, año, seriales de motor y chasis, estado, propietarios cuando estén disponibles y ficha técnica estructurada (`technicalSheet` con `engine`, `performance` y `dimensions` como largo, ancho, alto, distancia entre ejes, peso, tanque de combustible, puertas y ocupantes).

### Encabezados

| Nombre        | Valor              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parámetros

| Nombre  | Tipo   | Requerido | Descripción                                                 | Ejemplo  |
| ------- | ------ | --------- | ----------------------------------------------------------- | -------- |
| `plate` | string | Sí        | Número de placa del vehículo a consultar, sin espacios ni puntos. | `ABC123` |

### Notas

- `technicalSheet` (incluidos los campos de `dimensions` como `length`, `width`, `height`, `wheelbase`, `curbWeight`, `fuelTank`, `doors` y `occupants`) puede retornar `null` o completarse parcialmente cuando no hay coincidencia exacta de ficha técnica para el modelo/año del vehículo.
- En **modo sandbox**, placas como `ABC10001`–`ABC10010` devuelven perfiles de vehículo de ejemplo estables.
