# Perú - Orden de Captura Vehicular (SAT Lima)

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/captura-lima
```

Consulta en el SAT de Lima si una **`placa`** tiene orden de captura en la provincia de Lima. Una placa sin orden es una respuesta exitosa: `hasCaptureOrder` es `false` y `orders` queda vacío. Cuando hay orden, `message` trae el texto oficial del SAT y cada elemento de `orders` incluye `concept`, `amount` en soles, `period` y `documentNumber`. `status` se llena solo cuando el SAT lo envía. `columns` conserva las etiquetas originales de la fuente cuando el formulario público las trae.

### Encabezados

| Nombre          | Valor              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parámetros

| Nombre    | Tipo   | Requerido | Descripción                                                                 | Ejemplo  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | Sí      | Placa del vehículo, de 5 a 8 letras o dígitos, sin espacios. `F1E120` tiene orden. `V0R660` no.  | `F1E120` |
| `force` | boolean | No      | Opcional. Envía `true` o `1` para omitir el resultado guardado y consultar de nuevo al SAT.  | `true` |

### Notas

- La consulta cubre solo la provincia de Lima.
- Envía `plate` sin espacios ni guiones (de 5 a 8 caracteres alfanuméricos).
- Una placa sin orden de captura igual responde **HTTP 200**. El **404** es solo para una placa que no tenga de 5 a 8 letras o dígitos.
- `amount` va en soles (`S/ 505.86`). `status` queda vacío cuando el SAT no envía un estado.
- `F1E120` tiene orden de captura. `V0R660` no.
- Si no se puede consultar el SAT, la API responde **409** con `Endpoint_out_of_service`.
- En **modo sandbox**, `ABC10001` tiene orden de captura y `ABC10002` no.
