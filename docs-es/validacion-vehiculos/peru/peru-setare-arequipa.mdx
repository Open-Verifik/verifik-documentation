# Perú - Permiso de Taxi SETARE Arequipa

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/setare-arequipa
```

Valida si un vehículo cuenta con permiso de operación **SETARE** para servicio de taxi en Arequipa, Perú a partir de su número de placa (**`plate`**). Retorna el indicador booleano de vigencia (`hasActivePermit`), el permiso más reciente (`latestPermit`) y el listado completo de autorizaciones registradas (`permits`) en registros municipales oficiales.

### Encabezados

| Nombre        | Valor              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parámetros

| Nombre  | Tipo   | Requerido | Descripción                                                                   | Ejemplo  |
| ------- | ------ | --------- | ----------------------------------------------------------------------------- | -------- |
| `plate` | string | Sí        | Número de placa a consultar (6 caracteres alfanuméricos, ej. `V3D236`).      | `V3D236` |

### Notas

- Envía `plate` sin espacios ni guiones (6 caracteres alfanuméricos).
- `hasActivePermit` es `true` cuando al menos un permiso registrado tiene estado activo (`Vigente`, `Activo` o `Habilitado`).
- En **modo sandbox**, `ABC10001` devuelve un permiso `Definitivo` activo (`Vigente`) y `ABC10002` devuelve un permiso `Transitorio` vencido (`Vencido`).
