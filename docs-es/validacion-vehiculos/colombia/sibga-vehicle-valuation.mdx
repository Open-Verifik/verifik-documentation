# SIBGA - Avalúo comercial de vehículo

Devuelve el avalúo comercial oficial del **Ministerio de Transporte (SIBGA)** para un vehículo colombiano. Verifik consulta la placa en el **RUNT** y homologa marca, línea, clase, combustible y cilindraje con el catálogo SIBGA. No hace falta mantener una tabla de equivalencias.

Envíe solo la placa, o la placa junto con el documento del propietario. Con documento, el RUNT se consulta por placa y propietario, igual que [Registros de vehículo por placa](/verifik-es/validacion-de-vehiculo/colombia/vehiculo-por-placa-y-cedula-unicamente). Sin documento, la consulta sigue [Vehículo solo por placa](/verifik-es/validacion-vehiculos/colombia/runt-vehicle-by-plate-only).

Úselo para suscripción de seguros, crédito y avalúo de flotas cuando la base gravable debe salir de SIBGA.

## Qué devuelve esta API

- **`valuation`** — valor comercial en **COP** para el año modelo. `null` cuando SIBGA no avalúa ese año (los vehículos más nuevos que el periodo se avalúan con la factura)
- **`valuesByModel`** — avalúo de unos **25** años modelo, hasta el año anterior al periodo
- **`matched`** — tipo, clase, marca, línea, cilindraje SIBGA y el **`avalId`** del certificado
- **`confidence`** — fuerza de la homologación de línea, marca y clase (`exact`, `high`, `medium`, `low` o `none`)
- **`needsReview`** / **`reviewReason`** — cuando la homologación es débil, SIBGA rechazó la búsqueda, no hubo línea o el modelo no está avaluado
- **`alternatives`** — otras líneas del catálogo consideradas, con puntaje
- **`certificateUrl`** — PDF oficial de SIBGA cuando hay avalúo
- **`runtSource`** — marca, línea, modelo, clase y cilindraje del RUNT usados en la homologación
- Respuesta **firmada** por Verifik

## Referencia de la API

### Endpoint

```
GET https://api.verifik.co/v2/co/sibga/valuation
```

Envíe **`plate`** como parámetro de consulta. **`documentType`** y **`documentNumber`** son opcionales y deben enviarse juntos. **`period`** es el año gravable, desde **2016** hasta el año en curso, y si se omite se usa el año actual. La respuesta incluye el avalúo, la tabla por año modelo, el registro SIBGA homologado y una marca de revisión cuando una persona debe confirmar el resultado.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | Sí | Placa colombiana, **5–9** caracteres alfanuméricos. | `CUT984` |
| `documentType` | string | No | Tipo de documento del propietario. Uno de **`CC`**, **`CE`**, **`PA`**, **`NIT`**. Obligatorio junto con `documentNumber`. | `CC` |
| `documentNumber` | string | No | Número de documento del propietario, sin espacios ni puntuación. Obligatorio junto con `documentType`. | `63535790` |
| `period` | number | No | Año gravable, desde **2016** hasta el año en curso. Si se omite, se usa el año actual. | `2026` |

### Notes

- El código de AppFeature es **`colombia_api_vehicle_valuation_sibga`**.
- Un cuerpo con **`valuation: null`** sigue siendo **HTTP 200**. Lea **`reviewReason`**: `model_not_valued_in_period`, `low_confidence_match`, `no_matching_line` o `sibga_search_rejected`.
- **`documentType`** y **`documentNumber`** deben enviarse juntos, u omitirse ambos.
- Las clases no soportadas, como un semirremolque, devuelven **404**.
- En sandbox, las placas **`AA123BA`–`AA123BF`**, **`AA123BH`** y **`AA123BI`** devuelven vehículos distintos con avalúo. **`AA123BG`** devuelve **200** con `reviewReason: model_not_valued_in_period`. **`AA123BJ`** y **`ERR40401`** devuelven **404**. El documento **`90040401`** devuelve **404** y **`90050001`** devuelve **500**.
- Consultas RUNT relacionadas: [vehículo por placa](/verifik-es/validacion-de-vehiculo/colombia/vehiculo-por-placa-y-cedula-unicamente) y [vehículo solo por placa](/verifik-es/validacion-vehiculos/colombia/runt-vehicle-by-plate-only).
