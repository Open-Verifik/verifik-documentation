# Validación de Licencia de Conducir en RUNT (Básico)

La misma consulta de conductor que [Premium v2](/verifik-es/validacion-vehiculos/colombia/licencia-conducir-runt) (`GET /v2/co/runt/conductor`), cobrada al precio **Básico** de conductor. Debe enviar `primerApellido` (mínimo 2 caracteres) para todos los tipos de documento, incluido `TI`. Si lo omite, la API responde `409 MissingParameter`. Este endpoint no busca el apellido y no suma el precio de RUI.

Use esta ruta cuando ya conoce el primer apellido. Enviar `primerApellido` en v2 se cobra a este mismo precio Básico.

### v2 y v3

| | Premium `GET /v2/co/runt/conductor` | Básico `GET /v3/co/runt/conductor` |
| --- | --- | --- |
| Apellido (`primerApellido`) | No es obligatorio, salvo **`PA`**, que sí lo exige. Verifik encuentra el apellido cuando usted lo omite. | Obligatorio para todos los tipos de documento (mínimo 2 caracteres). |
| Tipos de documento | `CC`, `TI`, `CE`, `PA`, `PPT` | `CC`, `TI`, `CE`, `PA`, `PPT` |
| Cobro | Sin apellido: **Premium**. Para `TI` sin apellido, el precio de lista del conductor **más** el precio de lista de RUI (`GET /v2/co/rui`). Con apellido: **Básico**, el mismo precio que v3. | Precio **Básico** de conductor. No hay búsqueda de apellido ni precio de RUI. |

### Service URL

```
GET https://api.verifik.co/v3/co/runt/conductor
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parámetros

| Name             | Type   | Required | Description |
| ---------------- | ------ | -------- | ----------- |
| `documentType`   | string | Yes      | Uno de **`CC`**, **`TI`**, **`CE`**, **`PA`**, **`PPT`**. **`PA` es pasaporte, `PPT` no lo es**. **`TI`** es *tarjeta de identidad*. |
| `documentNumber` | string | Yes      | Número de documento del conductor, sin espacios ni puntos. |
| `primerApellido` | string | **Yes**  | Primer apellido (mínimo 2 caracteres). Obligatorio para todos los tipos de documento, incluido `TI`. |

### Tipos de documento

| Código | Nombre completo | Quién lo tiene | Etiqueta RUNT | `primerApellido` |
| --- | --- | --- | --- | --- |
| **`CC`** | *Cédula de Ciudadanía* | Ciudadanos colombianos | `C.` | **Obligatorio** |
| **`TI`** | *Tarjeta de Identidad* | Tarjeta de identidad colombiana | — | **Obligatorio** |
| **`CE`** | *Cédula de Extranjería* | Extranjeros residentes | `E.` | **Obligatorio** |
| **`PA`** | *Pasaporte* | Titulares de pasaporte | `P.` | **Obligatorio** |
| **`PPT`** | *Permiso por Protección Temporal* | Permiso temporal venezolano — **no es pasaporte** | `Y.` | **Obligatorio** |

### Notas

- Una solicitud al precio Básico de conductor, también para `TI` cuando envía `primerApellido`.
- Sin `primerApellido` este endpoint no busca el apellido y no suma el precio de RUI.
- Los valores aceptados de `documentType` son **`CC`**, **`TI`**, **`CE`**, **`PA`** y **`PPT`**.
- Para la resolución automática del apellido, use [`/v2/co/runt/conductor`](/verifik-es/validacion-vehiculos/colombia/licencia-conducir-runt). En ese endpoint, `TI` sin `primerApellido` se cobra como el precio de lista del conductor más el precio de lista de RUI.
