# Valores de Vehículos por Placa - Fasecolda

La API de Valores de Vehículos por Placa Fasecolda de Verifik permite obtener valoraciones comerciales oficiales y especificaciones técnicas de vehículos registrados en Colombia utilizando únicamente la placa. Para maximizar la tasa de éxito en automóviles, camionetas, camperos, vehículos pesados y motocicletas, este endpoint conecta **dos fuentes oficiales complementarias de datos vehiculares**:

1. **Resolución Primaria (Índice Directo Placa-Código)**: Cuando la placa tiene un código de valoración Fasecolda directamente asociado en el índice principal, Verifik retorna de inmediato la referencia exacta del catálogo.
2. **Resolución Secundaria (Cruce de Especificaciones Técnicas entre Fuentes)**: Cuando un vehículo (especialmente motocicletas o vehículos recién matriculados) no tiene un código directo asociado por placa en el índice de valoración, Verifik consulta automáticamente las especificaciones técnicas verificadas del vehículo (`brand`, `line`, `cylinderCapacity`, `year` y `vehicleClass`) en un registro oficial secundario y las cruza contra el catálogo de la Guía de Valores de Fasecolda.

Siempre que una respuesta se resuelve mediante el cruce de especificaciones entre fuentes, el payload incluye metadatos completos de trazabilidad y puntaje (`matchSource`, `matchConfidence`, `matchNote`, `matchDetails` y `runtVehicle`) para que tu flujo de suscripción o avalúo conozca con total transparencia cómo se obtuvo el código y qué factores redujeron el puntaje de confianza.

## ¿Qué valida esta API?

- **Información de Vehículos y Motocicletas por Placa**: Soporta placas colombianas de automóviles, camionetas, camperos, vehículos pesados y motocicletas (`ABC123`, `ABC12D`, `ABC12`). La placa se normaliza automáticamente (conversión a mayúsculas y eliminación de espacios, guiones y puntos).
- **Datos Técnicos y de Valoración Completos**: Retorna código Fasecolda (`code` / `homoloCode`), marca (`marke`), líneas (`line1`, `line2`, `line3`), clase (`class`), categoría (`category`), cilindraje (`cylinderCapacity`), combustible (`fuel`), transmisión (`transmission`), precio comercial base (`bcpp`) y valores históricos por modelo (`valueModel`).
- **Transparencia Multi-Fuente y Desglose de Confianza**: Entrega un puntaje ponderado de confianza (`0.60` a `1.00`) junto con la explicación detallada de cada deducción (`matchDetails.penalties`) cuando se utiliza el cruce de especificaciones técnicas.

## Referencia de API

### Endpoint

```
GET https://api.verifik.co/v2/co/fasecolda/values-by-plate
```

El servicio de consulta de valor de vehículo Fasecolda ofrece información integral sobre vehículos registrados en Colombia (`code`, `marke`, `line1`, `line2`, `line3`, `class`, `cylinderCapacity`, `bcpp`, `valueModel`) e incluye `matchSource`, `matchConfidence`, `matchNote`, `matchDetails` y `runtVehicle` cuando se resuelve por cruce de especificaciones entre fuentes. Envía la **placa** como parámetro de **consulta** (`plate`).

### Notas

- **Cobertura de Doble Fuente (Automóviles y Motocicletas)**: Cuando la placa tiene un código directamente indexado en el registro primario de valoración, se retorna la referencia exacta de Fasecolda (`matchSource` no se incluye). Cuando la placa no está directamente indexada —lo cual ocurre con frecuencia en motocicletas y algunos vehículos livianos—, Verifik verifica las especificaciones técnicas en un registro vehicular oficial secundario y las cruza con el catálogo de Fasecolda (`matchSource: "runt_fallback"`).
- **Fórmula de Confianza (`matchConfidence` y `matchDetails`)**: Las coincidencias por cruce entre fuentes se califican de `0.00` a `1.00` mediante la fórmula `0.55 * textScore + 0.25 * ccScore + 0.20 * yearScore`. Solo se retornan coincidencias con `matchConfidence >= 0.60`; por debajo de ese umbral se responde `404`.
- **¿Qué reduce el puntaje `matchConfidence`? (`matchDetails.penalties`)**:
  - **Tokens adicionales de versión/equipamiento en el catálogo (`textPoints` sobre `0.55`)**: Los registros de matrícula suelen almacenar únicamente la línea base (por ejemplo, `"VERSA"`, `"TRACKER"` o `"TRK 502X"`), mientras que el catálogo de Fasecolda detalla la versión, caja y frenos (`"ADVANCE AT 1600CC 2AB ABS"` o `"MT 500CC ABS"`). Estos tokens adicionales se listan en `extraGuideTokens` y explican por qué una coincidencia exacta del vehículo suele obtener entre `0.71` y `0.95`.
  - **Códigos de homologación vs. nombre comercial**: Algunos fabricantes registran códigos de homologación (como `"FZN250 A"` para `"FZ25 250"` o `"GPD150 A NMAX"` para `"NMAX"`). Los tokens que difieren se detallan en `unmatchedRuntTokens`.
  - **Redondeo nominal de cilindraje (`ccPoints` sobre `0.25`)**: Una diferencia menor al 5% (como `199cc` vs `200cc` o `124cc` vs `125cc`) obtiene el puntaje completo (`0.25/0.25`); diferencias nominales mayores del catálogo (como `373cc` real frente a la clase nominal `400cc`) descuentan `-0.07` y se explican en `penalties`.
- **Unidades de Valoración**: El arreglo `valueModel` contiene los valores comerciales por año de modelo y `bcpp` representa el precio comercial base (expresado en miles de Pesos Colombianos, COP).

## Casos de Uso Comunes

- **Valoración de Automóviles y Motocicletas**: Obtén valores comerciales confiables tanto para vehículos livianos/pesados como para motocicletas usando únicamente la placa.
- **Suscripción y Cotización de Seguros**: Automatiza la cotización de pólizas con total visibilidad sobre si el código provino del índice directo por placa o de un cruce verificado de especificaciones técnicas.
- **Avalúo de Flotas y Garantías**: Evalúa portafolios de vehículos usados y valida sus especificaciones técnicas (`cylinderCapacity`, `class`, `fuel`, `transmission`) en una sola consulta.
