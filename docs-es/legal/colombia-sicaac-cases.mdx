# Colombia — Conciliación Prejudicial e Insolvencia de Persona Natural

Verifik ofrece acceso programático al registro oficial de resolución de conflictos e insolvencia económica de Colombia. De conformidad con las Leyes 640 y 2220, la conciliación extrajudicial en derecho es un **requisito de procedibilidad obligatorio** previo a la presentación de demandas civiles, comerciales y laborales.

Este endpoint es una herramienta clave para **prevención de fraude y evaluación crediticia**, ya que detecta litigios inminentes e insolvencias **60 a 120 días antes** de que aparezcan en juzgados (Rama Judicial) o centrales de riesgo.

---

## 1. Casos de Conciliación Prejudicial

### Endpoint

```http
GET https://api.verifik.co/v2/co/sicaac/cases
```

*Ruta alterna:* `GET https://api.verifik.co/v2/co/legal/prelitigation`

### Encabezados

| Nombre        | Valor              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parámetros de Consulta

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `documentType` | string | No | Tipo de documento: `CC` (predeterminado), `CE`, `TI`, `RC`, `PAS`, `NIT`, `NIE`, `PPT`. |
| `documentNumber` | string | **Sí** | Número de documento a consultar (ej. `75086330` o `900123456`). |
| `force` | boolean | No | `true` para consultar la fuente oficial en vivo y omitir la caché. |

### Ejemplo de Respuesta

```json

    "documentType": "CC",
    "documentNumber": "75086330",
    "mechanism": "CONCILIACION",
    "hasRecords": true,

      "asConvocado": 1,
      "asConvocante": 0,

      {
        "caseType": "CONCILIACION",
```

## 2. Registro de Insolvencia de Persona Natural No Comerciante

Verifica si un ciudadano ha radicado trámites de insolvencia económica (negociación de deudas o liquidación patrimonial) bajo la Ley 1564 / Ley 2220.

### Endpoint

```http
GET https://api.verifik.co/v2/co/sicaac/insolvency
```

*Ruta alterna:* `GET https://api.verifik.co/v2/co/legal/insolvency`
