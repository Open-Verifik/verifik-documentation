# Costa Rica — Infracciones de tránsito

La consulta de **infracciones de tránsito de Costa Rica** lee boletas COSEVI de una placa. `plate` es obligatoria y debe tener de 3 a 6 caracteres. Un fallo de validación responde HTTP 409 con código `409:invalid_params`, no `MissingParameter`. Una placa sin boletas es 404 `NotFound`.

## Qué devuelve la llamada

- `plate` y `totalRecords`
- `infractions[]` con estado y montos

## Casos de uso

- Revise boletas antes de matricular un vehículo.
- Rechace una placa que no tenga de 3 a 6 caracteres.
- Lea el monto total de cada boleta.

---

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/cr/traffic-infractions
```

Un acierto incluye `plate`, `totalRecords` e `infractions` con serie, número, fecha, estado, autoridad y montos.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **Sí** | `123456` | Placa, de 3 a 6 caracteres, sin espacios. Una placa ausente o de largo incorrecto responde con código `409:invalid_params`. |

### Notas

- `plate` debe tener de 3 a 6 caracteres.
- Las placas inválidas responden con código `409:invalid_params`.
- Sin boletas para esa placa es 404 `NotFound`.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.
