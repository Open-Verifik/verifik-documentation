# Estados Unidos — Retiros de Seguridad y Fallas Vehiculares (NHTSA Recalls)

La API de **Retiros de Seguridad y Campañas de Reparación Vehicular de EE. UU.** de Verifik permite consultar el registro de alertas de seguridad emitidas por la autoridad oficial de seguridad vial en los Estados Unidos.

Permite verificar si un vehículo específico (mediante su número VIN de 17 caracteres) o una línea vehicular general (por Marca, Modelo y Año) se encuentra sujeto a llamados a revisión (*safety recalls*) abiertos por defectos de fábrica críticos en componentes como bolsas de aire (airbags), sistemas de frenos, dirección, tren motriz o sistemas de software.

---

## Casos de Uso

- **Gestión de Flotas y Rent-a-Car:** Monitoreo preventivo del parque automotor para atender campañas de seguridad antes de arrendar o movilizar vehículos.
- **Suscripción de Seguros de Autos:** Evaluación del perfil de riesgo mecánico del vehículo al tarificar pólizas de cobertura y responsabilidad civil.
- **Marketplaces y Concesionarios de Autos Usados:** Garantía de transparencia para compradores verificando que no existan retiros de seguridad críticos pendientes de reparación.

---

### Endpoint

```http
GET https://api.verifik.co/v2/usa/vehicle/recalls
```

### Headers

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parameters

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `vin` | string | **Condicional** | Número de Identificación Vehicular estandarizado de 17 caracteres (ej. `5YJSA1E26MF123456`). Si se suministra, el servicio decodifica automáticamente marca, modelo y año. Requerido si no se envían make, model y modelYear. |
| `make` | string | **Condicional** | Marca fabricante del vehículo (ej. `TESLA`, `FORD`, `TOYOTA`). Requerido si no se envía `vin`. |
| `model` | string | **Condicional** | Modelo comercial del vehículo (ej. `MODEL S`, `MUSTANG`, `CAMRY`). Requerido si no se envía `vin`. |
| `modelYear` | string | **Condicional** | Año del modelo del vehículo en formato de 4 dígitos (ej. `2021`). Requerido si no se envía `vin`. |

### Request

<Tabs>
  <TabItem value="javascript" label="Node.js (JavaScript)">

```javascript
import axios from "axios";

const options = {
  method: "GET",
  url: "https://api.verifik.co/v2/usa/vehicle/recalls",
  params: {
    vin: "5YJSA1E26MF123456",
  },
  headers: {
    Accept: "application/json",
    Authorization: "Bearer <tu_token>",
  },
};

try {
  const { data } = await axios.request(options);
  console.log(JSON.stringify(data, null, 2));
} catch (error) {
  console.error("Error al consultar retiros de seguridad del vehículo:", error.response?.data || error.message);
}
```
