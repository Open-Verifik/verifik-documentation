# Ecuador — Vehículo por placa (v3)

La consulta de **vehículo v3 de Ecuador** es `GET /v3/ec/vehiculo/placa`. `plate` es obligatoria. El cuerpo incluye campos de identificación (`vin`, `brand`, `model`, `year`, `color` y datos de placa), un objeto `revision` con fechas de inspección y un `technicalSheet` con motor, desempeño y dimensiones.

## Qué devuelve la llamada

- Identificación: `vin`, `brand`, `model`, `year`, `color`
- `revision` con inspecciones
- `technicalSheet.engine`, `performance` y `dimensions`

## Casos de uso

- Confirme un vehículo antes del seguro.
- Lea el último año de inspección.
- Guarde el VIN con la placa.

---

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v3/ec/vehiculo/placa
```

Espere `plate`, campos de identificación, `revision` y `technicalSheet`. Una placa desconocida es 404 `NotFound`.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **Sí** | `ABC1234` | Placa ecuatoriana. Obligatoria. |

### Notas

- La ruta es versión 3: `/v3/ec/vehiculo/placa`.
- `plate` es el único parámetro obligatorio.
- Una placa desconocida es 404 `NotFound`.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.

## Sandbox

| Escenario | Parámetros | Resultado |
| :--- | :--- | :--- |
| Registro en la fuente | `plate: "ABC1234"` | 200 con identificación, revision y technicalSheet. |
| Falta un valor obligatorio | Omit `plate` | 409 MissingParameter. |
| Valor desconocido | `plate: "ZZZ0000"` | 404 NotFound si la placa es desconocida. |

401 when the bearer token is missing or rejected.
