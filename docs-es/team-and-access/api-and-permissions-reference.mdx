# Referencia de API, Matriz de Permisos y MCP

Consulta esta referencia técnica para revisar cada clave de recurso, código compacto de acción, endpoint REST, respuesta de error y herramienta MCP del sistema RBAC y Sub-Equipos de Verifik.

---

## Leyenda de Códigos de Acción

Verifik evalúa cada permiso por tupla `(resource, action)` sobre **27 recursos** y **10 acciones granulares**:

| Código | Acción | Significado |
| --- | --- | --- |
| `R` | `read` | Leer tableros, registros, configuraciones o bitácoras |
| `C` | `create` | Crear registros, invitaciones, equipos, presets o ejecuciones |
| `U` | `update` | Editar registros, plantillas, roles o políticas de equipo |
| `D` | `delete` | Eliminar registros, plantillas, equipos o revocar API keys |
| `E` | `execute` | Ejecutar consultas pagadas, SmartScan, biometría o SmartBatches |
| `A` | `approve` | Aprobar o rechazar KYC, KYB, alertas o solicitudes JIT |
| `X` | `export` | Exportar CSV/XLSX, descargar PDFs y crear enlaces firmados |
| `K` | `manageKeys` | Emitir o gestionar API keys y secretos |
| `L` | `readAll` | Omitir aislamiento por equipo (`teamScopedVisibility`) en todo el workspace |
| `M` | `manageOwnTeam` | Administrar miembros, sub-equipos hijos, presupuestos y solicitudes dentro de equipos propios (`team_manager`) |

## Endpoints REST Principales

URL base: `https://api.verifik.co` (rutas `/v2/...` idénticas en `https://ai.verifik.co` con Bearer JWT).

### Staff, Roles, Sub-Equipos y Solicitudes

| Método | Ruta | Descripción |
| --- | --- | --- |
| `GET` | `/v2/staff/me/permissions` | Matriz efectiva, equipos, política CECO y permisos de solicitud |
| `GET` / `POST` | `/v2/staff` | Listar o invitar Staff (`role`, `customRole`, `team`, `additionalTeams`) |
| `PUT` / `DELETE` | `/v2/staff/:id` | Actualizar roles/equipos/overrides o eliminar miembro |
| `POST` | `/v2/staff/:id/revoke-session` | Rotar `JWTPhrase` del staff e invalidar tokens activos |
| `DELETE` | `/v2/staff/:id/grants/:grantId` | Revocar permiso temporal de inmediato |
| `GET` / `POST` | `/v2/client-roles/catalog`, `/v2/client-roles` | Consultar catálogo, crear, duplicar (`/:id/duplicate`), editar o eliminar roles |
| `GET` / `POST` / `PUT` / `DELETE` | `/v2/teams`, `/v2/teams/:id` | Gestionar Sub-Equipos, `parentTeam`, presupuestos y políticas CECO |
| `POST` | `/v2/teams/:id/boost` | Agregar incremento temporal o recurrente al presupuesto |
| `POST` | `/v2/teams/:id/api-keys` | Emitir API Key vinculada al Sub-Equipo (`{ clientId, teamId }`) |
| `POST` | `/v2/teams/:id/assign` | Asignar recursos o activar `visibility: "workspace"` |
| `POST` / `GET` | `/v2/staff-access-requests` | Crear, listar (`/mine`), aprobar (`/approve`), rechazar (`/reject`), cancelar (`/cancel`) o revocar (`/revoke`) |
| `GET` | `/v2/staff-audit-logs` | Consultar o exportar bitácora inmutable (`format=json|csv`) |
| `GET` / `POST` | `/v2/cost-centers` | Listar o crear Centros de Costo (CECO) |
| `GET` | `/v2/usage/cost-center-statement` | Estado de cuenta mensual por CECO y Sub-Equipo (`json`, `csv`, `xlsx`) |
| `POST` | `/v2/smart-reports/:id/signed-link` | Generar URL temporal firmada HMAC para PDF (máx. `86400`s) |
| `GET` | `/v2/smart-reports/:id/download` | Descargar PDF por firma temporal (`sig` + `exp`) o Bearer JWT |

## Catálogo Estructurado de Errores

| HTTP | Mensaje / Código | Causa y Solución |
| --- | --- | --- |
| `403` | `insufficient_staff_permissions` | Falta `(resource, action)`. Incluye `canRequestAccess` indicando si se permite solicitar acceso temporal (`false` en `report_builder`). |
| `403` | `owner_only` | Acción reservada para el Workspace Owner o SuperAdmin. |
| `403` | `cannot_escalate_permissions` | Intento de asignar permisos superiores al techo propio del actor. |
| `403` | `team_out_of_scope` | Lectura, escritura, invitación o aprobación fuera del sub-árbol propio (`team` + `additionalTeams` + descendientes). |
| `403` | `team_api_key_required` | `staffAccessPolicy.requireTeamApiKeys` activo y la petición usó un token global sin `teamId`. |
| `403` | `team_paused` | El Sub-Equipo está pausado (`status: "paused"`). |
| `403` | `team_budget_exceeded` | Presupuesto mensual agotado en modo `"hard"` (incluye metadata para solicitar o aplicar boost). |
| `403` | `team_feature_budget_exceeded` | Límite por endpoint específico (`featureBudgets`) alcanzado. |
| `400` | `cost_center_not_allowed_for_team` | Header `x-cost-center` fuera de `allowedCostCenters` / `defaultCostCenter` con `enforceCostCenter: true`. |

## Integración con Agentes AI vía MCP (`https://ai.verifik.co/mcp`)

Todas las operaciones de Equipos, Roles, Staff, Solicitudes JIT, Auditoría, CECOs y Enlaces Firmados están disponibles como **24 herramientas MCP autenticadas con Bearer JWT**.

<Tabs groupId="mcp-config">
<TabItem value="mcp-json" label="Configuración Claude / Cursor / Gemini" default>

```json
{
  "mcpServers": {
    "verifik": {
      "url": "https://ai.verifik.co/mcp",
      "headers": {
        "Authorization": "Bearer TU_VERIFIK_JWT"
      }
    }
  }
}
```

</TabItem>
<TabItem value="curl" label="Llamada directa JSON-RPC">

```bash
curl -X POST https://ai.verifik.co/mcp \
  -H "Authorization: Bearer $VERIFIK_JWT" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "usage_cost_center_statement",
      "arguments": { "period": "2026-11", "format": "json" }
    }
  }'
```

</TabItem>
