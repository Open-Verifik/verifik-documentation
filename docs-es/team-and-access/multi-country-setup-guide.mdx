# Guía Empresarial de Configuración Multi-País y Multi-Unidad

Esta guía describe cómo estructurar una cuenta única de Verifik para múltiples países o unidades de negocio (por ejemplo Colombia, México, Perú y Chile) garantizando aislamiento de PII, límites de gasto, enlaces temporales seguros y conciliación financiera mensual por Centro de Costos (CECO).

---

## Paso 1: Crear Centros de Costo (CECO) por País o Unidad

```bash
curl -X POST https://api.verifik.co/v2/cost-centers \
  -H "Authorization: Bearer $OWNER_JWT" \
  -H "Content-Type: application/json" \
  -d '{
    "code": "CO-OPS",
    "name": "Operaciones Colombia",
    "country": "CO"
  }'
```

---

## Paso 2: Construir la Jerarquía Regional y Nacional

Crea primero un equipo padre opcional (`LATAM Regional`) y luego cada equipo nacional apuntando a `parentTeam`, su `defaultCostCenter`, `allowedCostCenters`, `enforceCostCenter: true` y su presupuesto mensual `monthlyBudget`:

```bash
# 1. Equipo regional padre
curl -X POST https://api.verifik.co/v2/teams \
  -H "Authorization: Bearer $OWNER_JWT" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "LATAM Regional",
    "color": "indigo",
    "description": "Equipo sombrilla para operaciones de Latinoamérica"
  }'

# 2. Sub-Equipo hijo con bloqueo CECO y tope mensual estricto
curl -X POST https://api.verifik.co/v2/teams \
  -H "Authorization: Bearer $OWNER_JWT" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Colombia Ops",
    "color": "emerald",
    "parentTeam": "<LATAM_TEAM_ID>",
    "defaultCostCenter": "<CO_OPS_CECO_ID>",
    "allowedCostCenters": ["<CO_OPS_CECO_ID>"],
    "enforceCostCenter": true,
    "monthlyBudget": 1500,
    "budgetEnforcement": "hard"
  }'
```

---

## Paso 3: Activar Aislamiento Estricto y Publicar Plantillas Compartidas

Habilita `teamScopedVisibility: true` (y opcionalmente `requireTeamApiKeys: true`) en `PUT /v2/client-settings/:id`, y marca las plantillas corporativas maestras con `visibility: "workspace"` para que todos los países las ejecuten sin ver resultados ajenos:

```bash
curl -X PUT https://api.verifik.co/v2/client-settings/<CLIENT_SETTINGS_ID> \
  -H "Authorization: Bearer $OWNER_JWT" \
  -H "Content-Type: application/json" \
  -d '{
    "staffAccessPolicy": {
      "teamScopedVisibility": true,
      "requireTeamApiKeys": true
    }
  }'

curl -X POST https://api.verifik.co/v2/teams/<TEMPLATE_TEAM_ID>/assign \
  -H "Authorization: Bearer $OWNER_JWT" \
  -H "Content-Type: application/json" \
  -d '{
    "resourceType": "smartReportTemplates",
    "ids": ["<TEMPLATE_ID_1>", "<TEMPLATE_ID_2>"],
    "visibility": "workspace"
  }'
```

:::caution Antes de activar `requireTeamApiKeys` en producción
Emite y despliega las API Keys de Sub-Equipo en todos tus servicios antes de habilitar `requireTeamApiKeys: true`, ya que cualquier token legado sin `teamId` recibirá `403 team_api_key_required`.
:::

---

## Paso 4: Asignar Team Managers, Auditores Multi-País y Diseñadores

- **Líderes Regionales o de País (`team_manager`)**: Invita con `"role": "team_manager"` y su `"team"` asignado. Pueden gestionar miembros, sub-equipos hijos, presupuestos, solicitudes JIT y estados CECO únicamente dentro de su sub-árbol.
- **Auditores / Suplentes Multi-País (`additionalTeams`)**: Pasa `"additionalTeams": ["<MX_TEAM_ID>", "<PE_TEAM_ID>"]` en `POST /v2/staff` o `PUT /v2/staff/:id` sin conceder `team.readAll` global.
- **Diseñadores de Documentos (`report_builder`)**: Mantienen plantillas PDF y configuraciones sin ver resultados generados, datos personales (PII) ni API keys.

---

## Paso 5: Compartir PDFs mediante Enlaces Firmados Temporales

Genera enlaces HMAC temporales (`ttlSeconds` máximo de `86400` s / 24 horas) para compartir reportes sin exponer Bearer JWT:

```bash
curl -X POST https://api.verifik.co/v2/smart-reports/<REPORT_ID>/signed-link \
  -H "Authorization: Bearer $STAFF_OR_OWNER_JWT" \
  -H "Content-Type: application/json" \
  -d '{
    "ttlSeconds": 3600,
    "rowIndex": 0
  }'
```

---

## Paso 6: Exportar Estados de Cuenta Mensuales por CECO

Consolida el gasto de API Requests y créditos de SmartReports por **Centro de Costos + Sub-Equipo** (incluyendo top 5 endpoints más consumidos) sin costo de créditos:

<Tabs groupId="http-js">
<TabItem value="curl" label="cURL" default>

```bash
# Resumen en JSON
curl -X GET "https://api.verifik.co/v2/usage/cost-center-statement?period=2026-11&format=json" \
  -H "Authorization: Bearer $FINANCE_OR_MANAGER_JWT"

# Libro Excel con pestañas CECO Statement y Top Endpoints
curl -L -X GET "https://api.verifik.co/v2/usage/cost-center-statement?period=2026-11&format=xlsx" \
  -H "Authorization: Bearer $FINANCE_OR_MANAGER_JWT" \
  -o verifik-ceco-2026-11.xlsx
```
