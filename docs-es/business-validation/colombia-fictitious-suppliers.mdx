# Colombia — Proveedores ficticios o insolventes (DIAN)

La consulta de **proveedores ficticios o insolventes** criba el artículo 671 de la DIAN. Envíe `documentNumber` (o el alias `nit`) o `businessName` (alias `companyName` y `fullName`). Un proveedor listado pone `isFictitiousSupplier` en true e incluye la resolución. Una ausencia limpia sigue siendo HTTP 200 con `isFictitiousSupplier` en false. Esta ruta no responde 404 por una ausencia limpia.

## Qué devuelve la llamada

- `isFictitiousSupplier` — true solo si la DIAN lista al sujeto
- `resolutionNumber`, `resolutionDate` y `publicationDate` en un acierto
- `matches` — vacío si no hay lista
- `status` — etiqueta de la lista o la frase de no listado

## Casos de uso

- Bloquee un proveedor que la DIAN marcó como ficticio o insolvente.
- Registre una ausencia limpia como 200 con la bandera en false.
- Busque por NIT o por razón social.

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/co/dian/proveedores-ficticios
```

En un acierto, `isFictitiousSupplier` es true y `matches` trae número de resolución, fechas y dirección seccional. En una ausencia limpia, `isFictitiousSupplier` es false. Ambos resultados son HTTP 200.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `900123456` | NIT o número de persona, de 4 a 25 caracteres. Alias: `nit`. Obligatorio si no envía nombre. |
| `businessName` | string | **Condicional** | `INDUSTRIAS EJEMPLO SAS` | Razón o nombre comercial, de 2 a 200 caracteres. Alias: `companyName` y `fullName`. Obligatorio si no envía número. |
| `documentType` | string | No | `NIT` | Opcional. Valores: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### Notas

- Envíe un número o un nombre. Al menos uno es obligatorio.
- Quien no está en la lista es HTTP 200 con `isFictitiousSupplier` en false.
- No trate ese 200 como un 404.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.
