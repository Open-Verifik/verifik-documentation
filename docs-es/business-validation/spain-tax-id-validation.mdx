# España — Validación de Identificación Fiscal (NIF, NIE, CIF)

La API de **Validación de Identificación Fiscal de España** de Verifik ejecuta una verificación integral de números de identificación tributaria españoles, cubriendo:

- **DNI / NIF de Personas Físicas:** 8 dígitos numéricos más letra de control calculada mediante algoritmo Módulo 23 (`TRWAGMYFPDXBNJZSQVHLCKE`).
- **NIE de Residentes Extranjeros:** Prefijo de letra (`X`, `Y`, `Z`), 7 dígitos numéricos y letra de control Módulo 23.
- **CIF de Personas Jurídicas:** Letra de tipo de entidad (`A`–`W`), código provincial de 2 dígitos, 5 dígitos correlativos y dígito o letra de control algorítmico.

Adicionalmente, para personas jurídicas con CIF válido, el servicio realiza una comprobación enriquecida no bloqueante contra la autoridad tributaria oficial y el censo europeo VIES para corroborar el alta fiscal y razón social oficial.

---

## Casos de Uso

- **Prevención de Errores de Facturación:** Validación sintáctica y algorítmica inmediata en formularios de registro antes de enviar facturas con NIF/CIF erróneo.
- **Clasificación Automática de Entidades:** Identificación del tipo societario (Sociedad Anónima, Sociedad Limitada, Cooperativa, etc.) y provincia de origen a partir del CIF.
- **Onboarding Digital en España:** Verificación de autenticidad en tiempo real sin fricción para autónomos y empresas españolas.

---

### Endpoint

```http
GET https://api.verifik.co/v2/es/tax-id/validate
```

### Headers

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parameters

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | Sí | Número de identificación fiscal español a validar (ej. `A28015865`, `12345678Z`, `X1234567L`). |
| `documentType` | string | No | Tipo de documento opcional (`NIF`, `NIE`, `CIF`). Si se omite, el sistema infiere automáticamente la categoría. |
