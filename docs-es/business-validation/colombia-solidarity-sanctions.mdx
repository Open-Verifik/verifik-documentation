# Colombia — Sanciones del sector solidario

La consulta de **sanciones solidarias** lee el boletín de sancionados de Supersolidaria. Envíe un número o un nombre. `isSanctioned` es true solo si hay una sanción. Una ausencia limpia es HTTP 200 con `isSanctioned` en false, `sanctionsCount` 0 y estado `SIN SANCIONES REGISTRADAS`. Esta ruta no responde 404 por esa ausencia.

## Qué devuelve la llamada

- `isSanctioned` y `sanctionsCount`
- `status`
- `matches`

## Casos de uso

- Criba una cooperativa antes de financiarla.
- Registre un cheque limpio como 200.
- Busque por NIT o por el nombre sancionado.

---

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersolidaria/sanciones
```

Un acierto incluye `sanctionsCount` y `matches`. Una ausencia limpia es HTTP 200 con `isSanctioned` en false.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `900123456` | NIT o número. Alias `nit`. |
| `businessName` | string | **Condicional** | `EJEMPLO SAS` | Nombre. Alias `companyName` y `fullName`. |
| `documentType` | string | No | `NIT` | Opcional: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### Notas

- Una ausencia limpia es HTTP 200 con `isSanctioned` en false.
- Envíe al menos un valor de búsqueda.
- No mapee ese 200 a 404.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.
