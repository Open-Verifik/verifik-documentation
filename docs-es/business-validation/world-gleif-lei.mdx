# Global — Identificador de Entidad Jurídica (GLEIF LEI)

La API de **Identificador de Entidad Jurídica Global (LEI)** de Verifik permite consultar el directorio maestro internacional de entidades legales estandarizado bajo la norma **ISO 17442**, gestionado a través del registro mercantil oficial y la Fundación Global del Identificador de Entidad Jurídica (GLEIF).

El código LEI de 20 caracteres es el estándar dorado en los mercados financieros globales y la regulación bancaria para identificar de manera inequívoca a contrapartes corporativas, fondos de inversión, subsidiarias y entidades matrices controladoras a nivel mundial.

---

## Casos de Uso

- **Cumplimiento Regulatorio Financiero (MiFID II, EMIR, Dodd-Frank):** Validación del código LEI obligatorio en transacciones bursátiles y financieras internacionales.
- **Mapeo de Estructuras Corporativas y UBO:** Identificación de las relaciones de propiedad entre entidades matrices directas y últimas (*Ultimate Parent*).
- **Homologación de Proveedores Multinacionales:** Resolución de contrapartes internacionales con una clave unificada que trasciende los formatos locales de registro.

---

### Endpoint

```http
GET https://api.verifik.co/v2/world/lei
```

### Headers

| Nombre | Valor | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `Accept` | `application/json` | Sí | Formato de respuesta JSON |
| `Authorization` | `Bearer <token>` | Sí | Token JWT de autenticación en Verifik |

### Parameters

| Parámetro | Tipo | Requerido | Descripción |
| :--- | :--- | :--- | :--- |
| `lei` | string | **Condicional** | Código alfanumérico LEI de 20 caracteres según norma ISO 17442 (ej. `5493006MHB84DD0ZWV18`). Requerido si no se envía `companyName` ni `registrationNumber`. |
| `companyName` | string | **Condicional** | Razón social o denominación legal de la entidad internacional (ej. `ALPHABET INC.`). |
| `registrationNumber` | string | **Condicional** | Número de registro mercantil oficial local de la entidad en su país de origen. |
| `countryCode` | string | No | Código de país ISO de 2 letras (ej. `US`, `GB`, `DE`) para filtrar y acotar búsquedas por nombre. |
