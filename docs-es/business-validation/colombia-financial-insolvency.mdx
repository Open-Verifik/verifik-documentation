# Colombia — Concordatos y liquidaciones financieras

La consulta de **insolvencia financiera** lee concordatos y liquidaciones de la Superintendencia Financiera. Envíe un NIT o un nombre. `inConcordatoOrLiquidation` es true solo si hay un proceso. Una sociedad sin proceso sigue siendo HTTP 200, con la bandera en false. Esta ruta no usa 404 para esa ausencia limpia.

## Qué devuelve la llamada

- `inConcordatoOrLiquidation`
- `status` y `entityType`
- `matches` vacío en una ausencia limpia

## Casos de uso

- Detenga el alta de una entidad financiera ya en liquidación.
- Guarde un cribado limpio como 200.
- Busque por NIT o razón social.

---

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/co/superfinanciera/concordatos
```

Un acierto incluye `status`, `entityType` e `inConcordatoOrLiquidation` en true. Una ausencia limpia mantiene HTTP 200 y la bandera en false.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `900123456` | NIT o número. Alias `nit`. Obligatorio sin nombre. |
| `businessName` | string | **Condicional** | `EJEMPLO SAS` | Nombre. Alias `companyName` y `fullName`. Obligatorio sin número. |
| `documentType` | string | No | `NIT` | Opcional: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### Notas

- Una ausencia limpia es HTTP 200 con `inConcordatoOrLiquidation` en false.
- Envíe un número o un nombre.
- No mapee ese 200 a 404.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.
