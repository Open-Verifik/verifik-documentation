# Colombia — Sistema integrado de información societaria (SIIS)

La consulta **SIIS** lee los reportes societarios supervisados por Supersociedades. Envíe un NIT o una razón social. `found` es true si hay un reporte y false si la sociedad simplemente no está en el SIIS. Esa ausencia limpia es HTTP 200, con estado `NO REGISTRADA EN SIIS SUPERSOCIEDADES`. Use `inLiquidationOrReorganization` para ver una alerta concursal.

## Qué devuelve la llamada

- `found` e `inLiquidationOrReorganization`
- `ciiu`, sector y ciudad
- `financialSummary` si hay reporte
- `filings` — vacío en una ausencia limpia

## Casos de uso

- Traiga el último reporte SIIS antes de extender crédito.
- Marque una sociedad ya en reorganización.
- Registre un no-está-en-SIIS como 200, no como página ausente.

---

## Referencia de la API

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersociedades/siis
```

Un reporte incluye `status`, `ciiu`, dirección, `financialSummary` y `filings`. `found` false significa que la sociedad no está en el SIIS. Ambos son HTTP 200.

### Headers

| Nombre | Valor | Descripción |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato de la solicitud |
| Accept | `application/json` | Formato de la respuesta |
| Authorization | `Bearer <tu_token>` | JWT del cliente |

### Parameters

| Nombre | Tipo | Requerido | Ejemplo | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `900123456` | NIT o número de persona. Alias `nit`. Obligatorio si no envía nombre. |
| `businessName` | string | **Condicional** | `INDUSTRIAS EJEMPLO SAS` | Nombre, de 2 a 200 caracteres. Alias `companyName` y `fullName`. Obligatorio si no envía número. |
| `documentType` | string | No | `NIT` | Opcional: `NIT`, `CC`, `CE`, `PAS` o `TI`. |

### Notas

- Envíe un NIT o un nombre.
- `found` false es una ausencia limpia exitosa.
- No mapee ese cuerpo a HTTP 404.
- Envíe un JWT Bearer en el encabezado `Authorization`.
- El JSON de ejemplo ilustra los campos. Una llamada real devuelve el registro de los valores que envíe.
- No envíe un indicador de omisión de caché. Esta página documenta solo los parámetros de cliente.
