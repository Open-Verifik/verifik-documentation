API, Permissions Matrix & MCP Reference

Use this reference to inspect every resource key, compact action code, REST API endpoint, structured error response, and MCP tool powering Verifik Staff RBAC and Sub-Teams.

Action Codes Legend​

Verifik evaluates permissions per (resource, action) tuple across 27 resources and 10 granular actions:

CodeAction KeyMeaning
RreadView dashboards, records, configurations, or logs
CcreateCreate new records, invitations, teams, presets, or runs
UupdateEdit existing records, templates, roles, or team policies
DdeleteDelete records, templates, teams, or revoke API keys
EexecuteTrigger live paid lookups, SmartScan, biometrics, or SmartBatch runs
AapproveApprove/reject KYC dossiers, KYB companies, alerts, or JIT access requests
XexportExport CSV/XLSX reports, generate/send/download PDFs, mint signed links
KmanageKeysMint/manage API keys, webhooks secrets, or workspace keys
LreadAllBypass Sub-Team read isolation (teamScopedVisibility) across the workspace
MmanageOwnTeamManage members, child sub-teams, budgets, and JIT requests inside owned/child teams (team_manager)

Structured Error Reference​

HTTPError message / ReasonWhen It Occurs & How to Resolve
403insufficient_staff_permissionsCaller lacks (resource, action). Includes canRequestAccess boolean so UI/agents know whether POST /v2/staff-access-requests is allowed (false for report_builder).
403owner_onlyOperation requires Workspace Owner or SuperAdmin (for example deleting ClientSettings).
403cannot_escalate_permissionsStaff actor attempted to create/assign permissions above their own effective ceiling.
403team_out_of_scopeCross-team read, write, staff invite, or request approval outside the caller's team + additionalTeams + parentTeam subtree.
403team_api_key_requiredWorkspace has staffAccessPolicy.requireTeamApiKeys: true and caller used a plain client token instead of a Sub-Team API key.
403team_pausedTarget Sub-Team status is "paused". Resume the Sub-Team to re-enable executions.
403team_budget_exceededTeam monthly credit cap reached under "hard" enforcement. Payload includes boost metadata for requesting or applying POST /v2/teams/:id/boost.
403team_feature_budget_exceededPer-endpoint prefix cap (featureBudgets) reached for the target team.
400cost_center_not_allowed_for_teamRequested x-cost-center header is outside the Sub-Team's allowedCostCenters / defaultCostCenter when enforceCostCenter: true.

AI Agent & MCP Integration​

All Team, Role, Staff, Access Request, Audit Log, Cost Center, CECO Statement, and Signed Link operations are published as Bearer-authenticated MCP tools on https://ai.verifik.co/mcp so agents such as Claude, Cursor, Gemini, and Grok can automate multi-country provisioning safely.

Bearer JWT required on MCP

TeamRBAC MCP tools require your own Verifik Bearer JWT (VERIFIK_JWT) and are never exposed unauthenticated or over anonymous x402 billing routes.

  • Claude / Cursor / Gemini MCP Config
  • Direct JSON-RPC call
{
  "mcpServers": {
    "verifik": {
      "url": "https://ai.verifik.co/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_VERIFIK_JWT"
      }
    }
  }
}
curl -X POST https://ai.verifik.co/mcp \
  -H "Authorization: Bearer $VERIFIK_JWT" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "usage_cost_center_statement",
      "arguments": { "period": "2026-11", "format": "json" }
    }
  }'
