Check List

Você opera em um ou mais países e fica escolhendo de novo os mesmos serviços do SmartCheck. Salve essa combinação como uma Check List. Teste um serviço da lista ou envie-a para o SmartBatch.

Abra Check List no Smart-Agent em ai.verifik.co/check-list. Salvar a lista é grátis. Executar uma consulta gasta créditos como qualquer outra chamada de API.

Salvar a lista é grátis. Executar uma consulta gasta créditos como qualquer outra chamada de API.

O que você pode fazer​

Escolher países

Indique onde você opera ao criar a lista. O catálogo mostra os serviços desses países.

Pessoas, veículos, empresas

Adicione identidade, placas, registros empresariais e mais. Filtre o catálogo por domínio.

Testar uma consulta

Abra um serviço, preencha os campos e execute. Os créditos entram nessa chamada, não ao salvar a lista.

Criar um SmartBatch

Passe os serviços salvos ao SmartBatch para um arquivo ou uma fila. Se a lista tiver vários países, escolha um primeiro.

No Smart-Agent​

Entre com a sua conta de cliente Verifik. A Check List guarda as listas nessa conta — não num projeto SmartEnroll.

1. As suas listas​

O painel mostra quantas listas você tem, quantos países cobrem e quantos serviços salvou. Abra um cartão para editar ou crie uma nova.

Se ainda não tiver listas, comece por um país.

tip

Depois de criar, você volta a este painel. Abra o cartão novo para adicionar serviços.

2. Criar uma checklist​

Escolha um ou mais países e dê um nome (por exemplo KYC Colombia ou Fleet Chile).

Os países ficam definidos na criação. Você não os altera depois no espaço de trabalho.

3. Adicionar serviços​

Abra a lista. Os serviços salvos ficam no topo. Abaixo, pesquise o catálogo e filtre por Pessoas, Veículos ou Empresas. As consultas internacionais de antecedentes ficam no fim.

Use Selecionar para adicionar. Use Abrir para testar. Rascunho e Ativa são rótulos de organização — as duas funcionam igual.

4. Testar uma consulta​

Abra um serviço. A gaveta tem Sobre, Pedido e Resultado. Preencha os campos e clique em Executar.

O resultado é a mesma resposta da API de catálogo. O saldo de créditos atualiza depois da chamada.

5. Enviar um SmartBatch​

Quando quiser um arquivo ou uma fila com os mesmos serviços, clique em Criar SmartBatch. O SmartBatch usa um país. Se a lista tiver mais de um, escolha com qual começar.

O SmartBatch abre com esse país, o nome da lista e os serviços selecionados. Continue no assistente SmartBatch.

O que a Check List não é​

Evite pensarRealidade
Um motor de lotesA Check List guarda a combinação. O SmartBatch corre o arquivo ou a fila.
KYC hospedadoSmartEnroll é outro produto de enrollment.
Um cadastro novo a cada testeExecutar chama a API de catálogo desse serviço.
