Smart Report を実行する

1 回のリクエストで完全な検証およびレポートパイプラインを実行します。POST /v2/smart-reports/run は、Reports 向けの主要な ヘッドレス・オールインワン実行エンドポイント です。プリセット（systemKey）または既存の BatchConfiguration（batchConfigurationId）を解決し、設定の入力スキーマに対して入力値を検証し、アカウントの機能利用権限を確認し、FeatureRunner で各検証ステップを実行し、SmartBatch（headlessRun: true）と SmartReport の両方を作成し、任意で verificationScore を算出して PDF/HTML 出力をレンダリングし、任意でメール送信と Webhook 配信を行います。

小規模な実行（最大 5 行）では、実行モードのデフォルトが同期（mode: "sync"）となり、90 秒の同期ウィンドウ内に確定すれば 200 OK を返します。大規模なバッチや 90 秒の同期期限を超過した実行は、自動的に非同期実行へ切り替わり、ポーリング用およびダウンロード用の URL とともに 202 Accepted を返します。

エンドポイント​

POST https://api.verifik.co/v2/smart-reports/run

このエンドポイントは、お客様自身のクライアント別 Authorization: Bearer <VERIFIK_JWT> ヘッダーで認証する場合、Smart-Agent プロキシ経由の https://ai.verifik.co/v2/smart-reports/run でも利用できます。共有 x402 による実行は 403 Forbidden でブロックされます。

ヘッダー​

名前値説明
Content-Typeapplication/jsonリクエストペイロードの形式。
AuthorizationBearer <VERIFIK_JWT>クライアント単位の JWT（authUser.clientId）。

クライアント単位の JWT（authUser.clientId）が必要です。clientId が欠落しているトークンは 409 Conflict（client_context_required）を返します。JWT が欠落または無効な場合は 401 Unauthorized を返します。

ボディ​

名前型必須説明
systemKeystring条件付きプリセット識別子。前後空白トリム済み、最大 120 文字、パターン /^[a-z0-9][a-z0-9._-]{1,118}$/i。systemKey または batchConfigurationId の少なくとも一方が必須です。
batchConfigurationIdstring条件付き既存の BatchConfiguration ObjectId。systemKey または batchConfigurationId の少なくとも一方が必須です。
templateIdstringいいえレポートテンプレートの ObjectId。設定またはプリセット上の優先テンプレートを上書きします。
namestringいいえ生成されるレポートおよびバッチのカスタム表示名。最大 150 文字。
inputsobject or object[]条件付き単一の入力オブジェクトまたは入力オブジェクトの配列（最小 1、最大 500）。inputs または rows の少なくとも一方が必須です。両方送信された場合は inputs が優先されます。
rowsobject[]条件付きフラットなオブジェクト（{ ... }）または構造化された行オブジェクト（{ rowIndex, inputData }）として指定する 1〜500 件の行配列。inputs または rows の少なくとも一方が必須です。
modestringいいえ"sync" または "async"。行数が <= 5 の場合は "sync"、> 5 の場合は "async" がデフォルトです。> 5 行に対して mode: "sync" を渡すと 409 Conflict（sync_row_limit_exceeded）を返します。
generatePdfbooleanいいえ実行中に PDF をレンダリングするかどうか。デフォルトは true。注: emailTo が指定されている場合、generatePdf が false でも PDF がレンダリングされます。
includePdfBase64booleanいいえdata.pdf.buffer に base64 エンコードされた PDF を含めるかどうか。デフォルトは false。
pdfEnginestringいいえPDF レンダリングエンジン: "puppeteer" または "pdfkit"。テンプレート設定または "puppeteer" がデフォルトです。
scorebooleanいいえverificationScore を計算して付与するかどうか。
scoreProfilestringいいえscore が有効な場合に使用するスコアリングプロファイル識別子。最大 64 文字。
rowIndexintegerいいえPDF/HTML/スコアリング出力に使用する 0 始まりの行インデックス（>= 0）。デフォルトは 0。
emailTostring[]いいえレポートを配信する有効な受信者メールアドレスの配列（最大 20 件）。
emailSubjectstringいいえカスタムメール件名。最大 250 文字。
emailLanguagestringいいえメールテンプレートの言語: "en" または "es"。デフォルトは "es"。
webhookUrlstringいいえレポート単位の http または https Webhook 上書き URL。最大 2048 文字。
externalRefIdstringいいえ呼び出し元が指定する相関 ID（最大 200 文字）。レポートおよび Webhook ペイロードに出力されます。
createdByChannelstringいいえ発生元チャネル: "portal"、"api"、"mcp"、"x402"、または "webhook"。デフォルトは "api"。

実行時の動作とパラメータルール​

  • ターゲット解決（systemKey と batchConfigurationId）: プリセットの systemKey または既存の batchConfigurationId のいずれかを指定します。不明な ID やプリセットは 404 Not Found（batch_configuration_not_found、preset_not_found、または template_not_found）を返します。ステップが設定されていない設定やプリセットは 409 Conflict（preset_has_no_steps または batch_configuration_has_no_steps）を返します。
  • アカウントの機能権限: 解決されたプリセットまたはバッチ設定内のすべてのステップは、実行前にクライアントアカウントの有効な機能権限に対してチェックされます。権限のないステップがあると 409 Conflict（endpoints_not_in_account）で失敗します。
  • 同期期限と自動フォールバック: 同期実行は最大 90000 ms（SYNC_DEADLINE_MS = 90s）待機します。90 秒以内に検証またはレンダリングが完了しない場合、API は自動的に mode: "async" および pollUrl を含む 202 Accepted を返すため、統合システム側で Smart Report を取得する をポーリングするか Webhook を待機できます。
  • メール指定時の PDF 生成: emailTo を指定すると、明示的に generatePdf: false を設定した場合でも配信用の PDF 生成が保証されます。

Webhook と MCP 統合​

  • Webhook: webhookUrl が指定されている（またはプリセット/BatchConfiguration に設定されている）場合、Verifik はレポート生成時に smart_batch_report_generated または smart_batch_report_generation_failed を発行し、emailTo 配信の実行時に smart_batch_report_sent または smart_batch_report_delivery_failed を発行します。externalRefId はレポートドキュメントと Webhook イベントの両方に出力されます。詳細は SmartReports Webhook を参照してください。
  • MCP 相当ツール: MCP 経由で接続された AI エージェントは、同じヘッドレスパラメータで smart_report_run ツールを呼び出せます。詳細は MCP と AI エージェント を参照してください。

注記​

  • data.pdf は generatePdf が true の場合（または emailTo により PDF レンダリングがトリガーされた場合）のみ含まれ、data.pdf.buffer は includePdfBase64 が true の場合のみ含まれます。
  • data.email は emailTo が指定された場合のみ含まれます。配信に失敗した場合、data.email.error に失敗理由が格納されます。
  • data.verificationScore は score が有効な場合に出力されます。
