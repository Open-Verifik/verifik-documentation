观察名单 — ransomwhe.re 勒索软件地址

用地址对照 ransomwhe.re 的勒索软件地址名单。把地址放在 fullName。

调用返回的内容​

  • foundInCryptoRansomwhere
  • 命中时的 details
  • fullName

使用场景​

  • 付款或准入前筛查。
  • 把 false 标志当作干净的 200。
  • 发送名称，或证件类型加号码。

API 参考​

Endpoint​

GET https://api.verifik.co/v2/crypto/ransomwhere

命中时 foundInCryptoRansomwhere 为 true 并填写 details。不在名单上是 HTTP 200，foundInCryptoRansomwhere 为 false，details 为空。

Headers​

名称值说明
Content-Typeapplication/json请求格式
Acceptapplication/json响应格式
AuthorizationBearer <token>客户端 JWT

Parameters​

名称类型必填示例说明
fullNamestring条件必填SAMPLE NAME名称。钱包名单则放地址。只发它即可。
documentTypestring条件必填CPF省略 fullName 时必须与 documentNumber 一起发送。无姓名的 CPF 还需要 dateOfBirth。
documentNumberstring条件必填12345678901省略 fullName 时与 documentType 一起发送的至少 5 个字符的标识。
dateOfBirthstring条件必填1990-01-15省略 fullName 且为 CPF、CI、CCPA、DUI 或 CCUY 时必填。

Request​

  • Node.js / JavaScript
  • Python
  • cURL
import axios from "axios";

const options = {
  method: "GET",
  url: "https://api.verifik.co/v2/crypto/ransomwhere",
  params: {
    fullName: "bc1qexampleaddress000000000000000000000",
  },
  headers: {
    Accept: "application/json",
    Authorization: "Bearer <your_token>",
  },
};

try {
  const { data } = await axios.request(options);
  console.log(data);
} catch (error) {
  console.error(error.response ? error.response.data : error.message);
}
import requests

url = "https://api.verifik.co/v2/crypto/ransomwhere"
headers = {

print(response.json())

  -H "Accept: application/json" \
  -H "Authorization: Bearer <your_token>"

  • 200（找到记录）
  • 409（缺少参数）
  • 200（未命中）
  • 401（未授权）
  • 500（数据源不可用）

说明​

  • 发送 fullName，或同时发送 documentType 与 documentNumber。
  • 未列入是 HTTP 200，且 foundInCryptoRansomwhere 为 false。
  • 无姓名的 CPF 还需要 dateOfBirth。
  • 在 Authorization 头中发送 Bearer JWT。
  • JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
  • 不要发送绕过缓存的标志。本页只记录客户端参数。
