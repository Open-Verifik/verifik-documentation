Vehicle Values by Plate

Verifik's Fasecolda Vehicle Values by Plate API retrieves official commercial valuations and technical specifications for vehicles registered in Colombia using a license plate. To maximize success rates across cars, SUVs, pickups, heavy vehicles, and motorcycles, this endpoint connects two complementary official vehicle sources:

  1. Primary Resolution (Direct Plate-to-Code Index): Resolves the license plate directly against the primary valuation index when an exact catalog code is linked to the plate.
  2. Secondary Resolution (Cross-Source Specification Matching): When a plate has no direct valuation code (common for motorcycles and newly registered vehicles), Verifik retrieves the vehicle's verified technical specifications (brand, line, cylinderCapacity, year, and vehicleClass) from a secondary official vehicle registry and matches them against the Fasecolda valuation catalog (matchSource: "runt_fallback"), returning a detailed confidence breakdown (matchConfidence, matchNote, matchDetails, and runtVehicle).

Endpoint​

GET https://api.verifik.co/v2/co/fasecolda/values-by-plate

The Fasecolda Vehicle Value Inquiry service provides comprehensive information about vehicles registered in Colombia, including code, marke (brand), line1, line2, line3, class, year, bcpp, valueModel, cylinderCapacity, fuel, and matchDetails when resolved via cross-source specification matching. Pass the license plate as a query parameter.

Notes​

  • Dual-Source Coverage (Cars & Motorcycles): When a license plate is directly indexed in the primary valuation registry, the response returns the exact Fasecolda record (matchSource is omitted). When the plate is not directly indexed, Verifik verifies the vehicle's technical specifications from an official secondary vehicle registry and matches them against the Fasecolda valuation catalog (matchSource: "runt_fallback").
  • Confidence Formula (matchConfidence & matchDetails): Cross-source matches are scored on a 0.00 to 1.00 scale using 0.55 * textScore + 0.25 * ccScore + 0.20 * yearScore (minimum threshold 0.60).
  • What Lowers matchConfidence (matchDetails.penalties): Extra trim/transmission tokens in the Fasecolda catalog (extraGuideTokens), manufacturer homologation prefix differences (unmatchedRuntTokens), or nominal cylinder capacity rounding (ccPoints) are itemized in matchDetails.penalties.
  • Valuation Units: valueModel contains historical values by model year, and bcpp represents the base commercial price in Colombian Pesos (COP).
