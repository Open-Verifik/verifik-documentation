SmartReports

SmartReports는 다단계 Verifik 카탈로그 검증(SmartCheck + SmartBatch)을 자동화된 검증 점수(Verification Scores), 이메일 전송, 실시간 웹훅이 포함된 구조화된 HTML 및 PDF 리포트로 변환합니다. Smart-Agent 포털에서 리포트를 설계 및 검토하거나, 헤드리스 REST API를 통해 백엔드에서 종단 간 실행을 트리거하거나, **Model Context Protocol (MCP)**을 통해 자율 에이전트를 연결할 수 있습니다.

테넌트 격리 및 클라이언트별 인증

모든 SmartReports, 템플릿, 구성, 프리셋 및 배치 엔드포인트는 클라이언트별 Verifik Bearer JWT(Authorization: Bearer <VERIFIK_JWT>)가 필요합니다. 공유 x402 서비스 계정을 통한 실행은 엄격히 차단되며(403 Forbidden), 실행된 카탈로그 단계마다 Verifik 계정 잔액에서 크레딧이 직접 차감됩니다.

아키텍처 및 구성 요소​

SmartReports는 실행할 검증 항목, 결과 표시 방식, 각 실행의 전달 방식을 분리하여 관리합니다.

각 요소의 연결 방식​

  1. 프리셋 탐색 또는 복제: GET /v2/smart-batch-presets 및 POST /v2/smart-batch-presets/{systemKey}/clone을 호출하거나, 계정에 활성화된 카탈로그 엔드포인트로 사용자 지정 BatchConfiguration을 생성합니다.
  2. 필수 입력 확인: GET /v2/batch-configurations/{id}/input-schema(또는 프리셋의 inputSchema 객체)를 통해 requiredFields, optionalFields, jsonSchema, exampleInput 및 estimatedCreditsPerRow를 조회합니다.
  3. 템플릿 사용자 지정: /v2/smart-report-templates에서 내장 테마, AI 레이아웃 생성(POST /v2/smart-report-templates/generate-layout), 데이터 팔레트 분석(POST /v2/smart-report-templates/introspect), 크레딧 차감 없는 실시간 HTML 미리보기(POST /v2/smart-report-templates/preview-html)를 활용하여 템플릿을 구성합니다.
  4. 실행 및 전달: POST /v2/smart-reports/run(systemKey 또는 batchConfigurationId 지정)으로 단일 헤드리스 호출을 실행하거나, 대용량 처리 시 /v2/smart-batches 및 /v2/smart-batches/from-file을 사용한 후 /v2/smart-reports/{id}/generate, /download, /html, /send-email을 호출합니다.

인증 및 과금 모델​

클라이언트별 Bearer JWT 강제 적용​

모든 SmartReports, 템플릿, 배치 구성, 프리셋 및 SmartBatch 엔드포인트는 테넌트 단위로 격리되며 호출자가 제공하는 Verifik Bearer JWT가 필요합니다.

Authorization: Bearer <VERIFIK_JWT>
  • Smart-Agent 프록시 가드(smartReportAuthGuard): 유효한 클라이언트별 Bearer JWT 없이 /v2/smart-reports*, /v2/smart-report-templates*, /v2/batch-configurations*, /v2/smart-batches*, /v2/smart-batch-presets*(또는 /api/... / /api/proxy 대응 경로)로 요청을 보내면 x402 결제 처리 전에 **HTTP 403 Forbidden**으로 거부됩니다.
{
  "code": "Forbidden",
  "message": "SmartReports, SmartReportTemplates, BatchConfigurations, and SmartBatches require your own per-client Verifik Bearer JWT. They are not available through the shared x402 account."
}
  • MCP 테넌트 격리: 검색 메서드(initialize, ping, notifications/initialized, tools/list)는 자격 증명 없이 동작하지만, tools/call은 클라이언트별 Authorization: Bearer <VERIFIK_JWT> 헤더를 반드시 요구하며 헤더가 누락되었거나 공유 서비스 토큰이 전달되면 HTTP 401(JSON-RPC -32001)을 반환합니다.
  • SmartReports 라우트에서 x-payment-info 미사용: https://ai.verifik.co/openapi.json에서 SmartReports 라우트는 호출당 결제 x402 헤더 대신 bearerAuth 보안을 사용합니다.

크레딧 기반 종량제 과금​

  • 카탈로그 단계별 과금: 검증 단계가 카탈로그 소스를 대상으로 실제 실행될 때 Verifik 클라이언트 계정 잔액에서 크레딧이 차감됩니다(배치의 creditsSpent 필드로 추적됨).
  • 사전 비용 예측: GET /v2/smart-batch-presets 및 GET /v2/batch-configurations/{id}/input-schema는 조회를 실행하기 전에 estimatedCreditsPerRow를 반환합니다.
  • 크레딧 차감 없는 설계 및 조회 작업: 프리셋·템플릿 목록 조회, 스키마 검사, /introspect, /preview-html, /theme-starters, /score-profiles, /simulated-responses 호출, /v2/smart-reports/{id}/html 조회, PDF 다운로드 및 리포트 이메일 전송에는 검증 크레딧이 차감되지 않습니다.
  • 계정 권한 확인: 배치 또는 POST /v2/smart-reports/run을 실행하기 전, Verifik은 활성화된 모든 단계 엔드포인트가 클라이언트 계정에 활성화되어 있는지 확인합니다(사용 불가능한 단계가 있으면 409 Conflict 및 endpoints_not_in_account 반환).

검증 점수 프로필(scoreProfile)​

점수 산출이 활성화되면(score: true이거나 테마 적용 템플릿에 의해 자동 활성화됨), SmartReports는 실행된 각 검증 단계를 0–1 점수로 정규화하고(소수점 넷째 자리 score 및 0–100 범위의 score100), 부적격 규칙(knockout rules) 및 커버리지(approve 판정 시 최소 90%)를 평가하여 최종 판정을 생성합니다.

  • approve — 가중 점수 0.90–1.00, 커버리지 >= 90%, 모든 필수 검사 응답 완료
  • review — 가중 점수 0.70–0.89(또는 부적격 항목이 아닌 검토 필요 결과 포함)
  • reject — 가중 점수 < 0.70이거나 설정된 부적격 규칙(knockout rule) 발동
  • pending — 필수 검사에서 응답하지 못함(예: 업스트림 타임아웃/5xx) 또는 커버리지 < 90%

10가지 기본 제공 점수 프로필이 지원됩니다(실시간 ID 및 라벨은 GET /v2/smart-report-templates/score-profiles로 조회 가능).

PDF 렌더링 엔진: puppeteer vs pdfkit​

엔진동작 방식지원 기능
puppeteer (기본값)풀링된 헤드리스 Chromium 인스턴스를 통해 전체 HTML/CSS를 렌더링합니다.4가지 리포트 테마 전체, SVG 점수 게이지 및 차트(pie/bar), 동적 dataTable 및 keyValueGrid 레이아웃, 사용자 지정 글꼴, 이미지/텍스트 워터마크, 서명 오버레이, PDF 비밀번호 암호화.
pdfkit하위 호환성을 위해 템플릿 및 API 요청에서 허용되며, HTML/Puppeteer 호환성 심(pdf-pdfkit.service.js)을 통해 라우팅됩니다.pdfEngine: "pdfkit"으로 구성된 기존 템플릿도 기능 저하된 자리 표시자 없이 전체 테이블 렌더링, 워터마크 및 서명 기능을 자동으로 활용할 수 있습니다.
