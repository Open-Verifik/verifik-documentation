# Vehicle Validation

:::info SmartCheck Integration
Validate vehicles, inspect fleet status, and audit driver credentials instantly using **SmartCheck** at [ai.verifik.co](https://ai.verifik.co) or automate high-volume fleet checks through [SmartBatch](/smart-batch).
:::

Verifik's **Vehicle Validation** APIs deliver real-time motor vehicle records, legal status verification, and technical specifications directly from official transit registries and databases across Latin America, North America, and Europe.

Whether you are onboarding drivers for a ride-sharing fleet, underwriting auto insurance policies, evaluating collateral for auto financing, or vetting pre-owned vehicles on a marketplace, our automated APIs provide verified vehicle data in seconds.

---

## Verification Scope

Our vehicle verification services cover five essential categories:

### 1. Technical & Mechanical Specifications
Retrieve authoritative manufacturer specifications directly from official registries:
- **Vehicle Identification**: Make, model, model year, vehicle type, body style, and color.
- **Serial Identifiers**: Vehicle Identification Number (VIN), engine number, and chassis serial.
- **Powertrain Details**: Engine displacement (cc), fuel type (gasoline, diesel, hybrid, electric), and transmission.
- **Capacity**: Seating capacity, cargo capacity, and gross vehicle weight rating (GVWR).

### 2. Legal Standing & Title Encumbrances
Verify legal ownership and ensure the vehicle is free of judicial and financial encumbrances:
- Current registration status (active, cancelled, suspended, or scrapped).
- Theft reports, recovery notices, and active police alerts.
- Financial liens, chattel mortgages, and judicial embargoes.
- Transfer restrictions or administrative ownership limitations.

### 3. Compulsory Insurance & Technical Inspections
Confirm compliance with statutory roadworthiness standards:
- **Mandatory Traffic Accident Insurance**: Policy number, issuing underwriter, start date, and expiration timestamp.
- **Technical-Mechanical Inspection**: Certifying inspection center, emission certification status, and validity expiration date.

### 4. Traffic Violations & Infractions
Screen driver and vehicle infraction history:
- Outstanding traffic tickets, penalty amounts, and violation codes.
- Photofine notices and municipal citation records.
- Payment agreements and clearance certificates.
- Driver's license validity, category endorsements, and accrued penalty points.

### 5. Market Valuation & Historical Records
Access commercial valuation data and insurance claim history:
- Official guide values and standardized market depreciation tables.
- Historical accident claims and total loss declarations.
- Historical ownership transfers and licensing history.

## API Integration

Query vehicle data using the vehicle's license plate number (`plate`) and country code:

### Authentication
Include your API Bearer token in the request header:

```http
Authorization: Bearer <your_jwt_token>
```

### Request Example

<Tabs>
<TabItem value="curl" label="cURL">

```bash
curl -X POST https://api.verifik.co/v2/vehicle \
  -H "Authorization: Bearer <your_jwt_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "plate": "ABC123",
    "country": "CO"
  }'
```

</TabItem>
<TabItem value="nodejs" label="Node.js">

```javascript
const axios = require('axios');

async function validateVehicle() {
  try {
    const response = await axios.post(
      'https://api.verifik.co/v2/vehicle',
      {
        plate: 'ABC123',
        country: 'CO'
      },
      {
        headers: {
          'Authorization': `Bearer ${process.env.VERIFIK_API_KEY}`,
          'Content-Type': 'application/json'
        }
      }
    );

    console.log('Vehicle Details:', response.data);
  } catch (error) {
    console.error('Validation error:', error.response?.data || error.message);
  }
}

validateVehicle();
```

import os

url = "https://api.verifik.co/v2/vehicle"

## Response Status Codes

| HTTP Status | Description | Action Required |
|---|---|---|
| `200 OK` | Vehicle record retrieved successfully | Process vehicle specifications |
| `400 Bad Request` | Missing plate number or invalid syntax | Ensure license plate matches national standard format |
| `401 Unauthorized` | Invalid or expired token | Refresh API token |
| `404 Not Found` | License plate not found in official registry | Verify license plate characters and reissue |
| `500 Server Error` | Official transit service temporarily offline | Retry request via backoff |
