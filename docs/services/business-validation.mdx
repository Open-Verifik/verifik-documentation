# Business Validation

:::info SmartCheck Integration
Automate Know Your Business (KYB) and commercial entity audits from the **SmartCheck** dashboard at [ai.verifik.co](https://ai.verifik.co) or execute bulk vendor reviews using [SmartBatch](/smart-batch).
:::

Verifik's **Business Validation** APIs provide programmatic access to official commercial registries, tax authority databases, and corporate oversight systems across Latin America, North America, and Europe.

Built for fintechs, payment facilitators, B2B marketplaces, and enterprise procurement teams, our services streamline KYB compliance, merchant underwriting, credit scoring, and vendor onboarding with real-time official verification.

## Verification Capabilities

Our business verification suite covers five fundamental corporate audit dimensions:

### 1. Legal Entity Standing & Registry Verification
Verify the legal existence, incorporation details, and operating status of commercial entities:
- **Corporate Identity**: Registered legal name (*Razón Social*), trade name (*Nombre Comercial*), and corporate type (SAS, SA, LLC, S. de R.L.).
- **Registration Metrics**: Chamber of commerce or registry jurisdiction, registration number (*Matrícula Mercantil*), and date of incorporation.
- **Operating Status**: Active, dissolved, in liquidation, or bankrupt.
- **Fiscal Expiration**: Annual commercial registry renewal date and compliance standing.

### 2. Tax Identification & Regime Compliance
Validate official tax numbers and statutory tax classification:
- **Tax Identification Number**: Verification of NIT, RFC, RUC, CNPJ, CUIT, CIF, or EIN.
- **Verification Digit**: Mathematical and official validation of checksum digits (e.g., NIT verification digit in Colombia).
- **Tax Classification**: Simplified vs. common regime, VAT responsibility, and withholding agent status.
- **Electronic Invoicing Compliance**: Authorized electronic billing provider status and active invoicing status.

### 3. Corporate Leadership & Legal Representation
Uncover beneficial ownership and authorized signatories:
- Primary and alternate legal representatives (*Representante Legal*).
- Identification documents, names, and appointment terms for corporate officers.
- Board of directors composition and registered statutory auditors (*Revisor Fiscal*).
- Signing powers and monetary contract authority limits.

### 4. Economic Activities & Sector Classification
Classify business models and industry exposure:
- Primary and secondary International Standard Industrial Classification (ISIC / CIIU / NAICS) codes.
- Sector descriptions and registered commercial activities.
- Declared assets, equity, and operational size (micro, small, medium, large enterprise).

### 5. Reputational & Compliance Screening
Cross-check corporate entities and executive officers against compliance databases:
- Screening company and legal representatives against sanctions, PEP, and multilateral watchlists.
- Verification of fiscal liability and tax delinquent debtor status.
- Public procurement sanctions and contracting disqualifications.

|---|---|---|

| **Argentina** | CUIT Empresa | AFIP, Inspección General de Justicia (IGJ) |
| **United States** | EIN, State Filing # | Secretary of State Commercial Filings, IRS EIN Validation |
| **Spain** | CIF, NIF | Registro Mercantil Central, Agencia Tributaria (AEAT) |

## API Integration

Query business data using the corporate tax identification number (`taxId`) and country code:

### Authentication
Include your API Bearer token in the request header:

```http
Authorization: Bearer <your_jwt_token>
```

### Request Example

<Tabs>
<TabItem value="curl" label="cURL">

```bash
curl -X POST https://api.verifik.co/v2/business \
  -H "Authorization: Bearer <your_jwt_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "taxId": "900123456",
    "verificationDigit": "7",
    "country": "CO"
  }'
```

</TabItem>
<TabItem value="nodejs" label="Node.js">

```javascript
const axios = require('axios');

async function validateBusiness() {
  try {
    const response = await axios.post(
      'https://api.verifik.co/v2/business',
      {
        taxId: '900123456',
        verificationDigit: '7',
        country: 'CO'
      },
      {
        headers: {
          'Authorization': `Bearer ${process.env.VERIFIK_API_KEY}`,
          'Content-Type': 'application/json'
        }
      }
    );

    console.log('Business Record:', response.data);
  } catch (error) {
    console.error('Validation error:', error.response?.data || error.message);
  }
}

validateBusiness();
```

## Response Status Codes

| HTTP Status | Description | Action Required |
|---|---|---|
| `200 OK` | Business verified successfully | Process the verified company profile |
| `400 Bad Request` | Missing or invalid tax ID format | Check tax identifier and check digit |
| `401 Unauthorized` | Invalid or expired API credentials | Refresh your API token |
| `404 Not Found` | Entity not registered in official database | Confirm corporate ID with merchant |
| `500 Server Error` | Official commercial registry unavailable | Exponential backoff retry |
