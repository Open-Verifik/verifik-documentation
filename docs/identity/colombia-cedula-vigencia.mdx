# Colombia — National ID status (CC)

The **Colombia national ID status** lookup reads the Registraduría vigencia for a cédula de ciudadanía. Send `documentNumber`. The payload says whether that number exists and whether the holder is recorded as alive, together with the status text published by the registry. Use it when onboarding needs a current CC status before a fuller identity lookup.

## What the call returns

- `documentType` — CC
- `documentNumber` — the cédula you sent
- `exists` — whether the registry has the number
- `isAlive` — true, false, or null
- `documentStatus` — the vigencia text from the registry

## Use cases

- Confirm a CC is on file before you open an account.
- Separate a deceased record from a vigente cédula during KYC.
- Store the registry status text next to the document number.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/cedula/vigencia
```

A successful payload includes `documentType` (CC), `documentNumber`, `exists`, `isAlive`, and `documentStatus`. `exists` is false when the registry says the number is not on file. `isAlive` is true, false, or null when the source does not settle that question. Run it in a KYC file that needs the current vigencia.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Yes** | `1121329661` | Colombian cédula de ciudadanía, 5 to 10 digits, without spaces or punctuation. |

### Notes

- `documentNumber` is required and must be 5 to 10 characters.
- `isAlive` can be null when the registry returns a status that does not settle life or death.
- This route is the vigencia lookup. It does not replace a full citizen profile.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.
