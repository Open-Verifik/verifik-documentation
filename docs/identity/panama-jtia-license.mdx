# Panama — Engineering and architecture license (JTIA)

The **JTIA license** lookup reads idoneidad for engineers, architects, and technicians. Send one of `documentNumber` (or `cedula`), `licenseNumber` (or `idoneidad`), or `fullName`. A cédula that cannot be normalized returns 409. A missing board row is 404 `NotFound`.

## What the call returns

- Normalized cédula
- `licenseNumber` and `fullName`
- `status`

## Use cases

- Verify an engineer before a building permit.
- Search by cédula when the license number is unknown.
- Search by name when you only have the contract.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/pa/professional/jtia
```

A hit includes the normalized cédula, name, license, and status.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditional** | `8-224-2444` | Panamanian cédula, also accepted as `cedula`. The API normalizes it (for example `8-224-2444`). |
| `licenseNumber` | string | **Conditional** | `JTIA-100` | Idoneidad or license. Alias: `idoneidad`. |
| `fullName` | string | **Conditional** | `ANA RUIZ` | Name, 3 to 160 characters. Enough on its own. |

### Notes

- Send a cédula, a license, or a name.
- An invalid cédula shape is 409.
- No JTIA row is 404 `NotFound`.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |
| Record on file | `documentNumber: "8-224-2444"` | 200 with the normalized cédula and license. |
| Missing required value | Omit cédula, license, and name | 409 MissingParameter. |
| Unknown value | `documentNumber: "1-1-1"` | 409 when the cédula cannot be normalized, or 404 when JTIA has no row. |
