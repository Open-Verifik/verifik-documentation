# LATAM — Unified education and license score

The **education score** rolls university degrees and professional licenses into one score for `CO`, `PE`, `PA`, `MX`, or `CL` (English country names are accepted). `country` is required. You must also send one identity: `documentNumber`, `licenseNumber`, `fullName`, or both `firstName` and `lastName`. A 409 body is `{ "validationError": "..." }`, not `MissingParameter`. An unsupported country is also 409.

## What the call returns

- `educationScore` and `educationTier`
- `highestLevel` and `hasActiveLicense`
- `credentials` and `checkedSources`

## Use cases

- Rank a hire across degree and license sources.
- Require a country before you score.
- Read sanctions as a score reduction.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/score/education
```

The payload includes `educationScore` from 0 to 100, `educationTier`, `highestLevel`, `hasActiveLicense`, `hasSanctions`, and `credentials`.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `country` | string | **Yes** | `CO` | Required. `CO`, `PE`, `PA`, `MX`, `CL`, or the English name `COLOMBIA`, `PERU`, `PANAMA`, `MEXICO`, `CHILE`. |
| `documentNumber` | string | **Conditional** | `80123456` | One identity is required: this number, `licenseNumber`, `fullName`, or both `firstName` and `lastName`. |
| `licenseNumber` | string | **Conditional** | `AN205-27910` | Professional license. Counts as the required identity. |
| `fullName` | string | **Conditional** | `ANA PEREZ` | Full name. Counts as the required identity. |

### Notes

- `country` is required.
- 409 uses `validationError`, not `MissingParameter`.
- Supported countries are CO, PE, PA, MX, and CL.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |
| Record on file | `country: "CO"`, `documentNumber: "80123456"` | 200 with educationScore and tier. |
| Missing required value | Omit `country` | 409 `{ validationError }` when country or the identity is missing. |
| Unknown value | `country: "US"`, `documentNumber: "1"` | 409 when the country code is not supported. |

401 when the bearer token is missing or rejected.
