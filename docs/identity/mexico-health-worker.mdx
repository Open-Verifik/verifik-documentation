# Mexico — Health Worker License

Confirms that a person holds at least one health-related professional license in the official professional registry. The same lookup modes as [Professional License](/identity/mexico-cedula-profesional) apply: CURP, license number, or name. Non-health licenses are removed from the result.

Health titles include medicine, nursing, dentistry, pharmacy, nutrition, clinical psychology, psychiatry, obstetrics, physiotherapy, and optometry. Veterinary medicine is excluded. A person who only holds non-health licenses returns **404**.

This is credential screening, not identity proofing. For every license, use [Professional License](/identity/mexico-cedula-profesional). For the civil record, use [Mexican Citizen (CURP)](/identity/mexico).

## API reference

### Endpoint

```
https://api.verifik.co/v2/mx/health-worker
```

A match returns the same identity fields as the general license endpoint, plus `isHealthWorker: true` and `nonHealthCount` (how many non-health licenses were set aside). `cedulas` contains only the health licenses.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

Send `documentType` + `documentNumber`, or `firstName` + `lastName`. Do not mix the two modes.

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `documentType` | string | Document mode | `CURP` or `CEDULA` (case-insensitive). CURP is preferred for health hiring. | `CURP` |
| `documentNumber` | string | With `documentType` | A CURP of 17–18 characters or a license number. | `LOPE900501HDFGRN01` |
| `firstName` | string | Name mode | Given names. 2–80 characters. | `ANA` |
| `lastName` | string | Name mode | Both surnames, paternal first. 2–80 characters. | `LOPEZ RUIZ` |

### How matching works

The lookup is the same as the general license endpoint, then a health filter is applied.

- **CURP** tries a direct match (`matchMethod: "curp"`), then an exact-name fallback at no extra cost (`matchMethod: "curp_to_name"`).
- **CEDULA** is an exact license-number match. A non-health license returns **404**.
- **Name** is an exact full-name match. If none of the matching licenses are health titles, the response is **404**.
- `nonHealthCount` is the number of licenses that were found and excluded. `isHealthWorker` is `true` whenever this endpoint returns 200.

### Notes

- **404** means no health license was found. That includes a valid CURP with no license at all, and a person who only holds non-health licenses (for example law).
- In Smart Batch, that 404 is a completed screening result, not a failed row.
- Results are cached for up to 7 days.
- Sandbox CURP `LOPE900501HDFGRN01` returns one medicine license and `nonHealthCount: 1`.
- A CURP containing `000003` (for example `LOPE000003MDFRRN03`) returns the name-fallback health license.
- `documentType=CEDULA` and `documentNumber=10000002` returns a nursing license. `10000001` is law only and returns **404**.
- CURP `LOPE900404HDFNTF01`, a CURP containing `000002`, and `lastName=NOTFOUND` return **404**.
- A CURP shorter than 17 or longer than 18 characters, or an invalid `documentType`, returns **409** `MissingParameter`.
- When the registry cannot be reached, the response is **409** `Endpoint_out_of_service`. Retry later.
- Related: [Professional License](/identity/mexico-cedula-profesional), [Mexican Citizen (CURP)](/identity/mexico), [INE Validation](/identity/mexico-ine).
