# Mexico — ISSSTE Social Security Affiliation

Verifik's **Mexico ISSSTE Affiliation API** allows organizations, employers, and compliance teams to verify a citizen's public sector social security affiliation status and retrieve official non-affiliation certificates directly using an 18-character **CURP** (*Clave Única de Registro de Población*):

- **Labor Status Verification**: Determines whether the person is currently active (*ACTIVO*), inactive with historical records (*INACTIVO*), or unlocated (*NO LOCALIZADO*) in the federal public sector social security registry.
- **Certified Digital Details**: Extracts the official certificate metadata, including barcode folio number, unique identifier (UUID), issuance timestamp, and cryptographic digital seal.
- **Official Signed PDF Document**: Generates and downloads the official digitally signed PDF certificate (*Constancia de Acreditación de No Afiliación*) encoded as Base64 when requested (`includePdf=true`).
- **Federal Demographic Validation**: Validates and returns the citizen's official legal name parsed into `firstName`, `paternalSurname`, `maternalSurname`, `dateOfBirth`, `sex`, and `gender`.

---

## What does this API validate?

- **Affiliation Status (`affiliationStatus`)**: Reports whether the individual has an active public sector labor relationship with the Mexican government (`ACTIVO`), previously worked in the federal public sector but is now inactive (`INACTIVO`), or has never had registered contributions (`NO LOCALIZADO`).
- **Demographic Confirmation**: Verifies the citizen's identity and returns normalized demographic attributes: `firstName`, `lastName`, `paternalSurname`, `maternalSurname`, `dateOfBirth` (`YYYY-MM-DD`), `sex`, and `gender`.
- **Digital Certificate Verification (`certificate`)**: Returns the official certificate details:
  - `folio`: The unique registration folio printed alongside the barcode (e.g. `082611565`).
  - `uuid`: The official cryptographic UUID tracking the certification record.
  - `issuedAt`: The precise date and time of certificate generation.
  - `digitalSeal`: The base64-encoded official cryptographic hash ensuring tamper-proof legal validity.
  - `pdfBase64`: (Optional) The complete official digitally signed PDF certificate.
- **Verifik Cryptographic Signature**: Every response is signed by Verifik to certify origin and timestamp integrity.

## API Reference

### Endpoint

```
GET https://api.verifik.co/v2/mx/issste/affiliation
```

### Headers

| Name | Value | Description |
| --- | --- | --- |
| `Accept` | `application/json` | Required response content type. |
| `Authorization` | `Bearer <token>` | Your Verifik API JWT or client token. |

### Parameters

| Name | Type | Required | Default | Description | Example |
| --- | --- | --- | --- | --- | --- |
| `documentNumber` | string | **Yes** | — | Mexican **CURP** (18 characters). Case-insensitive. | `LOPE900501HDFGRN01` |
| `documentType` | string | No | `CURP` | Document type. Allowed value: `CURP`. | `CURP` |
| `includePdf` | boolean | No | `false` | Whether to return the official digitally signed PDF certificate encoded as Base64 in `certificate.pdfBase64`. | `true` |

### Notes

- This endpoint carries a starting price of **`0.50` credits**.
- Queries that return 404 (Record not found) or 409 (Validation errors) do not deduct credits.
- To obtain the full digitally signed PDF file, provide the query parameter `includePdf=true`.

## Common Use Cases

- **Employment Onboarding & Pre-Hiring Compliance**: Verify that candidates joining private companies do not have an active public sector appointment or conflict of interest.
- **Academic & University Enrollments**: Streamline student and faculty registration by automatically obtaining official non-affiliation proof required for healthcare subsidies and scholarships.
- **Legal & Social Security Audit**: Provide verifiable audit trails with digital seal and barcode folio numbers for labor background checks.
