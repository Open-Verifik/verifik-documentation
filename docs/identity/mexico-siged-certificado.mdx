# Mexico — Education Certificate (folio)

Validates a Mexican electronic education certificate by folio against the official education-certificate registry. Optionally send `fullName` or `curp` to confirm the certificate belongs to that person. When both are sent, `curp` wins. A mismatch returns **409** `name_mismatch`.

This checks the certificate record. It does not prove identity on its own. For a CURP civil record, see [Mexican Citizen (CURP)](/identity/mexico). For a professional license, see [Professional License](/identity/mexico-cedula-profesional).

## API reference

### Endpoint

```
https://api.verifik.co/v2/mx/siged/certificado
```

A match returns `folio`, `fullName`, `status`, `certificateType`, `career`, `institution`, `level`, `studyType`, `average`, `averageText`, `periodStart`, `periodEnd`, `registrationDate`, `laborTraining`, `federalEntity`, and `issueDate`. Empty fields are `null`.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `folio` | string | Yes | Folio printed on the electronic certificate. 4–64 characters. | `SIGED10000001` |
| `fullName` | string | No | Expected full name. A mismatch returns 409 `name_mismatch`. Ignored when `curp` is also sent. 3–160 characters. | `Ana Lopez Ruiz` |
| `curp` | string | No | CURP of the person. When sent, it overrides `fullName`. 17–18 characters. | `LOPE900501HDFGRN01` |

### Notes

- `folio` is required. `fullName` and `curp` are optional owner checks. When both are sent, `curp` is used and `fullName` is ignored.
- A folio that is not in the registry returns **404**. A name or CURP that does not belong to that certificate returns **409** `name_mismatch`.
- Results are cached for up to 7 days.
- Sandbox folio `SIGED10000001` returns the sample certificate for `ANA LOPEZ RUIZ`. `fullName=Ana Lopez Ruiz` also returns 200.
- `fullName=Maria Perez` on that folio returns **409** `name_mismatch`.
- Folio `FOLIO90040401` returns **404**.
- `curp=LOPE900501HDFGRN01` with any `fullName` returns 200, because CURP wins. `curp=LOPE900404HDFNTF01` returns **404**.
- A missing `folio` returns **409** `MissingParameter`.
- When the registry cannot be reached, the response is **409** `Endpoint_out_of_service`. Retry later.
