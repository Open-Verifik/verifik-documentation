# Colombia — Electrical and mechanical engineering license

The **electrical and mechanical engineering license** lookup reads the Consejo Profesional Nacional de Ingenierías Eléctrica, Mecánica y Profesiones Afines. Send one of `documentNumber`, `licenseNumber`, or `fullName`. The payload includes the license, specialty, registration status, and whether the council reports sanctions.

## What the call returns

- `licenseNumber` and `specialty`
- `status` such as VIGENTE
- `isRegistered` and `hasSanctions`
- `registrations` when the person has more than one row

## Use cases

- Confirm an electrical or mechanical engineer before site work.
- Read disciplinary sanctions next to the license.
- Match a contract name to the council row.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/consejo-profesional
```

A match includes `fullName`, `licenseNumber`, `specialty`, `status`, `isRegistered`, and `hasSanctions`. If the council has no row, the API returns 404 `NotFound`.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditional** | `80123456` | Colombian identity number, 5 to 15 characters. `documentType` may be `CC`, `CE`, `TI`, `PEP`, or `PPT`. |
| `licenseNumber` | string | **Conditional** | `AN205-27910` | Professional license, such as AN205-27910. Enough on its own. |
| `fullName` | string | **Conditional** | `ANA PEREZ` | Engineer name or surnames, 3 to 160 characters. Enough on its own. |

### Notes

- Send at least one of `documentNumber`, `licenseNumber`, or `fullName`.
- A missing council row is HTTP 404, not an empty 200.
- `documentType` is optional and defaults to CC in the sample.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.
