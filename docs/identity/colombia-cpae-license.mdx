# Colombia — Business administration license (CPAE)

The **CPAE license** lookup reads the Consejo Profesional de Administración de Empresas. `documentNumber` is required. Optional `documentType` accepts `CC`, `CE`, `TI`, `PEP`, or `PPT`. A hit returns the professional name, the profession, and whether the card is registered and active.

## What the call returns

- `fullName` and `profession`
- `entity` — CPAE
- `status`, `isRegistered`, and `isActive`

## Use cases

- Check a business-administration card during hiring.
- Confirm the card is still active.
- Store the CPAE profession text on the KYC file.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpae
```

The payload includes `fullName`, `profession`, `entity`, `status`, `isRegistered`, and `isActive`. An unknown number is 404 `NotFound`.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Yes** | `80123456` | Colombian identity number, 5 to 15 characters. `documentType` may be `CC`, `CE`, `TI`, `PEP`, or `PPT`. |

### Notes

- `documentNumber` is required.
- The CPAE returns 404 when the number has no professional card.
- Do not send a name in place of the document number.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.
