# Peru — SUNEDU degrees and CONCYTEC RENACYT

The **RENACYT** lookup reads SUNEDU degrees and the CONCYTEC researcher registry. Send at least one of `documentNumber` (alias `dni`), `codigoRegistro`, `orcid`, or `fullName`. When you send a document number, `documentType` defaults to `DNI`.

## What the call returns

- Degree and researcher fields
- `codigoRegistro` and `orcid` when present
- `fullName` and `documentNumber`

## Use cases

- Confirm a researcher before a grant.
- Match an ORCID to a DNI.
- Read the RENACYT code for a hiring file.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/pe/education/renacyt
```

A hit can include the degree, the RENACYT code, and the ORCID. No row is 404 `NotFound`.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditional** | `12345678` | DNI or other number. Alias: `dni`. Default `documentType` is `DNI`. Also accepted: `CE`, `PASAPORTE`, `PTP`. |
| `codigoRegistro` | string | **Conditional** | `REN-100` | RENACYT registry code. Enough on its own. |
| `orcid` | string | **Conditional** | `0000-0002-1825-0097` | ORCID, 10 to 30 characters. Enough on its own. |
| `fullName` | string | **Conditional** | `LUCIA QUISPE` | Researcher name. Enough on its own. |

### Notes

- Send a document, a RENACYT code, an ORCID, or a name.
- Document numbers default to type `DNI`.
- No registry row is 404 `NotFound`.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |
