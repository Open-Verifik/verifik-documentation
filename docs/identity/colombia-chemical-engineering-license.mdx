# Colombia — Chemical engineering license (CPIQ)

The **CPIQ license** lookup reads the Consejo Profesional de Ingeniería Química. Send `documentNumber` or `licenseNumber`. The module does not search by name: `fullName` alone returns HTTP 409 with `MissingParameter` and the message `Either documentNumber or licenseNumber must be provided`. A hit includes the license, resolution, status, and sanction fields.

## What the call returns

- `licenseNumber` and `resolutionNumber`
- `status` and `isActive`
- `sanctionType` and `hasSanctions`

## Use cases

- Verify a chemical engineer by cédula or CPIQ license.
- Reject name-only searches before they reach the council.
- Read sanction dates when the council publishes them.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpiq
```

A match includes `fullName`, `licenseNumber`, `resolutionNumber`, `status`, `sanctionType`, `isRegistered`, and `hasSanctions`. No CPIQ row is 404 `NotFound`.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditional** | `79876543` | Identity number. Required when `licenseNumber` is omitted. A request with only `fullName` returns 409. |
| `licenseNumber` | string | **Conditional** | `PQ-10293` | CPIQ professional-license number. Required when `documentNumber` is omitted. |

### Notes

- `fullName` is not a search key on this route. Name-only calls return 409.
- Send `documentNumber` or `licenseNumber`.
- A missing CPIQ row is HTTP 404.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |

| Missing required value | `fullName: "LUIS GOMEZ"` only | 409 because a name alone is not accepted. |
