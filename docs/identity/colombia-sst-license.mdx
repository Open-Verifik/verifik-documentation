# Colombia — Occupational safety license (SST)

The **SST license** lookup reads open occupational-safety licenses and technical applicator carnés for a Colombian identity number. `documentNumber` is required. A hit lists each license with its type, resolution or carné number, and issue date.

## What the call returns

- `licenses[]` with `licenseType`, resolution or carné number, and `issueDate`
- `totalLicenses`
- `status` and `isRegistered`

## Use cases

- Check an SST license before a contractor enters a site.
- See both the natural-person license and the technical carné.
- Keep the resolution number on the vendor file.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/sst/licencia
```

The payload includes `fullName`, `profession`, `totalLicenses`, and `licenses`. No license and no carné is 404 `NotFound`.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Yes** | `52111222` | Colombian identity number, 5 to 15 characters, used to read SST licenses and technical carnés. |

### Notes

- `documentNumber` is required.
- An identity with neither an SST license nor a technical carné is HTTP 404.
- Optional `documentType` accepts `CC`, `CE`, `TI`, `PEP`, or `PPT`.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.
