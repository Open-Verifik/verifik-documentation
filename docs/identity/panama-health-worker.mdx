# Panama — Health Worker & Medical Professional Verification (MINSA / Consejo Técnico de Salud)

Validates and retrieves registration details for physicians, specialists, dentists, nurses, pharmacists, and medical technologists in Panama. Queries can be executed by **Cédula (`documentNumber` or `cedula`)** or by **Full Name (`fullName`)**.

The verification checks official registries maintained by the Ministry of Health (*Ministerio de Salud — MINSA*) and the Technical Health Council (*Consejo Técnico de Salud*), returning professional standing, category, position, institution, and start date.

- **National Coverage:** Covers public health institutions, medical personnel, and licensed professionals throughout the Republic of Panama.
- **Multi-Profession Identification:** Identifies general practitioners, medical specialists, odontologists, registered nurses, and pharmacy personnel.
- **Identity Consistency:** Validates official Panamanian Cédula formats (standard `X-XXX-XXXX` and padded `X-XXXX-XXXXX`).

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/pa/health-worker
```

*(Also available via alias `https://api.verifik.co/v2/pa/medical-professional`)*

### Headers

| Name | Value |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `cedula` | string | Conditional | Panamanian Cédula (e.g. `8-224-2444` or `8-0224-02444`). Required if `fullName` is omitted. |
| `documentNumber` | string | Conditional | Alias for `cedula`. Standard document number parameter. |
| `documentType` | string | No | Document type: `CEDULA` (default) or `CCPA`. |
| `fullName` | string | Conditional | Full name of the health professional (minimum 3 characters). Required if document number is omitted. |
| `force` | boolean | No | Bypass recent lookup cache and trigger fresh verification. |

### Notes

- Use either `cedula` / `documentNumber` or `fullName` per query.
- Panamanian cédula numbers are accepted in hyphenated (`8-224-2444`), zero-padded (`8-0224-02444`), or raw digit format.
- In sandbox mode (`isSandbox`), use test cédulas `8-224-2444` (Médico Especialista) or `8-222-1461` (Odontólogo).
