# Ecuador — Voting location

The **Ecuador voting location** lookup reads the CNE padrón. `documentType` must be `CCEC` and `documentNumber` must be a 10-digit cédula whose province code is 01–24 or 30 and whose check digit is valid. The payload includes the name plus province, canton, parish, and junta (`pollingTable`).

## What the call returns

- `province`, `canton`, and `parish`
- `pollingTable` — the junta
- `fullName`

## Use cases

- Show a voter their polling place.
- Reject a cédula whose check digit fails.
- Store the junta with the identity file.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/ec/votacion
```

Fields include `fullName`, `province`, `canton`, `parish`, and `pollingTable`. An unknown cédula is 404 `NotFound`. A bad check digit is 409 `InvalidDocumentNumber`.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentType` | string | **Yes** | `CCEC` | Must be `CCEC`. |
| `documentNumber` | string | **Yes** | `1700000019` | 10-digit Ecuadorian cédula, including the check digit. Province digits must be 01–24 or 30. A bad number returns 409 `InvalidDocumentNumber`. |

### Notes

- `documentType` must be `CCEC`.
- The cédula is 10 digits with a valid province and check digit.
- Unknown numbers are 404 `NotFound`.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.
