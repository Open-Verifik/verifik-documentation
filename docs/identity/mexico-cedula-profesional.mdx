# Mexico — Professional License

Confirms that a person holds a professional license (cédula profesional) in the official professional registry. This is credential verification, not identity proofing.

Send **either** a document **or** a name:

- **CURP** (recommended). The registry is checked for licenses tied to that CURP first.
- **License number.** An exact match on the cédula number.
- **Name.** An exact, accent-insensitive match on given names plus both surnames.

A person can hold several licenses, so `cedulas` is an array. For the CURP holder’s civil record, see [Mexican Citizen (CURP)](/identity/mexico). For a voter credential, see [INE Validation](/identity/mexico-ine). For health-only licenses, see [Health Worker License](/identity/mexico-health-worker).

## API reference

### Endpoint

```
https://api.verifik.co/v2/mx/cedula-profesional
```

A match returns `fullName`, `matchMethod`, `ambiguous`, and `cedulas[]` with `licenseNumber`, `title`, `profession`, `institution`, and `registrationYear`.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

Send `documentType` + `documentNumber`, or `firstName` + `lastName`. Do not mix the two modes.

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `documentType` | string | Document mode | `CURP` or `CEDULA` (case-insensitive). | `CURP` |
| `documentNumber` | string | With `documentType` | A CURP of 17–18 characters (uppercased automatically) or a license number. | `LOPE900501HDFGRN01` |
| `firstName` | string | Name mode | Given names. 2–80 characters. | `ANA` |
| `lastName` | string | Name mode | Both surnames, paternal first. 2–80 characters. | `LOPEZ RUIZ` |

### How matching works

- **CURP.** Licenses tied to that CURP are returned first (`matchMethod: "curp"`). If none are tied directly, Verifik resolves the CURP holder’s official name and searches for an exact full-name match. That step costs nothing extra (`matchMethod: "curp_to_name"`, with `matchNote`). Rows that carry the same CURP win. Otherwise, rows without a CURP that match the exact name are returned.
- **`ambiguous: true`** means those rows belong to more than one institution and registration-year group, so a homonym is possible. Review the rows or ask for the license number.
- **CEDULA.** An exact license-number match (`matchMethod: "license"`).
- **Name.** An exact accent- and case-insensitive full-name match (`matchMethod: "name"`). `ambiguous` uses the same institution/year rule. Prefer CURP.

### Notes

- A valid CURP whose holder has no license returns **404**, including in sandbox. An empty `cedulas` array is not a success response.
- `ambiguous: true` means the rows span more than one institution and registration year. Review them or look up the license number.
- Results are cached for up to 7 days, so a repeat lookup is fast.
- Sandbox persona `ANA LOPEZ RUIZ`. Any CURP except the triggers below returns a direct match with two licenses.
- A CURP containing `000003` (for example `LOPE000003MDFRRN03`) returns `matchMethod: "curp_to_name"` and `cedulas[].curp: null`.
- A CURP containing `000002` (for example `LOPE000002MDFRRN02`) returns **404** (valid CURP, no license).
- CURP `LOPE900404HDFNTF01`, license `90040401`, or `lastName=NOTFOUND` returns **404**.
- `documentType=CEDULA` and `documentNumber=10000001` returns one law license. `firstName=ANA` and `lastName=AMBIGUA` returns `ambiguous: true`.
- A CURP shorter than 17 or longer than 18 characters, or an invalid `documentType`, returns **409** `MissingParameter`.
- When the registry cannot be reached, the response is **409** `Endpoint_out_of_service`. Retry later.
- Related: [Mexican Citizen (CURP)](/identity/mexico), [INE Validation](/identity/mexico-ine), [Health Worker License](/identity/mexico-health-worker), [Education Certificate (folio)](/identity/mexico-siged-certificado).
