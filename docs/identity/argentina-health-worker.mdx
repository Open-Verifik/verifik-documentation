# Argentina — Health Worker & Medical Professional Verification (SISA / REFEPS)

Validates and verifies medical professionals and healthcare practitioners across the Argentine Republic by **DNI (`documentNumber`)** or **Full Name (`fullName`)**, with optional professional license number (**`matricula`**).

The service queries the official **Registro Federal de Profesionales de la Salud (REFEPS)** integrated in the **Sistema de Información Sanitaria Argentino (SISA)** of the **Ministerio de Salud de la Nación (MSAL)**, confirming professional license numbers, degree titles, specialties, provincial health authority, and authorization status.

- **National and Provincial Scope:** Unifies records across the 23 provinces and the Autonomous City of Buenos Aires (CABA).
- **Comprehensive Health Disciplines:** Validates physicians (*médicos*), dentists (*odontólogos*), psychologists, nurses, pharmacists, and biochemists.
- **Accredited Specialties:** Confirms medical and clinical specialties registered with provincial colleges and the national ministry.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/ar/health-worker
```

*(Also available via alias `https://api.verifik.co/v2/ar/cedula/medico-profesional`)*

### Headers

| Name | Value |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | Conditional | Argentine DNI (e.g. `20123456` or `28456789`). Required if `fullName` is omitted. |
| `documentType` | string | No | Document type: `DNI` (default). |
| `fullName` | string | Conditional | Full name of the medical professional. Required if DNI is omitted. |
| `matricula` | string | No | Provincial or national professional license number (optional filter). |
| `force` | boolean | No | Bypass recent lookup cache and trigger fresh verification. |

### Notes

- Use either `documentNumber` (DNI) or `fullName`.
- `matricula` can be supplied alongside `documentNumber` or `fullName` to narrow down provincial registrations.
- In sandbox mode, test DNIs include `20123456` (Médico - Cardiología) and `28456789` (Médico - Pediatría).
