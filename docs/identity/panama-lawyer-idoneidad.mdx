# Panama — Lawyer idoneidad

The **lawyer idoneidad** lookup reads the Panamanian bar certificate by number. Send `idoneidad` or the alias `licenseNumber` as 1 to 10 digits. Optional `issueDate` uses `DD-MM-YYYY`. A missing number is 409 `MissingParameter`.

## What the call returns

- Idoneidad number and name
- `status`

## Use cases

- Confirm a lawyer before a filing.
- Match the issue date when you have it.
- Reject a non-numeric idoneidad.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/pa/lawyer/idoneidad
```

A hit includes the lawyer name, idoneidad number, and status. An unknown number is 404 `NotFound`.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `idoneidad` | string | **Conditional** | `12345` | Lawyer idoneidad number, 1 to 10 digits. Alias: `licenseNumber`. One of the two is required. |
| `issueDate` | string | No | `01-02-2010` | Optional issue date in `DD-MM-YYYY`. |

### Notes

- Send `idoneidad` or `licenseNumber`.
- Digits only, 1 to 10.
- Unknown numbers are 404 `NotFound`.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.
