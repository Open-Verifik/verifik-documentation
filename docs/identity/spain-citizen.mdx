# Identity Verification in Spain

Verifik's Identity Verification API helps you authenticate Spanish citizens and residents using official government data. It's designed to streamline your KYC (Know Your Customer) processes, prevent fraud, and ensure you meet all regulatory requirements effortlessly.

We built this integration for businesses that need a fast, secure, and automated way to confirm the true identity of users, employees, or customers.

## What does this API validate?

Our API connects directly with official records to validate:

-   **Full Name & Document Number**: Supports *Documento Nacional de Identidad* (DNI) and *Número de Identidad de Extranjero* (NIE).
-   **Identity Match**: Confirms that the name provided matches the document number.
-   **Expiration Date Verification**: Validates the document expiration date.

By verifying these details, you can be confident that the person you're dealing with is real and holds a valid document, significantly lowering the risk of impersonation and fraud.

## API Reference

### Endpoint

```
GET https://api.verifik.co/v2/es/cedula
```

Verifies a Spanish natural person’s identity against official sources using **`documentType`** (`DNIES` or `NIE`), **`documentNumber`** (no spaces), and **`expirationDate`** (`DD/MM/YYYY`) for `DNIES` and `NIE` numbers that do not start with `X`, `Y`, or `Z` (such as `M`-prefixed NIEs). `NIE` numbers starting with `X`, `Y`, or `Z` require **`supportNumber`** (`C` + 8 digits for the EU registration certificate, or `E` + 8 digits for the TIE). Use for **KYC**, **fraud prevention**, and **regulated onboarding**.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Name           | Type    | Required | Description                                    |
| -------------- | ------- | -------- | ---------------------------------------------- |
| `documentType` | string  | Yes      | Document type. Allowed values: `DNIES`, `NIE`. |
| `documentNumber` | string | Yes      | Document number without spaces. |
| `expirationDate` | string | Conditional | Validity/expiration date in `DD/MM/YYYY` format. Required for `DNIES` and for `NIE` numbers that do not start with `X`, `Y`, or `Z` (e.g., `M`-prefixed NIEs). Not accepted as the only proof for `X`/`Y`/`Z` NIEs. |
| `supportNumber` | string | Conditional | Required for `NIE` numbers starting with `X`, `Y`, or `Z`. Accepted formats: `C` + 8 digits (EU registration certificate) or `E` + 8 digits (TIE residence card). Shorter `C` or `E` values (1–7 digits) are zero-padded after the letter, and spaces/hyphens are ignored. |

### Notes

- `expirationDate` must follow the format `DD/MM/YYYY` and is required for `DNIES` and non-`X`/`Y`/`Z` `NIE` numbers (e.g. `M`-prefixed NIEs).
- `NIE` numbers starting with `X`, `Y`, or `Z` require `supportNumber` (`C` + 8 digits for the EU registration certificate, `E` + 8 digits for the TIE). Missing or invalid `supportNumber` returns an uncharged `409`.
