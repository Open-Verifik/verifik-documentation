# Mexico — RFC by CURP

Verifik's **Mexico RFC API** enables you to look up and validate a citizen's official **RFC** (*Registro Federal de Contribuyentes*) and 3-character **homoclave** directly from their **CURP** (*Clave Única de Registro de Población*).

This endpoint queries official tax records to confirm tax registration, returning the full 13-character RFC, validated personal name (first name, paternal surname, maternal surname), date of birth, gender, and state of registration.

---

## What does this API validate?

- **Official RFC & Homoclave**: Retrieves the active 13-character RFC registered before the tax authority, including its official 3-character homoclave.
- **Demographic & Name Confirmation**: Returns the registered legal full name parsed into `firstName`, `paternalSurname`, and `maternalSurname`.
- **Identity Consistency**: Confirms date of birth, biological sex / gender, state of registration, and nationality.
- **Cryptographic Signature**: Includes a Verifik cryptographic signature with timestamp certifying origin and integrity.

---

## API Reference

### Endpoints

```
GET https://api.verifik.co/v2/mx/rfc
```

*Alias endpoint:*
```
GET https://api.verifik.co/v2/mx/sat/rfc
```

### Headers

| Name | Value | Description |
| --- | --- | --- |
| `Accept` | `application/json` | Required response content type. |
| `Authorization` | `Bearer <token>` | Your Verifik API JWT or client token. |

### Parameters

| Name | Type | Required | Default | Description | Example |
| --- | --- | --- | --- | --- | --- |
| `documentNumber` | string | **Yes** | — | Mexican CURP (17–18 characters, case-insensitive). | `LOPE900501HDFGRN01` |
| `documentType` | string | No | `CURP` | Document type. Allowed value: `CURP`. | `CURP` |

## Sandbox & Testing

When testing in the **Sandbox environment** (`mode: sandbox`), no live credits are deducted and deterministic mock data is returned:

- **Success Profile**: Use `documentNumber=LOPE900501HDFGRN01`. Returns test persona `ANA LOPEZ RUIZ` with RFC `LOPE9005011A8` and homoclave `1A8`.
- **404 Trigger**: Use `documentNumber=LOPE900404HDFNTF01`. Returns HTTP 404 `Record not found.`.
- **Dynamic Sandbox CURPs**: Any other valid 18-character CURP in sandbox generates a deterministic demographic record and calculated RFC homoclave.
