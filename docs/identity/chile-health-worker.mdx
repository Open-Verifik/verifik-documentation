# Chile — Health Worker & Medical Professional Verification (SIS / RNPI)

Validates and verifies medical professionals and individual health providers in the Republic of Chile by **RUT (`documentNumber` or `rut`)** or **Full Name (`fullName`)**.

The service checks the official **Registro Nacional de Prestadores Individuales de Salud (RNPI)** maintained by the **Superintendencia de Salud (SIS)**, providing certified confirmation of medical degrees, recognized specialties, issuing institutions, and professional registration status.

- **Certified Health Professions:** Validates physicians, surgeons (*médico cirujano*), dentists (*cirujano dentista*), nurses, midwives, medical technologists, and physical therapists.
- **Accredited Medical Specialties:** Confirms medical specialties and sub-specialties certified by CONACEM or recognized universities.
- **Official Compliance:** Essential for clinics, telemedicine platforms, health insurers (FONASA / ISAPRE), and pharmacies to verify provider credentials.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/cl/health-worker
```

*(Also available via alias `https://api.verifik.co/v2/cl/medical-professional`)*

### Headers

| Name | Value |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `rut` | string | Conditional | Chilean RUT number (e.g. `4738039-1` or `12443604-4`). Required if `fullName` is omitted. |
| `documentNumber` | string | Conditional | Alias for `rut`. |
| `documentType` | string | No | Document type: `RUT` (default). |
| `fullName` | string | Conditional | Full name of the medical professional (minimum 3 characters). Required if RUT is omitted. |
| `force` | boolean | No | Bypass recent lookup cache and trigger fresh verification. |

### Notes

- Use either `rut` / `documentNumber` or `fullName`.
- RUT numbers can be provided with or without dots and dash (e.g., `4.738.039-1` or `4738039-1`).
- In sandbox mode, test RUTs include `4738039-1` (Médico Cirujano - Cirugía General) and `12443604-4` (Médico Cirujano - Traumatología).
