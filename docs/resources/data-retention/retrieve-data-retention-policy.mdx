### Endpoint

```http
GET https://api.verifik.co/v2/data-retention/policy
```

Resolves the hierarchical data retention policy for the authenticated client, with optional project and project flow overrides.

### Headers

| Name | Value |
| :--- | :--- |
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Query Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `projectId` | `string` | No | Optional project ID to resolve project-specific retention overrides |
| `projectFlowId` | `string` | No | Optional project flow ID to resolve flow-specific retention overrides |

### Request

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
const fetch = require("node-fetch");

async function getPolicy() {
  const res = await fetch("https://api.verifik.co/v2/data-retention/policy?projectId=6266193db77ccc8111730c90", {
    method: "GET",
    headers: {
      Authorization: `Bearer ${process.env.VERIFIK_TOKEN}`,
      "Content-Type": "application/json",
    },
  });
  console.log(await res.json());
}

getPolicy();
```
