### Endpoint

**DELETE** `https://api.verifik.co/v2/cost-centers/{id}`

Deactivates a cost center. The record is not removed: `active` becomes `false`, and usage history stays attached to it. New requests can no longer use this center.

#### headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### path parameters

#### `id`

**Type:** string  
**Required:** Yes

The cost center id to deactivate.
