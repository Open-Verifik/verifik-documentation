### Endpoint

**POST** `https://api.verifik.co/v2/cost-centers`

Creates a cost center on your account. Managing cost centers does not spend credits.

#### headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### body parameters

#### `name`

**Type:** string  
**Required:** Yes

Display name, up to 120 characters.

#### `code`

**Type:** string  
**Required:** Yes

Value you will send in `x-cost-center`. Letters, numbers, `.`, `-`, and `_`, up to 60 characters. Unique per account.

#### `country`

**Type:** string  
**Required:** Yes

ISO-2 country code, such as `ES`.

#### `active`

**Type:** boolean  
**Required:** No

Defaults to `true`.

### Request Example

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X POST "https://api.verifik.co/v2/cost-centers" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Spain operations","code":"SPAIN-OPS","country":"ES"}'
```

## Error Responses

A code that already exists on the account:

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```

A missing or invalid field, such as `name`, `code`, or `country`:

```json
{
  "message": "\"name\" is required",
  "code": "MissingParameter"
}
```
