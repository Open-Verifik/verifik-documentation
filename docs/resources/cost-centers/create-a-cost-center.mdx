# Create a cost center

```
POST https://api.verifik.co/v2/cost-centers
```

| Name      | Type    | Required | Description                         |
| --------- | ------- | -------- | ----------------------------------- |
| `name`    | string  | Yes      | Display name.                       |
| `code`    | string  | Yes      | Header value. Unique per account.   |
| `country` | string  | Yes      | ISO-2 country code.                 |
| `active`  | boolean | No       | Defaults to `true`.                 |

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X POST "https://api.verifik.co/v2/cost-centers" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Spain operations","code":"SPAIN-OPS","country":"ES"}'
```

</TabItem>
<TabItem value="nodejs" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.post(
	"https://api.verifik.co/v2/cost-centers",
	{ name: "Spain operations", code: "SPAIN-OPS", country: "ES" },
	{ headers: { Authorization: `Bearer ${process.env.VERIFIK_TOKEN}` } }
);

console.log(data.data._id);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.post(
    "https://api.verifik.co/v2/cost-centers",
    headers={"Authorization": f"Bearer {os.environ['VERIFIK_TOKEN']}"},
    json={"name": "Spain operations", "code": "SPAIN-OPS", "country": "ES"},
)

print(response.json()["data"]["_id"])
```

</TabItem>
</Tabs>

The response is the new [cost center object](/resources/the-cost-center-object) inside `data`. Reusing a code returns:

```json
{
	"code": "Conflict",
	"message": "cost_center_code_taken"
}
```
