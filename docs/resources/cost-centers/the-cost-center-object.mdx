### Overview

The cost center object is the record Verifik stores for one team, country, or business unit. API requests reference it by `_id`. You send `code` in the `x-cost-center` header.

```json
{
  "_id": "6acfbdda92451bac5d0a7ebe",
  "client": "69c2b824295cd7d276e478ad",
  "name": "Spain operations",
  "code": "SPAIN-OPS",
  "country": "ES",
  "active": true,
  "createdAt": "2026-10-14T17:37:30.469Z",
  "updatedAt": "2026-10-14T17:37:30.469Z"
}
```

### Attributes

#### `_id`

**Type:** string  
**Required:** Yes

Unique identifier. Use it in retrieve, update, and deactivate calls, and when you set a project default.

#### `client`

**Type:** string  
**Required:** Yes

The account that owns this cost center.

#### `name`

**Type:** string  
**Required:** Yes

Display name, up to 120 characters.

#### `code`

**Type:** string  
**Required:** Yes

The value you send in `x-cost-center`. Letters, numbers, `.`, `-`, and `_`, up to 60 characters. Unique per account.

#### `country`

**Type:** string  
**Required:** Yes

ISO-2 country this cost center usually serves, stored in uppercase.

#### `active`

**Type:** boolean  
**Required:** Yes

Inactive cost centers keep their history but cannot be assigned to new requests. Defaults to `true`.

#### `createdAt`

**Type:** string  
**Required:** Yes

When the cost center was created, in ISO-8601.

#### `updatedAt`

**Type:** string  
**Required:** Yes

When the cost center was last changed, in ISO-8601.
