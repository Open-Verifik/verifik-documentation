# The cost center object

```json
{
	"_id": "6acfbdda92451bac5d0a7ebe",
	"client": "69c2b824295cd7d276e478ad",
	"name": "Spain operations",
	"code": "SPAIN-OPS",
	"country": "ES",
	"active": true,
	"createdAt": "2026-10-14T17:37:30.469Z",
	"updatedAt": "2026-10-14T17:37:30.469Z"
}
```

| Field     | Type    | Description                                                                                         |
| --------- | ------- | --------------------------------------------------------------------------------------------------- |
| `name`    | string  | Display name, up to 120 characters.                                                                 |
| `code`    | string  | The value you send in `x-cost-center`. Letters, numbers, `.`, `-`, and `_`, up to 60 characters. Unique per account. |
| `country` | string  | ISO-2 country this cost center usually serves.                                                      |
| `active`  | boolean | Inactive cost centers keep their history but can't be assigned to new requests.                     |
