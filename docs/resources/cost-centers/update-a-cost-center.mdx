### Endpoint

**PUT** `https://api.verifik.co/v2/cost-centers/{id}`

Updates one cost center. Send only the fields you want to change. Requests already stamped keep the cost center they had.

#### headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### path parameters

#### `id`

**Type:** string  
**Required:** Yes

The cost center id.

#### body parameters

#### `name`

**Type:** string  
**Required:** No

Display name, up to 120 characters.

#### `code`

**Type:** string  
**Required:** No

New header value. Letters, numbers, `.`, `-`, and `_`, up to 60 characters. Unique per account.

#### `country`

**Type:** string  
**Required:** No

ISO-2 country code.

#### `active`

**Type:** boolean  
**Required:** No

Set `true` to reactivate a cost center, or `false` to stop assigning it to new requests.

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash

  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Spain operations","active":true}'
```

## Error Responses

Unknown id:

```json
{
  "message": "cost_center_not_found",
  "code": "NotFound"
}
```

A `code` that another cost center on the account already uses:

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```
