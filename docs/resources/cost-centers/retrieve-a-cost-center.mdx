### Endpoint

**GET** `https://api.verifik.co/v2/cost-centers/{id}`

Returns one cost center on your account, including its code, country, and whether it is active.

#### headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### path parameters

#### `id`

**Type:** string  
**Required:** Yes

The cost center id returned when you created it.

### Request Example

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl "https://api.verifik.co/v2/cost-centers/6acfbdda92451bac5d0a7ebe" \
  -H "Authorization: Bearer $VERIFIK_TOKEN"
```

</TabItem>
