### Endpoint

**GET** `https://api.verifik.co/v2/cost-centers`

Returns the cost centers on your account. Results are ordered by country, then by name.

#### headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### query parameters

#### `active`

**Type:** boolean  
**Required:** No

`true` returns active cost centers only. `false` returns inactive ones. Omit it to return both.

#### `country`

**Type:** string  
**Required:** No

ISO-2 country code, such as `ES`.

#### `page`

**Type:** number  
**Required:** No

Page number, starting at 1.

#### `limit`

**Type:** number  
**Required:** No

Items per page. Default 50, maximum 100.

## Error Responses

An invalid query, such as `limit` above 100 or a `country` that is not two letters:

```json
{
  "message": "\"limit\" must be less than or equal to 100",
  "code": "MissingParameter"
}
```
