Render a PDF for an existing `SmartReport` using either `"puppeteer"` or `"pdfkit"`, optionally compute `verificationScore`, and receive the base64-encoded PDF buffer alongside `downloadUrl` and `htmlUrl`.

On success, this endpoint marks the report `status: "generated"`, persists `verificationScoreSummary` when scoring is enabled, and emits the `smart_batch_report_generated` webhook. If PDF generation fails, the report is marked `status: "failed"` and the `smart_batch_report_generation_failed` webhook is emitted.

### Endpoint

```
POST https://api.verifik.co/v2/smart-reports/{id}/generate
```

This endpoint accepts JSON payloads up to **64 MB** (to accommodate custom `printHtml` documents). It is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-reports/{id}/generate` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format (64 MB limit).    |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | **Yes**  | `SmartReport` ObjectId. |

### Body

| Name           | Type    | Required | Description |
| -------------- | ------- | -------- | ----------- |
| `engine`       | string  | No       | PDF rendering engine: `"pdfkit"` or `"puppeteer"`. |
| `rowIndex`     | number  | No       | Zero-based row index from the linked `SmartBatch`. Defaults to row `0`. |
| `printHtml`    | string  | No       | Full HTML string (max `64000000` characters) used for non-themed templates containing `<html`. |
| `score`        | boolean | No       | Whether to calculate `verificationScore` and store `verificationScoreSummary` on the report. |
| `scoreProfile` | string  | No       | Scoring profile identifier used when `score` is enabled. Max `64` characters. |

#### Rendering and scoring behavior

- **Default row selection**: When `rowIndex` is omitted, generation defaults to row `0`. Requesting an out-of-range row returns `409 Conflict` (`row_not_found`).
- **Custom HTML (`printHtml`)**: When working with non-themed templates that provide full `<html` markup, pass `printHtml` (up to `64000000` characters).
- **Verification scoring**: Set `score: true` (and optionally `scoreProfile`) to compute `verificationScore`, return it at the top level of the response, and save `verificationScoreSummary` on the `SmartReport`. Unknown profiles fail with `409 Conflict` (`unknown_score_profile`).

#### Error codes

| Status | Error Code / Type | Cause |
| ------ | ----------------- | ----- |
| `401` | `Unauthorized` | Missing or invalid JWT. |
| `403` | `Forbidden` | Shared x402 execution was attempted; use your own per-client JWT. |
| `404` | `not_found` | Report ID does not exist or belongs to another client. |
| `404` | `template_not_found` | Linked template could not be found. |
| `404` | `batch_not_found` | Linked `SmartBatch` could not be found. |
| `409` | `MissingParameter` | Joi validation failed on one or more fields. |
| `409` | `row_not_found` | The requested `rowIndex` does not exist in the batch. |
| `409` | `unknown_score_profile` | The requested `scoreProfile` is not recognized. |
| `422` | `UnprocessableEntity` | Mongoose validation error. |
| `500` | `InternalServerError` | PDF rendering or internal processing failure (marks report `"failed"` and emits `smart_batch_report_generation_failed`). |

### Webhooks & MCP Integration

- **Webhooks**: Emits `smart_batch_report_generated` on successful PDF creation, or `smart_batch_report_generation_failed` if rendering errors occur (and updates `status` to `"failed"`). See [Smart Reports Webhooks](/resources/smart-reports-webhooks).
- **MCP Equivalent**: AI agents can render a report PDF directly via the `smart_report_generate_pdf` MCP tool. See [MCP and AI Agents](/smart-reports/mcp-and-ai-agents).

### Notes

- `pdf.buffer` contains the base64-encoded PDF bytes directly in the JSON response; if you prefer a binary PDF stream, call [Download Smart Report PDF](/smart-reports/download-smart-report-pdf).
- `verificationScore` is included in the response when `score` is enabled.
