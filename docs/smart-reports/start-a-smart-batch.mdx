Start execution on an existing `SmartBatch`. The batch must currently be in `"draft"`, `"pending"`, or `"cancelled"` status; any other status fails with `400 BadRequest` (`batch_not_in_startable_state`).

Before starting, the server validates that every enabled step in the linked `BatchConfiguration` is granted to your client account (`409 endpoints_not_in_account` if any feature is missing), sets `status: "processing"` and `startedAt`, and returns the updated `SmartBatch`.

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/{id}/start
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/{id}/start` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | Yes      | `SmartBatch` ObjectId to start. |

### Notes

- Only batches in `"draft"`, `"pending"`, or `"cancelled"` status can be started; paused batches must use [Resume a Smart Batch](/smart-reports/resume-a-smart-batch).
- Restarting a `"cancelled"` batch clears `completedAt` and resets any `"processing"` rows back to `"pending"`.
- Check projected credit charges beforehand using [Estimate Smart Batch cost](/smart-reports/estimate-smart-batch-cost) and monitor execution with [Get Smart Batch progress](/smart-reports/get-smart-batch-progress).
