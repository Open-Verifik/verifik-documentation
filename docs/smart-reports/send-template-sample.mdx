Render a saved Smart Report template (`{id}`) with `sampleData` and email the resulting PDF directly to one or more `recipients`. Optionally supply `printHtml` to bypass HTML generation or `pdfBase64` to attach a pre-rendered PDF buffer.

In headless CI/CD pipelines, template approval workflows, and AI agent automations, use this endpoint to distribute formatted report previews to compliance reviewers or product stakeholders without standing up your own email infrastructure. JSON request bodies up to `64MB` are accepted to accommodate embedded fonts, logos, pre-rendered HTML, or base64 PDFs.

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates/{id}/send-sample
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Content-Type  | `application/json`       |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Parameters

| Name | Type   | Required | Description                        |
| ---- | ------ | -------- | ---------------------------------- |
| `id` | string | Yes      | Smart Report template ObjectId.    |

### Body

Supports JSON payloads up to `64MB`.

| Name         | Type     | Required | Description                                                                                                                   |
| ------------ | -------- | -------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `recipients` | string[] | Yes      | Array of valid recipient email addresses (minimum `1`).                                                                       |
| `sampleData` | object   | Yes      | Sample payload containing `inputData`, `results`, `batchName`, and `rowIndex`.                                                |
| `subject`    | string   | No       | Custom email subject line. Defaults to `` `Sample Report: <name>` `` using the template's `name`.                             |
| `language`   | string   | No       | Email copy language: `"en"` or `"es"`. Defaults to `"es"`.                                                                    |
| `printHtml`  | string   | No       | Optional pre-rendered HTML document to convert to PDF instead of rendering from template `sections`.                          |
| `pdfBase64`  | string   | No       | Optional base64-encoded PDF attachment to send directly without server-side PDF generation.                                   |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func main() {
	id := "67c1f94b2d8a1c0012a4b301"
	body, _ := json.Marshal(map[string]interface{}{
		"recipients": []string{"compliance@acme.example"},
		"subject":    "Sample Report: Colombia Driver Onboarding",
		"language":   "en",
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding Sample",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{
					"fullName": "Mateo Rojas",
					"status":   "active",
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/"+id+"/send-sample", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notes

- Unlike other template endpoints that wrap payloads in `{ "data": ... }`, `send-sample` returns top-level `success`, `message`, `recipients`, `messageId`, and `delivery` fields.
- If `language` is omitted, the email defaults to `"es"`. Pass `"en"` for English stakeholder notifications.
- To save the rendered PDF locally instead of emailing it, use [Download template sample](/smart-reports/download-template-sample).
