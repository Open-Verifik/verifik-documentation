Re-enqueue rows in `"failed"` or `"partial"` status on a `SmartBatch` without affecting rows that already completed. Optionally pass `rowIndexes` to retry only a specific subset of rows; omit `rowIndexes` to retry every `"failed"` and `"partial"` row in the batch.

The request fails with `409 Conflict` (`batch_is_processing`) if the batch is currently in `"processing"` status. Returning `retried: 0` indicates no eligible failed or partial rows matched.

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/{id}/retry-failed
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/{id}/retry-failed` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | Yes      | `SmartBatch` ObjectId. |

### Body

| Name         | Type      | Required | Description |
| ------------ | --------- | -------- | ----------- |
| `rowIndexes` | integer[] | No       | Specific `0`-based row indexes (`>= 0`, maximum `10000` items) to retry. Omit to retry all `"failed"` and `"partial"` rows. |

Unknown body keys are rejected by Joi validation with `409 MissingParameter`.

### Notes

- Send `{}` (or omit `rowIndexes`) to retry all `"failed"` and `"partial"` rows at once.
- When `rowIndexes` is supplied, rows in `"completed"` or `"pending"` status are ignored even if their index is included.
- To re-run only specific step sequences on a single row while preserving results from other steps, use [Retry Smart Batch row steps](/smart-reports/retry-batch-row-steps).
