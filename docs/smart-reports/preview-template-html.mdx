Render any Smart Report template definition into a standalone HTML document completely in memory. No database record is created or updated, and Chromium is not launched during preview rendering, keeping response times fast for interactive template editors, CI verification checks, and AI design loops.

In headless and AI pipelines, use this endpoint to iterate on `sections`, `reportTheme`, margins, and verification score settings (`score`, `scoreProfile`, `scoreScale`) before persisting the template with [Create a report template](/smart-reports/create-a-report-template) or [Update a report template](/smart-reports/update-a-report-template). If you render a themed or scored template without providing `steps` or `results` inside `sampleData`, the renderer automatically injects synthetic driver sample data so your preview stays complete.

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates/preview-html
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Content-Type  | `application/json`       |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Body

This endpoint accepts preview/scoring helpers plus all public template design fields (`sections`, `reportTheme`, `sampleData`, `margins`, `pageSize`, `orientation`, `pdfEngine`, `primaryColor`, `identityColor`, `pageBackgroundColor`, `logo`, `header`, `footer`, `legend`, `termsAndConditions`, `watermark`, `showPageNumbers`, `customFonts`, etc.).

| Name            | Type            | Required | Description                                                                                                                                    |
| --------------- | --------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`          | string          | No       | Optional report title shown in the preview header/metadata.                                                                                    |
| `preview`       | boolean         | No       | Preview mode toggle. Defaults to `true`.                                                                                                       |
| `score`         | boolean         | No       | Enable verification score computation and include `verificationScore` in the response.                                                         |
| `scoreProfile`  | string          | No       | Score profile ID from [List score profiles](/smart-reports/list-score-profiles). Maximum `64` characters.                                      |
| `scoreScale`    | string          | No       | Score display scale: `"unit"` or `"percent"`. Top-level preview helper; save under `reportTheme.scoreScale` when persisting.                   |
| `themeTokens`   | object          | No       | Custom theme token overrides. Top-level preview helper; save under `reportTheme.tokens` when persisting.                                       |
| `scoreSettings` | object          | No       | Score presentation settings. Top-level preview helper; save under `reportTheme` (`scoreEnabled`, `scoreProfile`) when persisting.              |
| `sections`      | object[]        | No       | Array of `ReportSection` blocks to render.                                                                                                     |
| `reportTheme`   | string / object | No       | Theme preset ID (`"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"`) or full `reportTheme` configuration object.                  |
| `sampleData`    | object          | No       | Verification sample payload (`inputData`, `results`, `batchName`, `rowIndex`). If omitted on themed/scored previews, a synthetic driver sample is injected. |
| `pageSize`      | string          | No       | `"A4"`, `"Letter"`, or `"Legal"`. Defaults to `"A4"`.                                                                                          |
| `orientation`   | string          | No       | `"portrait"` or `"landscape"`. Defaults to `"portrait"`.                                                                                       |
| `margins`       | object          | No       | Margin object `` `{ "top": 40, "right": 40, "bottom": 40, "left": 40 }` ``.                                                                   |

import (

		"preview":      true,
		"score":        true,
		"scoreProfile": "cabify_driver",
		"scoreScale":   "percent",

		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/preview-html", bytes.NewReader(body))

### Notes

- `verificationScore` is included in `data` only when verification scoring is active (`score: true` or enabled in `reportTheme`).
- Because this endpoint renders purely in memory with no database write or Chromium launch, it is ideal for rapid layout iteration before calling [Download template sample](/smart-reports/download-template-sample) for final PDF pagination inspection.
- When persisting a previewed design via [Create a report template](/smart-reports/create-a-report-template) or [Update a report template](/smart-reports/update-a-report-template), place top-level preview helpers (`scoreScale`, `themeTokens`, `scoreSettings`) inside `reportTheme` (`reportTheme.scoreScale`, `reportTheme.tokens`, `reportTheme.scoreEnabled`/`reportTheme.scoreProfile`).
