Delete a custom Smart Report template owned by the authenticated client. The deleted template document is returned in `{ "data": ... }`.

In headless workflows and automated test pipelines, use this endpoint to clean up temporary templates or retire deprecated report designs. Built-in `"System"` templates cannot be deleted and return `403` (`system_template_readonly`). Deleting a template does not spend credits and does not remove previously generated `SmartBatch` reports.

### Endpoint

```
DELETE https://api.verifik.co/v2/smart-report-templates/{id}
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Parameters

| Name | Type   | Required | Description                        |
| ---- | ------ | -------- | ---------------------------------- |
| `id` | string | Yes      | Smart Report template ObjectId.    |

### Notes

- Built-in `"System"` templates cannot be deleted (`403` `system_template_readonly`).
- Once deleted, subsequent `GET`, `PUT`, or `DELETE` requests targeting the same `{id}` return `{ "data": null }` (on `GET`) or `404` `not_found` (on `PUT`/`DELETE`).
