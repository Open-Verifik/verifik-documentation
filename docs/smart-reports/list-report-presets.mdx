List curated system Smart Report presets available for your account. Each preset includes its `systemKey`, metadata (`country`, `category`, `tier`), account availability (`available`), ordered `presetSteps`, and a resolved `inputSchema` with `exampleInput` ready for headless execution or AI agents.

The resolved `inputSchema` automatically excludes internal execution parameters and step inputs already supplied through chained `visitaFlow` dependencies, leaving only the fields your caller needs to provide. Listing presets is a read-only discovery call and does not consume credits. This endpoint is also exposed as the `smart_report_list_presets` MCP tool.

### Endpoint

```
GET https://api.verifik.co/v2/smart-batch-presets
```

Also reachable via the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batch-presets` using your own per-client `Authorization: Bearer <VERIFIK_JWT>` header. Shared x402 execution is blocked on this route with `403 Forbidden`.

### Headers

| Name | Value |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

The token must be a **client JWT**. Missing or invalid credentials return `401 Unauthorized`.

### Parameters

All query parameters are optional. Combine them to narrow presets by jurisdiction, entity category, tier, or keyword.

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `country` | string | No | Country code filter. Trimmed and uppercased by the server (for example, `CO`). |
| `category` | string | No | Preset category filter. Allowed values: `citizen`, `company`, or `vehicle`. |
| `tier` | string | No | Preset depth filter. Allowed values: `essential` or `comprehensive`. |
| `search` | string | No | Case-insensitive regex match across `name`, `description`, and `systemKey`. |
| `text` | string | No | Alias for `search`. |

package main

import (
    "encoding/json"
    "fmt"
    "net/http"
    "net/url"
    "os"

func main() {
    u, _ := url.Parse("https://api.verifik.co/v2/smart-batch-presets")
    q := u.Query()
    q.Set("country", "CO")
    q.Set("category", "citizen")
    q.Set("tier", "essential")

    req, _ := http.NewRequest("GET", u.String(), nil)
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

    resp, _ := http.DefaultClient.Do(req)
    defer resp.Body.Close()

    var out map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&out)
    fmt.Println(out)
}

### Notes

- `country` is trimmed and uppercased before filtering (for example, `co` matches `CO`).
- `search` and `text` run the same case-insensitive regular-expression match against `name`, `description`, and `systemKey`.
- `inputSchema.estimatedCreditsPerRow` estimates the per-row credit cost across the preset's enabled steps.
- When `available` is `true`, all features in `presetSteps` are active for the environment and ready to clone with [Clone a report preset](/smart-reports/clone-a-report-preset).
- For AI agent integrations, this endpoint corresponds to the `smart_report_list_presets` MCP tool.
