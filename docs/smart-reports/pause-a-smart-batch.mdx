Pause an active `SmartBatch` (and any attached `FeatureRunner` run) without losing results already written for completed rows. Workers stop claiming remaining rows until you resume the batch.

Queue and browser batches must be in `"processing"` or `"pending"` status (`400 batch_not_pausable` otherwise). Batches backed by a `FeatureRunner` run require the run to be in `"queued"` or `"processing"` status (`400 run_not_pausable` otherwise). Pausing does not spend credits.

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/{id}/pause
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/{id}/pause` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | Yes      | `SmartBatch` ObjectId to pause. |

### Notes

- To pause a batch programmatically, always use this endpoint rather than `PUT /v2/smart-batches/{id}` (which does not accept `"paused"`).
- A `FeatureRunner`-backed batch returns `400 BadRequest` with `run_not_pausable` if its run is not in `"queued"` or `"processing"` status.
- Continue execution later using [Resume a Smart Batch](/smart-reports/resume-a-smart-batch), or terminate permanently with [Cancel a Smart Batch](/smart-reports/cancel-a-smart-batch).
