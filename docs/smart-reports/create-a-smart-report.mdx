Create a draft `SmartReport` record (`status: "draft"`) linked to an existing `template` and `smartBatch`. Use this endpoint when you already have a completed or ongoing `SmartBatch` and want to manage report creation, PDF generation, HTML retrieval, and email delivery as separate steps.

Creating a draft record returns HTTP **`200 OK`** with the new `SmartReport` in `{ data }`. It does not execute verification steps or render a PDF on its own — follow up with [Generate Smart Report PDF](/smart-reports/generate-smart-report-pdf) or [Send Smart Report by Email](/smart-reports/send-smart-report-email). If you want to execute verification steps and produce a report in one request, use [Run a Smart Report](/smart-reports/run-a-smart-report).

### Endpoint

```
POST https://api.verifik.co/v2/smart-reports
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-reports` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Body

| Name               | Type    | Required | Description |
| ------------------ | ------- | -------- | ----------- |
| `template`         | string  | **Yes**  | Template ObjectId to render this report against. |
| `smartBatch`       | string  | **Yes**  | `SmartBatch` ObjectId supplying verification row results. |
| `name`             | string  | No       | Display name for the report. Max `150` characters. |
| `externalRefId`    | string  | No       | Caller correlation identifier. Max `200` characters. |
| `webhookUrl`       | string  | No       | Per-report `http` or `https` webhook override URL. Max `2048` characters. |
| `rowIndex`         | integer | No       | Zero-based row index (`>= 0`) from the linked `SmartBatch`. |
| `createdByChannel` | string  | No       | Origin channel: `"portal"`, `"api"`, `"mcp"`, `"x402"`, or `"webhook"`. Default `"portal"`. |

#### Step-by-step workflow vs headless run

- Use `POST /v2/smart-reports` when your workflow already executed a `SmartBatch` (for example via SmartBatch UI or queue API) and you want to create a draft `SmartReport` (`status: "draft"`) first, preview HTML with [Retrieve Smart Report HTML](/smart-reports/retrieve-smart-report-html), render PDF with [Generate Smart Report PDF](/smart-reports/generate-smart-report-pdf), and deliver it with [Send Smart Report by Email](/smart-reports/send-smart-report-email).
- Note that `createdByChannel` defaults to `"portal"` on this route, so API integrations should set `createdByChannel: "api"` when tracking channel attribution.

### Webhooks & MCP Integration

- **Webhooks**: Storing `webhookUrl` and `externalRefId` on the draft `SmartReport` ensures subsequent generation (`smart_batch_report_generated`, `smart_batch_report_generation_failed`) and email delivery (`smart_batch_report_sent`, `smart_batch_report_delivery_failed`) calls inherit your per-report callback destination and correlation identifier. See [Smart Reports Webhooks](/resources/smart-reports-webhooks).
- **MCP Integration**: For single-call headless report execution in AI agents, use `smart_report_run`. See [MCP and AI Agents](/smart-reports/mcp-and-ai-agents).

### Notes

- Successful creation returns HTTP `200` (not `201`) with `status: "draft"`.
- Store `data._id` for subsequent calls to [Retrieve a Smart Report](/smart-reports/retrieve-a-smart-report), [Generate Smart Report PDF](/smart-reports/generate-smart-report-pdf), [Download Smart Report PDF](/smart-reports/download-smart-report-pdf), [Retrieve Smart Report HTML](/smart-reports/retrieve-smart-report-html), and [Send Smart Report by Email](/smart-reports/send-smart-report-email).
