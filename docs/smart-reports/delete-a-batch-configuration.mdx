Delete a `BatchConfiguration` owned by your client account. The endpoint removes the configuration document and returns the deleted document in `data`.

If `{id}` does not exist or belongs to another client account, the endpoint returns `404` (`not_found`). Deleting a configuration does not execute lookups and does not consume credits.

### Endpoint

```
DELETE https://api.verifik.co/v2/batch-configurations/{id}
```

Also reachable via the Smart-Agent proxy at `https://ai.verifik.co/v2/batch-configurations/{id}` using your own per-client `Authorization: Bearer <VERIFIK_JWT>` header. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name | Value |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

The token must be a **client JWT**. Missing or invalid credentials return `401 Unauthorized`.

### Parameters

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `id` | string | Yes | `BatchConfiguration` ObjectId to delete. |

### Notes

- Deleting a configuration returns the deleted document inside `data`. Subsequent `GET`, `PUT`, or `DELETE` requests using the same `{id}` will no longer find the record (`GET` returns `data: null`; `GET /input-schema`, `PUT`, and `DELETE` return `404` `not_found`).
- Deleting a configuration does not consume credits.
