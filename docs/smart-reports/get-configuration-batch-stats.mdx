Retrieve aggregate execution statistics across all `SmartBatch` records belonging to a specific `BatchConfiguration` on the authenticated client account. The response returns batch counts, row completion totals, and a per-status breakdown across `"draft"`, `"pending"`, `"processing"`, `"completed"`, `"failed"`, and `"cancelled"`.

Reading configuration stats does not run checks and does not spend credits.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/stats/{configId}
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/stats/{configId}` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name       | Type   | Required | Description |
| ---------- | ------ | -------- | ----------- |
| `configId` | string | Yes      | `BatchConfiguration` ObjectId to aggregate batch statistics for. |

### Notes

- Statistics are scoped to the authenticated client (`clientId` on your JWT).
- `pendingRows` is calculated as `totalRows - completedRows - failedRows - partialRows`.
- To inspect individual batches belonging to this configuration, pass `batchConfiguration` to [List Smart Batches](/smart-reports/list-smart-batches).
