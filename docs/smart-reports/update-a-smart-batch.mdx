Update fields on an existing `SmartBatch` owned by the authenticated client. You can update `name`, `status`, `executor`, or replace `rows`. When `rows` is supplied, the server recalculates `totalRows`, `completedRows`, `failedRows`, and `partialRows` and syncs external row snapshots.

Use the dedicated [Pause a Smart Batch](/smart-reports/pause-a-smart-batch) endpoint to transition a batch to `"paused"`. Changing `executor` only takes effect when the batch is currently in `"draft"`, `"pending"`, or `"cancelled"` status.

### Endpoint

```text
PUT https://api.verifik.co/v2/smart-batches/{id}
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/{id}` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | Yes      | `SmartBatch` ObjectId to update. |

### Body

| Name       | Type     | Required | Description |
| ---------- | -------- | -------- | ----------- |
| `name`     | string   | No       | Updated batch display name. Maximum `150` characters. |
| `status`   | string   | No       | Allowed values: `"draft"`, `"pending"`, `"processing"`, `"completed"`, `"failed"`, or `"cancelled"`. Use `POST /v2/smart-batches/{id}/pause` for `"paused"`. |
| `executor` | string   | No       | Allowed values: `"queue"`, `"featureRunner"`, or `"browser"`. Only takes effect when the current batch status is `"draft"`, `"pending"`, or `"cancelled"`. |
| `rows`     | object[] | No       | Replacement row list. Wrapped format requires `rowIndex` and `inputData` and optionally accepts `status`, `results`, `errors`, and `processedAt`; flat rows are normalized automatically. |

Unknown body keys are rejected by Joi validation with `409 MissingParameter`.

package main

import (

	body, _ := json.Marshal(map[string]interface{}{
		"name":     "Colombia Onboarding — Updated",
		"executor": "queue",

			{
				"rowIndex": 0,
				"inputData": map[string]string{

				},
				"status": "pending",
			},
		},
	})

	req, _ := http.NewRequest("PUT", "https://api.verifik.co/v2/smart-batches/"+batchID, bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notes

- `"paused"` is not accepted in `PUT /v2/smart-batches/{id}`; call [Pause a Smart Batch](/smart-reports/pause-a-smart-batch) instead.
- Updating `executor` is ignored unless the batch is currently in `"draft"`, `"pending"`, or `"cancelled"` status.
- To add new rows onto an existing batch without replacing existing ones, use [Append rows to a Smart Batch](/smart-reports/append-smart-batch-rows).
