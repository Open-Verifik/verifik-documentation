List Verifik catalog endpoints that have prebuilt sandbox simulated responses in the template-design inventory. Filter by `country` or search query (`q`) to discover endpoint `code` identifiers and expected `inputs`.

In headless report builders and AI agent pipelines, use this catalog discovery endpoint to select realistic mock datasets without running live billable queries or handling production PII. Pass any returned `code` to [Retrieve a simulated response](/smart-reports/retrieve-simulated-response) to obtain sample payloads for [Introspect sample data](/smart-reports/introspect-sample-data), [Generate template layout](/smart-reports/generate-template-layout), or [Preview template HTML](/smart-reports/preview-template-html).

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Parameters

| Name      | Type   | Required | Description                                                |
| --------- | ------ | -------- | ---------------------------------------------------------- |
| `country` | string | No       | Filter simulated endpoints by country.                     |
| `q`       | string | No       | Search string to filter endpoints by name, code, or metadata. |

### Notes

- Querying simulated responses does not run live catalog lookups and does not spend credits.
- Use each item's `code` with [Retrieve a simulated response](/smart-reports/retrieve-simulated-response) to fetch full `dataSample` and `emptySample` payloads.
