Calculate a pre-flight credit estimate for all non-terminal rows remaining on a `SmartBatch`. The response breaks down pricing per enabled step in the batch's `BatchConfiguration` and compares the projected cost against your client account's available credit balance.

Calling this endpoint performs no catalog lookups and spends zero credits.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/{id}/estimate
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/{id}/estimate` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | Yes      | `SmartBatch` ObjectId to estimate. |

### Notes

- `itemCount` and `pendingRows` reflect only rows not yet in a terminal row status (`completed`, `failed`, or `partial`).
- `availableCredits` combines your client account's `credits` and `extraCredits`; when `sufficientCredits` is `false`, `shortfall` indicates the additional credits needed.
- Per-step pricing uses your client account's `ClientFeature` snapshot pricing where applicable.
