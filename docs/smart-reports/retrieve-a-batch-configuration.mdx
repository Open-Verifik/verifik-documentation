Retrieve a single `BatchConfiguration` by its ObjectId (`{id}`). The lookup is scoped to the authenticated client JWT and returns populated `steps.appFeature` details enriched with your account's `ClientFeature` prices.

If no matching configuration exists or the ID belongs to another client account, the endpoint returns HTTP `200` with `data: null`. Reading a configuration does not run lookups and does not consume credits.

### Endpoint

```
GET https://api.verifik.co/v2/batch-configurations/{id}
```

Also reachable via the Smart-Agent proxy at `https://ai.verifik.co/v2/batch-configurations/{id}` using your own per-client `Authorization: Bearer <VERIFIK_JWT>` header. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name | Value |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

The token must be a **client JWT**. Missing or invalid credentials return `401 Unauthorized`.

### Parameters

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `id` | string | Yes | `BatchConfiguration` ObjectId from create, clone, or list. |

### Notes

- If `{id}` does not exist or belongs to another client account, this endpoint returns HTTP `200` with `{ "data": null }`.
- Check `data !== null` in your integration before reading properties from `data`.
- To inspect resolved required/optional inputs and an `exampleInput` payload for a configuration, call [Retrieve configuration input schema](/smart-reports/retrieve-configuration-input-schema).
