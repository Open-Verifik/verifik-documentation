List the `SmartBatch` records belonging to the authenticated client account. Results default to newest first (`-createdAt`) and exclude the `rows` array unless you explicitly pass `includeRows=true`, keeping list responses compact.

Send `page` to enable paginated output with `total`, `limit`, `page`, and `pages` metadata. Omit `page` to receive `{ data }` containing the matching batch array without pagination fields. Listing batches does not run checks and does not spend credits.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name                 | Type    | Required | Description |
| -------------------- | ------- | -------- | ----------- |
| `batchConfiguration` | string  | No       | Filter batches by `BatchConfiguration` ObjectId. |
| `status`             | string  | No       | Filter by batch status: `"draft"`, `"pending"`, `"processing"`, `"paused"`, `"completed"`, `"failed"`, or `"cancelled"`. |
| `page`               | number  | No       | Page number (`>= 1`). Enables pagination and adds `total`, `limit`, `page`, and `pages` to the response. |
| `limit`              | number  | No       | Maximum items per response (`1` to `200`). |
| `perPage`            | number  | No       | Page size (`1` to `200`) when `page` is set. Defaults to `20`. |
| `includeRows`        | boolean | No       | Set `true` to include `rows` on each returned batch. When omitted or `false`, `rows` is excluded. |
| `search`             | string  | No       | Case-insensitive regex search on batch `name`. |
| `sort`               | string  | No       | Sort field and direction. Defaults to `"-createdAt"`. |
| `sortBy`             | string  | No       | Sort field name when paired with `sortOrder`. |
| `sortOrder`          | string  | No       | Sort direction for `sortBy`: `"asc"` or `"desc"`. |

Unknown query parameters are rejected by Joi validation with `409 MissingParameter`.

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	params := url.Values{}
	params.Set("status", "processing")
	params.Set("page", "1")
	params.Set("perPage", "20")
	params.Set("search", "Colombia")
	params.Set("sort", "-createdAt")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-batches?"+params.Encode(), nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notes

- Results are scoped to the authenticated client (`clientId` on your JWT).
- Leaving `includeRows` omitted or `false` keeps list responses small; fetch full `rows` for one batch using [Retrieve a Smart Batch](/smart-reports/retrieve-a-smart-batch).
- Invalid query values or unknown query keys fail Joi validation with `409 MissingParameter`.
- When `page` is provided (`>= 1`), `perPage` defaults to `20` and supports `1` through `200`.
