Clear and re-queue only specific `sequences` on a single row (`rowIndex`) of a `SmartBatch`, leaving every other step's stored output and every other row untouched. Both `rowIndex` and `sequences` are required.

The server rejects the request with `409 Conflict` if the batch, target row, underlying `FeatureRunner` run, or run item is currently processing (`batch_is_processing`, `row_is_processing`, `run_is_processing`, `item_is_processing`).

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/{id}/retry-steps
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/{id}/retry-steps` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | Yes      | `SmartBatch` ObjectId. |

### Body

| Name        | Type      | Required | Description |
| ----------- | --------- | -------- | ----------- |
| `rowIndex`  | integer   | Yes      | `0`-based index (`>= 0`) of the row to partially retry. |
| `sequences` | integer[] | Yes      | Step sequence numbers (`>= 0`, minimum `1`, maximum `200` items) to clear and re-execute on that row. |

Unknown body keys or missing required fields are rejected by Joi validation with `409 MissingParameter`.

### Notes

- Stored `results` and `errors` are cleared only for the specified `sequences` on `rowIndex`; outcomes for all other step sequences remain intact.
- Possible `409 Conflict` reasons are `batch_is_processing`, `row_is_processing`, `run_is_processing`, and `item_is_processing`.
- Passing invalid or empty step sequence references returns `400 BadRequest` (`retry_steps_invalid`).
- To retry entire failed or partial rows across the batch, use [Retry failed Smart Batch rows](/smart-reports/retry-failed-batch-rows).
