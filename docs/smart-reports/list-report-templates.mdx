List the Smart Report templates available to the authenticated client. By default, this endpoint returns both your client-owned custom templates and Verifik's built-in `"System"` templates so you can discover reusable template IDs (`_id`), inspect layout and theme configurations, and pick a template before triggering `SmartBatch` runs or sample renders.

In headless verification pipelines and AI agent workflows, call this endpoint first to locate an existing template bound to a `batchConfiguration`, filter built-in `"System"` templates by `country`, `category`, or `tier`, or verify whether a custom template is active before cloning or updating it. Listing templates does not render PDFs or spend credits.

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

Responses populate `batchConfiguration` and `client` and select `+thumbnail.image` so dashboards and headless previews can inspect template thumbnails without an extra request.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Parameters

All query parameters are optional.

| Name                 | Type    | Required | Description                                                                                                                                      |
| -------------------- | ------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `batchConfiguration` | string  | No       | Filter templates linked to a specific `SmartBatch` configuration ObjectId.                                                                       |
| `type`               | string  | No       | Filter by origin: `"client"` or `"System"`. When omitted, returns your client's own templates alongside built-in `"System"` templates.           |
| `country`            | string  | No       | Country filter. Automatically uppercased on the server (for example `CO`, `MX`, or `COLOMBIA`).                                                  |
| `category`           | string  | No       | Domain category filter: `"citizen"`, `"company"`, or `"vehicle"`.                                                                                |
| `tier`               | string  | No       | Template tier filter: `"essential"` or `"comprehensive"`.                                                                                        |
| `isActive`           | boolean | No       | Filter by active state (`true` or `false`).                                                                                                      |
| `search`             | string  | No       | Case-insensitive regex search against `name` and `systemKey`. When `search` is sent without `type`, it matches across both your templates and `"System"` templates. |
| `page`               | integer | No       | Page number (1-based). Both `page` and `limit` must be provided together to enable pagination in this module.                                    |
| `limit`              | integer | No       | Page size. Must be provided together with `page` to paginate results.                                                                            |
| `sort`               | string  | No       | Sort specification. Defaults to `type: 1, createdAt: -1` (ordering by template type and newest first).                                           |

### Notes

- Both `page` and `limit` must be supplied together to paginate results. Sending only one parameter without the other does not trigger pagination.
- Built-in `"System"` templates returned in the list are read-only. Attempting to modify or delete them returns `403` (`system_template_readonly`). To customize a starter, pass its layout into [Create a report template](/smart-reports/create-a-report-template).
- Use [List theme starters](/smart-reports/list-theme-starters) when you want clean starter blueprints grouped by `reportTheme`.
