Resolve the exact input contract for a saved `BatchConfiguration` before submitting rows. This endpoint returns `preferredReportTemplate` (falling back to the latest active `SmartReportTemplate` linked to the configuration), `webhookUrl`, `stepCount`, `estimatedCreditsPerRow`, `requiredFields`, `optionalFields`, a standard `jsonSchema`, and a ready-to-send `exampleInput` payload.

The resolver automatically skips disabled steps, inactive `dependencyGroup` options, internal flags, and fields already supplied through `parameterDefaults` or `visitaFlow` step chaining (`{{results.N.field}}`), while remapping column names according to `inputFieldMapping`. This route is registered before `/{id}` so `/input-schema` resolves directly, and it is also available as the `smart_report_get_input_schema` MCP tool.

### Endpoint

```
GET https://api.verifik.co/v2/batch-configurations/{id}/input-schema
```

Also reachable via the Smart-Agent proxy at `https://ai.verifik.co/v2/batch-configurations/{id}/input-schema` using your own per-client `Authorization: Bearer <VERIFIK_JWT>` header. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name | Value |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

The token must be a **client JWT**. Missing or invalid credentials return `401 Unauthorized`.

### Parameters

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `id` | string | Yes | `BatchConfiguration` ObjectId to inspect. |

### Notes

- Inspecting the input schema does not run lookups and does not consume credits.
- If `preferredReportTemplate` is unset on the configuration, the server falls back to the latest active `SmartReportTemplate` linked to `{id}` (or `null` if none exists).
- When `inputFieldMapping` maps an input column to an API parameter, `requiredFields`, `optionalFields`, `jsonSchema`, and `exampleInput` expose the mapped input column name rather than the raw API parameter name.
- Missing or cross-client `{id}` values return `404` (`not_found`), unlike [Retrieve a batch configuration](/smart-reports/retrieve-a-batch-configuration) which returns `200` with `data: null`.
- For AI agents and headless pipelines, this endpoint corresponds to the `smart_report_get_input_schema` MCP tool.
