Retrieve Verifik's built-in themed starter templates, optionally filtered by `theme`. Each starter includes preconfigured `sections`, `reportTheme`, `sampleData`, page layout properties, and colors so you can launch production-grade report designs without assembling section trees from scratch.

In headless onboarding flows and AI agents, call this endpoint to pick a curated visual starting point, preview it immediately via [Preview template HTML](/smart-reports/preview-template-html), customize brand colors or logos, and save your own editable template via [Create a report template](/smart-reports/create-a-report-template).

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/theme-starters
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Parameters

| Name    | Type   | Required | Description                                                                                                                                                     |
| ------- | ------ | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `theme` | string | No       | Optional theme filter: `"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"`, or `"smart_enroll_v2"` (aliases `"light_cards"`; using canonical `"light_cards"` is recommended). |

### Notes

- `"smart_enroll_v2"` is accepted as an alias for `"light_cards"`, though filtering by the canonical theme ID `"light_cards"` is recommended.
- Starter items returned here carry `type: "System"` for reference. When saving a customized copy via [Create a report template](/smart-reports/create-a-report-template), send only your `name` and design fields (`sections`, `reportTheme`, `sampleData`, colors, and PDF settings).
