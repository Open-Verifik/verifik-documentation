Inspect a `sampleData` verification payload and receive a structured map of field paths, value shapes, recommended `sectionType` choices, alternative section types, suggested table columns, and binding suggestions.

In headless report authoring and AI agent pipelines, call this endpoint right after fetching a payload from [Retrieve a simulated response](/smart-reports/retrieve-simulated-response) or capturing a `SmartBatch` row. Instead of guessing `dataPath` strings or writing brittle JSON traversal logic, your UI or agent can use the introspected `nodes` and `batch` metadata to build valid `sections` directly or enrich `prompt` context for [Generate template layout](/smart-reports/generate-template-layout). The walker inspects up to depth `5` and up to `600` nodes.

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates/introspect
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Content-Type  | `application/json`       |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Body

| Name         | Type   | Required | Description                                                                                                                   |
| ------------ | ------ | -------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `sampleData` | object | Yes      | Sample verification payload with optional `batchName` (string), `rowIndex` (number), `inputData` (object), and `results` (object). |

package main

import (

			"rowIndex":  0,
			"inputData": map[string]interface{}{

			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/introspect", bytes.NewReader(body))

### Notes

- Traversal stops at depth `5` and caps at `600` nodes. When a very large payload hits the limit, `truncated` is `true`.
- This endpoint is read-only and stateless; it does not save a template or spend verification credits.
