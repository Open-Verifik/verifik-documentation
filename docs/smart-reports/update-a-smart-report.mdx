Update an existing `SmartReport` belonging to the authenticated client. Send only the fields you want to modify; fields omitted from the request remain unchanged.

If the report ID does not exist or belongs to another client, the endpoint returns `404 Not Found` (`{ "message": "not_found", "code": "NotFound" }`).

### Endpoint

```
PUT https://api.verifik.co/v2/smart-reports/{id}
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-reports/{id}` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | **Yes**  | `SmartReport` ObjectId to update. |

### Body

All body fields are optional; provide only the attributes you want to update.

| Name                       | Type   | Required | Description |
| -------------------------- | ------ | -------- | ----------- |
| `name`                     | string | No       | Display name for the report. |
| `status`                   | string | No       | Report status: `"draft"`, `"generating"`, `"generated"`, `"sent"`, or `"failed"`. |
| `pdfUrl`                   | string | No       | Stored URL for the generated PDF artifact. |
| `pdfSize`                  | number | No       | Size of the generated PDF in bytes. |
| `htmlSnapshot`             | string | No       | Saved HTML snapshot of the rendered report. |
| `pageCount`                | number | No       | Page count of the generated PDF. |
| `pdfEngine`                | string | No       | Rendering engine: `"pdfkit"` or `"puppeteer"`. |
| `generatedAt`              | string | No       | ISO 8601 timestamp when the report was generated. |
| `generationDurationMs`     | number | No       | PDF generation duration in milliseconds. |
| `dataSnapshot`             | object | No       | Snapshot of row or input data used for the report. |
| `externalRefId`            | string | No       | Caller correlation identifier. |
| `webhookUrl`               | string | No       | Per-report `http` or `https` webhook override URL. |
| `rowIndex`                 | number | No       | Zero-based row index associated with this report. |
| `createdByChannel`         | string | No       | Origin channel: `"portal"`, `"api"`, `"mcp"`, `"x402"`, or `"webhook"`. |
| `verificationScoreSummary` | object | No       | Summary metadata from verification scoring. |
| `error`                    | object or string | No | Error payload or message recorded for failed states. |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"

func main() {
	id := "6801a2b3c4d5e6f7a8b9c0d1"
	body, _ := json.Marshal(map[string]interface{}{
		"name":          "Background Check - Applicant 42 (Reviewed)",
		"externalRefId": "applicant-42-v2",

	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Webhooks & MCP Integration

- Updating `webhookUrl` or `externalRefId` updates the target callback URL and correlation ID used by subsequent [Generate Smart Report PDF](/smart-reports/generate-smart-report-pdf) and [Send Smart Report by Email](/smart-reports/send-smart-report-email) calls. See [Smart Reports Webhooks](/resources/smart-reports-webhooks).
- To inspect the updated record or run headless report operations via an AI agent, see [MCP and AI Agents](/smart-reports/mcp-and-ai-agents).

### Notes

- Updating a `SmartReport` only updates stored report fields; it does not automatically regenerate a PDF or dispatch emails. Call [Generate Smart Report PDF](/smart-reports/generate-smart-report-pdf) or [Send Smart Report by Email](/smart-reports/send-smart-report-email) when you want to re-render or deliver.
