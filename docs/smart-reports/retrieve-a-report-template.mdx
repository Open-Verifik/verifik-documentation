Retrieve a single Smart Report template by its ObjectId (`{id}`). This returns the full template specification, including `sections`, `reportTheme`, `sampleData`, page layout settings, and populated `batchConfiguration` and `client` references.

In headless and AI workflows, use this endpoint to load the current `sections` array before calling [Generate template layout](/smart-reports/generate-template-layout) in `append` or `edit` mode, to fetch stored `sampleData` for [Preview template HTML](/smart-reports/preview-template-html), or to inspect a template prior to running a `PUT` update. For security and payload size efficiency, `security.password` and `thumbnail.image` are deselected on this endpoint.

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/{id}
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Parameters

| Name | Type   | Required | Description                        |
| ---- | ------ | -------- | ---------------------------------- |
| `id` | string | Yes      | Smart Report template ObjectId.    |

### Notes

- When the template does not exist or belongs to another client, this endpoint returns HTTP `200` with `{ "data": null }` rather than `404`.
- `security.password` and `thumbnail.image` are excluded from the returned document. To render or inspect the template thumbnail, use [List report templates](/smart-reports/list-report-templates).
