List the `SmartReport` records belonging to the authenticated client. Results populate `template`, `smartBatch`, and `client`, and can be filtered by `smartBatch`, `template`, `externalRefId`, and `createdByChannel`, with optional pagination and sorting.

When you pass `page`, the response includes pagination metadata (`total`, `limit`, `page`, and `pages`). Omit `page` to receive the matching list inside `{ data: [...] }` without pagination metadata.

### Endpoint

```
GET https://api.verifik.co/v2/smart-reports
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-reports` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name               | Type   | Required | Description |
| ------------------ | ------ | -------- | ----------- |
| `smartBatch`       | string | No       | Filter reports linked to a specific `SmartBatch` ObjectId. |
| `template`         | string | No       | Filter reports linked to a specific template ObjectId. |
| `status`           | string | No       | Allowed values: `"draft"`, `"pending"`, `"generating"`, `"generated"`, `"failed"`, `"sent"`. Accepted by Joi validation for forward compatibility; current list filtering operates on `smartBatch`, `template`, `externalRefId`, and `createdByChannel`. |
| `externalRefId`    | string | No       | Filter by your external correlation identifier. Max `200` characters. |
| `createdByChannel` | string | No       | Filter by origin channel: `"portal"`, `"api"`, `"mcp"`, `"x402"`, or `"webhook"`. |
| `page`             | number | No       | Page number to retrieve. Providing `page` enables paginated output with `total`, `limit`, `page`, and `pages`. |
| `limit`            | number | No       | Maximum number of items per page. Defaults to `20` when `page` is set. |
| `sort`             | string | No       | Sort field and direction. Defaults to `"-updatedAt"` when `page` is set. |

#### Filtering and pagination notes

- **Forward-compatible `status` parameter**: Joi validates `status` against `"draft"`, `"pending"`, `"generating"`, `"generated"`, `"failed"`, and `"sent"`, while the underlying list query currently filters by `smartBatch`, `template`, `externalRefId`, and `createdByChannel`.
- **Two `200` response shapes**: Send `page` whenever your dashboard or sync job needs `total` and `pages`; omit `page` for a simpler `{ data: [...] }` payload.

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	params := url.Values{}
	params.Set("createdByChannel", "api")
	params.Set("externalRefId", "applicant-42")
	params.Set("page", "1")
	params.Set("limit", "20")
	params.Set("sort", "-updatedAt")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-reports?"+params.Encode(), nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notes

- `GET /v2/smart-reports` populates `template`, `smartBatch`, and `client` on each returned `SmartReport`.
- Invalid query parameter values fail Joi validation with `409 MissingParameter`.
- To inspect a single report with ready-to-use `downloadUrl` and `htmlUrl` fields, use [Retrieve a Smart Report](/smart-reports/retrieve-a-smart-report).
- To execute a new report end-to-end without managing `SmartBatch` and `SmartReport` records separately, use [Run a Smart Report](/smart-reports/run-a-smart-report).
