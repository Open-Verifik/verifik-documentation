Resume a paused `SmartBatch` (and any underlying `FeatureRunner` run). The server verifies that your client account still holds feature grants for all configured steps (`409 endpoints_not_in_account` if any endpoint access was revoked), checks that the batch is in `"paused"` status, and transitions it back to `"processing"`.

If the batch is not currently `"paused"`, the request fails with `400 BadRequest` (`batch_not_paused`, or `run_not_paused` when an underlying `FeatureRunner` run is not paused).

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/{id}/resume
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/{id}/resume` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | Yes      | `SmartBatch` ObjectId to resume. |

### Notes

- Resuming re-validates client feature grants and rejects the request with `409 endpoints_not_in_account` if any step endpoint is no longer enabled on your account.
- Completed rows keep their stored results and are not re-executed or double-charged on resume.
- If the batch was `"draft"`, `"pending"`, or `"cancelled"`, use [Start a Smart Batch](/smart-reports/start-a-smart-batch) instead.
