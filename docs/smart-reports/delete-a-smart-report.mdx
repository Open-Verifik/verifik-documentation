Delete a `SmartReport` record belonging to the authenticated client. On success, the API returns the removed `SmartReport` document inside `{ "data": ... }`.

If the report ID is missing or belongs to a different client, the endpoint returns `404 Not Found` (`{ "message": "not_found", "code": "NotFound" }`). Deleting a report removes the `SmartReport` document without deleting the underlying `SmartBatch` verification data.

### Endpoint

```
DELETE https://api.verifik.co/v2/smart-reports/{id}
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-reports/{id}` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | **Yes**  | `SmartReport` ObjectId to delete. |

### Notes

- Subsequent `GET /v2/smart-reports/{id}` calls return `{ "data": null }`, while `PUT`, `DELETE`, `/generate`, `/download`, `/html`, and `/send-email` return `404` (`not_found`).
- Deleting a `SmartReport` does not emit report delivery or generation webhooks; see [Smart Reports Webhooks](/resources/smart-reports-webhooks) and [MCP and AI Agents](/smart-reports/mcp-and-ai-agents) for lifecycle automation details.
