Deliver a `SmartReport` by email with attached PDF reports. You can let Verifik render the PDF for a single row (`rowIndex`) or all rows (`sendAll: true`, up to `50` rows), or supply pre-rendered `printHtml`, `pdfBase64`, or `pdfFiles` payloads.

Sending an email records `emailDelivery` on the `SmartReport` document and emits either `smart_batch_report_sent` on success or `smart_batch_report_delivery_failed` on delivery failure.

### Endpoint

```
POST https://api.verifik.co/v2/smart-reports/{id}/send-email
```

This endpoint accepts JSON payloads up to **64 MB**. It is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-reports/{id}/send-email` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format (64 MB limit).    |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | **Yes**  | `SmartReport` ObjectId. |

### Body

| Name         | Type     | Required | Description |
| ------------ | -------- | -------- | ----------- |
| `recipients` | string[] | **Yes**  | Array of valid recipient email addresses (minimum `1`). |
| `subject`    | string   | No       | Custom email subject line. |
| `language`   | string   | No       | Email copy language: `"en"` or `"es"`. Default `"es"`. |
| `rowIndex`   | number   | No       | Zero-based row index to render and attach when `sendAll` is not enabled. |
| `sendAll`    | boolean  | No       | When `true`, sends up to `50` rows (`MAX_SEND_ALL_ROWS`), attaching 1 PDF per row when the batch has more than 1 row. |
| `engine`     | string   | No       | PDF rendering engine: `"pdfkit"` or `"puppeteer"`. |
| `printHtml`  | string   | No       | Pre-rendered HTML string (max `64000000` characters) to convert and attach. |
| `pdfBase64`  | string   | No       | Pre-rendered base64-encoded PDF string (max `64000000` characters) to attach directly. |
| `pdfFiles`   | object[] | No       | Array of up to `200` attachment objects (`{ filename, pdfBase64 }`), where each `filename` (max `80` characters) and `pdfBase64` (max `64000000` characters) are required. |

#### Attachment and batch delivery rules

- **`sendAll` cap**: Sending all rows in a batch supports up to `50` rows (`MAX_SEND_ALL_ROWS`). Exceeding 50 rows fails with `409 Conflict` (`send_all_limit`). When a batch contains more than 1 row, each row is attached as its own PDF file.
- **Pre-rendered payloads**: Supply `pdfFiles` (up to `200` items), `pdfBase64`, or `printHtml` when your integration already rendered custom attachments. Corrupt PDF data returns `500` (`invalid_pdf`), and requests resolving to zero attachments return `409 Conflict` (`no_pdf_attachments`).
- **Delivery outcome response**: If the email transport fails after validation and PDF preparation succeed, the endpoint returns HTTP `200 OK` with `"success": false`, `"messageId": null`, and an `"error"` field while recording `emailDelivery` and emitting `smart_batch_report_delivery_failed`.

#### Error codes

| Status | Error Code / Type | Cause |
| ------ | ----------------- | ----- |
| `401` | `Unauthorized` | Missing or invalid JWT. |
| `403` | `Forbidden` | Shared x402 execution was attempted; use your own per-client JWT. |
| `404` | `not_found` | Report ID does not exist or belongs to another client. |
| `404` | `template_not_found` | Linked template could not be found. |
| `409` | `MissingParameter` | Joi validation failed (for example, missing or invalid `recipients`). |
| `409` | `send_all_limit` | `sendAll: true` was requested on a batch with more than `50` rows (`MAX_SEND_ALL_ROWS`). |
| `409` | `no_pdf_attachments` | No PDF attachments could be resolved or rendered for the request. |
| `409` | `row_not_found` | The requested `rowIndex` does not exist in the batch. |
| `422` | `UnprocessableEntity` | Mongoose validation error. |
| `500` | `invalid_pdf` | Supplied `pdfBase64` or `pdfFiles` payload is not a valid PDF. |

### Webhooks & MCP Integration

- **Webhooks**: Automatically emits `smart_batch_report_sent` when delivery succeeds or `smart_batch_report_delivery_failed` when delivery fails, and records `emailDelivery` on the `SmartReport`. See [Smart Reports Webhooks](/resources/smart-reports-webhooks).
- **MCP Equivalent**: AI agents can send report emails via the `smart_report_send_email` MCP tool. See [MCP and AI Agents](/smart-reports/mcp-and-ai-agents).

### Notes

- Always inspect `success` in the `200 OK` body, because email transport errors return `success: false` with `messageId: null` and `error` rather than a non-200 status code.
- If you want to run verification steps, generate PDFs, and send email in one call, use [Run a Smart Report](/smart-reports/run-a-smart-report).
