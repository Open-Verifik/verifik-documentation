List all supported verification score profiles that can be attached to a Smart Report template (`reportTheme.scoreProfile`) or passed to [Preview template HTML](/smart-reports/preview-template-html) (`scoreProfile`).

In headless configuration UIs and AI agent workflows, query this endpoint before enabling scoring so your application validates `scoreProfile` identifiers dynamically and avoids `409` (`unknown_score_profile`) errors during HTML preview or report rendering. Available profiles cover driver, identity, business, fleet, vehicle, lending, healthcare, and biometric workflows:

- `cabify_driver`
- `kyc`
- `kyb`
- `fleet`
- `vehicle_purchase`
- `identity_lookup`
- `background_check`
- `lending`
- `healthcare_professional`
- `biometrics`

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/score-profiles
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Parameters

No query or path parameters are required.

### Notes

- Use the returned `id` value in `reportTheme.scoreProfile` when creating or updating a template, or as `scoreProfile` on [Preview template HTML](/smart-reports/preview-template-html).
- Sending an unrecognized `scoreProfile` to `POST /v2/smart-report-templates/preview-html` returns `409` (`unknown_score_profile`).
