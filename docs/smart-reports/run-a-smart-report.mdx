Execute a complete verification and report pipeline in a single request. `POST /v2/smart-reports/run` is the primary **headless all-in-one execution endpoint** for Reports: it resolves a preset (`systemKey`) or an existing `BatchConfiguration` (`batchConfigurationId`), validates your inputs against the configuration input schema, verifies account feature grants, runs every verification step in `FeatureRunner`, creates both the `SmartBatch` (`headlessRun: true`) and the `SmartReport`, optionally computes `verificationScore`, renders PDF/HTML output, optionally sends emails, and dispatches webhooks.

For smaller runs (up to 5 rows), execution defaults to synchronous (`mode: "sync"`) and returns `200 OK` once settled within the 90-second sync window. Larger batches or runs that exceed the 90-second sync deadline automatically switch to asynchronous execution and return `202 Accepted` with polling and download URLs.

### Endpoint

```
POST https://api.verifik.co/v2/smart-reports/run
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-reports/run` when authenticating with your own per-client `Authorization: Bearer <VERIFIK_JWT>` header. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                                                      |
| --------------- | ---------------------- | ---------------------------------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                                          |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`).                         |

A client-scoped JWT (`authUser.clientId`) is required. Tokens missing `clientId` return `409 Conflict` (`client_context_required`). Missing or invalid JWTs return `401 Unauthorized`.

### Body

| Name                   | Type                                     | Required    | Description |
| ---------------------- | ---------------------------------------- | ----------- | ----------- |
| `systemKey`            | string                                   | Conditional | Preset identifier. Trimmed, max `120` characters, pattern `/^[a-z0-9][a-z0-9._-]{1,118}$/i`. At least one of `systemKey` or `batchConfigurationId` is required. |
| `batchConfigurationId` | string                                   | Conditional | Existing `BatchConfiguration` ObjectId. At least one of `systemKey` or `batchConfigurationId` is required. |
| `templateId`           | string                                   | No          | Report template ObjectId. Overrides the preferred template on the configuration or preset. |
| `name`                 | string                                   | No          | Custom display name for the generated report and batch. Max `150` characters. |
| `inputs`               | object or object[]                       | Conditional | Single input object or array of input objects (`min 1`, `max 500`). At least one of `inputs` or `rows` is required; `inputs` takes precedence if both are sent. |
| `rows`                 | object[]                                 | Conditional | Array of `1` to `500` row entries, formatted either as flat objects (`{ ... }`) or structured row objects (`{ rowIndex, inputData }`). At least one of `inputs` or `rows` is required. |
| `mode`                 | string                                   | No          | `"sync"` or `"async"`. Defaults to `"sync"` when row count is `<= 5`, and `"async"` when row count is `> 5`. Passing `mode: "sync"` with `> 5` rows returns `409 Conflict` (`sync_row_limit_exceeded`). |
| `generatePdf`          | boolean                                  | No          | Whether to render a PDF during the run. Default `true`. Note: if `emailTo` is provided, a PDF is rendered even when `generatePdf` is `false`. |
| `includePdfBase64`     | boolean                                  | No          | Whether to include the base64-encoded PDF in `data.pdf.buffer`. Default `false`. |
| `pdfEngine`            | string                                   | No          | PDF rendering engine: `"puppeteer"` or `"pdfkit"`. Defaults to the template setting or `"puppeteer"`. |
| `score`                | boolean                                  | No          | Whether to calculate and attach `verificationScore`. |
| `scoreProfile`         | string                                   | No          | Scoring profile identifier used when `score` is enabled. Max `64` characters. |
| `rowIndex`             | integer                                  | No          | Zero-based row index (`>= 0`) used for PDF/HTML/scoring output. Default `0`. |
| `emailTo`              | string[]                                 | No          | Array of valid recipient email addresses (max `20`) to deliver the report to. |
| `emailSubject`         | string                                   | No          | Custom email subject line. Max `250` characters. |
| `emailLanguage`        | string                                   | No          | Email template language: `"en"` or `"es"`. Default `"es"`. |
| `webhookUrl`           | string                                   | No          | Per-report `http` or `https` webhook override URL. Max `2048` characters. |
| `externalRefId`        | string                                   | No          | Caller-supplied correlation ID (max `200` characters), echoed in the report and webhook payloads. |
| `createdByChannel`     | string                                   | No          | Origin channel: `"portal"`, `"api"`, `"mcp"`, `"x402"`, or `"webhook"`. Default `"api"`. |

#### Execution behavior and parameter rules

- **Target resolution (`systemKey` vs `batchConfigurationId`)**: Provide either a preset `systemKey` or an existing `batchConfigurationId`. Unknown IDs or presets return `404 Not Found` (`batch_configuration_not_found`, `preset_not_found`, or `template_not_found`). Configurations or presets without steps return `409 Conflict` (`preset_has_no_steps` or `batch_configuration_has_no_steps`).
- **Account feature grants**: Every step in the resolved preset or batch configuration is checked against your client account's active feature grants before execution. Unentitled steps fail with `409 Conflict` (`endpoints_not_in_account`).
- **Sync deadline and automatic fallback**: Synchronous runs wait up to `90000` ms (`SYNC_DEADLINE_MS = 90s`). If verification or rendering does not settle within 90 seconds, the API automatically returns `202 Accepted` with `mode: "async"` and a `pollUrl` so your integration can poll [Retrieve a Smart Report](/smart-reports/retrieve-a-smart-report) or wait for webhooks.
- **Email triggers PDF generation**: Setting `emailTo` guarantees PDF generation for delivery even if you explicitly set `generatePdf: false`.

#### Error codes

| Status | Error Code / Type | Cause |
| ------ | ----------------- | ----- |
| `401` | `Unauthorized` | Missing or invalid JWT in the `Authorization` header. |
| `403` | `Forbidden` | Shared x402 execution was attempted; supply your own per-client JWT. |
| `404` | `batch_configuration_not_found` | The specified `batchConfigurationId` does not exist for your client. |
| `404` | `preset_not_found` | The specified `systemKey` preset could not be resolved. |
| `404` | `template_not_found` | The specified `templateId` or configured report template was not found. |
| `409` | `MissingParameter` | Joi schema validation failed on one or more request fields. |
| `409` | `client_context_required` | The JWT does not carry a valid `authUser.clientId`. |
| `409` | `missing_inputs` | Neither `inputs` nor `rows` was provided. |
| `409` | `max_rows_exceeded` | More than `500` rows/inputs were supplied. |
| `409` | `sync_row_limit_exceeded` | `mode: "sync"` was requested with more than `5` rows. |
| `409` | `missing_required_inputs` | One or more inputs required by the batch configuration schema are missing. |
| `409` | `preset_has_no_steps` | The resolved preset has no verification steps configured. |
| `409` | `batch_configuration_has_no_steps` | The target `BatchConfiguration` has no verification steps configured. |
| `409` | `endpoints_not_in_account` | Your client account does not have feature grants for one or more configured steps. |
| `409` | `row_not_found` | The requested `rowIndex` does not exist in the batch. |
| `409` | `unknown_score_profile` | The supplied `scoreProfile` is not recognized. |
| `422` | `UnprocessableEntity` | Mongoose validation failure or duplicate key conflict. |
| `500` | `InternalServerError` | Unexpected server error during execution or rendering. |

### Webhooks & MCP Integration

- **Webhooks**: When `webhookUrl` is provided (or configured on the preset/`BatchConfiguration`), Verifik emits `smart_batch_report_generated` or `smart_batch_report_generation_failed` for report generation, and `smart_batch_report_sent` or `smart_batch_report_delivery_failed` when `emailTo` delivery runs. Your `externalRefId` is echoed in both the report document and webhook events. See [Smart Reports Webhooks](/resources/smart-reports-webhooks).
- **MCP Equivalent**: AI agents connected via MCP can invoke the `smart_report_run` tool with the same headless parameters. See [MCP and AI Agents](/smart-reports/mcp-and-ai-agents).

### Notes

- `data.pdf` is included only when `generatePdf` is `true` (or `emailTo` triggers PDF rendering); `data.pdf.buffer` is included only when `includePdfBase64` is `true`.
- `data.email` is included only when `emailTo` is supplied; if delivery fails, `data.email.error` contains the failure reason.
- `data.verificationScore` is populated when `score` is enabled.
