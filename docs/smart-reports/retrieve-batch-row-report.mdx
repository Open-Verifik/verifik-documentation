Compose the structured row report model for a single row (`rowIndex`) of a `SmartBatch`. This endpoint runs Verifik's built-in report composer (`colombia_vehicle`) over the row's stored step outputs and optionally attaches a `verificationScore` when `score` or `scoreProfile` is passed.

If the batch's `BatchConfiguration` does not match a built-in composer, this endpoint returns `409 Conflict` (`no_report_composer_for_configuration`). For arbitrary custom report templates, use `POST /v2/smart-reports/run`, `GET /v2/smart-reports/{id}/html`, or `/generate` instead. Reading this endpoint does not spend credits.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Path Parameters

| Name       | Type   | Required | Description |
| ---------- | ------ | -------- | ----------- |
| `id`       | string | Yes      | `SmartBatch` ObjectId. |
| `rowIndex` | number | Yes      | `0`-based index of the row inside the batch. |

### Query Parameters

| Name           | Type             | Required | Description |
| -------------- | ---------------- | -------- | ----------- |
| `score`        | boolean or string | No      | Pass `true` or `"1"` to compute and include `verificationScore` in the response. |
| `scoreProfile` | string           | No       | Scoring profile identifier. Providing `scoreProfile` also enables `score`. |

  <TabItem value="go" label="Go">

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	rowIndex := "0"
	params := url.Values{}
	params.Set("score", "true")
	params.Set("scoreProfile", "fleet_standard")

	endpoint := fmt.Sprintf("https://api.verifik.co/v2/smart-batches/%s/rows/%s/report?%s", batchID, rowIndex, params.Encode())
	req, _ := http.NewRequest("GET", endpoint, nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}
```

### Notes

- This endpoint only serves built-in composed row reports (`colombia_vehicle`). Any other configuration returns `409 Conflict` (`no_report_composer_for_configuration`).
- For custom templates, themed HTML rendering, or PDF dossiers across any configuration, use `POST /v2/smart-reports/run`, `GET /v2/smart-reports/{id}/html`, or `/generate` (see [Run a Smart Report](/smart-reports/run-a-smart-report)).
- `verificationScore` is omitted unless `score=true`, `score=1`, or `scoreProfile` is supplied.
