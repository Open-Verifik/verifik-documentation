Delete a `SmartBatch` owned by the authenticated client. If the batch exists and belongs to your client account, the server deletes it and returns the removed `SmartBatch` document in `data`.

If the batch ID does not exist or belongs to another client, the endpoint returns `404` (`not_found`). Deleting a batch does not refund previously spent credits.

### Endpoint

```text
DELETE https://api.verifik.co/v2/smart-batches/{id}
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/{id}` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | Yes      | `SmartBatch` ObjectId to delete. |

### Notes

- To stop an active batch while retaining its historical rows and outputs, use [Cancel a Smart Batch](/smart-reports/cancel-a-smart-batch) instead of deleting it.
- Batches belonging to another client account return `404` (`not_found`).
