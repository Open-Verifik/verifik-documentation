Update a custom Smart Report template owned by your client account. Send any subset of updatable metadata, layout `sections`, `reportTheme`, `sampleData`, or PDF rendering options; fields omitted from the payload keep their existing values.

In headless and AI pipelines, use this endpoint to iterate on layouts generated by [Generate template layout](/smart-reports/generate-template-layout), refresh brand assets (`logo`, `primaryColor`, `customFonts`), update `SmartBatch` bindings, or toggle `isActive`. Built-in `"System"` templates are read-only and return `403` (`system_template_readonly`) if targeted.

### Endpoint

```
PUT https://api.verifik.co/v2/smart-report-templates/{id}
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Content-Type  | `application/json`       |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Parameters

| Name | Type   | Required | Description                        |
| ---- | ------ | -------- | ---------------------------------- |
| `id` | string | Yes      | Smart Report template ObjectId.    |

### Body

All body fields are optional on update.

| Name                  | Type             | Required | Description                                                                                                                                      |
| --------------------- | ---------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `name`                | string           | No       | Updated template display name. Maximum `150` characters.                                                                                         |
| `description`         | string           | No       | Updated template description. Maximum `500` characters.                                                                                          |
| `batchConfiguration`  | string           | No       | ObjectId of an associated `SmartBatch` configuration.                                                                                            |
| `country`             | string           | No       | Country identifier or label. Maximum `60` characters.                                                                                            |
| `category`            | string           | No       | Verification domain: `"citizen"`, `"company"`, or `"vehicle"`.                                                                                   |
| `isActive`            | boolean          | No       | Activate or deactivate the template.                                                                                                             |
| `logo`                | string           | No       | Brand logo URL or base64 data URI.                                                                                                               |
| `primaryColor`        | string           | No       | Primary brand accent hex color.                                                                                                                  |
| `identityColor`       | string           | No       | Secondary/identity accent hex color.                                                                                                             |
| `pageBackgroundColor` | string           | No       | Page background hex color.                                                                                                                       |
| `header`              | object           | No       | Custom header layout and content configuration.                                                                                                  |
| `footer`              | object           | No       | Custom footer layout and content configuration.                                                                                                  |
| `legend`              | string           | No       | Footer legend or compliance notice text. Maximum `2000` characters.                                                                              |
| `legendPosition`      | string           | No       | Legend alignment: `"left"`, `"center"`, or `"right"`.                                                                                            |
| `termsAndConditions`  | string           | No       | Legal terms and conditions text. Maximum `4000` characters.                                                                                      |
| `termsPosition`       | string           | No       | Terms alignment: `"left"`, `"center"`, or `"right"`.                                                                                             |
| `sections`            | object[]         | No       | Array of `ReportSection` objects (`id`, `type`, `order`, `dataPath`, `label`, `staticContent`, `columns`, `columnsPerRow`, `keyOverrides`, `valueRules`, `chartKind`, `style`, `condition`, `frame`, etc.). |
| `pageSize`            | string           | No       | PDF paper size: `"A4"`, `"Letter"`, or `"Legal"`.                                                                                                |
| `layoutVersion`       | integer          | No       | Layout renderer version: `1` or `2`.                                                                                                             |
| `orientation`         | string           | No       | Page orientation: `"portrait"` or `"landscape"`.                                                                                                 |
| `margins`             | object           | No       | Margin object `` `{ "top": 40, "right": 40, "bottom": 40, "left": 40 }` ``.                                                                      |
| `pdfEngine`           | string           | No       | PDF rendering engine: `"puppeteer"` or `"pdfkit"`.                                                                                               |
| `showPageNumbers`     | boolean          | No       | Show page numbers on rendered PDFs.                                                                                                              |
| `pageNumberPosition`  | string           | No       | Page number position: `"top-left"`, `"top-center"`, `"top-right"`, `"bottom-left"`, `"bottom-center"`, or `"bottom-right"`.                      |
| `pageNumberDivider`   | boolean / string | No       | Page number divider configuration.                                                                                                               |
| `watermark`           | object           | No       | Watermark overlay settings.                                                                                                                      |
| `security`            | object           | No       | PDF protection settings `` `{ "enabled": true, "password": "..." }` ``. Passing `"******"` or omitting `password` preserves the existing encrypted password. |
| `signature`           | object           | No       | Signature block configuration.                                                                                                                   |
| `logoSettings`        | object           | No       | Logo sizing and placement configuration.                                                                                                         |
| `sheetImages`         | object[]         | No       | Embedded template image assets. Maximum `12` items.                                                                                              |
| `customFonts`         | object[]         | No       | Custom font declarations (Google Fonts, external URL, or uploaded file). Maximum `6` items.                                                      |
| `headerLogos`         | object[]         | No       | Additional logos displayed in the header. Maximum `16` items.                                                                                    |
| `bodyTopPadding`      | number           | No       | Top padding applied to the document body, from `0` to `600`.                                                                                     |
| `sampleData`          | object           | No       | Sample verification payload stored with the template for previews and sample downloads.                                                          |
| `endpointDesign`      | object           | No       | Endpoint-specific presentation metadata.                                                                                                         |
| `reportTheme`         | string / object  | No       | Theme preset ID (`"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"`) or object (`id`, `scoreScale`, `scoreEnabled`, `scoreProfile`, `locale`, `density`, `eyebrow`, `coverTitle`, `headlines`, `legalNote`, `showVerifiedBadge`, `showWeights`, `showDeductions`, `showFields`, `showHowItWorks`, `blocks`, `tokens`). |

### Notes

- Passing `security.password: "******"` or omitting `security.password` preserves the template's existing encrypted password instead of overwriting it.
- Built-in `"System"` templates cannot be updated (`403` `system_template_readonly`). Create a custom copy via [Create a report template](/smart-reports/create-a-report-template) when customizing a system starter.
- Store preview helpers (`scoreScale`, `themeTokens`, `scoreSettings`) under `reportTheme` (`scoreScale`, `tokens`, `scoreEnabled`/`scoreProfile`) when saving changes.
