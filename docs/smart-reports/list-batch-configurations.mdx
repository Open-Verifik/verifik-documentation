List the Batch Configurations owned by your authenticated client account. Results are scoped to the client on your JWT, sorted newest first (`createdAt` descending), and returned with populated `steps.appFeature` metadata and client-specific `ClientFeature` pricing.

Pass `page` when you need paginated results with `total`, `limit`, `page`, and `pages` metadata. Omit `page` to receive the matching array directly in `data`. Listing configurations does not run lookups and does not consume credits.

### Endpoint

```
GET https://api.verifik.co/v2/batch-configurations
```

Also reachable via the Smart-Agent proxy at `https://ai.verifik.co/v2/batch-configurations` using your own per-client `Authorization: Bearer <VERIFIK_JWT>` header. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name | Value |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

The token must be a **client JWT**. Missing or invalid credentials return `401 Unauthorized`.

### Parameters

All query parameters are optional.

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `search` | string | No | Case-insensitive name filter applied to saved configurations. |
| `text` | string | No | Alias for `search`. |
| `page` | integer | No | Page number (`1`-based). When provided, enables pagination metadata (`total`, `limit`, `page`, `pages`) in the response. |
| `limit` | integer | No | Maximum number of configurations to return per page. |
| `perPage` | integer | No | Alias for `limit`. |

package main

import (
    "encoding/json"
    "fmt"
    "net/http"
    "net/url"
    "os"

func main() {
    u, _ := url.Parse("https://api.verifik.co/v2/batch-configurations")
    q := u.Query()
    q.Set("search", "Colombia")
    q.Set("page", "1")
    q.Set("limit", "20")
    u.RawQuery = q.Encode()

    req, _ := http.NewRequest("GET", u.String(), nil)
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

    resp, _ := http.DefaultClient.Do(req)
    defer resp.Body.Close()

    var out map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&out)
    fmt.Println(out)
}

### Notes

- Results are automatically scoped to the authenticated client JWT and sorted newest first (`-createdAt`).
- Each step's `steps.appFeature` is populated and enriched with your account's `ClientFeature` prices when configured.
- `perPage` is an alias for `limit`, and `text` is an alias for `search`.
- Pagination metadata (`total`, `limit`, `page`, `pages`) is included only when `page` is provided in the query string.
