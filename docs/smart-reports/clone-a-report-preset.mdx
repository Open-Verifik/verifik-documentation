Clone a curated system Smart Report preset into your client account. The operation returns both a `BatchConfiguration` and a linked `SmartReportTemplate`, ready to run immediately or customize further.

This endpoint is **idempotent** for client accounts. If an active client template cloned from `{systemKey}` already exists, the server reuses that configuration and template (remapping step sequences if needed) and returns `reused: true`. Otherwise, it creates a new `BatchConfiguration` (with `inputFormat: "csv"`, `outputFormat: "csv"`, `mergeStrategy: "sequential"`) and a new client `SmartReportTemplate` (`clonedFromSystemKey` set to `{systemKey}`) linked via `preferredReportTemplate` with `reused: false`. This endpoint is also exposed as the `smart_report_clone_preset` MCP tool.

### Endpoint

```
POST https://api.verifik.co/v2/smart-batch-presets/{systemKey}/clone
```

Also reachable via the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batch-presets/{systemKey}/clone` using your own per-client `Authorization: Bearer <VERIFIK_JWT>` header. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name | Value |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

The token must be a **client JWT**. Missing or invalid credentials return `401 Unauthorized`.

### Parameters

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `systemKey` | string | Yes | Preset key from [List report presets](/smart-reports/list-report-presets). Trimmed, max `120` characters, must match `/^[a-z0-9][a-z0-9._-]{1,118}$/i`. |

### Body

No request body is required for this endpoint.

### Notes

- Cloning a preset does not run lookups and does not spend credits.
- Calling this endpoint repeatedly with the same `{systemKey}` is safe and idempotent for a client account: the existing cloned configuration and template are returned with `reused: true`.
- `409 MissingParameter` is returned when `{systemKey}` fails Joi path validation (for example, exceeding `120` characters or containing unsupported characters). `409` with `preset_has_no_steps` is returned if the matched preset has no steps configured.
- `500 InternalServerError` can occur if a required preset feature is unavailable in your account.
- Once cloned, call [Retrieve configuration input schema](/smart-reports/retrieve-configuration-input-schema) with `batchConfiguration._id` before submitting rows, or use the `smart_report_clone_preset` MCP tool.
