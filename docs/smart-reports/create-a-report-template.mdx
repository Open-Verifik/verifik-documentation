Create a custom Smart Report template owned by the authenticated client. Only `name` is required; all branding, layout `sections`, `reportTheme`, `sampleData`, and PDF engine options are optional and can be updated later with [Update a report template](/smart-reports/update-a-report-template).

In headless and AI-driven pipelines, use this endpoint to persist layouts produced by [Generate template layout](/smart-reports/generate-template-layout), clone and brand a built-in starter from [List theme starters](/smart-reports/list-theme-starters), or provision environment-specific PDF templates for `SmartBatch` pipelines from code. Saving a template triggers asynchronous thumbnail generation and returns **HTTP `200`** (not `201`) with the created document in `{ "data": ... }`.

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Content-Type  | `application/json`       |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Body

| Name                  | Type             | Required | Description                                                                                                                                        |
| --------------------- | ---------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`                | string           | Yes      | Display name for the template. Maximum `150` characters.                                                                                           |
| `description`         | string           | No       | Human-readable description of the template. Maximum `500` characters.                                                                              |
| `batchConfiguration`  | string           | No       | ObjectId of an associated `SmartBatch` configuration.                                                                                              |
| `country`             | string           | No       | Country identifier or label. Maximum `60` characters.                                                                                              |
| `category`            | string           | No       | Verification domain: `"citizen"`, `"company"`, or `"vehicle"`.                                                                                     |
| `isActive`            | boolean          | No       | Whether the template is active. Defaults to `true`.                                                                                                |
| `logo`                | string           | No       | Brand logo URL or base64 data URI.                                                                                                                 |
| `primaryColor`        | string           | No       | Primary brand accent hex color. Defaults to `"#4F46E5"`.                                                                                           |
| `identityColor`       | string           | No       | Secondary/identity accent hex color. Defaults to `"#000000"`.                                                                                      |
| `pageBackgroundColor` | string           | No       | Page background hex color. Defaults to `"#ffffff"`.                                                                                                |
| `header`              | object           | No       | Custom header layout and content configuration.                                                                                                    |
| `footer`              | object           | No       | Custom footer layout and content configuration.                                                                                                    |
| `legend`              | string           | No       | Footer legend or compliance notice text. Maximum `2000` characters.                                                                                |
| `legendPosition`      | string           | No       | Legend alignment: `"left"`, `"center"`, or `"right"`.                                                                                              |
| `termsAndConditions`  | string           | No       | Legal terms and conditions text. Maximum `4000` characters.                                                                                        |
| `termsPosition`       | string           | No       | Terms alignment: `"left"`, `"center"`, or `"right"`.                                                                                               |
| `sections`            | object[]         | No       | Ordered array of `ReportSection` objects defining content blocks and data bindings (see [ReportSection properties](#reportsection-properties)).    |
| `pageSize`            | string           | No       | PDF paper size: `"A4"`, `"Letter"`, or `"Legal"`. Defaults to `"A4"`.                                                                              |
| `layoutVersion`       | integer          | No       | Layout renderer version: `1` or `2`.                                                                                                               |
| `orientation`         | string           | No       | Page orientation: `"portrait"` or `"landscape"`. Defaults to `"portrait"`.                                                                         |
| `margins`             | object           | No       | Margin object `` `{ "top": 40, "right": 40, "bottom": 40, "left": 40 }` ``. Defaults to `40` on all four sides.                                   |
| `pdfEngine`           | string           | No       | PDF rendering engine: `"puppeteer"` or `"pdfkit"`. Defaults to `"puppeteer"`.                                                                      |
| `showPageNumbers`     | boolean          | No       | Show page numbers on rendered PDFs.                                                                                                                |
| `pageNumberPosition`  | string           | No       | Page number position: `"top-left"`, `"top-center"`, `"top-right"`, `"bottom-left"`, `"bottom-center"`, or `"bottom-right"`.                        |
| `pageNumberDivider`   | boolean / string | No       | Page number divider configuration.                                                                                                                 |
| `watermark`           | object           | No       | Watermark overlay settings.                                                                                                                        |
| `security`            | object           | No       | PDF encryption settings `` `{ "enabled": true, "password": "..." }` ``.                                                                            |
| `signature`           | object           | No       | Signature block configuration.                                                                                                                     |
| `logoSettings`        | object           | No       | Logo sizing and placement configuration.                                                                                                           |
| `sheetImages`         | object[]         | No       | Embedded template image assets. Maximum `12` items.                                                                                                |
| `customFonts`         | object[]         | No       | Custom font declarations (Google Fonts, external URL, or uploaded file). Maximum `6` items.                                                        |
| `headerLogos`         | object[]         | No       | Additional logos displayed in the header. Maximum `16` items.                                                                                      |
| `bodyTopPadding`      | number           | No       | Top padding applied to the document body, from `0` to `600`.                                                                                       |
| `sampleData`          | object           | No       | Sample verification payload (`inputData`, `results`, `batchName`, `rowIndex`) used as the fallback dataset for previews and sample downloads.      |
| `endpointDesign`      | object           | No       | Endpoint-specific presentation metadata.                                                                                                           |
| `reportTheme`         | string / object  | No       | Theme preset ID (`"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"`) or full theme configuration object (see [Theme configuration](#theme-configuration)). |

#### `ReportSection` properties

Each element in `sections` describes one block in the report. Common properties include `id`, `type`, `order`, `dataPath`, `label`, `staticContent`, `columns`, `columnsPerRow`, `keyOverrides`, `valueRules`, `chartKind`, `style`, `condition`, and `frame`.

Supported `type` values include:

- **Core layout**: `header`, `text`, `table`, `field`, `image`, `divider`, `spacer`, `shape`
- **Structured blocks**: `dataTable`, `card`, `badge`, `keyValueGrid`, `repeater`, `reportBlocks`, `themeBlock`
- **Themed verification blocks**: `coverPage`, `scoreGauge`, `categoryBreakdown`, `checkTable`, `findings`, `sources`, `sourceCards`

#### Theme configuration

`reportTheme` accepts either a preset string (`"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"`) or an object containing:

`{ id, scoreScale, scoreEnabled, scoreProfile, locale, density, eyebrow, coverTitle, headlines, legalNote, showVerifiedBadge, showWeights, showDeductions, showFields, showHowItWorks, blocks, tokens }`

When migrating a payload tested on [Preview template HTML](/smart-reports/preview-template-html), move top-level preview helpers (`scoreScale`, `themeTokens`, `scoreSettings`) into `reportTheme` (`reportTheme.scoreScale`, `reportTheme.tokens`, `reportTheme.scoreEnabled`, and `reportTheme.scoreProfile`) before saving.

### Notes

- Successful creation returns HTTP **`200`** (not `201`) and triggers asynchronous thumbnail generation in the background.
- Top-level preview helpers (`scoreScale`, `themeTokens`, `scoreSettings`) used by [Preview template HTML](/smart-reports/preview-template-html) are not stored as top-level template fields. Place them inside `reportTheme` (`scoreScale`, `tokens`, `scoreEnabled`/`scoreProfile`) when persisting a template.
- Save the returned `_id` to render sample PDFs, send stakeholder previews, or attach the template to automated `SmartBatch` jobs.
