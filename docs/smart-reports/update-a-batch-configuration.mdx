Update an existing `BatchConfiguration` owned by your client account. Send only the fields you want to change; omitted fields retain their current values.

When `steps` is provided, the server normalizes missing `sequence` values to `index + 1` and clamps `retryDelayBaseSeconds` (`>= 1`) and `timeoutSeconds` (`>= 5`). Updating `notification` automatically syncs the associated Verifik Webhook, and changing `executor` propagates the new executor to non-terminal child batches. Updating a configuration does not run lookups and does not consume credits.

### Endpoint

```
PUT https://api.verifik.co/v2/batch-configurations/{id}
```

Also reachable via the Smart-Agent proxy at `https://ai.verifik.co/v2/batch-configurations/{id}` using your own per-client `Authorization: Bearer <VERIFIK_JWT>` header. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name | Value |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

The token must be a **client JWT**. Missing or invalid credentials return `401 Unauthorized`.

### Parameters

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `id` | string | Yes | `BatchConfiguration` ObjectId to update. |

### Body

All body fields are optional. Include only the properties you want to update.

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `name` | string | No | Display name for the configuration. Trimmed, maximum `150` characters. |
| `description` | string | No | Optional summary of the workflow. Maximum `800` characters. |
| `country` | string | No | Country scope. Trimmed and uppercased by the server. |
| `steps` | object[] | No | Replaces the ordered step array. Missing `sequence` defaults to `index + 1`; `retryDelayBaseSeconds` is clamped to `>= 1` and `timeoutSeconds` is clamped to `>= 5`. |
| `inputFormat` | string | No | Default input format: `csv`, `jsonl`, or `xlsx`. |
| `outputFormat` | string | No | Default output format: `csv`, `jsonl`, or `xlsx`. |
| `mergeStrategy` | string | No | Step execution strategy: `sequential`, `parallel-independent`, or `parallel-with-fallback`. |
| `notification` | object | No | Completion notification settings (`webhookUrl` and `emailOnCompletion`). Automatically syncs an active Verifik Webhook when `webhookUrl` is set. |
| `scheduleExpression` | string | No | Schedule expression for automated runs. |
| `preferredReportTemplate` | string | No | `SmartReportTemplate` ObjectId linked to this configuration. |
| `visitaFlow` | object | No | Visual node graph defining step chaining (`{{results.N.field}}` expressions are excluded from manual inputs in the derived input schema). |
| `isActive` | boolean | No | Whether the configuration is active. |
| `executor` | string | No | Execution target: `queue`, `featureRunner`, or `browser` (`featureRunner` is persisted as `browser`). Syncs non-terminal child batches when changed. |

### Notes

- Sending `steps` replaces the entire `steps` array on the configuration; it does not patch individual steps in place.
- Missing `sequence` values inside `steps` are normalized to `index + 1`, `retryDelayBaseSeconds` is clamped to `>= 1`, and `timeoutSeconds` is clamped to `>= 5`.
- Changing `executor` synchronizes any non-terminal child batches belonging to this configuration.
- Missing or cross-client IDs return `404` (`not_found`), while Mongoose schema validation errors return `422` (`UnprocessableEntity`).
