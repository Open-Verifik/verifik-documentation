Fetch a lightweight progress summary for a `SmartBatch` without transferring the entire `rows` array. The response includes row counters (`totalRows`, `completedRows`, `failedRows`, `partialRows`, `pendingRows`), execution timestamps, `creditsSpent`, and — when backed by a `FeatureRunner` run — nested `run` and ledger `spend` details.

Server-side `FeatureRunner` runs also emit a `smart_batch_batch_completed` webhook event (including `runId` and `creditsSpent`) upon completion when `batchConfiguration.notification.webhookUrl` is configured. Polling this endpoint does not spend credits.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/{id}/progress
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/{id}/progress` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | Yes      | `SmartBatch` ObjectId to poll. |

### Notes

- `run` and `spend` are included when the batch has an associated `FeatureRunner` run (`run` is `null` if the referenced run record is not returned).
- Server-side `FeatureRunner` runs emit the `smart_batch_batch_completed` webhook event (with `runId` and `creditsSpent`) when finished if `batchConfiguration.notification.webhookUrl` is set. See [Smart Reports Webhooks](/resources/smart-reports-webhooks).
- Once the batch reaches a terminal status, use [Retrieve a Smart Batch](/smart-reports/retrieve-a-smart-batch) to inspect row-level `results` and `errors`.
