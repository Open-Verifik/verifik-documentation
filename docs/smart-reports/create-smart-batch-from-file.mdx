Ingest a CSV, XLSX, or JSONL payload into a new `SmartBatch`. The server decodes raw text or base64 data URLs, enforces `MAX_ROWS` (`20000` by default), resolves column headers and camelCase aliases against your `BatchConfiguration` step dependencies, and computes a credit cost estimate.

Accepted rows are saved onto the batch in `pending` status while malformed rows are returned in `rejectedRows`. Pass `autoStart: true` to verify account endpoint grants and begin processing immediately; otherwise no checks execute and no credits are spent.

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/from-file
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/from-file` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Body

| Name                 | Type    | Required | Description |
| -------------------- | ------- | -------- | ----------- |
| `batchConfiguration` | string  | Yes      | `BatchConfiguration` ObjectId owned by the authenticated client. |
| `name`               | string  | Yes      | Batch display name. Maximum `150` characters. |
| `content`            | string  | Yes      | Raw CSV/JSONL text or a base64 data URL (`data:<mime>;base64,<payload>`). |
| `format`             | string  | No       | Input format: `"csv"`, `"xlsx"`, or `"jsonl"`. Defaults to `batchConfiguration.inputFormat` or `"csv"`. |
| `autoStart`          | boolean | No       | Set `true` to start the created batch immediately after ingest. |

Unknown body keys are rejected by Joi validation with `409 MissingParameter`.

### Notes

- File parsing enforces `MAX_ROWS` (`20000` default) and generates camelCase header aliases automatically so columns like `Document Number` resolve to `documentNumber`.
- For `.xlsx` workbooks, pass a base64 data URL (`data:application/vnd.openxmlformats-officedocument.spreadsheetml.sheet;base64,<payload>`) with `format: "xlsx"`.
- `409 Conflict` errors include `batch_file_has_no_sheets`, `batch_file_is_empty`, `batch_file_has_no_rows`, `batch_file_has_no_usable_rows`, `batch_jsonl_parse_failed_on_line_<N>`, `batch_configuration_has_no_steps`, and `endpoints_not_in_account`.
- Invalid row validation (`0` valid rows), unsupported format errors, and `MAX_ROWS` threshold errors return HTTP `500`.
