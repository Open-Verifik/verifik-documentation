Retrieve the simulated sandbox response, field `outline`, `dataSample`, and `emptySample` for a catalog endpoint `code` discovered via [List simulated responses](/smart-reports/list-simulated-responses). You can switch the returned `sample` state between populated records (`"data"`), empty matches (`"empty"`), or missing data (`"missing"`), and control array row counts with `listSize`.

In headless template design and automated QA workflows, this endpoint lets you validate how your template renders edge cases — such as empty tables, missing optional fields, or multi-page arrays (`listSize` from `2` to `30`) — before saving or shipping a template to production `SmartBatch` pipelines.

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses/{code}
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Parameters

| Name           | Type    | In    | Required | Description                                                                                  |
| -------------- | ------- | ----- | -------- | -------------------------------------------------------------------------------------------- |
| `code`         | string  | Path  | Yes      | Catalog endpoint code from [List simulated responses](/smart-reports/list-simulated-responses). |
| `availability` | string  | Query | No       | Simulated state to place in `sample`: `"data"`, `"empty"`, or `"missing"`. Defaults to `"data"`. |
| `listSize`     | integer | Query | No       | Number of synthetic items to generate for array/list fields. Valid range: `2` to `30`.       |

      method: "GET",
      headers: {
        Accept: "application/json",
        Authorization: `Bearer ${process.env.VERIFIK_JWT}`,
      },

  );

}

### Notes

- If `{code}` is not present in the sandbox inventory, the endpoint returns HTTP `200` with `found: false`, empty `outline` and `sample` objects, and an explanatory `note`.
- `listSize` accepts integers from `2` to `30` and is useful for testing multi-page PDF pagination via [Download template sample](/smart-reports/download-template-sample).
- This endpoint does not run live verifications and does not spend credits.
