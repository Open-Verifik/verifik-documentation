Retrieve a single `SmartBatch` document by ID for the authenticated client. Before returning the payload, the server merges any externally stored `smartbatchrows` outputs into `rows[].results` and runs `healIncompleteRows()` to reopen rows marked `completed` that are missing enabled configuration steps.

If the batch does not exist or belongs to a different client account, the endpoint returns `200` with `{ "data": null }`. Reading a batch does not run checks or spend credits.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/{id}
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-batches/{id}` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Path Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | Yes      | `SmartBatch` ObjectId. |

### Query Parameters

| Name          | Type     | Required | Description |
| ------------- | -------- | -------- | ----------- |
| `select`      | string   | No       | Field projection expression (for example `"-rows"` to exclude row payloads). |
| `columns`     | string   | No       | Subset of fields to include on the returned document. |
| `populates[]` | string[] | No       | Related documents to populate: `"batchConfiguration"` and/or `"client"`. |

### Notes

- External `smartbatchrows` step results are merged into `rows[].results` automatically when reading the batch.
- `healIncompleteRows()` inspects each `completed` row against enabled `batchConfiguration` steps and reopens any row missing step output or errors back to `pending`.
- For frequent status polling, prefer [Get Smart Batch progress](/smart-reports/get-smart-batch-progress) to avoid pulling full row payloads repeatedly.
