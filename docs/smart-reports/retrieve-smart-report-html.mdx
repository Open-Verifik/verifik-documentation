Retrieve the rendered HTML for a `SmartReport`, together with its linked `batchId`, `templateId`, `rowIndex`, optional `verificationScore`, and the corresponding `row` payload (`rowIndex`, `status`, `inputData`, `results`, `errors`).

**Important**: This endpoint responds with `Content-Type: application/json` and returns the HTML string inside `data.html`, **not** as a raw `text/html` document.

### Endpoint

```
GET https://api.verifik.co/v2/smart-reports/{id}/html
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-reports/{id}/html` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Accept`        | `application/json`     | JSON envelope response format.           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name           | Location | Type    | Required | Description |
| -------------- | -------- | ------- | -------- | ----------- |
| `id`           | path     | string  | **Yes**  | `SmartReport` ObjectId. |
| `rowIndex`     | query    | integer | No       | Zero-based row index (`>= 0`). |
| `preview`      | query    | boolean | No       | Render in preview mode when `true`. |
| `score`        | query    | boolean | No       | Whether to compute and include `verificationScore` in `data`. |
| `scoreProfile` | query    | string  | No       | Scoring profile identifier used when `score` is enabled (max `64` characters). |

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	id := "6801a2b3c4d5e6f7a8b9c0d1"
	params := url.Values{}
	params.Set("rowIndex", "0")
	params.Set("preview", "false")
	params.Set("score", "true")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-reports/"+id+"/html?"+params.Encode(), nil)
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

#### Error codes

| Status | Error Code / Type | Cause |
| ------ | ----------------- | ----- |
| `401` | `Unauthorized` | Missing or invalid JWT. |
| `403` | `Forbidden` | Shared x402 execution was attempted; use your own per-client JWT. |
| `404` | `not_found` | Report ID does not exist or belongs to another client. |
| `404` | `template_not_found` | Linked template could not be found. |
| `409` | `MissingParameter` | Joi validation failed on query or path parameters. |
| `409` | `row_not_found` | The requested `rowIndex` does not exist in the batch. |
| `409` | `unknown_score_profile` | The supplied `scoreProfile` is not recognized. |
| `422` | `UnprocessableEntity` | Mongoose validation error. |

### Webhooks & MCP Integration

- **MCP Equivalent**: AI agents can retrieve the rendered report HTML and row structure via the `smart_report_get_html` MCP tool. See [MCP and AI Agents](/smart-reports/mcp-and-ai-agents).
- **Webhooks**: The `htmlUrl` path (`/v2/smart-reports/{id}/html`) is included in [Run a Smart Report](/smart-reports/run-a-smart-report), [Retrieve a Smart Report](/smart-reports/retrieve-a-smart-report), and [Generate Smart Report PDF](/smart-reports/generate-smart-report-pdf) responses. See [Smart Reports Webhooks](/resources/smart-reports-webhooks).

### Notes

- Because the HTTP response uses `application/json`, extract `data.html` from the JSON payload before embedding it in a webview, iframe, or PDF renderer.
- `data.verificationScore` is present when `score=true` is passed.
- `data.row` is `null` if no batch row object is attached for the context.
