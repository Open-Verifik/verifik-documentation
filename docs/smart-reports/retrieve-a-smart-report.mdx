Retrieve a single `SmartReport` by its ID. The response populates `template`, `smartBatch`, and `client`, and attaches ready-to-use `downloadUrl` (`/v2/smart-reports/{id}/download`) and `htmlUrl` (`/v2/smart-reports/{id}/html`) paths.

This endpoint is also the polling target (`pollUrl`) returned when `POST /v2/smart-reports/run` executes in `"async"` mode or falls back to `202 Accepted` after the 90-second sync deadline. If the report ID does not exist or belongs to a different client, the endpoint returns HTTP `200 OK` with `{ "data": null }`.

### Endpoint

```
GET https://api.verifik.co/v2/smart-reports/{id}
```

This endpoint is also reachable through the Smart-Agent proxy at `https://ai.verifik.co/v2/smart-reports/{id}` using your own per-client `Authorization: Bearer <VERIFIK_JWT>`. Shared x402 execution is blocked with `403 Forbidden`.

### Headers

| Name            | Value                  | Description                              |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | Request payload format.                  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | Client-scoped JWT (`authUser.clientId`). |

### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| `id` | string | **Yes**  | `SmartReport` ObjectId returned by `POST /v2/smart-reports/run`, `POST /v2/smart-reports`, or `GET /v2/smart-reports`. |

### Webhooks & MCP Integration

- **Polling vs Webhooks**: For asynchronous runs, you can either poll `GET /v2/smart-reports/{id}` until `data.status` settles (`"generated"`, `"sent"`, or `"failed"`), or subscribe to webhook events (`smart_batch_report_generated`, `smart_batch_report_generation_failed`, `smart_batch_report_sent`, `smart_batch_report_delivery_failed`). See [Smart Reports Webhooks](/resources/smart-reports-webhooks).
- **MCP Equivalent**: AI agents can retrieve a report record using the `smart_report_get` MCP tool. See [MCP and AI Agents](/smart-reports/mcp-and-ai-agents).

### Notes

- Missing reports or reports belonging to another client return `200 OK` with `{ "data": null }` rather than `404`.
- `downloadUrl` and `htmlUrl` are relative API paths that can be appended to `https://api.verifik.co` (or `https://ai.verifik.co`).
