Generate, append, or edit structured `ReportSection` definitions from a natural-language `prompt` using Gemini (temperature `0.2`). Pass sample verification data in `previewData` so the model aligns section `dataPath` bindings and column layouts with your actual payload structure.

In headless report builders and AI agent pipelines, use this endpoint to scaffold complete layouts (`"create"`), add follow-up sections onto an existing template (`"append"`), or refine a single section (`"edit"`) without writing section JSON by hand. Pair this call with [Preview template HTML](/smart-reports/preview-template-html) to inspect the rendered output before persisting with [Create a report template](/smart-reports/create-a-report-template) or [Update a report template](/smart-reports/update-a-report-template).

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates/generate-layout
```

The Smart-Agent proxy (`https://ai.verifik.co`) exposes the same `/v2/...` paths and requires your own `Authorization: Bearer <VERIFIK_JWT>` header.

### Headers

| Name          | Value                    |
| ------------- | ------------------------ |
| Content-Type  | `application/json`       |
| Accept        | `application/json`       |
| Authorization | `Bearer <VERIFIK_JWT>`   |

### Body

| Name              | Type          | Required | Description                                                                                                                               |
| ----------------- | ------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`          | string        | Yes      | Natural-language instructions describing the layout to create, the sections to append, or the changes to apply in edit mode.              |
| `mode`            | string        | Yes      | Generation mode: `"create"`, `"edit"`, or `"append"`.                                                                                     |
| `previewData`     | object        | No       | Sample verification JSON (for example `inputData`, `results`, `batchName`) used to ground generated `dataPath` expressions and columns.   |
| `currentSections` | object[]      | No       | Existing `ReportSection` array. Recommended in `"append"` mode so newly generated sections continue the existing `order` sequence.         |
| `selectedSection` | object / null | No       | Target `ReportSection` object to modify when `mode` is `"edit"`. If `null` or omitted in `"edit"` mode, behavior falls back to `"create"`. |

		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/generate-layout", bytes.NewReader(body))

### Notes

- `"create"` and `"append"` modes return `{ "data": [ ...ReportSection ] }` (an array), while `"edit"` mode with a non-null `selectedSection` returns `{ "data": { ...ReportSection } }` (a single object).
- Calling `"edit"` with `selectedSection: null` or omitting `selectedSection` falls back to `"create"` mode and returns an array.
- This endpoint does not write to the database. Pass the returned `sections` into [Preview template HTML](/smart-reports/preview-template-html) to inspect the HTML or into [Create a report template](/smart-reports/create-a-report-template) to save it.
