# Colombia — PACO Anti-Corruption Observatory

The **Portal Anticorrupción de Colombia (PACO)** is the national transparency observatory and integrity clearinghouse managed by the **Secretaría de Transparencia de la Presidencia de la República**.

PACO unifies and cross-references data across Colombia's primary oversight bodies:
1. **SIRI (Sistema de Información de Registro de Inhabilidades y Sanciones)**: Disciplinary disqualifications and sanctions registered by the competent disciplinary authority.
2. **Boletín de Responsables Fiscales**: Unresolved fiscal liability rulings issued by the Contraloría General de la República.
3. **SECOP I, SECOP II & Tienda Virtual**: Administrative contract breach fines, forfeiture declarations, and procurement disqualifications (*inhabilidades para contratar con el Estado*).
4. **Historical Public Contracting History**: Volume and total contract values executed across municipal, departmental, and national public entities.

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/paco
```

*Alias route:* `GET https://api.verifik.co/v2/co/anticorruption`

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Yes** | Document or tax number (NIT or CC without spaces or hyphens). E.g. `900123456` or `75086330`. |
| `documentType` | string | No | Document type: `CC` (default), `CE`, `NIT`, `TI`, `PAS`. |

### Use Cases

- **Third-Party & Vendor Due Diligence:** Screen prospective suppliers and contractors against government-wide debarment lists before issuing contracts.
- **M&A and Joint Ventures:** Perform statutory compliance audits on target entities and executive leadership in Colombia.
- **Public Procurement Compliance:** Verify legal capacity (*habilidad contractual*) to avoid entering into legally void public contracts under Law 80 of 1993 and Law 1474 of 2011 (Anti-Corruption Statute).

import axios from "axios";

const options = {
