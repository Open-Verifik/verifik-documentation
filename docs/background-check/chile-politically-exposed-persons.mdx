# Chile — Politically Exposed Persons (PEP / Ley 19.913 & UAF)

Screen Chilean citizens by **RUT (`documentNumber` or `rut`)** or **Full Legal Name (`fullName`)** against consolidated official registries of Politically Exposed Persons (PEP) for anti-money laundering and terrorism financing prevention (AML/CFT) under:

- **Ley N° 19.913** (*Crea la Unidad de Análisis Financiero y modifica diversas disposiciones en materia de lavado y blanqueo de activos*)
- **Circular UAF N° 49/2012** (Instrucciones sobre Personas Expuestas Políticamente)
- Mandatory **2-year post-mandate lookback window** (*período de carencia* following cessation of public office).

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/cl/politically-exposed-persons
```

### Headers

| Name | Value |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `rut` | string | Conditional | Chilean RUT number (e.g. `16152235-6` or `7012456-8`). Required if `fullName` is omitted. |
| `documentNumber` | string | Conditional | Alias for `rut`. |
| `documentType` | string | No | Document type: `RUT` (default). |
| `fullName` | string | Conditional | Full legal name of the person to screen. Required if RUT is omitted. |
| `includeFormer` | boolean | No | Include former PEPs (*ex-PEP*) within the 2-year statutory lookback window. Defaults to `true`. |
| `force` | boolean | No | Bypass recent lookup cache and force fresh screening. |

### Notes

- Regulatory screening for financial institutions, fintechs, stock brokers, and reporting entities regulated by UAF Chile.
- When `includeFormer=true`, former public officials who stepped down within the last 2 years are returned with `isFormerPep: true` and `isPep: true`.
- In sandbox mode, test RUTs include `16152235-6` (President), `7012456-8` (Minister of Finance), and `18945612-3` (Clean / Non-PEP).
