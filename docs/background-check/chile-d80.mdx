# Chile - Vehicle in the transport register (D80)

Ride-hailing platforms in Chile ask drivers whether they use a private car, a taxi, or a **D80** vehicle. Taxis and D80 vehicles must be registered with the Ministry of Transport and Telecommunications (MTT).

Verifik checks that registration by plate with the [Chile Transport Vehicle](/vehicle-validation/chile/transport-vehicle) endpoint. You don't need a separate product.

## Request

```bash
curl -G "https://api.verifik.co/v2/cl/transport-vehicle" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  --data-urlencode "plate=BBCC12"
```

Send the plate without spaces, dots, or dashes.

## What to check in the response

| Field               | Use it to                                                                                  |
| ------------------- | ------------------------------------------------------------------------------------------ |
| `serviceType`       | Confirm the category the vehicle is registered for, such as `TRANSPORTE URBANO DE PASAJEROS`. Compare it with the categories your program accepts. |
| `vehicleStatus`     | Accept only vehicles whose status is `VIGENTE`.                                            |
| `serviceExpiryDate` | Reject or flag registrations that expire before your next review.                          |
| `serviceResponsibleName` | Compare with the driver or the fleet owner on file.                                   |
| `brand`, `model`, `plate` | Match the vehicle the driver declared.                                               |

A plate that isn't in the MTT register returns `404`. That means the vehicle isn't registered for passenger transport, which is the expected result for a private car.

See the [full reference](/vehicle-validation/chile/transport-vehicle) for every field and error.
