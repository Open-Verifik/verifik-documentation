# Colombia — PEP foreign missions

Screen officials of Colombian missions and consulates abroad.

## What the call returns

- `isPEP`
- `isForeignMissionOfficial`
- `fullName` and `documentNumber`
- `matches` — empty on a clean miss

## Use cases

- Screen a Colombian PEP directory before you onboard.
- Keep a not-listed person as HTTP 200.
- Search by name or by document number.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/pep/misiones-exterior
```

A hit sets `isPEP` true and `isForeignMissionOfficial` true. A person who is simply not in this directory is HTTP 200 with `isPEP` false and an empty `matches` array. That clean miss is not 404.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | `MARIA LOPEZ` | Person name. Enough on its own. Alias searches also accept `partyName`, `entityName`, or `country` where that directory has them. |
| `documentNumber` | string | **Conditional** | `80123456` | Identifier, 4 to 30 characters. Enough on its own. |
| `documentType` | string | No | `CC` | Optional: `CC`, `NIT`, `CE`, `PAS`, `TI`, `CD`. |

### Notes

- A clean miss is HTTP 200 with `isPEP` false.
- Send at least one search value.
- Do not map that 200 to 404.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |
| Record on file | `fullName: "MARIA LOPEZ"` | 200 with isPEP true on a hit. |
| Missing required value | Omit every search value | 409 when no search value is sent. |
| Unknown value | `fullName: "CLEAN NAME"` | 200 with isPEP false. A clean miss is not 404. |

401 when the bearer token is missing or rejected.
