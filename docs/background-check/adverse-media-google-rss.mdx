# Adverse Media & Negative News Screening

Under **Financial Action Task Force (FATF / GAFI)** recommendations and statutory Anti-Money Laundering and Counter-Terrorist Financing (AML/CFT) regulations, adverse media screening is essential to detect illicit activities before formal convictions or judicial indictments appear on public registries.

Verifik's Adverse Media API performs real-time searches across indexed news articles, regulatory press releases, and investigative journalism reports via Google News RSS feeds, combining subject names with targeted legal and criminal typologies. The API extracts sentiment, filters false positives, deduplicates headlines, and computes a standardized **AML Risk Score (0–100)**.

---

## Targeted Adverse Crime Typologies

The engine automatically expands queries with localized multi-language criminal taxonomy keywords:

- **Financial & Corporate Crimes:** Fraud (*estafa*), embezzlement (*peculado*), bribery (*soborno*), tax evasion (*evasión fiscal*), Ponzi schemes (*captación ilegal*).
- **AML / CFT:** Money laundering (*lavado de activos*), terrorism financing (*financiación del terrorismo*), shell companies (*empresas de fachada*).
- **Public Corruption:** Bid-rigging (*cartelización*), influence peddling (*tráfico de influencias*), illicit enrichment (*enriquecimiento ilícito*).
- **Organized Crime & Penal:** Drug trafficking (*narcotráfico*), extortion (*extorsión*), asset forfeiture (*extinción de dominio*), arrest warrants (*orden de captura*).

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/media/adverse
```

*Global multi-region news search route:* `GET https://api.verifik.co/v2/media/google-rss`

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Full name of the individual or registered commercial business name. Required if `documentNumber` is omitted. |
| `documentNumber` | string | **Conditional** | National ID (CC, NIT, CE). When supplied, the API automatically resolves the official name from national registries before querying. |
| `documentType` | string | No | Document type: `CC` (default), `NIT`, `CE`, `PAS`. |
| `country` | string | No | Regional jurisdiction filter: `co` (Colombia, default), `mx` (Mexico), `us` (United States), or `global`. |
| `lang` | string | No | Language of the media search: `es` (Spanish, default) or `en` (English). |
| `limit` | number | No | Maximum number of articles returned (default: `20`, maximum: `50`). |

### Use Cases

- **Enhanced Due Diligence (EDD):** Supplement standard watchlist checks for high-risk clients, PEPs, and corporate counterparties.
- **Merchant & Executive Onboarding:** Safeguard brand reputation by identifying controversies before formal partnerships or hires.
- **Ongoing AML Monitoring:** Periodically scan supplier bases for early-warning indicators of regulatory probes or criminal investigations.
