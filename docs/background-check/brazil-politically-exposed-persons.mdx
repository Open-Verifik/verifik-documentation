# Brazil — Politically Exposed Persons (PEP / COAF Resolução 40/2021)

Screen Brazilian **CPF** (*Cadastro de Pessoas Físicas*) numbers or **full legal names** against the consolidated Brazilian Politically Exposed Persons (PEP) registry for **PLD/FT** (*Prevenção à Lavagem de Dinheiro e ao Financiamento do Terrorismo*) compliance under:

- **COAF Resolução N° 40/2021** (*Conselho de Controle de Atividades Financeiras*)
- **Decreto N° 10.889/2021** (Sistema Eletrônico de Informações sobre PEP e Agentes Públicos)
- Mandatory **5-year grace period / lookback window** (*período de carência* under Art. 3° da Resolução COAF N° 40/2021) following the cessation of public functions.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/br/politically-exposed-persons
```

### Headers

| Name | Value |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `cpf` | string | Conditional | Brazilian CPF number (11 digits, formatted `000.000.000-00` or raw digits). Required if `fullName` is omitted. |
| `documentNumber` | string | Conditional | Alias for `cpf`. Peruvian/international standard document parameter. |
| `documentType` | string | No | Document type: `CPF` (default). |
| `fullName` | string | Conditional | Full legal name of the individual to screen (e.g., `LUIZ INACIO LULA DA SILVA`). Required if `cpf` / `documentNumber` is omitted. |
| `includeFormer` | boolean | No | Include former PEPs (*ex-PEP*) within the 5-year post-cessation look-back window established by COAF Resolução 40/2021 Art. 3°. Defaults to `true`. Set to `false` to return only currently active roles. |
| `force` | boolean | No | Bypass the recent lookup cache and force a fresh verification. |

---

## COAF Resolução N° 40/2021 Categories (I – IX)

Each matched record is classified into the corresponding **COAF Resolução N° 40/2021** category:

| Category | Description (COAF Resolução N° 40/2021) |
| :--- | :--- |
| `I` | President and Vice-President of the Republic, Ministers of State, and equivalent Executive Branch leadership |
| `II` | Senators, Federal Deputies, and Senior Officials of the National Congress |
| `III` | Ministers and Senior Judges of Superior Courts (STF, STJ, TST, TSE, STM) |
| `IV` | Attorney General of the Republic (PGR) and Senior Officials of the Federal and State Public Ministries |
| `V` | President and Directors of the Central Bank of Brazil (BACEN) and federal regulatory agencies (CVM, SUSEP, PREVIC, ANATEL, ANVISA, etc.) |
| `VI` | State and District Governors, Vice-Governors, State Secretaries, and State Deputies (Assembleias Legislativas) |
| `VII` | Municipal Mayors (*Prefeitos*), Vice-Mayors, Municipal Secretaries, and City Councilors (*Vereadores*) |
| `VIII` | Presidents, CEOs, and Executive Directors of State-Owned and Mixed-Capital Enterprises (Petrobras, Banco do Brasil, Caixa Econômica Federal, BNDES) |
| `IX` | National Presidents, Treasurers, and Legal Representatives of registered Political Parties |
