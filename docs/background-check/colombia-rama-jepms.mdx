# Colombia — Juzgados de Ejecución de Penas y Medidas de Seguridad (JEPMS)

The **Juzgados de Ejecución de Penas y Medidas de Seguridad (JEPMS)** are specialized courts within the Colombian Judiciary (**Rama Judicial**) tasked with supervising the execution, enforcement, and compliance of criminal sentences and security measures under the Colombian Penal Code (*Ley 599 de 2000*) and Criminal Procedure Code (*Ley 906 de 2004*).

Unlike general trial court dockets, JEPMS records specifically track individuals who have received formal criminal convictions. The system provides real-time visibility into prison execution status (*PPL - Persona Privada de la Libertad*), home detention (*prisión domiciliaria*), conditional parole (*libertad condicional*), work-release benefits, and sentence termination orders.

---

## Supported Judicial Districts

The API connects directly to the official judicial information system across **25 judicial districts**:

| Region | Supported City Slugs |
| :--- | :--- |
| **Capital & Central** | `bogota`, `tunja`, `ibague`, `neiva`, `villavicencio`, `acacias` |
| **Antioquia & Coffee Axis** | `medellin`, `pereira`, `manizales`, `armenia` |
| **Southwestern** | `cali`, `palmira`, `buga`, `popayan`, `pasto`, `florencia` |
| **Caribbean & Northern** | `barranquilla`, `cartagena`, `santamarta`, `valledupar`, `monteria`, `bucaramanga` |
| **Frontier & Amazonian** | `arauca`, `quibdo`, `leticia` |

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/rama/jepms
```

*Alias route:* `GET https://api.verifik.co/v2/co/rama/juzgado/expedientes`

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditional** | Colombian national ID or foreigner ID number. Required if `lastName` is not specified. |
| `documentType` | string | No | Document type: `CC` (default), `CE`, `PAS`, `TI`. |
| `lastName` | string | **Conditional** | Defendant surname. Required if `documentNumber` is not provided. |
| `city` | string | No | Judicial city district slug (e.g. `bogota`, `medellin`, `cali`). Defaults to `bogota`. Set to `all` to search all major judicial circuits concurrently. |

### Use Cases

- **Enhanced Criminal Record Verification:** Goes beyond police clearance certificates by identifying active sentence execution proceedings, probation conditions, and pending arrest warrants.
- **High-Trust Hiring & Security Clearances:** Essential for security guards, bullion transport, armored logistics, education staff, and executive leadership positions.
- **Legal Compliance:** Ascertain whether an individual is subject to civil rights disqualifications (*inhabilidad para el ejercicio de funciones públicas*) stemming from an ongoing criminal sentence.
