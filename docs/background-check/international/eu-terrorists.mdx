# EU Terrorists Sanctions (CP931)

Compliance with European Union restrictive measures on combating terrorism is legally binding on all EU individuals, legal entities incorporated under the law of an EU Member State, and any business conducted within the European Union.

The **EU Common Position 2001/931/CFSP** and Council Regulation (EC) No 2580/2001 establish specific restrictive measures directed against persons, groups, and entities involved in terrorist acts, enforcing asset freezes and prohibitions on making funds available.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/eu-terrorists
```

### Headers

| Name          | Value              | Description |
| ------------- | ------------------ | ----------- |
| Content-Type  | `application/json` | Request format |
| Accept        | `application/json` | Response format |
| Authorization | `Bearer <token>`   | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Full name of the individual or group to search. Required if document parameters are not provided. |
| `documentNumber` | string | **Conditional** | Document number. Required if fullName is not provided. |
| `documentType` | string | No | Document type (e.g., `PAS`, `CC`, `DNI`). Default: `CC`. |

### Use Cases

- **Sanctions & CTF Compliance:** Comply with European Union anti-terrorism financing regulations and asset freezing obligations.
- **Cross-Border Payments Screening:** Screen beneficiaries and remitter names prior to executing SEPA and SWIFT wire transfers.
- **Customer Onboarding:** Prevent onboarding of designated terrorist entities or affiliated individuals.
