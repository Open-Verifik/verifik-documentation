# FinCEN 311 and 9714 Special Measures

Screen a person or organization against the **FinCEN 311 and 9714 Special Measures**. The Financial Crimes Enforcement Network publishes this list for the United States.

This list covers special measures under Section 311 of the USA PATRIOT Act and Section 9714 actions, which impose additional requirements on transactions involving a designated jurisdiction, institution, or class of transactions.

Send `fullName`, `documentNumber`, or both. At least one of the two is required. The response sets `foundInFincenSpecialMeasures` to `true` when the query matches a published record and to `false` when it does not. On a match, `details` includes the listed name, entity type, regime or program, measures, country, identifiers, and remarks. Use the result in KYC, AML/CFT, vendor onboarding, and payment screening. Review every match before you rely on it. This call does not replace the official list and it is not a legal determination.

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/fincen-special-measures
```

A successful response returns `data.fullName`, `data.firstName` and `data.lastName` when the source record splits the name, `data.documentNumber` when you sent one, `data.foundInFincenSpecialMeasures`, and `data.details`. On a match, `details` includes the listed name, entity type, regime or program, measures, country, identifiers, and remarks. The `signature` object includes `dateTime` and the message `Certified by Verifik.co`. When `foundInFincenSpecialMeasures` is `false`, `details` is an empty object.

### Headers

| Name          | Value              | Description     |
| ------------- | ------------------ | --------------- |
| Content-Type  | `application/json` | Request format  |
| Accept        | `application/json` | Response format |
| Authorization | `Bearer <token>`   | Verifik JWT     |

### Parameters

| Parameter        | Type   | Required    | Example                  | Description                                                                                                            |
| ---------------- | ------ | ----------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `fullName`       | string | Conditional | `SAMPLE DESIGNATED NAME` | Full legal name of the person, or the registered name of the organization. Required when `documentNumber` is not sent. |
| `documentNumber` | string | Conditional | `A1234567`               | Identification number or corporate registration number, without spaces. Required when `fullName` is not sent.          |

### Use Cases

- **Sanctions screening:** Check customers, counterparties, and beneficiaries before onboarding or releasing a payment.
- **AML/CFT reviews:** Record a screen against this jurisdiction's published measures.
- **Audit trail:** Keep the certified response with the case file.

### Notes

- Send `fullName` or `documentNumber`. At least one is required. If both are missing, the API returns HTTP 409 with code `MissingParameter` and the message `Either fullName or documentNumber must be provided`.
- `foundInFincenSpecialMeasures` is `true` when the query matches a record on this list and `false` when it does not. `details` is an empty object when there is no match.
- The match example shows the response shape. A live match returns the attributes published for that record on this list.
- A match is a screening result for compliance review. It is not a legal determination and it does not replace the official source.
- Authenticate with a Bearer JWT in the `Authorization` header. Create or renew the JWT with the [authentication API](/authentication/renew-your-token-jwt).
- The result reflects the list at the time of the call. Run a new request when you need a later result.
