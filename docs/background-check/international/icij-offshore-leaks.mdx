# ICIJ Offshore Leaks Database

Uncovering **Ultimate Beneficial Ownership (UBO)** and opaque corporate structures hidden within offshore secrecy jurisdictions is a regulatory requirement under 5th/6th EU AML Directives, FinCEN Corporate Transparency Act, and international tax transparency standards (FATCA / CRS).

The **International Consortium of Investigative Journalists (ICIJ) Offshore Leaks Database** indexes more than **800,000 offshore companies, foundations, trusts, and intermediaries** leaked across landmark investigative disclosures:

- **Panama Papers** (Mossack Fonseca)
- **Pandora Papers** (14 offshore corporate service providers)
- **Paradise Papers** (Appleby and Asiaciti Trust)
- **Offshore Leaks & Bahamas Leaks**
- **FinCEN Files**

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/offshore-leaks
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Individual name (officer, shareholder, beneficiary) or offshore legal entity name (e.g. `MOSSACK FONSECA`). |
| `documentNumber` | string | **Conditional** | Tax identification number or national registration ID. |
| `documentType` | string | No | Document type (e.g., `NIT`, `CC`, `PAS`). |

### Use Cases

- **Ultimate Beneficial Owner (UBO) Discovery:** Trace corporate layers back to true individual beneficial owners behind bearer shares and nominee directors.
- **Tax Haven & Shell Company Exposure:** Uncover undisclosed offshore accounts and assets in British Virgin Islands (BVI), Panama, Bahamas, Samoa, and Cyprus.
- **Enhanced Due Diligence (EDD):** Identify political figures, business executives, and commercial counterparties linked to tax avoidance investigations.

<TabItem value="javascript" label="Node.js / JavaScript">

```javascript
import axios from "axios";

const options = {
  method: "GET",
  url: "https://api.verifik.co/v2/offshore-leaks",
  params: {
    fullName: "MOSSACK FONSECA",
  },
  headers: {
    Accept: "application/json",
    Authorization: "Bearer <your_token>",
  },
};

try {
  const { data } = await axios.request(options);
  console.log(data);
} catch (error) {
  console.error(error.response ? error.response.data : error.message);
}
```

<TabItem value="python" label="Python">

```python
import http.client
import urllib.parse
import json

conn = http.client.HTTPSConnection("api.verifik.co")
params = urllib.parse.urlencode({"fullName": "MOSSACK FONSECA"})
headers = {
    "Accept": "application/json",
    "Authorization": "Bearer <your_token>"
}

conn.request("GET", f"/v2/offshore-leaks?{params}", headers=headers)
res = conn.getresponse()
data = res.read()

print(json.loads(data.decode("utf-8")))
```
