# CIA World Leaders — Chiefs of State & Cabinet Members

Under **FATF Recommendation 12**, financial institutions, fintechs, and regulated entities must identify foreign **Politically Exposed Persons (PEPs)**, their immediate family members, and close associates.

The **Central Intelligence Agency (CIA) Chiefs of State and Cabinet Members of Foreign Governments** directory provides authoritative global intelligence on senior governmental leadership across more than 190 nations, indexing heads of state, prime ministers, cabinet ministers, central bank governors, and diplomatic leaders.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/cia-world-leaders
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Full name of the subject to search (e.g., `GUSTAVO PETRO`). |
| `documentNumber` | string | **Conditional** | Document number. When provided with `documentType`, Verifik resolves the citizen name prior to screening. |
| `documentType` | string | No | Document type (e.g., `CC`, `PAS`). |
| `country` | string | No | Filter by country name or ISO-2 code (e.g., `Colombia`, `CO`). |

### Use Cases

- **Foreign PEP Screening:** Identify high-risk government figures during customer onboarding to apply Enhanced Due Diligence (EDD) measures.
- **Cross-Border Banking & Wealth Management:** Detect sovereign wealth managers, finance ministers, and central bank leadership in international transactions.
- **Anti-Corruption Compliance (FCPA & UK Bribery Act):** Mitigate risk when interacting with state-owned enterprises (SOEs) and foreign government officials.
