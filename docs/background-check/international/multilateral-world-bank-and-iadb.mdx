# Multilateral Development Banks — World Bank & IDB Debarment

Under the landmark **Agreement for Mutual Enforcement of Debarment Decisions** signed on April 9, 2010, the world's leading Multilateral Development Banks (MDBs)—including the **World Bank Group**, **Inter-American Development Bank (IDB / BID)**, Asian Development Bank (ADB), European Bank for Reconstruction and Development (EBRD), and African Development Bank (AfDB)—mutually recognize and enforce anti-corruption debarment actions.

When an entity is sanctioned by one multilateral bank for fraudulent, corrupt, collusive, coercive, or obstructive practices in a development project, it is **cross-debarred across all participating institutions**.

Verifik provides dedicated endpoints to screen both registries:

1. **World Bank Listing of Ineligible Firms & Individuals (`/v2/world-bank`)**: Tracks global debarments administered by the World Bank Sanctions Board.
2. **Inter-American Development Bank Sanctions (`/v2/iadb-sanctions`)**: Official registry of individuals and corporate groups sanctioned by the IDB Group Office of Institutional Integrity (OII).

## API Reference

### Endpoints

```http
# World Bank Ineligible Firms & Individuals
GET https://api.verifik.co/v2/world-bank

# Inter-American Development Bank (IDB / BID) Sanctions
GET https://api.verifik.co/v2/iadb-sanctions
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Company name or individual name to search (e.g. `ODEBRECHT`). |
| `documentNumber` | string | **Conditional** | Corporate Tax ID or national registration code. |
| `documentType` | string | No | Document type (e.g., `NIT`, `EIN`, `PAS`). |

### Use Cases

- **Infrastructure & Construction Due Diligence:** Screen EPC contractors, project managers, and concessionaires participating in development bank financed initiatives.
- **Multilateral Tender Eligibility:** Guarantee bidder qualification before submitting consortium proposals to the World Bank, IDB, or CAF.
- **Supply Chain Anti-Bribery Compliance:** Detect entities previously involved in systemic bid-rigging or corruption in public tenders.

<TabItem value="python" label="Python">

```python
import http.client
import urllib.parse
import json

conn = http.client.HTTPSConnection("api.verifik.co")
params = urllib.parse.urlencode({"fullName": "CONSTRUCTORA NORBERTO ODEBRECHT"})
headers = {
    "Accept": "application/json",
    "Authorization": "Bearer <your_token>"
}

conn.request("GET", f"/v2/world-bank?{params}", headers=headers)
res = conn.getresponse()
data = res.read()

print(json.loads(data.decode("utf-8")))
```
