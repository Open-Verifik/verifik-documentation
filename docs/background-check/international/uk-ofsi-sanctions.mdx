# UK OFSI Consolidated Sanctions List

The **Office of Financial Sanctions Implementation (OFSI)**, part of **HM Treasury**, is the statutory body responsible for implementing and enforcing financial sanctions in the United Kingdom under the **Sanctions and Anti-Money Laundering Act 2018 (SAMLA)**.

UK financial sanctions apply to all persons within the territory and territorial sea of the UK, and to all UK persons (UK nationals and entities incorporated in the UK) wherever they are in the world. Breaches of financial sanctions are serious criminal offenses punishable by up to seven years' imprisonment and civil monetary penalties up to £1 million or 50% of the value of the breach.

---

## Targeted UK Sanctions Regimes

The OFSI Consolidated List encompasses over 8,900 individuals, corporations, ships, and aircraft designated under distinct geopolitical and thematic regimes:

- **Geographic Regimes:** Russia, Belarus, Iran, North Korea (DPRK), Syria, Venezuela, Myanmar.
- **Thematic Regimes:** Global Anti-Corruption, Global Human Rights (*Magnitsky-style*), Counter-Terrorism, Cyber, Chemical Weapons, and Disinformation.

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/ofsi
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Subject or corporate name (e.g. `ROMAN ABRAMOVICH`). |
| `documentNumber` | string | **Conditional** | Passport, national ID, or company registration number. |
| `documentType` | string | No | Document type (e.g., `PAS`, `CC`). |

### Use Cases

- **UK & Sterling Financial Transactions:** Ensure payments, loans, and escrow deposits in GBP or through UK clearinghouses do not touch designated persons.
- **Corporate & Wealth Advisory:** Screen beneficial owners and trust beneficiaries to comply with the UK's trust services prohibitions.
- **Maritime & Aviation Insurance:** Prevent underwriting of vessels and aircraft identified on the OFSI designated list.
