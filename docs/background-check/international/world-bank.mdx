# World Bank Debarred Firms & Individuals

The **World Bank Listing of Ineligible Firms & Individuals** contains businesses and individuals that have been sanctioned and declared ineligible to be awarded World Bank-financed contracts. Debarments are adjudicated under World Bank Group Sanctions Procedures for fraudulent, corrupt, collusive, coercive, or obstructive practices.

Under the 2010 **Agreement for Mutual Enforcement of Debarment Decisions (Multilateral Cross-Debarment Agreement)**, debarments exceeding one year are cross-enforced by participating multilateral development banks (IDB, ADB, EBRD, and AfDB).

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/world-bank
```

### Headers

| Name          | Value              | Description |
| ------------- | ------------------ | ----------- |
| Content-Type  | `application/json` | Request format |
| Accept        | `application/json` | Response format |
| Authorization | `Bearer <token>`   | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Company or individual name to search. Required if document parameters are not provided. |
| `documentNumber` | string | **Conditional** | Tax registration ID or national identity number. Required if fullName is not provided. |
| `documentType` | string | No | Document type (e.g., `NIT`, `EIN`, `CC`, `PAS`). Default: `CC`. |

### Use Cases

- **Procurement & Tender Compliance:** Verify that bidding engineering firms and consultants are not subject to multilateral debarment before contract award.
- **Multilateral Financing Compliance:** Comply with international development project guidelines prohibiting subcontracting with debarred entities.
- **Corporate Vendor Onboarding:** Screen global suppliers and consortium partners in public works and infrastructure projects.
