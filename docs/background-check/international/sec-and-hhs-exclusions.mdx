# SEC Sanctions & HHS Health Exclusions

Federal oversight across financial markets and healthcare services in the United States requires specialized regulatory screenings to prevent consumer fraud and Medicare/Medicaid violations:

1. **U.S. Securities and Exchange Commission (SEC) Sanctions (`/v2/sec-sanctions`)**: Enforces federal securities laws. Tracks administrative enforcement proceedings, civil injunctive actions, trading suspensions, and the **PAUSE list** (*Public Alert: Unregistered Soliciting Entities*), which flags entities targeting U.S. investors with bogus, unregistered securities or impersonating legitimate registered brokers.
2. **HHS OIG List of Excluded Individuals/Entities (`/v2/health-exclusions`)**: Administered by the **U.S. Department of Health and Human Services Office of Inspector General (HHS OIG)** pursuant to Sections 1128 and 1156 of the Social Security Act. Mandates that excluded healthcare practitioners, clinics, and billing entities cannot receive federal healthcare program payments (Medicare, Medicaid, TRICARE). Hiring an excluded party triggers substantial **Civil Monetary Penalties (CMP)**.

## API Reference

### Endpoints

```http
# U.S. Securities and Exchange Commission Sanctions & PAUSE List
GET https://api.verifik.co/v2/sec-sanctions

# HHS OIG List of Excluded Individuals and Entities (LEIE)
GET https://api.verifik.co/v2/health-exclusions
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Individual name (physician, executive, broker) or registered company name (e.g. `BERNARD L MADOFF`). |
| `documentNumber` | string | **Conditional** | Tax ID, NPI (National Provider Identifier), or social security / passport code. |
| `documentType` | string | No | Document type (e.g., `NPI`, `EIN`, `PAS`, `CC`). |

### Use Cases

- **Healthcare Provider Credentialing:** Screen doctors, nurses, pharmacists, and medical suppliers to prevent billing exclusion penalties under HHS LEIE regulations.
- **Fintech & Investment Advisor Due Diligence:** Screen financial advisors, broker-dealers, and crypto investment platforms against SEC PAUSE alerts.
- **Corporate Health Plan Administration:** Safeguard employer healthcare networks against fraudulent billing from debarred clinical laboratories.

```python
import http.client
import urllib.parse
import json

conn = http.client.HTTPSConnection("api.verifik.co")
params = urllib.parse.urlencode({"fullName": "BERNARD L MADOFF"})
headers = {
    "Accept": "application/json",
    "Authorization": "Bearer <your_token>"

conn.request("GET", f"/v2/sec-sanctions?{params}", headers=headers)
res = conn.getresponse()
data = res.read()

print(json.loads(data.decode("utf-8")))
```
