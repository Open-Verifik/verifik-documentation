# EU Terrorists & Consolidated Financial Sanctions

Compliance with **European Union restrictive measures (sanctions)** is legally binding on all EU individuals, legal entities incorporated under the law of an EU Member State, and any business conducted within the European Union.

Verifik provides dual endpoints covering both targeted anti-terrorism designations and the comprehensive financial sanctions regime:

1. **EU Common Position on Combating Terrorism (`/v2/eu-terrorists`)**: Implements **Council Common Position 2001/931/CFSP** and Regulation (EC) No 2580/2001, targeting individuals, groups, and entities involved in terrorist acts.
2. **EU Consolidated Financial Sanctions (`/v2/eu-financial-sanctions`)**: Official database maintained by the **European External Action Service (EEAS)** and Directorate-General for Financial Stability, Financial Services and Capital Markets Union (**DG FISMA**), enforcing asset freezes, prohibitions on providing funds or economic resources, and sector-specific restrictions.

## API Reference

### Endpoints

```http
# EU Anti-Terrorism Common Position screening
GET https://api.verifik.co/v2/eu-terrorists

# EU Consolidated Financial Sanctions screening
GET https://api.verifik.co/v2/eu-financial-sanctions
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Full name or company name to search (e.g. `HAMAS` or individual name). |
| `documentNumber` | string | **Conditional** | Document number. When passed alongside `documentType`, Verifik resolves identity before screening. |
| `documentType` | string | No | Document type (e.g., `PAS`, `CC`, `DNI`). |

### Use Cases

- **SEPA & SWIFT Wire Processing:** Prevent execution of cross-border wire transfers involving designated European sanctions targets.
- **Supply Chain & Trade Compliance:** Comply with EU export bans and dual-use goods prohibitions.
- **Fintech & Crypto KYC:** Block prohibited crypto wallet addresses, sanctioned designated persons, and affiliated front businesses.

```python
import http.client
import urllib.parse
import json

conn = http.client.HTTPSConnection("api.verifik.co")
params = urllib.parse.urlencode({"fullName": "ALEXEI NAVALNY"})
headers = {
    "Accept": "application/json",
    "Authorization": "Bearer <your_token>"
}

conn.request("GET", f"/v2/eu-financial-sanctions?{params}", headers=headers)
res = conn.getresponse()
data = res.read()

print(json.loads(data.decode("utf-8")))
```
