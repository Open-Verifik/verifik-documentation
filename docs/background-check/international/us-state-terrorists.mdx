# U.S. State Department Terrorist Designations

The **U.S. Department of State**, in coordination with the Department of Justice and the Department of the Treasury, designates individuals, groups, and charities involved in global terrorism under statutory authorities:

1. **Foreign Terrorist Organizations (FTO)**: Designated pursuant to **Section 219 of the Immigration and Nationality Act (INA)**. It is unlawful under federal law (18 U.S.C. § 2339B) for anyone to knowingly provide material support or resources to an FTO.
2. **Specially Designated Global Terrorists (SDGT)**: Designated pursuant to **Executive Order 13224**, blocking all property and interests in property subject to U.S. jurisdiction.
3. **Terrorist Exclusion List (TEL)**: Created under Section 411 of the **USA PATRIOT Act**, barring affiliated individuals from entering the United States.

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/us-terrorists
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Complete entity name, group title, or individual operative name (e.g. `AL-QA'IDA`). |
| `documentNumber` | string | **Conditional** | Passport or national registration number. |
| `documentType` | string | No | Document type (e.g., `PAS`, `CC`). |

### Use Cases

- **Statutory CFT Compliance:** Satisfy federal counter-terrorism financing mandates and avoid severe criminal liabilities under 18 U.S.C. § 2339B.
- **Cross-Border Payments & Remittances:** Block illicit money flows to designated terrorist networks, front organizations, and illicit charities.
- **Defense, Aerospace & Shipping:** Ensure logistics and shipping charters do not lease cargo capacity to designated organizations.
