# DSS & Secret Service Most Wanted Fugitives

Federal law enforcement agencies within the U.S. Departments of State and Homeland Security maintain specialized most-wanted registries focusing on transnational financial fraud, cyber-attacks, and diplomatic security threats:

1. **Diplomatic Security Service (DSS) & Rewards for Justice (`/v2/dss-most-wanted`)**: The law enforcement and security arm of the **U.S. Department of State**. Investigates international passport and visa fraud, human smuggling, counterintelligence, and terrorism suspects worldwide with active bounties under the *Rewards for Justice* program.
2. **U.S. Secret Service (USSS) Most Wanted (`/v2/secret-service`)**: Department of Homeland Security bureau targeting elite international cybercriminals, major financial fraudsters, ransomware syndicates, bank fraud conspirators, and currency counterfeiters.

---

## API Reference

### Endpoints

```http
# Diplomatic Security Service & Rewards for Justice
GET https://api.verifik.co/v2/dss-most-wanted

# U.S. Secret Service Most Wanted Fugitives
GET https://api.verifik.co/v2/secret-service
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Full name or known alias of the individual to search. |
| `documentNumber` | string | **Conditional** | National ID or passport number. |
| `documentType` | string | No | Document type (e.g., `PAS`, `CC`). |

### Use Cases

- **High-Risk AML & Anti-Fraud Screening:** Detect individuals indicted for large-scale wire fraud, payment processor exploitation, or automated ATM skimming.
- **Identity Verification & Travel Screening:** Flag subjects suspected of passport tampering, visa falsification, or stolen credentials.
- **Critical Infrastructure & IT Hiring:** Screen engineers and system administrators against cybercrime watchlists before granting root access.

<TabItem value="python" label="Python">

```python
import http.client
import urllib.parse
import json

conn = http.client.HTTPSConnection("api.verifik.co")
params = urllib.parse.urlencode({"fullName": "ROMAN VALEREEVICH SELEZNEV"})
headers = {
    "Accept": "application/json",
    "Authorization": "Bearer <your_token>"
}

conn.request("GET", f"/v2/secret-service?{params}", headers=headers)
res = conn.getresponse()
data = res.read()

print(json.loads(data.decode("utf-8")))
```
