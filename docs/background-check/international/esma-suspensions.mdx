# EU ESMA Suspensions and Removals

Screen a person or organization against the **EU ESMA Suspensions and Removals**. The European Securities and Markets Authority publishes this list for the European Union.

ESMA publishes suspensions and removals of financial instruments from trading, as reported by European Union trading venues.

Send `fullName`, `documentNumber`, or both. At least one of the two is required. The response sets `foundInEsmaSuspensions` to `true` when the query matches a published record and to `false` when it does not. On a match, `details` includes the party name, the regulator, the action type, the action date, and a short summary. Use the result in KYC, AML/CFT, vendor onboarding, and payment screening. Review every match before you rely on it. This call does not replace the official list and it is not a legal determination.

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/esma-suspensions
```

A successful response returns `data.fullName`, `data.firstName` and `data.lastName` when the source record splits the name, `data.documentNumber` when you sent one, `data.foundInEsmaSuspensions`, and `data.details`. On a match, `details` includes the party name, the regulator, the action type, the action date, and a short summary. The `signature` object includes `dateTime` and the message `Certified by Verifik.co`. When `foundInEsmaSuspensions` is `false`, `details` is an empty object.

### Headers

| Name          | Value              | Description     |
| ------------- | ------------------ | --------------- |
| Content-Type  | `application/json` | Request format  |
| Accept        | `application/json` | Response format |
| Authorization | `Bearer <token>`   | Verifik JWT     |

### Parameters

| Parameter        | Type   | Required    | Example                  | Description                                                                                                            |
| ---------------- | ------ | ----------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `fullName`       | string | Conditional | `SAMPLE DESIGNATED NAME` | Full legal name of the person, or the registered name of the organization. Required when `documentNumber` is not sent. |
| `documentNumber` | string | Conditional | `A1234567`               | Identification number or corporate registration number, without spaces. Required when `fullName` is not sent.          |

### Use Cases

- **Supervisory screening:** Check firms, directors, and counterparties against this regulator's published actions.
- **Financial-sector due diligence:** Use the result when onboarding a correspondent, broker, or vendor.
- **Policy evidence:** Retain the certified response when your procedure names this source.

### Notes

- Send `fullName` or `documentNumber`. At least one is required. If both are missing, the API returns HTTP 409 with code `MissingParameter` and the message `Either fullName or documentNumber must be provided`.
- `foundInEsmaSuspensions` is `true` when the query matches a record on this list and `false` when it does not. `details` is an empty object when there is no match.
- The match example shows the response shape. A live match returns the attributes published for that record on this list.
- A match is a screening result for compliance review. It is not a legal determination and it does not replace the official source.
- Authenticate with a Bearer JWT in the `Authorization` header. Create or renew the JWT with the [authentication API](/authentication/renew-your-token-jwt).
- The result reflects the list at the time of the call. Run a new request when you need a later result.
