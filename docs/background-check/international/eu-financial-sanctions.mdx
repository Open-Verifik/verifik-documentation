# EU Consolidated Financial Sanctions (FSF)

The **European Union Consolidated Financial Sanctions Database (FSF)** is the official database maintained by the **European External Action Service (EEAS)** and Directorate-General for Financial Stability, Financial Services and Capital Markets Union (**DG FISMA**).

It contains all individuals, groups, and entities subject to EU financial sanctions under Council Regulations, including asset freezes, prohibitions on providing funds or economic resources, and sector-specific restrictions.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/eu-financial-sanctions
```

### Headers

| Name          | Value              | Description |
| ------------- | ------------------ | ----------- |
| Content-Type  | `application/json` | Request format |
| Accept        | `application/json` | Response format |
| Authorization | `Bearer <token>`   | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Full name or company name to search. Required if document parameters are not provided. |
| `documentNumber` | string | **Conditional** | Document number. Required if fullName is not provided. |
| `documentType` | string | No | Document type (e.g., `PAS`, `CC`, `DNI`, `NIT`). Default: `CC`. |

### Use Cases

- **Mandatory EU Sanctions Screening:** Comply with European Union asset freezing orders and trade restrictions across financial institutions.
- **Trade & Export Due Diligence:** Screen trading partners, consignees, and buyers to avoid prohibited transactions with EU-sanctioned actors.
- **Vendor & Corporate KYC:** Screen beneficial owners and corporate entities against European restrictive measures.
