# EU Consolidated Travel Bans

Screen a person or organization against the **EU Consolidated Travel Bans**. The Council of the European Union publishes this list for the European Union.

The consolidated travel-ban list names persons who are prohibited from entering or transiting the European Union under Council decisions.

Send `fullName`, `documentNumber`, or both. At least one of the two is required. The response sets `foundInEuTravelBans` to `true` when the query matches a published record and to `false` when it does not. On a match, `details` includes the listed name, the restriction program, the issuing authority, and remarks. Use the result in KYC, AML/CFT, vendor onboarding, and payment screening. Review every match before you rely on it. This call does not replace the official list and it is not a legal determination.

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/eu-travel-bans
```

A successful response returns `data.fullName`, `data.firstName` and `data.lastName` when the source record splits the name, `data.documentNumber` when you sent one, `data.foundInEuTravelBans`, and `data.details`. On a match, `details` includes the listed name, the restriction program, the issuing authority, and remarks. The `signature` object includes `dateTime` and the message `Certified by Verifik.co`. When `foundInEuTravelBans` is `false`, `details` is an empty object.

### Headers

| Name          | Value              | Description     |
| ------------- | ------------------ | --------------- |
| Content-Type  | `application/json` | Request format  |
| Accept        | `application/json` | Response format |
| Authorization | `Bearer <token>`   | Verifik JWT     |

### Parameters

| Parameter        | Type   | Required    | Example                  | Description                                                                                                            |
| ---------------- | ------ | ----------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `fullName`       | string | Conditional | `SAMPLE DESIGNATED NAME` | Full legal name of the person, or the registered name of the organization. Required when `documentNumber` is not sent. |
| `documentNumber` | string | Conditional | `A1234567`               | Identification number or corporate registration number, without spaces. Required when `fullName` is not sent.          |

### Use Cases

- **Travel and visa screening:** Check a person against this published visa-restriction list.
- **Sanctions programs:** Use the result where a compliance program references visa bans.
- **Records:** Store the certified response with the other screening results.

### Notes

- Send `fullName` or `documentNumber`. At least one is required. If both are missing, the API returns HTTP 409 with code `MissingParameter` and the message `Either fullName or documentNumber must be provided`.
- `foundInEuTravelBans` is `true` when the query matches a record on this list and `false` when it does not. `details` is an empty object when there is no match.
- The match example shows the response shape. A live match returns the attributes published for that record on this list.
- A match is a screening result for compliance review. It is not a legal determination and it does not replace the official source.
- Authenticate with a Bearer JWT in the `Authorization` header. Create or renew the JWT with the [authentication API](/authentication/renew-your-token-jwt).
- The result reflects the list at the time of the call. Run a new request when you need a later result.
