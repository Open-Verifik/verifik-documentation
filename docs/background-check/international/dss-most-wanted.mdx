# Diplomatic Security Service (DSS) Most Wanted

The **Diplomatic Security Service (DSS)** is the law enforcement and security arm of the **U.S. Department of State**. DSS investigates transnational crimes that threaten diplomatic security, including international passport and visa fraud, human smuggling, counterintelligence, and international terrorism.

Through the **Rewards for Justice (RFJ)** program, the State Department offers substantial monetary rewards for information leading to the arrest or conviction of high-profile international fugitives.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/dss-most-wanted
```

### Headers

| Name          | Value              | Description |
| ------------- | ------------------ | ----------- |
| Content-Type  | `application/json` | Request format |
| Accept        | `application/json` | Response format |
| Authorization | `Bearer <token>`   | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Full name or known alias of the individual to search. Required if document parameters are not provided. |
| `documentNumber` | string | **Conditional** | Document number. Required if fullName is not provided. |
| `documentType` | string | No | Document type (e.g., `PAS`, `CC`, `DNI`). Default: `CC`. |

### Use Cases

- **Identity Verification & Travel Screening:** Flag individuals suspected of passport tampering, visa falsification, or stolen credentials.
- **High-Risk Background Checks:** Identify subjects with active federal bounties under the Rewards for Justice program.
- **Immigration & Onboarding Due Diligence:** Screen foreign nationals and contractor candidates against international diplomatic security registries.
