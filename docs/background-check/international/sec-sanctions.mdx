# U.S. SEC Sanctions & Enforcement

The **U.S. Securities and Exchange Commission (SEC)** is the federal regulatory body responsible for protecting investors, maintaining fair, orderly, and efficient markets, and facilitating capital formation.

The SEC enforcement registry tracks civil injunctive actions, administrative proceedings, trading suspensions, and the **PAUSE list** (*Public Alert: Unregistered Soliciting Entities*), which identifies entities falsely claiming to be registered or licensed in the U.S.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/sec
```

*Alias route:* `GET https://api.verifik.co/v2/sec-sanctions`

### Headers

| Name          | Value              | Description |
| ------------- | ------------------ | ----------- |
| Content-Type  | `application/json` | Request format |
| Accept        | `application/json` | Response format |
| Authorization | `Bearer <token>`   | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Individual name (executive, broker, advisor) or registered legal entity name. Required if document parameters are not provided. |
| `documentNumber` | string | **Conditional** | Tax identification number or corporate registration code. Required if fullName is not provided. |
| `documentType` | string | No | Document type (e.g., `EIN`, `PAS`, `CC`). Default: `CC`. |

### Use Cases

- **Capital Markets Due Diligence:** Screen broker-dealers, investment advisors, and fund managers prior to institutional onboarding.
- **Investor Protection:** Identify solicitations originating from unregistered entities on the SEC PAUSE list.
- **M&A Executive Screening:** Ensure target company officers and directors have no active SEC disqualifications or penny stock bars.
