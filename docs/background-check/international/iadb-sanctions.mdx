# Inter-American Development Bank (IDB) Sanctions

The **Inter-American Development Bank (IDB / BID)** Sanctions List comprises firms and individuals that have been sanctioned by the IDB Group Sanctions Committee for engaging in prohibited practices—including fraud, corruption, collusion, and coercion—in connection with IDB-financed activities.

Sanctions imposed by the IDB Group include public debarment, conditional non-debarment, and reprimands, and are enforced globally across participating MDBs through the 2010 Cross-Debarment Agreement.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/iadb-sanctions
```

### Headers

| Name          | Value              | Description |
| ------------- | ------------------ | ----------- |
| Content-Type  | `application/json` | Request format |
| Accept        | `application/json` | Response format |
| Authorization | `Bearer <token>`   | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Full corporate or individual name to search. Required if document parameters are not provided. |
| `documentNumber` | string | **Conditional** | Corporate Tax ID or national identity number. Required if fullName is not provided. |
| `documentType` | string | No | Document type (e.g., `NIT`, `EIN`, `CC`, `PAS`). Default: `CC`. |

### Use Cases

- **Latin American Infrastructure Due Diligence:** Screen contractors and engineering firms bidding on infrastructure projects in Latin America and the Caribbean.
- **Cross-Debarment Verification:** Ensure compliance with multilateral bank sanctions before executing consortium or joint-venture agreements.
- **Vendor Integrity Programs:** Maintain an automated audit trail for supplier compliance under institutional anti-corruption guidelines.
