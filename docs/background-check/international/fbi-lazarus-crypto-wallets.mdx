# Watchlist — FBI Lazarus crypto wallets

Screen a wallet address against the FBI Lazarus Group crypto-wallet list. Put the address in fullName.

## What the call returns

- `foundInCryptoFbiLazarus`
- `details` on a match
- `fullName`

## Use cases

- Screen before you pay or onboard.
- Treat a false flag as a clean 200.
- Send a name, or a document type plus number.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/crypto/fbi-lazarus
```

A match sets `foundInCryptoFbiLazarus` to true and fills `details`. A subject who is not on the list is HTTP 200 with `foundInCryptoFbiLazarus` false and empty `details`.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | `SAMPLE NAME` | Name or, for a wallet list, the address. Enough on its own. |
| `documentType` | string | **Conditional** | `CPF` | Required with `documentNumber` when `fullName` is omitted. CPF without a name also needs `dateOfBirth`. |
| `documentNumber` | string | **Conditional** | `12345678901` | Identifier of at least 5 characters, sent with `documentType` when `fullName` is omitted. |
| `dateOfBirth` | string | **Conditional** | `1990-01-15` | Required for CPF, CI, CCPA, DUI, or CCUY when `fullName` is omitted. |

### Notes

- Send `fullName`, or both `documentType` and `documentNumber`.
- A person or address that is not listed is HTTP 200 with `foundInCryptoFbiLazarus` false.
- CPF without a name also needs `dateOfBirth`.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |
| Record on file | `fullName: "0x1111111111111111111111111111111111111111"` | 200 with foundInCryptoFbiLazarus true when the list matches. |
| Missing required value | Omit fullName and the document pair | 409 when fullName and the document pair are both absent. |
| Unknown value | `fullName: "CLEAN SAMPLE"` | 200 with foundInCryptoFbiLazarus false when the subject is simply not listed. |

401 when the bearer token is missing or rejected.
