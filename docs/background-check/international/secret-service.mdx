# U.S. Secret Service Most Wanted Fugitives

The **United States Secret Service (USSS)**, an agency of the **Department of Homeland Security**, investigates major financial crimes, transnational cybercrime, payment systems fraud, ransomware attacks, identity theft, and currency counterfeiting.

The USSS Most Wanted list tracks international suspects and cybercriminals facing federal indictments with active arrest warrants and multi-million dollar rewards.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/secret-service
```

### Headers

| Name          | Value              | Description |
| ------------- | ------------------ | ----------- |
| Content-Type  | `application/json` | Request format |
| Accept        | `application/json` | Response format |
| Authorization | `Bearer <token>`   | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Full name or known alias of the individual to search. Required if document parameters are not provided. |
| `documentNumber` | string | **Conditional** | Document number. Required if fullName is not provided. |
| `documentType` | string | No | Document type (e.g., `PAS`, `CC`, `DNI`). Default: `CC`. |

### Use Cases

- **Anti-Fraud & Financial Crime Screening:** Detect suspects wanted for large-scale wire fraud, payment processor exploitation, or banking breaches.
- **Cybersecurity & Executive Due Diligence:** Screen key technical personnel and third-party contractors against federal cybercrime watchlists.
- **AML / SAR Investigations:** Cross-reference flagged transactions against Secret Service fugitives.
