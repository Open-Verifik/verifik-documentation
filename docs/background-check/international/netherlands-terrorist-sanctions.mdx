# Netherlands National Sanctionlist Terrorism

Screen a person or organization against the **Netherlands National Sanctionlist Terrorism**. The Dutch government publishes this list for the Netherlands.

The Netherlands publishes the national sanctions list for terrorism, naming persons and entities subject to Dutch national terrorist-sanctions measures.

Send `fullName`, `documentNumber`, or both. At least one of the two is required. The response sets `foundInNetherlandsTerroristSanctions` to `true` when the query matches a published record and to `false` when it does not. On a match, `details` includes the designated name, the authority, the designation date, aliases when the source provides them, and remarks. Use the result in KYC, AML/CFT, vendor onboarding, and payment screening. Review every match before you rely on it. This call does not replace the official list and it is not a legal determination.

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/netherlands-terrorist-sanctions
```

A successful response returns `data.fullName`, `data.firstName` and `data.lastName` when the source record splits the name, `data.documentNumber` when you sent one, `data.foundInNetherlandsTerroristSanctions`, and `data.details`. On a match, `details` includes the designated name, the authority, the designation date, aliases when the source provides them, and remarks. The `signature` object includes `dateTime` and the message `Certified by Verifik.co`. When `foundInNetherlandsTerroristSanctions` is `false`, `details` is an empty object.

### Headers

| Name          | Value              | Description     |
| ------------- | ------------------ | --------------- |
| Content-Type  | `application/json` | Request format  |
| Accept        | `application/json` | Response format |
| Authorization | `Bearer <token>`   | Verifik JWT     |

### Parameters

| Parameter        | Type   | Required    | Example                  | Description                                                                                                            |
| ---------------- | ------ | ----------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `fullName`       | string | Conditional | `SAMPLE DESIGNATED NAME` | Full legal name of the person, or the registered name of the organization. Required when `documentNumber` is not sent. |
| `documentNumber` | string | Conditional | `A1234567`               | Identification number or corporate registration number, without spaces. Required when `fullName` is not sent.          |

### Use Cases

- **Terrorist-designation screening:** Check parties against this published designation list.
- **CFT controls:** Use the result in payment screening and counter-terrorist financing reviews.
- **Escalation:** Route a match to compliance review before you proceed.

### Notes

- Send `fullName` or `documentNumber`. At least one is required. If both are missing, the API returns HTTP 409 with code `MissingParameter` and the message `Either fullName or documentNumber must be provided`.
- `foundInNetherlandsTerroristSanctions` is `true` when the query matches a record on this list and `false` when it does not. `details` is an empty object when there is no match.
- The match example shows the response shape. A live match returns the attributes published for that record on this list.
- A match is a screening result for compliance review. It is not a legal determination and it does not replace the official source.
- Authenticate with a Bearer JWT in the `Authorization` header. Create or renew the JWT with the [authentication API](/authentication/renew-your-token-jwt).
- The result reflects the list at the time of the call. Run a new request when you need a later result.
