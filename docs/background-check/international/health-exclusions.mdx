# U.S. Health Exclusions (HHS OIG LEIE)

The **List of Excluded Individuals and Entities (LEIE)** is administered by the **U.S. Department of Health and Human Services Office of Inspector General (HHS OIG)** pursuant to Sections 1128 and 1156 of the Social Security Act.

Healthcare practitioners, clinics, pharmacies, and billing agencies on the LEIE are prohibited from participating in and receiving payments from federal healthcare programs—including Medicare, Medicaid, and TRICARE. Employing or contracting with an excluded party exposes healthcare organizations to mandatory Civil Monetary Penalties (CMP).

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/health-exclusions
```

### Headers

| Name          | Value              | Description |
| ------------- | ------------------ | ----------- |
| Content-Type  | `application/json` | Request format |
| Accept        | `application/json` | Response format |
| Authorization | `Bearer <token>`   | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditional** | Healthcare provider full name or company name to search. Required if document parameters are not provided. |
| `documentNumber` | string | **Conditional** | National Provider Identifier (NPI), Tax ID, or identity document number. Required if fullName is not provided. |
| `documentType` | string | No | Document type (e.g., `NPI`, `EIN`, `PAS`, `CC`). Default: `CC`. |

### Use Cases

- **Healthcare Provider Credentialing:** Screen doctors, nurses, specialists, and administrative staff prior to onboarding and periodically during employment.
- **Vendor & Supplier Screening:** Ensure medical equipment suppliers, pharmacies, and billing agencies are eligible to bill federal health programs.
- **Regulatory CMP Penalty Prevention:** Prevent statutory penalties resulting from contracting with federally excluded healthcare entities.
