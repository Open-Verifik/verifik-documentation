# Global — Politically Exposed Persons (PEP)

Screen a person across jurisdictions by **passport or other document number** (`documentNumber`) or by **full legal name** (`fullName`) on `GET /v2/world/pep`. The same handler is also available at `GET /v2/world/politically-exposed-persons`. The check follows **FATF Recommendation 12** for foreign and domestic politically exposed persons and keeps a **5-year lookback** after a public mandate ends.

- **Framework:** FATF / GAFI Recommendation 12 (Politically Exposed Persons — Foreign & Domestic PEPs)
- **Authority:** Financial Action Task Force (FATF / GAFI) / OpenSanctions Global PEP Registry
- **Primary source:** OpenSanctions Global Politically Exposed Persons (PEPs) Consolidated Dataset & Wikidata Officeholders (`https://data.opensanctions.org/datasets/latest/peps/targets.simple.csv`)

- Cross-border onboarding when the subject's country is not covered by a single-country PEP endpoint.
- Optional `country` filter (ISO 3166-1 alpha-2) to limit the global registry to one jurisdiction.
- Enhanced due diligence and periodic rescreening of foreign PEPs.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/world/pep
```

A successful call returns `country`, `jurisdiction`, `documentType`, `documentNumber`, `fullName`, `isPEP`, `isActivePep`, `isFormerPep`, `totalMatches`, `matchCount`, `categories`, `includeFormer`, `lookbackYears` (5), `matches`, `checkedSources`, `regulation`, and `dateTime`. Each match includes `position`, `entity`, `category`, `categoryDescription`, `status` (`ACTIVE` or `FORMER_PEP`), `source`, and `sourceUrl`. The decision flag on the root object is `isPEP`. Each match uses `isPep`. A person who is not a PEP is still HTTP 200, with `isPEP` false and `totalMatches` 0.

### Headers

| Name | Value |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <your_token>` |

### Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | Conditional | Passport number. 3 to 40 characters. Required when `fullName` is omitted. Aliases: `id`, `dni`, `cedula`. Example: `WORLD-PEP-Q22686`. |
| `fullName` | string | Conditional | Full legal name, 3 to 160 characters. Required when `documentNumber` is omitted. Alias: `name`. Example: `URSULA GERTRUD VON DER LEYEN`. |
| `documentType` | string | No | Document type, 2 to 20 characters. Defaults to `PASSPORT` and is echoed in the response. |
| `includeFormer` | boolean | No | Include officeholders whose mandate ended inside the 5-year lookback. Defaults to `true`. Pass `false` to keep only `ACTIVE` roles. A former-only hit then returns `isPEP` false and an empty `matches` array. |
| `country` | string | No | Optional ISO 3166-1 alpha-2 country code, 2 to 10 characters (for example `PL`). Omit it to search the consolidated global registry. |

---

## PEP categories

Each match is classified from the office title into one of these categories:

| Category | Description |
| :--- | :--- |
| `HEAD_OF_STATE_OR_GOVERNMENT` | Head of state, head of government, or cabinet executive authority |
| `SENIOR_EXECUTIVE` | Senior executive-branch official or cabinet minister |
| `LEGISLATIVE` | Member of the national parliament or legislative assembly |
| `JUDICIAL_OR_OVERSIGHT` | Senior judicial, constitutional, or supreme audit authority |
| `DIPLOMATIC_MILITARY_OR_CENTRAL_BANK` | Senior diplomatic, military, or central-bank official |
| `PUBLIC_OFFICIAL_PEP` | Politically exposed person under FATF Recommendation 12 |

## Sandbox probes

With the account in sandbox mode, these values are deterministic:

| Document number | Full name | includeFormer | Result |
| :--- | :--- | :--- | :--- |
| `WORLD-PEP-Q22686` | `URSULA GERTRUD VON DER LEYEN` | `true` | Active PEP (`isPEP` true, category `HEAD_OF_STATE_OR_GOVERNMENT`) |
| `10000001` | `URSULA GERTRUD VON DER LEYEN` | `true` | Active PEP (same fixture as document number `10000001`) |
| `10000002` | `PEP FORMER MINISTER` | `true` | Former PEP (`isFormerPep` true) while `includeFormer` is true |
| `10000002` | `PEP FORMER MINISTER` | `false` | Clean result when `includeFormer` is false |
| `55555555` | `JUAN CARLOS CIUDADANO NO PEP` | `true` | Clean non-PEP (`isPEP` false, `totalMatches` 0) |
| `99999404` | `—` | `true` | 404 `NotFound` (sandbox probe only) |

### Notes

- Send `documentNumber` or `fullName`. The document aliases are `id`, `dni`, and `cedula`. The name alias is `name`. If none of them is present, the API returns 409 `MissingParameter` with message `Either documentNumber or fullName must be provided.`
- `includeFormer` defaults to true. Former officeholders inside the 5-year window come back with `status` `FORMER_PEP`, `isFormerPep` true, and `isPEP` true. `false` drops those rows and leaves only active roles.
- `documentType` defaults to `PASSPORT`. `jurisdiction` in the payload is the registry label `Otros países (Global PEP)`. `regulation.lookbackYears` is 5.
- Sandbox active hit: document `WORLD-PEP-Q22686` or name `URSULA GERTRUD VON DER LEYEN`, and also document `10000001`. Former hit: document `10000002` or a name containing `PEP FORMER`, `EX MINISTRO`, or `FORMER MINISTER`. Clean hit: document `55555555` with name `JUAN CARLOS CIUDADANO NO PEP`. A document number containing `99999404`, or a name containing `NOTFOUND`, returns 404 in sandbox. A live miss is HTTP 200 with `isPEP` false, not 404.
- Country endpoints stay on `/v2/` plus the ISO code plus `/politically-exposed-persons`. This global route does not replace those country pages. Pass `country` only when you want to narrow this global search.
- `checkedSources` lists the registry keys consulted for this jurisdiction. `regulation.framework` and `regulation.authority` identify the AML basis returned with the result.
