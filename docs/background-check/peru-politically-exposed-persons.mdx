# Peru — Politically Exposed Persons (PEP / SBS PLAFT)

Screen Peruvian **DNI** (*Documento Nacional de Identidad*), **CE** (*Carné de Extranjería*), or **full names** against the consolidated Peruvian Politically Exposed Persons (PEP) directory for **PLAFT** (*Prevención del Lavado de Activos y del Financiamiento del Terrorismo*) compliance under:

- **Resolución SBS N° 2660-2015** (*Reglamento de Gestión de Riesgos de Lavado de Activos y del Financiamiento del Terrorismo*)
- **Resolución SBS N° 4349-2016** (modified by **Resolución SBS N° 00199-2025** and **Resolución SBS N° 02868-2025**), including the **Anexo Numeral 2** classification categories (`a` through `m`) and the mandatory **2-year post-cessation look-back window** (*ex-PEP*).

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/pe/politically-exposed-persons
```

### Headers

| Name | Value |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Query Parameters

At least one of `documentNumber` or `fullName` must be provided.

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | Conditional | Peruvian DNI (8 digits) or CE (9–12 alphanumeric characters). Required if `fullName` is omitted. |
| `documentType` | string | No | `DNI` (default) or `CE`. |
| `fullName` | string | Conditional | Full name of the individual to screen (e.g., `DINA ERCILIA BOLUARTE ZEGARRA`). Required if `documentNumber` is omitted. |
| `includeFormer` | boolean | No | Include former PEPs (*ex-PEP*) within the 2-year post-cessation look-back window established by Res. SBS 4349-2016 / 02868-2025. Defaults to `true`. Set to `false` to return only currently active roles. |
| `force` | boolean | No | Bypass the recent lookup cache and force a fresh verification. |

---

## SBS Anexo Numeral 2 Categories (`a` – `m`)

Each matched record is automatically classified into the corresponding **SBS Resolution 4349-2016 / 02868-2025 Anexo Numeral 2** category:

| Category | Description (SBS Anexo Numeral 2) |
| :--- | :--- |
| `a` | President of the Republic, Vice Presidents, Members of Congress (*Congresistas*), and Andean Parliamentarians |
| `b` | Ministers, Vice Ministers, Secretaries General, and Executive Heads of National Public Entities |
| `c` | Regional Governors, Deputy Governors, Regional Councilors, Mayors (*Alcaldes*), and Municipal Councilors (*Regidores*) |
| `d` | Supreme and Superior Court Judges, Constitutional Tribunal Magistrates, JNJ, and Supreme/Superior Prosecutors |
| `e` | Heads and Board Members of Constitutional Autonomous Bodies (BCRP, SBS, JNE, ONPE, RENIEC, Contraloría, Defensoría) |
| `f` | General and Flag Officers of the Armed Forces (*Fuerzas Armadas*) and National Police of Peru (*PNP*) |
| `g` | Ambassadors, Consuls, and Senior Diplomatic Representatives |
| `h` | Board Members, General Managers, and Senior Executives of State-Owned Enterprises (FONAFE, Petroperú, Banco de la Nación) |
| `i` | Founders, National Executive Committee (CEN) Members, and Legal Representatives of Political Parties |
| `j` | Senior Officials of International Organizations operating in Peru |
| `k` | Public Officials responsible for Public Administration, Budget, Finance, Logistics, Treasury, and State Procurement |
| `l` | Close Associates, Collaborators, and Relatives up to the second degree of consanguinity / affinity |
| `m` | Other Senior Public Officials and Directors required to file Sworn Declarations (*DDJJ / DJI*) |
