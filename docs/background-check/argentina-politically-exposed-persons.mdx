# Argentina — Politically Exposed Persons (PEP / UIF Res. 35/2023)

Screen Argentine citizens by **DNI, CUIT, or CUIL (`documentNumber`)** or **Full Legal Name (`fullName`)** against consolidated official registries of Politically Exposed Persons (PEP) for anti-money laundering and terrorism financing prevention (AML/CFT) under:

- **Resolución UIF N° 35/2023** (*Nómina de Personas Expuestas Políticamente de la Unidad de Información Financiera*)
- **Decreto N° 823/2021** (Régimen de Integridad y Transparencia de la Administración Pública Nacional)
- Mandatory **2-year post-mandate lookback window** (*período de carencia* following cessation of public duties).

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/ar/politically-exposed-persons
```

### Headers

| Name | Value |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | Conditional | Argentine DNI, CUIT, or CUIL (e.g. `12063372` or `22195694`). Required if `fullName` is omitted. |
| `dni` | string | Conditional | Alias for `documentNumber`. |
| `documentType` | string | No | Document type: `DNI` (default), `CUIT`, or `CUIL`. |
| `fullName` | string | Conditional | Full legal name of the individual to screen. Required if document number is omitted. |
| `includeFormer` | boolean | No | Include former PEPs (*ex-PEP*) within the 2-year statutory lookback window. Defaults to `true`. |
| `force` | boolean | No | Bypass recent lookup cache and force fresh screening. |

### Notes

- Regulatory screening for financial institutions, fintechs, exchange houses, insurance companies, and entities supervised by UIF Argentina.
- When `includeFormer=true`, former public officials within the 2-year statutory lookback window are returned with `isFormerPep: true` and `isPep: true`.
- In sandbox mode, test DNIs include `12063372` (President of Argentina), `22195694` (Minister of Economy), and `35123456` (Clean / Non-PEP).
