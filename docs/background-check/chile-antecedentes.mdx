# Chile - Certificado de Antecedentes

The **Certificado de Antecedentes** is the criminal-record certificate that Chile's Registro Civil (SRCEI) issues. Ride-hailing and delivery platforms usually ask drivers to upload one during onboarding.

Verifik checks it with the [Civil Registry Certificate Verification](/background-check/chile-certificate-verify) endpoint. You don't need a separate product.

## What you need from the applicant

| Field              | Where it appears on the certificate | Example        |
| ------------------ | ----------------------------------- | -------------- |
| `folio`            | Folio number, 10 to 15 characters   | `50070080804`  |
| `verificationCode` | Código Verificador                  | `2aacbb9a636a` |

## Request

```bash
curl -G "https://api.verifik.co/v2/cl/registro-civil/certificado" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  --data-urlencode "folio=50070080804" \
  --data-urlencode "verificationCode=2aacbb9a636a"
```

The response confirms that the Registro Civil issued the certificate. It returns the holder's `name`, `run`, and `dateOfBirth`, each conviction register with its `fines` entry (for example `No registra anotaciones`), and the official PDF as `urlPDF` and `pdfBase64`. See the [full reference](/background-check/chile-certificate-verify) for every field and error.

## Onboarding checks

- **Match the holder.** Compare `details.run` with the applicant's ID. You can confirm the RUN with [Chilean Citizen](/identity/chile).
- **Check the issue date.** Many programs only accept certificates issued in the last 60 days. The issue date is printed on the returned PDF.
- **Review registers.** Each entry in `details.registers` names a register and what it records. Decide which entries block onboarding under your policy.

A criminal-record lookup by RUN alone requires the applicant's ClaveÚnica, so the certificate folio is the way to check it through Verifik.
