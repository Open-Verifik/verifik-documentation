# Colombia — Junta Central de Contadores (JCC) Disciplinary Sanctions

The **Junta Central de Contadores (JCC)** is the official disciplinary tribunal and regulatory authority for the accounting profession in Colombia under Law 43 of 1990 and Decree 1955 of 2010.

Verifik provides direct integration with the official registry to verify whether an individual public accountant (*Contador Público*) or accounting firm (*Sociedad de Contadores Públicos*) has active or historical disciplinary sanctions, suspensions, or cancellations of their professional registration card (*Tarjeta Profesional*).

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/jcc
```

*Alias route:* `GET https://api.verifik.co/v2/co/jcc/sanctions`

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Yes** | Document number to consult (5 to 15 digits, without dots or hyphens). E.g. `14322443` or `900123456`. |
| `documentType` | string | No | Document type: `CC` (default), `CE`, or `NIT`. |

### Use Cases

- **Vendor & Auditor Onboarding:** Ensure external audit teams, statutory auditors (*Revisores Fiscales*), and accounting advisors maintain unblemished professional standing.
- **Corporate Compliance & SOX:** Mitigate financial reporting risk by validating that signing accountants are legally authorized to certify financial statements under Colombian law.
- **Procurement & Tenders:** Comply with statutory requirements when contracting consulting or accounting firms for public and private tenders.
