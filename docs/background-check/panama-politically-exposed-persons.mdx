# Panama — Politically Exposed Persons (PEP / Ley 23 de 2015 & SBP 10-2015)

Screen Panamanian citizens by **Cédula (`documentNumber` or `cedula`)** or **Full Legal Name (`fullName`)** against consolidated official registries of Politically Exposed Persons (PEP) for anti-money laundering (AML/CFT) compliance under:

- **Ley N° 23 de 2015** (*Que adopta medidas para prevenir el blanqueo de capitales, el financiamiento del terrorismo y el financiamiento de la proliferación de armas de destrucción masiva*)
- **Acuerdo SBP N° 10-2015** (Superintendencia de Bancos de Panamá - Prevención de Blanqueo de Capitales)
- Mandatory **2-year post-mandate lookback window** (*período de carencia* following cessation of public duties).

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/pa/politically-exposed-persons
```

### Headers

| Name | Value |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `cedula` | string | Conditional | Panamanian Cédula (e.g. `8-204-1062` or `8-0204-01062`). Required if `fullName` is omitted. |
| `documentNumber` | string | Conditional | Alias for `cedula`. |
| `documentType` | string | No | Document type: `CEDULA` (default) or `CCPA`. |
| `fullName` | string | Conditional | Full legal name of the individual to screen. Required if cédula is omitted. |
| `includeFormer` | boolean | No | Include former PEPs (*ex-PEP*) within the 2-year post-mandate statutory window. Defaults to `true`. |
| `force` | boolean | No | Bypass recent lookup cache and force fresh screening. |

### Notes

- Mandatory compliance tool for financial entities, lawyers, accountants, real estate developers, and designated non-financial businesses (*APNFD*) regulated under Panamanian AML laws.
- When `includeFormer=true`, individuals who stepped down within the last 2 years are returned with `isFormerPep: true` and `isPep: true`.
- In sandbox mode, test cédulas include `8-204-1062` (Executive Official), `8-161-172` (National Assembly Deputy), and `8-712-901` (Clean / Non-PEP).
