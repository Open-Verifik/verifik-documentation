# France — Politically Exposed Persons (PEP)

Screen a person in **France** by **national identity number** (`documentNumber`) or by **full legal name** (`fullName`) against official politically exposed person (PEP) registers. The check follows **FATF Recommendation 12** and the national AML framework below, and keeps a **5-year lookback** for people whose public mandate has ended.

- **Framework:** Code monétaire et financier (Art. L. 561-10 et R. 561-18) & Loi du 11 octobre 2013 relative à la transparence de la vie publique
- **Authority:** Haute Autorité pour la transparence de la vie publique (HATVP) / TRACFIN
- **Primary source:** Haute Autorité pour la transparence de la vie publique (HATVP) / Assemblée Nationale Open Data (`https://www.hatvp.fr/open-data/`)

- Customer onboarding and enhanced due diligence for domestic PEPs.
- Periodic rescreening when a mandate starts, changes, or ends.
- Name search when the national document number is not yet on file.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/fr/politically-exposed-persons
```

A successful call returns `country`, `jurisdiction`, `documentType`, `documentNumber`, `fullName`, `isPEP`, `isActivePep`, `isFormerPep`, `totalMatches`, `matchCount`, `categories`, `includeFormer`, `lookbackYears` (5), `matches`, `checkedSources`, `regulation`, and `dateTime`. Each match includes `position`, `entity`, `category`, `categoryDescription`, `status` (`ACTIVE` or `FORMER_PEP`), `source`, and `sourceUrl`. The decision flag on the root object is `isPEP`. Each match uses `isPep`. A person who is not a PEP is still HTTP 200, with `isPEP` false and `totalMatches` 0.

### Headers

| Name | Value |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <your_token>` |

### Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | Conditional | National identity number. 3 to 40 characters. Required when `fullName` is omitted. Aliases: `id`, `dni`, `cedula`. Example: `FR-HATVP-77121`. |
| `fullName` | string | Conditional | Full legal name, 3 to 160 characters. Required when `documentNumber` is omitted. Alias: `name`. Example: `EMMANUEL JEAN MICHEL FREDERIC MACRON`. |
| `documentType` | string | No | Document type, 2 to 20 characters. Defaults to `ID` and is echoed in the response. |
| `includeFormer` | boolean | No | Include officeholders whose mandate ended inside the 5-year lookback. Defaults to `true`. Pass `false` to keep only `ACTIVE` roles. A former-only hit then returns `isPEP` false and an empty `matches` array. |

---

## PEP categories

Each match is classified from the office title into one of these categories:

| Category | Description |
| :--- | :--- |
| `HEAD_OF_STATE_OR_GOVERNMENT` | Head of state, head of government, or cabinet executive authority |
| `SENIOR_EXECUTIVE` | Senior executive-branch official or cabinet minister |
| `LEGISLATIVE` | Member of the national parliament or legislative assembly |
| `JUDICIAL_OR_OVERSIGHT` | Senior judicial, constitutional, or supreme audit authority |
| `DIPLOMATIC_MILITARY_OR_CENTRAL_BANK` | Senior diplomatic, military, or central-bank official |
| `PUBLIC_OFFICIAL_PEP` | Politically exposed person under FATF Recommendation 12 |

## Sandbox probes

With the account in sandbox mode, these values are deterministic:

| Document number | Full name | includeFormer | Result |
| :--- | :--- | :--- | :--- |
| `FR-HATVP-77121` | `EMMANUEL JEAN MICHEL FREDERIC MACRON` | `true` | Active PEP (`isPEP` true, category `HEAD_OF_STATE_OR_GOVERNMENT`) |
| `10000001` | `EMMANUEL JEAN MICHEL FREDERIC MACRON` | `true` | Active PEP (same fixture as document number `10000001`) |
| `10000002` | `PEP FORMER MINISTER` | `true` | Former PEP (`isFormerPep` true) while `includeFormer` is true |
| `10000002` | `PEP FORMER MINISTER` | `false` | Clean result when `includeFormer` is false |
| `55555555` | `JUAN CARLOS CIUDADANO NO PEP` | `true` | Clean non-PEP (`isPEP` false, `totalMatches` 0) |
| `99999404` | `—` | `true` | 404 `NotFound` (sandbox probe only) |

### Notes

- Send `documentNumber` or `fullName`. The document aliases are `id`, `dni`, and `cedula`. The name alias is `name`. If none of them is present, the API returns 409 `MissingParameter` with message `Either documentNumber or fullName must be provided.`
- `includeFormer` defaults to true. Former officeholders inside the 5-year window come back with `status` `FORMER_PEP`, `isFormerPep` true, and `isPEP` true. `false` drops those rows and leaves only active roles.
- `documentType` defaults to `ID`. `jurisdiction` in the payload is the registry label `Francia`. `regulation.lookbackYears` is 5.
- Sandbox active hit: document `FR-HATVP-77121` or name `EMMANUEL JEAN MICHEL FREDERIC MACRON`, and also document `10000001`. Former hit: document `10000002` or a name containing `PEP FORMER`, `EX MINISTRO`, or `FORMER MINISTER`. Clean hit: document `55555555` with name `JUAN CARLOS CIUDADANO NO PEP`. A document number containing `99999404`, or a name containing `NOTFOUND`, returns 404 in sandbox. A live miss is HTTP 200 with `isPEP` false, not 404.
- This route screens France only (`FR`). For a cross-border search use [Global PEP](/background-check/world-politically-exposed-persons).
- `checkedSources` lists the registry keys consulted for this jurisdiction. `regulation.framework` and `regulation.authority` identify the AML basis returned with the result.
