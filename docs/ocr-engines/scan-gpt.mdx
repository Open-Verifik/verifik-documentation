# Scan Agent

**Scan Agent** extracts structured fields from a document image. Call **POST** `https://api.verifik.co/v2/ocr/scan-gpt`. `image` is required. `documentType`, `backImage`, and `template` are optional. There is no `country` field on this body. The stored extraction sets `validationMethod` to `SCAN_AGENT`.

## What the call returns

- Extracted `documentType`, `documentNumber`, and name
- `validationMethod` — `SCAN_AGENT`

## Use cases

- Read an identity document from one image.
- Add the back image when the card has a second side.
- Pin a template when the layout is known.

---

## API Reference

### Endpoint

```http
POST https://api.verifik.co/v2/ocr/scan-gpt
```

A hit includes the extracted document fields and `validationMethod` `SCAN_AGENT`. The URL stays `/v2/ocr/scan-gpt`.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `image` | string | **Yes** | `data:image/jpeg;base64,AAAA` | Front image as base64 or a data URI. Required. |
| `documentType` | string | No | `CC` | Optional document family, such as `CC` or `DNI`. |
| `backImage` | string | No | `data:image/jpeg;base64,BBBB` | Optional back image. |
| `template` | string | No | `template_id` | Optional template id. |

### Notes

- `image` is required. `documentType`, `backImage`, and `template` are optional.
- Do not send a country field. This body does not accept one.
- The recorded method is `SCAN_AGENT` and the URL remains `/v2/ocr/scan-gpt`.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |
| Record on file | `image` plus `documentType: "CC"` | 200 with extracted fields and validationMethod SCAN_AGENT. |
| Missing required value | Omit `image` | 409 MissingParameter. |
| Unknown value | `image` and `backImage` | 200 when a back image is also sent. |

401 when the bearer token is missing or rejected.
