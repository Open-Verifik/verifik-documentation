### Endpoint

```
https://api.verifik.co/v2/ocr/scan-agent
```

Scan Agent reads a document image and returns the extracted fields in the response. The same call is what Smart Scan uses. Retention for a call that is not tied to a project is described below. A SmartEnroll scan tied to an app registration follows [Data retention](/getting-started/data-retention).

### Headers

| Name | Value |
| --- | --- |
| Content-Type | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `image` | string | Yes | Front image as a Base64 string or a `data:` URI. |
| `documentType` | string | Yes | Document type to read, for example `CC`. |
| `backImage` | string | No | Back image, same format as `image`. |
| `promptTemplateId` | string | No | Saved prompt template to apply. |
| `includeCost` | string | No | Pass `"true"` to include cost on the response. |

### Response

The HTTP response contains the unmasked extraction. For a call with no project, `url` and `backUrl` are inline `data:` URIs of the images you sent.

### Stored record and `url` / `backUrl`

This section is the call **without a project**. That is the standalone Scan Agent request.

| | Immediate response | Row saved for the scan |
| --- | --- | --- |
| `url`, `backUrl` | `data:` URIs of the images on this request. They are not hosted file links. | No hosted file is uploaded. |
| `OCRExtraction`, `fullName` | Full values, as read from the document. | Masked. |
| `documentNumber` | Full value. | Full value. The saved row keeps it in clear. |

Keep your own copy of the image if you need the photo later. An encrypted copy of the full extraction is removed 30 days after the scan.

A SmartEnroll scan that belongs to an app registration uses the account, project, and flow policy. In `none` and `ephemeral`, that response omits hosted URLs and can set `hasFrontImage` and `hasBackImage`. The response extraction is still unmasked. The saved extraction is masked when `ocrExtraction` is `none`.

See [Data retention](/getting-started/data-retention) and [Scan Prompt](/ocr-engines/scan-prompt).

### Notes

- Pass the front image in `image` and the back image in `backImage` when the document has two sides.
- `includeCost` is the string `"true"` when you want cost on the response.
- Policy changes apply to scans created after the change. Older rows keep the retention stamp they were given, and rows with no stamp stay as they are.
