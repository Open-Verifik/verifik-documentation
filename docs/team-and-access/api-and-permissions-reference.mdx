# API, Permissions Matrix & MCP Reference

Use this reference to inspect every resource key, compact action code, REST API endpoint, structured error response, and MCP tool powering Verifik Staff RBAC and Sub-Teams.

---

## Action Codes Legend

Verifik evaluates permissions per `(resource, action)` tuple across **27 resources** and **10 granular actions**:

| Code | Action Key | Meaning |
| --- | --- | --- |
| `R` | `read` | View dashboards, records, configurations, or logs |
| `C` | `create` | Create new records, invitations, teams, presets, or runs |
| `U` | `update` | Edit existing records, templates, roles, or team policies |
| `D` | `delete` | Delete records, templates, teams, or revoke API keys |
| `E` | `execute` | Trigger live paid lookups, SmartScan, biometrics, or SmartBatch runs |
| `A` | `approve` | Approve/reject KYC dossiers, KYB companies, alerts, or JIT access requests |
| `X` | `export` | Export CSV/XLSX reports, generate/send/download PDFs, mint signed links |
| `K` | `manageKeys` | Mint/manage API keys, webhooks secrets, or workspace keys |
| `L` | `readAll` | Bypass Sub-Team read isolation (`teamScopedVisibility`) across the workspace |
| `M` | `manageOwnTeam` | Manage members, child sub-teams, budgets, and JIT requests inside owned/child teams (`team_manager`) |

## REST API Endpoints Quick Reference

Base URL: `https://api.verifik.co` (identical `/v2/...` routes on `https://ai.verifik.co` with Bearer JWT).

### Staff & Sessions

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/v2/staff/me/permissions` | Inspect caller's effective matrix, teams, CECO policy, and request policy |
| `GET` | `/v2/staff` | List workspace staff (scoped for `team_manager`) |
| `POST` | `/v2/staff` | Invite staff member (`role`, `customRole`, `team`, `additionalTeams`) |
| `POST` | `/v2/staff/reinvite` | Re-send staff invitation email |
| `GET` | `/v2/staff/:id` | Show single staff member |
| `PUT` | `/v2/staff/:id` | Update role, `team`, `additionalTeams`, or `customPermissions` |
| `POST` | `/v2/staff/:id/revoke-session` | Rotate staff `JWTPhrase` to invalidate all active tokens |
| `DELETE` | `/v2/staff/:id/grants/:grantId` | Immediately revoke a staff temporary grant |
| `DELETE` | `/v2/staff/:id` | Remove staff member |

### Custom Roles & System Catalog

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/v2/client-roles/resources` | List all 27 resource definitions and 10 actions |
| `GET` | `/v2/client-roles/catalog` | Retrieve resources, built-in role presets, and custom roles |
| `GET` | `/v2/client-roles` | List tenant custom roles |
| `POST` | `/v2/client-roles` | Create custom role (`permissions`, `endpointPolicy`, `allowAccessRequests`) |
| `POST` | `/v2/client-roles/:id/duplicate` | Clone any built-in preset or custom role |
| `PUT` | `/v2/client-roles/:id` | Update custom role |
| `DELETE` | `/v2/client-roles/:id` | Delete custom role (with optional reassignment) |

### Sub-Teams, Budgets, API Keys & Assignments

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/v2/teams` | List Sub-Teams (`parentTeam`, spend, member counts) |
| `GET` | `/v2/teams/:id` | Show Sub-Team details |
| `POST` | `/v2/teams` | Create Sub-Team (`parentTeam`, `monthlyBudget`, CECO locks, `endpointPolicy`) |
| `PUT` | `/v2/teams/:id` | Update Sub-Team settings, members, or hierarchy |
| `POST` | `/v2/teams/:id/boost` | Add one-time or recurring monthly budget boost |

| `DELETE` | `/v2/teams/:id` | Delete Sub-Team (reparents children, cleans `additionalTeams`) |

## Structured Error Reference

| HTTP | Error `message` / Reason | When It Occurs & How to Resolve |
| --- | --- | --- |
| `403` | `insufficient_staff_permissions` | Caller lacks `(resource, action)`. Includes `canRequestAccess` boolean so UI/agents know whether `POST /v2/staff-access-requests` is allowed (`false` for `report_builder`). |
| `403` | `owner_only` | Operation requires Workspace Owner or SuperAdmin (for example deleting `ClientSettings`). |
| `403` | `cannot_escalate_permissions` | Staff actor attempted to create/assign permissions above their own effective ceiling. |
| `403` | `team_out_of_scope` | Cross-team read, write, staff invite, or request approval outside the caller's `team` + `additionalTeams` + `parentTeam` subtree. |
| `403` | `team_api_key_required` | Workspace has `staffAccessPolicy.requireTeamApiKeys: true` and caller used a plain client token instead of a Sub-Team API key. |
| `403` | `team_paused` | Target Sub-Team `status` is `"paused"`. Resume the Sub-Team to re-enable executions. |
| `403` | `team_budget_exceeded` | Team monthly credit cap reached under `"hard"` enforcement. Payload includes boost metadata for requesting or applying `POST /v2/teams/:id/boost`. |
| `403` | `team_feature_budget_exceeded` | Per-endpoint prefix cap (`featureBudgets`) reached for the target team. |
| `400` | `cost_center_not_allowed_for_team` | Requested `x-cost-center` header is outside the Sub-Team's `allowedCostCenters` / `defaultCostCenter` when `enforceCostCenter: true`. |

## AI Agent & MCP Integration

All Team, Role, Staff, Access Request, Audit Log, Cost Center, CECO Statement, and Signed Link operations are published as Bearer-authenticated MCP tools on **`https://ai.verifik.co/mcp`** so agents such as Claude, Cursor, Gemini, and Grok can automate multi-country provisioning safely.

:::warning Bearer JWT required on MCP
`TeamRBAC` MCP tools require your own Verifik Bearer JWT (`VERIFIK_JWT`) and are never exposed unauthenticated or over anonymous x402 billing routes.
:::

<Tabs groupId="mcp-config">
<TabItem value="mcp-json" label="Claude / Cursor / Gemini MCP Config" default>

```json
{
  "mcpServers": {
    "verifik": {
      "url": "https://ai.verifik.co/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_VERIFIK_JWT"
      }
    }
  }
}
```

</TabItem>
<TabItem value="curl" label="Direct JSON-RPC call">

```bash
curl -X POST https://ai.verifik.co/mcp \
  -H "Authorization: Bearer $VERIFIK_JWT" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "usage_cost_center_statement",
      "arguments": { "period": "2026-11", "format": "json" }
    }
  }'
```

</TabItem>
