# Face Detection

**Face Detection** is `POST /v2/face-recognition/face-validation`, an alias of the detect engine. `image` is required. If you omit them, this route sets `min_score` to `0.5` and `search_mode` to `FAST`. The live payload is `face_count`, `faces` (each with `score` and `bbox`), `imageDimensions`, and `engine`.

## What the call returns

- `face_count`
- `faces[].score` and `faces[].bbox`
- `imageDimensions` and `engine`

## Use cases

- Count faces before liveness.
- Read the box of the primary face.
- Rely on the default score and mode when you only have an image.

---

## API Reference

### Endpoint

```http
POST https://api.verifik.co/v2/face-recognition/face-validation
```

Read `face_count` first. Each item in `faces` has `score` and `bbox`. `imageDimensions` is the decoded width and height. `engine` names the detector.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `image` | string | **Yes** | `data:image/jpeg;base64,AAAA` | Face image as base64 or a data URI. Required. |
| `min_score` | number | No | `0.5` | Optional. This route defaults it to `0.5`. |
| `search_mode` | string | No | `FAST` | Optional. This route defaults it to `FAST`. `ACCURATE` is the other value. |

### Notes

- `image` is the only required field.
- Omitted `min_score` becomes `0.5` and omitted `search_mode` becomes `FAST`.
- The response uses `bbox`, not a separate landmark object.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |
| Record on file | `image` only | 200 with face_count, faces, imageDimensions, and engine. |
| Missing required value | Omit `image` | 409 MissingParameter. |
| Unknown value | `min_score: 0.8`, `search_mode: "ACCURATE"` | 200 using the score and mode you sent. |

401 when the bearer token is missing or rejected.
