# Peru - Vehicle Information (v3)

### Endpoint

```
GET https://api.verifik.co/v3/pe/vehiculo/placa
```

The Peruvian Vehicle Information v3 service returns registered vehicle details for a license plate (**`plate`**): make, model, year, engine and chassis identifiers, status, owners when available, and structured `technicalSheet` data (`engine`, `performance`, and vehicle `dimensions` such as length, width, height, wheelbase, curb weight, fuel tank capacity, doors, and seats).

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Name    | Type   | Required | Description                                                | Example  |
| ------- | ------ | -------- | ---------------------------------------------------------- | -------- |
| `plate` | string | Yes      | Vehicle license plate to query, without spaces or periods. | `ABC123` |

### Notes

- `technicalSheet` (including `dimensions` fields such as `length`, `width`, `height`, `wheelbase`, `curbWeight`, `fuelTank`, `doors`, and `occupants`) may be `null` or partially populated when matching technical specifications are unavailable for the vehicle model/year.
- In **sandbox mode**, plates `ABC10001`–`ABC10010` return stable fixture vehicle profiles.
