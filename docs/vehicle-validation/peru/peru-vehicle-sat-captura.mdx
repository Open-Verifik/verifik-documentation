# Peru - Vehicle Capture Order (SAT Lima)

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/captura-lima
```

Check with Lima's tax authority (**SAT**) whether a vehicle **`plate`** has a capture order in the province of Lima. A plate with no order is a successful response: `hasCaptureOrder` is `false` and `orders` is empty. When an order exists, `message` carries the official SAT text and each item in `orders` includes `concept`, `amount` in soles, `period`, and `documentNumber`. `status` is filled only when SAT sends it. `columns` keeps the original source labels when the public form provides them.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Name    | Type   | Required | Description                                                                 | Example  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | Yes      | Vehicle license plate, 5 to 8 letters or digits, without spaces. `F1E120` has an order. `V0R660` does not.  | `F1E120` |
| `force` | boolean | No      | Optional. Pass `true` or `1` to skip the stored result and query SAT again.  | `true` |

### Notes

- The lookup covers the province of Lima only.
- Send `plate` without spaces or hyphens (5 to 8 alphanumeric characters).
- A plate without a capture order still returns **HTTP 200**. **404** is only for a plate that is not 5 to 8 letters or digits.
- `amount` is formatted in soles (`S/ 505.86`). `status` stays empty when SAT does not send a status.
- `F1E120` has a capture order. `V0R660` does not.
- When SAT cannot be queried, the API returns **409** with `Endpoint_out_of_service`.
- In **sandbox mode**, `ABC10001` has a capture order and `ABC10002` does not.
