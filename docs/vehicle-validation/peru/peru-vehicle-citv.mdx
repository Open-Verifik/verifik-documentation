# Peru - Vehicle Technical Inspection (CITV)

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/inspeccion-tecnica
```

Look up the technical inspection certificates (**CITV**) registered with Peru's Ministry of Transport (**MTC**) for a license **`plate`**. The response includes whether a certificate was found (`found`), whether one is currently valid (`hasValidCertificate`), the most recent certificate (`latestCertificate`), and every certificate returned by the source (`certificates`).

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Name    | Type   | Required | Description                                                                 | Example  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | Yes      | Vehicle license plate, 5 to 8 letters or digits, without spaces. Example: `V0R660`.  | `V0R660` |
| `force` | boolean | No      | Optional. Pass `true` or `1` to skip the stored result and query the MTC source again.  | `true` |

### Notes

- Send `plate` without spaces or hyphens (5 to 8 alphanumeric characters).
- `hasValidCertificate` is `true` when at least one certificate has status `VIGENTE`.
- `latestCertificate` is the first certificate returned by the MTC. `certificates` lists every record for that plate. `V0R660` currently has two valid certificates.
- A plate with no certificate, or a plate that is not 5 to 8 letters or digits, returns **404**.
- When the MTC source is unavailable, the API returns **409** with `Endpoint_out_of_service`.
- In **sandbox mode**, `ABC10001` returns a valid (`VIGENTE`) certificate and `ABC10002` returns an expired (`VENCIDO`) certificate.
