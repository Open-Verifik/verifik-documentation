# Peru - SETARE Arequipa Taxi Permit

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/setare-arequipa
```

Validate whether a vehicle holds a registered **SETARE** taxi operating permit in Arequipa, Peru based on its license **`plate`**. Returns normalized active status (`hasActivePermit`), the most recent permit record (`latestPermit`), and the full list of permit entries (`permits`) retrieved from official municipal records.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Name    | Type   | Required | Description                                                                 | Example  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | Yes      | Vehicle license plate to query (6 alphanumeric characters, e.g. `V3D236`).  | `V3D236` |

### Notes

- Query **`plate`** without spaces or hyphens (6 alphanumeric characters).
- `hasActivePermit` is `true` when at least one returned permit has an active status (`Vigente`, `Activo`, or `Habilitado`).
- In **sandbox mode**, `ABC10001` returns an active `Definitivo` (`Vigente`) permit fixture and `ABC10002` returns an expired `Transitorio` (`Vencido`) permit fixture.
