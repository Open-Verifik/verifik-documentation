# Costa Rica — Traffic infractions

The **Costa Rica traffic infractions** lookup reads COSEVI tickets for one plate. `plate` is required and must be 3 to 6 characters. A validation failure returns HTTP 409 with code `409:invalid_params`, not `MissingParameter`. A plate with no tickets is 404 `NotFound`.

## What the call returns

- `plate` and `totalRecords`
- `infractions[]` with status and amounts

## Use cases

- Check tickets before you register a vehicle.
- Reject a plate that is not 3 to 6 characters.
- Read the total amount on each ticket.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/cr/traffic-infractions
```

A hit includes `plate`, `totalRecords`, and `infractions` with series, number, date, status, authority, and amounts.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **Yes** | `123456` | License plate, 3 to 6 characters, without spaces. A missing or wrong-length plate returns code `409:invalid_params`. |

### Notes

- `plate` must be 3 to 6 characters.
- Invalid plates return code `409:invalid_params`.
- No tickets for that plate is 404 `NotFound`.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

| :--- | :--- | :--- |
