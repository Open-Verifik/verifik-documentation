# United States — Vehicle Safety Recalls

The **United States Vehicle Safety Recalls API** queries official federal vehicle safety records to retrieve active safety campaigns, uncompleted defect remedies, and manufacturer recalls affecting motor vehicles operating on American roads.

Whether checking an individual car by its unique 17-character Vehicle Identification Number (VIN) or screening an entire commercial fleet by manufacturer Make, Model, and Model Year, this endpoint provides defect summaries, risk consequences, remedy actions, and campaign identification numbers directly from the official vehicle safety authority.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/usa/vehicle/recalls
```

Lookup open automotive safety recalls and defect campaigns by VIN or vehicle make/model/year combination.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <token>` | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `vin` | string | **Conditional** | 17-character standardized Vehicle Identification Number (e.g., `5YJSA1E26MF123456`). Required if `make`, `model`, and `modelYear` are not provided. |
| `make` | string | **Conditional** | Vehicle manufacturer make (e.g., `TESLA`, `FORD`, `TOYOTA`). Required if `vin` is not provided. |
| `model` | string | **Conditional** | Vehicle model name (e.g., `MODEL S`, `F-150`, `CAMRY`). Required if `vin` is not provided. |
| `modelYear` | string | **Conditional** | 4-digit manufacturing model year (e.g., `2021`). Required if `vin` is not provided. |

### Notes

- **Federal Safety Standards:** Recall campaigns reflect official defect determinations and safety notifications coordinated by the official vehicle safety authority in accordance with Federal Motor Vehicle Safety Standards (FMVSS).
- **Fleet Management & Underwriting:** Insurance carriers, auto lenders, and fleet managers leverage this endpoint to identify vehicles requiring urgent repairs before approving leases or issuing commercial policies.
- **Remedy Cost Exemption:** Under US federal law, safety recall repairs are executed free of charge by franchised brand dealerships regardless of vehicle ownership history or warranty status.
