# Ecuador — Vehicle by plate (v3)

The **Ecuador vehicle v3** lookup is `GET /v3/ec/vehiculo/placa`. `plate` is required. The body includes identification fields (`vin`, `brand`, `model`, `year`, `color`, and related plate data), a `revision` object with inspection dates, and a `technicalSheet` with engine, performance, and dimensions.

## What the call returns

- Identification: `vin`, `brand`, `model`, `year`, `color`
- `revision` with inspections
- `technicalSheet.engine`, `performance`, and `dimensions`

## Use cases

- Confirm a vehicle before insurance.
- Read the last inspection year.
- Store the VIN with the plate.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v3/ec/vehiculo/placa
```

Expect `plate`, identification fields, `revision`, and `technicalSheet`. An unknown plate is 404 `NotFound`.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **Yes** | `ABC1234` | Ecuadorian license plate. Required. |

### Notes

- The path is version 3: `/v3/ec/vehiculo/placa`.
- `plate` is the only required query parameter.
- An unknown plate is 404 `NotFound`.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.
