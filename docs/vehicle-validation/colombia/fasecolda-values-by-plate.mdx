# Vehicle Values by Plate - Fasecolda

Verifik's Fasecolda Vehicle Values by Plate API retrieves official commercial valuations and technical specifications for vehicles registered in Colombia using only a license plate. To maximize coverage across passenger cars, SUVs, pickups, heavy vehicles, and motorcycles, this endpoint combines **two complementary official vehicle data sources**:

1. **Primary Resolution (Direct Plate-to-Code Index)**: When the license plate is directly linked to a Fasecolda valuation code in the primary index, Verifik returns the exact catalog entry immediately.
2. **Secondary Resolution (Cross-Source Specification Matching)**: When a vehicle (such as most motorcycles or newly registered vehicles) is not directly indexed by plate in the valuation registry, Verifik automatically retrieves the vehicle's verified technical specifications (`brand`, `line`, `cylinderCapacity`, `year`, and `vehicleClass`) from a secondary official vehicle registry and cross-matches them against the Fasecolda valuation catalog.

Whenever a response is resolved through cross-source specification matching, the payload includes full provenance and scoring metadata (`matchSource`, `matchConfidence`, `matchNote`, `matchDetails`, and `runtVehicle`) so your underwriting or appraisal workflow knows exactly how the valuation code was matched and why any score points were deducted.

## What does this API validate?

- **Vehicle Information by Plate**: Supports Colombian automobile, SUV, pickup, commercial, and motorcycle license plates (`ABC123`, `ABC12D`, `ABC12`). Input plates are automatically normalized (uppercased, with spaces, hyphens, and periods removed).
- **Comprehensive Technical & Valuation Data**: Returns Fasecolda `code` / `homoloCode`, `marke` (brand), `line1`, `line2`, `line3`, `class`, `category`, `cylinderCapacity`, `fuel`, `transmission`, `bcpp` (base commercial price), and `valueModel` (historical values by model year).
- **Dual-Source Transparency & Confidence Breakdown**: Provides a weighted confidence score (`0.60` to `1.00`) and a transparent point-by-point explanation (`matchDetails.penalties`) whenever cross-source specification matching is used.

## API Reference

### Endpoint

```
GET https://api.verifik.co/v2/co/fasecolda/values-by-plate
```

The Fasecolda Vehicle Value Inquiry service returns official valuation and technical attributes (`code`, `marke`, `line1`, `line2`, `line3`, `class`, `cylinderCapacity`, `bcpp`, `valueModel`) for Colombian vehicles. When resolved via cross-source specification matching, it also returns `matchSource`, `matchConfidence`, `matchNote`, `matchDetails`, and `runtVehicle`. Pass the license **`plate`** as a **query** parameter.

### Notes

- **Dual-Source Coverage (Cars & Motorcycles)**: When a license plate is directly indexed in the primary valuation registry, the response returns the exact Fasecolda record (`matchSource` is omitted). When the plate is not directly indexed—which is common for motorcycles and certain light vehicles—Verifik verifies the vehicle's technical specifications from an official secondary vehicle registry and matches them against the Fasecolda valuation catalog (`matchSource: "runt_fallback"`).
- **Confidence Formula (`matchConfidence` & `matchDetails`)**: Cross-source matches are scored on a `0.00` to `1.00` scale using `0.55 * textScore + 0.25 * ccScore + 0.20 * yearScore`. Only matches with `matchConfidence >= 0.60` are returned; anything lower returns `404`.
- **Understanding What Lowers `matchConfidence` (`matchDetails.penalties`)**:
  - **Extra catalog trim/spec tokens (`textPoints` out of `0.55`)**: Official vehicle registration records often store only the base model line (for example, `"VERSA"`, `"TRACKER"`, or `"TRK 502X"`), whereas the Fasecolda catalog includes trim, transmission, and braking suffixes (`"ADVANCE AT 1600CC 2AB ABS"` or `"MT 500CC ABS"`). Those extra catalog tokens are listed in `extraGuideTokens` and explain why a 100% accurate vehicle match typically scores between `0.71` and `0.95`.
  - **Homologation vs. commercial line codes**: Some manufacturers register factory chassis codes (such as `"FZN250 A"` for `"FZ25 250"` or `"GPD150 A NMAX"` for `"NMAX"`). Token differences are itemized in `unmatchedRuntTokens`.
  - **Nominal cylinder capacity rounding (`ccPoints` out of `0.25`)**: A within-5% displacement difference (such as `199cc` vs `200cc` or `124cc` vs `125cc`) receives full points (`0.25/0.25`); larger nominal catalog rounding (such as `373cc` vs `400cc` nominal class) deducts `-0.07` and is noted in `penalties`.
- **Valuation Units**: `valueModel` contains commercial values by model year, and `bcpp` represents the base commercial price (expressed in thousands of Colombian Pesos, COP).

## Common Use Cases

- **Motorcycle & Vehicle Valuation**: Obtain reliable commercial valuations for both passenger vehicles and motorcycles using only the license plate.
- **Insurance Underwriting & Quoting**: Automate policy quoting with complete transparency into whether a valuation code came from a direct plate index or a verified specification cross-match.
- **Collateral & Fleet Appraisal**: Evaluate used vehicle portfolios and verify technical specifications (`cylinderCapacity`, `class`, `fuel`, `transmission`) in a single request.
