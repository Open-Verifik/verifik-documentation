Retrieve a Colombian vehicle's basic details and ownership records using only its license plate. This service is useful for ownership verification, onboarding, and vehicle due diligence.

### Endpoint

```
GET https://api.verifik.co/v2/co/runt/vehiculo/owners
```

The response includes `plate`, `brand`, `line`, `model`, and an `owners` array with owner identity, ownership period, financing, pledge, and registry details when available. Unlike **`GET /v2/co/runt/propietarios`**, this endpoint starts from a plate and returns normalized vehicle and owner records.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | Yes | Colombian license plate containing 5–9 alphanumeric characters. | `CRL299` |

### Request

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.get("https://api.verifik.co/v2/co/runt/vehiculo/owners", {
	params: { plate: "CRL299" },
	headers: {
		Accept: "application/json",
		Authorization: `Bearer ${process.env.VERIFIK_TOKEN}`,
	},
});
console.log(data);
```

  </TabItem>
  <TabItem value="python" label="Python">

```python
import os, requests

url = "https://api.verifik.co/v2/co/runt/vehiculo/owners"
headers = {"Accept": "application/json", "Authorization": f"Bearer {os.getenv('VERIFIK_TOKEN')}"}
response = requests.get(url, headers=headers, params={"plate": "CRL299"})
print(response.json())
```

### Notes

- The AppFeature code is **`colombia_api_vehicle_owners`**.
- Use **`CRL299`** in the sandbox.
- Owner properties may be `null` when a value is unavailable; `owners` may contain multiple historical records.
- Use **`GET /v2/co/runt/propietarios`** only for its separate query workflow; it is not an alias of this plate-based endpoint.
