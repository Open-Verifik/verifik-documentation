# Driver's License Validation in RUNT (Basic)

Same driver lookup as [Premium v2](/vehicle-validation/colombia/runt-drivers-license) (`GET /v2/co/runt/conductor`), billed at the **Basic** conductor price. You must send `primerApellido` (minimum 2 characters) for every document type, including `TI`. Omitting it returns `409 MissingParameter`. This endpoint does not look up the surname and does not add the RUI price.

Use this path when you already know the first last name. Sending `primerApellido` on v2 is billed at this same Basic price.

### v2 and v3

| | Premium `GET /v2/co/runt/conductor` | Basic `GET /v3/co/runt/conductor` |
| --- | --- | --- |
| Surname (`primerApellido`) | Not required, except **`PA`**, which requires it. Verifik finds the surname when you omit it. | Required for every document type (minimum 2 characters). |
| Document types | `CC`, `TI`, `CE`, `PA`, `PPT` | `CC`, `TI`, `CE`, `PA`, `PPT` |
| Billing | Omit the surname: **Premium**. For `TI` with no surname, the driver list price **plus** the RUI list price (`GET /v2/co/rui`). Send the surname: **Basic**, the same price as v3. | **Basic** conductor price. No surname lookup and no RUI price. |

### Endpoint

```
GET https://api.verifik.co/v3/co/runt/conductor
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Name             | Type   | Required | Description                                                    |
| ---------------- | ------ | -------- | -------------------------------------------------------------- |
| `documentType`   | string | Yes      | One of **`CC`**, **`TI`**, **`CE`**, **`PA`**, **`PPT`**. **`PA` is passport, `PPT` is not**. **`TI`** is *tarjeta de identidad*. |
| `documentNumber` | string | Yes      | Driver's document number, without spaces or periods.           |
| `primerApellido` | string | **Yes**  | First last name (minimum 2 characters). Required for every document type, including `TI`. |

### Document types

| Code | Full name | Who holds it | RUNT label | `primerApellido` |
| --- | --- | --- | --- | --- |
| **`CC`** | *Cédula de Ciudadanía* | Colombian citizens (national ID) | `C.` | **Required** |
| **`TI`** | *Tarjeta de Identidad* | Colombian tarjeta de identidad | — | **Required** |
| **`CE`** | *Cédula de Extranjería* | Foreign residents in Colombia | `E.` | **Required** |
| **`PA`** | *Pasaporte* (passport) | Passport holders | `P.` | **Required** |
| **`PPT`** | *Permiso por Protección Temporal* | Venezuelan temporary-protection permit — **not a passport** | `Y.` | **Required** |

### Request

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.get("https://api.verifik.co/v3/co/runt/conductor", {
	params: {
		documentType: "CC",
		documentNumber: "123456789",
		primerApellido: "GARCIA",
	},
	headers: {
		Accept: "application/json",
		Authorization: `Bearer ${process.env.VERIFIK_TOKEN}`,
	},
});
```

### Notes

- One API request at the Basic conductor price, including `TI` when you send `primerApellido`.
- Without `primerApellido` this endpoint does not look up the surname and does not add the RUI price.
- Accepted `documentType` values are **`CC`**, **`TI`**, **`CE`**, **`PA`**, and **`PPT`**.
- For automatic surname resolution, use [`/v2/co/runt/conductor`](/vehicle-validation/colombia/runt-drivers-license). On that endpoint, `TI` without `primerApellido` is billed as the driver list price plus the RUI list price.
