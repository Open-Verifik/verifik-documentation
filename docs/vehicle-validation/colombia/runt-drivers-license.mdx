# Driver's License Validation in RUNT (Premium)

Verifik's Driver's License Validation API allows you to query official information registered in Colombia's Registro Único Nacional de Tránsito (RUNT) using the driver's identification document number.

This integration is essential for transport companies, car rental agencies, insurers, and logistics platforms that need to verify the legal status and eligibility of drivers before hiring or authorizing vehicle use.

There are two driver (conductor) endpoints. This page is **Premium**, `GET /v2/co/runt/conductor`. Verifik finds the first last name (`primerApellido`) when you omit it, except for a passport (`PA`), which always requires it. [Basic v3](/vehicle-validation/colombia/runt-drivers-license-basic) (`GET /v3/co/runt/conductor`) requires `primerApellido` for every document type.

RUNT authenticates the driver with that first last name and may return masked names. This v2 path still works when you do not send the surname.

### v2 and v3

| | Premium `GET /v2/co/runt/conductor` | Basic `GET /v3/co/runt/conductor` |
| --- | --- | --- |
| Surname (`primerApellido`) | Not required, except **`PA`**, which requires it (minimum 2 characters). Verifik finds the surname when you omit it. | Required for every document type (minimum 2 characters). |
| Document types | `CC`, `TI`, `CE`, `PA`, `PPT` | `CC`, `TI`, `CE`, `PA`, `PPT` |
| Billing | Omit the surname: **Premium**. For `TI` with no surname, the driver list price **plus** the RUI list price. Send the surname: **Basic**, the same price as v3. | **Basic** conductor price. Verifik does not look up the surname and does not add the RUI price. |

### Tarjeta de identidad (`TI`) on v2

`TI` is a *tarjeta de identidad*. On this endpoint you can omit `primerApellido`, the same as `CC`, `CE`, and `PPT`.

When `documentType` is `TI` and you do not send `primerApellido`, Verifik first looks up the holder's surname through the Colombian identity lookup — the same data as [`GET /v2/co/rui`](/background-check/colombia-rui) — and then runs the driver lookup. The name on that record starts with the given name. Verifik uses the first surname. A leading particle (`DE`, `DEL`, `LA`, `LAS`, `LOS`, or `Y`) stays with that surname. For example, `ANA DE LA CRUZ LOPEZ` is used as `DE LA CRUZ`.

That request is billed as two requests: the driver (conductor) price plus the RUI price. Use list prices only. For example, driver list price + RUI list price = total. The RUI price is the list price of `GET /v2/co/rui`.

If the surname lookup fails, the call returns HTTP 409 and there is no RUI charge:

```json
{
	"code": "Conflict",
	"message": "Unable to resolve primer apellido for RUNT conductor"
}
```

Sending `primerApellido` on v2 skips that lookup. The call is billed at the **Basic** price, the same price as [`GET /v3/co/runt/conductor`](/vehicle-validation/colombia/runt-drivers-license-basic).

Use the dedicated [Basic v3](/vehicle-validation/colombia/runt-drivers-license-basic) path if you always send `primerApellido` and want that requirement enforced.

## What information does the API return?

When a document number query is made, the API returns updated data directly from RUNT, including:

-   Driver's full name and document details
-   License status (active, suspended, canceled)
-   License categories (e.g., B1, C1, A2)
-   Expiration dates for each category
-   Medical and aptitude certificate status
-   Traffic fines and infractions history (SIMIT/RUNT)

This data enables verification of the driver's capability and legal standing to operate vehicles.

## API Reference

### Endpoint

```
GET https://api.verifik.co/v2/co/runt/conductor
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Name             | Type   | Required | Description                                                    |
| ---------------- | ------ | -------- | -------------------------------------------------------------- |
| `documentType`   | string | Yes      | One of **`CC`**, **`TI`**, **`CE`**, **`PA`**, **`PPT`**. See the table below — **`PA` is passport, `PPT` is not**. |
| `documentNumber` | string | Yes      | Driver's document number, without spaces or periods.           |
| `primerApellido` | string | Conditional | First last name (minimum 2 characters). **Required for `PA`**. Optional for `CC`, `TI`, `CE`, and `PPT`. Omit it and Verifik finds the surname (**Premium**). Send it to skip that lookup and pay **Basic**, the same price as v3. For `TI` with no surname, the charge is the driver list price plus the RUI list price. Passport names are not resolved for you: send `primerApellido` for `PA`. |

### Document types

Do not send `PPT` when RUNT shows **`P.`** — that is a **passport (`PA`)**. `PPT` is an immigration permit.

| Code | Full name | Who holds it | RUNT label | `primerApellido` |
| --- | --- | --- | --- | --- |
| **`CC`** | *Cédula de Ciudadanía* | Colombian citizens (national ID) | `C.` | Optional |
| **`TI`** | *Tarjeta de Identidad* | Colombian tarjeta de identidad | — | Optional. With no surname, Verifik uses the same identity data as `GET /v2/co/rui`, then the driver lookup. Billed as driver list price + RUI list price. |
| **`CE`** | *Cédula de Extranjería* | Foreign residents in Colombia | `E.` | Optional |
| **`PA`** | *Pasaporte* (passport) | Passport holders | `P.` | **Required** |
| **`PPT`** | *Permiso por Protección Temporal* | Venezuelan temporary-protection permit — **not a passport** | `Y.` | Optional |

## Business Use Cases

The RUNT driver's license query API is used across multiple industries:

-   **Transportation and Logistics**: To verify driver eligibility and license validity during recruitment.
-   **Car Rental Agencies**: To ensure customers have a valid license before handing over a vehicle.
-   **Insurance Companies**: For risk assessment and policy issuance based on driver history.
-   **On-demand Delivery & Ride-hailing**: To validate gig workers' credentials in real-time.

## Compliance & Data Quality

### Compliance, availability, and accuracy

The API connects directly to official sources such as RUNT, ensuring:

-   Verified and up-to-date information.
-   High availability and optimal response times.
-   Regulatory compliance with KYC and transport regulations.
-   Data protection in accordance with Law 1581 of 2012.

### Additional technical information

-   **Method**: GET
-   **Response format**: JSON
-   **Update frequency**: Real-time, according to RUNT source
-   **Official source**: Registro Único Nacional de Tránsito (RUNT), Colombia
-   **Coverage**: Nationwide
-   License categories include B1 (cars), A2 (motorcycles), C1 (trucks), etc.
-   Status "ACTIVA" indicates the license is currently valid.
-   Multiple license categories can be associated with one driver.
-   `PA` is passport, not PPT. Send `primerApellido` when querying a passport.
-   Accepted `documentType` values are **`CC`**, **`TI`**, **`CE`**, **`PA`**, and **`PPT`**.
-   `TI` without `primerApellido` is billed as the driver list price plus the RUI list price (`GET /v2/co/rui`). A failed surname lookup returns 409 and adds no RUI charge.
-   Sending `primerApellido` on this v2 endpoint is billed at the Basic price, the same as v3.
