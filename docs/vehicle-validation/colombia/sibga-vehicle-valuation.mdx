# SIBGA - Vehicle Commercial Valuation

Returns the official **Ministerio de Transporte (SIBGA)** commercial value for a Colombian vehicle. Verifik looks the plate up in **RUNT** and maps brand, line, class, fuel, and displacement onto the SIBGA catalog. You do not maintain an equivalence table.

Send the plate alone, or send the owner's document together with the plate. With a document, RUNT is queried by plate and owner, the same way as [Vehicle records by plate](/vehicle-validation/colombia/runt-vehicle-by-plate). Without a document, the lookup follows [Vehicle records by plate only](/vehicle-validation/colombia/runt-vehicle-by-plate-only).

Use it for insurance underwriting, credit, and fleet valuation when the tax base must come from SIBGA.

## What this API returns

- **`valuation`** — commercial value in **COP** for the vehicle model year. `null` when SIBGA does not value that year (vehicles newer than the period are valued from the purchase invoice)
- **`valuesByModel`** — commercial value for about **25** model years ending the year before the period
- **`matched`** — SIBGA vehicle type, class, brand, line, cylinder capacity, and the certificate **`avalId`**
- **`confidence`** — match strength for the line, brand, and class (`exact`, `high`, `medium`, `low`, or `none`)
- **`needsReview`** / **`reviewReason`** — set when the catalog match is weak, SIBGA rejected the search, no line matched, or the model year is not valued
- **`alternatives`** — other catalog lines considered, with scores
- **`certificateUrl`** — official SIBGA PDF when a value was returned
- **`runtSource`** — the RUNT brand, line, model, class, and displacement used for the match
- A **signed** Verifik response

## API reference

### Endpoint

```
GET https://api.verifik.co/v2/co/sibga/valuation
```

Send **`plate`** as a query parameter. **`documentType`** and **`documentNumber`** are optional and must be sent together. **`period`** is the taxable year, from **2016** through the current year, and defaults to the current year. The response includes the commercial value, the model-year table, the matched SIBGA record, and a review flag when the match should be checked by a person.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | Yes | Colombian license plate, **5–9** alphanumeric characters. | `CUT984` |
| `documentType` | string | No | Owner document type. One of **`CC`**, **`CE`**, **`PA`**, **`NIT`**. Required together with `documentNumber`. | `CC` |
| `documentNumber` | string | No | Owner document number, without spaces or punctuation. Required together with `documentType`. | `63535790` |
| `period` | number | No | Taxable year, from **2016** through the current year. Defaults to the current year. | `2026` |

### Notes

- The AppFeature code is **`colombia_api_vehicle_valuation_sibga`**.
- A body with **`valuation: null`** is still **HTTP 200**. Read **`reviewReason`**: `model_not_valued_in_period`, `low_confidence_match`, `no_matching_line`, or `sibga_search_rejected`.
- **`documentType`** and **`documentNumber`** must be sent together, or both omitted.
- Unsupported classes, such as a semitrailer, return **404**.
- Sandbox plates **`AA123BA`–`AA123BF`**, **`AA123BH`**, and **`AA123BI`** return distinct valued vehicles. **`AA123BG`** returns **200** with `reviewReason: model_not_valued_in_period`. **`AA123BJ`** and **`ERR40401`** return **404**. Document **`90040401`** returns **404** and **`90050001`** returns **500**.
- Related RUNT lookups: [vehicle by plate](/vehicle-validation/colombia/runt-vehicle-by-plate) and [vehicle by plate only](/vehicle-validation/colombia/runt-vehicle-by-plate-only).
