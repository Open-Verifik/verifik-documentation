# Email OTP

**Email OTP** sends a one-time code. The live method is **POST** `https://api.verifik.co/v2/communication/email`, not GET. The body requires `project`, `validationMethod` (`manual` or `verificationCode`), `email`, and `type` (`validation`, `login`, `onboarding`, or `oneTimeLink`). Optional fields include `expiresAt`, `redirectUrl`, `webhookUrl`, `identityUrl`, `requires2FA`, `ipAddress`, and `language`.

## What the call returns

- `email` and `status`
- `type` and `validationMethod`

## Use cases

- Send a login code to a mailbox.
- Start onboarding that continues by email.
- Attach a webhook for delivery status.

---

## API Reference

### Endpoint

```http
POST https://api.verifik.co/v2/communication/email
```

A successful send returns the email validation with status `sent`. Confirm the code with the email validation endpoint your project already uses.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `project` | string | **Yes** | `project_id` | Project id that owns the email OTP. |
| `validationMethod` | string | **Yes** | `verificationCode` | `manual` or `verificationCode`. |
| `email` | string | **Yes** | `person@example.com` | Mailbox that receives the code. An invalid address is 409. |
| `type` | string | **Yes** | `validation` | `validation`, `login`, `onboarding`, or `oneTimeLink`. |

### Notes

- This route is POST, not GET.
- `project`, `validationMethod`, `email`, and `type` are required.
- An address that is not an email is 409.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.
