# SMS messaging

**SMS messaging** is **POST** `https://api.verifik.co/v2/communication/sms`, not GET. The body requires `phone` and `countryCode` (a dial code that starts with `+`). The route sets `phoneGateway` to `sms`, so you do not send that field. Optional `title` is 1 to 15 characters and `language` selects the copy. Account-owner tokens can call it. A staff user needs Smart Tools execute permission.

## What the call returns

- `phone` and `countryCode`
- `phoneGateway` set to `sms`
- `status`

## Use cases

- Send a login code by SMS.
- Use a national number plus a dial code.
- Let the route choose the SMS gateway.

---

## API Reference

### Endpoint

```http
POST https://api.verifik.co/v2/communication/sms
```

A successful send returns `phoneGateway` `sms` and status `sent`. You are charged when the OTP is delivered.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `phone` | string | **Yes** | `3001234567` | National number only. Do not include the dial code. |
| `countryCode` | string | **Yes** | `+57` | Dial code starting with `+`. |
| `title` | string | No | `ACME` | Optional sender name, 1 to 15 characters. |
| `language` | string | No | `es` | Optional template language. |

### Notes

- This route is POST, not GET.
- `phone` and `countryCode` are required. `countryCode` must start with `+`.
- Do not send `phoneGateway`; the route sets it to `sms`.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.
