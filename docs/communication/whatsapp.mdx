# WhatsApp messaging

**WhatsApp messaging** is **POST** `https://api.verifik.co/v2/communication/whatsapp`, not GET. The body requires `phone` and `countryCode`. The route sets `phoneGateway` to `whatsapp`. Optional `whatsappTemplate` is `authentication` (the default) or `flow2`. With `flow2`, `language` picks `flow2_es` or `flow2_en`, and optional `title` (1 to 15 characters) is the branded section.

## What the call returns

- `phone` and `countryCode`
- `phoneGateway` set to `whatsapp`
- `status`

## Use cases

- Send a login code on WhatsApp.
- Choose flow2 when you need a branded template.
- Keep authentication as the default template.

---

## API Reference

### Endpoint

```http
POST https://api.verifik.co/v2/communication/whatsapp
```

A successful send returns `phoneGateway` `whatsapp` and status `sent`.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `phone` | string | **Yes** | `3001234567` | National number only. |
| `countryCode` | string | **Yes** | `+57` | Dial code starting with `+`. |
| `whatsappTemplate` | string | No | `authentication` | Optional. `authentication` (default) or `flow2`. |
| `language` | string | No | `es` | Optional. With `flow2`, selects `flow2_es` or `flow2_en`. |

### Notes

- This route is POST, not GET.
- `whatsappTemplate` is optional: `authentication` or `flow2`.
- The route sets `phoneGateway` to `whatsapp`.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |
| Record on file | `phone: "3001234567"`, `countryCode: "+57"` | 200 when the WhatsApp OTP is sent. |
| Missing required value | Omit `countryCode` | 409 MissingParameter. |
| Unknown value | `whatsappTemplate: "flow2"`, `language: "es"` | 200 using the flow2 template when language is es. |

401 when the bearer token is missing or rejected.
