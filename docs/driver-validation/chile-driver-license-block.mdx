# 🇨🇱 Chile - Driver License Block Register

Query the **Servicio de Registro Civil e Identificación** nationwide driver-license block register by RUN.

Unlike municipal portals which only cover a single commune, this endpoint provides **nationwide coverage** of driver-license blocks and suspensions ordered by courts or civil authorities across Chile.

### Endpoint

```
GET https://api.verifik.co/v2/cl/driver-license/block
```

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Name | Type | Required | Description | Example |
| ---- | ---- | -------- | ----------- | ------- |
| `documentNumber` | string | **Yes** | Chilean RUN with check digit (DV). Dots and dashes are optional (`18.347.440-5` or `18347440-5`). The check digit must be valid. | `18347440-5` |
| `force` | boolean | No | Optional boolean or `1`/`true` to bypass server cache and query Registro Civil upstream. | `false` |

## Features

- **Nationwide Registry**: Official data from Chile's Registro Civil e Identificación.
- **Block & Suspension Status**: Immediate confirmation of license blocks (`hasBlock: true/false`).
- **Holder Verification**: Returns the full legal name registered with the driver credential.
- **Block Metadata**: Includes court order date, block type, and reason when an active restriction is in place.
- **Check-Digit Protection**: Automatic Modulo-11 verification prevents upstream query waste and guards against data-entry typos without charging credits.
