# Colombia — RUES business lookup (v2 path)

**`GET /v2/co/rues`** is an alias of the public catalog feature **Colombia — RUES business lookup (v3)** ([`GET /v3/co/rues`](/business-validation/colombia-rues-v3)). It is not a separate `nit`-only API. Send the same required query parameters as v3.

For a full dossier, use [RUES Complete (v3)](/business-validation/rues-complete-v3) (`GET /v3/co/rues-complete`). `GET /v2/co/rues/complete` is outside the current public catalog.

## Which endpoint should I use?

| | **`GET /v2/co/rues`** (alias of v3 basic) | **`GET /v3/co/rues-complete`** |
| --- | --- | --- |
| **Purpose** | Category summary | **Complete** business information |
| **Parameters** | `documentType`=`NIT`, required `category`, `documentNumber` | **Same** |
| **Catalog list price** | **$0.30** per call | **$0.40** per call |

### Endpoint

```
GET https://api.verifik.co/v2/co/rues
```

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `documentType` | string | Yes | Must be **`NIT`**. |
| `documentNumber` | string | Yes | Tax ID digits (punctuation is stripped server-side). |
| `category` | string | Yes | Required RUES line. One of **`RM`**, **`PROP`**, **`RUNEOL`**, **`RNT`**, **`ESAL`**, **`RESAL`**, **`JUEGOS`**, **`EXTRANJERAS`**. |

### Notes

- Catalog name: **Colombia — RUES business lookup (v3)** (`colombia_api_rues_v3`). List price **$0.30** per call. Subscribed plans can be lower on this API.
- Prefer the canonical path **`GET /v3/co/rues`**. See [RUES business lookup (v3)](/business-validation/colombia-rues-v3) and [RUES Complete (v3)](/business-validation/rues-complete-v3).

### Request

<Tabs>
  <TabItem value="javascript" label="JavaScript">

```javascript
import axios from "axios";

const { data } = await axios.get("https://api.verifik.co/v2/co/rues", {
	params: { documentType: "NIT", documentNumber: "900265177", category: "RM" },
	headers: {
		Accept: "application/json",
		Authorization: `Bearer ${process.env.VERIFIK_TOKEN}`,
	},
});
console.log(data);
```
