# Spain — Tax ID Validation (NIF / NIE / CIF)

The **Spain Tax ID Validation API** authenticates Spanish fiscal identification codes, verifying natural citizens (*NIF*), foreign residents (*NIE*), and corporate entities (*CIF*).

The service evaluates official check-digit algorithms (modulo 23 control letters for personal NIF/NIE and modulo 11 checksums for corporate CIFs), classifies the legal structure and province of incorporation, and cross-references registration in the European VIES database.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/es/tax-id/validate
```

Validate a Spanish tax identifier against official cryptographic control formulas and the official tax authority database.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <token>` | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Yes** | Spanish fiscal identifier to validate (e.g., `A28015865`, `12345678Z`, `Y1234567X`). |
| `documentType` | string | No | Explicit document classification (`NIF`, `NIE`, or `CIF`). If omitted, the service infers type automatically from syntax. |

### Notes

- **Entity Types in CIFs:** The initial letter designates the legal form (`A`: Sociedad Anónima, `B`: Sociedad de Responsabilidad Limitada, `C`: Sociedad Colectiva, `G`: Asociaciones, etc.).
- **Province Determination:** The first two digits of the numerical block identify the provincial delegation of incorporation (e.g., `28` for Madrid, `08` for Barcelona).
- **VIES Registration:** The `viesRegistered` flag indicates whether the entity has an active intra-Community VAT operator listing with the official tax authority.
