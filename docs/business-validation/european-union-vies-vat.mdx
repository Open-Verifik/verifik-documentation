# European Union — VIES VAT Validation

The **European Union VIES VAT Validation API** provides real-time verification of value-added tax (VAT) identification numbers for businesses registered across all 27 European Union member states and Northern Ireland (`XI`).

By querying the official European VAT Information Exchange System, this endpoint confirms whether a VAT number is legally active, verifies registered trade names, and retrieves standardized corporate addresses to support intra-Community B2B invoicing, Know Your Business (KYB) compliance, and tax fraud prevention.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/eu/vat
```

Query the official European tax authority registry to confirm the validity and active registration status of an EU VAT identification number.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <token>` | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `countryCode` | string | **Yes** | Two-letter ISO member state country code (e.g., `IE`, `FR`, `ES`, `DE`, `IT`, `NL`, `XI`). |
| `vatNumber` | string | **Yes** | VAT identification number excluding the country code prefix (e.g., `6388047V`). |

### Notes

- **Intra-Community Tax Exemption:** Validating VAT registration through the official European authority is mandatory to apply 0% VAT reverse charges on cross-border transactions between EU member states.
- **Country Prefix Handling:** Provide `countryCode` as the ISO code (e.g., `IE`) and `vatNumber` without the country prefix (e.g., `6388047V`). The API automatically constructs `fullVatNumber`.
- **Northern Ireland Protocol:** Businesses in Northern Ireland trading goods under the EU Single Market framework use the special territory code `XI`.
- **National Data Protections:** In certain member states (such as Germany or Spain), business names and addresses may not be publicly disclosed by the authority unless specific bilateral consent is registered.
