# Colombia — Financial insolvency and liquidation

The **financial insolvency** lookup reads Superintendencia Financiera concordato and liquidation rows. Send a NIT or a name. `inConcordatoOrLiquidation` is true only when a proceeding is on file. A company with no proceeding is still HTTP 200, with the flag false and a status that says there is no concordato or liquidation. This route does not use 404 for that clean miss.

## What the call returns

- `inConcordatoOrLiquidation`
- `status` and `entityType`
- `matches` — empty on a clean miss

## Use cases

- Stop onboarding a financial entity already in liquidation.
- Keep a clean financial screen as 200.
- Search by NIT or legal name.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/superfinanciera/concordatos
```

A hit includes `status`, `entityType`, and `inConcordatoOrLiquidation` true. A clean miss keeps HTTP 200 and sets the flag false.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditional** | `900123456` | NIT or person number. Alias `nit`. Required if no name is sent. |
| `businessName` | string | **Conditional** | `EJEMPLO SAS` | Name. Aliases `companyName` and `fullName`. Required if no number is sent. |
| `documentType` | string | No | `NIT` | Optional: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### Notes

- A clean miss is HTTP 200 with `inConcordatoOrLiquidation` false.
- Send a number or a name.
- Do not map that 200 to 404.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |
| Record on file | `documentNumber: "860000001"` | 200 with inConcordatoOrLiquidation true on a hit. |
| Missing required value | Omit number and name | 409 when no search value is sent. |
| Unknown value | `documentNumber: "800000111"` | 200 with inConcordatoOrLiquidation false. A clean miss is not 404. |

401 when the bearer token is missing or rejected.
