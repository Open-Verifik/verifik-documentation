# Colombia — Solidarity-sector sanctions

The **solidarity sanctions** lookup reads the Supersolidaria bulletin of sanctioned entities and persons. Send a number or a name. `isSanctioned` is true only when a sanction is on file. A clean miss is HTTP 200 with `isSanctioned` false, `sanctionsCount` 0, and status `SIN SANCIONES REGISTRADAS`. This route does not return 404 for that miss.

## What the call returns

- `isSanctioned` and `sanctionsCount`
- `status`
- `matches`

## Use cases

- Screen a cooperative before you fund it.
- Record a clean solidarity check as 200.
- Search by NIT or by the sanctioned name.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersolidaria/sanciones
```

A hit includes `sanctionsCount` and `matches`. A clean miss is HTTP 200 with `isSanctioned` false.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditional** | `900123456` | NIT or person number. Alias `nit`. |
| `businessName` | string | **Conditional** | `EJEMPLO SAS` | Name. Aliases `companyName` and `fullName`. |
| `documentType` | string | No | `NIT` | Optional: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### Notes

- A clean miss is HTTP 200 with `isSanctioned` false.
- Send at least one search value.
- Do not map that 200 to 404.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |
| Record on file | `documentNumber: "900555111"` | 200 with isSanctioned true on a hit. |
| Missing required value | Omit number and name | 409 when no search value is sent. |
| Unknown value | `documentNumber: "800000111"` | 200 with isSanctioned false. A clean miss is not 404. |

401 when the bearer token is missing or rejected.
