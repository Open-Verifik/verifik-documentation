# Colombia — Corporate information system (SIIS)

The **SIIS** lookup reads the integrated corporate filings supervised by Supersociedades. Send a NIT or a company name. `found` is true when a filing exists and false when the company is simply not in SIIS. That clean miss is HTTP 200, with status `NO REGISTRADA EN SIIS SUPERSOCIEDADES`. Use `inLiquidationOrReorganization` to see a concurso alert.

## What the call returns

- `found` and `inLiquidationOrReorganization`
- `ciiu`, sector, and city
- `financialSummary` when a filing exists
- `filings` — empty on a clean miss

## Use cases

- Pull the latest SIIS filing before you extend credit.
- Flag a company already in reorganization.
- Record a not-in-SIIS result as 200, not as a missing page.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersociedades/siis
```

A filing includes `status`, `ciiu`, address fields, `financialSummary`, and `filings`. `found` false means the company is not in SIIS. Both are HTTP 200.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditional** | `900123456` | NIT or person number. Alias `nit`. Required if you send no name. |
| `businessName` | string | **Conditional** | `INDUSTRIAS EJEMPLO SAS` | Name, 2 to 200 characters. Aliases `companyName` and `fullName`. Required if you send no number. |
| `documentType` | string | No | `NIT` | Optional: `NIT`, `CC`, `CE`, `PAS`, or `TI`. |

### Notes

- Send a NIT or a name.
- `found` false is a successful clean miss.
- Do not map that body to HTTP 404.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |
| Record on file | `documentNumber: "900673447"` | 200 and found is true on a hit. |
| Missing required value | Omit number and name | 409 when no search value is sent. |
| Unknown value | `documentNumber: "800000111"` | 200 and found is false on a clean miss. That miss is not 404. |

401 when the bearer token is missing or rejected.
