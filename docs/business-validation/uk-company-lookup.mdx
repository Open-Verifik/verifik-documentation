# United Kingdom — Company Lookup

The **United Kingdom Company Lookup API** verifies businesses incorporated in England, Wales, Scotland, and Northern Ireland through the official corporate registry of Great Britain.

Retrieve real-time legal status, 8-character company numbers, Legal Entity Identifiers (LEI), corporate creation dates, registered office addresses, and official regulatory filings to automate KYB verification and vendor screening.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/gb/company
```

Query the official corporate registry of the United Kingdom by company registration number or registered corporate name.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <token>` | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `companyNumber` | string | **Conditional** | 8-character alphanumeric UK company registration number (e.g., `00048839`, `SC123456`, `NI123456`). Required if `companyName` is omitted. |
| `companyName` | string | **Conditional** | Registered corporate name (e.g., `BARCLAYS PLC`). Required if `companyNumber` is omitted. |

### Notes

- **Company Number Normalization:** Standard English company numbers are 8 digits long with leading zeroes preserved (e.g., `00048839`). Scottish corporations begin with `SC`, Northern Irish companies with `NI`, and Limited Liability Partnerships with `OC`.
- **Global LEI Integration:** When available, the response cross-references the 20-character ISO 17442 Legal Entity Identifier (`lei`) associated with the entity for financial reporting compliance under MiFID II and EMIR.
- **Corporate Filings:** The `publicNotices` list includes the latest confirmation statements, account filings, and status changes recorded by the official corporate registry.
