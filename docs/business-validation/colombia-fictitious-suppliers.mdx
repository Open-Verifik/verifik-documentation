# Colombia — Fictitious or insolvent suppliers (DIAN)

The **fictitious or insolvent suppliers** lookup screens DIAN article 671. Send `documentNumber` (or the alias `nit`) or `businessName` (aliases `companyName` and `fullName`). A listed supplier sets `isFictitiousSupplier` to true and includes the resolution. A clean miss is still HTTP 200 with `isFictitiousSupplier` false and a status that says the number is not on that list. This route does not return 404 for a clean miss.

## What the call returns

- `isFictitiousSupplier` — true only when DIAN lists the subject
- `resolutionNumber`, `resolutionDate`, and `publicationDate` on a hit
- `matches` — empty when nothing is listed
- `status` — list label or the not-listed sentence

## Use cases

- Block a vendor that DIAN marked fictitious or insolvent.
- Record a clean miss as 200 with the flag false.
- Search by NIT or by legal name.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/co/dian/proveedores-ficticios
```

On a hit, `isFictitiousSupplier` is true and `matches` holds the resolution number, dates, and sectional office. On a clean miss, `isFictitiousSupplier` is false and `status` explains that the subject is not on the fictitious-supplier list. Both outcomes are HTTP 200.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <your_token>` | Client JWT |

### Parameters

| Name | Type | Required | Example | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditional** | `900123456` | NIT or person number, 4 to 25 characters. Alias: `nit`. Required when no name is sent. |
| `businessName` | string | **Conditional** | `INDUSTRIAS EJEMPLO SAS` | Legal or trade name, 2 to 200 characters. Aliases: `companyName` and `fullName`. Required when no number is sent. |
| `documentType` | string | No | `NIT` | Optional. Accepted values: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### Notes

- Send a number or a name. At least one is required.
- A subject who is not on the list is HTTP 200 with `isFictitiousSupplier` false.
- Do not treat that 200 as a 404.
- Send a Bearer JWT in the `Authorization` header.
- The JSON sample illustrates the fields. A live call returns the record for the values you send.
- Do not send a cache-bypass flag. This page documents only the client parameters.

## Sandbox

| Scenario | Parameters | Result |
| :--- | :--- | :--- |
| Record on file | `documentNumber: "900123456"` | 200 with isFictitiousSupplier true when the source lists the subject. |
| Missing required value | Omit every search value | 409 MissingParameter when no search value is sent. |
| Unknown value | `documentNumber: "00000000"` | 200 with isFictitiousSupplier false. A clean miss stays HTTP 200 and is not 404. |

401 when the bearer token is missing or rejected.
