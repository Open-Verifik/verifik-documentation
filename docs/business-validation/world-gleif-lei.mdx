# Global — Legal Entity Identifier (GLEIF LEI)

The **Global Legal Entity Identifier (LEI) API** queries the worldwide corporate registry governed by the Global Legal Entity Identifier Foundation (GLEIF) under the international standard **ISO 17442**.

Verify international financial counterparties, multinational corporations, subsidiaries, and institutional trading entities across more than 200 jurisdictions to satisfy mandatory global financial mandates including Dodd-Frank, EMIR, MiFID II, and Basel III.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/world/lei
```

Lookup an internationally verified entity by its 20-character ISO 17442 LEI code, local business registration number, corporate name, or jurisdiction.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <token>` | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `lei` | string | **Conditional** | 20-character alphanumeric ISO 17442 Legal Entity Identifier (e.g., `5493006MHB84DD0ZWV18`). Required if no other criteria are supplied. |
| `companyName` | string | **Conditional** | Legal business name to search (e.g., `ALPHABET INC.`). |
| `registrationNumber` | string | No | Local business registry or chamber of commerce number (e.g., `5786925`). |
| `countryCode` | string | No | Two-letter ISO 3166-1 alpha-2 country code of the jurisdiction (e.g., `US`, `GB`, `DE`). |

### Notes

- **ISO 17442 Structure:** An LEI code is a 20-character alphanumeric string: 4 characters identifying the Local Operating Unit (LOU), 2 reserved characters (`00`), 12 characters for the entity identifier, and 2 check digits (modulo 97).
- **Jurisdiction ISO Codes:** The `jurisdiction` string adopts ISO 3166-2 sub-entity codes where applicable (e.g., `US-DE` for Delaware, USA).
- **Annual Renewal Audits:** Legal Entity Identifiers must be renewed annually by the registrant. The `status` field reflects current active standing in the official global corporate registry.
