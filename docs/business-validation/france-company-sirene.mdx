# France — SIRENE Company Registry

The **France Company Verification API** connects to the official corporate registry of France (the SIRENE directory) to authenticate companies, subsidiaries, and physical establishments operating under French jurisdiction.

Verify legal entity status, 9-digit SIREN codes, 14-digit SIRET identifiers, European VAT numbers, corporate governance officers, and annual financial filings to power automated KYB and supplier due diligence workflows.

---

## API Reference

### Endpoint

```http
GET https://api.verifik.co/v2/fr/company
```

Query the official French corporate registry using a SIREN identifier, SIRET branch number, or legal entity name.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <token>` | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditional** | 9-digit legal entity SIREN or 14-digit establishment SIRET (e.g., `775670417`). Required if `companyName` is omitted. |
| `companyName` | string | **Conditional** | Official legal entity or registered trade name (e.g., `LVMH`). Required if `documentNumber` is omitted. |

### Notes

- **SIREN vs SIRET:** A **SIREN** is a unique 9-digit identifier assigned to the overarching legal entity. A **SIRET** is 14 digits consisting of the 9-digit SIREN plus a 5-digit NIC (*Numéro Interne de Classement*) representing an individual branch or facility.
- **Intra-Community VAT Calculation:** In France, the European VAT identification number is derived directly from the SIREN code via modulo 97 arithmetic: `FR + [12 + 3 * (SIREN % 97)] % 97 + SIREN`.
- **Corporate Governance:** The `officers` array includes legal representatives, managing directors (*Directeurs Généraux*), and board members reported in the official corporate registry.
