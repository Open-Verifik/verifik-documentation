# United States — Driver License Barcode (AAMVA PDF417)

The **United States Driver License Barcode API** decodes, standardizes, and validates the PDF417 two-dimensional barcode embedded on the reverse of driver licenses and identification cards issued by all 50 US states, the District of Columbia, and US territories.

Engineered to comply with the American Association of Motor Vehicle Administrators (**AAMVA**) Card Design Standard (CDS), the API extracts demographics, document identifiers, expiration dates, REAL ID compliance indicators, and machine-readable data subfiles from either raw scanner output or camera image captures.

---

## API Reference

### Endpoint

```http
POST https://api.verifik.co/v2/usa/driver-license/barcode
```

Parse and extract structured identity data from a rear US driver license barcode payload or image.

### Headers

| Name | Value | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Request payload format |
| Accept | `application/json` | Response format |
| Authorization | `Bearer <token>` | Client JWT authentication token |

### Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `rawBarcode` | string | **Conditional** | Raw ANSI/AAMVA PDF417 text string obtained from a hardware 2D barcode scanner or client SDK. Required if `backImage` is omitted. |
| `backImage` | string | **Conditional** | Base64-encoded image string or public HTTPS URL of the rear side of the driver license. Required if `rawBarcode` is omitted. |
| `licenseNumber` | string | No | Expected driver license number to confirm matching during parsing. |
| `state` | string | No | Expected two-letter US state postal abbreviation (e.g., `CA`, `FL`, `NY`, `TX`). |

### Notes

- **AAMVA Issuer Identification Number (IIN):** The 6-digit numeric prefix identifies the issuing jurisdiction (e.g., `636014` designates California, `636010` designates Florida, `636001` designates New York) under official motor vehicle administration standards.
- **REAL ID Verification:** Documents marked `isRealIdCompliant: true` satisfy federal statutory standards under the REAL ID Act for domestic airline boarding and federal building access.
- **Calculated Age & Expiration:** The endpoint automatically calculates subject age from the decoded date of birth and computes real-time `isExpired` boolean status against the current UTC date.
