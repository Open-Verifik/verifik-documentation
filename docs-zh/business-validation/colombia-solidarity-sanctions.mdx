# 哥伦比亚 — 互助部门处分

**互助处分**查询读取 Supersolidaria 的受处分公告。发送号码或名称。仅当存在处分时 `isSanctioned` 为 true。单纯未命中是 HTTP 200，`isSanctioned` 为 false，`sanctionsCount` 为 0，状态为 `SIN SANCIONES REGISTRADAS`。本接口不对这种未命中返回 404。

## 调用返回的内容

- `isSanctioned` 与 `sanctionsCount`
- `status`
- `matches`

## 使用场景

- 放款前筛查合作社。
- 把干净的互助检查存为 200。
- 按 NIT 或受处分名称检索。

---

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersolidaria/sanciones
```

命中含 `sanctionsCount` 和 `matches`。单纯未命中是 HTTP 200，且 `isSanctioned` 为 false。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **条件必填** | `900123456` | NIT 或号码。别名 `nit`。 |
| `businessName` | string | **条件必填** | `EJEMPLO SAS` | 名称。别名 `companyName` 与 `fullName`。 |
| `documentType` | string | 否 | `NIT` | 可选：`NIT`、`CC`、`CE`、`PAS`、`TI`。 |

### 说明

- 单纯未命中是 HTTP 200，且 `isSanctioned` 为 false。
- 至少发送一个检索值。
- 不要把这个 200 映射成 404。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `documentNumber: "900555111"` | 命中时 isSanctioned 为 true 的 200。 |
| 缺少必填值 | Omit number and name | 没有检索值时为 409。 |
| 未知的值 | `documentNumber: "800000111"` | isSanctioned 为 false 的 200。单纯未命中不是 404。 |

401 when the bearer token is missing or rejected.
