# 新西兰 — 企业与法人登记查询 (KYB)

**新西兰企业与法人登记查询**对照官方商业登记核验法人。请将公司注册号或税务标识（NZBN）作为 `documentNumber` 发送。用于 KYB 开户、供应商尽职调查和交易对手筛查。

`documentNumber` 为必填。`documentType` 为可选。发送时请写明标识种类（例如 `NZBN`），以便区分公布多种号码的国家。

## 登记机关返回的内容

- 法定名称
- 登记状态
- 成立日期
- 税务或注册标识
- 注册地址

## 使用场景

- 在首次付款前完成新西兰供应商或交易对手的开户。
- 核对合同或发票上的法定名称和登记状态。
- 为 KYB 档案收集成立日期、税务标识和注册地址。

## API 参考

### 端点

```http
GET https://api.verifik.co/v2/nz/company
```

使用 `documentNumber` 和可选的 `documentType` 查询新西兰官方商业登记。成功响应包含法定名称、登记状态、成立日期、税务标识（NZBN）和注册地址。用于 KYB 开户或供应商尽职调查。下方示例展示这些字段。包括 `status` 措辞在内的实际值来自登记机关。

### 请求头

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <your_token>` | 客户端 JWT 认证令牌 |

### 参数

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **是** | `9429000000000` | 官方公司注册号或税务标识（NZBN）。 |
| `documentType` | string | 否 | `NZBN` | 公司证件类型或登记前缀。可用示例：`NZBN`。只发送官方号码时可省略。 |

### 备注

- **标识格式.** NZBN 为 13 位数字。只发送数字，不要包含空格。
- 公司证件类型或登记前缀。可用示例：`NZBN`。只发送官方号码时可省略。
- 示例中的状态标签用于说明字段。实际登记机关返回其自身标签，可能是当地语言。
- 此接口的客户参数是 `documentNumber`，以及需要标明标识种类时的 `documentType`。
- JSON 示例说明上述字段。实际调用返回所发送标识对应的登记记录。

## 沙盒探测

账户处于沙盒模式时，用相同参数调用此接口。表中说明每种情况对应的已记录响应。

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| **已有标识** | `documentType: "NZBN"`, `documentNumber: "9429000000000"` | 来源持有该号码时返回 200，以及法定名称、状态、标识和地址或身份属性。 |
| **缺少 documentNumber** | 省略 `documentNumber` | 省略 `documentNumber` 时返回 409 `MissingParameter`。 |
| **未知号码** | `documentNumber: "000000000"` | 登记机关没有该号码的记录时返回 404 `NotFound`。 |

缺少或拒绝 bearer 令牌时返回 401。
