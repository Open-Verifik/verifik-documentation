# 哥伦比亚 — 综合公司信息（SIIS）

**SIIS** 查询读取 Supersociedades 监管的公司申报。发送 NIT 或公司名称。有申报时 `found` 为 true，只是不在 SIIS 中时为 false。该单纯未命中是 HTTP 200，状态为 `NO REGISTRADA EN SIIS SUPERSOCIEDADES`。用 `inLiquidationOrReorganization` 看破产预警。

## 调用返回的内容

- `found` 与 `inLiquidationOrReorganization`
- `ciiu`、行业与城市
- 有申报时的 `financialSummary`
- 单纯未命中时 `filings` 为空

## 使用场景

- 授信前拉取最新 SIIS 申报。
- 标记已进入重组的公司。
- 把不在 SIIS 记为 200，而不是 404。

---

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersociedades/siis
```

申报含 `status`、`ciiu`、地址、`financialSummary` 和 `filings`。`found` 为 false 表示不在 SIIS。两者都是 HTTP 200。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **条件必填** | `900123456` | NIT 或号码。别名 `nit`。没有名称时必填。 |
| `businessName` | string | **条件必填** | `INDUSTRIAS EJEMPLO SAS` | 名称，2 到 200 个字符。别名 `companyName` 与 `fullName`。没有号码时必填。 |
| `documentType` | string | 否 | `NIT` | 可选：`NIT`、`CC`、`CE`、`PAS` 或 `TI`。 |

### 说明

- 发送 NIT 或名称。
- `found` 为 false 是成功的单纯未命中。
- 不要把该正文映射成 HTTP 404。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `documentNumber: "900673447"` | 命中为 200 且 found 为 true。 |
| 缺少必填值 | Omit number and name | 没有检索值时为 409。 |
| 未知的值 | `documentNumber: "800000111"` | 单纯未命中为 200 且 found 为 false。不是 404。 |

401 when the bearer token is missing or rejected.
