取消 `SmartBatch`（以及任何关联的 `FeatureRunner` 运行）。该批次将转为 `status: "cancelled"` 状态并设置 `completedAt`。

已处于终态（`"completed"`、`"failed"` 或 `"cancelled"`）的批次无法被取消，并将返回 `400 BadRequest`（`batch_already_terminal`）。

### 接口

```text
POST https://api.verifik.co/v2/smart-batches/{id}/cancel
```

此接口也可通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches/{id}/cancel` 访问，需使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 参数

| 名称 | 类型   | 必填 | 描述 |
| ---- | ------ | ---- | ---- |
| `id` | string | 是   | 要取消的 `SmartBatch` ObjectId。 |

### 注意事项

- 已取消的批次会保留之前收集的所有行结果，之后可以通过[启动 Smart Batch](/verifik-zh/smart-reports/start-a-smart-batch)重新启动。
- 如果你想暂时停止处理并在之后直接继续而无需重新启动，请使用[暂停 Smart Batch](/verifik-zh/smart-reports/pause-a-smart-batch)。
