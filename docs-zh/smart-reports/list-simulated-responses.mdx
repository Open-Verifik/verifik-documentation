列出在模板设计清单中已预置沙盒模拟响应的 Verifik 目录端点。可通过 `country` 或搜索关键词（`q`）进行筛选，以发现端点 `code` 标识符与预期的 `inputs`。

在无头报告构建器与 AI 智能体流水线中，可使用此目录发现端点选择贴近真实的模拟数据集，无需执行会产生费用的实时查询或处理生产环境个人身份信息（PII）。将返回的任意 `code` 传入 [获取模拟响应](/verifik-zh/smart-reports/retrieve-simulated-response)，即可获取用于 [探测示例数据](/verifik-zh/smart-reports/introspect-sample-data)、[生成模板布局](/verifik-zh/smart-reports/generate-template-layout) 或 [预览模板 HTML](/verifik-zh/smart-reports/preview-template-html) 的示例负载。

### 端点

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses
```

Smart-Agent 代理（`https://ai.verifik.co`）暴露了完全相同的 `/v2/...` 路径，并同样要求携带你自己的 `Authorization: Bearer <VERIFIK_JWT>` 请求头。

### 请求头

| 名称 | 值 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 参数

| 名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `country` | string | 否 | 按国家筛选模拟端点。 |
| `q` | string | 否 | 用于按名称、代码或元数据筛选端点的搜索字符串。 |

import (

### 注意事项

- 查询模拟响应不会执行实时目录查询，也不会消耗积分。
- 将每个条目的 `code` 与 [获取模拟响应](/verifik-zh/smart-reports/retrieve-simulated-response) 配合使用，即可获取完整的 `dataSample` 与 `emptySample` 负载。
