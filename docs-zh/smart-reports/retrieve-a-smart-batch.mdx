根据 ID 为已认证客户获取单个 `SmartBatch` 文档。在返回载荷之前，服务器会将外部存储的 `smartbatchrows` 输出合并到 `rows[].results` 中，并执行 `healIncompleteRows()`，以重新打开已标记为 `completed` 但缺少已启用配置步骤输出的行。

如果该批次不存在或属于另一个客户账户，接口将返回 `200` 及 `{ "data": null }`。读取批次不会执行核验，也不会消耗积分。

### 接口

```text
GET https://api.verifik.co/v2/smart-batches/{id}
```

此接口也可通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches/{id}` 访问，需使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 路径参数

| 名称 | 类型   | 必填 | 描述 |
| ---- | ------ | ---- | ---- |
| `id` | string | 是   | `SmartBatch` ObjectId。 |

### 查询参数

| 名称          | 类型     | 必填 | 描述 |
| ------------- | -------- | ---- | ---- |
| `select`      | string   | 否   | 字段投影表达式（例如 `"-rows"` 表示排除行载荷）。 |
| `columns`     | string   | 否   | 要在返回文档中包含的字段子集。 |
| `populates[]` | string[] | 否   | 要填充的关联文档：`"batchConfiguration"` 和/或 `"client"`。 |

}

### 注意事项

- 读取批次时，外部 `smartbatchrows` 步骤结果会自动合并到 `rows[].results` 中。
- `healIncompleteRows()` 会对照已启用的 `batchConfiguration` 步骤检查每个 `completed` 行，并将任何缺少步骤输出或错误信息（errors）的行重新打开为 `pending`。
- 若需频繁轮询状态，建议优先使用[获取 Smart Batch 进度](/verifik-zh/smart-reports/get-smart-batch-progress)，以避免重复拉取完整的行载荷。
