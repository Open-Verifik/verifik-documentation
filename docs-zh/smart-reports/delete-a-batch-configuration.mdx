删除你客户账户拥有的 `BatchConfiguration`。此接口会移除该配置文档，并在 `data` 中返回被删除的文档。

如果 `{id}` 不存在或属于另一个客户账户，接口将返回 `404`（`not_found`）。删除配置不会执行查询，也不会消耗积分。

### 接口

```
DELETE https://api.verifik.co/v2/batch-configurations/{id}
```

也可以通过 Smart-Agent 代理 `https://ai.verifik.co/v2/batch-configurations/{id}` 访问，并使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>` 请求头。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称 | 值 |
| ---- | -- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

令牌必须是**客户 JWT**。缺少凭证或凭证无效将返回 `401 Unauthorized`。

### 参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| `id` | string | 是 | 要删除的 `BatchConfiguration` ObjectId。 |

### 注意事项

- 删除配置会在 `data` 中返回被删除的文档。随后使用同一 `{id}` 发起的 `GET`、`PUT` 或 `DELETE` 请求将不再找到该记录（`GET` 返回 `data: null`；`GET /input-schema`、`PUT` 和 `DELETE` 返回 `404` `not_found`）。
- 删除配置不会消耗积分。
