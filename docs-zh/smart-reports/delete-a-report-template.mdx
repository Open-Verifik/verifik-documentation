删除归属于已认证客户的自定义 Smart Report 模板。被删除的模板文档会在 `{ "data": ... }` 中返回。

在无头工作流与自动化测试流水线中，可使用此端点清理临时模板或下线已弃用的报告设计。内置的 `"System"` 模板不可删除，将返回 `403`（`system_template_readonly`）。删除模板不会消耗积分，也不会移除此前已生成的 `SmartBatch` 报告。

### 端点

```
DELETE https://api.verifik.co/v2/smart-report-templates/{id}
```

Smart-Agent 代理（`https://ai.verifik.co`）暴露了完全相同的 `/v2/...` 路径，并同样要求携带你自己的 `Authorization: Bearer <VERIFIK_JWT>` 请求头。

### 请求头

| 名称 | 值 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 参数

| 名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | Smart Report 模板 ObjectId。 |

### 注意事项

- 内置 `"System"` 模板不可删除（返回 `403` `system_template_readonly`）。
- 删除后，后续针对同一 `{id}` 发起的 `GET`、`PUT` 或 `DELETE` 请求将分别返回 `{ "data": null }`（`GET`）或 `404` `not_found`（`PUT`/`DELETE`）。
