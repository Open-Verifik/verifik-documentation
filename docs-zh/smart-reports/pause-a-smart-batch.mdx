暂停正在运行的 `SmartBatch`（以及任何关联的 `FeatureRunner` 运行），且不会丢失已完成行写入的结果。worker 将停止领取剩余行，直到你恢复该批次。

队列和浏览器模式批次必须处于 `"processing"` 或 `"pending"` 状态（否则返回 `400 batch_not_pausable`）。由 `FeatureRunner` 运行驱动的批次则要求运行记录处于 `"queued"` 或 `"processing"` 状态（否则返回 `400 run_not_pausable`）。暂停操作不消耗积分。

### 接口

```text
POST https://api.verifik.co/v2/smart-batches/{id}/pause
```

此接口也可通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches/{id}/pause` 访问，需使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 参数

| 名称 | 类型   | 必填 | 描述 |
| ---- | ------ | ---- | ---- |
| `id` | string | 是   | 要暂停的 `SmartBatch` ObjectId。 |

### 注意事项

- 若要通过编程方式暂停批次，请始终使用此接口，而非 `PUT /v2/smart-batches/{id}`（该接口不接受 `"paused"`）。
- 如果由 `FeatureRunner` 驱动的批次运行未处于 `"queued"` 或 `"processing"` 状态，接口将返回 `400 BadRequest` 及 `run_not_pausable`。
- 稍后可使用[恢复 Smart Batch](/verifik-zh/smart-reports/resume-a-smart-batch)继续执行，或使用[取消 Smart Batch](/verifik-zh/smart-reports/cancel-a-smart-batch)永久终止。
