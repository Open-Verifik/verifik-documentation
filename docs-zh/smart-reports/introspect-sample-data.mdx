检查 `sampleData` 核验负载，返回包含字段路径、值结构形态、推荐的 `sectionType` 选择、备选区块类型、建议表格列以及绑定建议的结构化映射。

在无头报告编排与 AI 智能体流水线中，可在从 [获取模拟响应](/verifik-zh/smart-reports/retrieve-simulated-response) 获取负载或捕获 `SmartBatch` 行数据后立即调用此端点。你的 UI 或智能体无需猜测 `dataPath` 字符串或编写脆弱的 JSON 遍历逻辑，即可使用探测得到的 `nodes` 与 `batch` 元数据直接构建有效的 `sections`，或丰富传入 [生成模板布局](/verifik-zh/smart-reports/generate-template-layout) 的 `prompt` 上下文。遍历器最多检查至第 `5` 层深度和最多 `600` 个节点。

### 端点

```
POST https://api.verifik.co/v2/smart-report-templates/introspect
```

Smart-Agent 代理（`https://ai.verifik.co`）暴露了完全相同的 `/v2/...` 路径，并同样要求携带你自己的 `Authorization: Bearer <VERIFIK_JWT>` 请求头。

### 请求头

| 名称 | 值 |
| --- | --- |
| Content-Type | `application/json` |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 请求体参数

| 名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `sampleData` | object | 是 | 示例核验负载，包含可选的 `batchName`（string）、`rowIndex`（number）、`inputData`（object）和 `results`（object）。 |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func main() {
	body, _ := json.Marshal(map[string]interface{}{
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{
					"fullName": "Mateo Rojas",
					"status":   "active",
				},
				"fines": []map[string]interface{}{
					{"code": "C02", "amount": 580000, "status": "pending"},
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/introspect", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### 注意事项

- 遍历会在第 `5` 层深度停止，且节点上限为 `600` 个。当超大负载触及该上限时，`truncated` 为 `true`。
- 此端点为只读且无状态；不会保存模板，也不会消耗核验积分。
