恢复已暂停的 `SmartBatch`（以及任何底层的 `FeatureRunner` 运行）。服务器会重新验证你的客户账户是否仍拥有所有已配置步骤的功能授权（如果任何端点访问权限已被吊销，则返回 `409 endpoints_not_in_account`），检查批次是否处于 `"paused"` 状态，然后将其重新转为 `"processing"`。

如果批次当前并非 `"paused"` 状态，请求将失败并返回 `400 BadRequest`（`batch_not_paused`，或当底层 `FeatureRunner` 运行未处于暂停状态时返回 `run_not_paused`）。

### 接口

```text
POST https://api.verifik.co/v2/smart-batches/{id}/resume
```

此接口也可通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches/{id}/resume` 访问，需使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 参数

| 名称 | 类型   | 必填 | 描述 |
| ---- | ------ | ---- | ---- |
| `id` | string | 是   | 要恢复的 `SmartBatch` ObjectId。 |

### 注意事项

- 恢复操作会重新校验客户的功能授权；如果任何步骤端点在你的账户上不再启用，请求将被拒绝并返回 `409 endpoints_not_in_account`。
- 已完成的行会保留其存储的结果，恢复时不会重复执行或重复扣费。
- 如果批次处于 `"draft"`、`"pending"` 或 `"cancelled"` 状态，请改用[启动 Smart Batch](/verifik-zh/smart-reports/start-a-smart-batch)。
