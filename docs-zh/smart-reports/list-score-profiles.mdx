列出所有受支持的核验评分配置，它们可绑定到 Smart Report 模板（`reportTheme.scoreProfile`）或传入 [预览模板 HTML](/verifik-zh/smart-reports/preview-template-html)（`scoreProfile`）。

在无头配置界面与 AI 智能体工作流中，建议在启用评分前先查询此端点，以便你的应用动态校验 `scoreProfile` 标识符，避免在 HTML 预览或报告渲染期间触发 `409`（`unknown_score_profile`）错误。可用配置覆盖司机、身份、企业、车队、车辆、信贷、医疗及生物特征识别工作流：

- `cabify_driver`
- `kyc`
- `kyb`
- `fleet`
- `vehicle_purchase`
- `identity_lookup`
- `background_check`
- `lending`
- `healthcare_professional`
- `biometrics`

### 端点

```
GET https://api.verifik.co/v2/smart-report-templates/score-profiles
```

Smart-Agent 代理（`https://ai.verifik.co`）暴露了完全相同的 `/v2/...` 路径，并同样要求携带你自己的 `Authorization: Bearer <VERIFIK_JWT>` 请求头。

### 请求头

| 名称 | 值 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 参数

无需查询参数或路径参数。

### 注意事项

- 在创建或更新模板时将返回的 `id` 值用于 `reportTheme.scoreProfile`，或在调用 [预览模板 HTML](/verifik-zh/smart-reports/preview-template-html) 时将其作为 `scoreProfile` 传入。
- 向 `POST /v2/smart-report-templates/preview-html` 发送未识别的 `scoreProfile` 会返回 `409`（`unknown_score_profile`）。
