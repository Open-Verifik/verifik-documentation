列出你已认证的客户账户所拥有的批处理配置（Batch Configurations）。结果按 JWT 所属客户作用域过滤，按最新创建时间降序排列（`createdAt` 降序），并返回已填充的 `steps.appFeature` 元数据以及客户专属的 `ClientFeature` 定价信息。

当你需要包含 `total`、`limit`、`page` 和 `pages` 元数据的分页结果时，请传入 `page`。若省略 `page`，则会直接在 `data` 中返回匹配的数组。列出配置不会执行查询，也不会消耗积分。

### 接口

```
GET https://api.verifik.co/v2/batch-configurations
```

也可以通过 Smart-Agent 代理 `https://ai.verifik.co/v2/batch-configurations` 访问，并使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>` 请求头。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称 | 值 |
| ---- | -- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

令牌必须是**客户 JWT**。缺少凭证或凭证无效将返回 `401 Unauthorized`。

### 参数

所有查询参数均为可选。

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| `search` | string | 否 | 对已保存配置的名称执行不区分大小写的筛选。 |
| `text` | string | 否 | `search` 的别名。 |
| `page` | integer | 否 | 页码（从 `1` 开始）。传入该参数时，响应中将包含分页元数据（`total`、`limit`、`page`、`pages`）。 |
| `limit` | integer | 否 | 每页返回的最大配置数量。 |
| `perPage` | integer | 否 | `limit` 的别名。 |

package main

import (
    "encoding/json"
    "fmt"
    "net/http"
    "net/url"
    "os"
)

func main() {
    u, _ := url.Parse("https://api.verifik.co/v2/batch-configurations")
    q := u.Query()
    q.Set("search", "Colombia")
    q.Set("page", "1")
    q.Set("limit", "20")
    u.RawQuery = q.Encode()

    req, _ := http.NewRequest("GET", u.String(), nil)
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

    resp, _ := http.DefaultClient.Do(req)
    defer resp.Body.Close()

    var out map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&out)
    fmt.Println(out)
}

### 注意事项

- 结果会自动按已认证的客户 JWT 所属作用域过滤，并按创建时间降序（`-createdAt`）排列。
- 若已配置，每个步骤的 `steps.appFeature` 都会被填充并附加你账户的 `ClientFeature` 定价信息。
- `perPage` 是 `limit` 的别名，`text` 是 `search` 的别名。
- 仅当查询字符串中提供 `page` 时，响应中才会包含分页元数据（`total`、`limit`、`page`、`pages`）。
