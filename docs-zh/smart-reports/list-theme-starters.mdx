获取 Verifik 内置的主题化起步模板，并支持按 `theme` 进行可选筛选。每个起步模板均预配置了 `sections`、`reportTheme`、`sampleData`、页面布局属性与配色方案，使你无需从零组装区块树即可快速上线生产级报告设计。

在无头准入流程与 AI 智能体中，可调用此端点挑选精心编排的视觉起点，立即通过 [预览模板 HTML](/verifik-zh/smart-reports/preview-template-html) 进行预览，按需自定义品牌配色或 Logo，然后通过 [创建报告模板](/verifik-zh/smart-reports/create-a-report-template) 保存为可编辑的自定义模板。

### 端点

```
GET https://api.verifik.co/v2/smart-report-templates/theme-starters
```

Smart-Agent 代理（`https://ai.verifik.co`）暴露了完全相同的 `/v2/...` 路径，并同样要求携带你自己的 `Authorization: Bearer <VERIFIK_JWT>` 请求头。

### 请求头

| 名称 | 值 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 参数

| 名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `theme` | string | 否 | 可选主题筛选：`"premium_dark"`、`"light_cards"`、`"editorial"`、`"dashboard"` 或 `"smart_enroll_v2"`（`"light_cards"` 的别名；建议使用规范名称 `"light_cards"`）。 |

### 注意事项

- `"smart_enroll_v2"` 可作为 `"light_cards"` 的别名使用，但建议按规范主题 ID `"light_cards"` 进行筛选。
- 此处返回的起步模板携带 `type: "System"` 以供参考。当通过 [创建报告模板](/verifik-zh/smart-reports/create-a-report-template) 保存自定义副本时，只需传入你的 `name` 及设计字段（`sections`、`reportTheme`、`sampleData`、配色和 PDF 设置）。
