更新由已认证客户拥有的现有 `SmartBatch` 字段。你可以更新 `name`、`status`、`executor`，或替换 `rows`。当请求中提供 `rows` 时，服务器会重新计算 `totalRows`、`completedRows`、`failedRows` 和 `partialRows`，并同步外部行快照。

若要将批次切换为 `"paused"` 状态，请使用专用的[暂停 Smart Batch](/verifik-zh/smart-reports/pause-a-smart-batch) 接口。仅当批次当前处于 `"draft"`、`"pending"` 或 `"cancelled"` 状态时，修改 `executor` 才会生效。

### 接口

```text
PUT https://api.verifik.co/v2/smart-batches/{id}
```

此接口也可通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches/{id}` 访问，需使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 参数

| 名称 | 类型   | 必填 | 描述 |
| ---- | ------ | ---- | ---- |
| `id` | string | 是   | 要更新的 `SmartBatch` ObjectId。 |

### 请求体

| 名称       | 类型     | 必填 | 描述 |
| ---------- | -------- | ---- | ---- |
| `name`     | string   | 否   | 更新后的批次显示名称。最多 `150` 个字符。 |
| `status`   | string   | 否   | 允许的值：`"draft"`、`"pending"`、`"processing"`、`"completed"`、`"failed"` 或 `"cancelled"`。如需设为 `"paused"`，请使用 `POST /v2/smart-batches/{id}/pause`。 |
| `executor` | string   | 否   | 允许的值：`"queue"`、`"featureRunner"` 或 `"browser"`。仅当当前批次状态为 `"draft"`、`"pending"` 或 `"cancelled"` 时生效。 |
| `rows`     | object[] | 否   | 用于替换的行列表。包装格式需包含 `rowIndex` 和 `inputData`，并可选传入 `status`、`results`、`errors` 和 `processedAt`；扁平格式行会自动标准化。 |

未知请求体键将被 Joi 校验拒绝，并返回 `409 MissingParameter`。

package main

import (

	batchID := "6801a2b3c4d5e6f7a8b9c0d3"

		"name":     "Colombia Onboarding — Updated",
		"executor": "queue",

			{
				"rowIndex": 0,
				"inputData": map[string]string{

				},
				"status": "pending",
			},
		},
	})

	req, _ := http.NewRequest("PUT", "https://api.verifik.co/v2/smart-batches/"+batchID, bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}

}

### 注意事项

- `PUT /v2/smart-batches/{id}` 不接受 `"paused"` 状态；请改用[暂停 Smart Batch](/verifik-zh/smart-reports/pause-a-smart-batch)。
- 除非批次当前处于 `"draft"`、`"pending"` 或 `"cancelled"` 状态，否则对 `executor` 的更新将被忽略。
- 若要在不替换现有行的前提下向现有批次追加新行，请使用[向 Smart Batch 追加行](/verifik-zh/smart-reports/append-smart-batch-rows)。
