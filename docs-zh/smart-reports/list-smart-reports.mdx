列出属于已认证客户的 `SmartReport` 记录。返回结果会填充 `template`、`smartBatch` 与 `client` 引用，并支持按 `smartBatch`、`template`、`externalRefId` 和 `createdByChannel` 筛选，同时支持可选的分页和排序。

当你传入 `page` 参数时，响应会包含分页元数据（`total`、`limit`、`page` 与 `pages`）。省略 `page` 则直接在 `{ data: [...] }` 中返回匹配列表，不含分页元数据。

### 端点

```
GET https://api.verifik.co/v2/smart-reports
```

使用你自己的每客户 `Authorization: Bearer <VERIFIK_JWT>`，也可通过 Smart-Agent 代理地址 `https://ai.verifik.co/v2/smart-reports` 访问此端点。共享 x402 执行会被拦截并返回 `403 Forbidden`。

### 请求头

| 名称 | 值 | 说明 |
| --- | --- | --- |
| `Content-Type` | `application/json` | 请求体负载格式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域 JWT（`authUser.clientId`）。 |

### 参数

| 名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `smartBatch` | string | 否 | 按关联的特定 `SmartBatch` ObjectId 筛选报告。 |
| `template` | string | 否 | 按关联的特定模板 ObjectId 筛选报告。 |
| `status` | string | 否 | 允许值：`"draft"`、`"pending"`、`"generating"`、`"generated"`、`"failed"`、`"sent"`。Joi 校验已接受该参数以保证前向兼容性；当前列表查询实际按 `smartBatch`、`template`、`externalRefId` 与 `createdByChannel` 筛选。 |
| `externalRefId` | string | 否 | 按你的外部关联标识符筛选。最多 `200` 个字符。 |
| `createdByChannel` | string | 否 | 按来源渠道筛选：`"portal"`、`"api"`、`"mcp"`、`"x402"` 或 `"webhook"`。 |
| `page` | number | 否 | 要获取的页码。传入 `page` 将启用包含 `total`、`limit`、`page` 与 `pages` 的分页输出。 |
| `limit` | number | 否 | 每页最大条目数。传入 `page` 时默认为 `20`。 |
| `sort` | string | 否 | 排序字段与方向。传入 `page` 时默认为 `"-updatedAt"`。 |

#### 筛选与分页说明

- **前向兼容的 `status` 参数**：Joi 会按 `"draft"`、`"pending"`、`"generating"`、`"generated"`、`"failed"` 和 `"sent"` 校验 `status`，而底层列表查询目前按 `smartBatch`、`template`、`externalRefId` 与 `createdByChannel` 过滤。
- **两种 `200` 响应形态**：当仪表盘或同步任务需要 `total` 和 `pages` 时传入 `page`；省略 `page` 可获取更精简的 `{ data: [...] }` 结构。

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	params := url.Values{}
	params.Set("createdByChannel", "api")
	params.Set("externalRefId", "applicant-42")
	params.Set("page", "1")
	params.Set("limit", "20")
	params.Set("sort", "-updatedAt")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-reports?"+params.Encode(), nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### 注意事项

- `GET /v2/smart-reports` 会在每条返回的 `SmartReport` 上填充 `template`、`smartBatch` 与 `client`。
- 无效的查询参数值会在 Joi 校验阶段失败并返回 `409 MissingParameter`。
- 若需查看包含可直接使用的 `downloadUrl` 与 `htmlUrl` 字段的单份报告，请使用 [获取 Smart Report](/verifik-zh/smart-reports/retrieve-a-smart-report)。
- 若需在不单独管理 `SmartBatch` 与 `SmartReport` 记录的情况下端到端运行新报告，请使用 [运行 Smart Report](/verifik-zh/smart-reports/run-a-smart-report)。
