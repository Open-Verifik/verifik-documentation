根据 ObjectId（`{id}`）获取单个 `BatchConfiguration`。查询仅限于已认证客户 JWT 所属的作用域，并返回已填充的 `steps.appFeature` 详情，同时附带你账户的 `ClientFeature` 定价信息。

如果不存在匹配的配置，或者该 ID 属于另一个客户账户，接口将返回 HTTP `200` 且 `data: null`。读取配置不会执行任何查询，也不会消耗积分。

### 接口

```
GET https://api.verifik.co/v2/batch-configurations/{id}
```

也可以通过 Smart-Agent 代理 `https://ai.verifik.co/v2/batch-configurations/{id}` 访问，并使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>` 请求头。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称 | 值 |
| ---- | -- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

令牌必须是**客户 JWT**。缺少凭证或凭证无效将返回 `401 Unauthorized`。

### 参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| `id` | string | 是 | 来自创建、克隆或列表接口的 `BatchConfiguration` ObjectId。 |

### 注意事项

- 如果 `{id}` 不存在或属于另一个客户账户，此接口将返回 HTTP `200` 及 `{ "data": null }`。
- 在集成代码中读取 `data` 的属性前，请先检查 `data !== null`。
- 若要查看某个配置已解析的必填/可选输入字段及 `exampleInput` 载荷，请调用[获取配置输入模式](/verifik-zh/smart-reports/retrieve-configuration-input-schema)。
