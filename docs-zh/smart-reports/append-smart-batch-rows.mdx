向现有 `SmartBatch` 追加新的输入行，且不会覆盖已有行或已存储的结果。同时支持包装格式行（`{ rowIndex?, inputData }`）与扁平格式行（`{ rowIndex?, ...inputFields }`），服务器会从 `maxExisting + 1` 开始分配连续的行索引。

当批次处于 `"processing"` 状态时，禁止追加行（返回 `400 batch_append_not_allowed_while_processing`）。如果批次此前处于 `"completed"` 或 `"failed"` 状态，追加行会将 `status` 重置为 `"pending"` 并清除 `completedAt`，以便新行得以运行。

### 接口

```text
POST https://api.verifik.co/v2/smart-batches/{id}/rows/append
```

此接口也可通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches/{id}/rows/append` 访问，需使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 参数

| 名称 | 类型   | 必填 | 描述 |
| ---- | ------ | ---- | ---- |
| `id` | string | 是   | 要追加行的 `SmartBatch` ObjectId。 |

### 请求体

| 名称   | 类型     | 必填 | 描述 |
| ------ | -------- | ---- | ---- |
| `rows` | object[] | 是   | 非空的包装格式（`{ rowIndex?, inputData }`）或扁平格式（`{ rowIndex?, ...inputFields }`）输入行数组（`min 1`）。服务器会按 `rowIndex = maxExisting + 1` 顺序分配索引。 |

未知请求体键或空的 `rows` 数组将被 Joi 校验拒绝，并返回 `409 MissingParameter`。

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	body, _ := json.Marshal(map[string]interface{}{
		"rows": []map[string]interface{}{
			{
				"inputData": map[string]string{
					"documentType":   "CC",
					"documentNumber": "1020304050",
				},
			},
			{
				"documentType":   "CC",
				"documentNumber": "1098765432",
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-batches/"+batchID+"/rows/append", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### 注意事项

- 追加行不会执行核验或消耗积分；随后可通过[启动 Smart Batch](/verifik-zh/smart-reports/start-a-smart-batch)启动该批次。
- 客户端传入的任何 `rowIndex` 均会被忽略，服务器将从 `maxExisting + 1` 开始按顺序分配编号。
- 如果批次原状态为 `"completed"` 或 `"failed"`，其 `status` 会重置为 `"pending"`，且 `completedAt` 会被清除。
