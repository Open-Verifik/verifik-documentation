列出属于已认证客户账户的 `SmartBatch` 记录。结果默认按最新创建时间降序排列（`-createdAt`），并且除非显式传入 `includeRows=true`，否则不会包含 `rows` 数组，以保持列表响应精简紧凑。

发送 `page` 可启用包含 `total`、`limit`、`page` 和 `pages` 元数据的分页输出。若省略 `page`，则会收到不包含分页字段的 `{ data }` 批次数组响应。列出批次不会执行核验，也不会消耗积分。

### 接口

```text
GET https://api.verifik.co/v2/smart-batches
```

也可以通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches` 访问，并使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 参数

| 名称                 | 类型    | 必填 | 描述 |
| -------------------- | ------- | ---- | ---- |
| `batchConfiguration` | string  | 否   | 按 `BatchConfiguration` ObjectId 筛选批次。 |
| `status`             | string  | 否   | 按批次状态筛选：`"draft"`、`"pending"`、`"processing"`、`"paused"`、`"completed"`、`"failed"` 或 `"cancelled"`。 |
| `page`               | number  | 否   | 页码（`>= 1`）。启用分页并在响应中添加 `total`、`limit`、`page` 和 `pages`。 |
| `limit`              | number  | 否   | 每次响应的最大条目数（`1` 到 `200`）。 |
| `perPage`            | number  | 否   | 当设置了 `page` 时的每页大小（`1` 到 `200`）。默认为 `20`。 |
| `includeRows`        | boolean | 否   | 设为 `true` 时，在每个返回的批次中包含 `rows`。省略或设为 `false` 时将排除 `rows`。 |
| `search`             | string  | 否   | 对批次 `name` 执行不区分大小写的正则搜索。 |
| `sort`               | string  | 否   | 排序字段与方向。默认为 `"-createdAt"`。 |
| `sortBy`             | string  | 否   | 与 `sortOrder` 配对使用的排序字段名。 |
| `sortOrder`          | string  | 否   | `sortBy` 的排序方向：`"asc"` 或 `"desc"`。 |

未知的查询参数将被 Joi 校验拒绝，并返回 `409 MissingParameter`。

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	params := url.Values{}
	params.Set("status", "processing")
	params.Set("page", "1")
	params.Set("perPage", "20")
	params.Set("search", "Colombia")
	params.Set("sort", "-createdAt")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-batches?"+params.Encode(), nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### 注意事项

- 结果仅限于已认证客户（JWT 中的 `clientId`）作用域。
- 省略 `includeRows` 或将其设为 `false` 可保持列表响应轻量；如需获取单个批次的完整 `rows`，请调用[查询 Smart Batch](/verifik-zh/smart-reports/retrieve-a-smart-batch)。
- 无效的查询值或未知的查询键将无法通过 Joi 校验，并返回 `409 MissingParameter`。
- 当提供 `page`（`>= 1`）时，`perPage` 默认为 `20`，支持 `1` 至 `200`。
