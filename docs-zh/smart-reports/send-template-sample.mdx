使用 `sampleData` 渲染已保存的 Smart Report 模板（`{id}`），并将生成的 PDF 直接通过电子邮件发送给一个或多个 `recipients`。你也可以选择提供 `printHtml` 以跳过 HTML 生成步骤，或提供 `pdfBase64` 以直接附加预渲染的 PDF 缓冲区。

在无头 CI/CD 流水线、模板审批工作流与 AI 智能体自动化中，无需自行搭建邮件基础设施即可使用此端点将格式化后的报告预览分发给合规审阅人员或产品相关方。最高支持 `64MB` 的 JSON 请求体，足以容纳嵌入字体、Logo、预渲染 HTML 或 base64 PDF。

### 端点

```
POST https://api.verifik.co/v2/smart-report-templates/{id}/send-sample
```

Smart-Agent 代理（`https://ai.verifik.co`）暴露了完全相同的 `/v2/...` 路径，并同样要求携带你自己的 `Authorization: Bearer <VERIFIK_JWT>` 请求头。

### 请求头

| 名称 | 值 |
| --- | --- |
| Content-Type | `application/json` |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 参数

| 名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | Smart Report 模板 ObjectId。 |

### 请求体参数

支持最大 `64MB` 的 JSON 负载。

| 名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `recipients` | string[] | 是 | 有效收件人邮箱地址数组（至少 `1` 个）。 |
| `sampleData` | object | 是 | 示例负载，包含 `inputData`、`results`、`batchName` 和 `rowIndex`。 |
| `subject` | string | 否 | 自定义邮件主题行。默认使用模板的 `name`，格式为 `` `Sample Report: <name>` ``。 |
| `language` | string | 否 | 邮件文案语言：`"en"` 或 `"es"`。默认为 `"es"`。 |
| `printHtml` | string | 否 | 可选的预渲染 HTML 文档，直接转换为 PDF，而非从模板 `sections` 渲染。 |
| `pdfBase64` | string | 否 | 可选的 base64 编码 PDF 附件，无需服务端生成 PDF 即可直接发送。 |

```go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func main() {
	id := "67c1f94b2d8a1c0012a4b301"
	body, _ := json.Marshal(map[string]interface{}{
		"recipients": []string{"compliance@acme.example"},
		"subject":    "Sample Report: Colombia Driver Onboarding",
		"language":   "en",
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding Sample",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{
					"fullName": "Mateo Rojas",
					"status":   "active",
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/"+id+"/send-sample", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}
```

### 注意事项

- 与其他将负载包装在 `{ "data": ... }` 中的模板端点不同，`send-sample` 直接在顶层返回 `success`、`message`、`recipients`、`messageId` 和 `delivery` 字段。
- 若省略 `language`，邮件默认使用 `"es"`。如需发送英文相关方通知，请传入 `"en"`。
- 如需在本地保存渲染后的 PDF 而非通过邮件发送，请使用 [下载模板示例](/verifik-zh/smart-reports/download-template-sample)。
