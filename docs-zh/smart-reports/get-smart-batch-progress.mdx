获取 `SmartBatch` 的轻量级进度摘要，无需传输整个 `rows` 数组。响应包含行计数器（`totalRows`、`completedRows`、`failedRows`、`partialRows`、`pendingRows`）、执行时间戳、`creditsSpent`，以及（当由 `FeatureRunner` 运行驱动时）嵌套的 `run` 和账本 `spend` 详情。

当配置了 `batchConfiguration.notification.webhookUrl` 时，服务端 `FeatureRunner` 运行在完成后还会发送一个 `smart_batch_batch_completed` webhook 事件（包含 `runId` 和 `creditsSpent`）。轮询此接口不消耗积分。

### 接口

```text
GET https://api.verifik.co/v2/smart-batches/{id}/progress
```

此接口也可通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches/{id}/progress` 访问，需使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 参数

| 名称 | 类型   | 必填 | 描述 |
| ---- | ------ | ---- | ---- |
| `id` | string | 是   | 要轮询进度的 `SmartBatch` ObjectId。 |

### 注意事项

- 当批次关联了 `FeatureRunner` 运行记录时，响应中会包含 `run` 和 `spend`（如果未返回引用的运行记录，则 `run` 为 `null`）。
- 如果设置了 `batchConfiguration.notification.webhookUrl`，服务端 `FeatureRunner` 运行会在完成时触发 `smart_batch_batch_completed` webhook 事件（附带 `runId` 和 `creditsSpent`）。请参阅 [SmartReports Webhook](/verifik-zh/resources/smart-reports-webhooks)。
- 批次进入终态后，请使用[查询 Smart Batch](/verifik-zh/smart-reports/retrieve-a-smart-batch)查看行级 `results` 和 `errors`。
