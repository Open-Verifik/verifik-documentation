删除属于已认证客户的 `SmartReport` 记录。成功后，API 会在 `{ "data": ... }` 中返回被删除的 `SmartReport` 文档。

如果报告 ID 不存在或属于其他客户，该端点会返回 `404 Not Found`（`{ "message": "not_found", "code": "NotFound" }`）。删除报告只会移除 `SmartReport` 文档，不会删除底层的 `SmartBatch` 核验数据。

### 端点

```
DELETE https://api.verifik.co/v2/smart-reports/{id}
```

使用你自己的每客户 `Authorization: Bearer <VERIFIK_JWT>`，也可通过 Smart-Agent 代理地址 `https://ai.verifik.co/v2/smart-reports/{id}` 访问此端点。共享 x402 执行会被拦截并返回 `403 Forbidden`。

### 请求头

| 名称 | 值 | 说明 |
| --- | --- | --- |
| `Content-Type` | `application/json` | 请求体负载格式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域 JWT（`authUser.clientId`）。 |

### 参数

| 名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | **是** | 要删除的 `SmartReport` ObjectId。 |

### 注意事项

- 后续对 `GET /v2/smart-reports/{id}` 的调用会返回 `{ "data": null }`，而 `PUT`、`DELETE`、`/generate`、`/download`、`/html` 和 `/send-email` 会返回 `404`（`not_found`）。
- 删除 `SmartReport` 不会触发报告投递或生成类的 Webhook；有关生命周期自动化的详细信息，请参阅 [SmartReports Webhooks](/verifik-zh/resources/smart-reports-webhooks) 与 [MCP 与 AI 智能体](/verifik-zh/smart-reports/mcp-and-ai-agents)。
