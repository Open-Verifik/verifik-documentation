按 ObjectId（`{id}`）获取单个 Smart Report 模板。此接口会返回完整的模板定义，包括 `sections`、`reportTheme`、`sampleData`、页面布局设置，以及已填充的 `batchConfiguration` 与 `client` 引用。

在无头与 AI 工作流中，可在以 `append` 或 `edit` 模式调用 [生成模板布局](/verifik-zh/smart-reports/generate-template-layout) 之前使用此端点加载当前的 `sections` 数组、获取已保存的 `sampleData` 以便用于 [预览模板 HTML](/verifik-zh/smart-reports/preview-template-html)，或在执行 `PUT` 更新前检查模板内容。出于安全性和负载体积考虑，此端点会排除 `security.password` 与 `thumbnail.image` 字段。

### 端点

```
GET https://api.verifik.co/v2/smart-report-templates/{id}
```

Smart-Agent 代理（`https://ai.verifik.co`）暴露了完全相同的 `/v2/...` 路径，并同样要求携带你自己的 `Authorization: Bearer <VERIFIK_JWT>` 请求头。

### 请求头

| 名称 | 值 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 参数

| 名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | Smart Report 模板 ObjectId。 |

### 注意事项

- 当模板不存在或属于其他客户时，此端点返回 HTTP `200` 及 `{ "data": null }`，而非 `404`。
- 返回文档中不包含 `security.password` 与 `thumbnail.image`。如需渲染或查看模板缩略图，请使用 [列出报告模板](/verifik-zh/smart-reports/list-report-templates)。
