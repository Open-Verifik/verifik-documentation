在提交数据行之前，解析已保存的 `BatchConfiguration` 所需的准确输入契约。此接口会返回 `preferredReportTemplate`（若未设置，则回退至关联到该配置的最新启用中 `SmartReportTemplate`）、`webhookUrl`、`stepCount`、`estimatedCreditsPerRow`、`requiredFields`、`optionalFields`、标准的 `jsonSchema` 以及可直接发送的 `exampleInput` 载荷。

解析器会自动跳过已禁用的步骤、未启用的 `dependencyGroup` 选项、内部标志，以及已通过 `parameterDefaults` 或 `visitaFlow` 步骤链（`{{results.N.field}}`）传入的字段，同时根据 `inputFieldMapping` 重新映射列名。该路由注册在 `/{id}` 之前，因此 `/input-schema` 会直接解析；同时它也作为 `smart_report_get_input_schema` MCP 工具提供。

### 接口

```
GET https://api.verifik.co/v2/batch-configurations/{id}/input-schema
```

也可以通过 Smart-Agent 代理 `https://ai.verifik.co/v2/batch-configurations/{id}/input-schema` 访问，并使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>` 请求头。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称 | 值 |
| ---- | -- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

令牌必须是**客户 JWT**。缺少凭证或凭证无效将返回 `401 Unauthorized`。

### 参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| `id` | string | 是 | 要查看的 `BatchConfiguration` ObjectId。 |

### 注意事项

- 查看输入模式不会执行查询，也不会消耗积分。
- 如果配置上未设置 `preferredReportTemplate`，服务器将回退使用关联到 `{id}` 的最新启用中 `SmartReportTemplate`（若不存在则为 `null`）。
- 当 `inputFieldMapping` 将输入列名映射为 API 参数时，`requiredFields`、`optionalFields`、`jsonSchema` 和 `exampleInput` 将暴露映射后的输入列名，而非原始的 API 参数名。
- 不存在或跨客户的 `{id}` 会返回 `404`（`not_found`），这与返回 `200` 及 `data: null` 的[查询批处理配置](/verifik-zh/smart-reports/retrieve-a-batch-configuration)不同。
- 对于 AI 智能体和无头流水线，该接口对应于 `smart_report_get_input_schema` MCP 工具。
