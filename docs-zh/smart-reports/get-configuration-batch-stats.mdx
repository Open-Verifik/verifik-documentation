获取已认证客户账户下属于特定 `BatchConfiguration` 的所有 `SmartBatch` 记录的汇总执行统计信息。响应返回批次总数、行完成总数，以及按 `"draft"`、`"pending"`、`"processing"`、`"completed"`、`"failed"` 和 `"cancelled"` 划分的状态分布。

读取配置统计信息不会执行核验，也不会消耗积分。

### 接口

```text
GET https://api.verifik.co/v2/smart-batches/stats/{configId}
```

此接口也可通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches/stats/{configId}` 访问，需使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 参数

| 名称       | 类型   | 必填 | 描述 |
| ---------- | ------ | ---- | ---- |
| `configId` | string | 是   | 用于汇总批次统计信息的 `BatchConfiguration` ObjectId。 |

### 注意事项

- 统计信息仅限于已认证客户（JWT 中的 `clientId`）作用域。
- `pendingRows` 的计算方式为 `totalRows - completedRows - failedRows - partialRows`。
- 如需查看属于此配置的单个批次详情，可将 `batchConfiguration` 传给[列出 Smart Batch](/verifik-zh/smart-reports/list-smart-batches)。
