为 `SmartBatch` 的单行（`rowIndex`）组装结构化行报告模型。该接口会在该行已存储的步骤输出上运行 Verifik 的内置报告编排器（`colombia_vehicle`），并在传入 `score` 或 `scoreProfile` 时可选地附加 `verificationScore`。

如果批次的 `BatchConfiguration` 未匹配任何内置编排器，此接口将返回 `409 Conflict`（`no_report_composer_for_configuration`）。对于任意自定义报告模板，请改用 `POST /v2/smart-reports/run`、`GET /v2/smart-reports/{id}/html` 或 `/generate`。读取此接口不消耗积分。

### 接口

```text
GET https://api.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report
```

此接口也可通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report` 访问，需使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 路径参数

| 名称       | 类型   | 必填 | 描述 |
| ---------- | ------ | ---- | ---- |
| `id`       | string | 是   | `SmartBatch` ObjectId。 |
| `rowIndex` | number | 是   | 该行在批次内从 `0` 开始的索引。 |

### 查询参数

| 名称           | 类型              | 必填 | 描述 |
| -------------- | ----------------- | ---- | ---- |
| `score`        | boolean 或 string | 否   | 传入 `true` 或 `"1"` 以计算并在响应中包含 `verificationScore`。 |
| `scoreProfile` | string            | 否   | 评分配置方案标识符。提供 `scoreProfile` 也会同时启用 `score`。 |

```javascript
import axios from "axios";

const run = async () => {
  const batchId = "6801a2b3c4d5e6f7a8b9c0d3";
  const rowIndex = 0;

  const { data } = await axios.get(
    `https://api.verifik.co/v2/smart-batches/${batchId}/rows/${rowIndex}/report`,
    {
      params: {
        score: true,
        scoreProfile: "fleet_standard",
      },
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${process.env.VERIFIK_JWT}`,
      },
    }
  );

  console.log(data);
};

run();
```

  <TabItem value="go" label="Go">

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	rowIndex := "0"
	params := url.Values{}
	params.Set("score", "true")
	params.Set("scoreProfile", "fleet_standard")

	endpoint := fmt.Sprintf("https://api.verifik.co/v2/smart-batches/%s/rows/%s/report?%s", batchID, rowIndex, params.Encode())
	req, _ := http.NewRequest("GET", endpoint, nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}
```

### 注意事项

- 此接口仅提供内置的组合行报告（`colombia_vehicle`）。其他任何配置都会返回 `409 Conflict`（`no_report_composer_for_configuration`）。
- 对于跨任意配置的自定义模板、主题化 HTML 渲染或 PDF 档案，请使用 `POST /v2/smart-reports/run`、`GET /v2/smart-reports/{id}/html` 或 `/generate`（请参阅[运行 Smart Report](/verifik-zh/smart-reports/run-a-smart-report)）。
- 除非提供 `score=true`、`score=1` 或 `scoreProfile`，否则响应中将省略 `verificationScore`。
