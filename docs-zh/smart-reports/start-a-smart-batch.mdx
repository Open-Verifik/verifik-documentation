启动现有 `SmartBatch` 的执行。批次当前必须处于 `"draft"`、`"pending"` 或 `"cancelled"` 状态；其他任何状态都将失败并返回 `400 BadRequest`（`batch_not_in_startable_state`）。

启动前，服务器会校验关联的 `BatchConfiguration` 中每个已启用的步骤是否均已授权给你的客户账户（若缺少任何功能，将返回 `409 endpoints_not_in_account`），随后设置 `status: "processing"` 和 `startedAt`，并返回更新后的 `SmartBatch`。

### 接口

```text
POST https://api.verifik.co/v2/smart-batches/{id}/start
```

此接口也可通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches/{id}/start` 访问，需使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 参数

| 名称 | 类型   | 必填 | 描述 |
| ---- | ------ | ---- | ---- |
| `id` | string | 是   | 要启动的 `SmartBatch` ObjectId。 |

### 注意事项

- 只有处于 `"draft"`、`"pending"` 或 `"cancelled"` 状态的批次才能启动；已暂停的批次必须使用[恢复 Smart Batch](/verifik-zh/smart-reports/resume-a-smart-batch)。
- 重新启动 `"cancelled"` 状态的批次会清除 `completedAt`，并将所有 `"processing"` 状态的行重置为 `"pending"`。
- 建议事先通过[估算 Smart Batch 费用](/verifik-zh/smart-reports/estimate-smart-batch-cost)核对预计积分扣费，并通过[获取 Smart Batch 进度](/verifik-zh/smart-reports/get-smart-batch-progress)监控执行状态。
