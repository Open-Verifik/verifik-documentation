将 `SmartBatch` 上处于 `"failed"` 或 `"partial"` 状态的行重新入队执行，且不会影响已经完成的行。你可以可选地传入 `rowIndexes`，仅重试特定子集的行；若省略 `rowIndexes`，则会重试该批次中所有处于 `"failed"` 和 `"partial"` 状态的行。

如果批次当前正处于 `"processing"` 状态，请求将失败并返回 `409 Conflict`（`batch_is_processing`）。响应中返回 `retried: 0` 表示没有符合条件的失败或部分完成行匹配。

### 接口

```text
POST https://api.verifik.co/v2/smart-batches/{id}/retry-failed
```

此接口也可通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches/{id}/retry-failed` 访问，需使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 参数

| 名称 | 类型   | 必填 | 描述 |
| ---- | ------ | ---- | ---- |
| `id` | string | 是   | `SmartBatch` ObjectId。 |

### 请求体

| 名称         | 类型      | 必填 | 描述 |
| ------------ | --------- | ---- | ---- |
| `rowIndexes` | integer[] | 否   | 要重试的从 `0` 开始的行索引数组（`>= 0`，最多 `10000` 项）。若省略，则重试所有 `"failed"` 和 `"partial"` 行。 |

未知请求体键将被 Joi 校验拒绝，并返回 `409 MissingParameter`。

### 注意事项

- 发送 `{}`（或省略 `rowIndexes`）可一次性重试所有 `"failed"` 和 `"partial"` 行。
- 传入 `rowIndexes` 时，即使索引包含处于 `"completed"` 或 `"pending"` 状态的行，这些行也会被忽略。
- 若需仅重新运行单行中的特定步骤序号同时保留其他步骤结果，请使用[重试 Smart Batch 行步骤](/verifik-zh/smart-reports/retry-batch-row-steps)。
