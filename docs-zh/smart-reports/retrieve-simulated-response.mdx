获取通过 [列出模拟响应](/verifik-zh/smart-reports/list-simulated-responses) 发现的目录端点 `code` 对应的沙盒模拟响应、字段 `outline`、`dataSample` 及 `emptySample`。你可以将返回的 `sample` 状态在已填充记录（`"data"`）、空匹配（`"empty"`）或缺失数据（`"missing"`）之间切换，并通过 `listSize` 控制数组行数。

在无头模板设计与自动化 QA 工作流中，此端点可让你在将模板保存或发布到生产环境 `SmartBatch` 流水线之前，验证模板在边界情况下的渲染表现——例如空表格、缺失可选字段或多页数组（`listSize` 范围为 `2` 到 `30`）。

### 端点

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses/{code}
```

Smart-Agent 代理（`https://ai.verifik.co`）暴露了完全相同的 `/v2/...` 路径，并同样要求携带你自己的 `Authorization: Bearer <VERIFIK_JWT>` 请求头。

### 请求头

| 名称 | 值 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 参数

| 名称 | 类型 | 位置 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `code` | string | 路径 | 是 | 来自 [列出模拟响应](/verifik-zh/smart-reports/list-simulated-responses) 的目录端点代码。 |
| `availability` | string | 查询 | 否 | 放入 `sample` 中的模拟状态：`"data"`、`"empty"` 或 `"missing"`。默认为 `"data"`。 |
| `listSize` | integer | 查询 | 否 | 为数组/列表字段生成的合成条目数量。有效范围：`2` 到 `30`。 |

async function run() {

  const params = new URLSearchParams({

    listSize: "5",
  });

  const res = await fetch(
    `https://api.verifik.co/v2/smart-report-templates/simulated-responses/${code}?${params.toString()}`,
    {
      method: "GET",
      headers: {
        Accept: "application/json",
        Authorization: `Bearer ${process.env.VERIFIK_JWT}`,
      },
    }
  );

  console.log(await res.json());
}

run();

### 注意事项

- 如果 `{code}` 不在沙盒清单中，端点会返回 HTTP `200`，其中包含 `found: false`、空的 `outline` 与 `sample` 对象，以及说明性的 `note`。
- `listSize` 接受 `2` 到 `30` 之间的整数，适合通过 [下载模板示例](/verifik-zh/smart-reports/download-template-sample) 测试多页 PDF 分页效果。
- 此端点不会执行实时核验，也不会消耗积分。
