删除已认证客户拥有的 `SmartBatch`。如果该批次存在且属于你的客户账户，服务器会将其删除并在 `data` 中返回被移除的 `SmartBatch` 文档。

如果批次 ID 不存在或属于另一个客户，接口将返回 `404`（`not_found`）。删除批次不会退还此前已消耗的积分。

### 接口

```text
DELETE https://api.verifik.co/v2/smart-batches/{id}
```

此接口也可通过 Smart-Agent 代理 `https://ai.verifik.co/v2/smart-batches/{id}` 访问，需使用你自己的客户专属 `Authorization: Bearer <VERIFIK_JWT>`。共享 x402 执行会被拒绝并返回 `403 Forbidden`。

### 请求头

| 名称            | 值                     | 描述                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 请求载荷格式。                           |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 客户作用域的 JWT（`authUser.clientId`）。 |

### 参数

| 名称 | 类型   | 必填 | 描述 |
| ---- | ------ | ---- | ---- |
| `id` | string | 是   | 要删除的 `SmartBatch` ObjectId。 |

package main

### 注意事项

- 若要停止运行中的批次同时保留其历史行与输出结果，请使用[取消 Smart Batch](/verifik-zh/smart-reports/cancel-a-smart-batch)，而非直接删除。
- 属于其他客户账户的批次将返回 `404`（`not_found`）。
