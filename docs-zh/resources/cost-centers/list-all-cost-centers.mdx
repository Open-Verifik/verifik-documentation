### 接口

**GET** `https://api.verifik.co/v2/cost-centers`

返回账户上的成本中心，先按国家、再按名称排序。

#### 请求头

| 名称          | 值                 |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### 查询参数

#### `active`

**类型:** boolean  
**必填:** 否

`true` 只返回启用的，`false` 只返回停用的。省略则两者都返回。

#### `country`

**类型:** string  
**必填:** 否

ISO-2 国家代码，例如 `ES`。

#### `page`

**类型:** number  
**必填:** 否

页码，从 1 开始。

#### `limit`

**类型:** number  
**必填:** 否

每页条数。默认 50，最多 100。

### 请求示例

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl "https://api.verifik.co/v2/cost-centers?active=true&country=ES&page=1&limit=50" \
  -H "Authorization: Bearer $VERIFIK_TOKEN"
```

</TabItem>

## 错误响应

无效的查询，例如 `limit` 大于 100，或 `country` 不是两个字母：

```json
{
  "message": "\"limit\" must be less than or equal to 100",
  "code": "MissingParameter"
}
```
