# 列出成本中心

```
GET https://api.verifik.co/v2/cost-centers
```

| 名称      | 类型    | 必填 | 说明                                      |
| --------- | ------- | ---- | ----------------------------------------- |
| `active`  | boolean | 否   | `true` 仅启用，`false` 仅停用。           |
| `country` | string  | 否   | ISO-2 国家代码。                          |
| `page`    | number  | 否   | 页码，从 1 开始。                         |
| `limit`   | number  | 否   | 每页条数。默认 50，最多 100。             |

```json
{
	"data": [
		{
			"_id": "6acfbdda92451bac5d0a7ebe",
			"name": "西班牙运营",
			"code": "SPAIN-OPS",
			"country": "ES",
			"active": true
		}
	],
	"total": 1,
	"page": 1,
	"pages": 1,
	"limit": 50
}
```
