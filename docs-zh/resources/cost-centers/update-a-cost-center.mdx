### 接口

**PUT** `https://api.verifik.co/v2/cost-centers/{id}`

更新一个成本中心。只发送要更改的字段。已经记录的请求仍保留当时的成本中心。

#### 请求头

| 名称          | 值                 |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### 路径参数

#### `id`

**类型:** string  
**必填:** 是

成本中心 id。

#### 请求体参数

#### `name`

**类型:** string  
**必填:** 否

显示名称，最多 120 个字符。

#### `code`

**类型:** string  
**必填:** 否

新的请求头值。字母、数字、`.`、`-` 和 `_`，最多 60 个字符。每个账户唯一。

#### `country`

**类型:** string  
**必填:** 否

ISO-2 国家代码。

#### `active`

**类型:** boolean  
**必填:** 否

`true` 重新启用，`false` 则不再分配给新请求。

### 请求示例

## 错误响应

未知 id：

```json
{
  "message": "cost_center_not_found",
  "code": "NotFound"
}
```

账户上另一个中心已经使用的 `code`：

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```
