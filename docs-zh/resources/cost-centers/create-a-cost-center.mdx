### 接口

**POST** `https://api.verifik.co/v2/cost-centers`

在账户上创建一个成本中心。管理成本中心不消耗积分。

#### 请求头

| 名称          | 值                 |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### 请求体参数

#### `name`

**类型:** string  
**必填:** 是

显示名称，最多 120 个字符。

#### `code`

**类型:** string  
**必填:** 是

将在 `x-cost-center` 中发送的值。字母、数字、`.`、`-` 和 `_`，最多 60 个字符。每个账户唯一。

#### `country`

**类型:** string  
**必填:** 是

ISO-2 国家代码，例如 `ES`。

#### `active`

**类型:** boolean  
**必填:** 否

默认为 `true`。

### 请求示例

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash

  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"西班牙运营","code":"SPAIN-OPS","country":"ES"}'
```

</TabItem>

## 错误响应

账户上已存在的代码：

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```

缺少或无效的字段，例如 `name`、`code` 或 `country`：

```json
{
  "message": "\"name\" is required",
  "code": "MissingParameter"
}
```
