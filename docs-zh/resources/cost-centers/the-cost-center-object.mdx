# 成本中心对象

```json
{
	"_id": "6acfbdda92451bac5d0a7ebe",
	"client": "69c2b824295cd7d276e478ad",
	"name": "西班牙运营",
	"code": "SPAIN-OPS",
	"country": "ES",
	"active": true,
	"createdAt": "2026-10-14T17:37:30.469Z",
	"updatedAt": "2026-10-14T17:37:30.469Z"
}
```

| 字段      | 类型    | 说明                                                                                 |
| --------- | ------- | ------------------------------------------------------------------------------------ |
| `name`    | string  | 显示名称，最多 120 个字符。                                                          |
| `code`    | string  | 在 `x-cost-center` 中发送的值。字母、数字、`.`、`-` 和 `_`，最多 60 个字符。每个账户唯一。 |
| `country` | string  | 该成本中心通常服务的 ISO-2 国家。                                                    |
| `active`  | boolean | 停用的中心保留历史，但不能再分配给新请求。                                           |
