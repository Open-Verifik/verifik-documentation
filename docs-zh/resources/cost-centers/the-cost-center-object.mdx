### 概述

成本中心对象是 Verifik 为一个团队、国家或业务单元保存的记录。请求通过 `_id` 引用它。`code` 通过 `x-cost-center` 请求头发送。

```json
{
  "_id": "6acfbdda92451bac5d0a7ebe",
  "client": "69c2b824295cd7d276e478ad",
  "name": "西班牙运营",
  "code": "SPAIN-OPS",
  "country": "ES",
  "active": true,
  "createdAt": "2026-10-14T17:37:30.469Z",
  "updatedAt": "2026-10-14T17:37:30.469Z"
}
```

### 属性

#### `_id`

**类型:** string  
**必填:** 是

唯一标识。用于查询、更新、停用，以及设置项目默认值。

#### `client`

**类型:** string  
**必填:** 是

拥有该成本中心的账户。

#### `name`

**类型:** string  
**必填:** 是

显示名称，最多 120 个字符。

#### `code`

**类型:** string  
**必填:** 是

在 `x-cost-center` 中发送的值。字母、数字、`.`、`-` 和 `_`，最多 60 个字符。每个账户唯一。

#### `country`

**类型:** string  
**必填:** 是

该中心通常服务的 ISO-2 国家，以大写保存。

#### `active`

**类型:** boolean  
**必填:** 是

停用的中心保留历史，但不能再分配给新请求。默认为 `true`。

#### `createdAt`

**类型:** string  
**必填:** 是

创建时间，ISO-8601。

#### `updatedAt`

**类型:** string  
**必填:** 是

最后更改时间，ISO-8601。
