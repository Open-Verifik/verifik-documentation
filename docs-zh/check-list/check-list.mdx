# Check List

你在一个或多个国家运营，却总在重复挑选同一批 SmartCheck 服务。**把这套组合存成 Check List。** 可以从列表里试跑一项，或发给 SmartBatch。

在 Smart-Agent 打开 **Check List**：[ai.verifik.co/check-list](https://ai.verifik.co/check-list)。保存列表不收费。执行查询会像其他 API 一样消耗积分。

## 在 Smart-Agent 中

使用 Verifik 客户账号登录。Check List 把列表存在该账号上，而不是 SmartEnroll 项目上。

### 1. 你的列表

仪表盘显示列表数量、覆盖国家和已保存服务数。打开卡片进行编辑，或新建列表。

<img src="/img/check-list/dashboard.png" alt="带统计和已保存列表的 Check List 仪表盘" />

还没有列表时，先从一个国家开始。

:::tip
创建后会回到此仪表盘。打开新卡片再添加服务。
:::

---

### 2. 创建清单

选择一个或多个国家，然后命名（例如 **KYC Colombia** 或 **Fleet Chile**）。

<img src="/img/check-list/create.png" alt="用国家和名称创建清单" />

国家在创建时确定。之后不能在工作区里改。

---

### 3. 添加服务

打开列表。已保存的服务在上方。下方搜索目录，并按 **人员**、**车辆**、**企业** 筛选。国际背景调查在最底部。

<img src="/img/check-list/workspace.png" alt="带已保存服务和目录的 Check List 工作区" />

用 **选择** 添加，用 **打开** 试跑。草稿 / 启用只是整理标签，行为相同。

---

### 4. 试跑查询

打开服务。抽屉有 **关于**、**请求**、**结果**。填好必填项后点击 **执行**。

<img src="/img/check-list/run-check.png" alt="执行查询抽屉" />

结果与该目录 API 的响应相同。调用后积分余额会更新。

---

### 5. 发送到 SmartBatch

要用文件或队列跑同一批服务时，点击 **创建 SmartBatch**。SmartBatch 只用 **一个国家**。列表有多个国家时，先选从哪个开始。

<img src="/img/check-list/smartbatch-handoff.png" alt="创建 SmartBatch 前选择国家" />

SmartBatch 会带上该国家、列表名称和所选服务。在 [SmartBatch](/verifik-zh/smart-batch) 向导中继续。

---

## Check List 不是什么

| 不要当成 | 实际情况 |
| --- | --- |
| 批处理引擎 | Check List **保存**组合。[SmartBatch](/verifik-zh/smart-batch) 才跑文件或队列。 |
| 托管 KYC | SmartEnroll 是另一套 enrollment 产品。 |
| 每次试跑都是新注册 | 执行调用的是该服务已有的目录 API。 |
