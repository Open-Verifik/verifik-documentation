# Scan Agent

**Scan Agent** 从证件图像提取结构化字段。调用 **POST** `https://api.verifik.co/v2/ocr/scan-gpt`。`image` 必填。`documentType`、`backImage` 和 `template` 可选。此正文没有 `country` 字段。保存的提取把 `validationMethod` 设为 `SCAN_AGENT`。

## 调用返回的内容

- 提取出的 `documentType`、`documentNumber` 和姓名
- `validationMethod` — `SCAN_AGENT`

## 使用场景

- 从一张图像读取身份证件。
- 证件有背面时附上背面图像。
- 版式已知时固定模板。

## API 参考

### Endpoint

```http
POST https://api.verifik.co/v2/ocr/scan-gpt
```

命中含提取出的证件字段和 `validationMethod` `SCAN_AGENT`。URL 仍是 `/v2/ocr/scan-gpt`。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `image` | string | **是** | `data:image/jpeg;base64,AAAA` | 正面图像的 base64 或 data URI。必填。 |
| `documentType` | string | 否 | `CC` | 可选证件类型，例如 `CC` 或 `DNI`。 |
| `backImage` | string | 否 | `data:image/jpeg;base64,BBBB` | 可选背面图像。 |
| `template` | string | 否 | `template_id` | 可选模板 id。 |

### 说明

- `image` 必填。`documentType`、`backImage` 和 `template` 可选。
- 不要发送国家字段。此正文不接受它。
- 记录的方法是 `SCAN_AGENT`，URL 仍是 `/v2/ocr/scan-gpt`。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `image` plus `documentType: "CC"` | 含提取字段和 validationMethod SCAN_AGENT 的 200。 |
| 缺少必填值 | Omit `image` | 409 MissingParameter。 |
| 未知的值 | `image` and `backImage` | 同时发送背面图像时为 200。 |

401 when the bearer token is missing or rejected.
