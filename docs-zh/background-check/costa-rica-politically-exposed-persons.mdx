# 哥斯达黎加 — 政治公众人物（PEP）筛查

在 **哥斯达黎加** 用 **公民身份证号**（`documentNumber`）或 **法定全名**（`fullName`）对照官方政治公众人物（PEP）名册筛查。筛查遵循 **FATF 建议 12** 以及下列本国反洗钱框架，并对已结束的公职保留 **5 年回溯窗口**。

- **依据：** Ley N° 7786 / Ley N° 8422 contra la Corrupción y el Enriquecimiento Ilícito en la Función Pública
- **主管机关：** Contraloría General de la República (CGR) / ICD Costa Rica
- **主要来源：** Contraloría General de la República (CGR) Declaraciones Juradas / Asamblea Legislativa (CR)（`https://cgrweb.cgr.go.cr/apex/f?p=152200`）

- 本国 PEP 的客户开户与强化尽职调查。
- 任期开始、变更或结束时的定期复筛。
- 尚未取得本国证件号码时按姓名检索。

## API 参考

### 端点

```http
GET https://api.verifik.co/v2/cr/politically-exposed-persons
```

成功调用返回 `country`、`jurisdiction`、`documentType`、`documentNumber`、`fullName`、`isPEP`、`isActivePep`、`isFormerPep`、`totalMatches`、`matchCount`、`categories`、`includeFormer`、`lookbackYears`（5）、`matches`、`checkedSources`、`regulation` 和 `dateTime`。每条匹配包含 `position`、`entity`、`category`、`categoryDescription`、`status`（`ACTIVE` 或 `FORMER_PEP`）、`source` 和 `sourceUrl`。根对象上的判定字段是 `isPEP`。每条匹配使用 `isPep`。不是 PEP 时同样返回 HTTP 200，`isPEP` 为 false，`totalMatches` 为 0。

### 请求头

| 名称 | 值 |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <your_token>` |

### 参数

| 名称 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | 条件 | 公民身份证号。3 到 40 个字符。省略 `fullName` 时必填。别名：`id`、`dni`、`cedula`。示例：`CR-105600981`。 |
| `fullName` | string | 条件 | 法定全名，3 到 160 个字符。省略 `documentNumber` 时必填。别名：`name`。示例：`RODRIGO ALBERTO CHAVES ROBLES`。 |
| `documentType` | string | 否 | 证件类型，2 到 20 个字符。默认值为 `CEDULA`，并在响应中原样返回。 |
| `includeFormer` | boolean | 否 | 包含在 5 年回溯窗口内结束任期的公职人员。默认值为 `true`。传入 `false` 时只保留 `ACTIVE` 职务。若只命中前公职人员，则 `isPEP` 为 false，`matches` 为空数组。 |

---

## PEP 分类

每条匹配会根据职务名称归入下列分类之一：

| 分类 | 说明 |
| :--- | :--- |
| `HEAD_OF_STATE_OR_GOVERNMENT` | 国家元首、政府首脑或内阁行政当局 |
| `SENIOR_EXECUTIVE` | 行政部门高级官员或内阁部长 |
| `LEGISLATIVE` | 国家议会或立法机关成员 |
| `JUDICIAL_OR_OVERSIGHT` | 高级司法、宪法或最高审计监督机构 |
| `DIPLOMATIC_MILITARY_OR_CENTRAL_BANK` | 高级外交、军事或中央银行官员 |
| `PUBLIC_OFFICIAL_PEP` | 符合 FATF 建议 12 的政治公众人物 |

## 沙盒探测

账户处于沙盒模式时，下列取值是确定的：

| 证件号码 | 全名 | includeFormer | 结果 |
| :--- | :--- | :--- | :--- |
| `CR-105600981` | `RODRIGO ALBERTO CHAVES ROBLES` | `true` | 在任 PEP（`isPEP` 为 true，分类 `HEAD_OF_STATE_OR_GOVERNMENT`） |
| `10000001` | `RODRIGO ALBERTO CHAVES ROBLES` | `true` | 在任 PEP（与证件 `10000001` 相同的夹具） |
| `10000002` | `PEP FORMER MINISTER` | `true` | `includeFormer` 为 true 时的前 PEP（`isFormerPep` 为 true） |
| `10000002` | `PEP FORMER MINISTER` | `false` | `includeFormer` 为 false 时的未命中 |
| `55555555` | `JUAN CARLOS CIUDADANO NO PEP` | `true` | 非 PEP（`isPEP` 为 false，`totalMatches` 为 0） |
| `99999404` | `—` | `true` | 404 `NotFound`（仅沙盒探测） |

### 备注

- 发送 `documentNumber` 或 `fullName`。证件别名是 `id`、`dni` 和 `cedula`。姓名别名是 `name`。若都没有，API 返回 409 `MissingParameter`，消息为 `Either documentNumber or fullName must be provided.`
- `includeFormer` 默认为 true。5 年窗口内的前公职人员返回 `status` `FORMER_PEP`、`isFormerPep` true 和 `isPEP` true。`false` 会去掉这些记录，只保留在任职务。
- `documentType` 默认为 `CEDULA`。响应中的 `jurisdiction` 是名册标签 `Costa Rica`。`regulation.lookbackYears` 为 5。
- 沙盒在任命中：证件 `CR-105600981` 或姓名 `RODRIGO ALBERTO CHAVES ROBLES`，以及证件 `10000001`。前公职：证件 `10000002`，或姓名包含 `PEP FORMER`、`EX MINISTRO` 或 `FORMER MINISTER`。未命中：证件 `55555555` 与姓名 `JUAN CARLOS CIUDADANO NO PEP`。证件号码包含 `99999404`，或姓名包含 `NOTFOUND`，在沙盒中返回 404。生产环境未命中是 HTTP 200 且 `isPEP` 为 false，不是 404。
- 此路径只筛查哥斯达黎加（`CR`）。跨境搜索请使用[全球 PEP](/verifik-zh/background-check/world-politically-exposed-persons)。
- `checkedSources` 列出本次法域查阅的名册键。`regulation.framework` 和 `regulation.authority` 标明随结果返回的反洗钱依据。
