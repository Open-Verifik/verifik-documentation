# 哥伦比亚 — PEP 政党官员

筛查哥伦比亚政党官员。

## 调用返回的内容

- `isPEP`
- `matches`
- `fullName` 与 `documentNumber`
- 单纯未命中时 `matches` 为空

## 使用场景

- 准入前对照哥伦比亚 PEP 名录。
- 把未列入的人存为 HTTP 200。
- 按姓名或证件号检索。

---

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/co/pep/partidos-politicos
```

命中时 `isPEP` 为 true。只是不在本名录中是 HTTP 200，`isPEP` 为 false，`matches` 为空。不是 404。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **条件必填** | `MARIA LOPEZ` | 只发姓名即可。名录有这些字段时也接受 `partyName`、`entityName` 或 `country`。 |
| `documentNumber` | string | **条件必填** | `80123456` | 标识 4 到 30 个字符。 |
| `documentType` | string | 否 | `CC` | 可选：`CC`、`NIT`、`CE`、`PAS`、`TI`、`CD`。 |

### 说明

- 单纯未命中是 HTTP 200，且 `isPEP` 为 false。
- 至少发送一个检索值。
- 不要把这个 200 映射成 404。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `fullName: "MARIA LOPEZ"` | 命中时 isPEP 为 true 的 200。 |
| 缺少必填值 | Omit every search value | 没有检索值时为 409。 |
| 未知的值 | `fullName: "CLEAN NAME"` | isPEP 为 false 的 200。单纯未命中不是 404。 |

401 when the bearer token is missing or rejected.
