# 吉尔吉斯斯坦国家名单

查询个人或组织是否列入**吉尔吉斯斯坦国家名单**。吉尔吉斯斯坦国家金融情报局发布该名单，用于吉尔吉斯斯坦。

吉尔吉斯斯坦金融情报机关公布这份被指定人员与实体的国家制裁名单。

可发送 `fullName`、`documentNumber` 或两者。至少提供其中一项。查询与已发布记录匹配时，`foundInKyrgyzstanSfisSanctions` 为 `true`，否则为 `false`。命中时 `details` 包含列入姓名、实体类型、机制或项目、措施、国家、识别号和备注。可将结果用于 KYC、反洗钱/反恐怖融资、供应商准入和付款筛查。在采信之前复核每一条命中。本次调用不替代官方名单，也不是法律认定。

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/kyrgyzstan-sfis-sanctions
```

成功响应包含 `data.fullName`、来源记录拆分姓名时的 `data.firstName` 与 `data.lastName`、请求中附带时的 `data.documentNumber`、`data.foundInKyrgyzstanSfisSanctions` 以及 `data.details`。命中时，`details` 包含列入姓名、实体类型、机制或项目、措施、国家、识别号和备注。`signature` 对象包含 `dateTime` 以及消息 `Certified by Verifik.co`。当 `foundInKyrgyzstanSfisSanctions` 为 `false` 时，`details` 为空对象。

### Headers

| 名称            | 值                  | 说明          |
| ------------- | ------------------ | ----------- |
| Content-Type  | `application/json` | 请求格式        |
| Accept        | `application/json` | 响应格式        |
| Authorization | `Bearer <token>`   | Verifik JWT |

### Parameters

| 参数               | 类型     | 是否必填 | 示例                       | 说明                                        |
| ---------------- | ------ | ---- | ------------------------ | ----------------------------------------- |
| `fullName`       | string | 条件必填 | `SAMPLE DESIGNATED NAME` | 个人的法定姓名或组织的注册名称。未发送 `documentNumber` 时必填。 |
| `documentNumber` | string | 条件必填 | `A1234567`               | 不含空格的身份证件号码或机构注册号。未发送 `fullName` 时必填。     |

### 使用场景

- **制裁筛查：** 在准入或放行付款之前核查客户、交易对手和受益人。
- **反洗钱/反恐怖融资复核：** 记录针对该司法辖区已公布措施的筛查。
- **审计留痕：** 将经认证的响应保存在案件档案中。

### Notes

- 请发送 `fullName` 或 `documentNumber`。至少提供一项。若两者都缺失，API 返回 HTTP 409，代码为 `MissingParameter`，消息为 `Either fullName or documentNumber must be provided`。
- `foundInKyrgyzstanSfisSanctions` 在查询命中本名单记录时为 `true`，未命中时为 `false`。未命中时 `details` 为空对象。
- 命中示例展示响应结构。实际命中会返回该记录在本名单上公布的属性。
- 命中是供合规复核的筛查结果。它不是法律认定，也不替代官方来源。
- 请在 `Authorization` 头中使用 Bearer JWT 进行认证。
- 结果反映调用当时的名单。需要更新结果时，请重新发起请求。
