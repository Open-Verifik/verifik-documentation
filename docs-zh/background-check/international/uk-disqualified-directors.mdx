# 英国公司注册处被取消资格的董事

查询个人或组织是否列入**英国公司注册处被取消资格的董事**。公司注册处（Companies House）发布该名单，用于英国。

公司注册处公布被取消在英国担任董事资格的董事；登记册载明期间时，也包括该取消资格期间。

可发送 `fullName`、`documentNumber` 或两者。至少提供其中一项。查询与已发布记录匹配时，`foundInUkDisqualifiedDirectors` 为 `true`，否则为 `false`。命中时 `details` 包含人员姓名、主管机关、取消资格状态和相关日期。可将结果用于 KYC、反洗钱/反恐怖融资、供应商准入和付款筛查。在采信之前复核每一条命中。本次调用不替代官方名单，也不是法律认定。

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/uk-disqualified-directors
```

成功响应包含 `data.fullName`、来源记录拆分姓名时的 `data.firstName` 与 `data.lastName`、请求中附带时的 `data.documentNumber`、`data.foundInUkDisqualifiedDirectors` 以及 `data.details`。命中时，`details` 包含人员姓名、主管机关、取消资格状态和相关日期。`signature` 对象包含 `dateTime` 以及消息 `Certified by Verifik.co`。当 `foundInUkDisqualifiedDirectors` 为 `false` 时，`details` 为空对象。

### Headers

| 名称            | 值                  | 说明          |
| ------------- | ------------------ | ----------- |
| Content-Type  | `application/json` | 请求格式        |
| Accept        | `application/json` | 响应格式        |
| Authorization | `Bearer <token>`   | Verifik JWT |

### Parameters

| 参数               | 类型     | 是否必填 | 示例                       | 说明                                        |
| ---------------- | ------ | ---- | ------------------------ | ----------------------------------------- |
| `fullName`       | string | 条件必填 | `SAMPLE DESIGNATED NAME` | 个人的法定姓名或组织的注册名称。未发送 `documentNumber` 时必填。 |
| `documentNumber` | string | 条件必填 | `A1234567`               | 不含空格的身份证件号码或机构注册号。未发送 `fullName` 时必填。     |

### 使用场景

- **董事筛查：** 对照该取消资格登记册核查董事或高级管理人员。
- **公司准入：** 在董事会任命或设立公司之前使用该结果。
- **记录：** 将经认证的响应保存在公司档案中。

### Notes

- 请发送 `fullName` 或 `documentNumber`。至少提供一项。若两者都缺失，API 返回 HTTP 409，代码为 `MissingParameter`，消息为 `Either fullName or documentNumber must be provided`。
- `foundInUkDisqualifiedDirectors` 在查询命中本名单记录时为 `true`，未命中时为 `false`。未命中时 `details` 为空对象。
- 命中示例展示响应结构。实际命中会返回该记录在本名单上公布的属性。
- 命中是供合规复核的筛查结果。它不是法律认定，也不替代官方来源。
- 请在 `Authorization` 头中使用 Bearer JWT 进行认证。
- 结果反映调用当时的名单。需要更新结果时，请重新发起请求。
