# 瑞士FINMA警示名单

查询个人或组织是否列入**瑞士FINMA警示名单**。瑞士金融市场监督管理局（FINMA）发布该名单，用于瑞士。

FINMA警示名单列入可能在瑞士未经授权提供金融服务的人员与公司。

可发送 `fullName`、`documentNumber` 或两者。至少提供其中一项。查询与已发布记录匹配时，`foundInSwitzerlandFinmaWarning` 为 `true`，否则为 `false`。命中时 `details` 包含被点名的当事人、发出警示的机关、警示日期以及所描述的活动。可将结果用于 KYC、反洗钱/反恐怖融资、供应商准入和付款筛查。在采信之前复核每一条命中。本次调用不替代官方名单，也不是法律认定。

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/switzerland-finma-warning
```

成功响应包含 `data.fullName`、来源记录拆分姓名时的 `data.firstName` 与 `data.lastName`、请求中附带时的 `data.documentNumber`、`data.foundInSwitzerlandFinmaWarning` 以及 `data.details`。命中时，`details` 包含被点名的当事人、发出警示的机关、警示日期以及所描述的活动。`signature` 对象包含 `dateTime` 以及消息 `Certified by Verifik.co`。当 `foundInSwitzerlandFinmaWarning` 为 `false` 时，`details` 为空对象。

### Headers

| 名称            | 值                  | 说明          |
| ------------- | ------------------ | ----------- |
| Content-Type  | `application/json` | 请求格式        |
| Accept        | `application/json` | 响应格式        |
| Authorization | `Bearer <token>`   | Verifik JWT |

### Parameters

| 参数               | 类型     | 是否必填 | 示例                       | 说明                                        |
| ---------------- | ------ | ---- | ------------------------ | ----------------------------------------- |
| `fullName`       | string | 条件必填 | `SAMPLE DESIGNATED NAME` | 个人的法定姓名或组织的注册名称。未发送 `documentNumber` 时必填。 |
| `documentNumber` | string | 条件必填 | `A1234567`               | 不含空格的身份证件号码或机构注册号。未发送 `fullName` 时必填。     |

### 使用场景

- **消费者保护筛查：** 在客户汇出资金之前，核查公司是否出现在该公开警示名单上。
- **欺诈防范：** 在准入金融中介时复核未经授权活动的警示。
- **记录：** 将经认证的响应保存在准入档案中。

### Notes

- 请发送 `fullName` 或 `documentNumber`。至少提供一项。若两者都缺失，API 返回 HTTP 409，代码为 `MissingParameter`，消息为 `Either fullName or documentNumber must be provided`。
- `foundInSwitzerlandFinmaWarning` 在查询命中本名单记录时为 `true`，未命中时为 `false`。未命中时 `details` 为空对象。
- 命中示例展示响应结构。实际命中会返回该记录在本名单上公布的属性。
- 命中是供合规复核的筛查结果。它不是法律认定，也不替代官方来源。
- 请在 `Authorization` 头中使用 Bearer JWT 进行认证。
- 结果反映调用当时的名单。需要更新结果时，请重新发起请求。
