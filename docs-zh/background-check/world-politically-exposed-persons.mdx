# 全球 — 政治公众人物（PEP）筛查

通过**护照或其他证件号码**（`documentNumber`）或**法定全名**（`fullName`）调用 `GET /v2/world/pep`，在多个法域筛查。同一处理程序也响应 `GET /v2/world/politically-exposed-persons`。筛查遵循 **FATF 建议 12** 中对本国与外国政治公众人物的要求，并在公职结束后保留 **5 年回溯窗口**。

- **依据：** FATF / GAFI Recommendation 12 (Politically Exposed Persons — Foreign & Domestic PEPs)
- **主管机关：** Financial Action Task Force (FATF / GAFI) / OpenSanctions Global PEP Registry
- **主要来源：** OpenSanctions Global Politically Exposed Persons (PEPs) Consolidated Dataset & Wikidata Officeholders（`https://data.opensanctions.org/datasets/latest/peps/targets.simple.csv`）

- 对象所在国家没有单一国家 PEP 端点时的跨境开户。
- 可选参数 `country`（ISO 3166-1 alpha-2）把全球名册限定到一个法域。
- 对外国 PEP 做强化尽职调查和定期复筛。

---

## API 参考

### 端点

```http
GET https://api.verifik.co/v2/world/pep
```

成功调用返回 `country`、`jurisdiction`、`documentType`、`documentNumber`、`fullName`、`isPEP`、`isActivePep`、`isFormerPep`、`totalMatches`、`matchCount`、`categories`、`includeFormer`、`lookbackYears`（5）、`matches`、`checkedSources`、`regulation` 和 `dateTime`。每条匹配包含 `position`、`entity`、`category`、`categoryDescription`、`status`（`ACTIVE` 或 `FORMER_PEP`）、`source` 和 `sourceUrl`。根对象上的判定字段是 `isPEP`。每条匹配使用 `isPep`。不是 PEP 时同样返回 HTTP 200，`isPEP` 为 false，`totalMatches` 为 0。

### 请求头

| 名称 | 值 |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <your_token>` |

### 参数

| 名称 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | 条件 | 护照号码。3 到 40 个字符。省略 `fullName` 时必填。别名：`id`、`dni`、`cedula`。示例：`WORLD-PEP-Q22686`。 |
| `fullName` | string | 条件 | 法定全名，3 到 160 个字符。省略 `documentNumber` 时必填。别名：`name`。示例：`URSULA GERTRUD VON DER LEYEN`。 |
| `documentType` | string | 否 | 证件类型，2 到 20 个字符。默认值为 `PASSPORT`，并在响应中原样返回。 |
| `includeFormer` | boolean | 否 | 包含在 5 年回溯窗口内结束任期的公职人员。默认值为 `true`。传入 `false` 时只保留 `ACTIVE` 职务。若只命中前公职人员，则 `isPEP` 为 false，`matches` 为空数组。 |
| `country` | string | 否 | 可选的 ISO 3166-1 alpha-2 国家代码，2 到 10 个字符（例如 `PL`）。省略则搜索合并的全球名册。 |

---

## PEP 分类

每条匹配会根据职务名称归入下列分类之一：

| 分类 | 说明 |
| :--- | :--- |
| `HEAD_OF_STATE_OR_GOVERNMENT` | 国家元首、政府首脑或内阁行政当局 |
| `SENIOR_EXECUTIVE` | 行政部门高级官员或内阁部长 |
| `LEGISLATIVE` | 国家议会或立法机关成员 |
| `JUDICIAL_OR_OVERSIGHT` | 高级司法、宪法或最高审计监督机构 |
| `DIPLOMATIC_MILITARY_OR_CENTRAL_BANK` | 高级外交、军事或中央银行官员 |
| `PUBLIC_OFFICIAL_PEP` | 符合 FATF 建议 12 的政治公众人物 |

## 沙盒探测

账户处于沙盒模式时，下列取值是确定的：

| 证件号码 | 全名 | includeFormer | 结果 |
| :--- | :--- | :--- | :--- |
| `WORLD-PEP-Q22686` | `URSULA GERTRUD VON DER LEYEN` | `true` | 在任 PEP（`isPEP` 为 true，分类 `HEAD_OF_STATE_OR_GOVERNMENT`） |
| `10000001` | `URSULA GERTRUD VON DER LEYEN` | `true` | 在任 PEP（与证件 `10000001` 相同的夹具） |
| `10000002` | `PEP FORMER MINISTER` | `true` | `includeFormer` 为 true 时的前 PEP（`isFormerPep` 为 true） |
| `10000002` | `PEP FORMER MINISTER` | `false` | `includeFormer` 为 false 时的未命中 |
| `55555555` | `JUAN CARLOS CIUDADANO NO PEP` | `true` | 非 PEP（`isPEP` 为 false，`totalMatches` 为 0） |
| `99999404` | `—` | `true` | 404 `NotFound`（仅沙盒探测） |

### 备注

- 发送 `documentNumber` 或 `fullName`。证件别名是 `id`、`dni` 和 `cedula`。姓名别名是 `name`。若都没有，API 返回 409 `MissingParameter`，消息为 `Either documentNumber or fullName must be provided.`
- `includeFormer` 默认为 true。5 年窗口内的前公职人员返回 `status` `FORMER_PEP`、`isFormerPep` true 和 `isPEP` true。`false` 会去掉这些记录，只保留在任职务。
- `documentType` 默认为 `PASSPORT`。响应中的 `jurisdiction` 是名册标签 `Otros países (Global PEP)`。`regulation.lookbackYears` 为 5。
- 沙盒在任命中：证件 `WORLD-PEP-Q22686` 或姓名 `URSULA GERTRUD VON DER LEYEN`，以及证件 `10000001`。前公职：证件 `10000002`，或姓名包含 `PEP FORMER`、`EX MINISTRO` 或 `FORMER MINISTER`。未命中：证件 `55555555` 与姓名 `JUAN CARLOS CIUDADANO NO PEP`。证件号码包含 `99999404`，或姓名包含 `NOTFOUND`，在沙盒中返回 404。生产环境未命中是 HTTP 200 且 `isPEP` 为 false，不是 404。
- 国家级端点使用 `/v2/`、ISO 代码和 `/politically-exposed-persons`。此全球路径不替代那些页面。只有在需要收窄这次全球搜索时才发送 `country`。
- `checkedSources` 列出本次法域查阅的名册键。`regulation.framework` 和 `regulation.authority` 标明随结果返回的反洗钱依据。
