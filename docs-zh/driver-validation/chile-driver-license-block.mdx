# 🇨🇱 智利 — 驾驶证冻结与暂停记录

通过 RUN 查询智利民事登记与身份服务局（**Servicio de Registro Civil e Identificación**）的全国驾驶证冻结登记系统。

与仅覆盖单一市镇的市政门户不同，本端点提供智利法院及行政主管机关下达的驾驶证冻结与吊销决定的**全国覆盖数据**。

### 端点

```
GET https://api.verifik.co/v2/cl/driver-license/block
```

### 请求头（Headers）

| 名称          | 取值               |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### 参数（Parameters）

| 名称 | 类型 | 必填 | 描述 | 示例 |
| --- | ---- | ---- | ---- | ---- |
| `documentNumber` | string | **是** | 包含校验位（DV）的智利 RUN 号。点号和连字符可选（如 `18.347.440-5` 或 `18347440-5`）。校验位必须符合 Modulo 11 算法。 | `18347440-5` |
| `force` | boolean | 否 | 可选布尔值或 `1`/`true`，用于绕过服务端缓存直接查询官方数据源。 | `false` |

## 特性

- **全国统一登记**: 官方数据直接来源于智利 Servicio de Registro Civil e Identificación。
- **即时冻结状态**: 通过 `hasBlock: true/false` 快速确认驾照有效性。
- **持有人实名校验**: 返回驾驶资质关联的正式法定全名。
- **冻结详细元数据**: 包含法院命令日期、冻结类型及具体法定事由。
- **Modulo 11 校验保护**: 前置校验位识别，杜绝因输入失误而扣减服务额度。
