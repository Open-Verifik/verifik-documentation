# 厄瓜多尔 — 按车牌查车辆（v3）

**厄瓜多尔车辆 v3** 查询是 `GET /v3/ec/vehiculo/placa`。`plate` 必填。正文包含识别字段（`vin`、`brand`、`model`、`year`、`color` 及车牌数据）、带检验日期的 `revision`，以及含发动机、性能和尺寸的 `technicalSheet`。

## 调用返回的内容

- 识别：`vin`、`brand`、`model`、`year`、`color`
- 含检验的 `revision`
- `technicalSheet.engine`、`performance` 与 `dimensions`

## 使用场景

- 投保前确认车辆。
- 读取最近检验年份。
- 把 VIN 和车牌一起保存。

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v3/ec/vehiculo/placa
```

预期有 `plate`、识别字段、`revision` 和 `technicalSheet`。未知车牌为 404 `NotFound`。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **是** | `ABC1234` | 厄瓜多尔车牌。必填。 |

### 说明

- 路径是第 3 版：`/v3/ec/vehiculo/placa`。
- 唯一必填查询参数是 `plate`。
- 未知车牌为 404 `NotFound`。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `plate: "ABC1234"` | 含识别、revision 和 technicalSheet 的 200。 |
| 缺少必填值 | Omit `plate` | 409 MissingParameter。 |
| 未知的值 | `plate: "ZZZ0000"` | 车牌未知时为 404 NotFound。 |

401 when the bearer token is missing or rejected.
