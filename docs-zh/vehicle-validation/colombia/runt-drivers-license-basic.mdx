### 端点

```
GET https://api.verifik.co/v3/co/runt/conductor
```

与 [Premium v2](/vehicle-validation/colombia/runt-drivers-license) 相同的 RUNT 查询，按**当前驾驶员价格**计费。`primerApellido` **必填**。缺少时返回 `409 MissingParameter`。

### 参数

| 名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `documentType` | string | 是 | **`CC`**、**`CE`**、**`PA`**、**`PPT`**。 |
| `documentNumber` | string | 是 | 不含空格的号码。 |
| `primerApellido` | string | **是** | 第一个姓氏（至少 2 个字符）。 |
