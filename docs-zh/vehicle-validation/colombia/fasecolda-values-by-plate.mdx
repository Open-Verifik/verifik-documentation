# 按车牌查询车辆价值 - Fasecolda

Verifik 的 Fasecolda 按车牌查询车辆价值 API 仅需车牌即可获取哥伦比亚注册车辆的官方商业估值与技术规格。为了在乘用车、SUV、皮卡、重型商用车和摩托车上实现最高查询成功率，此端点**结合了两个互补的官方车辆数据源**：

1. **主要解析（车牌-代码直接索引）**：当车牌在主要估值索引中直接关联了 Fasecolda 估值代码时，Verifik 会立即返回目录中的精确条目。
2. **次要解析（跨源技术规格匹配）**：当车辆（尤其是大多数摩托车或新注册车辆）未按车牌直接编入估值索引时，Verifik 会自动从官方二级车辆登记记录中获取经核实的技术规格（`brand`、`line`、`cylinderCapacity`、`year` 和 `vehicleClass`），并与 Fasecolda 估值目录进行交叉匹配（`matchSource: "runt_fallback"`）。

每当响应通过跨源技术规格匹配解析时，返回结果都会包含完整的溯源和评分明细（`matchSource`、`matchConfidence`、`matchNote`、`matchDetails` 和 `runtVehicle`），让您的核保或评估流程清楚了解估值代码是如何匹配的，以及哪些因素扣减了置信度得分。

## 此 API 验证哪些内容？

- **按车牌查询汽车与摩托车信息**：支持哥伦比亚轿车、SUV、皮卡、商用车和摩托车车牌（`ABC123`、`ABC12D`、`ABC12`）。输入的车牌会自动标准化（转为大写并去除空格、连字符和句点）。
- **完整的技术与估值数据**：返回 Fasecolda 代码（`code` / `homoloCode`）、品牌（`marke`）、车型系列（`line1`、`line2`、`line3`）、车辆类别（`class`）、分类（`category`）、排量（`cylinderCapacity`）、燃料（`fuel`）、变速箱（`transmission`）、基准商业价格（`bcpp`）以及分年份历史价格（`valueModel`）。
- **双源透明度与置信度评分明细**：在跨源匹配时提供加权置信度得分（`0.60` 至 `1.00`）以及每项扣分的详细说明（`matchDetails.penalties`）。

### Endpoint

```
GET https://api.verifik.co/v2/co/fasecolda/values-by-plate
```

查询哥伦比亚注册车辆的官方估值与技术属性（`code`、`marke`、`line1`、`line2`、`line3`、`class`、`cylinderCapacity`、`bcpp`、`valueModel`），并在跨源规格匹配时返回 `matchSource`、`matchConfidence`、`matchNote`、`matchDetails` 和 `runtVehicle`。通过**查询参数** **`plate`** 传入**车牌**。

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | Yes | 哥伦比亚汽车或摩托车车牌（空格、连字符和句点会自动去除）。 | `ABC123` |

### Notes

- **双源覆盖（汽车与摩托车）**：当车牌在主要估值索引中直接建有索引时，返回精确的 Fasecolda 记录（省略 `matchSource`）。当车牌未直接建有索引时（在摩托车及部分轻型车辆中尤为常见），Verifik 会从官方二级车辆登记记录核实技术规格并与 Fasecolda 估值目录匹配（`matchSource: "runt_fallback"`）。
- **置信度计算公式（`matchConfidence` 与 `matchDetails`）**：跨源匹配按 `0.55 * textScore + 0.25 * ccScore + 0.20 * yearScore` 在 `0.00` 至 `1.00` 范围内计分，最低阈值为 `0.60`。
- **导致 `matchConfidence` 扣分的因素（`matchDetails.penalties`）**：
  - **目录中额外的配置/变速箱词元（`textPoints`，满分 `0.55`）**：车辆登记记录通常仅保存基础车系名称（如 `"VERSA"`、`"TRACKER"` 或 `"TRK 502X"`），而 Fasecolda 目录包含具体配置、变速箱和 ABS 后缀（如 `"ADVANCE AT 1600CC 2AB ABS"`）。这些额外词元列在 `extraGuideTokens` 中。
  - **公告型号代码与商业名称差异**：例如 `"FZN250 A"` 对应 `"FZ25 250"`，差异词元记录在 `unmatchedRuntTokens` 中。
  - **标称排量取整差异（`ccPoints`，满分 `0.25`）**：5% 以内的排量差异（如 `199cc` 与 `200cc`）得满分（`0.25/0.25`）；较大的目录标称排量差异（如 `373cc` 与 `400cc`）扣减 `-0.07` 并在 `penalties` 中说明。
- **估值单位**：`valueModel` 为按车型年份的历史价格数组，`bcpp` 为基准商业基础价（单位为哥伦比亚比索 COP）。
