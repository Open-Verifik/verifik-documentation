仅使用车牌查询哥伦比亚车辆的基本信息及其所有权记录。适用于所有权核验、车辆接入和尽职调查。

### 端点

```
GET https://api.verifik.co/v2/co/runt/vehiculo/owners
```

响应包括 `plate`、`brand`、`line`、`model` 和 `owners` 数组；如有数据，还会返回所有人身份、持有期限、融资、抵押和登记信息。与 **`GET /v2/co/runt/propietarios`** 不同，本端点以车牌为查询条件，并返回标准化的车辆和所有人记录。

### 请求头

| 名称 | 值 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### 参数

| 名称 | 类型 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `plate` | string | 是 | 由 5–9 个字母或数字组成的哥伦比亚车牌。 | `CRL299` |

### 请求

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.get("https://api.verifik.co/v2/co/runt/vehiculo/owners", {
	params: { plate: "CRL299" },
	headers: {
		Accept: "application/json",
		Authorization: `Bearer ${process.env.VERIFIK_TOKEN}`,
	},
});
console.log(data);
```

  </TabItem>
  <TabItem value="python" label="Python">

```python
import os, requests

url = "https://api.verifik.co/v2/co/runt/vehiculo/owners"
headers = {"Accept": "application/json", "Authorization": f"Bearer {os.getenv('VERIFIK_TOKEN')}"}
response = requests.get(url, headers=headers, params={"plate": "CRL299"})
print(response.json())
```

### 说明

- AppFeature 代码为 **`colombia_api_vehicle_owners`**。
- 沙盒示例请使用 **`CRL299`**。
- 无可用值时，所有人字段可能为 `null`；`owners` 可能包含多条历史记录。
- **`GET /v2/co/runt/propietarios`** 使用不同的查询流程，并非本车牌查询端点的别名。
