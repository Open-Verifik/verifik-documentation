# 秘鲁 - 车辆扣押令（利马 SAT）

### 接口

```
GET https://api.verifik.co/v2/pe/vehiculo/captura-lima
```

向利马税务机构（**SAT**）查询车辆 **`plate`** 在利马省是否有扣押令。没有扣押令也是成功响应：`hasCaptureOrder` 为 `false`，`orders` 为空。有扣押令时，`message` 是 SAT 的官方原文，`orders` 的每一项包含 `concept`、索尔金额 `amount`、`period` 和 `documentNumber`。只有 SAT 提供状态时才会填写 `status`。公开表单带有列名时，`columns` 保留原始标签。

### 请求头

| 名称          | 值              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### 参数

| 名称    | 类型   | 必填 | 说明                                                                 | 示例  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | 是      | 车辆牌照，5 到 8 位字母或数字，不含空格。`F1E120` 有扣押令，`V0R660` 没有。  | `F1E120` |
| `force` | boolean | 否      | 可选。传 `true` 或 `1` 可跳过已保存的结果并重新查询 SAT。  | `true` |

### 说明

- 查询范围仅限利马省。
- `plate` 请去掉空格和连字符（5 到 8 位字母或数字）。
- 没有扣押令的车牌仍然返回 **HTTP 200**。**404** 只用于不是 5 到 8 位字母或数字的车牌。
- `amount` 以索尔格式返回（`S/ 505.86`）。SAT 未提供状态时 `status` 为空。
- `F1E120` 有扣押令。`V0R660` 没有。
- 无法查询 SAT 时，接口返回 **409** 和 `Endpoint_out_of_service`。
- **沙盒模式**下，`ABC10001` 有扣押令，`ABC10002` 没有。
