# 秘鲁 — 车辆信息 (v3)

### Endpoint

```
GET https://api.verifik.co/v3/pe/vehiculo/placa
```

秘鲁车辆信息 v3 服务按车牌号（**`plate`**）返回登记车辆详情，并在可用时返回 `technicalSheet`（`engine`、`performance` 以及包含车长、车宽、车高、轴距、整备质量、油箱容积、车门数与座位数在内的 `dimensions`）。

### 请求头（Headers）

| 名称          | 值                 |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### 参数（Parameters）

| 名称    | 类型   | 必填   | 描述                                       | 示例     |
| ------- | ------ | ------ | ------------------------------------------ | -------- |
| `plate` | string | **是** | 要查询的车牌号，不含空格或句点。           | `ABC123` |

### 请求（Request）

<Tabs>
<TabItem value="javascript" label="JavaScript">

```javascript
import axios from 'axios';

const { data } = await axios.get('https://api.verifik.co/v3/pe/vehiculo/placa', {
  params: { plate: 'ABC123' },
  headers: { Accept: 'application/json', Authorization: 'Bearer <您的令牌>' },
});
console.log(data);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import http.client

conn = http.client.HTTPSConnection("api.verifik.co")
headers = {"Accept": "application/json", "Authorization": "Bearer <您的令牌>"}
conn.request("GET", "/v3/pe/vehiculo/placa?plate=ABC123", headers=headers)
print(conn.getresponse().read().decode("utf-8"))
```

</TabItem>
</Tabs>

### 说明

- 当无匹配技术规格数据时，`technicalSheet`（包含 `dimensions` 中的 `length`、`width`、`height`、`wheelbase`、`curbWeight`、`fuelTank`、`doors`、`occupants`）可能为 `null` 或部分填充。
- 在**沙盒模式**下，`ABC10001`–`ABC10010` 返回稳定的演示车辆档案。
