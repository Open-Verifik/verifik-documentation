# 秘鲁 — 阿雷基帕 SETARE 出租车运营许可

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/setare-arequipa
```

根据秘鲁阿雷基帕市政官方记录，按车牌号（**`plate`**）验证车辆是否具备 **SETARE** 出租车运营许可，并返回 `hasActivePermit`、`latestPermit` 和 `permits`。

### 请求头（Headers）

| 名称          | 值                 |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### 参数（Parameters）

| 名称    | 类型   | 必填   | 描述                                                     | 示例     |
| ------- | ------ | ------ | -------------------------------------------------------- | -------- |
| `plate` | string | **是** | 要查询的车牌号（不含空格或连字符的 6 位字母数字，如 `V3D236`）。 | `V3D236` |

### 请求（Request）

<Tabs>
<TabItem value="javascript" label="JavaScript">

```javascript
import axios from 'axios';

const { data } = await axios.get('https://api.verifik.co/v2/pe/vehiculo/setare-arequipa', {
  params: { plate: 'V3D236' },
  headers: { Accept: 'application/json', Authorization: 'Bearer <您的令牌>' },
});
console.log(data);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import http.client

conn = http.client.HTTPSConnection("api.verifik.co")
headers = {"Accept": "application/json", "Authorization": "Bearer <您的令牌>"}
conn.request("GET", "/v2/pe/vehiculo/setare-arequipa?plate=V3D236", headers=headers)
print(conn.getresponse().read().decode("utf-8"))
```

### 说明

- 请传入不含空格或连字符的 6 位车牌号（`plate`）。
- 在**沙盒模式**下，`ABC10001` 返回有效许可（`Vigente`），`ABC10002` 返回已过期许可（`Vencido`）。
