# 秘鲁 - 车辆技术检验证书 (CITV)

### 接口

```
GET https://api.verifik.co/v2/pe/vehiculo/inspeccion-tecnica
```

按车牌 **`plate`** 查询秘鲁交通部（**MTC**）登记的车辆技术检验证书（**CITV**）。响应包含是否找到证书（`found`）、是否有当前有效证书（`hasValidCertificate`）、最近一张证书（`latestCertificate`）以及来源返回的全部证书（`certificates`）。

### 请求头

| 名称          | 值              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### 参数

| 名称    | 类型   | 必填 | 说明                                                                 | 示例  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | 是      | 车辆牌照，5 到 8 位字母或数字，不含空格。示例：`V0R660`。  | `V0R660` |
| `force` | boolean | 否      | 可选。传 `true` 或 `1` 可跳过已保存的结果并重新查询 MTC。  | `true` |

### 说明

- `plate` 请去掉空格和连字符（5 到 8 位字母或数字）。
- 至少有一张证书状态为 `VIGENTE` 时，`hasValidCertificate` 为 `true`。
- `latestCertificate` 是 MTC 返回的第一张证书。`certificates` 列出该车牌的全部记录。`V0R660` 目前有两张有效证书。
- 没有证书的车牌，或不是 5 到 8 位字母或数字的车牌，返回 **404**。
- MTC 来源不可用时，接口返回 **409** 和 `Endpoint_out_of_service`。
- **沙盒模式**下，`ABC10001` 返回有效（`VIGENTE`）证书，`ABC10002` 返回已过期（`VENCIDO`）证书。
