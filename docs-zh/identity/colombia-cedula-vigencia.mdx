# 哥伦比亚 — 公民身份证状态（CC）

**哥伦比亚公民身份证状态**查询读取 Registraduría 的有效状态。发送 `documentNumber`。响应说明该号码是否存在、持证人是否被记录为在世，以及登记机关公布的状态文字。在做更完整的身份查询之前，需要当前 CC 状态时使用。

## 调用返回的内容

- `documentType` — CC
- `documentNumber` — 你发送的身份证号
- `exists` — 登记机关是否有该号码
- `isAlive` — true、false 或 null
- `documentStatus` — 登记机关给出的有效状态文字

## 使用场景

- 开户前确认该 CC 已在登记机关备案。
- 在 KYC 中把死亡记录与有效身份证分开。
- 把状态文字和证件号码一起留存。

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/co/cedula/vigencia
```

成功响应包含 `documentType`（CC）、`documentNumber`、`exists`、`isAlive` 和 `documentStatus`。登记机关称该号码不存在时 `exists` 为 false。数据源未能确定生存状态时 `isAlive` 为 true、false 或 null。在需要当前有效状态的 KYC 档案中调用。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **是** | `1121329661` | 哥伦比亚公民身份证号，5 到 10 位数字，不要带空格或标点。 |

### 说明

- `documentNumber` 必填，长度为 5 到 10 个字符。
- 登记机关返回的状态不能判定生死时，`isAlive` 可以为 null。
- 本接口是有效状态查询，不能代替完整的公民档案。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `documentNumber: "1121329661"` | 包含上文所列字段的 200。 |
| 缺少必填值 | Omit `documentNumber` | 409 MissingParameter。 |
| 未知的值 | `documentNumber: "0000000000"` | 数据源没有该记录时为 404 NotFound。 |

401 when the bearer token is missing or rejected.
