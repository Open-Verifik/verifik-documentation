# 哥伦比亚 — 化学工程执照（CPIQ）

**CPIQ 执照**查询读取 Consejo Profesional de Ingeniería Química。发送 `documentNumber` 或 `licenseNumber`。该模块不按姓名检索：只发送 `fullName` 会返回 HTTP 409，代码 `MissingParameter`，消息为 `Either documentNumber or licenseNumber must be provided`。命中包含执照、决议、状态和处分字段。

## 调用返回的内容

- `licenseNumber` 与 `resolutionNumber`
- `status` 与 `isActive`
- `sanctionType` 与 `hasSanctions`

## 使用场景

- 用身份证或 CPIQ 执照核验化学工程师。
- 在到达理事会之前拒绝仅姓名的检索。
- 读取理事会公布的处分日期。

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpiq
```

命中包含 `fullName`、`licenseNumber`、`resolutionNumber`、`status`、`sanctionType`、`isRegistered` 和 `hasSanctions`。CPIQ 没有记录时为 404 `NotFound`。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **条件必填** | `79876543` | 身份号码。省略 `licenseNumber` 时必填。只发送 `fullName` 会返回 409。 |
| `licenseNumber` | string | **条件必填** | `PQ-10293` | CPIQ 专业执照号。省略 `documentNumber` 时必填。 |

### 说明

- 本接口不把 `fullName` 当作检索键。只发姓名会返回 409。
- 发送 `documentNumber` 或 `licenseNumber`。
- CPIQ 没有记录时为 HTTP 404。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `documentNumber: "79876543"` | 含执照和处分字段的 200。 |
| 缺少必填值 | `fullName: "LUIS GOMEZ"` only | 只发姓名不被接受，返回 409。 |
| 未知的值 | `documentNumber: "000000000"` | CPIQ 没有记录时为 404 NotFound。 |

401 when the bearer token is missing or rejected.
