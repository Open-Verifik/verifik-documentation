# 哥伦比亚 — 工商管理执照（CPAE）

**CPAE 执照**查询读取 Consejo Profesional de Administración de Empresas。`documentNumber` 必填。可选 `documentType` 接受 `CC`、`CE`、`TI`、`PEP` 或 `PPT`。命中时返回姓名、专业以及证件是否已登记且有效。

## 调用返回的内容

- `fullName` 与 `profession`
- `entity` — CPAE
- `status`、`isRegistered` 与 `isActive`

## 使用场景

- 招聘时核验工商管理资格证。
- 确认证件仍然有效。
- 把 CPAE 的专业文字写入 KYC 档案。

---

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpae
```

响应包含 `fullName`、`profession`、`entity`、`status`、`isRegistered` 和 `isActive`。未知号码为 404 `NotFound`。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **是** | `80123456` | 哥伦比亚身份号码，5 到 15 个字符。`documentType` 可以是 `CC`、`CE`、`TI`、`PEP` 或 `PPT`。 |

### 说明

- `documentNumber` 必填。
- 该号码没有专业证时 CPAE 返回 404。
- 不要用姓名代替证件号码。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `documentNumber: "52987654"` | 含专业和有效标志的 200。 |
| 缺少必填值 | Omit `documentNumber` | 409 MissingParameter。 |
| 未知的值 | `documentNumber: "000000000"` | CPAE 没有该证时为 404 NotFound。 |

401 when the bearer token is missing or rejected.
