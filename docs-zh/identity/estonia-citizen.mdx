# 爱沙尼亚 — 公民身份与个体经营者核验 (KYC)

**爱沙尼亚公民身份与个体经营者核验**按该标识（REGKOOD）的官方来源核验个人或个体经营者。请将该号码作为 `documentNumber` 发送。当开户需要法定姓名、登记状态以及来源公布的身份属性时使用。

`documentNumber` 为必填。`documentType` 默认为 `REGKOOD`。省略即使用该默认值，也可以显式发送 `REGKOOD`。

## 登记机关返回的内容

- 个人或个体经营者的法定姓名
- 登记状态
- 所查询的标识
- 来源公布的官方身份属性

## 使用场景

- 在开户时确认爱沙尼亚的个体经营者或已登记个人。
- 将档案中的法定姓名与官方标识核对。
- 保存登记状态以及官方来源公布的身份属性。

## API 参考

### 端点

```http
GET https://api.verifik.co/v2/ee/citizen
```

使用 `documentNumber` 查询爱沙尼亚的官方身份与个体经营者来源。`documentType` 选择标识种类（REGKOOD）。成功响应包含法定姓名、登记状态、所发送的标识，以及来源公布的官方身份属性。用于个人或个体经营者的 KYC 开户。下方示例展示这些字段。实际值来自官方来源。

### 请求头

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <your_token>` | 客户端 JWT 认证令牌 |

### 参数

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **是** | `10000018` | 个人或个体经营者的官方身份或纳税人号码（REGKOOD）。 |
| `documentType` | string | 否 | `REGKOOD` | 证件类型标识。默认值为 `REGKOOD`。 |

### 备注

- **标识格式.** 登记代码（registrikood）为 8 位数字。爱沙尼亚增值税号为前缀 EE 加上 9 位数字。发送登记代码时不要包含空格。
- 证件类型标识。默认值为 `REGKOOD`。
- 示例中的状态标签用于说明字段。实际登记机关返回其自身标签，可能是当地语言。
- 此接口的客户参数是 `documentNumber`，以及需要标明标识种类时的 `documentType`。
- JSON 示例说明上述字段。实际调用返回所发送标识对应的登记记录。

## 沙盒探测

账户处于沙盒模式时，用相同参数调用此接口。表中说明每种情况对应的已记录响应。

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| **已有标识** | `documentType: "REGKOOD"`, `documentNumber: "10000018"` | 来源持有该号码时返回 200，以及法定名称、状态、标识和地址或身份属性。 |
| **缺少 documentNumber** | 省略 `documentNumber` | 省略 `documentNumber` 时返回 409 `MissingParameter`。 |
| **未知号码** | `documentNumber: "000000000"` | 登记机关没有该号码的记录时返回 404 `NotFound`。 |

缺少或拒绝 bearer 令牌时返回 401。
