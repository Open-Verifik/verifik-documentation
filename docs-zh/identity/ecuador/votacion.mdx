# 厄瓜多尔 — 投票地点

**厄瓜多尔投票地点**查询读取 CNE 名册。`documentType` 必须是 `CCEC`，`documentNumber` 必须是省份码为 01–24 或 30 且校验位正确的 10 位身份证。响应包含姓名以及省、县、堂区和投票组（`pollingTable`）。

## 调用返回的内容

- `province`、`canton` 与 `parish`
- `pollingTable` — 投票组
- `fullName`

## 使用场景

- 向选民展示投票地点。
- 拒绝校验位失败的身份证。
- 把投票组和身份档案一起保存。

---

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/ec/votacion
```

字段包括 `fullName`、`province`、`canton`、`parish` 和 `pollingTable`。未知身份证为 404 `NotFound`。校验位错误为 409 `InvalidDocumentNumber`。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentType` | string | **是** | `CCEC` | 必须是 `CCEC`。 |
| `documentNumber` | string | **是** | `1700000019` | 含校验位的 10 位厄瓜多尔身份证。省份码必须是 01–24 或 30。错误号码返回 409 `InvalidDocumentNumber`。 |

### 说明

- `documentType` 必须是 `CCEC`。
- 身份证为 10 位，省份码和校验位必须有效。
- 未知号码为 404 `NotFound`。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `documentType: "CCEC"`, `documentNumber: "1700000019"` | 含省、县、堂区和投票组的 200。 |
| 缺少必填值 | Omit `documentType` | 409 MissingParameter。 |
| 未知的值 | `documentNumber: "1700000092"` | 名册没有记录时为 404 NotFound。 |

401 when the bearer token is missing or rejected.
