# 拉美 — 教育与执照统一评分

**教育评分**把 `CO`、`PE`、`PA`、`MX` 或 `CL`（也接受英文国名）的大学学位和专业执照合成一个分数。`country` 必填。还必须发送一项身份：`documentNumber`、`licenseNumber`、`fullName`，或同时发送 `firstName` 与 `lastName`。409 正文是 `{ "validationError": "..." }`，不是 `MissingParameter`。不支持的国家也是 409。

## 调用返回的内容

- `educationScore` 与 `educationTier`
- `highestLevel` 与 `hasActiveLicense`
- `credentials` 与 `checkedSources`

## 使用场景

- 按学位和执照来源给候选人排序。
- 打分前必须有国家。
- 把处分读作分数下降。

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/score/education
```

响应含 0 到 100 的 `educationScore`、`educationTier`、`highestLevel`、`hasActiveLicense`、`hasSanctions` 和 `credentials`。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `country` | string | **是** | `CO` | 必填。`CO`、`PE`、`PA`、`MX`、`CL`，或英文名 `COLOMBIA`、`PERU`、`PANAMA`、`MEXICO`、`CHILE`。 |
| `documentNumber` | string | **条件必填** | `80123456` | 需要一项身份：此号码、`licenseNumber`、`fullName`，或同时提供 `firstName` 与 `lastName`。 |
| `licenseNumber` | string | **条件必填** | `AN205-27910` | 专业执照。可作为必填身份。 |
| `fullName` | string | **条件必填** | `ANA PEREZ` | 全名。可作为必填身份。 |

### 说明

- `country` 必填。
- 409 使用 `validationError`，不是 `MissingParameter`。
- 支持的国家是 CO、PE、PA、MX 和 CL。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `country: "CO"`, `documentNumber: "80123456"` | 含 educationScore 和等级的 200。 |
| 缺少必填值 | Omit `country` | 缺少 country 或身份时为 409 `{ validationError }`。 |
| 未知的值 | `country: "US"`, `documentNumber: "1"` | 国家代码不受支持时为 409。 |

401 when the bearer token is missing or rejected.
