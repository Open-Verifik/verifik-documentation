# 哥伦比亚 — 职业安全卫生执照（SST）

**SST 执照**查询读取哥伦比亚身份号码对应的职业安全执照和技术施用证。`documentNumber` 必填。命中时列出每张证的类型、决议或证件号以及签发日期。

## 调用返回的内容

- 带 `licenseType`、决议或证件号和 `issueDate` 的 `licenses[]`
- `totalLicenses`
- `status` 与 `isRegistered`

## 使用场景

- 承包商进场前核验 SST 执照。
- 同时查看自然人执照和技术证。
- 把决议号留在供应商档案里。

---

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/co/sst/licencia
```

响应包含 `fullName`、`profession`、`totalLicenses` 和 `licenses`。既无执照也无技术证时为 404 `NotFound`。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **是** | `52111222` | 用于读取 SST 执照和技术证的哥伦比亚身份号码，5 到 15 个字符。 |

### 说明

- `documentNumber` 必填。
- 既没有 SST 执照也没有技术证时为 HTTP 404。
- 可选 `documentType` 接受 `CC`、`CE`、`TI`、`PEP` 或 `PPT`。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `documentNumber: "52111222"` | 含一张或多张执照的 200。 |
| 缺少必填值 | Omit `documentNumber` | 409 MissingParameter。 |
| 未知的值 | `documentNumber: "000000000"` | 两个数据源都没有记录时为 404 NotFound。 |

401 when the bearer token is missing or rejected.
