# 巴拿马 — 律师适任

**律师适任**查询按编号读取巴拿马律师证书。发送 1 到 10 位的 `idoneidad` 或别名 `licenseNumber`。可选 `issueDate` 使用 `DD-MM-YYYY`。缺少编号为 409 `MissingParameter`。

## 调用返回的内容

- 适任编号与姓名
- `status`

## 使用场景

- 提交文件前确认律师。
- 有签发日期时进行核对。
- 拒绝非数字适任编号。

---

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/pa/lawyer/idoneidad
```

命中含姓名、适任编号和状态。未知编号为 404 `NotFound`。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `idoneidad` | string | **条件必填** | `12345` | 律师适任编号，1 到 10 位数字。别名 `licenseNumber`。二者必填其一。 |
| `issueDate` | string | 否 | `01-02-2010` | 可选签发日期，格式 `DD-MM-YYYY`。 |

### 说明

- 发送 `idoneidad` 或 `licenseNumber`。
- 仅数字，1 到 10 位。
- 未知编号为 404 `NotFound`。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `idoneidad: "12345"` | 含律师记录的 200。 |
| 缺少必填值 | Omit `idoneidad` and `licenseNumber` | 409 MissingParameter。 |
| 未知的值 | `idoneidad: "999999"` | 编号未知时为 404 NotFound。 |

401 when the bearer token is missing or rejected.
