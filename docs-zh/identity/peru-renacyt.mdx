# 秘鲁 — SUNEDU 学位与 CONCYTEC RENACYT

**RENACYT** 查询读取 SUNEDU 学位和 CONCYTEC 研究人员登记。至少发送 `documentNumber`（别名 `dni`）、`codigoRegistro`、`orcid` 或 `fullName` 之一。发送证件号时 `documentType` 默认为 `DNI`。

## 调用返回的内容

- 学位与研究人员字段
- 有则含 `codigoRegistro` 与 `orcid`
- `fullName` 与 `documentNumber`

## 使用场景

- 拨款前确认研究人员。
- 把 ORCID 与 DNI 对齐。
- 读取招聘档案需要的 RENACYT 代码。

---

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/pe/education/renacyt
```

命中可含学位、RENACYT 代码和 ORCID。没有记录时为 404 `NotFound`。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **条件必填** | `12345678` | DNI 或其他号码。别名 `dni`。默认 `documentType` 为 `DNI`。也接受 `CE`、`PASAPORTE`、`PTP`。 |
| `codigoRegistro` | string | **条件必填** | `REN-100` | RENACYT 登记码。只发它即可。 |
| `orcid` | string | **条件必填** | `0000-0002-1825-0097` | ORCID，10 到 30 个字符。只发它即可。 |
| `fullName` | string | **条件必填** | `LUCIA QUISPE` | 研究者姓名。只发它即可。 |

### 说明

- 发送证件、RENACYT 代码、ORCID 或姓名。
- 证件号默认类型为 `DNI`。
- 登记处没有记录时为 404 `NotFound`。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `documentType: "DNI"`, `documentNumber: "12345678"` | 含学位或研究人员字段的 200。 |
| 缺少必填值 | Omit every search value | 409 MissingParameter。 |
| 未知的值 | `documentNumber: "00000000"` | SUNEDU 和 RENACYT 都没有记录时为 404 NotFound。 |

401 when the bearer token is missing or rejected.
