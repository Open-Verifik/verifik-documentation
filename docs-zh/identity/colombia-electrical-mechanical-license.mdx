# 哥伦比亚 — 电气与机械工程执照

**电气与机械工程执照**查询读取 Consejo Profesional Nacional de Ingenierías Eléctrica, Mecánica y Profesiones Afines。发送 `documentNumber`、`licenseNumber` 或 `fullName` 之一。响应包含执照、专业、状态以及是否有处分。

## 调用返回的内容

- `licenseNumber` 与 `specialty`
- 例如 VIGENTE 的 `status`
- `isRegistered` 与 `hasSanctions`
- 多条记录时的 `registrations`

## 使用场景

- 开工前确认电气或机械工程师。
- 读取执照旁的纪律处分。
- 把合同姓名与理事会记录对齐。

## API 参考

### Endpoint

```http
GET https://api.verifik.co/v2/co/consejo-profesional
```

命中包含 `fullName`、`licenseNumber`、`specialty`、`status`、`isRegistered` 和 `hasSanctions`。理事会没有记录时返回 404 `NotFound`。

### Headers

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 请求格式 |
| Accept | `application/json` | 响应格式 |
| Authorization | `Bearer <token>` | 客户端 JWT |

### Parameters

| 名称 | 类型 | 必填 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **条件必填** | `80123456` | 哥伦比亚身份号码，5 到 15 个字符。`documentType` 可以是 `CC`、`CE`、`TI`、`PEP` 或 `PPT`。 |
| `licenseNumber` | string | **条件必填** | `AN205-27910` | 专业执照号，例如 AN205-27910。只发它即可。 |
| `fullName` | string | **条件必填** | `ANA PEREZ` | 工程师姓名或姓氏，3 到 160 个字符。只发它即可。 |

### 说明

- 至少发送 `documentNumber`、`licenseNumber` 或 `fullName` 之一。
- 理事会没有记录是 HTTP 404，不是空的 200。
- `documentType` 可选。
- 在 `Authorization` 头中发送 Bearer JWT。
- JSON 示例只说明字段形状。实际调用返回你所发送数值对应的记录。
- 不要发送绕过缓存的标志。本页只记录客户端参数。

## 沙盒

| 场景 | 参数 | 结果 |
| :--- | :--- | :--- |
| 数据源有记录 | `documentNumber: "80123456"` | 含执照、专业和处分标志的 200。 |
| 缺少必填值 | Omit every search value | 409 MissingParameter。 |
| 未知的值 | `documentNumber: "000000000"` | 理事会没有记录时为 404 NotFound。 |

401 when the bearer token is missing or rejected.
