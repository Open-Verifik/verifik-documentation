# 🇵🇪 秘鲁 — DNI（扩展信息）

Verifik 的身份核验 API 可使用秘鲁公民的 DNI（*Documento Nacional de Identidad*）号码进行扩展身份验证。该 API 旨在简化您的 KYC（了解您的客户）流程、防范欺诈，并轻松满足合规要求。

我们专为需要快速、安全且自动化获取扩展个人信息（包括姓名全称、婚姻状态、出生日期、地址明细（省、区域、居住区）及相关身份字段）的企业打造此集成。

**为安全访问该信息，必须传入 Authorization 头。**

## 此 API 验证哪些内容？

我们的 API 直接对接秘鲁官方记录，验证以下内容：

-   **姓名全称与 DNI 号码**：支持 *Documento Nacional de Identidad*（DNI）证件。
-   **身份匹配**：确认所提供姓名与 DNI 号码相符。
-   **扩展个人信息**：返回婚姻状态、出生日期、性别、地址、省、区域和居住区。
-   **姓名组成部分**：返回 `firstName`、`lastName`、`paternalLastName`、`maternalLastName` 和 `arrayName`。
-   **证件信息**：返回证件类型和号码。

部分字段始终出现在响应中，但当前返回字符串 `not_available`（不会被省略）：`photo`、`expeditionDate`、`expirationDate`、`ubigeoReniec` 和 `verificationDigit`。此端点当前不提供照片。

通过验证这些信息，您可以确信对接的人员真实存在并持有有效证件，从而显著降低身份冒用与欺诈风险。

### 端点

```
GET https://api.verifik.co/v3/pe/cedula/extra
```

返回秘鲁公民的 **RENIEC DNI 扩展数据**：姓名全称、婚姻状态、出生日期、地址（省、区域、居住区）及相关身份字段。请传入 `documentType=DNI` 和 8 位 `documentNumber`。

`photo`、`expeditionDate`、`expirationDate`、`ubigeoReniec` 和 `verificationDigit` 包含在响应结构中，但当前返回 `not_available`。

### 请求头（Headers）

| 名称           | 取值                |
| -------------- | ------------------- |
| Content-Type   | `application/json`  |
| Authorization  | `Bearer <token>`    |

### 参数（Parameters）

| 名称 | 类型 | 必填 | 描述 | 示例 |
| ---- | ---- | ---- | ---- | ---- |
| `documentType` | string | **是** | 证件类型。允许值：`DNI`。 | `DNI` |
| `documentNumber` | string | **是** | 8 位 DNI 号码（不含空格）。 | `44868598` |

| `photo`、`expeditionDate`、`expirationDate`、`ubigeoReniec`、`verificationDigit` | `not_available` | 出现在响应中，但在当前产品层级未填充。 |

## 常见使用场景

-   **进阶 KYC 流程**：执行全面身份核验以加强合规与欺诈检测。
-   **金融服务**：为银行及金融服务申请验证详细身份信息。
-   **雇佣验证**：在招聘流程中确认完整的个人信息。
-   **合规与尽职调查**：满足秘鲁要求扩展身份数据的法规要求。
-   **欺诈检测**：使用扩展的人口统计与地址数据进行高级反欺诈。

## 官方数据源与可靠性

我们直接对接秘鲁政府的官方数据源（RENIEC），确保您获得经过验证且最新的信息。

## 主要优势

-   **自动化合规**：在不增加用户摩擦的前提下简化 KYC 检查并防范欺诈。
-   **扩展数据访问**：获取包含地址、婚姻状态及人口学信息在内的完整身份数据。
-   **即时结果**：在数秒内完成核验，适用于实时身份验证。
-   **可信数据**：采用直接来源于 RENIEC 官方记录的数据。
-   **轻松集成**：通过 REST API 或兼容 SDK 即可便捷接入。
