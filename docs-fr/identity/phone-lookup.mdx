# Global - Recherche de téléphone

## Référence de l'API

### Endpoint

```
https://api.verifik.co/v2/look-ups/phone
```

Le service de recherche de téléphone associe un numéro mobile ou fixe dans le monde au **nom du titulaire listé** et aux champs de profil associés lorsque la source a une correspondance. Envoyez **`countryCode`** (indicatif d'appel numérique) et **`phone`** (numéro national, sans préfixe pays) en **GET** (query) ou **POST** (corps JSON). Un objet `data` réussi inclut `name`, `phone`, `countryCode` et peut inclure `score`, `gender`, `about`, `jobTitle`, `companyName`, `phones`, `addresses`, `internetAddresses`, `imId`, `access` et `enhanced`. Utilisez-le pour l'onboarding, la détection de fraude et la vérification de contacts — pas comme preuve OTP de possession du terminal.

Pour envoyer un code à usage unique par SMS ou WhatsApp, voir [Validations de téléphone](/verifik-fr/resources/phone-validations).

### En-têtes (Headers)

| Nom            | Valeur              |
| -------------- | ------------------- |
| Content-Type   | `application/json`  |
| Authorization  | `Bearer <token>`    |

### Paramètres

| Nom             | Type   | Requis  | Description                                                                 |
| --------------- | ------ | ------- | --------------------------------------------------------------------------- |
| `countryCode`   | string | **Oui** | Indicatif d'appel numérique, pas un code ISO2. Exemple : `57` pour la Colombie, `1` pour les États-Unis. |
| `phone`         | string | **Oui** | Numéro national de la ligne à interroger, sans préfixe pays, espaces ni ponctuation. |

### Requête (Request)

<Tabs>
<TabItem value="javascript" label="JavaScript">

```javascript
import axios from "axios";

const options = {
  method: "GET",
  url: "https://api.verifik.co/v2/look-ups/phone",
  params: { countryCode: "57", phone: "3006094511" },
  headers: {
    Accept: "application/json",
    Authorization: "Bearer <votre_token>",
  },
};

try {
  const { data } = await axios.request(options);
  console.log(data);
} catch (error) {
  console.error(error);
}
```

```python
import http.client

payload = ""

conn.request("GET", "/v2/look-ups/phone?countryCode=57&phone=3006094511", payload, headers)

data = res.read()
```

### Remarques (Notes)

- **GET** et **POST** sont tous deux pris en charge. POST envoie les mêmes champs dans le corps JSON.
- `countryCode` est l'**indicatif d'appel numérique** (par exemple `57`), pas un code ISO2 tel que `CO`.
- Envoyez `phone` comme **numéro national uniquement** — ne préfixez pas à nouveau l'indicatif pays.
- Les champs de profil au-delà de `name`, `phone` et `countryCode` sont facultatifs ; la source peut les omettre.
- Cette route n'a pas de fixtures sandbox. Les recherches interrogent la source live. Les pannes temporaires renvoient **409** avec `Endpoint out of service.`
- Un **404** signifie qu'aucune fiche n'a été trouvée (ou que l'indicatif est inconnu). Les clients payants **ne sont pas facturés** pour les 404.
- Cet endpoint **ne prouve pas** que l'appelant possède le terminal. Pour une vérification OTP, utilisez [Validations de téléphone](/verifik-fr/resources/phone-validations).
