# Colombie — Licence d'administration des entreprises (CPAE)

La consultation de **licence CPAE** lit le Consejo Profesional de Administración de Empresas. `documentNumber` est obligatoire. `documentType` facultatif accepte `CC`, `CE`, `TI`, `PEP` ou `PPT`. Un résultat renvoie le nom, la profession et si la carte est enregistrée et active.

## Ce que l'appel renvoie

- `fullName` et `profession`
- `entity` — CPAE
- `status`, `isRegistered` et `isActive`

## Cas d'usage

- Contrôlez la carte d'administration à l'embauche.
- Confirmez que la carte est encore active.
- Conservez le libellé de profession du CPAE dans le dossier KYC.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpae
```

La réponse contient `fullName`, `profession`, `entity`, `status`, `isRegistered` et `isActive`. Un numéro inconnu est un 404 `NotFound`.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Oui** | `80123456` | Numéro d'identité colombien, 5 à 15 caractères. `documentType` peut valoir `CC`, `CE`, `TI`, `PEP` ou `PPT`. |

### Notes

- `documentNumber` est obligatoire.
- Le CPAE répond 404 si le numéro n'a pas de carte professionnelle.
- N'envoyez pas un nom à la place du numéro.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `documentNumber: "52987654"` | 200 avec profession et indicateur actif. |
| Valeur obligatoire absente | Omit `documentNumber` | 409 MissingParameter. |
| Valeur inconnue | `documentNumber: "000000000"` | 404 NotFound si le CPAE n'a pas de carte. |

401 when the bearer token is missing or rejected.
