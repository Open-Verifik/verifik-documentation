# Panama — Licence d'ingénierie et d'architecture (JTIA)

La consultation de **licence JTIA** lit l'idoneidad des ingénieurs, architectes et techniciens. Envoyez `documentNumber` (ou `cedula`), `licenseNumber` (ou `idoneidad`) ou `fullName`. Une cédula qui ne se normalise pas répond 409. Sans ligne au conseil, c'est un 404 `NotFound`.

## Ce que l'appel renvoie

- Cédula normalisée
- `licenseNumber` et `fullName`
- `status`

## Cas d'usage

- Vérifiez un ingénieur avant un permis de construire.
- Cherchez par cédula si vous n'avez pas la licence.
- Cherchez par nom si vous n'avez que le contrat.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/pa/professional/jtia
```

Une correspondance contient la cédula normalisée, le nom, la licence et le statut.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditionnel** | `8-224-2444` | Cédula panaméenne, aussi comme `cedula`. L'API la normalise (par exemple `8-224-2444`). |
| `licenseNumber` | string | **Conditionnel** | `JTIA-100` | Idoneidad ou licence. Alias : `idoneidad`. |
| `fullName` | string | **Conditionnel** | `ANA RUIZ` | Nom, 3 à 160 caractères. Il suffit seul. |

### Notes

- Envoyez une cédula, une licence ou un nom.
- Une cédula de forme invalide est un 409.
- Sans ligne JTIA, c'est un 404 `NotFound`.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `documentNumber: "8-224-2444"` | 200 avec la cédula normalisée et la licence. |
| Valeur obligatoire absente | Omit cédula, license, and name | 409 MissingParameter. |
| Valeur inconnue | `documentNumber: "1-1-1"` | 409 si la cédula ne se normalise pas, ou 404 si la JTIA n'a pas de ligne. |

401 when the bearer token is missing or rejected.
