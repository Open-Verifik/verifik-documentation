# Panama — Idoneidad d'avocat

La consultation d'**idoneidad d'avocat** lit le certificat du barreau panaméen par numéro. Envoyez `idoneidad` ou l'alias `licenseNumber` sur 1 à 10 chiffres. `issueDate` facultatif utilise `DD-MM-YYYY`. Sans numéro, c'est un 409 `MissingParameter`.

## Ce que l'appel renvoie

- Numéro d'idoneidad et nom
- `status`

## Cas d'usage

- Confirmez un avocat avant une écriture.
- Rapprochez la date de délivrance si vous l'avez.
- Rejetez une idoneidad non numérique.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/pa/lawyer/idoneidad
```

Une correspondance contient le nom, le numéro d'idoneidad et le statut. Un numéro inconnu est un 404 `NotFound`.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `idoneidad` | string | **Conditionnel** | `12345` | Numéro d'idoneidad de l'avocat, 1 à 10 chiffres. Alias : `licenseNumber`. L'un des deux est obligatoire. |
| `issueDate` | string | Non | `01-02-2010` | Date de délivrance facultative au format `DD-MM-YYYY`. |

### Notes

- Envoyez `idoneidad` ou `licenseNumber`.
- Chiffres seulement, 1 à 10.
- Les numéros inconnus sont des 404 `NotFound`.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `idoneidad: "12345"` | 200 avec le dossier de l'avocat. |
| Valeur obligatoire absente | Omit `idoneidad` and `licenseNumber` | 409 MissingParameter. |
| Valeur inconnue | `idoneidad: "999999"` | 404 NotFound si le numéro est inconnu. |

401 when the bearer token is missing or rejected.
