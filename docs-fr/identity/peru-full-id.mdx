# 🇵🇪 Pérou — DNI (données étendues)

L'API de vérification d'identité de Verifik vous permet d'effectuer une vérification d'identité étendue pour les citoyens péruviens à l'aide de leur numéro de DNI (*Documento Nacional de Identidad*). Elle est conçue pour automatiser vos processus KYC (Know Your Customer), prévenir la fraude et vous assurer de respecter sans effort toutes les exigences réglementaires.

Nous avons construit cette intégration pour les entreprises qui ont besoin d'un moyen rapide, sécurisé et automatisé d'accéder à des informations personnelles étendues, notamment le nom complet, l'état civil, la date de naissance, le détail de l'adresse (province, zone, district de résidence) et d'autres champs d'identité associés.

**L'en-tête Authorization est requis pour authentifier l'accès à ces informations en toute sécurité.**

## Que valide cette API ?

Notre API se connecte directement aux registres officiels péruviens pour valider :

-   **Nom complet et numéro de DNI** : prend en charge les documents *Documento Nacional de Identidad* (DNI).
-   **Correspondance d'identité** : confirme que le nom fourni correspond au numéro de DNI.
-   **Données personnelles étendues** : retourne l'état civil, la date de naissance, le sexe, l'adresse, la province, la zone et le district de résidence.
-   **Composantes du nom** : retourne `firstName`, `lastName`, `paternalLastName`, `maternalLastName` et `arrayName`.
-   **Informations sur le document** : retourne le type et le numéro de document.

Certains champs sont toujours présents dans la réponse mais retournent actuellement la chaîne `not_available` (ils ne sont pas omis) : `photo`, `expeditionDate`, `expirationDate`, `ubigeoReniec` et `verificationDigit`. La photo n'est pas actuellement proposée sur cet endpoint.

En vérifiant ces éléments, vous pouvez avoir la certitude que la personne avec qui vous traitez existe et possède un document valide, ce qui réduit considérablement les risques d'usurpation d'identité et de fraude.

### Endpoint

```
GET https://api.verifik.co/v3/pe/cedula/extra
```

Retourne les **données DNI RENIEC étendues** pour les citoyens péruviens : nom complet, état civil, date de naissance, adresse (province, zone, district de résidence) et autres champs d'identité associés. Envoyez `documentType=DNI` et le `documentNumber` à 8 chiffres.

`photo`, `expeditionDate`, `expirationDate`, `ubigeoReniec` et `verificationDigit` sont inclus dans la structure de la réponse mais retournent actuellement `not_available`.

### En-têtes (Headers)

| Nom            | Valeur              |
| -------------- | ------------------- |
| Content-Type   | `application/json`  |
| Authorization  | `Bearer <token>`    |

### Paramètres

| Nom | Type | Requis | Description | Exemple |
| --- | ---- | ------ | ----------- | ------- |
| `documentType` | string | **Oui** | Type de document. Valeur autorisée : `DNI`. | `DNI` |
| `documentNumber` | string | **Oui** | Numéro de DNI à 8 chiffres (sans espaces). | `44868598` |

| `civilStatus`, `dateOfBirth`, `sex` | Chaînes renseignées | Données démographiques. |
