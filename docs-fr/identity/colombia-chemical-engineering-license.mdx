# Colombie — Licence d'ingénierie chimique (CPIQ)

La consultation de **licence CPIQ** lit le Consejo Profesional de Ingeniería Química. Envoyez `documentNumber` ou `licenseNumber`. Le module ne cherche pas par nom : `fullName` seul répond HTTP 409 avec `MissingParameter` et le message `Either documentNumber or licenseNumber must be provided`. Un résultat contient la licence, la résolution, le statut et les sanctions.

## Ce que l'appel renvoie

- `licenseNumber` et `resolutionNumber`
- `status` et `isActive`
- `sanctionType` et `hasSanctions`

## Cas d'usage

- Vérifiez un ingénieur chimiste par cédula ou licence CPIQ.
- Rejetez les recherches par nom seul avant le conseil.
- Lisez les dates de sanction lorsque le conseil les publie.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpiq
```

Une correspondance contient `fullName`, `licenseNumber`, `resolutionNumber`, `status`, `sanctionType`, `isRegistered` et `hasSanctions`. Sans ligne au CPIQ, c'est un 404 `NotFound`.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditionnel** | `79876543` | Numéro d'identité. Obligatoire si `licenseNumber` est omis. Une requête avec seulement `fullName` répond 409. |
| `licenseNumber` | string | **Conditionnel** | `PQ-10293` | Numéro de matricule professionnelle du CPIQ. Obligatoire si `documentNumber` est omis. |

### Notes

- `fullName` n'est pas une clé de recherche sur cette route. Le nom seul répond 409.
- Envoyez `documentNumber` ou `licenseNumber`.
- Une ligne absente au CPIQ est un HTTP 404.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `documentNumber: "79876543"` | 200 avec licence et champs de sanction. |
| Valeur obligatoire absente | `fullName: "LUIS GOMEZ"` only | 409 parce qu'un nom seul n'est pas accepté. |
| Valeur inconnue | `documentNumber: "000000000"` | 404 NotFound si le CPIQ n'a pas de ligne. |

401 when the bearer token is missing or rejected.
