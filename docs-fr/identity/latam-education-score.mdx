# LATAM — Score unifié d'éducation et de licence

Le **score d'éducation** réunit diplômes et licences professionnelles en un score pour `CO`, `PE`, `PA`, `MX` ou `CL` (les noms de pays en anglais sont acceptés). `country` est obligatoire. Vous devez aussi envoyer une identité : `documentNumber`, `licenseNumber`, `fullName`, ou `firstName` et `lastName`. Un 409 porte `{ "validationError": "..." }`, pas `MissingParameter`. Un pays non pris en charge est aussi un 409.

## Ce que l'appel renvoie

- `educationScore` et `educationTier`
- `highestLevel` et `hasActiveLicense`
- `credentials` et `checkedSources`

## Cas d'usage

- Classez une embauche entre sources de diplôme et de licence.
- Exigez un pays avant de noter.
- Lisez les sanctions comme une baisse du score.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/score/education
```

La réponse contient `educationScore` de 0 à 100, `educationTier`, `highestLevel`, `hasActiveLicense`, `hasSanctions` et `credentials`.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `country` | string | **Oui** | `CO` | Obligatoire. `CO`, `PE`, `PA`, `MX`, `CL`, ou le nom anglais `COLOMBIA`, `PERU`, `PANAMA`, `MEXICO`, `CHILE`. |
| `documentNumber` | string | **Conditionnel** | `80123456` | Une identité est requise : ce numéro, `licenseNumber`, `fullName`, ou `firstName` et `lastName` ensemble. |
| `licenseNumber` | string | **Conditionnel** | `AN205-27910` | Licence professionnelle. Compte comme l'identité obligatoire. |
| `fullName` | string | **Conditionnel** | `ANA PEREZ` | Nom complet. Compte comme l'identité obligatoire. |

### Notes

- `country` est obligatoire.
- Le 409 utilise `validationError`, pas `MissingParameter`.
- Les pays pris en charge sont CO, PE, PA, MX et CL.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `country: "CO"`, `documentNumber: "80123456"` | 200 avec educationScore et niveau. |
| Valeur obligatoire absente | Omit `country` | 409 `{ validationError }` si country ou l'identité manque. |
| Valeur inconnue | `country: "US"`, `documentNumber: "1"` | 409 si le code pays n'est pas pris en charge. |

401 when the bearer token is missing or rejected.
