# Équateur — Lieu de vote

La consultation du **lieu de vote en Équateur** lit le padrón du CNE. `documentType` doit valoir `CCEC` et `documentNumber` doit être une cédula de 10 chiffres dont la province est 01–24 ou 30 et dont la clé est valide. La réponse contient le nom plus la province, le canton, la paroisse et la junta (`pollingTable`).

## Ce que l'appel renvoie

- `province`, `canton` et `parish`
- `pollingTable` — la junta
- `fullName`

## Cas d'usage

- Montrez à l'électeur son bureau.
- Rejetez une cédula dont la clé échoue.
- Conservez la junta avec le dossier d'identité.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/ec/votacion
```

Les champs comprennent `fullName`, `province`, `canton`, `parish` et `pollingTable`. Une cédula inconnue est un 404 `NotFound`. Une mauvaise clé est un 409 `InvalidDocumentNumber`.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentType` | string | **Oui** | `CCEC` | Doit valoir `CCEC`. |
| `documentNumber` | string | **Oui** | `1700000019` | Cédula équatorienne de 10 chiffres, avec la clé. La province doit être 01–24 ou 30. Un mauvais numéro répond 409 `InvalidDocumentNumber`. |

### Notes

- `documentType` doit valoir `CCEC`.
- La cédula a 10 chiffres avec une province et une clé valides.
- Les numéros inconnus sont des 404 `NotFound`.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `documentType: "CCEC"`, `documentNumber: "1700000019"` | 200 avec province, canton, paroisse et junta. |
| Valeur obligatoire absente | Omit `documentType` | 409 MissingParameter. |
| Valeur inconnue | `documentNumber: "1700000092"` | 404 NotFound si le padrón n'a pas de ligne. |

401 when the bearer token is missing or rejected.
