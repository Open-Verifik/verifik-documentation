# Mexique — Certificat d'études (folio)

Valide un certificat d'études électronique mexicain par folio auprès du registre officiel des certificats d'études. Vous pouvez aussi envoyer `fullName` ou `curp` pour confirmer que le certificat appartient à cette personne. Lorsque les deux sont envoyés, `curp` l'emporte. Une non-correspondance retourne **409** `name_mismatch`.

Cette requête contrôle l'enregistrement du certificat. Elle ne constitue pas, à elle seule, une preuve d'identité. Pour l'état civil par CURP, voir [Citoyen mexicain (CURP)](/verifik-fr/identity/mexico). Pour une licence professionnelle, voir [Mexique — Licence professionnelle](/verifik-fr/identity/mexico-cedula-profesional).

## API reference

### Endpoint

```
https://api.verifik.co/v2/mx/siged/certificado
```

Une correspondance retourne `folio`, `fullName`, `status`, `certificateType`, `career`, `institution`, `level`, `studyType`, `average`, `averageText`, `periodStart`, `periodEnd`, `registrationDate`, `laborTraining`, `federalEntity` et `issueDate`. Les champs vides valent `null`.

### Headers

| Nom | Valeur |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Nom | Type | Requis | Description | Exemple |
| --- | --- | --- | --- | --- |
| `folio` | string | Oui | Folio imprimé sur le certificat électronique. 4 à 64 caractères. | `SIGED10000001` |
| `fullName` | string | Non | Nom complet attendu. Une non-correspondance retourne 409 `name_mismatch`. Ignoré lorsque `curp` est aussi envoyé. 3 à 160 caractères. | `Ana Lopez Ruiz` |
| `curp` | string | Non | CURP de la personne. Lorsqu'il est envoyé, il remplace `fullName`. 17 à 18 caractères. | `LOPE900501HDFGRN01` |

### Notes

- `folio` est obligatoire. `fullName` et `curp` sont des contrôles optionnels du titulaire. Lorsque les deux sont envoyés, `curp` est utilisé et `fullName` est ignoré.
- Un folio absent du registre retourne **404**. Un nom ou un CURP qui n'appartient pas à ce certificat retourne **409** `name_mismatch`.
- Les résultats sont mis en cache jusqu'à 7 jours.
- Le folio sandbox `SIGED10000001` retourne le certificat d'exemple pour `ANA LOPEZ RUIZ`. `fullName=Ana Lopez Ruiz` retourne aussi 200.
- `fullName=Maria Perez` sur ce folio retourne **409** `name_mismatch`.
- Le folio `FOLIO90040401` retourne **404**.
- `curp=LOPE900501HDFGRN01` avec n'importe quel `fullName` retourne 200, car le CURP l'emporte. `curp=LOPE900404HDFNTF01` retourne **404**.
- Un `folio` manquant retourne **409** `MissingParameter`.
- Lorsque le registre est injoignable, la réponse est **409** `Endpoint_out_of_service`. Réessayez plus tard.
- Voir aussi : [Citoyen mexicain (CURP)](/verifik-fr/identity/mexico), [Mexique — Licence professionnelle](/verifik-fr/identity/mexico-cedula-profesional), [Mexique — Licence de professionnel de santé](/verifik-fr/identity/mexico-health-worker).
