# Colombie — Statut de la cédula (CC)

La consultation du **statut de la cédula en Colombie** lit la vigencia de la Registraduría. Envoyez `documentNumber`. La réponse indique si le numéro existe et si le titulaire est enregistré comme vivant, avec le libellé publié par le registre. Utilisez-la lorsqu'une entrée en relation exige l'état courant de la CC avant une recherche d'identité plus large.

## Ce que l'appel renvoie

- `documentType` — CC
- `documentNumber` — la cédula envoyée
- `exists` — le registre a-t-il le numéro
- `isAlive` — true, false ou null
- `documentStatus` — le libellé de vigencia du registre

## Cas d'usage

- Confirmez qu'une CC est au registre avant d'ouvrir un compte.
- Séparez un dossier de personne décédée d'une cédula vigente pendant le KYC.
- Conservez le libellé de statut à côté du numéro.

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/co/cedula/vigencia
```

Une réponse réussie contient `documentType` (CC), `documentNumber`, `exists`, `isAlive` et `documentStatus`. `exists` vaut false lorsque le registre indique que le numéro n'existe pas. `isAlive` vaut true, false ou null si la source ne tranche pas. Utilisez-la dans un dossier KYC qui a besoin de la vigencia courante.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Oui** | `1121329661` | Cédula de ciudadanía colombienne, 5 à 10 chiffres, sans espaces ni ponctuation. |

### Notes

- `documentNumber` est obligatoire et doit compter 5 à 10 caractères.
- `isAlive` peut valoir null si le registre renvoie un statut qui ne tranche pas la vie ou le décès.
- Cette route est la consulta de vigencia. Elle ne remplace pas un profil citoyen complet.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `documentNumber: "1121329661"` | 200 avec les champs ci-dessus. |
| Valeur obligatoire absente | Omit `documentNumber` | 409 MissingParameter. |
| Valeur inconnue | `documentNumber: "0000000000"` | 404 NotFound lorsque la source n'a pas l'enregistrement. |

401 when the bearer token is missing or rejected.
