# Norvège — Vérification d'identité et d'entreprise individuelle (KYC)

La **vérification d'identité et d'entreprise individuelle de Norvège** interroge une personne ou un entrepreneur individuel dans la source officielle de cet identifiant (ORGNR). Envoyez ce numéro dans `documentNumber`. Utilisez-la quand l'entrée en relation a besoin du nom légal, du statut d'enregistrement et des attributs d'identité publiés par la source.

`documentNumber` est obligatoire. `documentType` vaut `ORGNR` par défaut. Omettez-le pour garder cette valeur, ou envoyez `ORGNR` explicitement.

## Ce que renvoie le registre

- Nom légal de la personne ou de l'entreprise individuelle
- Statut d'enregistrement
- Identifiant interrogé
- Attributs d'identité officiels publiés par la source

## Cas d'usage

- Confirmer un entrepreneur individuel ou une personne inscrite en Norvège lors de l'entrée en relation.
- Rapprocher le nom légal du dossier et l'identifiant officiel.
- Conserver le statut d'enregistrement et les attributs d'identité publiés par la source officielle.

---

## Référence de l'API

### Point d'accès

```http
GET https://api.verifik.co/v2/no/citizen
```

Interrogez la source officielle d'identité et d'entreprise individuelle de Norvège avec `documentNumber`. `documentType` choisit la famille d'identifiant (ORGNR). Une réponse réussie contient le nom légal, le statut d'enregistrement, l'identifiant envoyé et les attributs d'identité officiels publiés par la source. Elle sert au KYC d'une personne ou d'une entreprise individuelle. L'exemple montre ces champs. Les valeurs réelles viennent de la source officielle.

### En-têtes

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | Jeton JWT d'authentification du client |

### Paramètres

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Oui** | `974760673` | Numéro officiel d'identité ou de contribuable de la personne ou de l'entreprise individuelle (ORGNR). |
| `documentType` | string | Non | `ORGNR` | Identifiant du type de document. La valeur par défaut est `ORGNR`. |

### Remarques

- **Format de l'identifiant.** L'organisasjonsnummer comporte 9 chiffres. Envoyez uniquement les chiffres, sans espaces.
- Identifiant du type de document. La valeur par défaut est `ORGNR`.
- Le libellé d'état de l'exemple illustre le champ. Le registre réel renvoie son propre libellé, éventuellement dans la langue locale.
- Envoyez `documentNumber` et, lorsque vous devez nommer la famille d'identifiant, `documentType`. Ce sont les paramètres client de cette route.
- Le JSON d'exemple illustre les champs ci-dessus. Un appel réel renvoie la fiche du registre pour l'identifiant envoyé.

## Jeux d'essai sandbox

Avec le compte en mode sandbox, les mêmes paramètres exercent cette route. Le tableau décrit la réponse documentée pour chaque cas.

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| **Identifiant connu** | `documentType: "ORGNR"`, `documentNumber: "974760673"` | 200 avec le nom légal, le statut, l'identifiant et l'adresse ou les attributs d'identité lorsque la source détient le numéro. |
| **documentNumber absent** | Omettre `documentNumber` | 409 `MissingParameter` si `documentNumber` est omis. |
| **Numéro inconnu** | `documentNumber: "000000000"` | 404 `NotFound` lorsque le registre n'a pas de fiche pour ce numéro. |

401 lorsque le jeton bearer est absent ou refusé.
