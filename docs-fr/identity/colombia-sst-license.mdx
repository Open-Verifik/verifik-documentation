# Colombie — Licence de sécurité et santé au travail (SST)

La consultation de **licence SST** lit les licences de sécurité au travail et les cartes d'applicateur technique pour un numéro d'identité colombien. `documentNumber` est obligatoire. Un résultat liste chaque licence avec son type, sa résolution ou son numéro de carte et la date.

## Ce que l'appel renvoie

- `licenses[]` avec `licenseType`, résolution ou numéro de carte et `issueDate`
- `totalLicenses`
- `status` et `isRegistered`

## Cas d'usage

- Contrôlez la licence SST avant l'entrée d'un prestataire sur site.
- Voyez la licence de personne physique et la carte technique.
- Conservez le numéro de résolution dans le dossier fournisseur.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/co/sst/licencia
```

La réponse contient `fullName`, `profession`, `totalLicenses` et `licenses`. Sans licence ni carte, c'est un 404 `NotFound`.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Oui** | `52111222` | Numéro d'identité colombien, 5 à 15 caractères, pour lire les licences SST et les cartes techniques. |

### Notes

- `documentNumber` est obligatoire.
- Une identité sans licence SST ni carte technique est un HTTP 404.
- `documentType` facultatif accepte `CC`, `CE`, `TI`, `PEP` ou `PPT`.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `documentNumber: "52111222"` | 200 avec une ou plusieurs licences. |
| Valeur obligatoire absente | Omit `documentNumber` | 409 MissingParameter. |
| Valeur inconnue | `documentNumber: "000000000"` | 404 NotFound si aucune source n'a de ligne. |

401 when the bearer token is missing or rejected.
