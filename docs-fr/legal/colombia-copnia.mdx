# Colombie — Licences COPNIA par document

Verifik interroge **COPNIA** (*Consejo Profesional Nacional de Ingeniería*) avec **`documentType`** et **`documentNumber`**. La source live est le portail de certificat de validité COPNIA. Utilisez cet endpoint pour le **recrutement**, l’**habilitation** et la **conformité** des ingénieurs en Colombie.

## Ce que renvoie l’API

- Champs d’**identité** : `documentType`, `documentNumber`, `firstName`, `lastName`, `fullName`, `arrayName`
- **`licenses[]`** — inscriptions professionnelles trouvées pour cette personne
- Chaque licence peut inclure **`licenseNumber`**, **`licenseStatus`**, **`licenseType`**, **`profession`**, **`resolutionDate`**, **`resolutionNumber`**
- Réponse Verifik **signée**

### Endpoint

```
GET https://api.verifik.co/v2/co/copnia
```

Envoyez **`documentType`** et **`documentNumber`** en **query**. Le handler renvoie la personne et un tableau `licenses`. Les champs de détail (`licenseStatus`, `licenseType`, `resolutionDate`, `resolutionNumber`) sont hydratés pour **10** licences au plus ; les lignes suivantes ne conservent que `licenseNumber` et `profession`.

### En-têtes

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Paramètres

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `documentType` | string | Oui | Un de **`CC`**, **`CE`**, **`PA`**, **`PEP`**, **`PE`**, **`PPT`**, **`TI`**, **`NIT`**. | `CC` |
| `documentNumber` | string | Oui | Numéro de document sans espaces ni ponctuation (minimum **5** caractères). | `80176161` |

## Fonctionnalités

- Types acceptés : **CC**, **CE**, **PA**, **PEP**, **PE**, **PPT**, **TI**, **NIT**
- **GET** uniquement, paramètres de requête
- Le **sandbox** renvoie un payload COPNIA pour les documents de test
- Réponses **signées**, facturées comme feature hybride `apiRequest`

## Cas d’usage

- **Recrutement** et habilitation d’ingénieurs
- Contrôles de **conformité** avant attribution de contrats
- **Onboarding** lorsqu’une matrícula COPNIA est exigée

### Remarques

- Exemple sandbox : **`CC` / `80176161`**. La licence sandbox est **`091132-0839078 CNDC`**.
- Au plus **10** licences sont hydratées. Les lignes supplémentaires gardent `licenseNumber` et `profession`. Un échec de détail est silencieux (la ligne de liste reste).
- Une panne de source ou de session peut renvoyer **`409`** avec `timeout_data_source`.
- Traitez la réponse comme **donnée personnelle sensible**.
- Pour une matrícula unique, utilisez [COPNIA par licence](/verifik-fr/legal/colombia-copnia-license).
