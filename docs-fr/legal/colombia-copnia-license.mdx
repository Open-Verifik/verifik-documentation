# Colombie — Licence COPNIA par matrícula

Verifik interroge **COPNIA** (*Consejo Profesional Nacional de Ingeniería*) avec un seul **`licenseNumber`** (matrícula). Utilisez-le lorsque vous avez déjà le numéro d’inscription et besoin du titulaire et du statut.

## Ce que renvoie l’API

- Champs d’**identité** : `documentType`, `documentNumber`, `firstName`, `lastName`, `fullName`, `arrayName`
- Champs de licence aplatis : **`licenseNumber`**, **`licenseStatus`**, **`licenseType`**, **`profession`**, **`resolutionDate`**, **`resolutionNumber`**
- Réponse Verifik **signée** (pas de tableau `licenses[]`)

### Endpoint

```
GET https://api.verifik.co/v2/co/copnia/matricula
```

Envoyez **`licenseNumber`** en **query**. Le handler renvoie la personne et les six champs de licence sur le même objet. Une valeur typique ressemble à `091132-0839078 CNDC` (6–40 caractères).

### En-têtes

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Paramètres

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `licenseNumber` | string | Oui | Numéro d’inscription COPNIA (matrícula), **6–40** caractères. Les espaces sont autorisés. | `091132-0839078 CNDC` |

## Fonctionnalités

- Recherche par **matrícula** sans numéro de document
- **GET** uniquement, paramètres de requête
- Le **sandbox** renvoie un payload COPNIA fixe pour la licence d’exemple
- Réponses **signées**, facturées comme feature hybride `apiRequest`

## Cas d’usage

- Confirmer une matrícula **imprimée ou transmise**
- Revérifier le **statut** (`VIGENTE` ou autre) pendant l’onboarding
- Recouper une licence trouvée via [COPNIA par document](/verifik-fr/legal/colombia-copnia)

### Remarques

- Exemple sandbox : **`091132-0839078 CNDC`**. La personne associée est **`CC` / `80176161`**.
- Une valeur qui se normalise en chaîne vide renvoie **`409`** (`invalid_license_number`).
- Une panne de source ou de session peut renvoyer **`409`** avec `timeout_data_source`.
- Traitez la réponse comme **donnée personnelle sensible**.
