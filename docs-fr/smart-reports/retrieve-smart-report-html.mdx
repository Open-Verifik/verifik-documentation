Récupérez le HTML rendu pour un `SmartReport`, accompagné de ses identifiants liés `batchId`, `templateId`, `rowIndex`, d'un `verificationScore` facultatif et du payload `row` correspondant (`rowIndex`, `status`, `inputData`, `results`, `errors`).

**Important** : Ce point de terminaison répond avec `Content-Type: application/json` et renvoie la chaîne HTML dans `data.html`, et **non** sous forme de document brut `text/html`.

### Point de terminaison

```
GET https://api.verifik.co/v2/smart-reports/{id}/html
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-reports/{id}/html` en utilisant votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                                 |
| --------------- | ---------------------- | ------------------------------------------- |
| `Accept`        | `application/json`     | Format de réponse en enveloppe JSON.        |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT limité au client (`authUser.clientId`). |

### Paramètres

| Nom            | Emplacement | Type    | Requis  | Description |
| -------------- | ----------- | ------- | ------- | ----------- |
| `id`           | chemin      | string  | **Oui** | ObjectId du `SmartReport`. |
| `rowIndex`     | requête     | integer | Non     | Index de ligne basé sur zéro (`>= 0`). |
| `preview`      | requête     | boolean | Non     | Effectue le rendu en mode aperçu lorsqu'il vaut `true`. |
| `score`        | requête     | boolean | Non     | Indique s'il faut calculer et inclure `verificationScore` dans `data`. |
| `scoreProfile` | requête     | string  | Non     | Identifiant du profil de notation utilisé lorsque `score` est activé (max `64` caractères). |

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	id := "6801a2b3c4d5e6f7a8b9c0d1"
	params := url.Values{}
	params.Set("rowIndex", "0")
	params.Set("preview", "false")
	params.Set("score", "true")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-reports/"+id+"/html?"+params.Encode(), nil)
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}
```

#### Codes d'erreur

| Statut | Code / Type d'erreur | Cause |
| ------ | -------------------- | ----- |
| `401` | `Unauthorized` | JWT manquant ou invalide. |
| `403` | `Forbidden` | Exécution partagée x402 tentée ; utilisez votre propre JWT par client. |
| `404` | `not_found` | L'ID du rapport n'existe pas ou appartient à un autre client. |
| `404` | `template_not_found` | Le modèle lié est introuvable. |
| `409` | `MissingParameter` | La validation Joi a échoué sur les paramètres de requête ou de chemin. |
| `409` | `row_not_found` | Le `rowIndex` demandé n'existe pas dans le lot. |
| `409` | `unknown_score_profile` | Le `scoreProfile` fourni n'est pas reconnu. |
| `422` | `UnprocessableEntity` | Erreur de validation Mongoose. |

- **Équivalent MCP** : Les agents IA peuvent récupérer le HTML rendu et la structure de la ligne via l'outil MCP `smart_report_get_html`. Consultez [MCP et Agents IA](/verifik-fr/smart-reports/mcp-and-ai-agents).
- **Webhooks** : Le chemin `htmlUrl` (`/v2/smart-reports/{id}/html`) est inclus dans les réponses de [Exécuter un Smart Report](/verifik-fr/smart-reports/run-a-smart-report), [Récupérer un Smart Report](/verifik-fr/smart-reports/retrieve-a-smart-report) et [Générer le PDF d'un Smart Report](/verifik-fr/smart-reports/generate-smart-report-pdf). Consultez [Webhooks SmartReports](/verifik-fr/resources/smart-reports-webhooks).

### Notes

- Comme la réponse HTTP utilise `application/json`, extrayez `data.html` du payload JSON avant de l'intégrer dans une webview, une iframe ou un moteur de rendu PDF.
- `data.verificationScore` est présent lorsque `score=true` est passé.
- `data.row` vaut `null` si aucun objet de ligne de lot n'est associé au contexte.
