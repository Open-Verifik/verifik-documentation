Récupérez les statistiques agrégées d'exécution sur l'ensemble des enregistrements `SmartBatch` appartenant à une `BatchConfiguration` spécifique sur le compte client authentifié. La réponse renvoie le nombre total de lots, les totaux d'achèvement des lignes ainsi qu'une répartition par statut sur `"draft"`, `"pending"`, `"processing"`, `"completed"`, `"failed"` et `"cancelled"`.

La consultation des statistiques de configuration n'exécute aucune vérification et ne consomme pas de crédits.

### Point de terminaison

```text
GET https://api.verifik.co/v2/smart-batches/stats/{configId}
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/stats/{configId}` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom        | Type   | Requis | Description |
| ---------- | ------ | ------ | ----------- |
| `configId` | string | Oui    | ObjectId `BatchConfiguration` pour lequel agréger les statistiques des lots. |

### Notes

- Les statistiques sont limitées au client authentifié (`clientId` de votre JWT).
- `pendingRows` est calculé selon `totalRows - completedRows - failedRows - partialRows`.
- Pour inspecter individuellement les lots appartenant à cette configuration, passez `batchConfiguration` à [Lister les Smart Batches](/verifik-fr/smart-reports/list-smart-batches).
