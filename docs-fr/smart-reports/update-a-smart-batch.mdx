Mettez à jour des champs d'un `SmartBatch` existant détenu par le client authentifié. Vous pouvez modifier `name`, `status`, `executor` ou remplacer `rows`. Lorsque `rows` est fourni, le serveur recalcule `totalRows`, `completedRows`, `failedRows` et `partialRows`, et synchronise les instantanés de lignes externes.

Utilisez le point de terminaison dédié [Mettre en pause un Smart Batch](/verifik-fr/smart-reports/pause-a-smart-batch) pour faire passer un lot à `"paused"`. La modification de `executor` ne prend effet que lorsque le lot est actuellement au statut `"draft"`, `"pending"` ou `"cancelled"`.

### Point de terminaison

```text
PUT https://api.verifik.co/v2/smart-batches/{id}
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom  | Type   | Requis | Description |
| ---- | ------ | ------ | ----------- |
| `id` | string | Oui    | ObjectId `SmartBatch` à mettre à jour. |

### Corps de la requête

| Nom        | Type     | Requis | Description |
| ---------- | -------- | ------ | ----------- |
| `name`     | string   | Non    | Nom affiché mis à jour du lot. `150` caractères maximum. |
| `status`   | string   | Non    | Valeurs autorisées : `"draft"`, `"pending"`, `"processing"`, `"completed"`, `"failed"` ou `"cancelled"`. Utilisez `POST /v2/smart-batches/{id}/pause` pour `"paused"`. |
| `executor` | string   | Non    | Valeurs autorisées : `"queue"`, `"featureRunner"` ou `"browser"`. Ne prend effet que si le statut actuel du lot est `"draft"`, `"pending"` ou `"cancelled"`. |
| `rows`     | object[] | Non    | Liste de lignes de remplacement. Le format encapsulé requiert `rowIndex` et `inputData` et accepte facultativement `status`, `results`, `errors` et `processedAt` ; les lignes plates sont normalisées automatiquement. |

Les clés de corps inconnues sont rejetées par la validation Joi avec `409 MissingParameter`.

### Notes

- `"paused"` n'est pas accepté dans `PUT /v2/smart-batches/{id}` ; appelez plutôt [Mettre en pause un Smart Batch](/verifik-fr/smart-reports/pause-a-smart-batch).
- La mise à jour de `executor` est ignorée sauf si le lot est actuellement au statut `"draft"`, `"pending"` ou `"cancelled"`.
- Pour ajouter de nouvelles lignes à un lot existant sans remplacer les lignes actuelles, utilisez [Ajouter des lignes à un Smart Batch](/verifik-fr/smart-reports/append-smart-batch-rows).
