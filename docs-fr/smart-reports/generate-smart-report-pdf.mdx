Effectuez le rendu d'un PDF pour un `SmartReport` existant à l'aide de `"puppeteer"` ou `"pdfkit"`, calculez `verificationScore` en option et recevez le tampon PDF encodé en base64 accompagné de `downloadUrl` et `htmlUrl`.

En cas de succès, ce point de terminaison passe le rapport à `status: "generated"`, enregistre `verificationScoreSummary` lorsque la notation est activée et émet le webhook `smart_batch_report_generated`. Si la génération du PDF échoue, le rapport passe à `status: "failed"` et le webhook `smart_batch_report_generation_failed` est émis.

### Point de terminaison

```
POST https://api.verifik.co/v2/smart-reports/{id}/generate
```

Ce point de terminaison accepte des payloads JSON jusqu'à **64 Mo** (afin de prendre en charge les documents `printHtml` personnalisés). Il est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-reports/{id}/generate` en utilisant votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                                                |
| --------------- | ---------------------- | ---------------------------------------------------------- |
| `Content-Type`  | `application/json`     | Format du payload de la requête (limite de 64 Mo).         |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT limité au client (`authUser.clientId`).                |

### Paramètres

| Nom  | Type   | Requis  | Description |
| ---- | ------ | ------- | ----------- |
| `id` | string | **Oui** | ObjectId du `SmartReport`. |

### Corps de la requête

| Nom            | Type    | Requis | Description |
| -------------- | ------- | ------ | ----------- |
| `engine`       | string  | Non    | Moteur de rendu PDF : `"pdfkit"` ou `"puppeteer"`. |
| `rowIndex`     | number  | Non    | Index de ligne basé sur zéro provenant du `SmartBatch` lié. Vaut `0` par défaut. |
| `printHtml`    | string  | Non    | Chaîne HTML complète (max `64000000` caractères) utilisée pour les modèles non thématiques contenant `<html`. |
| `score`        | boolean | Non    | Indique s'il faut calculer `verificationScore` et enregistrer `verificationScoreSummary` sur le rapport. |
| `scoreProfile` | string  | Non    | Identifiant du profil de notation utilisé lorsque `score` est activé. Max `64` caractères. |

#### Comportement de rendu et de notation

- **Sélection de ligne par défaut** : Lorsque `rowIndex` est omis, la génération utilise la ligne `0` par défaut. Demander une ligne hors limites renvoie `409 Conflict` (`row_not_found`).
- **HTML personnalisé (`printHtml`)** : Lorsque vous travaillez avec des modèles non thématiques fournissant un balisage `<html` complet, passez `printHtml` (jusqu'à `64000000` caractères).
- **Score de vérification** : Définissez `score: true` (et éventuellement `scoreProfile`) pour calculer `verificationScore`, le renvoyer au niveau racine de la réponse et enregistrer `verificationScoreSummary` sur le `SmartReport`. Les profils inconnus échouent avec `409 Conflict` (`unknown_score_profile`).

#### Codes d'erreur

| Statut | Code / Type d'erreur | Cause |
| ------ | -------------------- | ----- |
| `401` | `Unauthorized` | JWT manquant ou invalide. |
| `403` | `Forbidden` | Exécution partagée x402 tentée ; utilisez votre propre JWT par client. |
| `404` | `not_found` | L'ID du rapport n'existe pas ou appartient à un autre client. |
| `404` | `template_not_found` | Le modèle lié est introuvable. |
| `404` | `batch_not_found` | Le `SmartBatch` lié est introuvable. |
| `409` | `MissingParameter` | La validation Joi a échoué sur un ou plusieurs champs. |
| `409` | `row_not_found` | Le `rowIndex` demandé n'existe pas dans le lot. |
| `409` | `unknown_score_profile` | Le `scoreProfile` demandé n'est pas reconnu. |
| `422` | `UnprocessableEntity` | Erreur de validation Mongoose. |
| `500` | `InternalServerError` | Échec du rendu PDF ou du traitement interne (marque le rapport `"failed"` et émet `smart_batch_report_generation_failed`). |

### Intégration Webhooks et MCP

- **Webhooks** : Émet `smart_batch_report_generated` en cas de création PDF réussie, ou `smart_batch_report_generation_failed` en cas d'erreur de rendu (et met à jour `status` à `"failed"`). Consultez [Webhooks SmartReports](/verifik-fr/resources/smart-reports-webhooks).
- **Équivalent MCP** : Les agents IA peuvent générer le PDF d'un rapport directement via l'outil MCP `smart_report_generate_pdf`. Consultez [MCP et Agents IA](/verifik-fr/smart-reports/mcp-and-ai-agents).

### Notes

- `pdf.buffer` contient les octets PDF encodés en base64 directement dans la réponse JSON ; si vous préférez un flux PDF binaire, appelez [Télécharger le PDF d'un Smart Report](/verifik-fr/smart-reports/download-smart-report-pdf).
- `verificationScore` est inclus dans la réponse lorsque `score` est activé.
