Mettez à jour un modèle Smart Report personnalisé appartenant à votre compte client. Envoyez n'importe quel sous-ensemble de métadonnées modifiables, de `sections` de mise en page, de `reportTheme`, de `sampleData` ou d'options de rendu PDF ; les champs omis du payload conservent leurs valeurs existantes.

Dans les pipelines headless et IA, utilisez ce point de terminaison pour itérer sur les mises en page générées par [Générer la mise en page d'un modèle](/verifik-fr/smart-reports/generate-template-layout), actualiser les ressources de marque (`logo`, `primaryColor`, `customFonts`), mettre à jour les liaisons `SmartBatch` ou basculer `isActive`. Les modèles intégrés `"System"` sont en lecture seule et renvoient `403` (`system_template_readonly`) s'ils sont ciblés.

### Point de terminaison

```
PUT https://api.verifik.co/v2/smart-report-templates/{id}
```

Le proxy Smart-Agent (`https://ai.verifik.co`) expose les mêmes chemins `/v2/...` et exige votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`.

### En-têtes

| Nom           | Valeur                 |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Paramètres

| Nom  | Type   | Requis | Description                      |
| ---- | ------ | ------ | -------------------------------- |
| `id` | string | Oui    | ObjectId du modèle Smart Report. |

### Corps de la requête

Tous les champs du corps sont facultatifs lors de la mise à jour.

| Nom                   | Type             | Requis | Description                                                                                                                                      |
| --------------------- | ---------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `name`                | string           | Non    | Nom d'affichage mis à jour du modèle. Maximum `150` caractères.                                                                                  |
| `description`         | string           | Non    | Description mise à jour du modèle. Maximum `500` caractères.                                                                                     |
| `batchConfiguration`  | string           | Non    | ObjectId d'une configuration `SmartBatch` associée.                                                                                              |
| `country`             | string           | Non    | Identifiant ou libellé du pays. Maximum `60` caractères.                                                                                         |
| `category`            | string           | Non    | Domaine de vérification : `"citizen"`, `"company"` ou `"vehicle"`.                                                                               |
| `isActive`            | boolean          | Non    | Activer ou désactiver le modèle.                                                                                                                 |
| `logo`                | string           | Non    | URL du logo de marque ou URI de données base64.                                                                                                  |
| `primaryColor`        | string           | Non    | Couleur hexadécimale d'accentuation principale.                                                                                                  |
| `identityColor`       | string           | Non    | Couleur hexadécimale d'accentuation secondaire/d'identité.                                                                                       |
| `pageBackgroundColor` | string           | Non    | Couleur hexadécimale d'arrière-plan de page.                                                                                                     |
| `header`              | object           | Non    | Configuration personnalisée de mise en page et de contenu de l'en-tête.                                                                          |
| `footer`              | object           | Non    | Configuration personnalisée de mise en page et de contenu du pied de page.                                                                       |
| `legend`              | string           | Non    | Texte de légende en pied de page ou mention de conformité. Maximum `2000` caractères.                                                           |
| `legendPosition`      | string           | Non    | Alignement de la légende : `"left"`, `"center"` ou `"right"`.                                                                                    |
| `termsAndConditions`  | string           | Non    | Texte des conditions générales légales. Maximum `4000` caractères.                                                                               |
| `termsPosition`       | string           | Non    | Alignement des conditions : `"left"`, `"center"` ou `"right"`.                                                                                   |
| `sections`            | object[]         | Non    | Tableau d'objets `ReportSection` (`id`, `type`, `order`, `dataPath`, `label`, `staticContent`, `columns`, `columnsPerRow`, `keyOverrides`, `valueRules`, `chartKind`, `style`, `condition`, `frame`, etc.). |
| `pageSize`            | string           | Non    | Format de papier PDF : `"A4"`, `"Letter"` ou `"Legal"`.                                                                                          |
| `layoutVersion`       | integer          | Non    | Version du moteur de mise en page : `1` ou `2`.                                                                                                  |
| `orientation`         | string           | Non    | Orientation de la page : `"portrait"` ou `"landscape"`.                                                                                          |
| `margins`             | object           | Non    | Objet de marges `{ "top": 40, "right": 40, "bottom": 40, "left": 40 }`.                                                                          |
| `pdfEngine`           | string           | Non    | Moteur de rendu PDF : `"puppeteer"` ou `"pdfkit"`.                                                                                               |
| `showPageNumbers`     | boolean          | Non    | Afficher les numéros de page sur les PDF générés.                                                                                                |
| `pageNumberPosition`  | string           | Non    | Position du numéro de page : `"top-left"`, `"top-center"`, `"top-right"`, `"bottom-left"`, `"bottom-center"` ou `"bottom-right"`.                |
| `pageNumberDivider`   | boolean / string | Non    | Configuration du séparateur de numéro de page.                                                                                                   |
| `watermark`           | object           | Non    | Paramètres du calque de filigrane.                                                                                                               |
| `security`            | object           | Non    | Paramètres de protection PDF `{ "enabled": true, "password": "..." }`. Passer `"******"` ou omettre `password` conserve le mot de passe chiffré existant. |
| `signature`           | object           | Non    | Configuration du bloc de signature.                                                                                                              |
| `logoSettings`        | object           | Non    | Configuration de la taille et du placement du logo.                                                                                              |
| `sheetImages`         | object[]         | Non    | Ressources d'images intégrées au modèle. Maximum `12` éléments.                                                                                  |
| `customFonts`         | object[]         | Non    | Déclarations de polices personnalisées (Google Fonts, URL externe ou fichier téléversé). Maximum `6` éléments.                                   |
| `headerLogos`         | object[]         | Non    | Logos supplémentaires affichés dans l'en-tête. Maximum `16` éléments.                                                                            |
| `bodyTopPadding`      | number           | Non    | Espacement supérieur appliqué au corps du document, de `0` à `600`.                                                                              |
| `sampleData`          | object           | Non    | Payload de vérification d'exemple stocké avec le modèle pour les aperçus et téléchargements d'exemples.                                          |
| `endpointDesign`      | object           | Non    | Métadonnées de présentation spécifiques au point de terminaison.                                                                                 |
| `reportTheme`         | string / object  | Non    | ID de préréglage de thème (`"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"`) ou objet (`id`, `scoreScale`, `scoreEnabled`, `scoreProfile`, `locale`, `density`, `eyebrow`, `coverTitle`, `headlines`, `legalNote`, `showVerifiedBadge`, `showWeights`, `showDeductions`, `showFields`, `showHowItWorks`, `blocks`, `tokens`). |

### Notes

- Passer `security.password: "******"` ou omettre `security.password` conserve le mot de passe chiffré existant du modèle au lieu de l'écraser.
- Les modèles intégrés `"System"` ne peuvent pas être mis à jour (`403` `system_template_readonly`). Créez une copie personnalisée via [Créer un modèle de rapport](/verifik-fr/smart-reports/create-a-report-template) lorsque vous personnalisez un modèle de démarrage système.
- Enregistrez les assistants d'aperçu (`scoreScale`, `themeTokens`, `scoreSettings`) sous `reportTheme` (`scoreScale`, `tokens`, `scoreEnabled`/`scoreProfile`) lors de la sauvegarde des modifications.
