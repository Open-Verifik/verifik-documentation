Listez les points de terminaison du catalogue Verifik disposant de réponses simulées préconstruites en sandbox dans l'inventaire de conception de modèles. Filtrez par `country` ou par requête de recherche (`q`) afin de découvrir les identifiants `code` des points de terminaison et les `inputs` attendus.

Dans les générateurs de rapports headless et les pipelines d'agents IA, utilisez ce point de terminaison de découverte du catalogue pour sélectionner des jeux de données fictifs réalistes sans exécuter de requêtes réelles facturables ni manipuler de données personnelles (PII) de production. Transmettez n'importe quel `code` renvoyé à [Récupérer une réponse simulée](/verifik-fr/smart-reports/retrieve-simulated-response) afin d'obtenir des payloads d'exemple pour [Introspecter des données d'exemple](/verifik-fr/smart-reports/introspect-sample-data), [Générer la mise en page d'un modèle](/verifik-fr/smart-reports/generate-template-layout) ou [Prévisualiser le HTML d'un modèle](/verifik-fr/smart-reports/preview-template-html).

### Point de terminaison

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses
```

Le proxy Smart-Agent (`https://ai.verifik.co`) expose les mêmes chemins `/v2/...` et exige votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`.

### En-têtes

| Nom           | Valeur                 |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Paramètres

| Nom       | Type   | Requis | Description                                                             |
| --------- | ------ | ------ | ----------------------------------------------------------------------- |
| `country` | string | Non    | Filtrer les points de terminaison simulés par pays.                     |
| `q`       | string | Non    | Chaîne de recherche pour filtrer les points de terminaison par nom, code ou métadonnées. |

### Notes

- L'interrogation des réponses simulées n'exécute aucune consultation réelle du catalogue et ne consomme pas de crédits.
- Utilisez le `code` de chaque élément avec [Récupérer une réponse simulée](/verifik-fr/smart-reports/retrieve-simulated-response) pour récupérer les payloads complets `dataSample` et `emptySample`.
