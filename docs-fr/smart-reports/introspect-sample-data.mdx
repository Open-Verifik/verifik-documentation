Inspectez un payload de vérification `sampleData` et recevez une carte structurée des chemins de champs, des formes de valeurs, des choix `sectionType` recommandés, des types de sections alternatifs, des colonnes de tableau suggérées et des propositions de liaison.

Dans la création de rapports headless et les pipelines d'agents IA, appelez ce point de terminaison juste après avoir récupéré un payload depuis [Récupérer une réponse simulée](/verifik-fr/smart-reports/retrieve-simulated-response) ou capturé une ligne `SmartBatch`. Au lieu de deviner les chaînes `dataPath` ou d'écrire une logique fragile de parcours JSON, votre interface ou votre agent peut utiliser les `nodes` et métadonnées `batch` inspectés pour construire directement des `sections` valides ou enrichir le contexte du `prompt` pour [Générer la mise en page d'un modèle](/verifik-fr/smart-reports/generate-template-layout). L'analyseur explore jusqu'à une profondeur de `5` et jusqu'à `600` nœuds.

### Point de terminaison

```
POST https://api.verifik.co/v2/smart-report-templates/introspect
```

Le proxy Smart-Agent (`https://ai.verifik.co`) expose les mêmes chemins `/v2/...` et exige votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`.

### En-têtes

| Nom           | Valeur                 |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Corps de la requête

| Nom          | Type   | Requis | Description                                                                                                                   |
| ------------ | ------ | ------ | ----------------------------------------------------------------------------------------------------------------------------- |
| `sampleData` | object | Oui    | Payload de vérification d'exemple avec `batchName` (string), `rowIndex` (number), `inputData` (object) et `results` (object) facultatifs. |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"

func main() {
	body, _ := json.Marshal(map[string]interface{}{
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{
					"fullName": "Mateo Rojas",
					"status":   "active",
				},
				"fines": []map[string]interface{}{
					{"code": "C02", "amount": 580000, "status": "pending"},
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/introspect", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notes

- Le parcours s'arrête à une profondeur de `5` et plafonne à `600` nœuds. Lorsqu'un payload très volumineux atteint cette limite, `truncated` vaut `true`.
- Ce point de terminaison est en lecture seule et sans état ; il n'enregistre aucun modèle et ne consomme aucun crédit de vérification.
