Récupérez la réponse simulée en sandbox, le contour des champs (`outline`), `dataSample` et `emptySample` pour un `code` de point de terminaison du catalogue découvert via [Lister les réponses simulées](/verifik-fr/smart-reports/list-simulated-responses). Vous pouvez basculer l'état `sample` renvoyé entre des enregistrements renseignés (`"data"`), des résultats vides (`"empty"`) ou des données manquantes (`"missing"`), et contrôler le nombre de lignes des tableaux avec `listSize`.

Dans la conception de modèles headless et les workflows d'assurance qualité automatisée, ce point de terminaison vous permet de valider la manière dont votre modèle restitue les cas limites — tels que des tableaux vides, des champs facultatifs absents ou des tableaux multi-pages (`listSize` de `2` à `30`) — avant d'enregistrer ou de déployer un modèle vers vos pipelines `SmartBatch` de production.

### Point de terminaison

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses/{code}
```

Le proxy Smart-Agent (`https://ai.verifik.co`) expose les mêmes chemins `/v2/...` et exige votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`.

### En-têtes

| Nom           | Valeur                 |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Paramètres

| Nom            | Type    | Emplacement | Requis | Description                                                                                  |
| -------------- | ------- | ----------- | ------ | -------------------------------------------------------------------------------------------- |
| `code`         | string  | Chemin      | Oui    | Code du point de terminaison du catalogue issu de [Lister les réponses simulées](/verifik-fr/smart-reports/list-simulated-responses). |
| `availability` | string  | Requête     | Non    | État simulé à placer dans `sample` : `"data"`, `"empty"` ou `"missing"`. Vaut `"data"` par défaut. |
| `listSize`     | integer | Requête     | Non    | Nombre d'éléments synthétiques à générer pour les champs de type tableau/liste. Plage valide : `2` à `30`. |

async function run() {
  const code = "co_cedula";
  const params = new URLSearchParams({

    `https://api.verifik.co/v2/smart-report-templates/simulated-responses/${code}?${params.toString()}`,

      method: "GET",
      headers: {
        Accept: "application/json",
        Authorization: `Bearer ${process.env.VERIFIK_JWT}`,
      },
    }
  );

  console.log(await res.json());

### Notes

- Si `{code}` n'est pas présent dans l'inventaire sandbox, le point de terminaison renvoie HTTP `200` avec `found: false`, des objets `outline` et `sample` vides et un champ explicatif `note`.
- `listSize` accepte des entiers de `2` à `30` et est utile pour tester la pagination PDF multi-pages via [Télécharger un exemple de modèle](/verifik-fr/smart-reports/download-template-sample).
- Ce point de terminaison n'exécute pas de vérifications réelles et ne consomme pas de crédits.
