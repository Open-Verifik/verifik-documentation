Récupérez les modèles de démarrage thématiques intégrés de Verifik, éventuellement filtrés par `theme`. Chaque modèle de démarrage inclut des `sections` préconfigurées, `reportTheme`, `sampleData`, les propriétés de mise en page et les couleurs afin que vous puissiez lancer des rapports prêts pour la production sans assembler d'arborescences de sections de zéro.

Dans les flux d'intégration headless et les agents IA, appelez ce point de terminaison pour choisir un point de départ visuel soigné, prévisualisez-le immédiatement via [Prévisualiser le HTML d'un modèle](/verifik-fr/smart-reports/preview-template-html), personnalisez les couleurs ou logos de marque et enregistrez votre propre modèle modifiable via [Créer un modèle de rapport](/verifik-fr/smart-reports/create-a-report-template).

### Point de terminaison

```
GET https://api.verifik.co/v2/smart-report-templates/theme-starters
```

Le proxy Smart-Agent (`https://ai.verifik.co`) expose les mêmes chemins `/v2/...` et exige votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`.

### En-têtes

| Nom           | Valeur                 |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Paramètres

| Nom     | Type   | Requis | Description                                                                                                                                                     |
| ------- | ------ | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `theme` | string | Non    | Filtre de thème facultatif : `"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"` ou `"smart_enroll_v2"` (alias de `"light_cards"` ; l'utilisation de la valeur canonique `"light_cards"` est recommandée). |

### Notes

- `"smart_enroll_v2"` est accepté comme alias pour `"light_cards"`, bien que le filtrage par l'ID de thème canonique `"light_cards"` soit recommandé.
- Les éléments de démarrage renvoyés ici portent `type: "System"` à titre de référence. Lors de l'enregistrement d'une copie personnalisée via [Créer un modèle de rapport](/verifik-fr/smart-reports/create-a-report-template), envoyez uniquement votre `name` et vos champs de conception (`sections`, `reportTheme`, `sampleData`, couleurs et paramètres PDF).
