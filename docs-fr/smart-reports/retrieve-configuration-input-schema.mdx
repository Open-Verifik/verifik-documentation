Résolvez le contrat d'entrée exact d'une `BatchConfiguration` enregistrée avant de soumettre des lignes. Ce point de terminaison renvoie `preferredReportTemplate` (en se repliant sur le dernier `SmartReportTemplate` actif lié à la configuration), `webhookUrl`, `stepCount`, `estimatedCreditsPerRow`, `requiredFields`, `optionalFields`, un `jsonSchema` standard et une charge utile `exampleInput` prête à être envoyée.

Le résolveur ignore automatiquement les étapes désactivées, les options `dependencyGroup` inactives, les indicateurs internes ainsi que les champs déjà fournis via `parameterDefaults` ou le chaînage d'étapes `visitaFlow` (`{{results.N.field}}`), tout en remappant les noms de colonnes selon `inputFieldMapping`. Cette route est enregistrée avant `/{id}` afin que `/input-schema` soit résolu directement, et elle est également disponible en tant qu'outil MCP `smart_report_get_input_schema`.

### Point de terminaison

```
GET https://api.verifik.co/v2/batch-configurations/{id}/input-schema
```

Également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/batch-configurations/{id}/input-schema` avec votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom | Valeur |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

Le jeton doit être un **JWT client**. Des identifiants manquants ou invalides renvoient `401 Unauthorized`.

### Paramètres

| Nom | Type | Requis | Description |
| ---- | ---- | -------- | ----------- |
| `id` | string | Oui | ObjectId `BatchConfiguration` à inspecter. |

### Notes

- L'inspection du schéma d'entrée n'exécute aucune consultation et ne consomme pas de crédits.
- Si `preferredReportTemplate` n'est pas défini sur la configuration, le serveur se replie sur le dernier `SmartReportTemplate` actif lié à `{id}` (ou `null` s'il n'en existe aucun).
- Lorsque `inputFieldMapping` mappe une colonne d'entrée vers un paramètre API, `requiredFields`, `optionalFields`, `jsonSchema` et `exampleInput` exposent le nom de colonne d'entrée mappé plutôt que le nom brut du paramètre API.
- Les valeurs `{id}` manquantes ou appartenant à un autre client renvoient `404` (`not_found`), contrairement à [Récupérer une configuration de lot](/verifik-fr/smart-reports/retrieve-a-batch-configuration) qui renvoie `200` avec `data: null`.
- Pour les agents IA et les pipelines headless, ce point de terminaison correspond à l'outil MCP `smart_report_get_input_schema`.
