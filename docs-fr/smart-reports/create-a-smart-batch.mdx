Créez un `SmartBatch` lié à une `BatchConfiguration` existante. Vous fournissez un nom affiché `name` et au moins une ligne d'entrée dans `rows`. La création du lot enregistre les lignes d'entrée avec `status: "draft"` et n'exécute aucune étape du catalogue ni ne consomme de crédits tant que l'exécution n'a pas démarré.

Chaque entrée de `rows` accepte soit un objet encapsulé (`{ rowIndex?, inputData }`), soit un objet plat (`{ rowIndex?, ...inputFields }`), que la couche de validation normalise en `{ rowIndex, inputData }`. N'incluez **pas** `status`, `results` ou `errors` lors de la création.

### Point de terminaison

```text
POST https://api.verifik.co/v2/smart-batches
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Corps de la requête

| Nom                  | Type     | Requis | Description |
| -------------------- | -------- | ------ | ----------- |
| `batchConfiguration` | string   | Oui    | ObjectId `BatchConfiguration` définissant les étapes du workflow. |
| `name`               | string   | Oui    | Nom affiché du lot. `150` caractères maximum. |
| `executor`           | string   | Non    | Mode d'exécution : `"queue"`, `"featureRunner"` ou `"browser"`. Lorsqu'il est dérivé de `batchConfiguration`, il est normalisé en `"queue"` ou `"browser"`. |
| `source`             | string   | Non    | Identifiant du produit d'origine : `"smart_batch"` (par défaut) ou `"smart_fleet"`. |
| `rows`               | object[] | Oui    | Tableau d'au moins `1` ligne (`min 1`). Accepte le format encapsulé `{ rowIndex?, inputData }` ou plat `{ rowIndex?, ...inputFields }`. N'envoyez **pas** `status`, `results` ou `errors` lors de la création. |

Les clés inconnues et les propriétés de ligne interdites (`status`, `results`, `errors`) sont rejetées par la validation Joi avec `409 MissingParameter`.

### Notes

- Ne transmettez jamais `status`, `results` ou `errors` dans `rows` lors de la création d'un lot ; les lignes nouvellement créées démarrent toujours au statut `pending`.
- Si `executor` est omis, il est résolu à partir de `batchConfiguration.executor` et normalisé en `"queue"` ou `"browser"`.
- Après la création, appelez [Estimer le coût d'un Smart Batch](/verifik-fr/smart-reports/estimate-smart-batch-cost) pour prévisualiser les frais en crédits et [Démarrer un Smart Batch](/verifik-fr/smart-reports/start-a-smart-batch) pour lancer le traitement.
- Pour les imports en masse CSV, XLSX ou JSONL avec validation des dépendances et exécution immédiate facultative, utilisez [Créer un Smart Batch à partir d'un fichier](/verifik-fr/smart-reports/create-smart-batch-from-file).
