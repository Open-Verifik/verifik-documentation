Supprimez une `BatchConfiguration` détenue par votre compte client. Le point de terminaison supprime le document de configuration et renvoie le document supprimé dans `data`.

Si `{id}` n'existe pas ou appartient à un autre compte client, le point de terminaison renvoie `404` (`not_found`). La suppression d'une configuration n'exécute aucune consultation et ne consomme pas de crédits.

### Point de terminaison

```
DELETE https://api.verifik.co/v2/batch-configurations/{id}
```

Également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/batch-configurations/{id}` avec votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom | Valeur |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

Le jeton doit être un **JWT client**. Des identifiants manquants ou invalides renvoient `401 Unauthorized`.

### Paramètres

| Nom | Type | Requis | Description |
| ---- | ---- | -------- | ----------- |
| `id` | string | Oui | ObjectId `BatchConfiguration` à supprimer. |

### Notes

- La suppression d'une configuration renvoie le document supprimé dans `data`. Les requêtes `GET`, `PUT` ou `DELETE` ultérieures utilisant le même `{id}` ne trouveront plus l'enregistrement (`GET` renvoie `data: null` ; `GET /input-schema`, `PUT` et `DELETE` renvoient `404` `not_found`).
- La suppression d'une configuration ne consomme pas de crédits.
