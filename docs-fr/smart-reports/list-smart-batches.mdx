Listez les enregistrements `SmartBatch` appartenant au compte client authentifié. Par défaut, les résultats sont triés du plus récent au plus ancien (`-createdAt`) et excluent le tableau `rows` sauf si vous passez explicitement `includeRows=true`, ce qui garde les réponses de liste compactes.

Envoyez `page` pour activer la sortie paginée avec les métadonnées `total`, `limit`, `page` et `pages`. Omettez `page` pour recevoir `{ data }` contenant le tableau des lots correspondants sans champs de pagination. Le listage des lots n'exécute aucune vérification et ne consomme pas de crédits.

### Point de terminaison

```text
GET https://api.verifik.co/v2/smart-batches
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom                  | Type    | Requis | Description |
| -------------------- | ------- | ------ | ----------- |
| `batchConfiguration` | string  | Non    | Filtrer les lots par ObjectId `BatchConfiguration`. |
| `status`             | string  | Non    | Filtrer par statut de lot : `"draft"`, `"pending"`, `"processing"`, `"paused"`, `"completed"`, `"failed"` ou `"cancelled"`. |
| `page`               | number  | Non    | Numéro de page (`>= 1`). Active la pagination et ajoute `total`, `limit`, `page` et `pages` à la réponse. |
| `limit`              | number  | Non    | Nombre maximal d'éléments par réponse (`1` à `200`). |
| `perPage`            | number  | Non    | Taille de page (`1` à `200`) lorsque `page` est défini. `20` par défaut. |
| `includeRows`        | boolean | Non    | Définissez `true` pour inclure `rows` sur chaque lot renvoyé. Lorsqu'il est omis ou vaut `false`, `rows` est exclu. |
| `search`             | string  | Non    | Recherche par expression régulière insensible à la casse sur le champ `name` du lot. |
| `sort`               | string  | Non    | Champ et sens de tri. `"-createdAt"` par défaut. |
| `sortBy`             | string  | Non    | Nom du champ de tri lorsqu'il est associé à `sortOrder`. |
| `sortOrder`          | string  | Non    | Sens de tri pour `sortBy` : `"asc"` ou `"desc"`. |

Les paramètres de requête inconnus sont rejetés par la validation Joi avec `409 MissingParameter`.

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	params := url.Values{}
	params.Set("status", "processing")
	params.Set("page", "1")
	params.Set("perPage", "20")
	params.Set("search", "Colombia")
	params.Set("sort", "-createdAt")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-batches?"+params.Encode(), nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notes

- Les résultats sont limités au client authentifié (`clientId` de votre JWT).
- Laisser `includeRows` omis ou à `false` garde les réponses de liste légères ; récupérez l'ensemble des `rows` d'un lot via [Récupérer un Smart Batch](/verifik-fr/smart-reports/retrieve-a-smart-batch).
- Les valeurs de requête invalides ou les clés de requête inconnues échouent à la validation Joi avec `409 MissingParameter`.
- Lorsque `page` est fourni (`>= 1`), `perPage` vaut `20` par défaut et accepte de `1` à `200`.
