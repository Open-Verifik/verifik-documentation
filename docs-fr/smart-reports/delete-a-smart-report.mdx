Supprimez un enregistrement `SmartReport` appartenant au client authentifié. En cas de succès, l'API renvoie le document `SmartReport` supprimé dans `{ "data": ... }`.

Si l'ID du rapport est manquant ou appartient à un autre client, le point de terminaison renvoie `404 Not Found` (`{ "message": "not_found", "code": "NotFound" }`). La suppression d'un rapport retire le document `SmartReport` sans supprimer les données de vérification sous-jacentes du `SmartBatch`.

### Point de terminaison

```
DELETE https://api.verifik.co/v2/smart-reports/{id}
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-reports/{id}` en utilisant votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                                 |
| --------------- | ---------------------- | ------------------------------------------- |
| `Content-Type`  | `application/json`     | Format du payload de la requête.            |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT limité au client (`authUser.clientId`). |

### Paramètres

| Nom  | Type   | Requis  | Description |
| ---- | ------ | ------- | ----------- |
| `id` | string | **Oui** | ObjectId du `SmartReport` à supprimer. |

### Notes

- Les appels suivants à `GET /v2/smart-reports/{id}` renvoient `{ "data": null }`, tandis que `PUT`, `DELETE`, `/generate`, `/download`, `/html` et `/send-email` renvoient `404` (`not_found`).
- La suppression d'un `SmartReport` n'émet aucun webhook de livraison ou de génération ; consultez [Webhooks SmartReports](/verifik-fr/resources/smart-reports-webhooks) et [MCP et Agents IA](/verifik-fr/smart-reports/mcp-and-ai-agents) pour les détails d'automatisation du cycle de vie.
