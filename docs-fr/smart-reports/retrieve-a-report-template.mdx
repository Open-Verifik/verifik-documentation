Récupérez un modèle Smart Report unique à partir de son ObjectId (`{id}`). Cela renvoie la spécification complète du modèle, incluant `sections`, `reportTheme`, `sampleData`, les paramètres de mise en page ainsi que les références peuplées `batchConfiguration` et `client`.

Dans les workflows headless et IA, utilisez ce point de terminaison pour charger le tableau `sections` actuel avant d'appeler [Générer la mise en page d'un modèle](/verifik-fr/smart-reports/generate-template-layout) en mode `append` ou `edit`, pour récupérer `sampleData` enregistré pour [Prévisualiser le HTML d'un modèle](/verifik-fr/smart-reports/preview-template-html), ou pour inspecter un modèle avant d'effectuer une mise à jour `PUT`. Par souci de sécurité et d'efficacité de la taille du payload, `security.password` et `thumbnail.image` sont exclus sur ce point de terminaison.

### Point de terminaison

```
GET https://api.verifik.co/v2/smart-report-templates/{id}
```

Le proxy Smart-Agent (`https://ai.verifik.co`) expose les mêmes chemins `/v2/...` et exige votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`.

### En-têtes

| Nom           | Valeur                 |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Paramètres

| Nom  | Type   | Requis | Description                      |
| ---- | ------ | ------ | -------------------------------- |
| `id` | string | Oui    | ObjectId du modèle Smart Report. |

### Notes

- Lorsque le modèle n'existe pas ou appartient à un autre client, ce point de terminaison renvoie HTTP `200` avec `{ "data": null }` plutôt que `404`.
- `security.password` et `thumbnail.image` sont exclus du document renvoyé. Pour afficher ou inspecter la vignette du modèle, utilisez [Lister les modèles de rapport](/verifik-fr/smart-reports/list-report-templates).
