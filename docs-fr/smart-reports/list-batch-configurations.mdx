Listez les objets `BatchConfiguration` détenus par votre compte client authentifié. Les résultats sont limités au client de votre JWT, triés du plus récent au plus ancien (`createdAt` décroissant) et renvoyés avec les métadonnées `steps.appFeature` renseignées ainsi que la tarification `ClientFeature` propre au client.

Passez `page` lorsque vous avez besoin de résultats paginés avec les métadonnées `total`, `limit`, `page` et `pages`. Omettez `page` pour recevoir directement le tableau correspondant dans `data`. Le listage des configurations n'exécute aucune consultation et ne consomme pas de crédits.

### Point de terminaison

```
GET https://api.verifik.co/v2/batch-configurations
```

Également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/batch-configurations` avec votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom | Valeur |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

Le jeton doit être un **JWT client**. Des identifiants manquants ou invalides renvoient `401 Unauthorized`.

### Paramètres

Tous les paramètres de requête sont facultatifs.

| Nom | Type | Requis | Description |
| ---- | ---- | -------- | ----------- |
| `search` | string | Non | Filtre sur le nom insensible à la casse appliqué aux configurations enregistrées. |
| `text` | string | Non | Alias de `search`. |
| `page` | integer | Non | Numéro de page (indexé à partir de `1`). Lorsqu'il est fourni, active les métadonnées de pagination (`total`, `limit`, `page`, `pages`) dans la réponse. |
| `limit` | integer | Non | Nombre maximal de configurations à renvoyer par page. |
| `perPage` | integer | Non | Alias de `limit`. |

import (

}

### Notes

- Les résultats sont automatiquement limités au JWT client authentifié et triés du plus récent au plus ancien (`-createdAt`).
- Le champ `steps.appFeature` de chaque étape est renseigné et enrichi avec les tarifs `ClientFeature` de votre compte lorsqu'ils sont configurés.
- `perPage` est un alias de `limit` et `text` est un alias de `search`.
- Les métadonnées de pagination (`total`, `limit`, `page`, `pages`) ne sont incluses que lorsque `page` est fourni dans la chaîne de requête.
