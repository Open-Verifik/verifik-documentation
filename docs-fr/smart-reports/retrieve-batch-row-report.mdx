Composez le modèle de rapport structuré pour une seule ligne (`rowIndex`) d'un `SmartBatch`. Ce point de terminaison exécute le compositeur de rapport intégré de Verifik (`colombia_vehicle`) sur les sorties d'étapes enregistrées de la ligne et joint facultativement un `verificationScore` lorsque `score` ou `scoreProfile` est transmis.

Si la `BatchConfiguration` du lot ne correspond pas à un compositeur intégré, ce point de terminaison renvoie `409 Conflict` (`no_report_composer_for_configuration`). Pour des modèles de rapport personnalisés quelconques, utilisez plutôt `POST /v2/smart-reports/run`, `GET /v2/smart-reports/{id}/html` ou `/generate`. La lecture de ce point de terminaison ne consomme pas de crédits.

### Point de terminaison

```text
GET https://api.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres de chemin

| Nom        | Type   | Requis | Description |
| ---------- | ------ | ------ | ----------- |
| `id`       | string | Oui    | ObjectId `SmartBatch`. |
| `rowIndex` | number | Oui    | Index basé sur `0` de la ligne dans le lot. |

### Paramètres de requête

| Nom            | Type              | Requis | Description |
| -------------- | ----------------- | ------ | ----------- |
| `score`        | boolean ou string | Non    | Passez `true` ou `"1"` pour calculer et inclure `verificationScore` dans la réponse. |
| `scoreProfile` | string            | Non    | Identifiant du profil de notation. Fournir `scoreProfile` active également `score`. |

```javascript
import axios from "axios";

const run = async () => {
  const batchId = "6801a2b3c4d5e6f7a8b9c0d3";

        scoreProfile: "fleet_standard",
      },
      headers: {
        "Content-Type": "application/json",

      },
    }
  );
```

  <TabItem value="go" label="Go">

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	rowIndex := "0"
	params := url.Values{}
	params.Set("score", "true")
	params.Set("scoreProfile", "fleet_standard")

	endpoint := fmt.Sprintf("https://api.verifik.co/v2/smart-batches/%s/rows/%s/report?%s", batchID, rowIndex, params.Encode())
	req, _ := http.NewRequest("GET", endpoint, nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}
```

### Notes

- Ce point de terminaison sert uniquement les rapports de ligne composés intégrés (`colombia_vehicle`). Toute autre configuration renvoie `409 Conflict` (`no_report_composer_for_configuration`).
- Pour les modèles personnalisés, le rendu HTML thématisé ou les dossiers PDF sur n'importe quelle configuration, utilisez `POST /v2/smart-reports/run`, `GET /v2/smart-reports/{id}/html` ou `/generate` (voir [Exécuter un Smart Report](/verifik-fr/smart-reports/run-a-smart-report)).
- `verificationScore` est omis sauf si `score=true`, `score=1` ou `scoreProfile` est fourni.
