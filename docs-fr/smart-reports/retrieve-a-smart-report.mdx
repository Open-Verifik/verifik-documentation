Récupérez un `SmartReport` unique à partir de son ID. La réponse peuple `template`, `smartBatch` et `client`, et attache les chemins prêts à l'emploi `downloadUrl` (`/v2/smart-reports/{id}/download`) et `htmlUrl` (`/v2/smart-reports/{id}/html`).

Ce point de terminaison sert également de cible de polling (`pollUrl`) renvoyée lorsque `POST /v2/smart-reports/run` s'exécute en mode `"async"` ou bascule sur `202 Accepted` après le délai synchrone de 90 secondes. Si l'ID du rapport n'existe pas ou appartient à un autre client, le point de terminaison renvoie HTTP `200 OK` avec `{ "data": null }`.

### Point de terminaison

```
GET https://api.verifik.co/v2/smart-reports/{id}
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-reports/{id}` en utilisant votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                                 |
| --------------- | ---------------------- | ------------------------------------------- |
| `Content-Type`  | `application/json`     | Format du payload de la requête.            |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT limité au client (`authUser.clientId`). |

### Paramètres

| Nom  | Type   | Requis  | Description |
| ---- | ------ | ------- | ----------- |
| `id` | string | **Oui** | ObjectId du `SmartReport` renvoyé par `POST /v2/smart-reports/run`, `POST /v2/smart-reports` ou `GET /v2/smart-reports`. |

### Intégration Webhooks et MCP

- **Polling vs Webhooks** : Pour les exécutions asynchrones, vous pouvez soit interroger `GET /v2/smart-reports/{id}` jusqu'à ce que `data.status` se stabilise (`"generated"`, `"sent"` ou `"failed"`), soit vous abonner aux événements webhook (`smart_batch_report_generated`, `smart_batch_report_generation_failed`, `smart_batch_report_sent`, `smart_batch_report_delivery_failed`). Consultez [Webhooks SmartReports](/verifik-fr/resources/smart-reports-webhooks).
- **Équivalent MCP** : Les agents IA peuvent récupérer un enregistrement de rapport à l'aide de l'outil MCP `smart_report_get`. Consultez [MCP et Agents IA](/verifik-fr/smart-reports/mcp-and-ai-agents).

### Notes

- Les rapports manquants ou appartenant à un autre client renvoient `200 OK` avec `{ "data": null }` plutôt que `404`.
- `downloadUrl` et `htmlUrl` sont des chemins API relatifs pouvant être ajoutés à `https://api.verifik.co` (ou `https://ai.verifik.co`).
