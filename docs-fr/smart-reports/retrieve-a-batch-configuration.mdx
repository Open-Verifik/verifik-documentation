Récupérez une seule `BatchConfiguration` par son ObjectId (`{id}`). La recherche est limitée au JWT client authentifié et renvoie les détails `steps.appFeature` renseignés, enrichis avec les tarifs `ClientFeature` de votre compte.

Si aucune configuration correspondante n'existe ou si l'identifiant appartient à un autre compte client, le point de terminaison renvoie HTTP `200` avec `data: null`. La lecture d'une configuration n'exécute aucune consultation et ne consomme pas de crédits.

### Point de terminaison

```
GET https://api.verifik.co/v2/batch-configurations/{id}
```

Également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/batch-configurations/{id}` avec votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom | Valeur |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

Le jeton doit être un **JWT client**. Des identifiants manquants ou invalides renvoient `401 Unauthorized`.

### Paramètres

| Nom | Type | Requis | Description |
| ---- | ---- | -------- | ----------- |
| `id` | string | Oui | ObjectId `BatchConfiguration` issu de la création, du clonage ou du listage. |

### Notes

- Si `{id}` n'existe pas ou appartient à un autre compte client, ce point de terminaison renvoie HTTP `200` avec `{ "data": null }`.
- Vérifiez `data !== null` dans votre intégration avant de lire les propriétés de `data`.
- Pour inspecter les entrées obligatoires et facultatives résolues ainsi qu'une charge utile `exampleInput` pour une configuration, appelez [Récupérer le schéma d'entrée d'une configuration](/verifik-fr/smart-reports/retrieve-configuration-input-schema).
