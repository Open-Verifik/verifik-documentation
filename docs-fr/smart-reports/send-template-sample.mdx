Effectuez le rendu d'un modèle Smart Report enregistré (`{id}`) avec `sampleData` et envoyez le PDF obtenu directement par e-mail à un ou plusieurs `recipients`. Fournissez éventuellement `printHtml` pour contourner la génération HTML ou `pdfBase64` pour joindre un tampon PDF pré-rendu.

Dans les pipelines CI/CD headless, les workflows d'approbation de modèles et les automatisations d'agents IA, utilisez ce point de terminaison pour distribuer des aperçus de rapports mis en forme aux responsables conformité ou parties prenantes produit sans déployer votre propre infrastructure d'envoi d'e-mails. Les corps de requête JSON jusqu'à `64MB` sont acceptés pour intégrer des polices personnalisées, des logos, du HTML pré-rendu ou des PDF en base64.

### Point de terminaison

```
POST https://api.verifik.co/v2/smart-report-templates/{id}/send-sample
```

Le proxy Smart-Agent (`https://ai.verifik.co`) expose les mêmes chemins `/v2/...` et exige votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`.

### En-têtes

| Nom           | Valeur                 |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Paramètres

| Nom  | Type   | Requis | Description                      |
| ---- | ------ | ------ | -------------------------------- |
| `id` | string | Oui    | ObjectId du modèle Smart Report. |

### Corps de la requête

Prend en charge des payloads JSON jusqu'à `64MB`.

| Nom          | Type     | Requis | Description                                                                                                                   |
| ------------ | -------- | ------ | ----------------------------------------------------------------------------------------------------------------------------- |
| `recipients` | string[] | Oui    | Tableau d'adresses e-mail de destinataires valides (minimum `1`).                                                             |
| `sampleData` | object   | Oui    | Payload d'exemple contenant `inputData`, `results`, `batchName` et `rowIndex`.                                                |
| `subject`    | string   | Non    | Objet d'e-mail personnalisé. Vaut `` `Sample Report: <name>` `` par défaut à partir du `name` du modèle.                      |
| `language`   | string   | Non    | Langue du texte de l'e-mail : `"en"` ou `"es"`. Vaut `"es"` par défaut.                                                       |
| `printHtml`  | string   | Non    | Document HTML pré-rendu facultatif à convertir en PDF au lieu d'effectuer le rendu depuis les `sections` du modèle.           |
| `pdfBase64`  | string   | Non    | Pièce jointe PDF encodée en base64 facultative à envoyer directement sans génération PDF côté serveur.                        |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func main() {
	id := "67c1f94b2d8a1c0012a4b301"
	body, _ := json.Marshal(map[string]interface{}{
		"recipients": []string{"compliance@acme.example"},
		"subject":    "Sample Report: Colombia Driver Onboarding",
		"language":   "en",
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding Sample",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{
					"fullName": "Mateo Rojas",
					"status":   "active",
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/"+id+"/send-sample", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notes

- Contrairement aux autres points de terminaison de modèles qui encapsulent les payloads dans `{ "data": ... }`, `send-sample` renvoie directement au niveau racine les champs `success`, `message`, `recipients`, `messageId` et `delivery`.
- Si `language` est omis, l'e-mail utilise `"es"` par défaut. Passez `"en"` pour des notifications en anglais destinées aux parties prenantes.
- Pour enregistrer le PDF généré localement au lieu de l'envoyer par e-mail, utilisez [Télécharger un exemple de modèle](/verifik-fr/smart-reports/download-template-sample).
