Mettez à jour un `SmartReport` existant appartenant au client authentifié. Envoyez uniquement les champs que vous souhaitez modifier ; les champs omis dans la requête restent inchangés.

Si l'ID du rapport n'existe pas ou appartient à un autre client, le point de terminaison renvoie `404 Not Found` (`{ "message": "not_found", "code": "NotFound" }`).

### Point de terminaison

```
PUT https://api.verifik.co/v2/smart-reports/{id}
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-reports/{id}` en utilisant votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                                 |
| --------------- | ---------------------- | ------------------------------------------- |
| `Content-Type`  | `application/json`     | Format du payload de la requête.            |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT limité au client (`authUser.clientId`). |

### Paramètres

| Nom  | Type   | Requis  | Description |
| ---- | ------ | ------- | ----------- |
| `id` | string | **Oui** | ObjectId du `SmartReport` à mettre à jour. |

### Corps de la requête

Tous les champs du corps sont facultatifs ; fournissez uniquement les attributs que vous souhaitez mettre à jour.

| Nom                        | Type             | Requis | Description |
| -------------------------- | ---------------- | ------ | ----------- |
| `name`                     | string           | Non    | Nom d'affichage du rapport. |
| `status`                   | string           | Non    | Statut du rapport : `"draft"`, `"generating"`, `"generated"`, `"sent"` ou `"failed"`. |
| `pdfUrl`                   | string           | Non    | URL enregistrée de l'artefact PDF généré. |
| `pdfSize`                  | number           | Non    | Taille du PDF généré en octets. |
| `htmlSnapshot`             | string           | Non    | Instantané HTML enregistré du rapport généré. |
| `pageCount`                | number           | Non    | Nombre de pages du PDF généré. |
| `pdfEngine`                | string           | Non    | Moteur de rendu : `"pdfkit"` ou `"puppeteer"`. |
| `generatedAt`              | string           | Non    | Horodatage ISO 8601 de génération du rapport. |
| `generationDurationMs`     | number           | Non    | Durée de génération du PDF en millisecondes. |
| `dataSnapshot`             | object           | Non    | Instantané des données de ligne ou d'entrée utilisées pour le rapport. |
| `externalRefId`            | string           | Non    | Identifiant de corrélation de l'appelant. |
| `webhookUrl`               | string           | Non    | URL de surcharge webhook `http` ou `https` spécifique au rapport. |
| `rowIndex`                 | number           | Non    | Index de ligne basé sur zéro associé à ce rapport. |
| `createdByChannel`         | string           | Non    | Canal d'origine : `"portal"`, `"api"`, `"mcp"`, `"x402"` ou `"webhook"`. |
| `verificationScoreSummary` | object           | Non    | Métadonnées récapitulatives issues du calcul de score de vérification. |
| `error`                    | object ou string | Non    | Payload ou message d'erreur enregistré pour les états d'échec. |

import (

### Intégration Webhooks et MCP

- La mise à jour de `webhookUrl` ou `externalRefId` actualise l'URL de callback cible et l'identifiant de corrélation utilisés par les appels ultérieurs à [Générer le PDF d'un Smart Report](/verifik-fr/smart-reports/generate-smart-report-pdf) et [Envoyer un Smart Report par e-mail](/verifik-fr/smart-reports/send-smart-report-email). Consultez [Webhooks SmartReports](/verifik-fr/resources/smart-reports-webhooks).
- Pour inspecter l'enregistrement mis à jour ou exécuter des opérations de rapport headless via un agent IA, consultez [MCP et Agents IA](/verifik-fr/smart-reports/mcp-and-ai-agents).

### Notes

- La mise à jour d'un `SmartReport` modifie uniquement les champs enregistrés sur le rapport ; elle ne régénère pas automatiquement de PDF et n'envoie pas d'e-mails. Appelez [Générer le PDF d'un Smart Report](/verifik-fr/smart-reports/generate-smart-report-pdf) ou [Envoyer un Smart Report par e-mail](/verifik-fr/smart-reports/send-smart-report-email) lorsque vous souhaitez effectuer un nouveau rendu ou une livraison.
