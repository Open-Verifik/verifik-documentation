Listez tous les profils de score de vérification pris en charge qui peuvent être associés à un modèle Smart Report (`reportTheme.scoreProfile`) ou passés à [Prévisualiser le HTML d'un modèle](/verifik-fr/smart-reports/preview-template-html) (`scoreProfile`).

Dans les interfaces de configuration headless et les workflows d'agents IA, interrogez ce point de terminaison avant d'activer le calcul de score afin que votre application valide dynamiquement les identifiants `scoreProfile` et évite les erreurs `409` (`unknown_score_profile`) lors de l'aperçu HTML ou du rendu de rapport. Les profils disponibles couvrent les workflows conducteur, identité, entreprise, flotte, véhicule, crédit, santé et biométrie :

- `cabify_driver`
- `kyc`
- `kyb`
- `fleet`
- `vehicle_purchase`
- `identity_lookup`
- `background_check`
- `lending`
- `healthcare_professional`
- `biometrics`

### Point de terminaison

```
GET https://api.verifik.co/v2/smart-report-templates/score-profiles
```

Le proxy Smart-Agent (`https://ai.verifik.co`) expose les mêmes chemins `/v2/...` et exige votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`.

### En-têtes

| Nom           | Valeur                 |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Paramètres

Aucun paramètre de requête ou de chemin n'est requis.

### Notes

- Utilisez la valeur `id` renvoyée dans `reportTheme.scoreProfile` lors de la création ou de la mise à jour d'un modèle, ou en tant que `scoreProfile` sur [Prévisualiser le HTML d'un modèle](/verifik-fr/smart-reports/preview-template-html).
- Envoyer un `scoreProfile` non reconnu à `POST /v2/smart-report-templates/preview-html` renvoie `409` (`unknown_score_profile`).
