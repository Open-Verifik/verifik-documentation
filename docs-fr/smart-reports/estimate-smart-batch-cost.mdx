Calculez une estimation préalable des crédits pour toutes les lignes non terminales restantes d'un `SmartBatch`. La réponse détaille la tarification pour chaque étape activée de la `BatchConfiguration` du lot et compare le coût prévisionnel au solde de crédits disponible sur votre compte client.

L'appel à ce point de terminaison n'effectue aucune consultation catalogue et ne consomme aucun crédit.

### Point de terminaison

```text
GET https://api.verifik.co/v2/smart-batches/{id}/estimate
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}/estimate` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom  | Type   | Requis | Description |
| ---- | ------ | ------ | ----------- |
| `id` | string | Oui    | ObjectId `SmartBatch` à estimer. |

### Notes

- `itemCount` et `pendingRows` reflètent uniquement les lignes qui ne sont pas encore dans un statut terminal de ligne (`completed`, `failed` ou `partial`).
- `availableCredits` combine `credits` et `extraCredits` de votre compte client ; lorsque `sufficientCredits` vaut `false`, `shortfall` indique les crédits supplémentaires nécessaires.
- La tarification par étape utilise les tarifs `ClientFeature` enregistrés de votre compte client le cas échéant.
