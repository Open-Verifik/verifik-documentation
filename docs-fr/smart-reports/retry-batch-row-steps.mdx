Effacez et remettez en file d'attente uniquement les `sequences` spécifiées sur une seule ligne (`rowIndex`) d'un `SmartBatch`, en laissant intactes les sorties enregistrées de chaque autre étape et de chaque autre ligne. `rowIndex` et `sequences` sont tous deux obligatoires.

Le serveur rejette la requête avec `409 Conflict` si le lot, la ligne cible, l'exécution `FeatureRunner` sous-jacente ou l'élément d'exécution est en cours de traitement (`batch_is_processing`, `row_is_processing`, `run_is_processing`, `item_is_processing`).

### Point de terminaison

```text
POST https://api.verifik.co/v2/smart-batches/{id}/retry-steps
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}/retry-steps` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom  | Type   | Requis | Description |
| ---- | ------ | ------ | ----------- |
| `id` | string | Oui    | ObjectId `SmartBatch`. |

### Corps de la requête

| Nom         | Type      | Requis | Description |
| ----------- | --------- | ------ | ----------- |
| `rowIndex`  | integer   | Oui    | Index basé sur `0` (`>= 0`) de la ligne à relancer partiellement. |
| `sequences` | integer[] | Oui    | Numéros de séquence d'étapes (`>= 0`, minimum `1`, maximum `200` éléments) à effacer et réexécuter sur cette ligne. |

Les clés de corps inconnues ou les champs obligatoires manquants sont rejetés par la validation Joi avec `409 MissingParameter`.

### Notes

- Les champs `results` et `errors` stockés ne sont effacés que pour les `sequences` spécifiées sur `rowIndex` ; les résultats de toutes les autres séquences d'étapes restent intacts.
- Les motifs possibles pour `409 Conflict` sont `batch_is_processing`, `row_is_processing`, `run_is_processing` et `item_is_processing`.
- La transmission de références de séquences d'étapes invalides ou vides renvoie `400 BadRequest` (`retry_steps_invalid`).
- Pour relancer des lignes entières en échec ou partielles sur l'ensemble du lot, utilisez [Relancer les lignes en échec d'un Smart Batch](/verifik-fr/smart-reports/retry-failed-batch-rows).
