Créez un enregistrement brouillon `SmartReport` (`status: "draft"`) lié à un `template` et à un `smartBatch` existants. Utilisez ce point de terminaison lorsque vous disposez déjà d'un `SmartBatch` terminé ou en cours et que vous souhaitez gérer la création du rapport, la génération PDF, la récupération HTML et l'envoi par e-mail en étapes distinctes.

La création d'un enregistrement brouillon renvoie HTTP **`200 OK`** avec le nouveau `SmartReport` dans `{ data }`. Elle n'exécute pas d'étapes de vérification et ne génère pas de PDF par elle-même — enchaînez avec [Générer le PDF d'un Smart Report](/verifik-fr/smart-reports/generate-smart-report-pdf) ou [Envoyer un Smart Report par e-mail](/verifik-fr/smart-reports/send-smart-report-email). Si vous souhaitez exécuter les étapes de vérification et produire un rapport en une seule requête, utilisez [Exécuter un Smart Report](/verifik-fr/smart-reports/run-a-smart-report).

### Point de terminaison

```
POST https://api.verifik.co/v2/smart-reports
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-reports` en utilisant votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                                 |
| --------------- | ---------------------- | ------------------------------------------- |
| `Content-Type`  | `application/json`     | Format du payload de la requête.            |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT limité au client (`authUser.clientId`). |

### Corps de la requête

| Nom                | Type    | Requis  | Description |
| ------------------ | ------- | ------- | ----------- |
| `template`         | string  | **Oui** | ObjectId du modèle selon lequel effectuer le rendu de ce rapport. |
| `smartBatch`       | string  | **Oui** | ObjectId du `SmartBatch` fournissant les résultats des lignes de vérification. |
| `name`             | string  | Non     | Nom d'affichage du rapport. Max `150` caractères. |
| `externalRefId`    | string  | Non     | Identifiant de corrélation de l'appelant. Max `200` caractères. |
| `webhookUrl`       | string  | Non     | URL de surcharge webhook `http` ou `https` spécifique au rapport. Max `2048` caractères. |
| `rowIndex`         | integer | Non     | Index de ligne basé sur zéro (`>= 0`) provenant du `SmartBatch` lié. |
| `createdByChannel` | string  | Non     | Canal d'origine : `"portal"`, `"api"`, `"mcp"`, `"x402"` ou `"webhook"`. Défaut `"portal"`. |

#### Workflow étape par étape vs exécution headless

- Utilisez `POST /v2/smart-reports` lorsque votre workflow a déjà exécuté un `SmartBatch` (par exemple via l'interface SmartBatch ou l'API file) et que vous souhaitez d'abord créer un brouillon `SmartReport` (`status: "draft"`), prévisualiser le HTML avec [Récupérer le HTML d'un Smart Report](/verifik-fr/smart-reports/retrieve-smart-report-html), générer le PDF avec [Générer le PDF d'un Smart Report](/verifik-fr/smart-reports/generate-smart-report-pdf) et l'envoyer avec [Envoyer un Smart Report par e-mail](/verifik-fr/smart-reports/send-smart-report-email).
- Notez que `createdByChannel` vaut `"portal"` par défaut sur cette route ; les intégrations API doivent donc définir `createdByChannel: "api"` pour suivre l'attribution du canal.

### Intégration Webhooks et MCP

- **Webhooks** : Enregistrer `webhookUrl` et `externalRefId` sur le brouillon `SmartReport` garantit que les appels ultérieurs de génération (`smart_batch_report_generated`, `smart_batch_report_generation_failed`) et d'envoi par e-mail (`smart_batch_report_sent`, `smart_batch_report_delivery_failed`) héritent de votre destination de callback et de votre identifiant de corrélation propres au rapport. Consultez [Webhooks SmartReports](/verifik-fr/resources/smart-reports-webhooks).
- **Intégration MCP** : Pour une exécution headless de rapport en un seul appel dans des agents IA, utilisez `smart_report_run`. Consultez [MCP et Agents IA](/verifik-fr/smart-reports/mcp-and-ai-agents).

### Notes

- Une création réussie renvoie HTTP `200` (et non `201`) avec `status: "draft"`.
- Conservez `data._id` pour les appels ultérieurs vers [Récupérer un Smart Report](/verifik-fr/smart-reports/retrieve-a-smart-report), [Générer le PDF d'un Smart Report](/verifik-fr/smart-reports/generate-smart-report-pdf), [Télécharger le PDF d'un Smart Report](/verifik-fr/smart-reports/download-smart-report-pdf), [Récupérer le HTML d'un Smart Report](/verifik-fr/smart-reports/retrieve-smart-report-html) et [Envoyer un Smart Report par e-mail](/verifik-fr/smart-reports/send-smart-report-email).
