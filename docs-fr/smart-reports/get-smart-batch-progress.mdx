Récupérez un résumé léger de la progression d'un `SmartBatch` sans transférer l'intégralité du tableau `rows`. La réponse inclut les compteurs de lignes (`totalRows`, `completedRows`, `failedRows`, `partialRows`, `pendingRows`), les horodatages d'exécution, `creditsSpent` et — lorsqu'il est adossé à une exécution `FeatureRunner` — les détails imbriqués `run` et le grand livre `spend`.

Les exécutions `FeatureRunner` côté serveur émettent également un événement webhook `smart_batch_batch_completed` (incluant `runId` et `creditsSpent`) à la fin du traitement lorsque `batchConfiguration.notification.webhookUrl` est configuré. L'interrogation de ce point de terminaison ne consomme pas de crédits.

### Point de terminaison

```text
GET https://api.verifik.co/v2/smart-batches/{id}/progress
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}/progress` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom  | Type   | Requis | Description |
| ---- | ------ | ------ | ----------- |
| `id` | string | Oui    | ObjectId `SmartBatch` à interroger. |

### Notes

- `run` et `spend` sont inclus lorsque le lot est associé à une exécution `FeatureRunner` (`run` vaut `null` si l'enregistrement d'exécution référencé n'est pas renvoyé).
- Les exécutions `FeatureRunner` côté serveur émettent l'événement webhook `smart_batch_batch_completed` (avec `runId` et `creditsSpent`) lorsqu'elles se terminent si `batchConfiguration.notification.webhookUrl` est défini. Voir [Webhooks SmartReports](/verifik-fr/resources/smart-reports-webhooks).
- Une fois que le lot atteint un statut terminal, utilisez [Récupérer un Smart Batch](/verifik-fr/smart-reports/retrieve-a-smart-batch) pour inspecter les champs `results` et `errors` au niveau des lignes.
