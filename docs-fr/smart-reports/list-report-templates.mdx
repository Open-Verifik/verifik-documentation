Listez les modèles Smart Report disponibles pour le client authentifié. Par défaut, ce point de terminaison renvoie à la fois vos modèles personnalisés appartenant au client et les modèles intégrés `"System"` de Verifik afin que vous puissiez découvrir les ID de modèles réutilisables (`_id`), inspecter les configurations de mise en page et de thème, et sélectionner un modèle avant de déclencher des exécutions `SmartBatch` ou des rendus d'exemple.

Dans les pipelines de vérification headless et les workflows d'agents IA, appelez ce point de terminaison en premier pour localiser un modèle existant lié à une `batchConfiguration`, filtrer les modèles intégrés `"System"` par `country`, `category` ou `tier`, ou vérifier si un modèle personnalisé est actif avant de le cloner ou de le mettre à jour. Le listage des modèles ne génère pas de PDF et ne consomme pas de crédits.

### Point de terminaison

```
GET https://api.verifik.co/v2/smart-report-templates
```

Le proxy Smart-Agent (`https://ai.verifik.co`) expose les mêmes chemins `/v2/...` et exige votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`.

### En-têtes

| Nom           | Valeur                 |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Paramètres

Tous les paramètres de requête sont facultatifs.

| Nom                  | Type    | Requis | Description                                                                                                                                      |
| -------------------- | ------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `batchConfiguration` | string  | Non    | Filtrer les modèles liés à un ObjectId de configuration `SmartBatch` spécifique.                                                                 |
| `type`               | string  | Non    | Filtrer par origine : `"client"` ou `"System"`. Lorsqu'il est omis, renvoie vos modèles client ainsi que les modèles `"System"` intégrés.       |
| `country`            | string  | Non    | Filtre par pays. Converti automatiquement en majuscules côté serveur (par exemple `CO`, `MX` ou `COLOMBIA`).                                     |
| `category`           | string  | Non    | Filtre par catégorie de domaine : `"citizen"`, `"company"` ou `"vehicle"`.                                                                       |
| `tier`               | string  | Non    | Filtre par niveau de modèle : `"essential"` ou `"comprehensive"`.                                                                                |
| `isActive`           | boolean | Non    | Filtrer par état actif (`true` ou `false`).                                                                                                      |
| `search`             | string  | Non    | Recherche par expression régulière insensible à la casse sur `name` et `systemKey`. Si `search` est envoyé sans `type`, la recherche porte sur vos modèles et sur les modèles `"System"`. |
| `page`               | integer | Non    | Numéro de page (indexé à 1). `page` et `limit` doivent tous deux être fournis ensemble pour activer la pagination dans ce module.                |
| `limit`              | integer | Non    | Taille de page. Doit être fourni conjointement avec `page` pour paginer les résultats.                                                           |
| `sort`               | string  | Non    | Spécification de tri. Vaut `type: 1, createdAt: -1` par défaut (tri par type de modèle puis du plus récent au plus ancien).                       |

### Notes

- `page` et `limit` doivent tous deux être fournis ensemble pour paginer les résultats. Envoyer un seul paramètre sans l'autre ne déclenche pas la pagination.
- Les modèles intégrés `"System"` renvoyés dans la liste sont en lecture seule. Tenter de les modifier ou de les supprimer renvoie `403` (`system_template_readonly`). Pour personnaliser un modèle de démarrage, transmettez sa mise en page à [Créer un modèle de rapport](/verifik-fr/smart-reports/create-a-report-template).
- Utilisez [Lister les thèmes de démarrage](/verifik-fr/smart-reports/list-theme-starters) lorsque vous souhaitez obtenir des modèles de démarrage épurés regroupés par `reportTheme`.
