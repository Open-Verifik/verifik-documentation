Supprimez un modèle Smart Report personnalisé appartenant au client authentifié. Le document du modèle supprimé est renvoyé dans `{ "data": ... }`.

Dans les workflows headless et les pipelines de tests automatisés, utilisez ce point de terminaison pour nettoyer des modèles temporaires ou retirer des conceptions de rapports obsolètes. Les modèles intégrés `"System"` ne peuvent pas être supprimés et renvoient `403` (`system_template_readonly`). La suppression d'un modèle ne consomme pas de crédits et ne supprime pas les rapports `SmartBatch` générés précédemment.

### Point de terminaison

```
DELETE https://api.verifik.co/v2/smart-report-templates/{id}
```

Le proxy Smart-Agent (`https://ai.verifik.co`) expose les mêmes chemins `/v2/...` et exige votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`.

### En-têtes

| Nom           | Valeur                 |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Paramètres

| Nom  | Type   | Requis | Description                      |
| ---- | ------ | ------ | -------------------------------- |
| `id` | string | Oui    | ObjectId du modèle Smart Report. |

### Notes

- Les modèles intégrés `"System"` ne peuvent pas être supprimés (`403` `system_template_readonly`).
- Une fois supprimé, les requêtes `GET`, `PUT` ou `DELETE` suivantes ciblant le même `{id}` renvoient `{ "data": null }` (pour `GET`) ou `404` `not_found` (pour `PUT`/`DELETE`).
