Annulez un `SmartBatch` (ainsi que toute exécution `FeatureRunner` associée). Le lot passe à `status: "cancelled"` et définit `completedAt`.

Les lots déjà dans un statut terminal (`"completed"`, `"failed"` ou `"cancelled"`) ne peuvent pas être annulés et renvoient `400 BadRequest` (`batch_already_terminal`).

### Point de terminaison

```text
POST https://api.verifik.co/v2/smart-batches/{id}/cancel
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}/cancel` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom  | Type   | Requis | Description |
| ---- | ------ | ------ | ----------- |
| `id` | string | Oui    | ObjectId `SmartBatch` à annuler. |

### Notes

- Les lots annulés conservent tous les résultats de lignes collectés précédemment et peuvent être redémarrés ultérieurement via [Démarrer un Smart Batch](/verifik-fr/smart-reports/start-a-smart-batch).
- Si vous souhaitez interrompre temporairement le traitement et continuer plus tard sans redémarrer, utilisez [Mettre en pause un Smart Batch](/verifik-fr/smart-reports/pause-a-smart-batch).
