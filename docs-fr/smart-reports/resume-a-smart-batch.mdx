Reprenez un `SmartBatch` mis en pause (ainsi que toute exécution `FeatureRunner` sous-jacente). Le serveur vérifie que votre compte client dispose toujours des autorisations pour toutes les étapes configurées (`409 endpoints_not_in_account` si l'accès à un point de terminaison a été révoqué), contrôle que le lot est au statut `"paused"` et le refait passer à `"processing"`.

Si le lot n'est pas actuellement à l'état `"paused"`, la requête échoue avec `400 BadRequest` (`batch_not_paused`, ou `run_not_paused` lorsqu'une exécution `FeatureRunner` sous-jacente n'est pas en pause).

### Point de terminaison

```text
POST https://api.verifik.co/v2/smart-batches/{id}/resume
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}/resume` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom  | Type   | Requis | Description |
| ---- | ------ | ------ | ----------- |
| `id` | string | Oui    | ObjectId `SmartBatch` à reprendre. |

### Notes

- La reprise revalide les autorisations de fonctionnalités du client et rejette la requête avec `409 endpoints_not_in_account` si un point de terminaison d'étape n'est plus activé sur votre compte.
- Les lignes terminées conservent leurs résultats enregistrés et ne sont ni réexécutées ni facturées en double à la reprise.
- Si le lot était au statut `"draft"`, `"pending"` ou `"cancelled"`, utilisez plutôt [Démarrer un Smart Batch](/verifik-fr/smart-reports/start-a-smart-batch).
