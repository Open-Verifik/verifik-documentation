Listez les préréglages système Smart Report disponibles pour votre compte. Chaque préréglage inclut sa clé `systemKey`, ses métadonnées (`country`, `category`, `tier`), la disponibilité pour le compte (`available`), les étapes ordonnées `presetSteps`, ainsi qu'un `inputSchema` résolu avec `exampleInput` prêt pour l'exécution headless ou par des agents IA.

L'`inputSchema` résolu exclut automatiquement les paramètres d'exécution internes et les entrées d'étapes déjà fournies via les dépendances chaînées `visitaFlow`, ne conservant que les champs que votre appelant doit fournir. Le listage des préréglages est un appel de découverte en lecture seule et ne consomme pas de crédits. Ce point de terminaison est également exposé en tant qu'outil MCP `smart_report_list_presets`.

### Point de terminaison

```
GET https://api.verifik.co/v2/smart-batch-presets
```

Également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batch-presets` avec votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée sur cette route avec `403 Forbidden`.

### En-têtes

| Nom | Valeur |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

Le jeton doit être un **JWT client**. Des identifiants manquants ou invalides renvoient `401 Unauthorized`.

### Paramètres

Tous les paramètres de requête sont facultatifs. Combinez-les pour filtrer les préréglages par juridiction, catégorie d'entité, niveau ou mot-clé.

| Nom | Type | Requis | Description |
| ---- | ---- | -------- | ----------- |
| `country` | string | Non | Filtre par code pays. Nettoyé des espaces et converti en majuscules par le serveur (par exemple, `CO`). |
| `category` | string | Non | Filtre par catégorie de préréglage. Valeurs autorisées : `citizen`, `company` ou `vehicle`. |
| `tier` | string | Non | Filtre par niveau de profondeur du préréglage. Valeurs autorisées : `essential` ou `comprehensive`. |
| `search` | string | Non | Correspondance par expression régulière insensible à la casse sur `name`, `description` et `systemKey`. |
| `text` | string | Non | Alias de `search`. |

import (

}

### Notes

- `country` est nettoyé des espaces et converti en majuscules avant le filtrage (par exemple, `co` correspond à `CO`).
- `search` et `text` exécutent la même correspondance par expression régulière insensible à la casse sur `name`, `description` et `systemKey`.
- `inputSchema.estimatedCreditsPerRow` estime le coût en crédits par ligne sur l'ensemble des étapes activées du préréglage.
- Lorsque `available` vaut `true`, toutes les fonctionnalités de `presetSteps` sont actives pour l'environnement et prêtes à être clonées avec [Cloner un préréglage de rapport](/verifik-fr/smart-reports/clone-a-report-preset).
- Pour les intégrations d'agents IA, ce point de terminaison correspond à l'outil MCP `smart_report_list_presets`.
