Démarrez l'exécution d'un `SmartBatch` existant. Le lot doit actuellement être au statut `"draft"`, `"pending"` ou `"cancelled"` ; tout autre statut échoue avec `400 BadRequest` (`batch_not_in_startable_state`).

Avant de démarrer, le serveur vérifie que chaque étape activée de la `BatchConfiguration` liée est bien autorisée sur votre compte client (`409 endpoints_not_in_account` si une fonctionnalité est manquante), définit `status: "processing"` et `startedAt`, puis renvoie le `SmartBatch` mis à jour.

### Point de terminaison

```text
POST https://api.verifik.co/v2/smart-batches/{id}/start
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}/start` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom  | Type   | Requis | Description |
| ---- | ------ | ------ | ----------- |
| `id` | string | Oui    | ObjectId `SmartBatch` à démarrer. |

### Notes

- Seuls les lots au statut `"draft"`, `"pending"` ou `"cancelled"` peuvent être démarrés ; les lots en pause doivent utiliser [Reprendre un Smart Batch](/verifik-fr/smart-reports/resume-a-smart-batch).
- Le redémarrage d'un lot `"cancelled"` efface `completedAt` et remet toutes les lignes `"processing"` à `"pending"`.
- Vérifiez au préalable les coûts prévisionnels en crédits via [Estimer le coût d'un Smart Batch](/verifik-fr/smart-reports/estimate-smart-batch-cost) et suivez l'exécution avec [Obtenir la progression d'un Smart Batch](/verifik-fr/smart-reports/get-smart-batch-progress).
