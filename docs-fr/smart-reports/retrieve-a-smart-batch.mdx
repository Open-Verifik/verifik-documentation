Récupérez un seul document `SmartBatch` par identifiant pour le client authentifié. Avant de renvoyer la charge utile, le serveur fusionne les sorties `smartbatchrows` stockées en externe dans `rows[].results` et exécute `healIncompleteRows()` pour rouvrir les lignes marquées `completed` auxquelles il manque des étapes de configuration activées.

Si le lot n'existe pas ou appartient à un autre compte client, le point de terminaison renvoie `200` avec `{ "data": null }`. La lecture d'un lot n'exécute aucune vérification et ne consomme pas de crédits.

### Point de terminaison

```text
GET https://api.verifik.co/v2/smart-batches/{id}
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres de chemin

| Nom  | Type   | Requis | Description |
| ---- | ------ | ------ | ----------- |
| `id` | string | Oui    | ObjectId `SmartBatch`. |

### Paramètres de requête

| Nom           | Type     | Requis | Description |
| ------------- | -------- | ------ | ----------- |
| `select`      | string   | Non    | Expression de projection de champs (par exemple `"-rows"` pour exclure les charges utiles des lignes). |
| `columns`     | string   | Non    | Sous-ensemble de champs à inclure sur le document renvoyé. |
| `populates[]` | string[] | Non    | Documents associés à renseigner : `"batchConfiguration"` et/ou `"client"`. |

### Notes

- Les résultats d'étapes externes `smartbatchrows` sont automatiquement fusionnés dans `rows[].results` lors de la lecture du lot.
- `healIncompleteRows()` inspecte chaque ligne `completed` par rapport aux étapes activées de `batchConfiguration` et remet en `pending` toute ligne à laquelle il manque la sortie d'une étape ou une erreur enregistrée.
- Pour un suivi fréquent du statut, privilégiez [Obtenir la progression d'un Smart Batch](/verifik-fr/smart-reports/get-smart-batch-progress) afin d'éviter de transférer à répétition les charges utiles complètes des lignes.
