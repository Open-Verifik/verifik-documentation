Ajoutez de nouvelles lignes d'entrée à un `SmartBatch` existant sans écraser les lignes existantes ni les résultats enregistrés. Les lignes encapsulées (`{ rowIndex?, inputData }`) comme les lignes plates (`{ rowIndex?, ...inputFields }`) sont acceptées, et le serveur attribue des index de ligne séquentiels à partir de `maxExisting + 1`.

L'ajout de lignes est interdit pendant que le lot est en `"processing"` (`400 batch_append_not_allowed_while_processing`). Si le lot était précédemment au statut `"completed"` ou `"failed"`, l'ajout de lignes réinitialise `status` à `"pending"` et efface `completedAt` afin que les nouvelles lignes puissent être exécutées.

### Point de terminaison

```text
POST https://api.verifik.co/v2/smart-batches/{id}/rows/append
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}/rows/append` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom  | Type   | Requis | Description |
| ---- | ------ | ------ | ----------- |
| `id` | string | Oui    | ObjectId `SmartBatch` auquel ajouter des lignes. |

### Corps de la requête

| Nom    | Type     | Requis | Description |
| ------ | -------- | ------ | ----------- |
| `rows` | object[] | Oui    | Tableau non vide (`min 1`) de lignes d'entrée encapsulées (`{ rowIndex?, inputData }`) ou plates (`{ rowIndex?, ...inputFields }`). Le serveur attribue séquentiellement `rowIndex = maxExisting + 1`. |

Les clés de corps inconnues ou les tableaux `rows` vides sont rejetés par la validation Joi avec `409 MissingParameter`.

package main

import (

		"rows": []map[string]interface{}{
			{

					"documentNumber": "1020304050",

			},
			{
				"documentType":   "CC",
				"documentNumber": "1098765432",
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-batches/"+batchID+"/rows/append", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)

### Notes

- L'ajout de lignes n'exécute aucune vérification et ne consomme pas de crédits ; démarrez ensuite le lot avec [Démarrer un Smart Batch](/verifik-fr/smart-reports/start-a-smart-batch).
- Tout `rowIndex` fourni par le client est ignoré au profit d'une numérotation séquentielle attribuée par le serveur à partir de `maxExisting + 1`.
- Si le lot était au statut `"completed"` ou `"failed"`, son `status` est réinitialisé à `"pending"` et `completedAt` est effacé.
