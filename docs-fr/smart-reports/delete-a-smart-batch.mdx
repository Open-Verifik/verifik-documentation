Supprimez un `SmartBatch` détenu par le client authentifié. Si le lot existe et appartient à votre compte client, le serveur le supprime et renvoie le document `SmartBatch` supprimé dans `data`.

Si l'identifiant du lot n'existe pas ou appartient à un autre client, le point de terminaison renvoie `404` (`not_found`). La suppression d'un lot ne rembourse pas les crédits déjà dépensés.

### Point de terminaison

```text
DELETE https://api.verifik.co/v2/smart-batches/{id}
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom  | Type   | Requis | Description |
| ---- | ------ | ------ | ----------- |
| `id` | string | Oui    | ObjectId `SmartBatch` à supprimer. |

import axios from "axios";

const run = async () => {
  const batchId = "6801a2b3c4d5e6f7a8b9c0d3";

  const { data } = await axios.delete(`https://api.verifik.co/v2/smart-batches/${batchId}`, {

      "Content-Type": "application/json",
      Authorization: `Bearer ${process.env.VERIFIK_JWT}`,

### Notes

- Pour arrêter un lot actif tout en conservant son historique de lignes et ses sorties, utilisez [Annuler un Smart Batch](/verifik-fr/smart-reports/cancel-a-smart-batch) plutôt que de le supprimer.
- Les lots appartenant à un autre compte client renvoient `404` (`not_found`).
