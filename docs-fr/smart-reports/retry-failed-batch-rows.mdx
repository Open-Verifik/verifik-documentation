Remettez en file d'attente les lignes au statut `"failed"` ou `"partial"` sur un `SmartBatch` sans affecter les lignes déjà terminées. Passez facultativement `rowIndexes` pour ne relancer qu'un sous-ensemble spécifique de lignes ; omettez `rowIndexes` pour relancer toutes les lignes `"failed"` et `"partial"` du lot.

La requête échoue avec `409 Conflict` (`batch_is_processing`) si le lot est actuellement au statut `"processing"`. Une réponse avec `retried: 0` indique qu'aucune ligne en échec ou partielle éligible ne correspondait.

### Point de terminaison

```text
POST https://api.verifik.co/v2/smart-batches/{id}/retry-failed
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}/retry-failed` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom  | Type   | Requis | Description |
| ---- | ------ | ------ | ----------- |
| `id` | string | Oui    | ObjectId `SmartBatch`. |

### Corps de la requête

| Nom          | Type      | Requis | Description |
| ------------ | --------- | ------ | ----------- |
| `rowIndexes` | integer[] | Non    | Index de lignes spécifiques basés sur `0` (`>= 0`, `10000` éléments maximum) à relancer. Omettez pour relancer toutes les lignes `"failed"` et `"partial"`. |

Les clés de corps inconnues sont rejetées par la validation Joi avec `409 MissingParameter`.

### Notes

- Envoyez `{}` (ou omettez `rowIndexes`) pour relancer en une seule fois toutes les lignes `"failed"` et `"partial"`.
- Lorsque `rowIndexes` est fourni, les lignes au statut `"completed"` ou `"pending"` sont ignorées même si leur index figure dans le tableau.
- Pour ne réexécuter que certaines séquences d'étapes sur une seule ligne tout en préservant les résultats des autres étapes, utilisez [Relancer les étapes d'une ligne de Smart Batch](/verifik-fr/smart-reports/retry-batch-row-steps).
