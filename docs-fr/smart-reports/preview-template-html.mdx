Effectuez le rendu de n'importe quelle définition de modèle Smart Report en un document HTML autonome entièrement en mémoire. Aucun enregistrement n'est créé ni mis à jour en base de données, et Chromium n'est pas lancé durant le rendu de l'aperçu, garantissant des temps de réponse rapides pour les éditeurs de modèles interactifs, les contrôles de vérification CI et les boucles de conception par IA.

Dans les pipelines headless et IA, utilisez ce point de terminaison pour itérer sur `sections`, `reportTheme`, les marges et les paramètres du score de vérification (`score`, `scoreProfile`, `scoreScale`) avant d'enregistrer le modèle avec [Créer un modèle de rapport](/verifik-fr/smart-reports/create-a-report-template) ou [Mettre à jour un modèle de rapport](/verifik-fr/smart-reports/update-a-report-template). Si vous effectuez le rendu d'un modèle thématique ou noté sans fournir `steps` ou `results` dans `sampleData`, le moteur injecte automatiquement des données d'exemple synthétiques de conducteur afin que votre aperçu reste complet.

### Point de terminaison

```
POST https://api.verifik.co/v2/smart-report-templates/preview-html
```

Le proxy Smart-Agent (`https://ai.verifik.co`) expose les mêmes chemins `/v2/...` et exige votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`.

### En-têtes

| Nom           | Valeur                 |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Corps de la requête

Ce point de terminaison accepte les assistants d'aperçu/notation ainsi que tous les champs publics de conception de modèle (`sections`, `reportTheme`, `sampleData`, `margins`, `pageSize`, `orientation`, `pdfEngine`, `primaryColor`, `identityColor`, `pageBackgroundColor`, `logo`, `header`, `footer`, `legend`, `termsAndConditions`, `watermark`, `showPageNumbers`, `customFonts`, etc.).

| Nom             | Type            | Requis | Description                                                                                                                                    |
| --------------- | --------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`          | string          | Non    | Titre de rapport facultatif affiché dans l'en-tête/les métadonnées de l'aperçu.                                                                |
| `preview`       | boolean         | Non    | Activation du mode aperçu. Vaut `true` par défaut.                                                                                             |
| `score`         | boolean         | Non    | Active le calcul du score de vérification et inclut `verificationScore` dans la réponse.                                                       |
| `scoreProfile`  | string          | Non    | ID de profil de score issu de [Lister les profils de score](/verifik-fr/smart-reports/list-score-profiles). Maximum `64` caractères.           |
| `scoreScale`    | string          | Non    | Échelle d'affichage du score : `"unit"` ou `"percent"`. Assistant d'aperçu de niveau racine ; enregistrez sous `reportTheme.scoreScale` lors de la sauvegarde. |
| `themeTokens`   | object          | Non    | Surcharges de jetons de thème personnalisés. Assistant d'aperçu de niveau racine ; enregistrez sous `reportTheme.tokens` lors de la sauvegarde. |
| `scoreSettings` | object          | Non    | Paramètres de présentation du score. Assistant d'aperçu de niveau racine ; enregistrez sous `reportTheme` (`scoreEnabled`, `scoreProfile`) lors de la sauvegarde. |
| `sections`      | object[]        | Non    | Tableau de blocs `ReportSection` à générer.                                                                                                    |
| `reportTheme`   | string / object | Non    | ID de préréglage de thème (`"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"`) ou objet complet de configuration `reportTheme`.    |
| `sampleData`    | object          | Non    | Payload d'exemple de vérification (`inputData`, `results`, `batchName`, `rowIndex`). S'il est omis sur les aperçus thématiques/notés, un exemple synthétique de conducteur est injecté. |
| `pageSize`      | string          | Non    | `"A4"`, `"Letter"` ou `"Legal"`. Vaut `"A4"` par défaut.                                                                                       |
| `orientation`   | string          | Non    | `"portrait"` ou `"landscape"`. Vaut `"portrait"` par défaut.                                                                                   |
| `margins`       | object          | Non    | Objet de marges `{ "top": 40, "right": 40, "bottom": 40, "left": 40 }`.                                                                        |

import (

	"fmt"

	body, _ := json.Marshal(map[string]interface{}{
		"name":         "Driver Background Preview",
		"preview":      true,
		"score":        true,
		"scoreProfile": "cabify_driver",
		"scoreScale":   "percent",
		"pageSize":     "A4",

			{"id": "sec-breakdown", "type": "categoryBreakdown", "order": 1, "label": "Category Breakdown"},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/preview-html", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notes

- `verificationScore` n'est inclus dans `data` que lorsque le calcul du score de vérification est actif (`score: true` ou activé dans `reportTheme`).
- Comme ce point de terminaison effectue le rendu uniquement en mémoire sans écriture en base ni lancement de Chromium, il est idéal pour itérer rapidement sur la mise en page avant d'appeler [Télécharger un exemple de modèle](/verifik-fr/smart-reports/download-template-sample) pour l'inspection finale de la pagination PDF.
- Lors de l'enregistrement d'une conception prévisualisée via [Créer un modèle de rapport](/verifik-fr/smart-reports/create-a-report-template) ou [Mettre à jour un modèle de rapport](/verifik-fr/smart-reports/update-a-report-template), placez les assistants d'aperçu de niveau racine (`scoreScale`, `themeTokens`, `scoreSettings`) dans `reportTheme` (`reportTheme.scoreScale`, `reportTheme.tokens`, `reportTheme.scoreEnabled`/`reportTheme.scoreProfile`).
