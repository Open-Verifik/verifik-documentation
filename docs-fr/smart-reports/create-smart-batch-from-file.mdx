Importez une charge utile CSV, XLSX ou JSONL dans un nouveau `SmartBatch`. Le serveur décode le texte brut ou les URL de données en base64, applique la limite `MAX_ROWS` (`20000` par défaut), résout les en-têtes de colonnes et les alias en camelCase par rapport aux dépendances d'étapes de votre `BatchConfiguration`, et calcule une estimation du coût en crédits.

Les lignes acceptées sont enregistrées dans le lot au statut `pending`, tandis que les lignes mal formées sont renvoyées dans `rejectedRows`. Passez `autoStart: true` pour vérifier les autorisations de points de terminaison du compte et démarrer le traitement immédiatement ; sinon, aucune vérification n'est exécutée et aucun crédit n'est dépensé.

### Point de terminaison

```text
POST https://api.verifik.co/v2/smart-batches/from-file
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/from-file` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Corps de la requête

| Nom                  | Type    | Requis | Description |
| -------------------- | ------- | ------ | ----------- |
| `batchConfiguration` | string  | Oui    | ObjectId `BatchConfiguration` détenu par le client authentifié. |
| `name`               | string  | Oui    | Nom affiché du lot. `150` caractères maximum. |
| `content`            | string  | Oui    | Texte brut CSV/JSONL ou URL de données en base64 (`data:<mime>;base64,<payload>`). |
| `format`             | string  | Non    | Format d'entrée : `"csv"`, `"xlsx"` ou `"jsonl"`. Par défaut `batchConfiguration.inputFormat` ou `"csv"`. |
| `autoStart`          | boolean | Non    | Définissez `true` pour démarrer le lot créé immédiatement après l'import. |

Les clés de corps inconnues sont rejetées par la validation Joi avec `409 MissingParameter`.

### Notes

- L'analyse de fichier applique `MAX_ROWS` (`20000` par défaut) et génère automatiquement des alias d'en-têtes en camelCase afin que des colonnes comme `Document Number` soient résolues vers `documentNumber`.
- Pour les classeurs `.xlsx`, transmettez une URL de données en base64 (`data:application/vnd.openxmlformats-officedocument.spreadsheetml.sheet;base64,<payload>`) avec `format: "xlsx"`.
- Les erreurs `409 Conflict` incluent `batch_file_has_no_sheets`, `batch_file_is_empty`, `batch_file_has_no_rows`, `batch_file_has_no_usable_rows`, `batch_jsonl_parse_failed_on_line_<N>`, `batch_configuration_has_no_steps` et `endpoints_not_in_account`.
- Les erreurs de validation des lignes (`0` ligne valide), les erreurs de format non pris en charge et les erreurs de dépassement de `MAX_ROWS` renvoient HTTP `500`.
