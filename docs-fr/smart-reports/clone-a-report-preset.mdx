Clonez un préréglage système Smart Report dans votre compte client. L'opération renvoie à la fois un `BatchConfiguration` et un `SmartReportTemplate` lié, prêts à être exécutés immédiatement ou personnalisés davantage.

Ce point de terminaison est **idempotent** pour les comptes clients. Si un modèle client actif cloné depuis `{systemKey}` existe déjà, le serveur réutilise cette configuration et ce modèle (en remappant les séquences d'étapes si nécessaire) et renvoie `reused: true`. Sinon, il crée un nouveau `BatchConfiguration` (avec `inputFormat: "csv"`, `outputFormat: "csv"`, `mergeStrategy: "sequential"`) et un nouveau `SmartReportTemplate` client (`clonedFromSystemKey` défini sur `{systemKey}`) lié via `preferredReportTemplate` avec `reused: false`. Ce point de terminaison est également exposé en tant qu'outil MCP `smart_report_clone_preset`.

### Point de terminaison

```
POST https://api.verifik.co/v2/smart-batch-presets/{systemKey}/clone
```

Également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batch-presets/{systemKey}/clone` avec votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom | Valeur |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

Le jeton doit être un **JWT client**. Des identifiants manquants ou invalides renvoient `401 Unauthorized`.

### Paramètres

| Nom | Type | Requis | Description |
| ---- | ---- | -------- | ----------- |
| `systemKey` | string | Oui | Clé du préréglage issue de [Lister les préréglages de rapport](/verifik-fr/smart-reports/list-report-presets). Nettoyée des espaces, `120` caractères maximum, doit correspondre à `/^[a-z0-9][a-z0-9._-]{1,118}$/i`. |

### Corps de la requête

Aucun corps de requête n'est requis pour ce point de terminaison.

### Notes

- Cloner un préréglage n'exécute aucune consultation et ne consomme aucun crédit.
- Appeler ce point de terminaison de manière répétée avec la même clé `{systemKey}` est sûr et idempotent pour un compte client : la configuration et le modèle clonés existants sont renvoyés avec `reused: true`.
- `409 MissingParameter` est renvoyé lorsque `{systemKey}` échoue à la validation de chemin Joi (par exemple, en dépassant `120` caractères ou en contenant des caractères non pris en charge). `409` avec `preset_has_no_steps` est renvoyé si le préréglage correspondant n'a aucune étape configurée.
- `500 InternalServerError` peut survenir si une fonctionnalité requise par le préréglage n'est pas disponible sur votre compte.
- Une fois cloné, appelez [Récupérer le schéma d'entrée d'une configuration](/verifik-fr/smart-reports/retrieve-configuration-input-schema) avec `batchConfiguration._id` avant de soumettre des lignes, ou utilisez l'outil MCP `smart_report_clone_preset`.
