Mettez en pause un `SmartBatch` actif (ainsi que toute exécution `FeatureRunner` associée) sans perdre les résultats déjà enregistrés pour les lignes terminées. Les workers cessent de prendre en charge les lignes restantes jusqu'à ce que vous repreniez le lot.

Les lots en file d'attente ou navigateur doivent être au statut `"processing"` ou `"pending"` (`400 batch_not_pausable` sinon). Les lots adossés à une exécution `FeatureRunner` requièrent que l'exécution soit au statut `"queued"` ou `"processing"` (`400 run_not_pausable` sinon). La mise en pause ne consomme pas de crédits.

### Point de terminaison

```text
POST https://api.verifik.co/v2/smart-batches/{id}/pause
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-batches/{id}/pause` avec votre propre en-tête `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                               |
| --------------- | ---------------------- | ----------------------------------------- |
| `Content-Type`  | `application/json`     | Format de la charge utile de la requête.  |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT lié au client (`authUser.clientId`).  |

### Paramètres

| Nom  | Type   | Requis | Description |
| ---- | ------ | ------ | ----------- |
| `id` | string | Oui    | ObjectId `SmartBatch` à mettre en pause. |

### Notes

- Pour mettre en pause un lot par programmation, utilisez toujours ce point de terminaison plutôt que `PUT /v2/smart-batches/{id}` (qui n'accepte pas `"paused"`).
- Un lot adossé à `FeatureRunner` renvoie `400 BadRequest` avec `run_not_pausable` si son exécution n'est pas au statut `"queued"` ou `"processing"`.
- Poursuivez l'exécution plus tard via [Reprendre un Smart Batch](/verifik-fr/smart-reports/resume-a-smart-batch), ou interrompez-la définitivement avec [Annuler un Smart Batch](/verifik-fr/smart-reports/cancel-a-smart-batch).
