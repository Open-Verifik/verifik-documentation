Listez les enregistrements `SmartReport` appartenant au client authentifié. Les résultats peuplent `template`, `smartBatch` et `client`, et peuvent être filtrés par `smartBatch`, `template`, `externalRefId` et `createdByChannel`, avec pagination et tri facultatifs.

Lorsque vous passez `page`, la réponse inclut les métadonnées de pagination (`total`, `limit`, `page` et `pages`). Omettez `page` pour recevoir la liste correspondante dans `{ data: [...] }` sans métadonnées de pagination.

### Point de terminaison

```
GET https://api.verifik.co/v2/smart-reports
```

Ce point de terminaison est également accessible via le proxy Smart-Agent à l'adresse `https://ai.verifik.co/v2/smart-reports` en utilisant votre propre en-tête par client `Authorization: Bearer <VERIFIK_JWT>`. L'exécution partagée x402 est bloquée avec `403 Forbidden`.

### En-têtes

| Nom             | Valeur                 | Description                                 |
| --------------- | ---------------------- | ------------------------------------------- |
| `Content-Type`  | `application/json`     | Format du payload de la requête.            |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT limité au client (`authUser.clientId`). |

### Paramètres

| Nom                | Type   | Requis | Description |
| ------------------ | ------ | ------ | ----------- |
| `smartBatch`       | string | Non    | Filtrer les rapports liés à un ObjectId `SmartBatch` spécifique. |
| `template`         | string | Non    | Filtrer les rapports liés à un ObjectId de modèle spécifique. |
| `status`           | string | Non    | Valeurs autorisées : `"draft"`, `"pending"`, `"generating"`, `"generated"`, `"failed"`, `"sent"`. Accepté par la validation Joi pour la compatibilité future ; le filtrage actuel de la liste s'opère sur `smartBatch`, `template`, `externalRefId` et `createdByChannel`. |
| `externalRefId`    | string | Non    | Filtrer par votre identifiant de corrélation externe. Max `200` caractères. |
| `createdByChannel` | string | Non    | Filtrer par canal d'origine : `"portal"`, `"api"`, `"mcp"`, `"x402"` ou `"webhook"`. |
| `page`             | number | Non    | Numéro de page à récupérer. Fournir `page` active la sortie paginée avec `total`, `limit`, `page` et `pages`. |
| `limit`            | number | Non    | Nombre maximal d'éléments par page. Vaut `20` par défaut lorsque `page` est défini. |
| `sort`             | string | Non    | Champ et sens de tri. Vaut `"-updatedAt"` par défaut lorsque `page` est défini. |

#### Notes sur le filtrage et la pagination

- **Paramètre `status` compatible avec les évolutions futures** : Joi valide `status` par rapport à `"draft"`, `"pending"`, `"generating"`, `"generated"`, `"failed"` et `"sent"`, tandis que la requête de liste sous-jacente filtre actuellement par `smartBatch`, `template`, `externalRefId` et `createdByChannel`.
- **Deux formes de réponse `200`** : Envoyez `page` dès que votre tableau de bord ou tâche de synchronisation a besoin de `total` et `pages` ; omettez `page` pour obtenir un payload `{ data: [...] }` plus simple.

package main

import (
	"encoding/json"
	"fmt"
	"net/http"

	"os"

func main() {
	params := url.Values{}
	params.Set("createdByChannel", "api")
	params.Set("externalRefId", "applicant-42")
	params.Set("page", "1")
	params.Set("limit", "20")
	params.Set("sort", "-updatedAt")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-reports?"+params.Encode(), nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notes

- `GET /v2/smart-reports` peuple `template`, `smartBatch` et `client` sur chaque `SmartReport` renvoyé.
- Les valeurs de paramètres de requête invalides échouent à la validation Joi avec `409 MissingParameter`.
- Pour inspecter un rapport individuel avec les champs prêts à l'emploi `downloadUrl` et `htmlUrl`, utilisez [Récupérer un Smart Report](/verifik-fr/smart-reports/retrieve-a-smart-report).
- Pour exécuter un nouveau rapport de bout en bout sans gérer séparément les enregistrements `SmartBatch` et `SmartReport`, utilisez [Exécuter un Smart Report](/verifik-fr/smart-reports/run-a-smart-report).
