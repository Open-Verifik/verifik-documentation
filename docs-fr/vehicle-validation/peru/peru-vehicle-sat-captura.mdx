# Pérou - Ordre de capture véhicule (SAT Lima)

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/captura-lima
```

Vérifiez auprès du SAT de Lima si une **`plaque`** a un ordre de capture dans la province de Lima. Une plaque sans ordre est une réponse réussie : `hasCaptureOrder` vaut `false` et `orders` est vide. Lorsqu'un ordre existe, `message` contient le texte officiel du SAT et chaque élément de `orders` inclut `concept`, `amount` en soles, `period` et `documentNumber`. `status` n'est renseigné que lorsque le SAT l'envoie. `columns` conserve les libellés d'origine lorsque le formulaire public les fournit.

### En-têtes

| Nom          | Valeur              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Paramètres

| Nom    | Type   | Requis | Description                                                                 | Exemple  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | Oui      | Plaque du véhicule, 5 à 8 lettres ou chiffres, sans espaces. `F1E120` a un ordre. `V0R660` n'en a pas.  | `F1E120` |
| `force` | boolean | Non      | Facultatif. Envoyez `true` ou `1` pour ignorer le résultat enregistré et interroger à nouveau le SAT.  | `true` |

### Notes

- La recherche couvre uniquement la province de Lima.
- Envoyez `plate` sans espaces ni tirets (5 à 8 caractères alphanumériques).
- Une plaque sans ordre de capture renvoie quand même **HTTP 200**. Le **404** concerne seulement une plaque qui n'a pas 5 à 8 lettres ou chiffres.
- `amount` est formaté en soles (`S/ 505.86`). `status` reste vide lorsque le SAT n'envoie pas de statut.
- `F1E120` a un ordre de capture. `V0R660` n'en a pas.
- Si le SAT ne peut pas être consulté, l'API renvoie **409** avec `Endpoint_out_of_service`.
- En **mode sandbox**, `ABC10001` a un ordre de capture et `ABC10002` n'en a pas.
