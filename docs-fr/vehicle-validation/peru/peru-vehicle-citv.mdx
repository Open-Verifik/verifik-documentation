# Pérou - Certificat d'inspection technique (CITV)

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/inspeccion-tecnica
```

Consultez les certificats d'inspection technique (**CITV**) enregistrés auprès du ministère des Transports du Pérou (**MTC**) pour une **`plaque`**. La réponse indique si un certificat a été trouvé (`found`), si l'un est actuellement valide (`hasValidCertificate`), le certificat le plus récent (`latestCertificate`) et tous les certificats renvoyés par la source (`certificates`).

### En-têtes

| Nom          | Valeur              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Paramètres

| Nom    | Type   | Requis | Description                                                                 | Exemple  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | Oui      | Plaque du véhicule, 5 à 8 lettres ou chiffres, sans espaces. Exemple : `V0R660`.  | `V0R660` |
| `force` | boolean | Non      | Facultatif. Envoyez `true` ou `1` pour ignorer le résultat enregistré et interroger à nouveau le MTC.  | `true` |

### Notes

- Envoyez `plate` sans espaces ni tirets (5 à 8 caractères alphanumériques).
- `hasValidCertificate` vaut `true` lorsqu'au moins un certificat a le statut `VIGENTE`.
- `latestCertificate` est le premier certificat renvoyé par le MTC. `certificates` liste tous les enregistrements de cette plaque. `V0R660` a actuellement deux certificats valides.
- Une plaque sans certificat, ou une plaque qui n'a pas 5 à 8 lettres ou chiffres, renvoie **404**.
- Si la source du MTC est indisponible, l'API renvoie **409** avec `Endpoint_out_of_service`.
- En **mode sandbox**, `ABC10001` renvoie un certificat valide (`VIGENTE`) et `ABC10002` un certificat expiré (`VENCIDO`).
