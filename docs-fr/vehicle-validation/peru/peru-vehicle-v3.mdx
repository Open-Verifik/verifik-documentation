# Pérou — Informations véhicule (v3)

### Endpoint

```
GET https://api.verifik.co/v3/pe/vehiculo/placa
```

Le service v3 d'informations véhicule du Pérou retourne les données officielles d'immatriculation par **`plate`** ainsi que la fiche technique `technicalSheet` (`engine`, `performance` et `dimensions` : longueur, largeur, hauteur, empattement, poids à vide, réservoir, portes et places) lorsqu'elle est disponible.

### En-têtes (Headers)

| Nom           | Valeur             |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Paramètres

| Nom     | Type   | Requis  | Description                                                 | Exemple  |
| ------- | ------ | ------- | ----------------------------------------------------------- | -------- |
| `plate` | string | **Oui** | Numéro de plaque à interroger, sans espaces ni points.      | `ABC123` |

### Requête (Request)

<Tabs>
<TabItem value="javascript" label="JavaScript">

```javascript
import axios from 'axios';

const { data } = await axios.get('https://api.verifik.co/v3/pe/vehiculo/placa', {
  params: { plate: 'ABC123' },
  headers: { Accept: 'application/json', Authorization: 'Bearer <votre_token>' },
});
console.log(data);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import http.client

conn = http.client.HTTPSConnection("api.verifik.co")
headers = {"Accept": "application/json", "Authorization": "Bearer <votre_token>"}
conn.request("GET", "/v3/pe/vehiculo/placa?plate=ABC123", headers=headers)
print(conn.getresponse().read().decode("utf-8"))
```

### Notes

- `technicalSheet` (dont `dimensions` : `length`, `width`, `height`, `wheelbase`, `curbWeight`, `fuelTank`, `doors`, `occupants`) peut être `null` ou partiel selon la disponibilité technique du modèle.
- En **mode sandbox**, les plaques `ABC10001`–`ABC10010` retournent des profils stables.
