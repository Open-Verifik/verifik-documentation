# Pérou — Permis taxi SETARE Arequipa

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/setare-arequipa
```

Vérifie si un véhicule détient une autorisation taxi **SETARE** à Arequipa (Pérou) à partir de sa plaque (**`plate`**) et retourne `hasActivePermit`, `latestPermit` et `permits` depuis les registres municipaux officiels.

### En-têtes (Headers)

| Nom           | Valeur             |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Paramètres

| Nom     | Type   | Requis  | Description                                                                   | Exemple  |
| ------- | ------ | ------- | ----------------------------------------------------------------------------- | -------- |
| `plate` | string | **Oui** | Numéro de plaque à consulter (6 caractères alphanumériques, ex. `V3D236`).    | `V3D236` |

### Requête (Request)

<Tabs>
<TabItem value="javascript" label="JavaScript">

```javascript
import axios from 'axios';

const { data } = await axios.get('https://api.verifik.co/v2/pe/vehiculo/setare-arequipa', {
  params: { plate: 'V3D236' },
  headers: { Accept: 'application/json', Authorization: 'Bearer <votre_token>' },
});
console.log(data);
```

### Notes

- Saisissez `plate` sans espaces ni tirets (6 caractères alphanumériques).
- En **mode sandbox**, `ABC10001` retourne un permis actif (`Vigente`) et `ABC10002` retourne un permis expiré (`Vencido`).
