# RUNT — Véhicule par plaque uniquement

Interrogez les informations officielles RUNT d’un véhicule avec **uniquement** la plaque. Contrairement à [Véhicule par plaque (complet)](/verifik-fr/vehicle-validation/colombia/runt-vehicle-by-plate), cet endpoint **n’exige pas** le `documentType` ni le `documentNumber` du titulaire.

Utilisez-le lorsque vous avez besoin des blocs d’identité, techniques et de statut d’une plaque colombienne sans le document du propriétaire.

## Que renvoie l’API ?

- **`informacionGeneral`** — plaque, marque, ligne, modèle, classe, service, statut et champs d’immatriculation lorsqu’ils sont présents
- **`datosTecnicos`** — champs techniques lorsqu’ils sont présents
- Blocs temporels tels que **`soat[]`** et **`tecnoMecanica[]`** lorsqu’ils sont présents
- Autres blocs RUNT (`solicitudes`, `polizasResponsabilidadCivil` et similaires) lorsque la réponse les inclut
- **`documentType`** et **`documentNumber`** peuvent être `null`
- Réponse **signée** par Verifik

## Référence API

### Endpoint

```
GET https://api.verifik.co/v2/co/runt/placas
```

Envoyez **`plate`** en **paramètre de requête**. Le handler renvoie la forme complète du véhicule RUNT. Les sections d’identité, techniques et de statut sont incluses lorsqu’elles sont disponibles. Les champs de document du titulaire ne sont pas obligatoires et peuvent revenir à `null`.

### En-têtes

| Nom | Valeur |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Paramètres

| Nom | Type | Obligatoire | Description | Exemple |
| --- | --- | --- | --- | --- |
| `plate` | string | Oui | Plaque colombienne de **5 à 9** caractères alphanumériques. | `AA123BA` |

### Notes

- Le code AppFeature est **`colombia_api_runt_placas`**.
- Cette route est la sœur « plaque seule » de [GET `/v2/co/runt/vehicle-by-plate`](/verifik-fr/vehicle-validation/colombia/runt-vehicle-by-plate). Elle n’accepte pas le `documentType` ni le `documentNumber` du titulaire.
- `documentType` et `documentNumber` du payload peuvent être `null`.
- Les blocs d’identité, techniques et de statut sont renvoyés lorsqu’ils existent ; un tableau ou un objet vide signifie que la section n’avait aucune ligne.
- Dans le sandbox, **`AA123BA`** et **`ABC10001`–`ABC10010`** renvoient des 200 stables. **`ERR40401`** renvoie **404** `NotFound`.
- **409** est utilisé pour les erreurs de validation et lorsque le service est temporairement indisponible.
