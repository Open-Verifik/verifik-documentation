### Endpoint

```
GET https://api.verifik.co/v2/co/runt/conductor
```

Interroge le **RUNT** pour le **permis de conduire** avec **`documentType`** et **`documentNumber`**. La réponse peut inclure statut, catégories, certificats, demandes et indication de sanctions.

Sans `primerApellido` : tarif **Premium** (résolution du nom). Avec `primerApellido` : tarif **Basic**, comme [`/v3/co/runt/conductor`](/vehicle-validation/colombia/runt-drivers-license-basic).

### En-têtes

| Nom | Valeur |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Paramètres

| Nom | Type | Obligatoire | Description |
| --- | --- | --- | --- |
| `documentType` | string | Oui | Un de **`CC`**, **`CE`**, **`PA`**, **`PPT`**. Voir le tableau — **`PA` est le passeport, `PPT` ne l’est pas**. |
| `documentNumber` | string | Oui | Numéro sans espaces ni ponctuation. |
| `primerApellido` | string | Conditionnel | Premier nom de famille. **Obligatoire pour `PA`**. Optionnel pour `CC`, `CE` et `PPT`. Procuraduría et `/v2/co/cedula` ne consultent pas les passeports. |

### Types de document

N’envoyez pas `PPT` lorsque RUNT affiche **`P.`** — c’est un **passeport (`PA`)**. `PPT` est un permis d’immigration.

| Code | Nom complet | Titulaire | Libellé RUNT | `primerApellido` |
| --- | --- | --- | --- | --- |
| **`CC`** | *Cédula de Ciudadanía* | Citoyens colombiens (pièce nationale) | `C.` | Optionnel |
| **`CE`** | *Cédula de Extranjería* | Résidents étrangers en Colombie | `E.` | Optionnel |
| **`PA`** | *Pasaporte* (passeport) | Titulaires de passeport | `P.` | **Obligatoire** |
| **`PPT`** | *Permiso por Protección Temporal* | Permis temporaire vénézuélien — **pas un passeport** | `Y.` | Optionnel |

### Notes

- La structure dépend du retour **RUNT**.
- Types de document validés sur cet endpoint : **`CC`**, **`CE`**, **`PA`** (passeport), **`PPT`**.
- `primerApellido` est obligatoire pour **`PA`** et optionnel pour **`CC`**, **`CE`**, **`PPT`**.
