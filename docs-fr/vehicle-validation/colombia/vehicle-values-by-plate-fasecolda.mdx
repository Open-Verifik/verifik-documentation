L'API Fasecolda de valeurs de véhicules par plaque de Verifik récupère les valorisations commerciales officielles et les spécifications techniques des véhicules immatriculés en Colombie. Pour maximiser le taux de réussite sur les voitures, SUV, pick-up, poids lourds et motos, ce point de terminaison combine **deux sources officielles complémentaires** :

1. **Résolution primaire (index direct plaque-code)** : résout directement la plaque lorsque le code Fasecolda est rattaché à l'immatriculation.
2. **Résolution secondaire (croisement des spécifications techniques entre sources)** : lorsque la plaque n'a pas de code direct, Verifik vérifie les spécifications techniques (`brand`, `line`, `cylinderCapacity`, `year`, `vehicleClass`) auprès d'un registre officiel secondaire et les croise avec le catalogue Fasecolda (`matchSource: "runt_fallback"`), en renvoyant `matchConfidence`, `matchNote`, `matchDetails` et `runtVehicle`.

### Endpoint

```
GET https://api.verifik.co/v2/co/fasecolda/values-by-plate
```

Le service de valorisation Fasecolda fournit les données complètes des véhicules immatriculés en Colombie (`code`, `marke`, `line1`, `line2`, `line3`, `class`, `cylinderCapacity`, `bcpp`, `valueModel`, ainsi que `matchDetails` lors d'un croisement entre sources). Passez la **plaque** en paramètre **`plate`**.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | Yes | Plaque d'immatriculation colombienne (voiture ou moto). Les espaces, tirets et points sont supprimés automatiquement. | `ABC123` |

### Notes

- **Couverture à double source (voitures et motos)** : combine l'index direct par plaque et le croisement des spécifications techniques officielles avec le catalogue Fasecolda (`matchSource: "runt_fallback"`).
- **Formule de confiance (`matchConfidence` et `matchDetails`)** : calculée selon `0.55 * textScore + 0.25 * ccScore + 0.20 * yearScore` (seuil minimal `0.60`), avec détail des pénalités dans `matchDetails.penalties`.
- **Unités de valorisation** : `valueModel` contient les valeurs historiques par année modèle et `bcpp` indique le prix commercial de base en pesos colombiens (COP).
