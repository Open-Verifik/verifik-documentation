### Endpoint

```
GET https://api.verifik.co/v3/co/runt/conductor
```

Même consultation que [Premium v2](/vehicle-validation/colombia/runt-drivers-license) (`GET /v2/co/runt/conductor`), au prix **Basic** du conducteur. `primerApellido` est **obligatoire** (2 caractères minimum) pour chaque type, y compris `TI`. Sans ce champ : `409 MissingParameter`. Cet endpoint ne cherche pas le nom et n’ajoute pas le prix RUI.

Envoyer `primerApellido` sur v2 facture ce même prix Basic.

| | Premium `GET /v2/co/runt/conductor` | Basic `GET /v3/co/runt/conductor` |
| --- | --- | --- |
| Nom de famille (`primerApellido`) | Facultatif, sauf **`PA`**. Verifik le trouve si vous l’omettez. | Obligatoire pour chaque type (2 caractères minimum). |
| Types de document | `CC`, `TI`, `CE`, `PA`, `PPT` | `CC`, `TI`, `CE`, `PA`, `PPT` |
| Facturation | Sans nom : **Premium**. `TI` sans nom : prix catalogue conducteur + prix catalogue RUI (`GET /v2/co/rui`). Avec nom : **Basic**, le même prix que v3. | Prix **Basic**. Pas de recherche du nom et pas de prix RUI. |

### Paramètres

| Nom | Type | Obligatoire | Description |
| --- | --- | --- | --- |
| `documentType` | string | Oui | **`CC`**, **`TI`**, **`CE`**, **`PA`**, **`PPT`**. **`TI`** est la tarjeta de identidad. |
| `documentNumber` | string | Oui | Numéro sans espaces. |
| `primerApellido` | string | **Oui** | Premier nom de famille (2 caractères minimum), y compris pour `TI`. |

### Requête

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
const { data } = await axios.get("https://api.verifik.co/v3/co/runt/conductor", {
	params: { documentType: "CC", documentNumber: "123456789", primerApellido: "GARCIA" },
	headers: { Accept: "application/json", Authorization: `Bearer ${process.env.VERIFIK_TOKEN}` },
});
```

  </TabItem>
  <TabItem value="curl-ti" label="curl (TI)">

```bash
curl -G "https://api.verifik.co/v3/co/runt/conductor" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  --data-urlencode "documentType=TI" \
  --data-urlencode "documentNumber=1002003001" \
  --data-urlencode "primerApellido=EJEMPLO"
```

Valeurs fictives. `primerApellido` est obligatoire. Prix Basic, sans prix RUI.
