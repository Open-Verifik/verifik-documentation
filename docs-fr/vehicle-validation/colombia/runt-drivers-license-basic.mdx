### Endpoint

```
GET https://api.verifik.co/v3/co/runt/conductor
```

Même consultation RUNT que [Premium v2](/vehicle-validation/colombia/runt-drivers-license), au **tarif conducteur actuel**. `primerApellido` est **obligatoire**. Sans ce champ : `409 MissingParameter`.

### Paramètres

| Nom | Type | Obligatoire | Description |
| --- | --- | --- | --- |
| `documentType` | string | Oui | **`CC`**, **`CE`**, **`PA`**, **`PPT`**. |
| `documentNumber` | string | Oui | Numéro sans espaces. |
| `primerApellido` | string | **Oui** | Premier nom de famille (min. 2). |

### Requête

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
const { data } = await axios.get("https://api.verifik.co/v3/co/runt/conductor", {
	params: { documentType: "CC", documentNumber: "123456789", primerApellido: "GARCIA" },
	headers: { Accept: "application/json", Authorization: `Bearer ${process.env.VERIFIK_TOKEN}` },
});
```
