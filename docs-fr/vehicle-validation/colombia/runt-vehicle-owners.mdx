Consultez les données de base d’un véhicule colombien et ses historiques de propriété uniquement avec sa plaque. Ce service convient à la vérification de propriété, à l’intégration et aux contrôles préalables.

### Endpoint

```
GET https://api.verifik.co/v2/co/runt/vehiculo/owners
```

La réponse contient `plate`, `brand`, `line`, `model` et un tableau `owners` avec l’identité, la période de propriété, le financement, le gage et l’immatriculation lorsqu’ils sont disponibles. Contrairement à **`GET /v2/co/runt/propietarios`**, cet endpoint part d’une plaque et renvoie des données normalisées sur le véhicule et ses propriétaires.

### En-têtes

| Nom | Valeur |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Paramètres

| Nom | Type | Obligatoire | Description | Exemple |
| --- | --- | --- | --- | --- |
| `plate` | string | Oui | Plaque colombienne composée de 5 à 9 caractères alphanumériques. | `CRL299` |

### Requête

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.get("https://api.verifik.co/v2/co/runt/vehiculo/owners", {
	params: { plate: "CRL299" },
	headers: {
		Accept: "application/json",
		Authorization: `Bearer ${process.env.VERIFIK_TOKEN}`,
	},
});
console.log(data);
```

  </TabItem>
  <TabItem value="python" label="Python">

```python
import os, requests

url = "https://api.verifik.co/v2/co/runt/vehiculo/owners"
```

### Notes

- Le code AppFeature est **`colombia_api_vehicle_owners`**.
- Utilisez **`CRL299`** dans le sandbox.
- Les propriétés d’un propriétaire peuvent être `null` et `owners` peut contenir plusieurs historiques.
- **`GET /v2/co/runt/propietarios`** suit un autre flux de recherche ; ce n’est pas un alias de cet endpoint par plaque.
