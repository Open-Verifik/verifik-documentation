# 🇨🇱 Chili — Véhicule volé

Vérifiez si un véhicule chilien a un **signalement de vol actif** (*encargo por robo o hurto*).

Charge utile signée lorsque la consultation répond :

- **`plate`** — Plaque chilienne (Patente), **4–7** caractères alphanumériques
- **`hasTheftReport`** — `true` s'il y a un encargo actif ; `false` sinon
- **`description`** — texte de statut (ex. `NO REGISTRA ENCARGO Vigentes`)
- **`theftReport`** — objet du signalement : **`typeCode`**, **`plateOriginal`**, **`plateFormatted`**, **`reportDate`**, **`partiallyResolved`**, **`items`**
- **`items[]`** — pièces volées : **`name`**, **`description`**, **`serial`**, **`resolvedDate`**, **`delivered`**, **`deliveryDate`**, **`type`**
- Réponse **signée** Verifik

Utile pour la **souscription d'assurance**, l'**onboarding de flottes** et la **due diligence** avant d'enregistrer ou de financer un véhicule chilien.

### Endpoint

```
GET v2/cl/vehicle-stolen
```

Champs typiques : **`plate`**, **`hasTheftReport`**, **`description`** et **`theftReport`**. Un véhicule sans encargo actif renvoie quand même **HTTP 200**.

### En-têtes

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Paramètres

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | **Yes** | Plaque chilienne (Patente), 4–7 caractères alphanumériques. | `PTKX93` |

### Notes

- **Aucun signalement actif** renvoie **HTTP 200** avec **`hasTheftReport: false`** — ce n'est pas un 404.
- **Mode sandbox :** la plaque **`PTKX93`** renvoie un profil sans encargo ; **`NG8245`** renvoie un signalement de vol.
- Un format de plaque invalide renvoie **409** `invalid_plate_format`.
- La **disponibilité** du registre dépend de l'environnement ; une panne peut renvoyer **409** timeout.
