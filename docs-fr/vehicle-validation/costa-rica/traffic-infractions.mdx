# Costa Rica — Infractions routières

La consultation des **infractions routières du Costa Rica** lit les amendes COSEVI d'une plaque. `plate` est obligatoire et doit compter 3 à 6 caractères. Un échec de validation répond HTTP 409 avec le code `409:invalid_params`, pas `MissingParameter`. Une plaque sans amende est un 404 `NotFound`.

## Ce que l'appel renvoie

- `plate` et `totalRecords`
- `infractions[]` avec statut et montants

## Cas d'usage

- Contrôlez les amendes avant d'immatriculer un véhicule.
- Rejetez une plaque qui n'a pas 3 à 6 caractères.
- Lisez le montant total de chaque amende.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/cr/traffic-infractions
```

Une correspondance contient `plate`, `totalRecords` et `infractions` avec série, numéro, date, statut, autorité et montants.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **Oui** | `123456` | Plaque, 3 à 6 caractères, sans espaces. Une plaque absente ou de mauvaise longueur répond avec le code `409:invalid_params`. |

### Notes

- `plate` doit compter 3 à 6 caractères.
- Les plaques invalides répondent avec le code `409:invalid_params`.
- Aucune amende pour cette plaque est un 404 `NotFound`.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `plate: "123456"` | 200 avec infractions. |
| Valeur obligatoire absente | Omit `plate` | 409 avec le code `409:invalid_params`. |
| Valeur inconnue | `plate: "ABC"` | 404 NotFound si COSEVI n'a pas d'amende. |

401 when the bearer token is missing or rejected.
