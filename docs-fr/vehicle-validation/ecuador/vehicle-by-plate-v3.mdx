# Équateur — Véhicule par plaque (v3)

La consultation **véhicule v3 d'Équateur** est `GET /v3/ec/vehiculo/placa`. `plate` est obligatoire. Le corps contient les champs d'identification (`vin`, `brand`, `model`, `year`, `color` et données de plaque), un objet `revision` avec les dates d'inspection et un `technicalSheet` avec moteur, performances et dimensions.

## Ce que l'appel renvoie

- Identification : `vin`, `brand`, `model`, `year`, `color`
- `revision` avec inspections
- `technicalSheet.engine`, `performance` et `dimensions`

## Cas d'usage

- Confirmez un véhicule avant l'assurance.
- Lisez la dernière année d'inspection.
- Conservez le VIN avec la plaque.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v3/ec/vehiculo/placa
```

Attendez `plate`, les champs d'identification, `revision` et `technicalSheet`. Une plaque inconnue est un 404 `NotFound`.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **Oui** | `ABC1234` | Plaque équatorienne. Obligatoire. |

### Notes

- Le chemin est en version 3 : `/v3/ec/vehiculo/placa`.
- `plate` est le seul paramètre obligatoire.
- Une plaque inconnue est un 404 `NotFound`.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `plate: "ABC1234"` | 200 avec identification, revision et technicalSheet. |
| Valeur obligatoire absente | Omit `plate` | 409 MissingParameter. |
| Valeur inconnue | `plate: "ZZZ0000"` | 404 NotFound si la plaque est inconnue. |

401 when the bearer token is missing or rejected.
