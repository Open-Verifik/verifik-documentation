# Messagerie WhatsApp

**Messagerie WhatsApp** est **POST** `https://api.verifik.co/v2/communication/whatsapp`, pas GET. Le corps exige `phone` et `countryCode`. La route fixe `phoneGateway` à `whatsapp`. `whatsappTemplate` facultatif vaut `authentication` (le défaut) ou `flow2`. Avec `flow2`, `language` choisit `flow2_es` ou `flow2_en`, et `title` facultatif (1 à 15 caractères) est la section de marque.

## Ce que l'appel renvoie

- `phone` et `countryCode`
- `phoneGateway` à `whatsapp`
- `status`

## Cas d'usage

- Envoyez un code de connexion sur WhatsApp.
- Choisissez flow2 si vous voulez un modèle de marque.
- Laissez authentication comme modèle par défaut.

---

## Référence de l'API

### Endpoint

```http
POST https://api.verifik.co/v2/communication/whatsapp
```

Un envoi réussi renvoie `phoneGateway` `whatsapp` et le statut `sent`.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `phone` | string | **Oui** | `3001234567` | Numéro national seulement. |
| `countryCode` | string | **Oui** | `+57` | Indicatif qui commence par `+`. |
| `whatsappTemplate` | string | Non | `authentication` | Facultatif. `authentication` (défaut) ou `flow2`. |
| `language` | string | Non | `es` | Facultatif. Avec `flow2`, choisit `flow2_es` ou `flow2_en`. |

### Notes

- Cette route est POST, pas GET.
- `whatsappTemplate` est facultatif : `authentication` ou `flow2`.
- La route fixe `phoneGateway` à `whatsapp`.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `phone: "3001234567"`, `countryCode: "+57"` | 200 lorsque l'OTP WhatsApp est envoyé. |
| Valeur obligatoire absente | Omit `countryCode` | 409 MissingParameter. |
| Valeur inconnue | `whatsappTemplate: "flow2"`, `language: "es"` | 200 avec le modèle flow2 si language vaut es. |

401 when the bearer token is missing or rejected.
