# OTP par e-mail

**OTP par e-mail** envoie un code à usage unique. La méthode réelle est **POST** `https://api.verifik.co/v2/communication/email`, pas GET. Le corps exige `project`, `validationMethod` (`manual` ou `verificationCode`), `email` et `type` (`validation`, `login`, `onboarding` ou `oneTimeLink`). Champs facultatifs : `expiresAt`, `redirectUrl`, `webhookUrl`, `identityUrl`, `requires2FA`, `ipAddress` et `language`.

## Ce que l'appel renvoie

- `email` et `status`
- `type` et `validationMethod`

## Cas d'usage

- Envoyez un code de connexion à une boîte.
- Démarrez une entrée en relation qui continue par e-mail.
- Attachez un webhook d'état de livraison.

---

## Référence de l'API

### Endpoint

```http
POST https://api.verifik.co/v2/communication/email
```

Un envoi réussi renvoie la validation e-mail avec le statut `sent`. Confirmez le code avec l'endpoint de validation e-mail que votre projet utilise déjà.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `project` | string | **Oui** | `project_id` | Identifiant du projet propriétaire de l'OTP e-mail. |
| `validationMethod` | string | **Oui** | `verificationCode` | `manual` ou `verificationCode`. |
| `email` | string | **Oui** | `person@example.com` | Boîte qui reçoit le code. Une adresse invalide est un 409. |
| `type` | string | **Oui** | `validation` | `validation`, `login`, `onboarding` ou `oneTimeLink`. |

### Notes

- Cette route est POST, pas GET.
- `project`, `validationMethod`, `email` et `type` sont obligatoires.
- Une adresse qui n'est pas un e-mail est un 409.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | the example body | 200 lorsque le code est envoyé. |
| Valeur obligatoire absente | Omit `project` | 409 MissingParameter. |
| Valeur inconnue | `email: "not-an-email"` | 409 si le format d'e-mail est invalide. |

401 when the bearer token is missing or rejected.
