# Messagerie SMS

**Messagerie SMS** est **POST** `https://api.verifik.co/v2/communication/sms`, pas GET. Le corps exige `phone` et `countryCode` (un indicatif qui commence par `+`). La route fixe `phoneGateway` à `sms`, donc n'envoyez pas ce champ. `title` facultatif compte 1 à 15 caractères et `language` choisit le texte. Les jetons du propriétaire du compte peuvent l'appeler. Un utilisateur staff a besoin du droit d'exécution Smart Tools.

## Ce que l'appel renvoie

- `phone` et `countryCode`
- `phoneGateway` à `sms`
- `status`

## Cas d'usage

- Envoyez un code de connexion par SMS.
- Utilisez un numéro national plus l'indicatif.
- Laissez la route choisir la passerelle SMS.

---

## Référence de l'API

### Endpoint

```http
POST https://api.verifik.co/v2/communication/sms
```

Un envoi réussi renvoie `phoneGateway` `sms` et le statut `sent`. Vous êtes facturé lorsque l'OTP est remis.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `phone` | string | **Oui** | `3001234567` | Numéro national seulement. N'incluez pas l'indicatif. |
| `countryCode` | string | **Oui** | `+57` | Indicatif qui commence par `+`. |
| `title` | string | Non | `ACME` | Nom d'expéditeur facultatif, 1 à 15 caractères. |
| `language` | string | Non | `es` | Langue facultative du modèle. |

### Notes

- Cette route est POST, pas GET.
- `phone` et `countryCode` sont obligatoires. `countryCode` doit commencer par `+`.
- N'envoyez pas `phoneGateway` ; la route le fixe à `sms`.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `phone: "3001234567"`, `countryCode: "+57"` | 200 lorsque l'OTP SMS est envoyé. |
| Valeur obligatoire absente | Omit `phone` | 409 MissingParameter. |
| Valeur inconnue | `countryCode: "57"` | 409 si countryCode ne commence pas par +. |

401 when the bearer token is missing or rejected.
