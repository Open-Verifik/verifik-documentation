# Scan Agent

**Scan Agent** extrait des champs structurés de l'image d'un document. Appelez **POST** `https://api.verifik.co/v2/ocr/scan-gpt`. `image` est obligatoire. `documentType`, `backImage` et `template` sont facultatifs. Ce corps n'a pas de champ `country`. L'extraction enregistrée met `validationMethod` à `SCAN_AGENT`.

## Ce que l'appel renvoie

- `documentType`, `documentNumber` et nom extraits
- `validationMethod` — `SCAN_AGENT`

## Cas d'usage

- Lisez un document d'identité depuis une image.
- Ajoutez l'image verso si la carte a un second côté.
- Fixez un modèle si la mise en page est connue.

---

## Référence de l'API

### Endpoint

```http
POST https://api.verifik.co/v2/ocr/scan-gpt
```

Une correspondance contient les champs extraits et `validationMethod` `SCAN_AGENT`. L'URL reste `/v2/ocr/scan-gpt`.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `image` | string | **Oui** | `data:image/jpeg;base64,AAAA` | Image recto en base64 ou data URI. Obligatoire. |
| `documentType` | string | Non | `CC` | Famille de document facultative, comme `CC` ou `DNI`. |
| `backImage` | string | Non | `data:image/jpeg;base64,BBBB` | Image verso facultative. |
| `template` | string | Non | `template_id` | Identifiant de modèle facultatif. |

### Notes

- `image` est obligatoire. `documentType`, `backImage` et `template` sont facultatifs.
- N'envoyez pas de champ pays. Ce corps n'en accepte pas.
- La méthode enregistrée est `SCAN_AGENT` et l'URL reste `/v2/ocr/scan-gpt`.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `image` plus `documentType: "CC"` | 200 avec les champs extraits et validationMethod SCAN_AGENT. |
| Valeur obligatoire absente | Omit `image` | 409 MissingParameter. |
| Valeur inconnue | `image` and `backImage` | 200 si une image verso est aussi envoyée. |

401 when the bearer token is missing or rejected.
