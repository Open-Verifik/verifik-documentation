# Détection de visage

**Détection de visage** est `POST /v2/face-recognition/face-validation`, un alias du moteur de détection. `image` est obligatoire. Si vous les omettez, cette route met `min_score` à `0.5` et `search_mode` à `FAST`. La charge réelle est `face_count`, `faces` (chacun avec `score` et `bbox`), `imageDimensions` et `engine`.

## Ce que l'appel renvoie

- `face_count`
- `faces[].score` et `faces[].bbox`
- `imageDimensions` et `engine`

## Cas d'usage

- Comptez les visages avant la preuve de vie.
- Lisez la boîte du visage principal.
- Utilisez le score et le mode par défaut si vous n'avez que l'image.

---

## Référence de l'API

### Endpoint

```http
POST https://api.verifik.co/v2/face-recognition/face-validation
```

Lisez d'abord `face_count`. Chaque élément de `faces` a `score` et `bbox`. `imageDimensions` est la largeur et la hauteur décodées. `engine` nomme le détecteur.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `image` | string | **Oui** | `data:image/jpeg;base64,AAAA` | Image du visage en base64 ou data URI. Obligatoire. |
| `min_score` | number | Non | `0.5` | Facultatif. Cette route le met à `0.5` par défaut. |
| `search_mode` | string | Non | `FAST` | Facultatif. Cette route le met à `FAST` par défaut. L'autre valeur est `ACCURATE`. |

### Notes

- `image` est le seul champ obligatoire.
- Un `min_score` omis devient `0.5` et un `search_mode` omis devient `FAST`.
- La réponse utilise `bbox`, pas un objet de repères séparé.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `image` only | 200 avec face_count, faces, imageDimensions et engine. |
| Valeur obligatoire absente | Omit `image` | 409 MissingParameter. |
| Valeur inconnue | `min_score: 0.8`, `search_mode: "ACCURATE"` | 200 avec le score et le mode envoyés. |

401 when the bearer token is missing or rejected.
