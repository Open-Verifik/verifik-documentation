# 🇨🇱 Chili — Registre de blocage de permis de conduire

Interrogez le registre national des blocages de permis de conduire du **Servicio de Registro Civil e Identificación** par RUN.

Contrairement aux portails municipaux qui ne couvrent qu'une seule commune, ce point de terminaison offre une **couverture nationale** des blocages et suspensions de permis de conduire ordonnés par les tribunaux ou les autorités civiles au Chili.

### Point d'accès

```
GET https://api.verifik.co/v2/cl/driver-license/block
```

### En-têtes (Headers)

| Nom           | Valeur             |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Paramètres

| Nom | Type | Requis | Description | Exemple |
| --- | ---- | ------ | ----------- | ------- |
| `documentNumber` | string | **Oui** | RUN chilien avec chiffre de contrôle (DV). Points et tirets facultatifs (`18.347.440-5` ou `18347440-5`). Le chiffre de contrôle doit être valide. | `18347440-5` |
| `force` | boolean | Non | Booléen optionnel ou `1`/`true` pour contourner le cache serveur et interroger directement le Registro Civil. | `false` |

## Fonctionnalités

- **Registre National** : Données officielles du Registro Civil e Identificación du Chili.
- **Statut de suspension immédiat** : Confirmation immédiate des restrictions de permis (`hasBlock: true/false`).
- **Vérification du titulaire** : Renvoie le nom légal complet enregistré avec la licence.
- **Métadonnées de blocage** : Date de l'ordonnance judiciaire, type et motif de la restriction.
- **Protection par chiffre de contrôle** : Validation automatique par modulo 11 protégeant les crédits contre les erreurs de frappe.
