# Casier judiciaire colombien (police nationale)

## Référence de l'API

### Endpoint

```
https://api.verifik.co/v2/co/policia/consultar
```

Le service de casier judiciaire de la police colombienne vérifie si une personne a des affaires en cours auprès des autorités judiciaires colombiennes, conformément à l'article 248 de la Constitution. Envoyez **`documentType`** et **`documentNumber`** en **GET** (query) ou **POST** (corps JSON). Un objet `data` réussi contient `documentType`, `documentNumber`, `firstName`, `lastName`, `fullName`, `arrayName` et `details`. Idéal pour le recrutement, l'onboarding et la diligence raisonnable.

### En-têtes (Headers)

| Nom            | Valeur              |
| -------------- | ------------------- |
| Content-Type   | `application/json`  |
| Authorization  | `Bearer <token>`    |

### Paramètres

:::info
Pour la liste complète des **types de documents** pris en charge ainsi que de leurs paramètres obligatoires spécifiques, consultez le guide [Types de documents](/background-check/document-types).
:::

| Nom              | Type   | Requis  | Description                                                                 |
| ---------------- | ------ | ------- | --------------------------------------------------------------------------- |
| `documentType`   | string | **Oui** | Type de document. Valeurs valides : **CC**, **CE**, **PPT**, **PA**, **DP**. **DP** = Documento Diplomático. **PPT** est accepté ; le portail de la Policía le traite comme un passeport. |
| `documentNumber` | string | **Oui** | Numéro de document de la personne à interroger, sans espaces ni points.      |

Cet endpoint **n'accepte pas** le paramètre `date` (contrairement au [RNMC](/verifik-fr/background-check/colombia-police-compliance-corrective-measures)).

### Remarques (Notes)

- **GET** et **POST** sont tous deux pris en charge. POST envoie les mêmes champs dans le corps JSON.
- Le portail de la Policía affiche **les apellidos puis les nombres**. Verifik renvoie d'abord les prénoms : `firstName` `LILIA MANUELA`, `lastName` `LESPORT FERNANDEZ`, `fullName` `LILIA MANUELA LESPORT FERNANDEZ`, et `arrayName` prénoms puis noms de famille.
- En production, `data.details` contient uniquement la phrase **NO TIENE** / **REGISTRA ASUNTOS**. La légende constitutionnelle est retirée.
- Le sandbox peut aussi renvoyer `legend`. Ne pas considérer `legend` comme un champ de production garanti.
- Les valeurs `documentType` autorisées sont **CC**, **CE**, **PPT**, **PA** et **DP** (Documento Diplomático). **PPT** est accepté ; le portail le traite comme un passeport.
- Cette route n'exige pas de `date` d'expédition (le RNMC oui).
- Les pannes temporaires de la source ou du captcha renvoient **409** avec `Endpoint_out_of_service` ou `captcha_failed`.
- Pour les mesures correctives en attente, utilisez [Colombie - Mesures correctives (RNMC)](/verifik-fr/background-check/colombia-police-compliance-corrective-measures) (`GET /v2/co/policia/rnmc`).
