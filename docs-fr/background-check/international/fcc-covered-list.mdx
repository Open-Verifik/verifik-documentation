# Covered List de la FCC des États-Unis

Vérifiez si une personne ou une organisation figure sur **Covered List de la FCC des États-Unis**. La Federal Communications Commission (FCC) publie cette liste pour les États-Unis.

La Covered List nomme des équipements et services de communications que la FCC a jugés présenter un risque inacceptable pour la sécurité nationale des États-Unis ou pour la sûreté des personnes américaines.

Envoyez `fullName`, `documentNumber`, ou les deux. Au moins l'un des deux est obligatoire. La réponse met `foundInFccCoveredList` à `true` lorsque la requête correspond à un enregistrement publié et à `false` dans le cas contraire. En cas de correspondance, `details` contient le nom de la société, l'autorité, le motif d'exclusion, le statut et les dates pertinentes. Utilisez le résultat pour le KYC, la LCB-FT, l'intégration des fournisseurs et le filtrage des paiements. Examinez chaque correspondance avant de vous y fier. Cet appel ne remplace pas la liste officielle et ne constitue pas une décision juridique.

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/fcc-covered-list
```

Une réponse réussie renvoie `data.fullName`, `data.firstName` et `data.lastName` lorsque la source sépare le nom, `data.documentNumber` si vous l'avez envoyé, `data.foundInFccCoveredList` et `data.details`. En cas de correspondance, `details` contient le nom de la société, l'autorité, le motif d'exclusion, le statut et les dates pertinentes. L'objet `signature` contient `dateTime` et le message `Certified by Verifik.co`. Lorsque `foundInFccCoveredList` vaut `false`, `details` est un objet vide.

### Headers

| Nom           | Valeur             | Description          |
| ------------- | ------------------ | -------------------- |
| Content-Type  | `application/json` | Format de la requête |
| Accept        | `application/json` | Format de la réponse |
| Authorization | `Bearer <token>`   | JWT Verifik          |

### Parameters

| Paramètre        | Type   | Requis       | Exemple                  | Description                                                                                                           |
| ---------------- | ------ | ------------ | ------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| `fullName`       | string | Conditionnel | `SAMPLE DESIGNATED NAME` | Nom légal complet de la personne ou dénomination de l'organisation. Obligatoire si `documentNumber` n'est pas envoyé. |
| `documentNumber` | string | Conditionnel | `A1234567`               | Numéro d'identification ou d'immatriculation, sans espaces. Obligatoire si `fullName` n'est pas envoyé.               |

### Cas d'usage

- **Criblage d'exclusions :** Vérifiez si une société est exclue, sous observation ou autrement restreinte sur cette liste.
- **Investissement et chaîne d'approvisionnement :** Utilisez le résultat avant une détention, un mandat ou un contrat.
- **Dossier :** Conservez la réponse certifiée dans le dossier d'investissement ou de fournisseur.

### Notes

- Envoyez `fullName` ou `documentNumber`. Au moins l'un des deux est obligatoire. S'ils manquent tous les deux, l'API renvoie HTTP 409 avec le code `MissingParameter` et le message `Either fullName or documentNumber must be provided`.
- `foundInFccCoveredList` vaut `true` lorsque la requête correspond à un enregistrement de cette liste et `false` dans le cas contraire. `details` est un objet vide s'il n'y a pas de correspondance.
- L'exemple de correspondance montre la forme de la réponse. Une correspondance réelle renvoie les attributs publiés pour cet enregistrement sur cette liste.
- Une correspondance est un résultat de criblage destiné à un examen de conformité. Ce n'est pas une décision juridique et cela ne remplace pas la source officielle.
- Authentifiez-vous avec un JWT Bearer dans l'en-tête `Authorization`.
- Le résultat reflète la liste au moment de l'appel. Relancez une requête lorsque vous avez besoin d'un résultat ultérieur.
