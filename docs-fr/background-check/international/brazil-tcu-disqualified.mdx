# Liste — Disqualification TCU du service public au Brésil

Filtrez la liste du TCU brésilien des personnes disqualifiées du service public.

## Ce que l'appel renvoie

- `foundInBrTcuDisqualified`
- `details` en cas de correspondance
- `fullName`

## Cas d'usage

- Filtrez avant de payer ou d'entrer en relation.
- Traitez un indicateur false comme un 200 net.
- Envoyez un nom, ou un type et un numéro.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/br/tcu-disqualified
```

Une correspondance met `foundInBrTcuDisqualified` à true et remplit `details`. Un sujet absent de la liste est un HTTP 200 avec `foundInBrTcuDisqualified` à false et `details` vide.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditionnel** | `SAMPLE NAME` | Nom ou, pour une liste de portefeuilles, l'adresse. Il suffit seul. |
| `documentType` | string | **Conditionnel** | `CPF` | Obligatoire avec `documentNumber` si `fullName` est omis. Un CPF sans nom exige aussi `dateOfBirth`. |
| `documentNumber` | string | **Conditionnel** | `12345678901` | Identifiant d'au moins 5 caractères, avec `documentType`, si `fullName` est omis. |
| `dateOfBirth` | string | **Conditionnel** | `1990-01-15` | Obligatoire pour CPF, CI, CCPA, DUI ou CCUY si `fullName` est omis. |

### Notes

- Envoyez `fullName`, ou `documentType` et `documentNumber`.
- Un sujet non listé est un HTTP 200 avec `foundInBrTcuDisqualified` à false.
- Un CPF sans nom exige aussi `dateOfBirth`.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `fullName: "SAMPLE NAME"` | 200 avec foundInBrTcuDisqualified à true si la liste correspond. |
| Valeur obligatoire absente | Omit fullName and the document pair | 409 si fullName et la paire documentaire manquent. |
| Valeur inconnue | `fullName: "CLEAN SAMPLE"` | 200 avec foundInBrTcuDisqualified à false si le sujet n'est simplement pas listé. |

401 when the bearer token is missing or rejected.
