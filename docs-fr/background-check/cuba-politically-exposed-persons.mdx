# Cuba — Personnes politiquement exposées (PPE)

Contrôlez une personne en **Cuba** par **cédula de identidad (CI)** (`documentNumber`) ou par **nom légal complet** (`fullName`) dans les registres officiels de personnes politiquement exposées (PPE). Le contrôle suit la **Recommandation 12 du GAFI** et le cadre LCB-FT national ci-dessous, avec un **recul de 5 ans** pour les mandats publics terminés.

- **Cadre :** Decreto-Ley N° 317 del Consejo de Estado y Estándares GAFI/GAFILAT Recomendación 12
- **Autorité :** Asamblea Nacional del Poder Popular (ANPP) / Banco Central de Cuba
- **Source principale :** Asamblea Nacional del Poder Popular / Consejo de Estado / OpenSanctions PEP (CU) (`https://parlamentocubano.gob.cu`)

- Entrée en relation et vigilance renforcée sur les PPE nationales.
- Revérification périodique lorsqu'un mandat commence, change ou prend fin.
- Recherche par nom lorsque le numéro de document national n'est pas encore au dossier.

---

## Référence de l'API

### Point d'accès

```http
GET https://api.verifik.co/v2/cu/politically-exposed-persons
```

Un appel réussi renvoie `country`, `jurisdiction`, `documentType`, `documentNumber`, `fullName`, `isPEP`, `isActivePep`, `isFormerPep`, `totalMatches`, `matchCount`, `categories`, `includeFormer`, `lookbackYears` (5), `matches`, `checkedSources`, `regulation` et `dateTime`. Chaque correspondance contient `position`, `entity`, `category`, `categoryDescription`, `status` (`ACTIVE` ou `FORMER_PEP`), `source` et `sourceUrl`. L'indicateur de décision à la racine est `isPEP`. Chaque correspondance utilise `isPep`. Une personne qui n'est pas PPE reste en HTTP 200, avec `isPEP` à false et `totalMatches` à 0.

### En-têtes

| Nom | Valeur |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <votre_token>` |

### Paramètres

| Nom | Type | Requis | Description |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | Conditionnel | Cédula de identidad (CI). 3 à 40 caractères. Obligatoire si `fullName` est omis. Alias : `id`, `dni`, `cedula`. Exemple : `CU-ANPP-600420`. |
| `fullName` | string | Conditionnel | Nom légal complet, 3 à 160 caractères. Obligatoire si `documentNumber` est omis. Alias : `name`. Exemple : `MIGUEL MARIO DIAZ CANEL BERMUDEZ`. |
| `documentType` | string | Non | Type de document, 2 à 20 caractères. La valeur par défaut est `CI` et elle est renvoyée dans la réponse. |
| `includeFormer` | boolean | Non | Inclut les mandats terminés dans la fenêtre de 5 ans. Valeur par défaut : `true`. Passez `false` pour ne garder que les rôles `ACTIVE`. Un seul ancien mandat donne alors `isPEP` à false et un tableau `matches` vide. |

---

## Catégories PPE

Chaque correspondance est classée à partir de l'intitulé de fonction dans l'une de ces catégories :

| Catégorie | Description |
| :--- | :--- |
| `HEAD_OF_STATE_OR_GOVERNMENT` | Chef de l'État, chef du gouvernement ou autorité exécutive du cabinet |
| `SENIOR_EXECUTIVE` | Haut responsable du pouvoir exécutif ou ministre du cabinet |
| `LEGISLATIVE` | Membre du parlement national ou de l'assemblée législative |
| `JUDICIAL_OR_OVERSIGHT` | Haute autorité judiciaire, constitutionnelle ou de contrôle suprême |
| `DIPLOMATIC_MILITARY_OR_CENTRAL_BANK` | Haut responsable diplomatique, militaire ou de la banque centrale |
| `PUBLIC_OFFICIAL_PEP` | Personne politiquement exposée au sens de la Recommandation 12 du GAFI |

## Jeux d'essai sandbox

Avec le compte en mode sandbox, ces valeurs sont déterministes :

| Numéro de document | Nom complet | includeFormer | Résultat |
| :--- | :--- | :--- | :--- |
| `CU-ANPP-600420` | `MIGUEL MARIO DIAZ CANEL BERMUDEZ` | `true` | PPE active (`isPEP` true, catégorie `HEAD_OF_STATE_OR_GOVERNMENT`) |
| `10000001` | `MIGUEL MARIO DIAZ CANEL BERMUDEZ` | `true` | PPE active (même jeu que le document `10000001`) |
| `10000002` | `PEP FORMER MINISTER` | `true` | Ancienne PPE (`isFormerPep` true) lorsque `includeFormer` vaut true |
| `10000002` | `PEP FORMER MINISTER` | `false` | Résultat vierge lorsque `includeFormer` vaut false |
| `55555555` | `JUAN CARLOS CIUDADANO NO PEP` | `true` | Non-PPE (`isPEP` false, `totalMatches` 0) |
| `99999404` | `—` | `true` | 404 `NotFound` (sonde sandbox uniquement) |

### Remarques

- Envoyez `documentNumber` ou `fullName`. Les alias du document sont `id`, `dni` et `cedula`. L'alias du nom est `name`. Si aucun n'est présent, l'API renvoie 409 `MissingParameter` avec le message `Either documentNumber or fullName must be provided.`
- `includeFormer` vaut true par défaut. Les anciens mandats dans la fenêtre de 5 ans reviennent avec `status` `FORMER_PEP`, `isFormerPep` à true et `isPEP` à true. `false` retire ces lignes et ne garde que les rôles actifs.
- `documentType` vaut `CI` par défaut. `jurisdiction` dans la charge est le libellé de registre `Cuba`. `regulation.lookbackYears` vaut 5.
- Correspondance active en sandbox : document `CU-ANPP-600420` ou nom `MIGUEL MARIO DIAZ CANEL BERMUDEZ`, ainsi que le document `10000001`. Ancien mandat : document `10000002` ou un nom contenant `PEP FORMER`, `EX MINISTRO` ou `FORMER MINISTER`. Vierge : document `55555555` avec le nom `JUAN CARLOS CIUDADANO NO PEP`. Un numéro contenant `99999404`, ou un nom contenant `NOTFOUND`, renvoie 404 en sandbox. Une absence en production est HTTP 200 avec `isPEP` à false, pas 404.
- Cette route ne couvre que Cuba (`CU`). Pour une recherche transfrontalière, utilisez [PPE mondiale](/verifik-fr/background-check/world-politically-exposed-persons).
- `checkedSources` liste les clés de registre consultées pour cette juridiction. `regulation.framework` et `regulation.authority` identifient le fondement LCB-FT renvoyé avec le résultat.
