# Colombie — PEP candidats électoraux

Filtrez les candidats électoraux qui sont des personnes politiquement exposées en Colombie.

## Ce que l'appel renvoie

- `isPEP`
- `isCandidate`
- `fullName` et `documentNumber`
- `matches` vide en cas d'absence nette

## Cas d'usage

- Filtrez un annuaire PEP de Colombie avant l'entrée en relation.
- Conservez une personne non listée comme HTTP 200.
- Cherchez par nom ou par numéro.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/co/pep/candidatos
```

Une correspondance met `isPEP` à true et `isCandidate` à true. Une personne simplement absente de cet annuaire est un HTTP 200 avec `isPEP` à false et `matches` vide. Ce n'est pas un 404.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **Conditionnel** | `MARIA LOPEZ` | Nom. Il suffit seul. `partyName`, `entityName` ou `country` sont aussi acceptés quand l'annuaire les a. |
| `documentNumber` | string | **Conditionnel** | `80123456` | Identifiant de 4 à 30 caractères. |
| `documentType` | string | Non | `CC` | Facultatif : `CC`, `NIT`, `CE`, `PAS`, `TI`, `CD`. |

### Notes

- Une absence nette est un HTTP 200 avec `isPEP` à false.
- Envoyez au moins une valeur de recherche.
- Ne mappez pas ce 200 sur un 404.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `fullName: "MARIA LOPEZ"` | 200 avec isPEP à true si ça correspond. |
| Valeur obligatoire absente | Omit every search value | 409 si aucune valeur n'est envoyée. |
| Valeur inconnue | `fullName: "CLEAN NAME"` | 200 avec isPEP à false. L'absence nette n'est pas un 404. |

401 when the bearer token is missing or rejected.
