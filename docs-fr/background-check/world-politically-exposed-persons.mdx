# Monde — Personnes politiquement exposées (PPE)

Contrôlez une personne dans plusieurs juridictions par **numéro de passeport ou autre document** (`documentNumber`) ou par **nom légal complet** (`fullName`) sur `GET /v2/world/pep`. Le même traitement répond aussi sur `GET /v2/world/politically-exposed-persons`. Le contrôle suit la **Recommandation 12 du GAFI** pour les PPE nationales et étrangères et conserve un **recul de 5 ans** après la fin du mandat public.

- **Cadre :** FATF / GAFI Recommendation 12 (Politically Exposed Persons — Foreign & Domestic PEPs)
- **Autorité :** Financial Action Task Force (FATF / GAFI) / OpenSanctions Global PEP Registry
- **Source principale :** OpenSanctions Global Politically Exposed Persons (PEPs) Consolidated Dataset & Wikidata Officeholders (`https://data.opensanctions.org/datasets/latest/peps/targets.simple.csv`)

- Entrée en relation transfrontalière lorsque le pays de la personne n'a pas d'endpoint PPE dédié.
- Filtre facultatif `country` (ISO 3166-1 alpha-2) pour limiter le registre mondial à une juridiction.
- Vigilance renforcée et revérification périodique des PPE étrangères.

---

## Référence de l'API

### Point d'accès

```http
GET https://api.verifik.co/v2/world/pep
```

Un appel réussi renvoie `country`, `jurisdiction`, `documentType`, `documentNumber`, `fullName`, `isPEP`, `isActivePep`, `isFormerPep`, `totalMatches`, `matchCount`, `categories`, `includeFormer`, `lookbackYears` (5), `matches`, `checkedSources`, `regulation` et `dateTime`. Chaque correspondance contient `position`, `entity`, `category`, `categoryDescription`, `status` (`ACTIVE` ou `FORMER_PEP`), `source` et `sourceUrl`. L'indicateur de décision à la racine est `isPEP`. Chaque correspondance utilise `isPep`. Une personne qui n'est pas PPE reste en HTTP 200, avec `isPEP` à false et `totalMatches` à 0.

### En-têtes

| Nom | Valeur |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <votre_token>` |

### Paramètres

| Nom | Type | Requis | Description |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | Conditionnel | Numéro de passeport. 3 à 40 caractères. Obligatoire si `fullName` est omis. Alias : `id`, `dni`, `cedula`. Exemple : `WORLD-PEP-Q22686`. |
| `fullName` | string | Conditionnel | Nom légal complet, 3 à 160 caractères. Obligatoire si `documentNumber` est omis. Alias : `name`. Exemple : `URSULA GERTRUD VON DER LEYEN`. |
| `documentType` | string | Non | Type de document, 2 à 20 caractères. La valeur par défaut est `PASSPORT` et elle est renvoyée dans la réponse. |
| `includeFormer` | boolean | Non | Inclut les mandats terminés dans la fenêtre de 5 ans. Valeur par défaut : `true`. Passez `false` pour ne garder que les rôles `ACTIVE`. Un seul ancien mandat donne alors `isPEP` à false et un tableau `matches` vide. |
| `country` | string | Non | Code pays ISO 3166-1 alpha-2 facultatif, 2 à 10 caractères (par exemple `PL`). Omettez-le pour interroger le registre mondial consolidé. |

---

## Catégories PPE

Chaque correspondance est classée à partir de l'intitulé de fonction dans l'une de ces catégories :

| Catégorie | Description |
| :--- | :--- |
| `HEAD_OF_STATE_OR_GOVERNMENT` | Chef de l'État, chef du gouvernement ou autorité exécutive du cabinet |
| `SENIOR_EXECUTIVE` | Haut responsable du pouvoir exécutif ou ministre du cabinet |
| `LEGISLATIVE` | Membre du parlement national ou de l'assemblée législative |
| `JUDICIAL_OR_OVERSIGHT` | Haute autorité judiciaire, constitutionnelle ou de contrôle suprême |
| `DIPLOMATIC_MILITARY_OR_CENTRAL_BANK` | Haut responsable diplomatique, militaire ou de la banque centrale |
| `PUBLIC_OFFICIAL_PEP` | Personne politiquement exposée au sens de la Recommandation 12 du GAFI |

## Jeux d'essai sandbox

Avec le compte en mode sandbox, ces valeurs sont déterministes :

| Numéro de document | Nom complet | includeFormer | Résultat |
| :--- | :--- | :--- | :--- |
| `WORLD-PEP-Q22686` | `URSULA GERTRUD VON DER LEYEN` | `true` | PPE active (`isPEP` true, catégorie `HEAD_OF_STATE_OR_GOVERNMENT`) |
| `10000001` | `URSULA GERTRUD VON DER LEYEN` | `true` | PPE active (même jeu que le document `10000001`) |
| `10000002` | `PEP FORMER MINISTER` | `true` | Ancienne PPE (`isFormerPep` true) lorsque `includeFormer` vaut true |
| `10000002` | `PEP FORMER MINISTER` | `false` | Résultat vierge lorsque `includeFormer` vaut false |
| `55555555` | `JUAN CARLOS CIUDADANO NO PEP` | `true` | Non-PPE (`isPEP` false, `totalMatches` 0) |
| `99999404` | `—` | `true` | 404 `NotFound` (sonde sandbox uniquement) |

### Remarques

- Envoyez `documentNumber` ou `fullName`. Les alias du document sont `id`, `dni` et `cedula`. L'alias du nom est `name`. Si aucun n'est présent, l'API renvoie 409 `MissingParameter` avec le message `Either documentNumber or fullName must be provided.`
- `includeFormer` vaut true par défaut. Les anciens mandats dans la fenêtre de 5 ans reviennent avec `status` `FORMER_PEP`, `isFormerPep` à true et `isPEP` à true. `false` retire ces lignes et ne garde que les rôles actifs.
- `documentType` vaut `PASSPORT` par défaut. `jurisdiction` dans la charge est le libellé de registre `Otros países (Global PEP)`. `regulation.lookbackYears` vaut 5.
- Correspondance active en sandbox : document `WORLD-PEP-Q22686` ou nom `URSULA GERTRUD VON DER LEYEN`, ainsi que le document `10000001`. Ancien mandat : document `10000002` ou un nom contenant `PEP FORMER`, `EX MINISTRO` ou `FORMER MINISTER`. Vierge : document `55555555` avec le nom `JUAN CARLOS CIUDADANO NO PEP`. Un numéro contenant `99999404`, ou un nom contenant `NOTFOUND`, renvoie 404 en sandbox. Une absence en production est HTTP 200 avec `isPEP` à false, pas 404.
- Les endpoints par pays utilisent `/v2/` plus le code ISO plus `/politically-exposed-persons`. Cette route mondiale ne les remplace pas. Envoyez `country` seulement pour restreindre cette recherche mondiale.
- `checkedSources` liste les clés de registre consultées pour cette juridiction. `regulation.framework` et `regulation.authority` identifient le fondement LCB-FT renvoyé avec le résultat.
