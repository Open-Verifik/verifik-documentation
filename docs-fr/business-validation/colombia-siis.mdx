# Colombie — Système intégré d'information sociétaire (SIIS)

La consultation **SIIS** lit les dépôts sociétaires supervisés par Supersociedades. Envoyez un NIT ou une raison sociale. `found` vaut true s'il existe un dépôt et false si la société n'est simplement pas dans le SIIS. Cette absence nette est un HTTP 200, avec le statut `NO REGISTRADA EN SIIS SUPERSOCIEDADES`. Utilisez `inLiquidationOrReorganization` pour une alerte de procédure collective.

## Ce que l'appel renvoie

- `found` et `inLiquidationOrReorganization`
- `ciiu`, secteur et ville
- `financialSummary` s'il y a un dépôt
- `filings` — vide en cas d'absence nette

## Cas d'usage

- Récupérez le dernier dépôt SIIS avant d'accorder un crédit.
- Signalez une société déjà en réorganisation.
- Enregistrez un absent-du-SIIS comme 200, pas comme une page manquante.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersociedades/siis
```

Un dépôt contient `status`, `ciiu`, l'adresse, `financialSummary` et `filings`. `found` à false signifie que la société n'est pas dans le SIIS. Les deux sont des HTTP 200.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditionnel** | `900123456` | NIT ou numéro. Alias `nit`. Obligatoire sans nom. |
| `businessName` | string | **Conditionnel** | `INDUSTRIAS EJEMPLO SAS` | Nom, 2 à 200 caractères. Alias `companyName` et `fullName`. Obligatoire sans numéro. |
| `documentType` | string | Non | `NIT` | Facultatif : `NIT`, `CC`, `CE`, `PAS` ou `TI`. |

### Notes

- Envoyez un NIT ou un nom.
- `found` à false est une absence nette réussie.
- Ne mappez pas ce corps sur un HTTP 404.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `documentNumber: "900673447"` | 200 et found vaut true en cas de correspondance. |
| Valeur obligatoire absente | Omit number and name | 409 si aucune valeur n'est envoyée. |
| Valeur inconnue | `documentNumber: "800000111"` | 200 et found vaut false en cas d'absence nette. Ce n'est pas un 404. |

401 when the bearer token is missing or rejected.
