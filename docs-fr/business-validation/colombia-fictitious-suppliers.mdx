# Colombie — Fournisseurs fictifs ou insolvables (DIAN)

La consultation des **fournisseurs fictifs ou insolvables** filtre l'article 671 de la DIAN. Envoyez `documentNumber` (ou l'alias `nit`) ou `businessName` (alias `companyName` et `fullName`). Un fournisseur listé met `isFictitiousSupplier` à true et inclut la résolution. Une absence nette reste un HTTP 200 avec `isFictitiousSupplier` à false. Cette route ne répond pas 404 pour une absence nette.

## Ce que l'appel renvoie

- `isFictitiousSupplier` — true seulement si la DIAN liste le sujet
- `resolutionNumber`, `resolutionDate` et `publicationDate` en cas de correspondance
- `matches` — vide si rien n'est listé
- `status` — libellé de liste ou phrase de non-inscription

## Cas d'usage

- Bloquez un fournisseur que la DIAN a marqué fictif ou insolvable.
- Enregistrez une absence nette comme 200 avec l'indicateur à false.
- Cherchez par NIT ou par raison sociale.

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/co/dian/proveedores-ficticios
```

En cas de correspondance, `isFictitiousSupplier` vaut true et `matches` porte le numéro de résolution, les dates et la direction sectionnelle. En cas d'absence nette, `isFictitiousSupplier` vaut false. Les deux issues sont des HTTP 200.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditionnel** | `900123456` | NIT ou numéro de personne, 4 à 25 caractères. Alias : `nit`. Obligatoire si aucun nom n'est envoyé. |
| `businessName` | string | **Conditionnel** | `INDUSTRIAS EJEMPLO SAS` | Raison ou nom commercial, 2 à 200 caractères. Alias : `companyName` et `fullName`. Obligatoire si aucun numéro n'est envoyé. |
| `documentType` | string | Non | `NIT` | Facultatif. Valeurs : `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### Notes

- Envoyez un numéro ou un nom. Au moins l'un est obligatoire.
- Un sujet absent de la liste est un HTTP 200 avec `isFictitiousSupplier` à false.
- Ne traitez pas ce 200 comme un 404.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `documentNumber: "900123456"` | 200 avec isFictitiousSupplier à true lorsque la source liste le sujet. |
| Valeur obligatoire absente | Omit every search value | 409 MissingParameter si aucune valeur de recherche n'est envoyée. |
| Valeur inconnue | `documentNumber: "00000000"` | 200 avec isFictitiousSupplier à false. Une absence nette reste un HTTP 200 et n'est pas un 404. |

401 when the bearer token is missing or rejected.
