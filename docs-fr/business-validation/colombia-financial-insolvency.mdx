# Colombie — Concordats et liquidations financières

La consultation d'**insolvabilité financière** lit les concordats et liquidations de la Superintendencia Financiera. Envoyez un NIT ou un nom. `inConcordatoOrLiquidation` vaut true seulement s'il y a une procédure. Une société sans procédure reste un HTTP 200, avec l'indicateur à false. Cette route n'utilise pas 404 pour cette absence nette.

## Ce que l'appel renvoie

- `inConcordatoOrLiquidation`
- `status` et `entityType`
- `matches` vide en cas d'absence nette

## Cas d'usage

- Arrêtez l'entrée en relation d'une entité déjà en liquidation.
- Conservez un filtrage net comme 200.
- Cherchez par NIT ou raison sociale.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/co/superfinanciera/concordatos
```

Une correspondance contient `status`, `entityType` et `inConcordatoOrLiquidation` à true. Une absence nette reste en HTTP 200 avec l'indicateur à false.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditionnel** | `900123456` | NIT ou numéro. Alias `nit`. Obligatoire sans nom. |
| `businessName` | string | **Conditionnel** | `EJEMPLO SAS` | Nom. Alias `companyName` et `fullName`. Obligatoire sans numéro. |
| `documentType` | string | Non | `NIT` | Facultatif : `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### Notes

- Une absence nette est un HTTP 200 avec `inConcordatoOrLiquidation` à false.
- Envoyez un numéro ou un nom.
- Ne mappez pas ce 200 sur un 404.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `documentNumber: "860000001"` | 200 avec inConcordatoOrLiquidation à true en cas de correspondance. |
| Valeur obligatoire absente | Omit number and name | 409 si aucune valeur n'est envoyée. |
| Valeur inconnue | `documentNumber: "800000111"` | 200 avec inConcordatoOrLiquidation à false. Une absence nette n'est pas un 404. |

401 when the bearer token is missing or rejected.
