# Trinité-et-Tobago — Consultation du registre des entreprises (KYB)

La **consultation du registre des entreprises de Trinité-et-Tobago** vérifie une personne morale auprès du registre officiel. Envoyez le numéro d'immatriculation ou l'identifiant fiscal (Company Number / BIR) dans `documentNumber`. Elle sert à l'entrée en relation KYB, à la diligence fournisseurs et au criblage des contreparties.

`documentNumber` est obligatoire. `documentType` est facultatif. Quand vous l'envoyez, indiquez la famille d'identifiant (par exemple `BIR`) afin de distinguer les pays qui publient plusieurs numéros.

## Ce que renvoie le registre

- Dénomination sociale
- Statut d'immatriculation
- Date de constitution
- Identifiant fiscal ou d'immatriculation
- Adresse du siège

## Cas d'usage

- Entrer en relation avec un fournisseur ou une contrepartie en Trinité-et-Tobago avant le premier paiement.
- Confirmer la dénomination et le statut figurant sur un contrat ou une facture.
- Recueillir la date de constitution, l'identifiant fiscal et l'adresse pour un dossier KYB.

---

## Référence de l'API

### Point d'accès

```http
GET https://api.verifik.co/v2/tt/company
```

Interrogez le registre officiel des entreprises de Trinité-et-Tobago avec `documentNumber` et un `documentType` facultatif. Une réponse réussie contient la dénomination sociale, le statut d'immatriculation, la date de constitution, l'identifiant fiscal (Company Number / BIR) et l'adresse du siège. Utilisez-la dans un parcours KYB ou une diligence fournisseur. L'exemple montre ces champs. Les valeurs réelles, y compris le libellé de `status`, viennent du registre.

### En-têtes

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | Jeton JWT d'authentification du client |

### Paramètres

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Oui** | `C-12345` | Numéro officiel d'immatriculation ou identifiant fiscal (Company Number / BIR). |
| `documentType` | string | Non | `BIR` | Type de document sociétaire ou préfixe de registre. Exemples acceptés : `BIR`, `COMPANY`. Omettez-le pour n'envoyer que le numéro officiel. |

### Remarques

- **Format de l'identifiant.** Envoyez le numéro de société ou le numéro de dossier BIR tel que le registre de Trinité-et-Tobago le délivre.
- Type de document sociétaire ou préfixe de registre. Exemples acceptés : `BIR`, `COMPANY`. Omettez-le pour n'envoyer que le numéro officiel.
- Le libellé d'état de l'exemple illustre le champ. Le registre réel renvoie son propre libellé, éventuellement dans la langue locale.
- Envoyez `documentNumber` et, lorsque vous devez nommer la famille d'identifiant, `documentType`. Ce sont les paramètres client de cette route.
- Le JSON d'exemple illustre les champs ci-dessus. Un appel réel renvoie la fiche du registre pour l'identifiant envoyé.

## Jeux d'essai sandbox

Avec le compte en mode sandbox, les mêmes paramètres exercent cette route. Le tableau décrit la réponse documentée pour chaque cas.

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| **Identifiant connu** | `documentType: "BIR"`, `documentNumber: "C-12345"` | 200 avec le nom légal, le statut, l'identifiant et l'adresse ou les attributs d'identité lorsque la source détient le numéro. |
| **documentNumber absent** | Omettre `documentNumber` | 409 `MissingParameter` si `documentNumber` est omis. |
| **Numéro inconnu** | `documentNumber: "000000000"` | 404 `NotFound` lorsque le registre n'a pas de fiche pour ce numéro. |

401 lorsque le jeton bearer est absent ou refusé.
