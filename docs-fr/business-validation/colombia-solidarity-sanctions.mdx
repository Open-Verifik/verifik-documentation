# Colombie — Sanctions du secteur solidaire

La consultation des **sanctions solidaires** lit le bulletin des sanctionnés de Supersolidaria. Envoyez un numéro ou un nom. `isSanctioned` vaut true seulement s'il y a une sanction. Une absence nette est un HTTP 200 avec `isSanctioned` à false, `sanctionsCount` 0 et le statut `SIN SANCIONES REGISTRADAS`. Cette route ne répond pas 404 pour cette absence.

## Ce que l'appel renvoie

- `isSanctioned` et `sanctionsCount`
- `status`
- `matches`

## Cas d'usage

- Filtrez une coopérative avant de la financer.
- Enregistrez un contrôle net comme 200.
- Cherchez par NIT ou par le nom sanctionné.

---

## Référence de l'API

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersolidaria/sanciones
```

Une correspondance contient `sanctionsCount` et `matches`. Une absence nette est un HTTP 200 avec `isSanctioned` à false.

### Headers

| Nom | Valeur | Description |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Format de la requête |
| Accept | `application/json` | Format de la réponse |
| Authorization | `Bearer <votre_token>` | JWT client |

### Parameters

| Nom | Type | Requis | Exemple | Description |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Conditionnel** | `900123456` | NIT ou numéro. Alias `nit`. |
| `businessName` | string | **Conditionnel** | `EJEMPLO SAS` | Nom. Alias `companyName` et `fullName`. |
| `documentType` | string | Non | `NIT` | Facultatif : `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### Notes

- Une absence nette est un HTTP 200 avec `isSanctioned` à false.
- Envoyez au moins une valeur de recherche.
- Ne mappez pas ce 200 sur un 404.
- Envoyez un JWT Bearer dans l'en-tête `Authorization`.
- Le JSON d'exemple illustre les champs. Un appel réel renvoie l'enregistrement des valeurs envoyées.
- N'envoyez pas d'indicateur de contournement du cache. Cette page ne documente que les paramètres client.

## Bac à sable

| Scénario | Paramètres | Résultat |
| :--- | :--- | :--- |
| Enregistrement à la source | `documentNumber: "900555111"` | 200 avec isSanctioned à true si ça correspond. |
| Valeur obligatoire absente | Omit number and name | 409 si aucune valeur n'est envoyée. |
| Valeur inconnue | `documentNumber: "800000111"` | 200 avec isSanctioned à false. L'absence nette n'est pas un 404. |

401 when the bearer token is missing or rejected.
