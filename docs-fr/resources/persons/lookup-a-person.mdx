### Endpoint

```
GET https://api.verifik.co/v2/face-recognition/persons/lookup
```

Recherche les personnes déjà enregistrées pour votre client par **nom** (obligatoire) et **date de naissance** optionnelle. Utilisez cet endpoint lorsque la création renvoie `412 person_already_set`, ou avant l’enrôlement, pour obtenir le **`_id` de la personne** et les **`code`** de collection sans lancer une recherche faciale 1:N.

Il s’agit d’une recherche de **métadonnées Mongo**, pas d’un match facial. Les chiffres dans `name` sont retirés comme à la création (`"Maria 123"` devient `"Maria"`). La correspondance est un **contains** insensible à la casse (`Maria` trouve `Maria Perez Gonzalez`). Utilisez au moins 3 caractères.

Utilisez `collections[].code` (UUID de 36 caractères) comme `collection_id` pour la recherche faciale. N’envoyez pas le `_id` Mongo de la collection.

### Headers

| Name | Value |
| --- | --- |
| Content-Type | `application/json` |
| Authorization | `Bearer <token>` |

### Params

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Nom partiel ou complet (minimum 3 caractères après suppression des chiffres). Contains, insensible à la casse. |
| `date_of_birth` | string | No | `YYYY-MM-DD`. Si présent, restreint à ce jour. |
| `page` | number | No | Numéro de page (défaut : `1`). |
| `limit` | number | No | Taille de page (défaut : `20`, max : `100`). |

### Notes

- Préférez ce helper (ou l’objet `data` de `412 person_already_set`) à une recherche 1:N lorsque vous connaissez une partie du nom et, éventuellement, la date de naissance.
- Un prénom seul suffit (`name=Maria`). Ajoutez `date_of_birth` si beaucoup de personnes partagent ce prénom.
- L’unicité de `POST /v2/face-recognition/persons` est aussi **nom + date de naissance** dans une collection, pas la similarité faciale.
- `collections[].code` est la valeur qu’OpenCV attend comme `collection_id`.
