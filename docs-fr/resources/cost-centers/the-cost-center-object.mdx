# L'objet centre de coût

```json
{
	"_id": "6acfbdda92451bac5d0a7ebe",
	"client": "69c2b824295cd7d276e478ad",
	"name": "Opérations Espagne",
	"code": "SPAIN-OPS",
	"country": "ES",
	"active": true,
	"createdAt": "2026-10-14T17:37:30.469Z",
	"updatedAt": "2026-10-14T17:37:30.469Z"
}
```

| Champ     | Type    | Description                                                                                                      |
| --------- | ------- | ---------------------------------------------------------------------------------------------------------------- |
| `name`    | string  | Nom affiché, jusqu'à 120 caractères.                                                                             |
| `code`    | string  | Valeur envoyée dans `x-cost-center`. Lettres, chiffres, `.`, `-` et `_`, jusqu'à 60 caractères. Unique par compte. |
| `country` | string  | Pays ISO-2 que ce centre de coût sert en général.                                                                |
| `active`  | boolean | Un centre inactif garde son historique mais ne peut plus être assigné à de nouvelles requêtes.                   |
