### Aperçu

L'objet centre de coût est l'enregistrement que Verifik conserve pour une équipe, un pays ou une unité. Les requêtes le référencent par `_id`. Vous envoyez `code` dans le header `x-cost-center`.

```json
{
  "_id": "6acfbdda92451bac5d0a7ebe",
  "client": "69c2b824295cd7d276e478ad",
  "name": "Opérations Espagne",
  "code": "SPAIN-OPS",
  "country": "ES",
  "active": true,
  "createdAt": "2026-10-14T17:37:30.469Z",
  "updatedAt": "2026-10-14T17:37:30.469Z"
}
```

### Attributs

#### `_id`

**Type :** string  
**Requis :** Oui

Identifiant unique. Utilisez-le pour consulter, mettre à jour et désactiver, et pour la valeur par défaut d'un projet.

#### `client`

**Type :** string  
**Requis :** Oui

Le compte propriétaire de ce centre de coût.

#### `name`

**Type :** string  
**Requis :** Oui

Nom affiché, jusqu'à 120 caractères.

#### `code`

**Type :** string  
**Requis :** Oui

Valeur envoyée dans `x-cost-center`. Lettres, chiffres, `.`, `-` et `_`, jusqu'à 60 caractères. Unique par compte.

#### `country`

**Type :** string  
**Requis :** Oui

Pays ISO-2 que ce centre sert en général, en majuscules.

#### `active`

**Type :** boolean  
**Requis :** Oui

Un centre inactif garde son historique mais ne peut plus être assigné à de nouvelles requêtes. `true` par défaut.

#### `createdAt`

**Type :** string  
**Requis :** Oui

Date de création, en ISO-8601.

#### `updatedAt`

**Type :** string  
**Requis :** Oui

Date du dernier changement, en ISO-8601.
