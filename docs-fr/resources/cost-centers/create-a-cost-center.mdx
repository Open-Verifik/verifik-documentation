### Endpoint

**POST** `https://api.verifik.co/v2/cost-centers`

Crée un centre de coût sur votre compte. Gérer les centres de coût ne consomme pas de crédits.

#### en-têtes

| Nom           | Valeur             |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### paramètres du corps

#### `name`

**Type :** string  
**Requis :** Oui

Nom affiché, jusqu'à 120 caractères.

#### `code`

**Type :** string  
**Requis :** Oui

Valeur que vous enverrez dans `x-cost-center`. Lettres, chiffres, `.`, `-` et `_`, jusqu'à 60 caractères. Unique par compte.

#### `country`

**Type :** string  
**Requis :** Oui

Code pays ISO-2, par exemple `ES`.

#### `active`

**Type :** boolean  
**Requis :** Non

`true` par défaut.

### Exemple de requête

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X POST "https://api.verifik.co/v2/cost-centers" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Opérations Espagne","code":"SPAIN-OPS","country":"ES"}'
```

</TabItem>

## Réponses d'erreur

Un code déjà utilisé sur le compte :

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```

Un champ manquant ou invalide, comme `name`, `code` ou `country` :

```json
{
  "message": "\"name\" is required",
  "code": "MissingParameter"
}
```
