# Créer un centre de coût

```
POST https://api.verifik.co/v2/cost-centers
```

| Nom       | Type    | Requis | Description                              |
| --------- | ------- | ------ | ---------------------------------------- |
| `name`    | string  | Oui    | Nom affiché.                             |
| `code`    | string  | Oui    | Valeur du header. Unique par compte.     |
| `country` | string  | Oui    | Code pays ISO-2.                         |
| `active`  | boolean | Non    | `true` par défaut.                       |

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X POST "https://api.verifik.co/v2/cost-centers" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Opérations Espagne","code":"SPAIN-OPS","country":"ES"}'
```

</TabItem>
<TabItem value="nodejs" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.post(
	"https://api.verifik.co/v2/cost-centers",
	{ name: "Opérations Espagne", code: "SPAIN-OPS", country: "ES" },
	{ headers: { Authorization: `Bearer ${process.env.VERIFIK_TOKEN}` } }
);

console.log(data.data._id);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.post(
    "https://api.verifik.co/v2/cost-centers",
    headers={"Authorization": f"Bearer {os.environ['VERIFIK_TOKEN']}"},
    json={"name": "Opérations Espagne", "code": "SPAIN-OPS", "country": "ES"},
)

print(response.json()["data"]["_id"])
```

</TabItem>
</Tabs>

La réponse est le nouvel [objet centre de coût](/verifik-fr/resources/the-cost-center-object) dans `data`. Un code déjà utilisé renvoie :

```json
{
	"code": "Conflict",
	"message": "cost_center_code_taken"
}
```
