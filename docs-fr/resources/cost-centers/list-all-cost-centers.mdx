# Lister les centres de coût

```
GET https://api.verifik.co/v2/cost-centers
```

| Nom       | Type    | Requis | Description                                              |
| --------- | ------- | ------ | -------------------------------------------------------- |
| `active`  | boolean | Non    | `true` pour les actifs seulement, `false` pour les inactifs. |
| `country` | string  | Non    | Code pays ISO-2.                                         |
| `page`    | number  | Non    | Numéro de page, à partir de 1.                           |
| `limit`   | number  | Non    | Éléments par page. 50 par défaut, jusqu'à 100.           |

```json
{
	"data": [
		{
			"_id": "6acfbdda92451bac5d0a7ebe",
			"name": "Opérations Espagne",
			"code": "SPAIN-OPS",
			"country": "ES",
			"active": true
		}
	],
	"total": 1,
	"page": 1,
	"pages": 1,
	"limit": 50
}
```
