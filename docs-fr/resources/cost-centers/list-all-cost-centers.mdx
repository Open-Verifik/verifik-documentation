### Endpoint

**GET** `https://api.verifik.co/v2/cost-centers`

Renvoie les centres de coût de votre compte, triés par pays puis par nom.

#### en-têtes

| Nom           | Valeur             |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### paramètres de requête

#### `active`

**Type :** boolean  
**Requis :** Non

`true` ne renvoie que les actifs. `false` ne renvoie que les inactifs. Omettez-le pour les deux.

#### `country`

**Type :** string  
**Requis :** Non

Code pays ISO-2, par exemple `ES`.

#### `page`

**Type :** number  
**Requis :** Non

Numéro de page, à partir de 1.

#### `limit`

**Type :** number  
**Requis :** Non

Éléments par page. 50 par défaut, 100 au maximum.

### Exemple de requête

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl "https://api.verifik.co/v2/cost-centers?active=true&country=ES&page=1&limit=50" \
  -H "Authorization: Bearer $VERIFIK_TOKEN"
```

</TabItem>
<TabItem value="node" label="Node.js">

```javascript

const config = {

axios.request(config)
```

## Réponses d'erreur

Une requête invalide, par exemple un `limit` supérieur à 100 ou un `country` qui n'a pas deux lettres :

```json
{
  "message": "\"limit\" must be less than or equal to 100",
  "code": "MissingParameter"
}
```
