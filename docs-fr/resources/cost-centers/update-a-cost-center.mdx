### Endpoint

**PUT** `https://api.verifik.co/v2/cost-centers/{id}`

Met à jour un centre de coût. Envoyez seulement les champs à changer. Les requêtes déjà enregistrées gardent le centre qu'elles avaient.

#### en-têtes

| Nom           | Valeur             |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### paramètres de chemin

#### `id`

**Type :** string  
**Requis :** Oui

L'id du centre de coût.

#### paramètres du corps

#### `name`

**Type :** string  
**Requis :** Non

Nom affiché, jusqu'à 120 caractères.

#### `code`

**Type :** string  
**Requis :** Non

Nouvelle valeur du header. Lettres, chiffres, `.`, `-` et `_`, jusqu'à 60 caractères. Unique par compte.

#### `country`

**Type :** string  
**Requis :** Non

Code pays ISO-2.

#### `active`

**Type :** boolean  
**Requis :** Non

`true` pour réactiver, `false` pour ne plus l'assigner aux nouvelles requêtes.

### Exemple de requête

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash

  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Opérations Espagne","active":true}'
```

## Réponses d'erreur

Id inconnu :

```json
{
  "message": "cost_center_not_found",
  "code": "NotFound"
}
```

Un `code` déjà utilisé par un autre centre du compte :

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```
