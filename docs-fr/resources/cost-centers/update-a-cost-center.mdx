# Mettre à jour un centre de coût

```
PUT https://api.verifik.co/v2/cost-centers/{id}
```

Envoyez `name`, `code`, `country` ou `active`. Utilisez `active: true` pour réactiver un centre. Les requêtes déjà enregistrées gardent le centre de coût qu'elles avaient.
