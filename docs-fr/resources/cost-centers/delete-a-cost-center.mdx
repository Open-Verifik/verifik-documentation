### Endpoint

**DELETE** `https://api.verifik.co/v2/cost-centers/{id}`

Désactive un centre de coût. L'enregistrement n'est pas supprimé : `active` passe à `false` et l'historique d'usage reste attaché. Les nouvelles requêtes ne peuvent plus utiliser ce centre.

#### en-têtes

| Nom           | Valeur             |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### paramètres de chemin

#### `id`

**Type :** string  
**Requis :** Oui

L'id du centre de coût à désactiver.

### Exemple de requête

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X DELETE "https://api.verifik.co/v2/cost-centers/6acfbdda92451bac5d0a7ebe" \
  -H "Authorization: Bearer $VERIFIK_TOKEN"
```
