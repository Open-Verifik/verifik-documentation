Supprimez une Check List que vous possédez. L’API renvoie le document supprimé dans `{ data }`. Un ObjectId invalide, une liste absente ou une liste appartenant à un autre client renvoie `404`.

La suppression n’exécute pas de consultations et ne consomme pas de crédits. L’historique catalogue et les jobs SmartBatch qui ont utilisé les mêmes codes de features ne sont pas retirés.

### Endpoint

```
DELETE https://api.verifik.co/v2/check-lists/{id}
```

Retire la liste de la collection du client et renvoie le document qui a été supprimé. Après cet appel, GET / PUT / DELETE sur le même id renvoient `404`.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

Le jeton doit être un **JWT client**. Un jeton sans `clientId` renvoie `403`.

### Parameters

| Name | Type   | Required | Description                          |
| ---- | ------ | -------- | ------------------------------------ |
| `id` | string | Yes      | ObjectId Check List issu de la création ou de la liste. |

### Notes

- Le corps `200` est le document supprimé, pas un objet vide.
- Les ObjectId invalides et les listes d’autres clients renvoient tous les deux `404` (`check_list_not_found`).
- La suppression ne consomme pas de crédits et n’annule pas le travail catalogue ou SmartBatch.
- Il n’y a pas d’endpoint d’exécution de checklist. Voir [Check List](/verifik-fr/check-list) et [SmartBatch](/verifik-fr/smart-batch).
