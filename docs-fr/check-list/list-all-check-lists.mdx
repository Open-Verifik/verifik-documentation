Listez les Check Lists enregistrées sur le client authentifié. Les résultats sont limités à ce client et triés par `updatedAt` décroissant (plus récentes d’abord). Cet appel n’exécute pas de consultations et ne consomme pas de crédits.

Utilisez `search` (ou `text`) pour filtrer par nom. Envoyez `page` lorsque vous voulez les métadonnées de pagination. Omettez `page` pour recevoir le tableau correspondant dans `data` sans les champs `total` / `pages`.

### Endpoint

```
GET https://api.verifik.co/v2/check-lists
```

Renvoie les listes enregistrées du client. Chaque élément inclut `name`, `countries`, `domains`, `featureCodes` et `status`. Lorsque `page` est présent, la réponse inclut aussi `total`, `limit`, `page` et `pages`.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

Le jeton doit être un **JWT client**. Un jeton sans `clientId` renvoie `403`.

### Parameters

| Name      | Type    | Required | Description                                                                 |
| --------- | ------- | -------- | --------------------------------------------------------------------------- |
| `page`    | integer | No       | Lorsque défini, l’API pagine et renvoie `total`, `limit`, `page` et `pages`. Omettez-le pour obtenir uniquement le tableau correspondant. |
| `perPage` | integer | No       | Taille de page. Alias de `limit`. Appliqué même lorsque `page` est omis.    |
| `limit`   | integer | No       | Taille de page. Alias de `perPage`.                                         |
| `search`  | string  | No       | Filtre de nom insensible à la casse.                                        |
| `text`    | string  | No       | Alias de `search`.                                                          |

### Notes

- Les listes appartiennent au client du JWT. Vous ne pouvez pas lire les listes d’un autre client.
- Le tri est toujours par `updatedAt` le plus récent d’abord.
- `search` et `text` font le même filtrage de nom insensible à la casse.
- `perPage` et `limit` sont des alias. Si vous envoyez `limit` sans `page`, le tableau est quand même plafonné.
- Cet endpoint ne consomme pas de crédits et n’exécute pas les services enregistrés.
- Parcours produit : [Check List](/verifik-fr/check-list). Création : [Créer une checklist](/verifik-fr/check-list/create-a-check-list).
