Créez une Check List sur le client authentifié. `name` est obligatoire. Les pays, domaines et codes de features sont optionnels à la création — vous pouvez ajouter des services plus tard avec [Mettre à jour une checklist](/verifik-fr/check-list/update-a-check-list).

Enregistrer la liste n’exécute pas de consultations et ne consomme pas de crédits. Dans Smart-Agent, la création vous ramène au tableau de bord ; cette API renvoie le nouveau document immédiatement.

### Endpoint

```
POST https://api.verifik.co/v2/check-lists
```

Crée une liste appartenant au client du JWT. L’objet `data` de la réponse inclut `_id` — conservez-le pour les appels GET, PUT et DELETE suivants. Le `status` par défaut est `draft`.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

Le jeton doit être un **JWT client**. Un jeton sans `clientId` renvoie `403`.

### Body

| Name           | Type     | Required | Description                                                                 |
| -------------- | -------- | -------- | --------------------------------------------------------------------------- |
| `name`         | string   | Yes      | Nom d’affichage. Espaces en trop retirés, 1–150 caractères.                 |
| `countries`    | string[] | No       | Noms de pays où vous opérez (par exemple `Colombia`). Les doublons sont retirés. Défaut `[]`. |
| `domains`      | string[] | No       | Onglets optionnels : `people`, `vehicles`, `businesses`. Défaut `[]`.       |
| `featureCodes` | string[] | No       | Valeurs `code` AppFeature à enregistrer sur la liste. Défaut `[]`.          |
| `status`       | string   | No       | `draft` (défaut) ou `active`. Libellé d’organisation uniquement — les deux fonctionnent pareil. |

Les `featureCodes` inconnus échouent. Un service dont le pays ne correspond pas à `countries` échoue sauf si ce service est mondial ou si `countries` est vide.

### Notes

- `name` est le seul champ obligatoire. Vous pouvez créer une liste vide et ajouter des `featureCodes` plus tard.
- Les pays sont stockés tels que vous les envoyez (par exemple `Colombia`). Ce ne sont pas des codes ISO.
- `status` ne change pas le comportement du serveur. Les listes brouillon et actives fonctionnent toutes les deux.
- Les valeurs `domains` inconnues échouent à la validation. Valeurs autorisées : `people`, `vehicles`, `businesses`.
- Créer une liste ne consomme pas de crédits. Exécuter un service enregistré est un appel catalogue normal.
- Il n’y a pas d’endpoint d’exécution de checklist. Voir [Check List](/verifik-fr/check-list) et [SmartBatch](/verifik-fr/smart-batch).
