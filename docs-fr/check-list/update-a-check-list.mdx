Mettez à jour une Check List que vous possédez. Envoyez uniquement les champs que vous voulez changer. Les champs omis conservent leurs valeurs actuelles. Le document fusionné est ensuite revalidé, donc `name` doit toujours être présent après la fusion.

Enregistrer les changements n’exécute pas de consultations et ne consomme pas de crédits. Dans Smart-Agent, les pays sont verrouillés après la création — cette API accepte encore un nouveau tableau `countries` si vous en envoyez un.

### Endpoint

```
PUT https://api.verifik.co/v2/check-lists/{id}
```

Renvoie la liste mise à jour. Utilisez cet appel lorsque l’utilisateur ajoute ou retire des services (`featureCodes`), change le nom ou définit `status`. Les ids invalides et les listes d’autres clients renvoient `404`.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

Le jeton doit être un **JWT client**. Un jeton sans `clientId` renvoie `403`.

### Parameters

| Name | Type   | Required | Description                          |
| ---- | ------ | -------- | ------------------------------------ |
| `id` | string | Yes      | ObjectId Check List issu de la création ou de la liste. |

### Body

Tous les champs sont optionnels dans la requête. Après fusion, `name` reste obligatoire.

| Name           | Type     | Required | Description                                                                 |
| -------------- | -------- | -------- | --------------------------------------------------------------------------- |
| `name`         | string   | No       | Nom d’affichage. Espaces en trop retirés, 1–150 caractères.                 |
| `countries`    | string[] | No       | Noms de pays. Remplace la liste stockée lorsqu’il est envoyé.               |
| `domains`      | string[] | No       | `people`, `vehicles` et/ou `businesses`. Remplace la liste stockée lorsqu’il est envoyé. |
| `featureCodes` | string[] | No       | Valeurs `code` AppFeature. Remplace la liste stockée lorsqu’il est envoyé.  |
| `status`       | string   | No       | `draft` ou `active`. Libellé d’organisation uniquement.                     |

Les `featureCodes` inconnus échouent. Un service dont le pays ne correspond pas aux `countries` fusionnés échoue sauf si ce service est mondial ou si `countries` est vide.

### Notes

- Les champs omis conservent leurs valeurs actuelles. Envoyer `featureCodes` remplace tout le tableau — ce n’est pas une fusion partielle des codes.
- Après fusion, Joi exige toujours `name`. Vider le nom échoue avec `ValidationError`.
- Les `featureCodes` inconnus renvoient `409` (`check_list_invalid_feature`).
- Une feature dont le pays est hors des `countries` fusionnés renvoie `409` (`check_list_feature_country_mismatch`) sauf si la feature est mondiale ou si `countries` est vide.
- Les mises à jour ne consomment pas de crédits. Exécuter un code enregistré est un appel catalogue. SmartBatch est un produit distinct.
- Parcours produit : [Check List](/verifik-fr/check-list).
