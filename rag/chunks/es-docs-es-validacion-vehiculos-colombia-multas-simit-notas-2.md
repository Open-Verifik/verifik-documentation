# SIMIT - Multas
**API path(s):** /v2/co/simit/comparendos

## Notas

- SIMIT es el Sistema Integrado de Violaciones de Tráfico de Colombia.
- "Comparendo" es el término en español para comparendo de tráfico.
- Las multas se proporcionan en Pesos Colombianos (COP).
- El estado "Pendiente" indica que el comparendo está pendiente de pago.
- Las violaciones por detección fotográfica se marcan con `fotodeteccion: true`.
