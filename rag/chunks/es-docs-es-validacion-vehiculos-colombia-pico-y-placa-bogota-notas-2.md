# Pico y Placa
**API path(s):** /v2/co/vehiculo/pico-y-placa

## Notas

- Este servicio solo funciona para vehículos registrados en Bogotá.
- Las restricciones de Pico y Placa se basan en el último dígito de la placa de matrícula.
- Pueden aplicar excepciones para vehículos con permisos especiales (discapacidad, emergencia, etc.).
- El estado "ACTIVO" indica que la excepción está actualmente válida.
