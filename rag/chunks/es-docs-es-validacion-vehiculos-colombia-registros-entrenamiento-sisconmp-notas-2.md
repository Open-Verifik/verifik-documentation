# Registros de Entrenamiento SISCONMP
**API path(s):** /v2/co/sisconmp/trainings

## Notas

- SISCONMP es el Sistema de Control y Monitoreo de Personal que transporta mercancías peligrosas de Colombia.
- "CURSO BASICO" se refiere a cursos de entrenamiento básico requeridos para el transporte de mercancías peligrosas.
- Los certificados de entrenamiento tienen fechas de vencimiento específicas que deben renovarse.
- Los números de licencia típicamente son iguales al número de documento.
- "inactive: No" indica que el registro de entrenamiento está actualmente activo.
