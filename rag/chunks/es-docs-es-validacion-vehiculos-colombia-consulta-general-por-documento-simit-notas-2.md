# SIMIT - Consulta General por Documento de Identificación
**API path(s):** /v2/co/simit/consultar

## Notas

- Este servicio completo proporciona todos los datos SIMIT para una persona incluyendo multas, cursos y acuerdos de pago.
- "Multas" contiene detalles de violaciones de tráfico con códigos y descripciones de infracciones.
- "Cursos" muestra cursos de educación vial tomados por la persona.
- "AcuerdosPago" muestra acuerdos de pago para multas pendientes.
- Los montos se proporcionan en Pesos Colombianos (COP).
