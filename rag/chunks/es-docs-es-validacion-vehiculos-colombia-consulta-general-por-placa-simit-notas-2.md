# SIMIT - Consulta General por Número de Placa
**API path(s):** /v2/co/simit/consultar/placa

## Notas

- Este servicio completo proporciona todos los datos SIMIT para un vehículo incluyendo multas, cursos y acuerdos de pago.
- "Multas" contiene detalles de violaciones de tráfico asociadas con la placa del vehículo.
- "Cursos" muestra cursos de educación vial relacionados con las violaciones del vehículo.
- "AcuerdosPago" muestra acuerdos de pago para multas pendientes.
- Los montos se proporcionan en Pesos Colombianos (COP).
