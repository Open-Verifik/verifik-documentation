# Medellín - Transit Fines
**API path(s):** /v2/co/medellin/vehicle/fines

## Notes

- **Sandbox mode:** plates **`ABC10001`**–**`ABC10010`** return fixed fixtures; **`ERR404`** returns **404**.
- This endpoint covers **Medellín only**; for national SIMIT data see [SIMIT - Fines](/vehicle-validation/colombia/simit-fines).
- Municipal portal **availability** may vary; outages can return **5xx** errors.
