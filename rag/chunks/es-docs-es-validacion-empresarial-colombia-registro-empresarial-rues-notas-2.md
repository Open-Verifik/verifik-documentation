# Colombia - Registro Empresarial RUES
**API path(s):** /v2/co/rues

Consulta **básica** en RUES por **NIT** (API v2, legado). Devuelve datos esenciales de registro; para el expediente completo en v2 usa `GET /v2/co/rues/complete`.

## Notas

- Consulta **básica** v2; para expediente completo usa **`GET /v2/co/rues/complete`** ([RUES completa v2](/verifik-es/business-validation/colombia/complete-business-registry-rues)).
- **Precio:** menor que la ruta **complete** en el mismo catálogo.
- Preferir **v3** para nuevas integraciones.
