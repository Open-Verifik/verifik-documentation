# Búsqueda Facial
**API path(s):** /v2/face-recognition/search

## Notas

- Proporciona 1–3 imágenes de la misma persona en `images` para mejor recuperación.
- Usa `ACCURATE` para mayor precisión a costa de latencia; usa `FAST` para velocidad.
