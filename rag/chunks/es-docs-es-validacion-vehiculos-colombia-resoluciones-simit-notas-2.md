# SIMIT - Resoluciones
**API path(s):** /v2/co/simit/resoluciones

## Notas

- Las Resoluciones SIMIT son decisiones oficiales sobre violaciones de tráfico.
- El estado "Pendiente de pago" indica que la resolución está pendiente de pago.
- Los números de resolución se usan para rastrear decisiones administrativas específicas.
- Los montos se proporcionan en Pesos Colombianos (COP).
