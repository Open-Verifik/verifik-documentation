# Valores de Vehículos por Placa
**API path(s):** /v2/co/fasecolda/values-by-plate

La API de Valores de Vehículos por Placa Fasecolda de Verifik te ayuda a obtener información completa de vehículos usando placas de matrícula. Está diseñada para agilizar tus procesos de verificación de vehículos, proporcionar valoraciones precisas y asegurar que tengas datos completos del vehículo.
Creamos esta integración para empresas que necesitan una forma rápida, segura y automatizada de acceder a información y valores de vehículos usando placas de matrícula.

## Notas

- Fasecolda es el sistema oficial de valoración de vehículos de Colombia.
- El array `valueModel` contiene valores históricos para diferentes años de modelo.
- Los valores se proporcionan en Pesos Colombianos (COP).
- El campo `bcpp` contiene el precio comercial base del vehículo.
- `estado: "USADO"` indica valores de vehículos usados.

## Casos de Uso Comunes

-   **Valoración de Vehículos**: Obtén valores precisos de vehículos para seguros, ventas o tasaciones.
-   **Consulta de Información de Vehículos**: Accede a especificaciones y detalles completos del vehículo.
-   **Gestión de Flotas**: Verifica información de vehículos para operaciones de flota.
-   **Suscripción de Seguros**: Usa datos de vehículos para evaluación de pólizas de seguros.

## Fuentes Oficiales y Confiabilidad

Nos conectamos directamente con fuentes oficiales de Fasecolda para asegurar que recibas información verificada y actualizada al minuto.
Cada consulta se maneja con estricto cumplimiento de estándares de seguridad y regulatorios.

## Beneficios Clave

-   **Valoraciones Precisas**: Accede a valores y especificaciones oficiales de vehículos Fasecolda.
-   **Resultados Instantáneos**: Procesa verificaciones en segundos, perfecto para verificaciones de vehículos en tiempo real.
-   **Datos Confiables**: Confía en datos obtenidos directamente de registros oficiales de Fasecolda.
-   **Integración Sencilla**: Conéctate fácilmente vía nuestra API REST o usa nuestros SDKs compatibles.
