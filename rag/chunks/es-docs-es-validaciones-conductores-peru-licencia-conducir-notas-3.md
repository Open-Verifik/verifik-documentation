# Perú - Licencia de Conducir
**API path(s):** /v2/pe/driver-license

## Notas

- Solo se admite `documentType=DNI`.
- `documentNumber` debe tener **6–8** dígitos.
- En **modo sandbox**, usa `documentNumber` **10000001**–**10000010** para respuestas de ejemplo estables; `90040401` devuelve **404**.
