# Accidentalidad de Vehículos
**API path(s):** /v2/co/bogota/vehicle/accidentality

## Notas

- La gravedad del accidente "SOLO DAÑOS" indica solo daños materiales (sin lesiones).
- El campo `form` contiene el número oficial del reporte de accidente para referencia.
- Las fechas se proporcionan en formato español con día de la semana y fecha completa.
