## Endpoints Relacionados

- [Crear una Validación de Email de Registro de App](/verifik-es/resources/registros-aplicacion/crear-una-validacion-email-registro-aplicacion)
- [Crear una Validación de Teléfono de Registro de App](/verifik-es/resources/registros-aplicacion/crear-una-validacion-telefono-registro-aplicacion)
- [Crear una Validación Biométrica de Registro de App](/verifik-es/resources/registros-aplicacion/crear-una-validacion-biometrica-registro-aplicacion)
- [Crear una Validación de Documento de Registro de App](/verifik-es/resources/registros-aplicacion/crear-una-validacion-documento-registro-aplicacion)

### Características

- **Asociación automática**: Los objetos se asocian automáticamente cuando se crean durante el registro
- **Rastreo completo**: Todos los objetos relacionados se pueden recuperar a través del registro de aplicación
- **Estado sincronizado**: El estado del registro se actualiza cuando se completan las validaciones asociadas
