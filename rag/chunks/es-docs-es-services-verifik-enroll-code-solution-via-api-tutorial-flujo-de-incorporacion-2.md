# Tutorial - Verifik Enroll Code Solution

**SmartEnroll** es una solución sin código diseñada para proporcionar incorporaciones seguras y fluidas para los usuarios. Esta plataforma permite a las empresas ofrecer diversas verificaciones de incorporación, incluyendo verificación de correo electrónico, teléfono y biométrica, validaciones de documentos, verificaciones AML, verificaciones de manipulación y más.

## Flujo de Incorporación

El proceso de incorporación típico incluye:

1. **Recopilación de Información Básica**: Nombre, correo electrónico, teléfono
2. **Verificación de Correo**: Validación de correo electrónico con OTP
3. **Verificación de Teléfono**: Validación de número de teléfono con OTP
4. **Validación de Documento**: Verificación de documento de identidad
5. **Verificación Biométrica**: Reconocimiento facial y detección de vida
6. **Verificación de Antecedentes**: Verificación AML y listas de sanciones
