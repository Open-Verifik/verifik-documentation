# Check List

## Qué puedes hacer

Operas en uno o más países y vuelves a elegir los mismos servicios de SmartCheck. **Guarda esa mezcla como una Check List.** Prueba un servicio de la lista o envíala a SmartBatch.

Abre **Check List** en Smart-Agent en [ai.verifik.co/check-list](https://ai.verifik.co/check-list). Guardar la lista es gratis. Ejecutar un servicio gasta créditos como cualquier otra llamada a la API.

Guardar la lista es gratis. Ejecutar un servicio gasta créditos como cualquier otra llamada a la API.

## Qué puedes hacer

  
    
      
        Elige países
      
      
        Elige dónde operas al crear la lista. El catálogo muestra servicios de esos países.
      
    
  
  
    
      
        Personas, vehículos, empresas
      
      
        Agrega identidad, placas, registros mercantiles y más. Filtra el catálogo por dominio.
      
    
  

  
    
      
        Prueba un servicio
      
      
        Abre un servicio, llena los campos y ejecútalo. Los créditos se cobran en esa llamada, no al guardar la lista.
      
    
  
  
    
      
        Crea un SmartBatch
      
      
        Pasa los servicios guardados a SmartBatch para un archivo o una cola. Si la lista tiene varios países, elige uno primero.

## En Smart-Agent

Inicia sesión con tu cuenta de cliente Verifik. Check List guarda las listas en esa cuenta, no en un proyecto SmartEnroll.

### 1. Tus listas

El panel muestra cuántas listas tienes, cuántos países cubren y cuántos servicios guardaste. Abre una tarjeta para editar, o crea una nueva.

Si aún no tienes listas, empieza por un país.

:::tip
Después de crear una lista vuelves a este panel. Abre la tarjeta nueva para agregar servicios.
:::
