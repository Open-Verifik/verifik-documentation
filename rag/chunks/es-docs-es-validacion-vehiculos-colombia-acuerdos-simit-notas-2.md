# SIMIT - Acuerdos
**API path(s):** /v2/co/simit/acuerdos

## Notas

- Los Acuerdos SIMIT permiten a los infractores pagar multas de tráfico en cuotas.
- El estado "Acuerdo de pago" indica un acuerdo de pago activo.
- `permitePago: "N"` significa que el pago no está actualmente permitido.
- Los montos se proporcionan en Pesos Colombianos (COP).
- Los números de resolución se usan para rastrear acuerdos específicos.
