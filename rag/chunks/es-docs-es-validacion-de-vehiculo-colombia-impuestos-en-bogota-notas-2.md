# Impuestos en Bogotá
**API path(s):** /v2/co/bogota/vehicle/tax

## Notas

- Usa `CC` para cédula de ciudadanía colombiana o `NIT` para número de identificación tributaria.
- Si `obligationStatus` es "Moroso", hay impuestos pendientes que necesitan ser pagados.
