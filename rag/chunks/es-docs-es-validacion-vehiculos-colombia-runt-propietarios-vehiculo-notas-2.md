# RUNT - Propietarios de vehículo por placa
**API path(s):** /v2/co/runt/propietarios

## Notas

- El código AppFeature es **`colombia_api_runt_owners`**.
- Usa **`CRL299`** en el sandbox.
- Los campos del propietario pueden ser `null` y `owners` puede contener varios registros históricos.
- **`GET /v2/co/runt/vehiculo/owners`** es un alias legado del mismo endpoint; no cambia el resultado ni el cobro.
