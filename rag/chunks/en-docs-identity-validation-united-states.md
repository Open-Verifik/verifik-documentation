# United States Identity Validation

## Available Services

Comprehensive identity validation services for the United States, including Social Security Number verification and state-specific driver license validation.

## Available Services

- **[SSN Verification](/identity-validation/united-states/ssn-verification-social-security-number)** - Social Security Number verification
- **[Kansas Driver's License Verification](/identity-validation/united-states/kansas-drivers-license-verification)** - Kansas driver license validation
- **[Florida Driver License Validation](/identity-validation/united-states/florida-driver-license-validation)** - Florida driver license validation

## Features

- **SSN Verification**: Verify Social Security Numbers with official government data
- **Driver License Validation**: Validate state-issued driver licenses
- **Real-time Data**: Access current and up-to-date information
- **Compliance**: Meet regulatory requirements for identity verification

For detailed API documentation and integration guides, please refer to the specific service documentation.
