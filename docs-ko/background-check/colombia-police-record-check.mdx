# 콜롬비아 경찰 범죄 경력 조회

## API 레퍼런스

### Endpoint

```
https://api.verifik.co/v2/co/policia/consultar
```

콜롬비아 경찰 범죄 경력 조회는 헌법 제248조에 따라 사법 당국과 미결 사항이 있는지를 확인합니다. **`documentType`** 과 **`documentNumber`** 를 **GET**(쿼리) 또는 **POST**(JSON 본문)으로 보냅니다. 성공 시 `data`에는 `documentType`, `documentNumber`, `firstName`, `lastName`, `fullName`, `arrayName`, `details`가 포함됩니다. 채용, 온보딩, 실사 배경 조회에 사용합니다.

### 헤더(Headers)

| 이름           | 값                  |
| -------------- | ------------------- |
| Content-Type   | `application/json`  |
| Authorization  | `Bearer <token>`    |

### 매개변수(Parameters)

:::info
지원되는 **문서 종류**의 전체 목록과 각 종류별 필수 매개변수는 [Document Types](/background-check/document-types) 가이드를 참고해 주세요.
:::

| 이름             | 형식    | 필수 | 설명                                                                       |
| ---------------- | ------- | ---- | -------------------------------------------------------------------------- |
| `documentType`   | string  | 예   | 문서 종류. 허용 값: **CC**, **CE**, **PPT**, **PA**, **DP**. **DP**는 Documento Diplomático(외교 문서)입니다. **PPT**는 허용되며, 경찰 포털에서 여권처럼 매핑됩니다. |
| `documentNumber` | string  | 예   | 조회 대상자의 문서 번호. 공백이나 점 없이 입력합니다.                      |

이 엔드포인트는 `date` 매개변수를 **받지 않습니다**([RNMC](/verifik-ko/background-check/colombia-police-compliance-corrective-measures)와 다름).

### 참고 (Notes)

- **GET**과 **POST**를 모두 지원합니다. POST는 동일한 필드를 JSON 본문으로 보냅니다.
- 경찰 포털은 **성(apellidos) 다음 이름(nombres)** 순으로 표시합니다. Verifik는 이름을 먼저 반환합니다: `firstName` `LILIA MANUELA`, `lastName` `LESPORT FERNANDEZ`, `fullName` `LILIA MANUELA LESPORT FERNANDEZ`, `arrayName`은 이름 다음 성입니다.
- 프로덕션 `data.details`는 **NO TIENE** / **REGISTRA ASUNTOS** 문장만 포함합니다. 헌법 설명 문구는 제거됩니다.
- 샌드박스는 `legend`를 포함할 수 있습니다. `legend`를 프로덕션 보장 필드로 취급하지 마세요.
- 허용 `documentType`은 **CC**, **CE**, **PPT**, **PA**, **DP**(Documento Diplomático)입니다. **PPT**는 허용되며 포털에서 여권처럼 매핑됩니다.
- 이 경로는 발급 `date`가 필요 없습니다(RNMC는 필요).
- 일시적인 업스트림 또는 captcha 실패는 **409**와 `Endpoint_out_of_service` 또는 `captcha_failed`를 반환합니다.
- 미이행 시정 조치는 [콜롬비아 — RNMC 시정 조치](/verifik-ko/background-check/colombia-police-compliance-corrective-measures) (`GET /v2/co/policia/rnmc`)를 사용하세요.
