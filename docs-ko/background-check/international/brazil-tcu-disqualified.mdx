# 감시 목록 — 브라질 TCU 공직 결격

브라질 TCU의 공직 결격자 목록을 대조합니다.

## 응답에 포함되는 값

- `foundInBrTcuDisqualified`
- 일치 시 `details`
- `fullName`

## 사용 사례

- 지급이나 온보딩 전에 대조합니다.
- false 플래그를 깨끗한 200으로 다룹니다.
- 이름, 또는 문서 유형과 번호를 보냅니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/br/tcu-disqualified
```

일치하면 `foundInBrTcuDisqualified`가 true이고 `details`가 채워집니다. 목록에 없으면 HTTP 200이고 `foundInBrTcuDisqualified`는 false이며 `details`는 비어 있습니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **조건부** | `SAMPLE NAME` | 이름. 지갑 목록이면 주소. 이것만으로 충분합니다. |
| `documentType` | string | **조건부** | `CPF` | `fullName`을 생략하면 `documentNumber`와 함께 필수입니다. 이름 없는 CPF는 `dateOfBirth`도 필요합니다. |
| `documentNumber` | string | **조건부** | `12345678901` | `fullName`을 생략하면 `documentType`과 함께 보내는 5자 이상 식별자. |
| `dateOfBirth` | string | **조건부** | `1990-01-15` | `fullName`을 생략하고 CPF, CI, CCPA, DUI, CCUY일 때 필수입니다. |

### 참고

- `fullName`, 또는 `documentType`과 `documentNumber`를 보냅니다.
- 미등재는 `foundInBrTcuDisqualified`가 false인 HTTP 200입니다.
- 이름 없는 CPF는 `dateOfBirth`도 필요합니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.
