# EU 통합 여행금지

개인 또는 조직이 **EU 통합 여행금지**에 등재되어 있는지 조회합니다. 유럽연합 이사회가 유럽연합 관련 목록으로 이 명단을 공개합니다.

통합 여행금지 명단은 이사회 결정에 따라 유럽연합 입국 또는 경유가 금지된 사람을 수록합니다.

`fullName`, `documentNumber` 또는 둘 다 보낼 수 있습니다. 둘 중 하나 이상은 필수입니다. 조회가 공개 기록과 일치하면 응답의 `foundInEuTravelBans`는 `true`이고, 일치하지 않으면 `false`입니다. 일치하면 `details`에 등재 이름, 제한 프로그램, 발령 기관, 비고 포함됩니다. KYC, AML/CFT, 공급업체 온보딩, 지급 심사에 사용하십시오. 결과를 그대로 쓰기 전에 일치 건을 검토하십시오. 이 호출은 공식 명단을 대체하지 않으며 법적 판단이 아닙니다.

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/eu-travel-bans
```

성공 응답에는 `data.fullName`, 원천 기록이 이름을 나눌 때의 `data.firstName` 및 `data.lastName`, 요청에 포함한 경우 `data.documentNumber`, `data.foundInEuTravelBans`, `data.details`가 있습니다. 일치하면 `details`에는 등재 이름, 제한 프로그램, 발령 기관, 비고이(가) 포함됩니다. `signature` 객체에는 `dateTime`과 메시지 `Certified by Verifik.co`가 있습니다. `foundInEuTravelBans`가 `false`이면 `details`는 빈 객체입니다.

### Headers

| 이름            | 값                  | 설명          |
| ------------- | ------------------ | ----------- |
| Content-Type  | `application/json` | 요청 형식       |
| Accept        | `application/json` | 응답 형식       |
| Authorization | `Bearer <token>`   | Verifik JWT |

### Parameters

| 파라미터             | 유형     | 필수  | 예시                       | 설명                                                      |
| ---------------- | ------ | --- | ------------------------ | ------------------------------------------------------- |
| `fullName`       | string | 조건부 | `SAMPLE DESIGNATED NAME` | 개인 또는 조직의 법적 명칭입니다. `documentNumber`를 보내지 않을 때 필요합니다.   |
| `documentNumber` | string | 조건부 | `A1234567`               | 공백 없는 신분증 번호 또는 법인 등록번호입니다. `fullName`을 보내지 않을 때 필요합니다. |

### 사용 사례

- **여행·비자 스크리닝:** 이 공개 비자 제한 목록과 인물을 대조합니다.
- **제재 프로그램:** 컴플라이언스 프로그램이 비자 금지를 인용할 때 결과를 사용합니다.
- **기록:** 인증된 응답을 다른 스크리닝 결과와 함께 보관합니다.

### Notes

- `fullName` 또는 `documentNumber`를 보내십시오. 하나 이상은 필수입니다. 둘 다 없으면 API는 HTTP 409, 코드 `MissingParameter`, 메시지 `Either fullName or documentNumber must be provided`를 반환합니다.
- `foundInEuTravelBans`는 이 목록의 기록과 일치하면 `true`이고, 그렇지 않으면 `false`입니다. 불일치이면 `details`는 빈 객체입니다.
- 일치 예시는 응답 형식을 보여 줍니다. 실제 일치는 이 목록에 공개된 해당 기록의 속성을 반환합니다.
- 일치는 컴플라이언스 검토를 위한 스크리닝 결과입니다. 법적 판단이 아니며 공식 출처를 대체하지 않습니다.
- `Authorization` 헤더에 Bearer JWT로 인증하십시오.
- 결과는 호출 시점의 목록을 반영합니다. 이후 결과가 필요하면 새로 요청하십시오.
