# 콜롬비아 — PEP 정부 구조

콜롬비아 정부 구조의 공직자를 대조합니다.

## 응답에 포함되는 값

- `isPEP`
- `matches`
- `fullName`과 `documentNumber`
- 단순 미검출이면 빈 `matches`

## 사용 사례

- 온보딩 전에 콜롬비아 PEP 명부를 대조합니다.
- 미등재 인물을 HTTP 200으로 보관합니다.
- 이름 또는 문서 번호로 검색합니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/co/pep/estructura-gobierno
```

일치하면 `isPEP`가 true입니다. 이 명부에 없으면 HTTP 200이고 `isPEP`는 false이며 `matches`는 비어 있습니다. 404가 아닙니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **조건부** | `MARIA LOPEZ` | 이름만으로 충분합니다. 디렉터리에 있으면 `partyName`, `entityName`, `country`도 받습니다. |
| `documentNumber` | string | **조건부** | `80123456` | 식별자 4–30자. |
| `documentType` | string | 아니오 | `CC` | 선택: `CC`, `NIT`, `CE`, `PAS`, `TI`, `CD`. |

### 참고

- 단순 미검출은 `isPEP`가 false인 HTTP 200입니다.
- 검색 값을 하나 이상 보냅니다.
- 그 200을 404로 매핑하지 않습니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.

## 샌드박스

| 시나리오 | 파라미터 | 결과 |
| :--- | :--- | :--- |
| 원천에 기록 있음 | `fullName: "MARIA LOPEZ"` | 일치하면 isPEP가 true인 200. |
| 필수 값 누락 | Omit every search value | 검색 값이 없으면 409. |
| 알 수 없는 값 | `fullName: "CLEAN NAME"` | isPEP가 false인 200. 단순 미검출은 404가 아닙니다. |

401 when the bearer token is missing or rejected.
