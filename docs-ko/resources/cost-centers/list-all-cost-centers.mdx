### 엔드포인트

**GET** `https://api.verifik.co/v2/cost-centers`

계정의 비용 센터를 반환합니다. 국가, 그다음 이름 순입니다.

#### 헤더

| 이름          | 값                 |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### 쿼리 매개변수

#### `active`

**타입:** boolean  
**필수:** 아니요

`true`는 활성만, `false`는 비활성만 반환합니다. 생략하면 둘 다 반환합니다.

#### `country`

**타입:** string  
**필수:** 아니요

ISO-2 국가 코드. 예: `ES`.

#### `page`

**타입:** number  
**필수:** 아니요

페이지 번호. 1부터.

#### `limit`

**타입:** number  
**필수:** 아니요

페이지당 개수. 기본 50, 최대 100.

## 오류 응답

잘못된 쿼리입니다. 예를 들어 `limit`이 100을 넘거나 `country`가 두 글자가 아닌 경우입니다.

```json
{
  "message": "\"limit\" must be less than or equal to 100",
  "code": "MissingParameter"
}
```
