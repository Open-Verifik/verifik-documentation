# 비용 센터 목록

```
GET https://api.verifik.co/v2/cost-centers
```

| 이름      | 타입    | 필수   | 설명                                              |
| --------- | ------- | ------ | ------------------------------------------------- |
| `active`  | boolean | 아니요 | `true`는 활성만, `false`는 비활성만.              |
| `country` | string  | 아니요 | ISO-2 국가 코드.                                  |
| `page`    | number  | 아니요 | 페이지 번호. 1부터.                               |
| `limit`   | number  | 아니요 | 페이지당 개수. 기본 50, 최대 100.                 |

```json
{
	"data": [
		{
			"_id": "6acfbdda92451bac5d0a7ebe",
			"name": "스페인 운영",
			"code": "SPAIN-OPS",
			"country": "ES",
			"active": true
		}
	],
	"total": 1,
	"page": 1,
	"pages": 1,
	"limit": 50
}
```
