# 비용 센터 수정

```
PUT https://api.verifik.co/v2/cost-centers/{id}
```

`name`, `code`, `country`, `active` 중 원하는 항목을 보냅니다. `active: true`로 다시 활성화합니다. 이미 기록된 요청은 당시의 비용 센터를 유지합니다.
