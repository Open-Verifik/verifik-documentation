### 엔드포인트

**PUT** `https://api.verifik.co/v2/cost-centers/{id}`

비용 센터 하나를 수정합니다. 바꿀 필드만 보냅니다. 이미 기록된 요청은 당시의 비용 센터를 유지합니다.

#### 헤더

| 이름          | 값                 |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### 경로 매개변수

#### `id`

**타입:** string  
**필수:** 예

비용 센터 id입니다.

#### 본문 매개변수

#### `name`

**타입:** string  
**필수:** 아니요

표시 이름. 최대 120자.

#### `code`

**타입:** string  
**필수:** 아니요

새 헤더 값. 문자, 숫자, `.`, `-`, `_`. 최대 60자. 계정당 고유.

#### `country`

**타입:** string  
**필수:** 아니요

ISO-2 국가 코드.

#### `active`

**타입:** boolean  
**필수:** 아니요

`true`로 다시 활성화하고, `false`로 새 요청에 지정되지 않게 합니다.

### 요청 예시

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X PUT "https://api.verifik.co/v2/cost-centers/6acfbdda92451bac5d0a7ebe" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"스페인 운영","active":true}'
```

</TabItem>

## 오류 응답

알 수 없는 id:

```json
{
  "message": "cost_center_not_found",
  "code": "NotFound"
}
```

계정의 다른 센터가 이미 쓰는 `code`:

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```
