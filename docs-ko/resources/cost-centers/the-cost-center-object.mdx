### 개요

비용 센터 객체는 팀, 국가 또는 사업 단위에 대해 Verifik이 저장하는 기록입니다. 요청은 `_id`로 참조합니다. `code`는 `x-cost-center` 헤더로 보냅니다.

```json
{
  "_id": "6acfbdda92451bac5d0a7ebe",
  "client": "69c2b824295cd7d276e478ad",
  "name": "스페인 운영",
  "code": "SPAIN-OPS",
  "country": "ES",
  "active": true,
  "createdAt": "2026-10-14T17:37:30.469Z",
  "updatedAt": "2026-10-14T17:37:30.469Z"
}
```

### 속성

#### `_id`

**타입:** string  
**필수:** 예

고유 식별자. 조회, 수정, 비활성화와 프로젝트 기본값에 사용합니다.

#### `client`

**타입:** string  
**필수:** 예

이 비용 센터를 소유한 계정입니다.

#### `name`

**타입:** string  
**필수:** 예

표시 이름. 최대 120자.

#### `code`

**타입:** string  
**필수:** 예

`x-cost-center`에 보내는 값. 문자, 숫자, `.`, `-`, `_`. 최대 60자. 계정당 고유.

#### `country`

**타입:** string  
**필수:** 예

이 센터가 주로 담당하는 ISO-2 국가. 대문자로 저장됩니다.

#### `active`

**타입:** boolean  
**필수:** 예

비활성 센터는 기록은 남지만 새 요청에 지정할 수 없습니다. 기본값 `true`.

#### `createdAt`

**타입:** string  
**필수:** 예

만든 시각. ISO-8601.

#### `updatedAt`

**타입:** string  
**필수:** 예

마지막으로 바뀐 시각. ISO-8601.
