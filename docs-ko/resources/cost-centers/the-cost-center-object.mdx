# 비용 센터 객체

```json
{
	"_id": "6acfbdda92451bac5d0a7ebe",
	"client": "69c2b824295cd7d276e478ad",
	"name": "스페인 운영",
	"code": "SPAIN-OPS",
	"country": "ES",
	"active": true,
	"createdAt": "2026-10-14T17:37:30.469Z",
	"updatedAt": "2026-10-14T17:37:30.469Z"
}
```

| 필드      | 타입    | 설명                                                                                          |
| --------- | ------- | --------------------------------------------------------------------------------------------- |
| `name`    | string  | 표시 이름. 최대 120자.                                                                        |
| `code`    | string  | `x-cost-center`에 보내는 값. 문자, 숫자, `.`, `-`, `_`. 최대 60자. 계정당 고유.               |
| `country` | string  | 이 비용 센터가 주로 담당하는 ISO-2 국가.                                                      |
| `active`  | boolean | 비활성 센터는 기록은 남지만 새 요청에 지정할 수 없습니다.                                     |
