# 비용 센터 조회

```
GET https://api.verifik.co/v2/cost-centers/{id}
```

[비용 센터 객체](/verifik-ko/resources/the-cost-center-object)를 반환하거나, 없으면 `404`와 `cost_center_not_found`를 반환합니다.
