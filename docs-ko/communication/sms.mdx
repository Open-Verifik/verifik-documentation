# SMS 메시지

**SMS 메시지**는 GET이 아니라 **POST** `https://api.verifik.co/v2/communication/sms`입니다. 본문에는 `phone`과 `+`로 시작하는 `countryCode`가 필요합니다. 경로가 `phoneGateway`를 `sms`로 고정하므로 그 필드는 보내지 않습니다. 선택 `title`은 1–15자이고 `language`가 문구를 고릅니다. 계정 소유자 토큰으로 호출할 수 있습니다. 스태프는 Smart Tools 실행 권한이 필요합니다.

## 응답에 포함되는 값

- `phone`과 `countryCode`
- `sms`로 고정된 `phoneGateway`
- `status`

## 사용 사례

- SMS로 로그인 코드를 보냅니다.
- 국내 번호와 국가 번호를 사용합니다.
- 경로가 SMS 게이트웨이를 고르게 합니다.

---

## API 레퍼런스

### Endpoint

```http
POST https://api.verifik.co/v2/communication/sms
```

성공한 발송은 `phoneGateway` `sms`와 상태 `sent`를 반환합니다. OTP가 전달될 때 과금됩니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `phone` | string | **예** | `3001234567` | 국내 번호만. 국가 번호를 넣지 않습니다. |
| `countryCode` | string | **예** | `+57` | `+`로 시작하는 국가 번호. |
| `title` | string | 아니오 | `ACME` | 선택 발신자 이름 1–15자. |
| `language` | string | 아니오 | `es` | 선택 템플릿 언어. |

### 참고

- 이 경로는 GET이 아니라 POST입니다.
- `phone`과 `countryCode`는 필수입니다. `countryCode`는 `+`로 시작합니다.
- `phoneGateway`는 보내지 않습니다. 경로가 `sms`로 고정합니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.

## 샌드박스

| 시나리오 | 파라미터 | 결과 |
| :--- | :--- | :--- |
| 원천에 기록 있음 | `phone: "3001234567"`, `countryCode: "+57"` | SMS OTP가 보내지면 200. |

| 알 수 없는 값 | `countryCode: "57"` | countryCode가 +로 시작하지 않으면 409. |

401 when the bearer token is missing or rejected.
