# 이메일 OTP

**이메일 OTP**는 일회용 코드를 보냅니다. 실제 메서드는 GET이 아니라 **POST** `https://api.verifik.co/v2/communication/email`입니다. 본문에는 `project`, `validationMethod`(`manual` 또는 `verificationCode`), `email`, `type`(`validation`, `login`, `onboarding`, `oneTimeLink`)이 필요합니다. 선택 필드는 `expiresAt`, `redirectUrl`, `webhookUrl`, `identityUrl`, `requires2FA`, `ipAddress`, `language`입니다.

## 응답에 포함되는 값

- `email`과 `status`
- `type`과 `validationMethod`

## 사용 사례

- 메일함으로 로그인 코드를 보냅니다.
- 이메일로 이어지는 온보딩을 시작합니다.
- 전달 상태 웹훅을 붙입니다.

---

## API 레퍼런스

### Endpoint

```http
POST https://api.verifik.co/v2/communication/email
```

성공한 발송은 상태 `sent`인 이메일 검증을 반환합니다. 프로젝트가 이미 쓰는 이메일 검증 엔드포인트로 코드를 확인합니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `project` | string | **예** | `project_id` | 이메일 OTP를 소유한 프로젝트 id. |
| `validationMethod` | string | **예** | `verificationCode` | `manual` 또는 `verificationCode`. |
| `email` | string | **예** | `person@example.com` | 코드를 받는 메일함. 잘못된 주소는 409입니다. |
| `type` | string | **예** | `validation` | `validation`, `login`, `onboarding`, `oneTimeLink`. |

### Request

<Tabs>
<TabItem value="javascript" label="Node.js / JavaScript">

```javascript
import axios from "axios";

const options = {
  method: "POST",
  url: "https://api.verifik.co/v2/communication/email",
  headers: {
    "Content-Type": "application/json",
    Accept: "application/json",
    Authorization: "Bearer <your_token>",
  },
  data: {
    "project": "project_id",
    "validationMethod": "verificationCode",
    "email": "person@example.com",
    "type": "validation"
  },
};

try {
  const { data } = await axios.request(options);
  console.log(data);
} catch (error) {
  console.error(error.response ? error.response.data : error.message);
}
```

### 참고

- 이 경로는 GET이 아니라 POST입니다.
- `project`, `validationMethod`, `email`, `type`은 필수입니다.
- 이메일이 아닌 주소는 409입니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.

| 원천에 기록 있음 | the example body | 코드가 보내지면 200. |
