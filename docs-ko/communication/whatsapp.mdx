# WhatsApp 메시지

**WhatsApp 메시지**는 GET이 아니라 **POST** `https://api.verifik.co/v2/communication/whatsapp`입니다. 본문에는 `phone`과 `countryCode`가 필요합니다. 경로가 `phoneGateway`를 `whatsapp`으로 고정합니다. 선택 `whatsappTemplate`은 `authentication`(기본) 또는 `flow2`입니다. `flow2`이면 `language`가 `flow2_es` 또는 `flow2_en`을 고르고, 선택 `title`(1–15자)이 브랜드 구역입니다.

## 응답에 포함되는 값

- `phone`과 `countryCode`
- `whatsapp`으로 고정된 `phoneGateway`
- `status`

## 사용 사례

- WhatsApp으로 로그인 코드를 보냅니다.
- 브랜드 템플릿이 필요하면 flow2를 고릅니다.
- 기본 템플릿은 authentication입니다.

---

## API 레퍼런스

### Endpoint

```http
POST https://api.verifik.co/v2/communication/whatsapp
```

성공한 발송은 `phoneGateway` `whatsapp`과 상태 `sent`를 반환합니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `phone` | string | **예** | `3001234567` | 국내 번호만. |
| `countryCode` | string | **예** | `+57` | `+`로 시작하는 국가 번호. |
| `whatsappTemplate` | string | 아니오 | `authentication` | 선택. `authentication`(기본) 또는 `flow2`. |
| `language` | string | 아니오 | `es` | 선택. `flow2`이면 `flow2_es` 또는 `flow2_en`을 고릅니다. |

```javascript
import axios from "axios";

const options = {
  method: "POST",
  url: "https://api.verifik.co/v2/communication/whatsapp",

}
```

### 참고

- 이 경로는 GET이 아니라 POST입니다.
- `whatsappTemplate`은 선택입니다. `authentication` 또는 `flow2`.
- 경로가 `phoneGateway`를 `whatsapp`으로 고정합니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.

| 시나리오 | 파라미터 | 결과 |
