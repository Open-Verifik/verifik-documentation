# 🇨🇱 칠레 — 운전면허 정지 및 차단 등록부

**Servicio de Registro Civil e Identificación**의 전국 운전면허 차단 등록부를 RUN 번호로 조회합니다.

단일 코뮌만 지원하는 지자체 포털과 달리, 본 엔드포인트는 칠레 전역의 법원 및 행정 기관에서 명령한 운전면허 정지 및 차단에 대한 **전국 단위 커버리지**를 제공합니다.

### 엔드포인트

```
GET https://api.verifik.co/v2/cl/driver-license/block
```

### 헤더(Headers)

| 이름           | 값                  |
| -------------- | ------------------- |
| Accept         | `application/json`  |
| Authorization  | `Bearer <token>`    |

### 매개변수(Parameters)

| 이름 | 형식 | 필수 | 설명 | 예시 |
| ---- | ---- | ---- | ---- | ---- |
| `documentNumber` | string | **예** | 검증 번호(DV)가 포함된 칠레 RUN 번호. 마침표 및 하이픈은 선택 사항입니다(`18.347.440-5` 또는 `18347440-5`). 검증 번호는 올바른 Modulo 11 계산값이어야 합니다. | `18347440-5` |
| `force` | boolean | 아니요 | 서버 캐시를 우회하고 출처 기관에 직접 조회할지 여부. | `false` |

## 주요 기능

- **전국 등록부 조회**: 칠레 Servicio de Registro Civil e Identificación 공식 데이터.
- **면허 정지 및 차단 여부 즉시 확인**: `hasBlock: true/false`로 신속 판별.
- **명의자 성명 검증**: 운전면허 자격에 등록된 공식 법적 성명 반환.
- **차단 메타데이터**: 법원 명령 일자, 정지 유형 및 사유 상세 제공.
- **Modulo 11 검증 보호**: 오타 입력 시 사전 감지하여 불필요한 크레딧 차감 방지.
