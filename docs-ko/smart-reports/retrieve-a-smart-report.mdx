ID로 단일 `SmartReport`를 조회합니다. 응답은 `template`, `smartBatch`, `client`를 채워서(populate) 반환하며 바로 사용할 수 있는 `downloadUrl` (`/v2/smart-reports/{id}/download`) 및 `htmlUrl` (`/v2/smart-reports/{id}/html`) 경로를 포함합니다.

이 엔드포인트는 `POST /v2/smart-reports/run`이 `"async"` 모드로 실행되거나 90초 동기 제한 시간 이후 `202 Accepted`로 폴백할 때 반환되는 폴링 대상(`pollUrl`)이기도 합니다. 리포트 ID가 존재하지 않거나 다른 클라이언트에 속한 경우, 이 엔드포인트는 `{ "data": null }`과 함께 HTTP `200 OK`를 반환합니다.

### 엔드포인트

```
GET https://api.verifik.co/v2/smart-reports/{id}
```

이 엔드포인트는 본인의 클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-reports/{id}`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름            | 값                     | 설명                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 요청 페이로드 형식.                      |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입   | 필수   | 설명 |
| ---- | ------ | ------ | ---- |
| `id` | string | **예** | `POST /v2/smart-reports/run`, `POST /v2/smart-reports` 또는 `GET /v2/smart-reports`가 반환한 `SmartReport` ObjectId. |

### 웹훅 및 MCP 연동

- **폴링 vs 웹훅**: 비동기 실행의 경우 `data.status`가 최종 상태(`"generated"`, `"sent"` 또는 `"failed"`)가 될 때까지 `GET /v2/smart-reports/{id}`를 폴링하거나 웹훅 이벤트(`smart_batch_report_generated`, `smart_batch_report_generation_failed`, `smart_batch_report_sent`, `smart_batch_report_delivery_failed`)를 구독할 수 있습니다. [SmartReports 웹훅](/verifik-ko/resources/smart-reports-webhooks)을 참조하세요.
- **MCP 대응 도구**: AI 에이전트는 `smart_report_get` MCP 도구를 사용하여 리포트 레코드를 조회할 수 있습니다. [MCP 및 AI 에이전트](/verifik-ko/smart-reports/mcp-and-ai-agents)를 참조하세요.

### 참고 사항

- 리포트가 존재하지 않거나 다른 클라이언트에 속한 경우 `404` 대신 `{ "data": null }`과 함께 `200 OK`를 반환합니다.
- `downloadUrl`과 `htmlUrl`은 `https://api.verifik.co`(또는 `https://ai.verifik.co`) 뒤에 붙여서 사용할 수 있는 상대 API 경로입니다.
