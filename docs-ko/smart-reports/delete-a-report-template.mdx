인증된 클라이언트가 소유한 사용자 지정 Smart Report 템플릿을 삭제합니다. 삭제된 템플릿 문서는 `{ "data": ... }`로 반환됩니다.

헤드리스 워크플로 및 자동화된 테스트 파이프라인에서 임시 템플릿을 정리하거나 더 이상 사용하지 않는 리포트 디자인을 제거할 때 이 엔드포인트를 사용하세요. 기본 제공 `"System"` 템플릿은 삭제할 수 없으며 `403` (`system_template_readonly`)을 반환합니다. 템플릿을 삭제해도 크레딧이 차감되지 않으며 이전에 생성된 `SmartBatch` 리포트도 제거되지 않습니다.

### 엔드포인트

```
DELETE https://api.verifik.co/v2/smart-report-templates/{id}
```

Smart-Agent 프록시(`https://ai.verifik.co`)도 동일한 `/v2/...` 경로를 제공하며 본인의 `Authorization: Bearer <VERIFIK_JWT>` 헤더가 필요합니다.

### 헤더

| 이름          | 값                     |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 매개변수

| 이름 | 타입   | 필수 | 설명 |
| ---- | ------ | ---- | ---- |
| `id` | string | 예   | Smart Report 템플릿 ObjectId. |

### 참고 사항

- 기본 제공 `"System"` 템플릿은 삭제할 수 없습니다(`403` `system_template_readonly`).
- 삭제된 후 동일한 `{id}`를 대상으로 하는 후속 `GET`, `PUT` 또는 `DELETE` 요청은 `{ "data": null }`(`GET` 시) 또는 `404` `not_found`(`PUT`/`DELETE` 시)를 반환합니다.
