기존 행이나 저장된 결과를 덮어쓰지 않고 기존 `SmartBatch`에 새 입력 행을 추가합니다. 래핑된 행(`{ rowIndex?, inputData }`)과 평면 행(`{ rowIndex?, ...inputFields }`)이 모두 허용되며, 서버는 `maxExisting + 1`부터 시작하는 순차적 행 인덱스를 할당합니다.

배치가 `"processing"` 상태인 동안에는 행을 추가할 수 없습니다(`400 batch_append_not_allowed_while_processing`). 배치가 이전에 `"completed"` 또는 `"failed"` 상태였던 경우, 행을 추가하면 새 행을 실행할 수 있도록 `status`가 `"pending"`으로 재설정되고 `completedAt`이 지워집니다.

### 엔드포인트

```text
POST https://api.verifik.co/v2/smart-batches/{id}/rows/append
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/{id}/rows/append`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | 행을 추가할 `SmartBatch` ObjectId. |

### 본문

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `rows` | object[] | 예 | 래핑된(`{ rowIndex?, inputData }`) 또는 평면(`{ rowIndex?, ...inputFields }`) 입력 행의 비어 있지 않은 배열(`min 1`). 서버가 순차적인 `rowIndex = maxExisting + 1`을 할당합니다. |

알 수 없는 본문 키 또는 빈 `rows` 배열은 Joi 검증에 의해 `409 MissingParameter`로 거부됩니다.

package main

import (
	"bytes"

	"fmt"
	"net/http"
	"os"

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	body, _ := json.Marshal(map[string]interface{}{
		"rows": []map[string]interface{}{
			{

					"documentNumber": "1020304050",
				},
			},
			{
				"documentType":   "CC",
				"documentNumber": "1098765432",
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-batches/"+batchID+"/rows/append", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### 참고

- 행을 추가해도 검사가 실행되거나 크레딧이 소비되지 않습니다. 이후 [Smart Batch 시작](/verifik-ko/smart-reports/start-a-smart-batch)으로 배치를 시작하세요.
- 클라이언트가 제공한 `rowIndex`는 무시되며, `maxExisting + 1`부터 시작하는 서버 할당 순차 번호가 사용됩니다.
- 배치가 `"completed"` 또는 `"failed"` 상태였던 경우 `status`가 `"pending"`으로 재설정되고 `completedAt`이 지워집니다.
