`SmartBatch`에 남아 있는 종료되지 않은 모든 행에 대한 사전 크레딧 추정치를 계산합니다. 응답은 배치의 `BatchConfiguration`에서 활성화된 단계별로 가격을 세분화하고, 예상 비용을 클라이언트 계정의 사용 가능한 크레딧 잔액과 비교합니다.

이 엔드포인트를 호출해도 카탈로그 조회가 실행되지 않으며 크레딧이 전혀 소비되지 않습니다.

### 엔드포인트

```text
GET https://api.verifik.co/v2/smart-batches/{id}/estimate
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/{id}/estimate`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | 비용을 추정할 `SmartBatch` ObjectId. |

### 참고

- `itemCount`와 `pendingRows`는 아직 종료 행 상태(`completed`, `failed` 또는 `partial`)가 아닌 행만 반영합니다.
- `availableCredits`는 클라이언트 계정의 `credits`와 `extraCredits`를 합산합니다. `sufficientCredits`가 `false`일 때 `shortfall`은 추가로 필요한 크레딧을 나타냅니다.
- 단계별 가격 책정은 해당되는 경우 클라이언트 계정의 `ClientFeature` 스냅샷 가격을 사용합니다.
