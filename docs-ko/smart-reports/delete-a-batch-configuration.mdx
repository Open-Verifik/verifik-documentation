클라이언트 계정이 소유한 `BatchConfiguration`을 삭제합니다. 이 엔드포인트는 구성 문서를 제거하고 `data`에 삭제된 문서를 반환합니다.

`{id}`가 존재하지 않거나 다른 클라이언트 계정에 속한 경우 엔드포인트는 `404` (`not_found`)를 반환합니다. 구성을 삭제해도 조회가 실행되지 않으며 크레딧이 소비되지 않습니다.

### 엔드포인트

```
DELETE https://api.verifik.co/v2/batch-configurations/{id}
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>` 헤더를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/batch-configurations/{id}`)에서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 |
| ---- | -- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

토큰은 **클라이언트 JWT**여야 합니다. 자격 증명이 누락되었거나 유효하지 않으면 `401 Unauthorized`가 반환됩니다.

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | 삭제할 `BatchConfiguration` ObjectId. |

### 참고

- 구성을 삭제하면 삭제된 문서가 `data`에 반환됩니다. 이후 동일한 `{id}`를 사용하는 `GET`, `PUT` 또는 `DELETE` 요청에서는 더 이상 해당 레코드를 찾을 수 없습니다(`GET`은 `data: null`을 반환하고 `GET /input-schema`, `PUT`, `DELETE`는 `404` `not_found`를 반환).
- 구성을 삭제해도 크레딧이 소비되지 않습니다.
