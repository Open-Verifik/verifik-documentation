행을 제출하기 전에 저장된 `BatchConfiguration`의 정확한 입력 계약(input contract)을 확인합니다. 이 엔드포인트는 `preferredReportTemplate`(구성에 연결된 최신 활성 `SmartReportTemplate`으로 폴백), `webhookUrl`, `stepCount`, `estimatedCreditsPerRow`, `requiredFields`, `optionalFields`, 표준 `jsonSchema` 및 바로 전송할 수 있는 `exampleInput` 페이로드를 반환합니다.

리졸버(resolver)는 비활성화된 단계, 비활성 `dependencyGroup` 옵션, 내부 플래그, 그리고 `parameterDefaults`나 `visitaFlow` 단계 체이닝(`{{results.N.field}}`)을 통해 이미 공급된 필드를 자동으로 건너뛰며, `inputFieldMapping`에 따라 열 이름을 다시 매핑합니다. 이 경로는 `/input-schema`가 직접 해석되도록 `/{id}`보다 먼저 등록되어 있으며 `smart_report_get_input_schema` MCP 도구로도 사용할 수 있습니다.

### 엔드포인트

```
GET https://api.verifik.co/v2/batch-configurations/{id}/input-schema
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>` 헤더를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/batch-configurations/{id}/input-schema`)에서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 |
| ---- | -- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

토큰은 **클라이언트 JWT**여야 합니다. 자격 증명이 누락되었거나 유효하지 않으면 `401 Unauthorized`가 반환됩니다.

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | 검사할 `BatchConfiguration` ObjectId. |

### 참고

- 입력 스키마를 검사해도 조회가 실행되지 않으며 크레딧이 소비되지 않습니다.
- 구성에 `preferredReportTemplate`이 설정되지 않은 경우, 서버는 `{id}`에 연결된 최신 활성 `SmartReportTemplate`으로 폴백합니다(없으면 `null`).
- `inputFieldMapping`이 입력 열을 API 매개변수에 매핑하는 경우, `requiredFields`, `optionalFields`, `jsonSchema`, `exampleInput`은 원시 API 매개변수 이름 대신 매핑된 입력 열 이름을 노출합니다.
- `200`과 함께 `{ "data": null }`을 반환하는 [배치 구성 조회](/verifik-ko/smart-reports/retrieve-a-batch-configuration)와 달리, 누락되었거나 다른 클라이언트의 `{id}` 값은 `404` (`not_found`)를 반환합니다.
- AI 에이전트 및 헤드리스 파이프라인의 경우 이 엔드포인트는 `smart_report_get_input_schema` MCP 도구에 해당합니다.
