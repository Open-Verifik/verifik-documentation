인증된 클라이언트에 속한 `SmartReport` 레코드 목록을 조회합니다. 결과에는 `template`, `smartBatch` 및 `client`가 채워지며(populate), `smartBatch`, `template`, `externalRefId`, `createdByChannel`로 필터링하고 선택적으로 페이지네이션 및 정렬을 적용할 수 있습니다.

`page`를 전달하면 응답에 페이지네이션 메타데이터(`total`, `limit`, `page`, `pages`)가 포함됩니다. `page`를 생략하면 페이지네이션 메타데이터 없이 `{ data: [...] }` 형태로 일치하는 목록을 반환합니다.

### 엔드포인트

```
GET https://api.verifik.co/v2/smart-reports
```

이 엔드포인트는 본인의 클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-reports`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름            | 값                     | 설명                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 요청 페이로드 형식.                      |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름               | 타입   | 필수   | 설명 |
| ------------------ | ------ | ------ | ---- |
| `smartBatch`       | string | 아니요 | 특정 `SmartBatch` ObjectId에 연결된 리포트로 필터링합니다. |
| `template`         | string | 아니요 | 특정 템플릿 ObjectId에 연결된 리포트로 필터링합니다. |
| `status`           | string | 아니요 | 허용 값: `"draft"`, `"pending"`, `"generating"`, `"generated"`, `"failed"`, `"sent"`. 향후 호환성을 위해 Joi 검증에서는 허용되지만, 현재 목록 필터링은 `smartBatch`, `template`, `externalRefId`, `createdByChannel`에 대해 동작합니다. |
| `externalRefId`    | string | 아니요 | 외부 상관관계 식별자로 필터링합니다. 최대 `200`자. |
| `createdByChannel` | string | 아니요 | 발생 채널로 필터링합니다: `"portal"`, `"api"`, `"mcp"`, `"x402"` 또는 `"webhook"`. |
| `page`             | number | 아니요 | 조회할 페이지 번호. `page`를 전달하면 `total`, `limit`, `page`, `pages`가 포함된 페이지네이션 출력이 활성화됩니다. |
| `limit`            | number | 아니요 | 페이지당 최대 항목 수. `page` 설정 시 기본값은 `20`입니다. |
| `sort`             | string | 아니요 | 정렬 필드 및 방향. `page` 설정 시 기본값은 `"-updatedAt"`입니다. |

#### 필터링 및 페이지네이션 참고 사항

- **하위/향후 호환 `status` 매개변수**: Joi는 `"draft"`, `"pending"`, `"generating"`, `"generated"`, `"failed"`, `"sent"`에 대해 `status`를 검증하지만, 기본 목록 쿼리는 현재 `smartBatch`, `template`, `externalRefId`, `createdByChannel`을 기준으로 필터링합니다.
- **두 가지 `200` 응답 형식**: 대시보드나 동기화 작업에 `total` 및 `pages`가 필요하면 `page`를 전달하세요. 더 간단한 `{ data: [...] }` 페이로드가 필요하면 `page`를 생략하세요.

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	params := url.Values{}
	params.Set("createdByChannel", "api")
	params.Set("externalRefId", "applicant-42")
	params.Set("page", "1")
	params.Set("limit", "20")
	params.Set("sort", "-updatedAt")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-reports?"+params.Encode(), nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### 참고 사항

- `GET /v2/smart-reports`는 반환되는 각 `SmartReport`에 `template`, `smartBatch`, `client`를 채워서(populate) 반환합니다.
- 유효하지 않은 쿼리 매개변수 값은 `409 MissingParameter`로 Joi 검증에 실패합니다.
- 바로 사용할 수 있는 `downloadUrl` 및 `htmlUrl` 필드가 포함된 단일 리포트를 조회하려면 [Smart Report 조회](/verifik-ko/smart-reports/retrieve-a-smart-report)를 사용하세요.
- `SmartBatch`와 `SmartReport` 레코드를 별도로 관리하지 않고 종단 간으로 새 리포트를 실행하려면 [Smart Report 실행](/verifik-ko/smart-reports/run-a-smart-report)을 사용하세요.
