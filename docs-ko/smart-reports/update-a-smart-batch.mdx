인증된 클라이언트가 소유한 기존 `SmartBatch`의 필드를 수정합니다. `name`, `status`, `executor`를 수정하거나 `rows`를 교체할 수 있습니다. `rows`를 제공하면 서버는 `totalRows`, `completedRows`, `failedRows`, `partialRows`를 다시 계산하고 외부 행 스냅샷을 동기화합니다.

배치를 `"paused"` 상태로 전환하려면 전용 [Smart Batch 일시 중지](/verifik-ko/smart-reports/pause-a-smart-batch) 엔드포인트를 사용하세요. `executor` 변경은 배치가 현재 `"draft"`, `"pending"` 또는 `"cancelled"` 상태일 때만 적용됩니다.

### 엔드포인트

```text
PUT https://api.verifik.co/v2/smart-batches/{id}
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/{id}`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | 수정할 `SmartBatch` ObjectId. |

### 본문

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `name` | string | 아니요 | 수정된 배치 표시 이름. 최대 `150`자. |
| `status` | string | 아니요 | 허용 값: `"draft"`, `"pending"`, `"processing"`, `"completed"`, `"failed"` 또는 `"cancelled"`. `"paused"` 상태로 변경하려면 `POST /v2/smart-batches/{id}/pause`를 사용하세요. |
| `executor` | string | 아니요 | 허용 값: `"queue"`, `"featureRunner"` 또는 `"browser"`. 현재 배치 상태가 `"draft"`, `"pending"` 또는 `"cancelled"`일 때만 적용됩니다. |
| `rows` | object[] | 아니요 | 교체할 행 목록. 래핑된 형식에는 `rowIndex`와 `inputData`가 필요하며 선택적으로 `status`, `results`, `errors`, `processedAt`을 허용합니다. 평면 행은 자동으로 정규화됩니다. |

알 수 없는 본문 키는 Joi 검증에 의해 `409 MissingParameter`로 거부됩니다.

### 참고

- `PUT /v2/smart-batches/{id}`에서는 `"paused"`가 허용되지 않습니다. 대신 [Smart Batch 일시 중지](/verifik-ko/smart-reports/pause-a-smart-batch)를 호출하세요.
- 배치가 현재 `"draft"`, `"pending"` 또는 `"cancelled"` 상태가 아니면 `executor` 수정은 무시됩니다.
- 기존 행을 교체하지 않고 기존 배치에 새 행을 추가하려면 [Smart Batch에 행 추가](/verifik-ko/smart-reports/append-smart-batch-rows)를 사용하세요.
