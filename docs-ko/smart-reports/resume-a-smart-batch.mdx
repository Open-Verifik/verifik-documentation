일시 중지된 `SmartBatch`(및 기반 `FeatureRunner` 실행)를 재개합니다. 서버는 클라이언트 계정이 구성된 모든 단계에 대한 기능 권한을 여전히 보유하고 있는지 확인하고(엔드포인트 액세스가 취소된 경우 `409 endpoints_not_in_account`), 배치가 `"paused"` 상태인지 검사한 다음 `"processing"` 상태로 다시 전환합니다.

배치가 현재 `"paused"` 상태가 아니면 요청이 `400 BadRequest`로 실패합니다(`batch_not_paused`, 또는 기반 `FeatureRunner` 실행이 일시 중지 상태가 아닌 경우 `run_not_paused`).

### 엔드포인트

```text
POST https://api.verifik.co/v2/smart-batches/{id}/resume
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/{id}/resume`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | 재개할 `SmartBatch` ObjectId. |

### 참고

- 재개 시 클라이언트 기능 권한을 다시 검증하며, 계정에 더 이상 활성화되지 않은 단계 엔드포인트가 있는 경우 `409 endpoints_not_in_account`로 요청을 거부합니다.
- 완료된 행은 저장된 결과를 그대로 유지하며, 재개 시 다시 실행되거나 중복 과금되지 않습니다.
- 배치가 `"draft"`, `"pending"` 또는 `"cancelled"` 상태였던 경우 대신 [Smart Batch 시작](/verifik-ko/smart-reports/start-a-smart-batch)을 사용하세요.
