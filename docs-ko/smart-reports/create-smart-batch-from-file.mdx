CSV, XLSX 또는 JSONL 페이로드를 새 `SmartBatch`로 수집(ingest)합니다. 서버는 원시 텍스트 또는 base64 데이터 URL을 디코딩하고, `MAX_ROWS`(기본값 `20000`)를 적용하며, `BatchConfiguration` 단계 종속성을 기준으로 열 헤더와 camelCase 별칭을 해석하고, 크레딧 비용 추정치를 계산합니다.

수락된 행은 `pending` 상태로 배치에 저장되며, 형식이 잘못된 행은 `rejectedRows`에 반환됩니다. 계정 엔드포인트 권한을 확인하고 즉시 처리를 시작하려면 `autoStart: true`를 전달하세요. 그렇지 않으면 검사가 실행되지 않으며 크레딧이 소비되지 않습니다.

### 엔드포인트

```text
POST https://api.verifik.co/v2/smart-batches/from-file
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/from-file`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 본문

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `batchConfiguration` | string | 예 | 인증된 클라이언트가 소유한 `BatchConfiguration` ObjectId. |
| `name` | string | 예 | 배치 표시 이름. 최대 `150`자. |
| `content` | string | 예 | 원시 CSV/JSONL 텍스트 또는 base64 데이터 URL (`data:<mime>;base64,<payload>`). |
| `format` | string | 아니요 | 입력 형식: `"csv"`, `"xlsx"` 또는 `"jsonl"`. 기본값은 `batchConfiguration.inputFormat` 또는 `"csv"`입니다. |
| `autoStart` | boolean | 아니요 | 수집 직후 생성된 배치를 즉시 시작하려면 `true`로 설정합니다. |

알 수 없는 본문 키는 Joi 검증에 의해 `409 MissingParameter`로 거부됩니다.

### 참고

- 파일 파싱은 `MAX_ROWS`(기본값 `20000`)를 적용하며, `Document Number` 같은 열이 `documentNumber`로 해석되도록 camelCase 헤더 별칭을 자동으로 생성합니다.
- `.xlsx` 통합 문서의 경우 `format: "xlsx"`와 함께 base64 데이터 URL(`data:application/vnd.openxmlformats-officedocument.spreadsheetml.sheet;base64,<payload>`)을 전달하세요.
- `409 Conflict` 오류에는 `batch_file_has_no_sheets`, `batch_file_is_empty`, `batch_file_has_no_rows`, `batch_file_has_no_usable_rows`, `batch_jsonl_parse_failed_on_line_<N>`, `batch_configuration_has_no_steps` 및 `endpoints_not_in_account`가 포함됩니다.
- 유효하지 않은 행 검증(`0`개의 유효한 행), 지원되지 않는 형식 오류 및 `MAX_ROWS` 임계값 오류는 HTTP `500`을 반환합니다.
