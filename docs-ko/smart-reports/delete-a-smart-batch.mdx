인증된 클라이언트가 소유한 `SmartBatch`를 삭제합니다. 배치가 존재하고 클라이언트 계정에 속해 있는 경우 서버는 배치를 삭제하고 `data`에 제거된 `SmartBatch` 문서를 반환합니다.

배치 ID가 존재하지 않거나 다른 클라이언트에 속한 경우 엔드포인트는 `404` (`not_found`)를 반환합니다. 배치를 삭제해도 이전에 사용한 크레딧은 환불되지 않습니다.

### 엔드포인트

```text
DELETE https://api.verifik.co/v2/smart-batches/{id}
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/{id}`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | 삭제할 `SmartBatch` ObjectId. |

```javascript
import axios from "axios";

const run = async () => {
  const batchId = "6801a2b3c4d5e6f7a8b9c0d3";

  const { data } = await axios.delete(`https://api.verifik.co/v2/smart-batches/${batchId}`, {
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${process.env.VERIFIK_JWT}`,
    },
  });

  console.log(data);
};

run();
```

```go
package main

import (
	"encoding/json"
	"fmt"

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"

	req, _ := http.NewRequest("DELETE", "https://api.verifik.co/v2/smart-batches/"+batchID, nil)

	json.NewDecoder(resp.Body).Decode(&out)

}
```

- 기록된 행과 출력을 유지하면서 활성 배치를 중지하려면 삭제 대신 [Smart Batch 취소](/verifik-ko/smart-reports/cancel-a-smart-batch)를 사용하세요.
