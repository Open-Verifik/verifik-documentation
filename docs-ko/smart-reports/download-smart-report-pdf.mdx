`SmartReport`의 렌더링된 PDF 파일을 바이너리 스트림(`Content-Type: application/pdf`)으로 다운로드합니다. 백엔드, 포털 또는 연동 시스템에서 [Smart Report PDF 생성](/verifik-ko/smart-reports/generate-smart-report-pdf)이 반환하는 base64 JSON 엔벨로프 대신 원시 PDF 바이트가 필요할 때 이 엔드포인트를 사용하세요.

선택적 `rowIndex` 쿼리 매개변수는 연결된 `SmartBatch`에서 렌더링하거나 다운로드할 행을 선택합니다. `rowIndex`를 생략하면 `SmartReport`의 `dataSnapshot.rowIndex`로 폴백한 뒤 `0`으로 폴백합니다.

### 엔드포인트

```
GET https://api.verifik.co/v2/smart-reports/{id}/download
```

이 엔드포인트는 본인의 클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-reports/{id}/download`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름            | 값                     | 설명                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Accept`        | `application/pdf`      | 바이너리 PDF 응답 스트림.                |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름       | 위치  | 타입   | 필수   | 설명 |
| ---------- | ----- | ------ | ------ | ---- |
| `id`       | path  | string | **예** | `SmartReport` ObjectId. |
| `rowIndex` | query | number | 아니요 | 다운로드할 0부터 시작하는 행 인덱스. `dataSnapshot.rowIndex`로 폴백한 뒤 `0`으로 폴백합니다. |

### 요청

이 엔드포인트는 JSON 대신 원시 바이너리 PDF 바이트를 스트리밍하므로, HTTP 클라이언트가 JSON을 파싱하지 않고 바이너리 버퍼를 읽도록 구성하세요.

import fs from "fs";
import axios from "axios";

const run = async () => {
  const id = "6801a2b3c4d5e6f7a8b9c0d1";
  const response = await axios.get(`https://api.verifik.co/v2/smart-reports/${id}/download`, {

    responseType: "arraybuffer",
    headers: {
      Accept: "application/pdf",
      Authorization: `Bearer ${process.env.VERIFIK_JWT}`,
    },
  });

  fs.writeFileSync("report.pdf", Buffer.from(response.data));
  console.log(`Saved report.pdf (${response.data.byteLength} bytes)`);
};

run();

import os

  <TabItem value="go" label="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"os"
)

func main() {
	id := "6801a2b3c4d5e6f7a8b9c0d1"
	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-reports/"+id+"/download?rowIndex=0", nil)
	req.Header.Set("Accept", "application/pdf")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	pdfBytes, err := io.ReadAll(resp.Body)
	if err != nil {
		panic(err)
	}

	if resp.StatusCode != http.StatusOK {
		fmt.Printf("Download failed (%d): %s\n", resp.StatusCode, string(pdfBytes))
		return
	}

	if err := os.WriteFile("report.pdf", pdfBytes, 0644); err != nil {
		panic(err)
	}
	fmt.Printf("Saved report.pdf (%d bytes)\n", len(pdfBytes))
}
```

#### 응답 헤더 (`200 OK`)

| 헤더                  | 값 / 형식                                            | 설명 |
| --------------------- | ---------------------------------------------------- | ---- |
| `Content-Type`        | `application/pdf`                                    | 바이너리 PDF MIME 타입. |
| `Content-Disposition` | `attachment; filename="Consulta_<rowIndex+1>.pdf"`   | 1부터 시작하는 행 번호를 사용하는 첨부 파일 이름(예: `rowIndex: 0`인 경우 `Consulta_1.pdf`). |
| `Content-Length`      | 정수 바이트 길이                                     | 스트리밍되는 PDF의 정확한 바이트 크기. |

#### 오류 코드

| 상태 | 오류 코드 / 유형 | 원인 |
| ---- | ---------------- | ---- |
| `401` | `Unauthorized` | JWT가 누락되었거나 유효하지 않음. |
| `403` | `Forbidden` | 공유 x402 실행이 시도됨. 본인의 클라이언트별 JWT를 사용하세요. |
| `404` | `not_found` | 리포트 ID가 존재하지 않거나 다른 클라이언트에 속함. |
| `404` | `template_not_found` | 연결된 템플릿을 찾을 수 없음. |
| `409` | `MissingParameter` | 쿼리 또는 경로 매개변수에서 Joi 검증 실패. |
| `409` | `row_not_found` | 해석된 `rowIndex`가 배치에 존재하지 않음. |
| `422` | `UnprocessableEntity` | Mongoose 유효성 검사 오류. |
