인증된 클라이언트 계정이 소유한 배치 구성(`BatchConfiguration`) 목록을 조회합니다. 결과는 JWT의 클라이언트 범위로 제한되며 최신순(`createdAt` 내림차순)으로 정렬되고, 채워진 `steps.appFeature` 메타데이터 및 클라이언트별 `ClientFeature` 가격 정보와 함께 반환됩니다.

`total`, `limit`, `page`, `pages` 메타데이터가 포함된 페이지네이션 결과가 필요하면 `page`를 전달하세요. `data`에서 일치하는 배열을 직접 받으려면 `page`를 생략하세요. 구성을 나열해도 조회가 실행되지 않으며 크레딧이 소비되지 않습니다.

### 엔드포인트

```
GET https://api.verifik.co/v2/batch-configurations
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>` 헤더를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/batch-configurations`)에서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 |
| ---- | -- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

토큰은 **클라이언트 JWT**여야 합니다. 자격 증명이 누락되었거나 유효하지 않으면 `401 Unauthorized`가 반환됩니다.

### 매개변수

모든 쿼리 매개변수는 선택 사항입니다.

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `search` | string | 아니요 | 저장된 구성에 적용되는 대소문자 구분 없는 이름 필터. |
| `text` | string | 아니요 | `search`의 별칭. |
| `page` | integer | 아니요 | 페이지 번호(`1`부터 시작). 제공하면 응답에서 페이지네이션 메타데이터(`total`, `limit`, `page`, `pages`)가 활성화됩니다. |
| `limit` | integer | 아니요 | 페이지당 반환할 최대 구성 수. |
| `perPage` | integer | 아니요 | `limit`의 별칭. |

package main

import (
    "encoding/json"
    "fmt"
    "net/http"
    "net/url"
    "os"
)

func main() {
    u, _ := url.Parse("https://api.verifik.co/v2/batch-configurations")
    q := u.Query()
    q.Set("search", "Colombia")
    q.Set("page", "1")
    q.Set("limit", "20")
    u.RawQuery = q.Encode()

    req, _ := http.NewRequest("GET", u.String(), nil)
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

    resp, _ := http.DefaultClient.Do(req)
    defer resp.Body.Close()

    var out map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&out)
    fmt.Println(out)
}

### 참고

- 결과는 인증된 클라이언트 JWT 범위로 자동 제한되며 최신순(`-createdAt`)으로 정렬됩니다.
- 각 단계의 `steps.appFeature`는 구성된 경우 계정의 `ClientFeature` 가격으로 채워지고 보강됩니다.
- `perPage`는 `limit`의 별칭이고 `text`는 `search`의 별칭입니다.
- 페이지네이션 메타데이터(`total`, `limit`, `page`, `pages`)는 쿼리 문자열에 `page`가 제공된 경우에만 포함됩니다.
