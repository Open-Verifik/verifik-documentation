기존 `BatchConfiguration`에 연결된 `SmartBatch`를 생성합니다. 표시용 `name`과 `rows`에 최소 하나의 입력 행을 제공하세요. 배치를 생성하면 입력 행이 `status: "draft"` 상태로 저장되며, 실행이 시작될 때까지 카탈로그 단계를 실행하거나 크레딧을 소비하지 않습니다.

`rows`의 각 항목은 래핑된 객체(`{ rowIndex?, inputData }`) 또는 평면 객체(`{ rowIndex?, ...inputFields }`) 중 하나를 허용하며, 검증 계층이 이를 `{ rowIndex, inputData }`로 정규화합니다. 생성 시 `status`, `results` 또는 `errors`를 포함하지 **마세요**.

### 엔드포인트

```text
POST https://api.verifik.co/v2/smart-batches
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 본문

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `batchConfiguration` | string | 예 | 워크플로우 단계를 정의하는 `BatchConfiguration` ObjectId. |
| `name` | string | 예 | 배치 표시 이름. 최대 `150`자. |
| `executor` | string | 아니요 | 실행 모드: `"queue"`, `"featureRunner"` 또는 `"browser"`. `batchConfiguration`에서 파생될 때는 `"queue"` 또는 `"browser"`로 정규화됩니다. |
| `source` | string | 아니요 | 원본 제품 식별자: `"smart_batch"`(기본값) 또는 `"smart_fleet"`. |
| `rows` | object[] | 예 | 최소 `1`개의 행 배열(`min 1`). 래핑된 `{ rowIndex?, inputData }` 또는 평면 `{ rowIndex?, ...inputFields }` 형식을 허용합니다. 생성 시 `status`, `results` 또는 `errors`를 전송하지 **마세요**. |

알 수 없는 키와 허용되지 않는 행 속성(`status`, `results`, `errors`)은 Joi 검증에 의해 `409 MissingParameter`로 거부됩니다.

### 참고

- 배치를 생성할 때 `rows` 내부에 `status`, `results` 또는 `errors`를 절대 전달하지 마세요. 새로 생성된 행은 항상 `pending` 상태로 시작합니다.
- `executor`가 생략되면 `batchConfiguration.executor`에서 확인되어 `"queue"` 또는 `"browser"`로 정규화됩니다.
- 생성 후에는 [Smart Batch 비용 추정](/verifik-ko/smart-reports/estimate-smart-batch-cost)을 호출하여 예상 크레딧 요금을 미리 확인하고 [Smart Batch 시작](/verifik-ko/smart-reports/start-a-smart-batch)으로 처리를 시작하세요.
- 종속성 검증 및 선택적 즉시 실행을 지원하는 대량 CSV, XLSX 또는 JSONL 가져오기의 경우 [파일에서 Smart Batch 생성](/verifik-ko/smart-reports/create-smart-batch-from-file)을 사용하세요.
