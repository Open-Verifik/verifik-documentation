Smart Report 템플릿(`reportTheme.scoreProfile`)에 연결하거나 [템플릿 HTML 미리보기](/verifik-ko/smart-reports/preview-template-html) (`scoreProfile`)에 전달할 수 있는 지원 검증 점수 프로필 전체 목록을 조회합니다.

헤드리스 구성 UI 및 AI 에이전트 워크플로에서는 점수 계산을 활성화하기 전에 이 엔드포인트를 조회하여 애플리케이션이 `scoreProfile` 식별자를 동적으로 검증하고, HTML 미리보기 또는 리포트 렌더링 중 발생하는 `409` (`unknown_score_profile`) 오류를 방지하세요. 제공되는 프로필은 드라이버, 신원, 기업, 차량 관리(플릿), 차량 구매, 대출, 의료 및 생체 인증 워크플로를 포괄합니다.

- `cabify_driver`
- `kyc`
- `kyb`
- `fleet`
- `vehicle_purchase`
- `identity_lookup`
- `background_check`
- `lending`
- `healthcare_professional`
- `biometrics`

### 엔드포인트

```
GET https://api.verifik.co/v2/smart-report-templates/score-profiles
```

Smart-Agent 프록시(`https://ai.verifik.co`)도 동일한 `/v2/...` 경로를 제공하며 본인의 `Authorization: Bearer <VERIFIK_JWT>` 헤더가 필요합니다.

### 헤더

| 이름          | 값                     |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 매개변수

필수 쿼리 또는 경로 매개변수가 없습니다.

### 참고 사항

- 템플릿을 생성하거나 수정할 때는 반환된 `id` 값을 `reportTheme.scoreProfile`에 사용하고, [템플릿 HTML 미리보기](/verifik-ko/smart-reports/preview-template-html)에서는 `scoreProfile`로 사용하세요.
- 인식되지 않는 `scoreProfile`을 `POST /v2/smart-report-templates/preview-html`에 전송하면 `409` (`unknown_score_profile`)가 반환됩니다.
