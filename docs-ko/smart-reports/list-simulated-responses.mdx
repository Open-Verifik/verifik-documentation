템플릿 디자인 인벤토리에 사전 구축된 샌드박스 시뮬레이션 응답이 있는 Verifik 카탈로그 엔드포인트 목록을 조회합니다. `country` 또는 검색어(`q`)로 필터링하여 엔드포인트 `code` 식별자와 예상 `inputs`를 확인하세요.

헤드리스 리포트 빌더 및 AI 에이전트 파이프라인에서는 유료 실시간 조회를 실행하거나 운영 개인식별정보(PII)를 다루지 않고도 현실적인 모의 데이터 세트를 선택할 때 이 카탈로그 검색 엔드포인트를 사용하세요. 반환된 `code`를 [시뮬레이션 응답 조회](/verifik-ko/smart-reports/retrieve-simulated-response)에 전달하면 [샘플 데이터 구조 분석](/verifik-ko/smart-reports/introspect-sample-data), [템플릿 레이아웃 생성](/verifik-ko/smart-reports/generate-template-layout) 또는 [템플릿 HTML 미리보기](/verifik-ko/smart-reports/preview-template-html)에 사용할 샘플 페이로드를 얻을 수 있습니다.

### 엔드포인트

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses
```

Smart-Agent 프록시(`https://ai.verifik.co`)도 동일한 `/v2/...` 경로를 제공하며 본인의 `Authorization: Bearer <VERIFIK_JWT>` 헤더가 필요합니다.

### 헤더

| 이름          | 값                     |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 매개변수

| 이름      | 타입   | 필수   | 설명 |
| --------- | ------ | ------ | ---- |
| `country` | string | 아니요 | 국가별로 시뮬레이션 엔드포인트를 필터링합니다. |
| `q`       | string | 아니요 | 이름, 코드 또는 메타데이터로 엔드포인트를 필터링할 검색 문자열. |

package main

import (

}

### 참고 사항

- 시뮬레이션 응답 조회는 실시간 카탈로그 조회를 실행하지 않으며 크레딧을 소모하지 않습니다.
- 각 항목의 `code`를 [시뮬레이션 응답 조회](/verifik-ko/smart-reports/retrieve-simulated-response)와 함께 사용하여 전체 `dataSample` 및 `emptySample` 페이로드를 가져오세요.
