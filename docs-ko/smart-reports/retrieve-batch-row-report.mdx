`SmartBatch`의 단일 행(`rowIndex`)에 대한 구조화된 행 보고서 모델을 구성합니다. 이 엔드포인트는 해당 행의 저장된 단계 출력에 대해 Verifik의 기본 제공 보고서 컴포저(`colombia_vehicle`)를 실행하며, `score` 또는 `scoreProfile`이 전달되면 선택적으로 `verificationScore`를 첨부합니다.

배치의 `BatchConfiguration`이 기본 제공 컴포저와 일치하지 않으면 이 엔드포인트는 `409 Conflict` (`no_report_composer_for_configuration`)를 반환합니다. 임의의 사용자 지정 보고서 템플릿의 경우 대신 `POST /v2/smart-reports/run`, `GET /v2/smart-reports/{id}/html` 또는 `/generate`를 사용하세요. 이 엔드포인트를 읽어도 크레딧이 소비되지 않습니다.

### 엔드포인트

```text
GET https://api.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 경로 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | `SmartBatch` ObjectId. |
| `rowIndex` | number | 예 | 배치 내부 행의 `0` 기반 인덱스. |

### 쿼리 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `score` | boolean or string | 아니요 | 응답에 `verificationScore`를 계산하여 포함하려면 `true` 또는 `"1"`을 전달합니다. |
| `scoreProfile` | string | 아니요 | 채점 프로필 식별자. `scoreProfile`을 제공하면 `score`도 함께 활성화됩니다. |

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	rowIndex := "0"
	params := url.Values{}
	params.Set("score", "true")
	params.Set("scoreProfile", "fleet_standard")

	endpoint := fmt.Sprintf("https://api.verifik.co/v2/smart-batches/%s/rows/%s/report?%s", batchID, rowIndex, params.Encode())
	req, _ := http.NewRequest("GET", endpoint, nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}
```

### 참고

- 이 엔드포인트는 기본 제공 구성 행 보고서(`colombia_vehicle`)만 제공합니다. 그 외의 다른 구성은 `409 Conflict` (`no_report_composer_for_configuration`)를 반환합니다.
- 모든 구성에서 사용자 지정 템플릿, 테마가 적용된 HTML 렌더링 또는 PDF 문서를 생성하려면 `POST /v2/smart-reports/run`, `GET /v2/smart-reports/{id}/html` 또는 `/generate`를 사용하세요([Smart Report 실행](/verifik-ko/smart-reports/run-a-smart-report) 참조).
- `score=true`, `score=1` 또는 `scoreProfile`이 제공되지 않으면 `verificationScore`는 생략됩니다.
