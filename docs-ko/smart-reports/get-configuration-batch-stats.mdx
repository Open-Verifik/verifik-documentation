인증된 클라이언트 계정에서 특정 `BatchConfiguration`에 속한 모든 `SmartBatch` 레코드의 집계 실행 통계를 조회합니다. 응답은 배치 수, 행 완료 합계 및 `"draft"`, `"pending"`, `"processing"`, `"completed"`, `"failed"`, `"cancelled"` 전반에 걸친 상태별 분류를 반환합니다.

구성 통계를 읽어도 검사가 실행되지 않으며 크레딧이 소비되지 않습니다.

### 엔드포인트

```text
GET https://api.verifik.co/v2/smart-batches/stats/{configId}
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/stats/{configId}`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `configId` | string | 예 | 배치 통계를 집계할 `BatchConfiguration` ObjectId. |

### 참고

- 통계는 인증된 클라이언트(JWT의 `clientId`) 범위로 제한됩니다.
- `pendingRows`는 `totalRows - completedRows - failedRows - partialRows`로 계산됩니다.
- 이 구성에 속한 개별 배치를 검사하려면 [Smart Batch 목록](/verifik-ko/smart-reports/list-smart-batches)에 `batchConfiguration`을 전달하세요.
