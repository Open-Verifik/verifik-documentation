인증된 클라이언트에 속한 `SmartReport` 레코드를 삭제합니다. 성공 시 API는 `{ "data": ... }` 안에 삭제된 `SmartReport` 문서를 반환합니다.

리포트 ID가 없거나 다른 클라이언트에 속한 경우, 이 엔드포인트는 `404 Not Found`(`{ "message": "not_found", "code": "NotFound" }`)를 반환합니다. 리포트를 삭제하면 `SmartReport` 문서만 제거되며 기반이 되는 `SmartBatch` 검증 데이터는 삭제되지 않습니다.

### 엔드포인트

```
DELETE https://api.verifik.co/v2/smart-reports/{id}
```

이 엔드포인트는 본인의 클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-reports/{id}`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름            | 값                     | 설명                                     |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type`  | `application/json`     | 요청 페이로드 형식.                      |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입   | 필수   | 설명 |
| ---- | ------ | ------ | ---- |
| `id` | string | **예** | 삭제할 `SmartReport` ObjectId. |

### 참고 사항

- 삭제 후 `GET /v2/smart-reports/{id}` 호출은 `{ "data": null }`을 반환하며, `PUT`, `DELETE`, `/generate`, `/download`, `/html`, `/send-email` 호출은 `404` (`not_found`)를 반환합니다.
- `SmartReport` 삭제는 리포트 전송 또는 생성 웹훅을 발송하지 않습니다. 수명 주기 자동화 세부 정보는 [SmartReports 웹훅](/verifik-ko/resources/smart-reports-webhooks) 및 [MCP 및 AI 에이전트](/verifik-ko/smart-reports/mcp-and-ai-agents)를 참조하세요.
