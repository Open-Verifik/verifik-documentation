Verifik의 기본 제공 테마 적용 스타터 템플릿을 조회하며, 선택적으로 `theme`별 필터링을 지원합니다. 각 스타터에는 사전 구성된 `sections`, `reportTheme`, `sampleData`, 페이지 레이아웃 속성 및 색상이 포함되어 있어 섹션 트리를 처음부터 조립하지 않고도 프로덕션 수준의 리포트 디자인을 빠르게 시작할 수 있습니다.

헤드리스 온보딩 흐름 및 AI 에이전트에서는 이 엔드포인트를 호출해 엄선된 시각적 시작점을 선택하고, [템플릿 HTML 미리보기](/verifik-ko/smart-reports/preview-template-html)로 즉시 미리보기를 확인한 뒤, 브랜드 색상이나 로고를 사용자 지정하여 [리포트 템플릿 생성](/verifik-ko/smart-reports/create-a-report-template)을 통해 편집 가능한 자체 템플릿으로 저장할 수 있습니다.

### 엔드포인트

```
GET https://api.verifik.co/v2/smart-report-templates/theme-starters
```

Smart-Agent 프록시(`https://ai.verifik.co`)도 동일한 `/v2/...` 경로를 제공하며 본인의 `Authorization: Bearer <VERIFIK_JWT>` 헤더가 필요합니다.

### 헤더

| 이름          | 값                     |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 매개변수

| 이름    | 타입   | 필수   | 설명 |
| ------- | ------ | ------ | ---- |
| `theme` | string | 아니요 | 선택적 테마 필터: `"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"` 또는 `"smart_enroll_v2"`(`"light_cards"`의 별칭이며, 표준 값인 `"light_cards"` 사용이 권장됩니다). |

### 참고 사항

- `"smart_enroll_v2"`는 `"light_cards"`의 별칭으로 허용되지만, 표준 테마 ID인 `"light_cards"`로 필터링하는 것이 권장됩니다.
- 여기서 반환되는 스타터 항목에는 참조용으로 `type: "System"`이 포함됩니다. [리포트 템플릿 생성](/verifik-ko/smart-reports/create-a-report-template)을 통해 사용자 지정 사본을 저장할 때는 본인의 `name`과 디자인 필드(`sections`, `reportTheme`, `sampleData`, 색상 및 PDF 설정)만 전송하세요.
