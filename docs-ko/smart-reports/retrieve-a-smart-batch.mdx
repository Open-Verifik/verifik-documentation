인증된 클라이언트에 대해 ID로 단일 `SmartBatch` 문서를 조회합니다. 페이로드를 반환하기 전에 서버는 외부에 저장된 `smartbatchrows` 출력을 `rows[].results`에 병합하고, `healIncompleteRows()`를 실행하여 활성화된 구성 단계가 누락된 채 `completed`로 표시된 행을 다시 엽니다.

배치가 존재하지 않거나 다른 클라이언트 계정에 속한 경우 엔드포인트는 `{ "data": null }`과 함께 `200`을 반환합니다. 배치를 읽어도 검사가 실행되거나 크레딧이 소비되지 않습니다.

### 엔드포인트

```text
GET https://api.verifik.co/v2/smart-batches/{id}
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/{id}`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 경로 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | `SmartBatch` ObjectId. |

### 쿼리 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `select` | string | 아니요 | 필드 프로젝션 표현식(예: 행 페이로드를 제외하려면 `"-rows"`). |
| `columns` | string | 아니요 | 반환된 문서에 포함할 필드의 하위 집합. |
| `populates[]` | string[] | 아니요 | 채울 관련 문서: `"batchConfiguration"` 및/또는 `"client"`. |

### 참고

- 배치를 읽을 때 외부 `smartbatchrows` 단계 결과가 자동으로 `rows[].results`에 병합됩니다.
- `healIncompleteRows()`는 활성화된 `batchConfiguration` 단계를 기준으로 각 `completed` 행을 검사하여, 단계 출력이나 오류가 누락된 행을 다시 `pending` 상태로 되돌립니다.
- 빈번한 상태 폴링을 위해서는 전체 행 페이로드를 반복해서 가져오지 않도록 [Smart Batch 진행률 조회](/verifik-ko/smart-reports/get-smart-batch-progress)를 사용하는 것이 좋습니다.
