Gemini(temperature `0.2`)를 사용하여 자연어 `prompt`로부터 구조화된 `ReportSection` 정의를 생성, 추가 또는 편집합니다. 모델이 섹션의 `dataPath` 바인딩과 열 레이아웃을 실제 페이로드 구조에 맞출 수 있도록 `previewData`에 샘플 검증 데이터를 전달하세요.

헤드리스 리포트 빌더 및 AI 에이전트 파이프라인에서는 섹션 JSON을 수동으로 작성하지 않고도 전체 레이아웃을 스캐폴딩하거나(`"create"`), 기존 템플릿에 후속 섹션을 추가하거나(`"append"`), 단일 섹션을 다듬을 때(`"edit"`) 이 엔드포인트를 사용하세요. [리포트 템플릿 생성](/verifik-ko/smart-reports/create-a-report-template) 또는 [리포트 템플릿 수정](/verifik-ko/smart-reports/update-a-report-template)으로 저장하기 전에 [템플릿 HTML 미리보기](/verifik-ko/smart-reports/preview-template-html)와 함께 호출하여 렌더링된 출력을 확인할 수 있습니다.

### 엔드포인트

```
POST https://api.verifik.co/v2/smart-report-templates/generate-layout
```

Smart-Agent 프록시(`https://ai.verifik.co`)도 동일한 `/v2/...` 경로를 제공하며 본인의 `Authorization: Bearer <VERIFIK_JWT>` 헤더가 필요합니다.

### 헤더

| 이름          | 값                     |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 요청 본문

| 이름              | 타입          | 필수   | 설명 |
| ----------------- | ------------- | ------ | ---- |
| `prompt`          | string        | 예     | 생성할 레이아웃, 추가할 섹션 또는 edit 모드에서 적용할 변경 사항을 설명하는 자연어 지침. |
| `mode`            | string        | 예     | 생성 모드: `"create"`, `"edit"` 또는 `"append"`. |
| `previewData`     | object        | 아니요 | 생성된 `dataPath` 표현식과 열을 실제 데이터에 맞추기 위한 샘플 검증 JSON(예: `inputData`, `results`, `batchName`). |
| `currentSections` | object[]      | 아니요 | 기존 `ReportSection` 배열. 새로 생성된 섹션이 기존 `order` 시퀀스를 이어갈 수 있도록 `"append"` 모드에서 권장됩니다. |
| `selectedSection` | object / null | 아니요 | `mode`가 `"edit"`일 때 수정할 대상 `ReportSection` 객체. `"edit"` 모드에서 `null`이거나 생략되면 `"create"` 모드로 폴백합니다. |

package main

import (

	"fmt"

func main() {
	body, _ := json.Marshal(map[string]interface{}{
		"prompt": "Create a clean 2-column driver summary section followed by a table of traffic citations.",
		"mode":   "create",
		"previewData": map[string]interface{}{
			"batchName": "Driver Onboarding",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",

			"results": map[string]interface{}{
				"identity": map[string]interface{}{"fullName": "Mateo Rojas", "status": "active"},
				"fines": []map[string]interface{}{
					{"code": "C02", "amount": 580000, "status": "pending"},
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/generate-layout", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### 참고 사항

- `"create"` 및 `"append"` 모드는 `{ "data": [ ...ReportSection ] }`(배열)을 반환하는 반면, `null`이 아닌 `selectedSection`이 있는 `"edit"` 모드는 `{ "data": { ...ReportSection } }`(단일 객체)를 반환합니다.
- `selectedSection: null`로 `"edit"`를 호출하거나 `selectedSection`을 생략하면 `"create"` 모드로 폴백하여 배열을 반환합니다.
- 이 엔드포인트는 데이터베이스에 쓰지 않습니다. 반환된 `sections`를 [템플릿 HTML 미리보기](/verifik-ko/smart-reports/preview-template-html)에 전달하여 HTML을 확인하거나 [리포트 템플릿 생성](/verifik-ko/smart-reports/create-a-report-template)에 전달하여 저장하세요.
