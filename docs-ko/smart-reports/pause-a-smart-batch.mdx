완료된 행에 이미 기록된 결과를 잃지 않고 활성 `SmartBatch`(및 연결된 모든 `FeatureRunner` 실행)를 일시 중지합니다. 배치를 재개할 때까지 워커는 남은 행을 가져오지 않습니다.

큐 및 브라우저 배치는 `"processing"` 또는 `"pending"` 상태여야 합니다(그렇지 않으면 `400 batch_not_pausable`). `FeatureRunner` 실행이 뒷받침되는 배치는 해당 실행이 `"queued"` 또는 `"processing"` 상태여야 합니다(그렇지 않으면 `400 run_not_pausable`). 일시 중지해도 크레딧이 소비되지 않습니다.

### 엔드포인트

```text
POST https://api.verifik.co/v2/smart-batches/{id}/pause
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/{id}/pause`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | 일시 중지할 `SmartBatch` ObjectId. |

### 참고

- 배치를 프로그래밍 방식으로 일시 중지하려면 `"paused"`를 허용하지 않는 `PUT /v2/smart-batches/{id}` 대신 항상 이 엔드포인트를 사용하세요.
- `FeatureRunner` 기반 배치는 실행 상태가 `"queued"` 또는 `"processing"`이 아닌 경우 `run_not_pausable`과 함께 `400 BadRequest`를 반환합니다.
- 나중에 [Smart Batch 재개](/verifik-ko/smart-reports/resume-a-smart-batch)를 사용하여 실행을 계속하거나, [Smart Batch 취소](/verifik-ko/smart-reports/cancel-a-smart-batch)로 영구 종료할 수 있습니다.
