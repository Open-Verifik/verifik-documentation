[시뮬레이션 응답 목록 조회](/verifik-ko/smart-reports/list-simulated-responses)를 통해 찾은 카탈로그 엔드포인트 `code`의 시뮬레이션된 샌드박스 응답, 필드 `outline`, `dataSample` 및 `emptySample`을 조회합니다. 반환되는 `sample` 상태를 채워진 레코드(`"data"`), 빈 일치 결과(`"empty"`), 또는 누락 데이터(`"missing"`) 간에 전환할 수 있으며 `listSize`로 배열 행 수를 제어할 수 있습니다.

헤드리스 템플릿 설계 및 자동화된 QA 워크플로에서는 템플릿을 저장하거나 프로덕션 `SmartBatch` 파이프라인에 배포하기 전에 빈 테이블, 누락된 선택 필드 또는 다중 페이지 배열(`listSize` `2`~`30`)과 같은 엣지 케이스가 어떻게 렌더링되는지 이 엔드포인트로 검증할 수 있습니다.

### 엔드포인트

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses/{code}
```

Smart-Agent 프록시(`https://ai.verifik.co`)도 동일한 `/v2/...` 경로를 제공하며 본인의 `Authorization: Bearer <VERIFIK_JWT>` 헤더가 필요합니다.

### 헤더

| 이름          | 값                     |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 매개변수

| 이름           | 타입    | 위치  | 필수   | 설명 |
| -------------- | ------- | ----- | ------ | ---- |
| `code`         | string  | Path  | 예     | [시뮬레이션 응답 목록 조회](/verifik-ko/smart-reports/list-simulated-responses)에서 가져온 카탈로그 엔드포인트 코드. |
| `availability` | string  | Query | 아니요 | `sample`에 배치할 시뮬레이션 상태: `"data"`, `"empty"` 또는 `"missing"`. 기본값은 `"data"`입니다. |
| `listSize`     | integer | Query | 아니요 | 배열/목록 필드에 생성할 합성 항목 수. 유효 범위: `2`~`30`. |

async function run() {

        Accept: "application/json",
        Authorization: `Bearer ${process.env.VERIFIK_JWT}`,

### 참고 사항

- `{code}`가 샌드박스 인벤토리에 없는 경우, 이 엔드포인트는 `found: false`, 빈 `outline` 및 `sample` 객체, 그리고 설명 `note`와 함께 HTTP `200`을 반환합니다.
- `listSize`는 `2`부터 `30`까지의 정수를 허용하며 [템플릿 샘플 다운로드](/verifik-ko/smart-reports/download-template-sample)를 통해 다중 페이지 PDF 페이지 나누기를 테스트할 때 유용합니다.
- 이 엔드포인트는 실시간 검증을 실행하지 않으며 크레딧을 소모하지 않습니다.
