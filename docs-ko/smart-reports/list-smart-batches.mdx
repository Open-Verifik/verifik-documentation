인증된 클라이언트 계정에 속한 `SmartBatch` 레코드 목록을 조회합니다. 결과는 기본적으로 최신순(`-createdAt`)으로 정렬되며, 목록 응답을 간결하게 유지하기 위해 `includeRows=true`를 명시적으로 전달하지 않는 한 `rows` 배열을 제외합니다.

`total`, `limit`, `page`, `pages` 메타데이터가 포함된 페이지네이션 출력을 활성화하려면 `page`를 전송하세요. 페이지네이션 필드 없이 일치하는 배치 배열을 포함한 `{ data }`를 받으려면 `page`를 생략하세요. 배치를 나열해도 검사가 실행되지 않으며 크레딧이 소비되지 않습니다.

### 엔드포인트

```text
GET https://api.verifik.co/v2/smart-batches
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `batchConfiguration` | string | 아니요 | `BatchConfiguration` ObjectId로 배치를 필터링합니다. |
| `status` | string | 아니요 | 배치 상태로 필터링합니다: `"draft"`, `"pending"`, `"processing"`, `"paused"`, `"completed"`, `"failed"` 또는 `"cancelled"`. |
| `page` | number | 아니요 | 페이지 번호 (`>= 1`). 페이지네이션을 활성화하고 응답에 `total`, `limit`, `page`, `pages`를 추가합니다. |
| `limit` | number | 아니요 | 응답당 최대 항목 수 (`1` ~ `200`). |
| `perPage` | number | 아니요 | `page`가 설정된 경우의 페이지 크기 (`1` ~ `200`). 기본값은 `20`입니다. |
| `includeRows` | boolean | 아니요 | 반환되는 각 배치에 `rows`를 포함하려면 `true`로 설정합니다. 생략하거나 `false`인 경우 `rows`가 제외됩니다. |
| `search` | string | 아니요 | 배치 `name`에 대한 대소문자 구분 없는 정규식 검색. |
| `sort` | string | 아니요 | 정렬 필드 및 방향. 기본값은 `"-createdAt"`입니다. |
| `sortBy` | string | 아니요 | `sortOrder`와 함께 사용할 때의 정렬 필드 이름. |
| `sortOrder` | string | 아니요 | `sortBy`의 정렬 방향: `"asc"` 또는 `"desc"`. |

알 수 없는 쿼리 매개변수는 Joi 검증에 의해 `409 MissingParameter`로 거부됩니다.

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	params := url.Values{}
	params.Set("status", "processing")
	params.Set("page", "1")
	params.Set("perPage", "20")
	params.Set("search", "Colombia")
	params.Set("sort", "-createdAt")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-batches?"+params.Encode(), nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### 참고

- 결과는 인증된 클라이언트(JWT의 `clientId`) 범위로 제한됩니다.
- `includeRows`를 생략하거나 `false`로 두면 목록 응답 크기를 작게 유지할 수 있습니다. 단일 배치의 전체 `rows`를 가져오려면 [Smart Batch 조회](/verifik-ko/smart-reports/retrieve-a-smart-batch)를 사용하세요.
- 유효하지 않은 쿼리 값이나 알 수 없는 쿼리 키는 Joi 검증에 의해 `409 MissingParameter`로 실패합니다.
- `page`가 제공되면(`>= 1`), `perPage`의 기본값은 `20`이며 `1`부터 `200`까지 지원합니다.
