`sampleData` 검증 페이로드를 검사하여 필드 경로, 값 형태, 권장 `sectionType` 선택지, 대체 섹션 타입, 추천 테이블 열 및 바인딩 제안을 담은 구조화된 맵을 수신합니다.

헤드리스 리포트 작성 및 AI 에이전트 파이프라인에서는 [시뮬레이션 응답 조회](/verifik-ko/smart-reports/retrieve-simulated-response)에서 페이로드를 가져오거나 `SmartBatch` 행을 캡처한 직후 이 엔드포인트를 호출하세요. `dataPath` 문자열을 추측하거나 취약한 JSON 순회 로직을 작성하는 대신, UI나 에이전트가 분석된 `nodes` 및 `batch` 메타데이터를 사용해 유효한 `sections`를 직접 구성하거나 [템플릿 레이아웃 생성](/verifik-ko/smart-reports/generate-template-layout)용 `prompt` 컨텍스트를 보강할 수 있습니다. 탐색기(walker)는 최대 깊이 `5` 및 최대 `600`개 노드까지 검사합니다.

### 엔드포인트

```
POST https://api.verifik.co/v2/smart-report-templates/introspect
```

Smart-Agent 프록시(`https://ai.verifik.co`)도 동일한 `/v2/...` 경로를 제공하며 본인의 `Authorization: Bearer <VERIFIK_JWT>` 헤더가 필요합니다.

### 헤더

| 이름          | 값                     |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 요청 본문

| 이름         | 타입   | 필수 | 설명 |
| ------------ | ------ | ---- | ---- |
| `sampleData` | object | 예   | 선택적 `batchName`(string), `rowIndex`(number), `inputData`(object), `results`(object)를 포함하는 샘플 검증 페이로드. |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func main() {
	body, _ := json.Marshal(map[string]interface{}{
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{
					"fullName": "Mateo Rojas",
					"status":   "active",
				},
				"fines": []map[string]interface{}{
					{"code": "C02", "amount": 580000, "status": "pending"},
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/introspect", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### 참고 사항

- 순회는 깊이 `5`에서 중단되며 최대 `600`개 노드로 제한됩니다. 매우 큰 페이로드가 제한에 도달하면 `truncated`가 `true`가 됩니다.
- 이 엔드포인트는 읽기 전용 및 무상태(stateless)로 동작하며, 템플릿을 저장하거나 검증 크레딧을 소모하지 않습니다.
