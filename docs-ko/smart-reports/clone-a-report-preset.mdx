선별된 시스템 Smart Report 프리셋을 클라이언트 계정으로 복제합니다. 이 작업은 즉시 실행하거나 추가로 사용자 지정할 수 있는 `BatchConfiguration`과 연결된 `SmartReportTemplate`을 모두 반환합니다.

이 엔드포인트는 클라이언트 계정에 대해 **멱등성(idempotent)**을 가집니다. `{systemKey}`에서 복제된 활성 클라이언트 템플릿이 이미 존재하면 서버는 해당 구성과 템플릿을 재사용하고(필요한 경우 단계 순서를 다시 매핑) `reused: true`를 반환합니다. 그렇지 않으면 새 `BatchConfiguration`(`inputFormat: "csv"`, `outputFormat: "csv"`, `mergeStrategy: "sequential"`)과 `preferredReportTemplate`로 연결된 새 클라이언트 `SmartReportTemplate`(`clonedFromSystemKey`가 `{systemKey}`로 설정됨)을 생성하고 `reused: false`를 반환합니다. 이 엔드포인트는 `smart_report_clone_preset` MCP 도구로도 노출됩니다.

### 엔드포인트

```
POST https://api.verifik.co/v2/smart-batch-presets/{systemKey}/clone
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>` 헤더를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batch-presets/{systemKey}/clone`)에서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 |
| ---- | -- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

토큰은 **클라이언트 JWT**여야 합니다. 자격 증명이 누락되었거나 유효하지 않으면 `401 Unauthorized`가 반환됩니다.

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `systemKey` | string | 예 | [보고서 프리셋 목록](/verifik-ko/smart-reports/list-report-presets)의 프리셋 키. 앞뒤 공백이 제거되며 최대 `120`자이고 `/^[a-z0-9][a-z0-9._-]{1,118}$/i` 패턴과 일치해야 합니다. |

### 본문

이 엔드포인트에는 요청 본문이 필요하지 않습니다.

### 참고

- 프리셋을 복제해도 조회가 실행되지 않으며 크레딧이 소비되지 않습니다.
- 동일한 `{systemKey}`로 이 엔드포인트를 반복 호출하는 것은 클라이언트 계정에 대해 안전하고 멱등적입니다. 기존에 복제된 구성과 템플릿이 `reused: true`와 함께 반환됩니다.
- `{systemKey}`가 Joi 경로 검증을 통과하지 못하면(예: `120`자를 초과하거나 지원되지 않는 문자를 포함한 경우) `409 MissingParameter`가 반환됩니다. 일치하는 프리셋에 구성된 단계가 없으면 `preset_has_no_steps`와 함께 `409`가 반환됩니다.
- 계정에서 필요한 프리셋 기능을 사용할 수 없는 경우 `500 InternalServerError`가 발생할 수 있습니다.
- 복제한 후에는 행을 제출하기 전에 `batchConfiguration._id`를 사용하여 [구성 입력 스키마 조회](/verifik-ko/smart-reports/retrieve-configuration-input-schema)를 호출하거나 `smart_report_clone_preset` MCP 도구를 사용하세요.
