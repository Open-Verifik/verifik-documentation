ObjectId(`{id}`)로 단일 Smart Report 템플릿을 조회합니다. `sections`, `reportTheme`, `sampleData`, 페이지 레이아웃 설정 및 채워진(populate) `batchConfiguration`·`client` 참조를 포함한 전체 템플릿 사양을 반환합니다.

헤드리스 및 AI 워크플로에서는 `append` 또는 `edit` 모드로 [템플릿 레이아웃 생성](/verifik-ko/smart-reports/generate-template-layout)을 호출하기 전에 현재 `sections` 배열을 불러오거나, [템플릿 HTML 미리보기](/verifik-ko/smart-reports/preview-template-html)용으로 저장된 `sampleData`를 가져오거나, `PUT` 업데이트를 실행하기 전에 템플릿을 검사할 때 이 엔드포인트를 사용하세요. 보안 및 페이로드 크기 효율성을 위해 이 엔드포인트에서는 `security.password`와 `thumbnail.image`가 제외됩니다.

### 엔드포인트

```
GET https://api.verifik.co/v2/smart-report-templates/{id}
```

Smart-Agent 프록시(`https://ai.verifik.co`)도 동일한 `/v2/...` 경로를 제공하며 본인의 `Authorization: Bearer <VERIFIK_JWT>` 헤더가 필요합니다.

### 헤더

| 이름          | 값                     |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### 매개변수

| 이름 | 타입   | 필수 | 설명 |
| ---- | ------ | ---- | ---- |
| `id` | string | 예   | Smart Report 템플릿 ObjectId. |

### 참고 사항

- 템플릿이 존재하지 않거나 다른 클라이언트에 속한 경우, 이 엔드포인트는 `404` 대신 `{ "data": null }`과 함께 HTTP `200`을 반환합니다.
- `security.password` 및 `thumbnail.image`는 반환된 문서에서 제외됩니다. 템플릿 썸네일을 렌더링하거나 확인하려면 [리포트 템플릿 목록 조회](/verifik-ko/smart-reports/list-report-templates)를 사용하세요.
