전체 `rows` 배열을 전송하지 않고 `SmartBatch`의 경량 진행률 요약을 가져옵니다. 응답에는 행 카운터(`totalRows`, `completedRows`, `failedRows`, `partialRows`, `pendingRows`), 실행 타임스탬프, `creditsSpent`, 그리고 `FeatureRunner` 실행이 뒷받침되는 경우 중첩된 `run` 및 원장 `spend` 세부 정보가 포함됩니다.

서버 측 `FeatureRunner` 실행은 `batchConfiguration.notification.webhookUrl`이 구성된 경우 완료 시 `smart_batch_batch_completed` 웹훅 이벤트(`runId` 및 `creditsSpent` 포함)도 발생시킵니다. 이 엔드포인트를 폴링해도 크레딧이 소비되지 않습니다.

### 엔드포인트

```text
GET https://api.verifik.co/v2/smart-batches/{id}/progress
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/{id}/progress`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | 진행률을 폴링할 `SmartBatch` ObjectId. |

### 참고

- `run`과 `spend`는 배치에 연결된 `FeatureRunner` 실행이 있을 때 포함됩니다(참조된 실행 레코드가 반환되지 않으면 `run`은 `null`입니다).
- 서버 측 `FeatureRunner` 실행은 `batchConfiguration.notification.webhookUrl`이 설정된 경우 완료 시 `smart_batch_batch_completed` 웹훅 이벤트(`runId` 및 `creditsSpent` 포함)를 발생시킵니다. [Smart Reports 웹훅](/verifik-ko/resources/smart-reports-webhooks)을 참조하세요.
- 배치가 종료 상태에 도달하면 [Smart Batch 조회](/verifik-ko/smart-reports/retrieve-a-smart-batch)를 사용하여 행 수준의 `results`와 `errors`를 확인하세요.
