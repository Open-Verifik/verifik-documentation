`SmartBatch`(및 연결된 모든 `FeatureRunner` 실행)를 취소합니다. 배치는 `status: "cancelled"`로 전환되고 `completedAt`이 설정됩니다.

이미 종료 상태(`"completed"`, `"failed"` 또는 `"cancelled"`)에 있는 배치는 취소할 수 없으며 `400 BadRequest` (`batch_already_terminal`)를 반환합니다.

### 엔드포인트

```text
POST https://api.verifik.co/v2/smart-batches/{id}/cancel
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/{id}/cancel`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | 취소할 `SmartBatch` ObjectId. |

### 참고

- 취소된 배치는 이전에 수집된 모든 행 결과를 보존하며, 나중에 [Smart Batch 시작](/verifik-ko/smart-reports/start-a-smart-batch)을 통해 다시 시작할 수 있습니다.
- 처리를 일시적으로 중단하고 다시 시작하지 않은 채 나중에 계속하려면 [Smart Batch 일시 중지](/verifik-ko/smart-reports/pause-a-smart-batch)를 사용하세요.
