이미 완료된 행에 영향을 주지 않고 `SmartBatch`에서 `"failed"` 또는 `"partial"` 상태인 행을 다시 큐에 넣습니다. 특정 행의 하위 집합만 재시도하려면 선택적으로 `rowIndexes`를 전달하고, 배치 내 모든 `"failed"` 및 `"partial"` 행을 재시도하려면 `rowIndexes`를 생략하세요.

배치가 현재 `"processing"` 상태이면 요청이 `409 Conflict` (`batch_is_processing`)로 실패합니다. `retried: 0`이 반환되면 일치하는 실패 또는 부분 완료 행이 없음을 나타냅니다.

### 엔드포인트

```text
POST https://api.verifik.co/v2/smart-batches/{id}/retry-failed
```

클라이언트별 `Authorization: Bearer <VERIFIK_JWT>`를 사용하여 Smart-Agent 프록시(`https://ai.verifik.co/v2/smart-batches/{id}/retry-failed`)를 통해서도 호출할 수 있습니다. 공유 x402 실행은 `403 Forbidden`으로 차단됩니다.

### 헤더

| 이름 | 값 | 설명 |
| ---- | -- | ---- |
| `Content-Type` | `application/json` | 요청 페이로드 형식. |
| `Authorization` | `Bearer <VERIFIK_JWT>` | 클라이언트 범위 JWT (`authUser.clientId`). |

### 매개변수

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `id` | string | 예 | `SmartBatch` ObjectId. |

### 본문

| 이름 | 타입 | 필수 | 설명 |
| ---- | ---- | ---- | ---- |
| `rowIndexes` | integer[] | 아니요 | 재시도할 `0` 기반의 특정 행 인덱스(`>= 0`, 최대 `10000`개 항목). 모든 `"failed"` 및 `"partial"` 행을 재시도하려면 생략하세요. |

알 수 없는 본문 키는 Joi 검증에 의해 `409 MissingParameter`로 거부됩니다.

### 참고

- 모든 `"failed"` 및 `"partial"` 행을 한 번에 재시도하려면 `{}`를 보내거나 `rowIndexes`를 생략하세요.
- `rowIndexes`가 제공된 경우 해당 인덱스가 포함되어 있더라도 `"completed"` 또는 `"pending"` 상태의 행은 무시됩니다.
- 다른 단계의 결과를 유지하면서 단일 행의 특정 단계 시퀀스만 다시 실행하려면 [Smart Batch 행 단계 재시도](/verifik-ko/smart-reports/retry-batch-row-steps)를 사용하세요.
