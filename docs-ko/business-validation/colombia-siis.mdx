# 콜롬비아 — 통합 회사 정보 (SIIS)

**SIIS** 조회는 Supersociedades가 감독하는 회사 신고를 읽습니다. NIT 또는 회사명을 보냅니다. 신고가 있으면 `found`는 true이고, SIIS에 없으면 false입니다. 그 단순 미검출은 HTTP 200이며 상태는 `NO REGISTRADA EN SIIS SUPERSOCIEDADES`입니다. 도산 경보는 `inLiquidationOrReorganization`을 봅니다.

## 응답에 포함되는 값

- `found`와 `inLiquidationOrReorganization`
- `ciiu`, 부문, 도시
- 신고가 있으면 `financialSummary`
- 단순 미검출이면 빈 `filings`

## 사용 사례

- 신용을 주기 전에 최신 SIIS 신고를 가져옵니다.
- 이미 회생 중인 회사를 표시합니다.
- SIIS에 없음을 404가 아닌 200으로 기록합니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersociedades/siis
```

신고에는 `status`, `ciiu`, 주소, `financialSummary`, `filings`가 있습니다. `found`가 false이면 SIIS에 없습니다. 둘 다 HTTP 200입니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **조건부** | `900123456` | NIT 또는 번호. 별칭 `nit`. 이름이 없으면 필수. |
| `businessName` | string | **조건부** | `INDUSTRIAS EJEMPLO SAS` | 이름. 2–200자. 별칭 `companyName`, `fullName`. 번호가 없으면 필수. |
| `documentType` | string | 아니오 | `NIT` | 선택: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### 참고

- NIT 또는 이름을 보냅니다.
- `found` false는 성공한 단순 미검출입니다.
- 그 본문을 HTTP 404로 매핑하지 않습니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.

## 샌드박스

| 시나리오 | 파라미터 | 결과 |
| :--- | :--- | :--- |
| 원천에 기록 있음 | `documentNumber: "900673447"` | 일치하면 200이고 found는 true. |
| 필수 값 누락 | Omit number and name | 검색 값이 없으면 409. |
| 알 수 없는 값 | `documentNumber: "800000111"` | 단순히 없으면 200이고 found는 false. 404가 아닙니다. |

401 when the bearer token is missing or rejected.
