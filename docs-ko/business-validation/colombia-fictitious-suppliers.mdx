# 콜롬비아 — 허위 또는 지급불능 공급자 (DIAN)

**허위 또는 지급불능 공급자** 조회는 DIAN 제671조를 대조합니다. `documentNumber`(별칭 `nit`) 또는 `businessName`(별칭 `companyName`, `fullName`)을 보냅니다. 등재되면 `isFictitiousSupplier`가 true이고 결의가 포함됩니다. 단순히 없으면 HTTP 200이고 `isFictitiousSupplier`는 false입니다. 이 경로는 단순 미검출에 404를 쓰지 않습니다.

## 응답에 포함되는 값

- `isFictitiousSupplier` — DIAN이 등재할 때만 true
- 일치 시 `resolutionNumber`, `resolutionDate`, `publicationDate`
- 등재가 없으면 빈 `matches`
- `status` — 목록 문구 또는 미등재 문장

## 사용 사례

- DIAN이 허위 또는 지급불능으로 표시한 공급자를 막습니다.
- 단순 미검출을 플래그 false인 200으로 기록합니다.
- NIT 또는 법인명으로 검색합니다.

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/co/dian/proveedores-ficticios
```

일치하면 `isFictitiousSupplier`는 true이고 `matches`에 결의 번호, 날짜, 세무서가 있습니다. 단순히 없으면 `isFictitiousSupplier`는 false입니다. 둘 다 HTTP 200입니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **조건부** | `900123456` | NIT 또는 개인 번호. 4–25자. 별칭 `nit`. 이름을 보내지 않으면 필수입니다. |
| `businessName` | string | **조건부** | `INDUSTRIAS EJEMPLO SAS` | 상호 또는 법인명. 2–200자. 별칭 `companyName`, `fullName`. 번호를 보내지 않으면 필수입니다. |
| `documentType` | string | 아니오 | `NIT` | 선택. 값: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### 참고

- 번호 또는 이름을 보냅니다. 하나 이상은 필수입니다.
- 목록에 없으면 `isFictitiousSupplier`가 false인 HTTP 200입니다.
- 그 200을 404로 다루지 않습니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.

## 샌드박스

| 시나리오 | 파라미터 | 결과 |
| :--- | :--- | :--- |
| 원천에 기록 있음 | `documentNumber: "900123456"` | 원천이 대상을 올리면 isFictitiousSupplier가 true인 200. |
| 필수 값 누락 | Omit every search value | 검색 값이 없으면 409 MissingParameter. |
| 알 수 없는 값 | `documentNumber: "00000000"` | isFictitiousSupplier가 false인 200. 단순히 없음은 HTTP 200이며 404가 아닙니다. |

401 when the bearer token is missing or rejected.
