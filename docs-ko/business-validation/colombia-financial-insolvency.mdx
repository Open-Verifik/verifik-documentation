# 콜롬비아 — 금융 회생과 청산

**금융 회생** 조회는 Superintendencia Financiera의 회생·청산 행을 읽습니다. NIT 또는 이름을 보냅니다. 절차가 있을 때만 `inConcordatoOrLiquidation`이 true입니다. 절차가 없어도 HTTP 200이고 플래그는 false입니다. 이 경로는 그 단순 미검출에 404를 쓰지 않습니다.

## 응답에 포함되는 값

- `inConcordatoOrLiquidation`
- `status`와 `entityType`
- 단순 미검출이면 빈 `matches`

## 사용 사례

- 이미 청산 중인 금융회사의 온보딩을 멈춥니다.
- 깨끗한 금융 조회를 200으로 보관합니다.
- NIT 또는 법인명으로 검색합니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/co/superfinanciera/concordatos
```

일치에는 `status`, `entityType`, true인 `inConcordatoOrLiquidation`이 있습니다. 단순 미검출은 HTTP 200이고 플래그는 false입니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **조건부** | `900123456` | NIT 또는 번호. 별칭 `nit`. 이름이 없으면 필수. |
| `businessName` | string | **조건부** | `EJEMPLO SAS` | 이름. 별칭 `companyName`, `fullName`. 번호가 없으면 필수. |
| `documentType` | string | 아니오 | `NIT` | 선택: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### 참고

- 단순 미검출은 `inConcordatoOrLiquidation`이 false인 HTTP 200입니다.
- 번호 또는 이름을 보냅니다.
- 그 200을 404로 매핑하지 않습니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.
