# 콜롬비아 — 연대 부문 제재

**연대 제재** 조회는 Supersolidaria 제재 게시판을 읽습니다. 번호 또는 이름을 보냅니다. 제재가 있을 때만 `isSanctioned`가 true입니다. 단순 미검출은 HTTP 200이고 `isSanctioned`는 false, `sanctionsCount`는 0, 상태는 `SIN SANCIONES REGISTRADAS`입니다. 이 경로는 그 미검출에 404를 쓰지 않습니다.

## 응답에 포함되는 값

- `isSanctioned`와 `sanctionsCount`
- `status`
- `matches`

## 사용 사례

- 자금을 주기 전에 협동조합을 대조합니다.
- 깨끗한 연대 조회를 200으로 기록합니다.
- NIT 또는 제재된 이름으로 검색합니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersolidaria/sanciones
```

일치에는 `sanctionsCount`와 `matches`가 있습니다. 단순 미검출은 `isSanctioned`가 false인 HTTP 200입니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **조건부** | `900123456` | NIT 또는 번호. 별칭 `nit`. |
| `businessName` | string | **조건부** | `EJEMPLO SAS` | 이름. 별칭 `companyName`, `fullName`. |
| `documentType` | string | 아니오 | `NIT` | 선택: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### 참고

- 단순 미검출은 `isSanctioned`가 false인 HTTP 200입니다.
- 검색 값을 하나 이상 보냅니다.
- 그 200을 404로 매핑하지 않습니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.

## 샌드박스

| 시나리오 | 파라미터 | 결과 |
| :--- | :--- | :--- |
| 원천에 기록 있음 | `documentNumber: "900555111"` | 일치하면 isSanctioned가 true인 200. |
| 필수 값 누락 | Omit number and name | 검색 값이 없으면 409. |
| 알 수 없는 값 | `documentNumber: "800000111"` | isSanctioned가 false인 200. 단순 미검출은 404가 아닙니다. |

401 when the bearer token is missing or rejected.
