id로 Check List 하나를 불러옵니다. 목록은 JWT의 클라이언트에 속해야 합니다. 잘못된 ObjectId, 없는 목록, 다른 클라이언트가 소유한 목록은 `404`를 반환합니다.

이 호출은 조회를 실행하지 않으며 크레딧을 쓰지 않습니다. 문서의 `featureCodes`로 각 카탈로그 API를 직접 호출하세요.

### Endpoint

```
GET https://api.verifik.co/v2/check-lists/{id}
```

저장된 목록을 반환합니다: `name`, `countries`, `domains`, `featureCodes`, `status`. 이 코드를 해당하는 SmartCheck / 카탈로그 URL과 함께 사용하세요. 이 경로에는 체크리스트 실행 동작이 없습니다.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

토큰은 **클라이언트 JWT**여야 합니다. `clientId`가 없는 토큰은 `403`을 반환합니다.

### Parameters

| Name | Type   | Required | Description                          |
| ---- | ------ | -------- | ------------------------------------ |
| `id` | string | Yes      | 생성 또는 목록에서 받은 Check List ObjectId. |

### Notes

- 잘못된 ObjectId와 다른 클라이언트의 목록 모두 `404` (`check_list_not_found`)입니다.
- 응답에는 호스팅된 resume URL이나 배치 URL이 없습니다. Check List는 조합만 저장합니다.
- 필드를 바꾸려면 [체크리스트 수정](/verifik-ko/check-list/update-a-check-list)을 사용하세요. 제거하려면 [체크리스트 삭제](/verifik-ko/check-list/delete-a-check-list)를 사용하세요.
- `featureCodes`의 코드를 실행하는 것은 일반 카탈로그 호출이며, 크레딧은 그 호출에서 차감됩니다.
