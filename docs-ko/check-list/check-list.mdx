# Check List

여러 국가에서 같은 SmartCheck 서비스를 반복해서 고르고 있다면, **그 조합을 Check List로 저장하세요.** 목록에서 조회를 실행하거나 SmartBatch로 보낼 수 있습니다.

Smart-Agent의 **Check List**는 [ai.verifik.co/check-list](https://ai.verifik.co/check-list)입니다. 목록 저장은 무료입니다. 조회를 실행하면 다른 API와 같이 크레딧이 차감됩니다.

## Smart-Agent에서

Verifik 고객 계정으로 로그인하세요. Check List는 SmartEnroll 프로젝트가 아니라 그 계정에 목록을 저장합니다.

### 1. 내 목록

대시보드에 목록 수, 국가 수, 저장한 서비스 수가 보입니다. 카드를 열어 편집하거나 새 목록을 만드세요.

<img src="/img/check-list/dashboard.png" alt="통계와 저장된 목록이 있는 Check List 대시보드" />

목록이 없으면 국가부터 시작하세요.

:::tip
목록을 만들면 이 대시보드로 돌아갑니다. 새 카드를 열어 서비스를 추가하세요.
:::

---

### 2. 체크리스트 만들기

국가를 하나 이상 고른 뒤 이름을 붙입니다 (예: **KYC Colombia**, **Fleet Chile**).

<img src="/img/check-list/create.png" alt="국가와 이름으로 체크리스트 만들기" />

국가는 만들 때 정해집니다. 작업 공간에서 나중에 바꾸지 않습니다.

---

### 3. 서비스 추가

목록을 엽니다. 저장한 서비스가 위에 있습니다. 아래에서 카탈로그를 검색하고 **사람**, **차량**, **기업**으로 필터하세요. 국제 배경 조회는 맨 아래에 있습니다.

<img src="/img/check-list/workspace.png" alt="저장된 서비스와 카탈로그가 있는 Check List 작업 공간" />

**선택**으로 추가하고 **열기**로 실행합니다. 초안/활성은 정리용 라벨이며 동작은 같습니다.

---

### 4. 조회 실행

서비스를 열면 **정보**, **요청**, **결과** 탭이 있습니다. 필수 항목을 채우고 **실행**을 누르세요.

<img src="/img/check-list/run-check.png" alt="조회 실행 서랍" />

결과는 해당 카탈로그 API와 같습니다. 호출 후 크레딧이 갱신됩니다.

---

### 5. SmartBatch로 보내기

같은 서비스를 파일이나 큐로 돌리려면 **Create SmartBatch**를 누르세요. SmartBatch는 **국가 하나**만 사용합니다. 목록에 여러 국가가 있으면 시작할 국가를 고르세요.

<img src="/img/check-list/smartbatch-handoff.png" alt="SmartBatch를 만들기 전에 국가 선택" />

SmartBatch가 그 국가, 목록 이름, 선택한 서비스로 열립니다. [SmartBatch](/verifik-ko/smart-batch) 마법사에서 이어 가세요.

---

## Check List가 아닌 것

| 오해 | 실제 |
| --- | --- |
| 배치 실행기 | Check List는 조합을 **저장**합니다. [SmartBatch](/verifik-ko/smart-batch)가 파일이나 큐를 실행합니다. |
| 호스팅 KYC | SmartEnroll은 별도의 enrollment 제품입니다. |
| 실행할 때마다 새 등록 | 실행은 해당 서비스의 기존 카탈로그 API를 호출합니다. |
