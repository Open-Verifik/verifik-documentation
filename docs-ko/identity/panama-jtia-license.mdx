# 파나마 — 공학·건축 면허 (JTIA)

**JTIA 면허** 조회는 엔지니어, 건축가, 기술자의 적격을 읽습니다. `documentNumber`(또는 `cedula`), `licenseNumber`(또는 `idoneidad`), `fullName` 중 하나를 보냅니다. 정규화할 수 없는 시민증은 409입니다. 이사회에 행이 없으면 404 `NotFound`입니다.

## 응답에 포함되는 값

- 정규화된 시민증
- `licenseNumber`와 `fullName`
- `status`

## 사용 사례

- 건축 허가 전에 엔지니어를 확인합니다.
- 면허 번호가 없으면 시민증으로 검색합니다.
- 계약서만 있으면 이름으로 검색합니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/pa/professional/jtia
```

일치에는 정규화된 시민증, 이름, 면허, 상태가 있습니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **조건부** | `8-224-2444` | 파나마 시민증. `cedula`로도 받습니다. API가 정규화합니다(예: `8-224-2444`). |
| `licenseNumber` | string | **조건부** | `JTIA-100` | 적격 또는 면허. 별칭 `idoneidad`. |
| `fullName` | string | **조건부** | `ANA RUIZ` | 이름 3–160자. 이것만으로 충분합니다. |

### 참고

- 시민증, 면허 또는 이름을 보냅니다.
- 형식이 틀린 시민증은 409입니다.
- JTIA 행이 없으면 404 `NotFound`입니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.

## 샌드박스

| 시나리오 | 파라미터 | 결과 |
| :--- | :--- | :--- |
| 원천에 기록 있음 | `documentNumber: "8-224-2444"` | 정규화된 시민증과 면허가 있는 200. |
| 필수 값 누락 | Omit cédula, license, and name | 409 MissingParameter. |
| 알 수 없는 값 | `documentNumber: "1-1-1"` | 시민증을 정규화할 수 없으면 409, JTIA에 행이 없으면 404. |

401 when the bearer token is missing or rejected.
