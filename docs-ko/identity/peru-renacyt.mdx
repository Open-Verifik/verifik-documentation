# 페루 — SUNEDU 학위와 CONCYTEC RENACYT

**RENACYT** 조회는 SUNEDU 학위와 CONCYTEC 연구자 등록을 읽습니다. `documentNumber`(별칭 `dni`), `codigoRegistro`, `orcid`, `fullName` 중 하나 이상을 보냅니다. 문서 번호를 보내면 `documentType` 기본값은 `DNI`입니다.

## 응답에 포함되는 값

- 학위와 연구자 필드
- 있으면 `codigoRegistro`와 `orcid`
- `fullName`과 `documentNumber`

## 사용 사례

- 지원금 전에 연구자를 확인합니다.
- ORCID를 DNI와 맞춥니다.
- 채용 파일용 RENACYT 코드를 읽습니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/pe/education/renacyt
```

일치에는 학위, RENACYT 코드, ORCID가 있을 수 있습니다. 행이 없으면 404 `NotFound`입니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **조건부** | `12345678` | DNI 또는 다른 번호. 별칭 `dni`. 기본 `documentType`은 `DNI`. `CE`, `PASAPORTE`, `PTP`도 됩니다. |
| `codigoRegistro` | string | **조건부** | `REN-100` | RENACYT 등록 코드. 이것만으로 충분합니다. |
| `orcid` | string | **조건부** | `0000-0002-1825-0097` | ORCID 10–30자. 이것만으로 충분합니다. |
| `fullName` | string | **조건부** | `LUCIA QUISPE` | 연구자 이름. 이것만으로 충분합니다. |

### 참고

- 문서, RENACYT 코드, ORCID 또는 이름을 보냅니다.
- 문서 번호의 기본 유형은 `DNI`입니다.
- 등록 행이 없으면 404 `NotFound`입니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.
