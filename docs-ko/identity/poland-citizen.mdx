# 폴란드 — 개인 신원 및 개인사업자 확인 (KYC)

**폴란드 개인 신원 및 개인사업자 확인**은 이 식별자(NIP)의 공식 출처에서 개인 또는 개인사업자를 확인합니다. 해당 번호를 `documentNumber`로 보내세요. 온보딩에 법적 이름, 등록 상태, 출처가 공개하는 신원 속성이 필요할 때 사용합니다.

`documentNumber`는 필수입니다. `documentType`의 기본값은 `NIP`입니다. 기본값을 쓰려면 생략하고, 명시하려면 `NIP`을 보내세요.

## 등록부가 반환하는 항목

- 개인 또는 개인사업자의 법적 이름
- 등록 상태
- 조회한 식별자
- 출처가 공개하는 공식 신원 속성

## 사용 사례

- 온보딩 중 폴란드의 개인사업자 또는 등록 개인을 확인합니다.
- 파일의 법적 이름을 공식 식별자와 맞춥니다.
- 등록 상태와 공식 출처가 공개하는 신원 속성을 보관합니다.

---

## API 레퍼런스

### 엔드포인트

```http
GET https://api.verifik.co/v2/pl/citizen
```

`documentNumber`로 폴란드의 공식 신원·개인사업자 출처를 조회합니다. `documentType`은 식별자 종류(NIP)를 고릅니다. 성공 응답에는 법적 이름, 등록 상태, 보낸 식별자, 출처가 공개하는 공식 신원 속성이 포함됩니다. 개인 또는 개인사업자 KYC 온보딩에 사용하세요. 아래 예시는 그 필드를 보여 줍니다. 실제 값은 공식 출처에서 옵니다.

### 헤더

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <your_token>` | 고객 JWT 인증 토큰 |

### 매개변수

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **예** | `5252344078` | 개인 또는 개인사업자의 공식 신원·납세 번호(NIP). |
| `documentType` | string | 아니요 | `NIP` | 문서 유형 식별자. 기본값은 `NIP`입니다. |

### 참고

- **식별자 형식.** 이 경로의 식별자는 10자리 NIP입니다. documentType 기본값은 NIP입니다. 공백과 대시 없이 숫자만 보내세요.
- 문서 유형 식별자. 기본값은 `NIP`입니다.
- 예시의 상태 표기는 필드를 보여 주기 위한 값입니다. 실제 등록부는 자체 표기를 반환하며 현지 언어일 수 있습니다.
- 이 경로의 고객 매개변수는 `documentNumber`와, 식별자 종류를 밝혀야 할 때의 `documentType`입니다.
- JSON 예시는 위 필드의 형태입니다. 실제 호출은 보낸 식별자에 대한 등록부 기록을 반환합니다.

## 샌드박스

계정이 샌드박스 모드이면 같은 매개변수로 이 경로를 호출합니다. 표는 각 경우에 문서화된 응답을 설명합니다.

| 시나리오 | 매개변수 | 결과 |
| :--- | :--- | :--- |
| **등록된 식별자** | `documentType: "NIP"`, `documentNumber: "5252344078"` | 출처에 번호가 있으면 200과 함께 법적 이름, 상태, 식별자, 주소 또는 신원 속성을 반환합니다. |
| **documentNumber 없음** | 생략 `documentNumber` | `documentNumber`를 빼면 409 `MissingParameter`. |
| **알 수 없는 번호** | `documentNumber: "000000000"` | 등록부에 해당 번호가 없으면 404 `NotFound`. |

bearer 토큰이 없거나 거부되면 401.
