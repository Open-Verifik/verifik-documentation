# 에콰도르 — 투표 장소

**에콰도르 투표 장소** 조회는 CNE 명부를 읽습니다. `documentType`은 `CCEC`이고 `documentNumber`는 주 코드가 01–24 또는 30이며 검증 숫자가 맞는 10자리 시민증이어야 합니다. 응답에는 이름과 주, 칸톤, 교구, 준타(`pollingTable`)가 있습니다.

## 응답에 포함되는 값

- `province`, `canton`, `parish`
- `pollingTable` — 준타
- `fullName`

## 사용 사례

- 유권자에게 투표소를 보여 줍니다.
- 검증 숫자가 틀린 시민증을 거부합니다.
- 신원 파일과 함께 준타를 보관합니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/ec/votacion
```

필드에는 `fullName`, `province`, `canton`, `parish`, `pollingTable`이 있습니다. 알 수 없는 시민증은 404 `NotFound`입니다. 검증 숫자가 틀리면 409 `InvalidDocumentNumber`입니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `documentType` | string | **예** | `CCEC` | `CCEC`여야 합니다. |
| `documentNumber` | string | **예** | `1700000019` | 검증 숫자를 포함한 10자리 에콰도르 시민증. 주 코드는 01–24 또는 30. 잘못된 번호는 409 `InvalidDocumentNumber`입니다. |

### 참고

- `documentType`은 `CCEC`입니다.
- 시민증은 유효한 주와 검증 숫자가 있는 10자리입니다.
- 알 수 없는 번호는 404 `NotFound`입니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.
