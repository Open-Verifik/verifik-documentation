# 콜롬비아 — 화학공학 면허 (CPIQ)

**CPIQ 면허** 조회는 Consejo Profesional de Ingeniería Química를 읽습니다. `documentNumber` 또는 `licenseNumber`를 보냅니다. 모듈은 이름으로 검색하지 않습니다. `fullName`만 보내면 HTTP 409 `MissingParameter`와 메시지 `Either documentNumber or licenseNumber must be provided`가 옵니다. 일치에는 면허, 결의, 상태, 제재 필드가 있습니다.

## 응답에 포함되는 값

- `licenseNumber`와 `resolutionNumber`
- `status`와 `isActive`
- `sanctionType`과 `hasSanctions`

## 사용 사례

- 시민증 또는 CPIQ 면허로 화학 엔지니어를 확인합니다.
- 위원회에 가기 전에 이름만 있는 검색을 거부합니다.
- 위원회가 공개한 제재 날짜를 읽습니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpiq
```

일치에는 `fullName`, `licenseNumber`, `resolutionNumber`, `status`, `sanctionType`, `isRegistered`, `hasSanctions`가 있습니다. CPIQ에 행이 없으면 404 `NotFound`입니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **조건부** | `79876543` | 신원 번호. `licenseNumber`를 생략하면 필수입니다. `fullName`만 보내면 409입니다. |
| `licenseNumber` | string | **조건부** | `PQ-10293` | CPIQ 전문 면허 번호. `documentNumber`를 생략하면 필수입니다. |

### 참고

- 이 경로에서 `fullName`은 검색 키가 아닙니다. 이름만 보내면 409입니다.
- `documentNumber` 또는 `licenseNumber`를 보냅니다.
- CPIQ에 행이 없으면 HTTP 404입니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.
