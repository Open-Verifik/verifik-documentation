# 파나마 — 변호사 적격

**변호사 적격** 조회는 번호로 파나마 변호사 증서를 읽습니다. `idoneidad` 또는 별칭 `licenseNumber`를 1–10자리로 보냅니다. 선택 `issueDate`는 `DD-MM-YYYY`입니다. 번호가 없으면 409 `MissingParameter`입니다.

## 응답에 포함되는 값

- 적격 번호와 이름
- `status`

## 사용 사례

- 서면 제출 전에 변호사를 확인합니다.
- 발급일이 있으면 맞춥니다.
- 숫자가 아닌 적격 번호를 거부합니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/pa/lawyer/idoneidad
```

일치에는 이름, 적격 번호, 상태가 있습니다. 알 수 없는 번호는 404 `NotFound`입니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `idoneidad` | string | **조건부** | `12345` | 변호사 적격 번호. 1–10자리. 별칭 `licenseNumber`. 둘 중 하나는 필수입니다. |
| `issueDate` | string | 아니오 | `01-02-2010` | 선택 발급일 `DD-MM-YYYY`. |

### 참고

- `idoneidad` 또는 `licenseNumber`를 보냅니다.
- 숫자만 1–10자리.
- 알 수 없는 번호는 404 `NotFound`입니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.

## 샌드박스

| 시나리오 | 파라미터 | 결과 |

401 when the bearer token is missing or rejected.
