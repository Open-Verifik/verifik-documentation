# 콜롬비아 — 경영학 면허 (CPAE)

**CPAE 면허** 조회는 Consejo Profesional de Administración de Empresas를 읽습니다. `documentNumber`는 필수입니다. 선택 `documentType`은 `CC`, `CE`, `TI`, `PEP`, `PPT`를 받습니다. 일치하면 이름, 직업, 등록 및 활성 여부를 반환합니다.

## 응답에 포함되는 값

- `fullName`과 `profession`
- `entity` — CPAE
- `status`, `isRegistered`, `isActive`

## 사용 사례

- 채용 때 경영학 자격증을 확인합니다.
- 자격증이 아직 활성인지 확인합니다.
- KYC 파일에 CPAE 직업 문구를 보관합니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpae
```

응답에는 `fullName`, `profession`, `entity`, `status`, `isRegistered`, `isActive`가 있습니다. 알 수 없는 번호는 404 `NotFound`입니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **예** | `80123456` | 콜롬비아 신원 번호. 5자에서 15자. `documentType`은 `CC`, `CE`, `TI`, `PEP`, `PPT`일 수 있습니다. |

### 참고

- `documentNumber`는 필수입니다.
- 번호에 전문 자격증이 없으면 CPAE는 404를 반환합니다.
- 문서 번호 대신 이름을 보내지 않습니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.

## 샌드박스

| 시나리오 | 파라미터 | 결과 |
| :--- | :--- | :--- |
| 원천에 기록 있음 | `documentNumber: "52987654"` | 직업과 활성 플래그가 있는 200. |
| 필수 값 누락 | Omit `documentNumber` | 409 MissingParameter. |
| 알 수 없는 값 | `documentNumber: "000000000"` | CPAE에 자격증이 없으면 404 NotFound. |

401 when the bearer token is missing or rejected.
