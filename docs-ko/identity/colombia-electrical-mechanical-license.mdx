# 콜롬비아 — 전기·기계 공학 면허

**전기·기계 공학 면허** 조회는 Consejo Profesional Nacional de Ingenierías Eléctrica, Mecánica y Profesiones Afines를 읽습니다. `documentNumber`, `licenseNumber`, `fullName` 중 하나를 보냅니다. 응답에는 면허, 전문 분야, 상태, 제재 여부가 있습니다.

## 응답에 포함되는 값

- `licenseNumber`와 `specialty`
- VIGENTE 같은 `status`
- `isRegistered`와 `hasSanctions`
- 행이 둘 이상이면 `registrations`

## 사용 사례

- 현장 작업 전에 전기 또는 기계 엔지니어를 확인합니다.
- 면허 옆의 징계를 읽습니다.
- 계약서 이름을 위원회 행과 맞춥니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/co/consejo-profesional
```

일치에는 `fullName`, `licenseNumber`, `specialty`, `status`, `isRegistered`, `hasSanctions`가 있습니다. 위원회에 행이 없으면 404 `NotFound`입니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **조건부** | `80123456` | 콜롬비아 신원 번호. 5자에서 15자. `documentType`은 `CC`, `CE`, `TI`, `PEP`, `PPT`일 수 있습니다. |
| `licenseNumber` | string | **조건부** | `AN205-27910` | 전문 면허 번호. 예: AN205-27910. 이것만으로 충분합니다. |
| `fullName` | string | **조건부** | `ANA PEREZ` | 엔지니어 이름 또는 성. 3자에서 160자. 이것만으로 충분합니다. |

### 참고

- `documentNumber`, `licenseNumber`, `fullName` 중 하나 이상을 보냅니다.
- 위원회에 행이 없으면 빈 200이 아니라 HTTP 404입니다.
- `documentType`은 선택입니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.
