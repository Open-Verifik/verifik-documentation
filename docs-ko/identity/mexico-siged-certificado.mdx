# 멕시코 — 학업 증명서 (folio)

folio로 공식 학업 증명서 등록부에서 멕시코 전자 학업 증명서를 검증합니다. 선택적으로 `fullName` 또는 `curp`를 보내 증명서가 해당자에게 속하는지 확인할 수 있습니다. 둘 다 보내면 `curp`가 우선합니다. 불일치는 **409** `name_mismatch`를 반환합니다.

이것은 증명서 기록을 확인합니다. 그 자체로 신원을 증명하지는 않습니다. CURP 민사 기록은 [멕시코 시민(CURP)](/verifik-ko/identity/mexico)을 참고하세요. 전문 면허는 [전문 면허](/verifik-ko/identity/mexico-cedula-profesional)를 참고하세요.

## API reference

### Endpoint

```
https://api.verifik.co/v2/mx/siged/certificado
```

일치하면 `folio`, `fullName`, `status`, `certificateType`, `career`, `institution`, `level`, `studyType`, `average`, `averageText`, `periodStart`, `periodEnd`, `registrationDate`, `laborTraining`, `federalEntity`, `issueDate`를 반환합니다. 빈 필드는 `null`입니다.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `folio` | string | 예 | 전자 증명서에 인쇄된 folio. 4–64자. | `SIGED10000001` |
| `fullName` | string | 아니오 | 예상 전체 이름. 불일치하면 409 `name_mismatch`. `curp`도 보내면 무시됩니다. 3–160자. | `Ana Lopez Ruiz` |
| `curp` | string | 아니오 | 해당자의 CURP. 보내면 `fullName`보다 우선합니다. 17–18자. | `LOPE900501HDFGRN01` |

### Request

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.get("https://api.verifik.co/v2/mx/siged/certificado", {
  params: {
    folio: "SIGED10000001",
    fullName: "Ana Lopez Ruiz",
  },
  headers: { Accept: "application/json", Authorization: `Bearer ${process.env.VERIFIK_TOKEN}` },
});
console.log(data);
```

### Notes

- `folio`는 필수입니다. `fullName`과 `curp`는 선택적 소유자 확인입니다. 둘 다 보내면 `curp`가 사용되고 `fullName`은 무시됩니다.
- 등록부에 없는 folio는 **404**를 반환합니다. 해당 증명서의 소유자가 아닌 이름 또는 CURP는 **409** `name_mismatch`를 반환합니다.
- 결과는 최대 7일간 캐시됩니다.
- 샌드박스 folio `SIGED10000001`은 `ANA LOPEZ RUIZ`의 샘플 증명서를 반환합니다. `fullName=Ana Lopez Ruiz`도 200을 반환합니다.
- 같은 folio에 `fullName=Maria Perez`를 보내면 **409** `name_mismatch`를 반환합니다.
- Folio `FOLIO90040401`은 **404**를 반환합니다.
- `curp=LOPE900501HDFGRN01`은 어떤 `fullName`과 함께 보내도 200을 반환합니다. CURP가 `fullName`보다 우선하기 때문입니다. `curp=LOPE900404HDFNTF01`은 **404**를 반환합니다.
- `folio`가 없으면 **409** `MissingParameter`를 반환합니다.
- 등록부에 연결할 수 없으면 응답은 **409** `Endpoint_out_of_service`입니다. 나중에 다시 시도하세요.
