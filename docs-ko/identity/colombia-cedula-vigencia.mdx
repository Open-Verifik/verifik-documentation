# 콜롬비아 — 시민증 상태 (CC)

**콜롬비아 시민증 상태** 조회는 Registraduría 유효 상태를 읽습니다. `documentNumber`를 보냅니다. 응답은 번호 존재 여부, 생존 기록 여부, 등록부가 게시한 상태 문구를 담습니다. 더 넓은 신원 조회 전에 현재 CC 상태가 필요할 때 사용합니다.

## 응답에 포함되는 값

- `documentType` — CC
- `documentNumber` — 보낸 시민증 번호
- `exists` — 등록부에 번호가 있는지
- `isAlive` — true, false 또는 null
- `documentStatus` — 등록부가 준 유효 상태 문구

## 사용 사례

- 계좌를 열기 전에 CC가 등록되어 있는지 확인합니다.
- KYC 중 사망 기록과 유효한 시민증을 구분합니다.
- 문서 번호 옆에 상태 문구를 보관합니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/co/cedula/vigencia
```

성공 응답에는 `documentType`(CC), `documentNumber`, `exists`, `isAlive`, `documentStatus`가 있습니다. 등록부에 번호가 없으면 `exists`는 false입니다. 원천이 생존 여부를 확정하지 않으면 `isAlive`는 true, false 또는 null입니다. 현재 유효 상태가 필요한 KYC 파일에서 실행합니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **예** | `1121329661` | 콜롬비아 시민증 번호. 5자리에서 10자리 숫자이며 공백과 기호는 넣지 않습니다. |

### 참고

- `documentNumber`는 필수이며 5자에서 10자입니다.
- 등록부가 생사를 확정하지 않는 상태를 주면 `isAlive`는 null일 수 있습니다.
- 이 경로는 유효 상태 조회입니다. 전체 시민 프로필을 대체하지 않습니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.
