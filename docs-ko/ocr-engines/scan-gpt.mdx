# Scan Agent

**Scan Agent**는 문서 이미지에서 구조화 필드를 추출합니다. **POST** `https://api.verifik.co/v2/ocr/scan-gpt`를 호출합니다. `image`는 필수입니다. `documentType`, `backImage`, `template`은 선택입니다. 이 본문에는 `country` 필드가 없습니다. 저장된 추출은 `validationMethod`를 `SCAN_AGENT`로 둡니다.

## 응답에 포함되는 값

- 추출된 `documentType`, `documentNumber`, 이름
- `validationMethod` — `SCAN_AGENT`

## 사용 사례

- 이미지 하나에서 신원 문서를 읽습니다.
- 카드에 뒷면이 있으면 뒷면 이미지를 더합니다.
- 레이아웃을 알면 템플릿을 고정합니다.

---

## API 레퍼런스

### Endpoint

```http
POST https://api.verifik.co/v2/ocr/scan-gpt
```

일치에는 추출된 문서 필드와 `validationMethod` `SCAN_AGENT`가 있습니다. URL은 `/v2/ocr/scan-gpt`입니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `image` | string | **예** | `data:image/jpeg;base64,AAAA` | 앞면 이미지 base64 또는 data URI. 필수. |
| `documentType` | string | 아니오 | `CC` | 선택 문서 종류. 예: `CC`, `DNI`. |
| `backImage` | string | 아니오 | `data:image/jpeg;base64,BBBB` | 선택 뒷면 이미지. |
| `template` | string | 아니오 | `template_id` | 선택 템플릿 id. |

### 참고

- `image`는 필수입니다. `documentType`, `backImage`, `template`은 선택입니다.
- 국가 필드는 보내지 않습니다. 이 본문은 받지 않습니다.
- 기록된 메서드는 `SCAN_AGENT`이고 URL은 `/v2/ocr/scan-gpt`입니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.

## 샌드박스

| 시나리오 | 파라미터 | 결과 |
| :--- | :--- | :--- |
| 원천에 기록 있음 | `image` plus `documentType: "CC"` | 추출 필드와 validationMethod SCAN_AGENT가 있는 200. |
| 필수 값 누락 | Omit `image` | 409 MissingParameter. |
| 알 수 없는 값 | `image` and `backImage` | 뒷면 이미지도 보내면 200. |

401 when the bearer token is missing or rejected.
