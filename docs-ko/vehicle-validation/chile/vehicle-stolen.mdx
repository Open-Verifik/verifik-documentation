# 🇨🇱 칠레 — 도난 차량

칠레 차량에 활성 **도난·절도 신고**(*encargo por robo o hurto*)가 있는지 조회합니다.

조회가 성공하면 서명된 페이로드를 반환합니다.

- **`plate`** — 칠레 번호판(Patente), **4–7**자 영숫자
- **`hasTheftReport`** — 활성 신고가 있으면 `true`, 아니면 `false`
- **`description`** — 상태 텍스트(예: `NO REGISTRA ENCARGO Vigentes`)
- **`theftReport`** — 신고 객체: **`typeCode`**, **`plateOriginal`**, **`plateFormatted`**, **`reportDate`**, **`partiallyResolved`**, **`items`**
- **`items[]`** — 도난 부품: **`name`**, **`description`**, **`serial`**, **`resolvedDate`**, **`delivered`**, **`deliveryDate`**, **`type`**
- Verifik **서명** 응답

칠레 차량을 등록하거나 금융하기 전 **보험 인수**, **플릿 온보딩**, **실사**에 사용합니다.

### 엔드포인트

```
GET v2/cl/vehicle-stolen
```

일반 필드: **`plate`**, **`hasTheftReport`**, **`description`**, 중첩 **`theftReport`**. 활성 신고가 없어도 **HTTP 200**을 반환합니다.

### 헤더

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### 매개변수

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | **Yes** | 칠레 번호판(Patente), 4–7자 영숫자. | `PTKX93` |

### 참고

- **활성 도난 신고 없음**은 **`hasTheftReport: false`**와 함께 **HTTP 200**을 반환합니다. 404가 아닙니다.
- **샌드박스 모드:** 번호판 **`PTKX93`**은 신고 없음 프로필, **`NG8245`**는 도난 신고 프로필을 반환합니다.
- 잘못된 번호판 형식은 **409** `invalid_plate_format`을 반환합니다.
- 레지스트리 **가용성**은 환경에 따라 다르며, 장애 시 **409** 타임아웃이 발생할 수 있습니다.
