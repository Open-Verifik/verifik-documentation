# 코스타리카 — 교통 위반

**코스타리카 교통 위반** 조회는 번호판 하나의 COSEVI 벌금을 읽습니다. `plate`는 필수이며 3–6자입니다. 검증 실패는 `MissingParameter`가 아니라 코드 `409:invalid_params`의 HTTP 409입니다. 벌금이 없는 번호판은 404 `NotFound`입니다.

## 응답에 포함되는 값

- `plate`와 `totalRecords`
- 상태와 금액이 있는 `infractions[]`

## 사용 사례

- 차량을 등록하기 전에 벌금을 확인합니다.
- 3–6자가 아닌 번호판을 거부합니다.
- 각 벌금의 총액을 읽습니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v2/cr/traffic-infractions
```

일치에는 `plate`, `totalRecords`, 그리고 계열, 번호, 날짜, 상태, 기관, 금액이 있는 `infractions`가 있습니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **예** | `123456` | 번호판. 3–6자, 공백 없음. 없거나 길이가 틀리면 코드 `409:invalid_params`입니다. |

### 참고

- `plate`는 3–6자입니다.
- 잘못된 번호판은 코드 `409:invalid_params`입니다.
- 그 번호판에 벌금이 없으면 404 `NotFound`입니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.
