### 엔드포인트

```
GET https://api.verifik.co/v2/co/runt/conductor
```

**RUNT** 에 등록된 **운전면허** 정보를 명의자 **`documentType`**·**`documentNumber`** 로 조회합니다. 면허 상태, 카테고리, 적성·의무 교육 관련 데이터, 제재·과태료 요약 등이 응답에 포함될 수 있습니다.

`primerApellido` 생략: **Premium** (이름 조회 포함). `primerApellido` 전송: **Basic** 요금 — [`/v3/co/runt/conductor`](/vehicle-validation/colombia/runt-drivers-license-basic).

### 헤더(Headers)

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### 매개변수(Parameters)

| name | type | required | description |
| --- | --- | --- | --- |
| `documentType` | string | yes | **`CC`**, **`CE`**, **`PA`**, **`PPT`** 중 하나. 아래 표 참고 — **`PA`는 여권, `PPT`는 여권이 아닙니다**. |
| `documentNumber` | string | yes | 운전자 문서 번호(공백·마침표 없음). |
| `primerApellido` | string | 조건부 | 첫 번째 성. **`PA`는 필수**. `CC`, `CE`, `PPT`는 선택. Procuraduría와 `/v2/co/cedula`는 여권을 조회하지 않습니다. |

### 문서 유형

RUNT에 **`P.`** 가 보이면 `PPT`를 보내지 마세요. 그것은 **여권(`PA`)** 입니다. `PPT`는 이민 허가입니다.

| 코드 | 정식 명칭 | 대상 | RUNT 표시 | `primerApellido` |
| --- | --- | --- | --- | --- |
| **`CC`** | *Cédula de Ciudadanía* | 콜롬비아 국민(주민등록증) | `C.` | 선택 |
| **`CE`** | *Cédula de Extranjería* | 콜롬비아 거주 외국인 | `E.` | 선택 |
| **`PA`** | *Pasaporte* (여권) | 여권 소지자 | `P.` | **필수** |
| **`PPT`** | *Permiso por Protección Temporal* | 베네수엘라 임시보호 허가 — **여권이 아님** | `Y.` | 선택 |

### 요청(Request)

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.get("https://api.verifik.co/v2/co/runt/conductor", {
	params: { documentType: "CC", documentNumber: "123456789" },
	headers: {
		Accept: "application/json",
		Authorization: `Bearer ${process.env.VERIFIK_TOKEN}`,
	},
});
console.log(data);
```

  </TabItem>
  <TabItem value="python" label="Python">

```python
import os, requests

url = "https://api.verifik.co/v2/co/runt/conductor"
headers = {"Accept": "application/json", "Authorization": f"Bearer {os.getenv('VERIFIK_TOKEN')}"}
params = {"documentType": "CC", "documentNumber": "123456789"}
r = requests.get(url, headers=headers, params=params)
print(r.json())
```

### 참고(Notes)

- 응답 필드는 **RUNT** 원천 데이터에 따라 달라질 수 있습니다.
- 제품 UI에 다른 문서 유형이 보일 수 있으나, 이 경로의 검증은 **`CC`**, **`CE`**, **`PA`**(여권), **`PPT`** 입니다.
- `primerApellido`는 **`PA`에서 필수**이며 **`CC`**, **`CE`**, **`PPT`** 에서는 선택입니다.
