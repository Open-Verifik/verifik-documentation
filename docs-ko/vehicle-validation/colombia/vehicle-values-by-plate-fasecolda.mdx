Verifik의 Fasecolda 번호판 차량 가치 조회 API는 번호판만으로 콜롬비아 등록 차량의 공식 상업 가치와 기술 제원을 조회합니다. 승용차, SUV, 픽업트럭, 상용차 및 오토바이 전반의 조회 성공률을 극대화하기 위해 **두 가지 상호보완적인 공식 데이터 소스를 연결**합니다:

1. **1차 조회 (번호판-코드 직접 인덱스)**: 번호판에 연결된 Fasecolda 코드를 직접 조회합니다.
2. **2차 조회 (교차 소스 제원 매칭)**: 직접 코드가 없는 경우 공식 차량 등록 제원(`brand`, `line`, `cylinderCapacity`, `year`, `vehicleClass`)을 검증하여 Fasecolda 카탈로그와 매칭(`matchSource: "runt_fallback"`)하고 `matchConfidence`, `matchNote`, `matchDetails`, `runtVehicle`을 함께 반환합니다.

### Endpoint

```
GET https://api.verifik.co/v2/co/fasecolda/values-by-plate
```

콜롬비아 등록 차량의 `code`, `marke`, `line1`, `line2`, `line3`, `class`, `year`, `bcpp`, `valueModel`, `cylinderCapacity`, `fuel` 및 교차 매칭 상세 정보(`matchDetails`)를 반환합니다.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | Yes | 조회할 콜롬비아 차량 또는 오토바이 번호판(공백, 하이픈, 마침표 자동 제거). | `ABC123` |

### Request

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.get("https://api.verifik.co/v2/co/fasecolda/values-by-plate", {
  params: { plate: "ABC123" },
  headers: {
    Accept: "application/json",
    Authorization: `Bearer ${process.env.VERIFIK_TOKEN}`,
  },
});
console.log(data);
```

  <TabItem value="python" label="Python">

```python
import os, requests

url = "https://api.verifik.co/v2/co/fasecolda/values-by-plate"
```

### Notes

- **이중 소스 커버리지**: 번호판 직접 인덱스와 공식 차량 제원 교차 매칭(`matchSource: "runt_fallback"`)을 결합합니다.
- **신뢰도 공식(`matchConfidence` 및 `matchDetails`)**: `0.55 * textScore + 0.25 * ccScore + 0.20 * yearScore` (최소 `0.60`), 감점 요인은 `matchDetails.penalties`에 기록됩니다.
- **통화 단위**: `valueModel`은 연식별 가격 배열이며 `bcpp`는 콜롬비아 페소(COP) 기준 기본 상업 가격입니다.
