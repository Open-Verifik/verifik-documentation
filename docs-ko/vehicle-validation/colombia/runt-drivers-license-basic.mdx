### 엔드포인트

```
GET https://api.verifik.co/v3/co/runt/conductor
```

[Premium v2](/vehicle-validation/colombia/runt-drivers-license) 와 동일한 RUNT 조회이며 **현재 운전자 요금**입니다. `primerApellido` 는 **필수**입니다. 없으면 `409 MissingParameter`.

### 파라미터

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| `documentType` | string | 예 | **`CC`**, **`CE`**, **`PA`**, **`PPT`**. |
| `documentNumber` | string | 예 | 공백 없는 번호. |
| `primerApellido` | string | **예** | 첫 성 (최소 2자). |
