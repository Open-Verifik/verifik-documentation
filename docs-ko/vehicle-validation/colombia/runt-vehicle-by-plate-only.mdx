# RUNT — 번호판만으로 차량 조회

**번호판만**으로 RUNT 공식 차량 정보를 조회합니다. [차량 확인](/verifik-ko/vehicle-validation/colombia/runt-vehicle-by-plate)과 달리 소유자의 `documentType` 및 `documentNumber`는 **필요하지 않습니다**.

소유자 서류 없이 콜롬비아 번호판의 신원·기술·상태 블록이 필요할 때 사용합니다.

## API가 반환하는 내용

- **`informacionGeneral`** — 번호판, 브랜드, 라인, 모델, 클래스, 서비스, 상태 및 등록 필드(있는 경우)
- **`datosTecnicos`** — 기술 필드(있는 경우)
- **`soat[]`**, **`tecnoMecanica[]`** 같은 기간 제한 블록(있는 경우)
- 기타 RUNT 차량 블록(`solicitudes`, `polizasResponsabilidadCivil` 등, 응답에 포함된 경우)
- **`documentType`** 과 **`documentNumber`** 는 `null`일 수 있습니다
- Verifik가 **서명한** 응답

## API 참조

### 엔드포인트

```
GET https://api.verifik.co/v2/co/runt/vehicle-by-plate-only
```

**`plate`** 를 **쿼리** 파라미터로 보냅니다. 핸들러는 전체 RUNT 차량 형태를 반환합니다. 신원·기술·상태 섹션은 가능할 때 포함됩니다. 소유자 서류 필드는 필수가 아니며 `null`로 돌아올 수 있습니다.

### 헤더

| 이름 | 값 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### 파라미터

| 이름 | 유형 | 필수 | 설명 | 예 |
| --- | --- | --- | --- | --- |
| `plate` | string | 예 | 콜롬비아 번호판. 영숫자 **5–9**자. | `AA123BA` |

### 참고

- AppFeature 코드는 **`colombia_api_runt_vehicle_by_plate_only`** 입니다.
- 이 경로는 [GET `/v2/co/runt/vehicle-by-plate`](/verifik-ko/vehicle-validation/colombia/runt-vehicle-by-plate) 의 번호판 전용 형제입니다. 소유자 `documentType` / `documentNumber` 는 받지 않습니다.
- 페이로드의 `documentType` 과 `documentNumber` 는 `null`일 수 있습니다.
- 신원·기술·상태 블록은 있을 때 반환됩니다. 빈 배열이나 객체는 해당 섹션에 행이 없었음을 의미합니다.
- 샌드박스에서 **`AA123BA`** 와 **`ABC10001`–`ABC10010`** 은 안정적인 200을 반환합니다. **`ERR40401`** 은 **404** `NotFound` 입니다.
- **409** 는 유효성 검사 오류와 서비스가 일시적으로 이용 불가할 때 사용됩니다.
