# SIBGA - 차량 상업 평가액

콜롬비아 차량의 **교통부(SIBGA)** 공식 상업 평가액을 반환합니다. Verifik가 번호판을 **RUNT**에서 조회하고 제조사, 라인, 차종, 연료, 배기량을 SIBGA 카탈로그에 자동으로 대응합니다. 별도의 대조표를 유지할 필요가 없습니다.

번호판만 보내거나, 소유자 문서와 함께 보낼 수 있습니다. 문서가 있으면 [번호판으로 차량 조회(전체)](/verifik-ko/vehicle-validation/colombia/runt-vehicle-by-plate)와 같이 번호판과 소유자로 RUNT를 조회합니다. 문서가 없으면 [번호판만으로 차량 조회](/verifik-ko/vehicle-validation/colombia/runt-vehicle-by-plate-only)와 같은 경로를 따릅니다.

과세 기준이 SIBGA에서 나와야 하는 보험 인수, 여신, 차량 자산 평가에 사용합니다.

## 이 API가 반환하는 값

- **`valuation`** — 연식에 대한 **COP** 상업 평가액. SIBGA가 그 연식을 평가하지 않으면 `null`입니다(과세 연도보다 새로운 차량은 송장으로 평가)
- **`valuesByModel`** — 과세 연도 직전까지 약 **25**개 연식의 평가액
- **`matched`** — SIBGA 차량 유형, 차종, 제조사, 라인, 배기량, 증명서 **`avalId`**
- **`confidence`** — 라인, 제조사, 차종 대응의 강도(`exact`, `high`, `medium`, `low`, `none`)
- **`needsReview`** / **`reviewReason`** — 대응이 약하거나, SIBGA가 검색을 거절했거나, 라인이 없거나, 연식이 평가되지 않을 때 설정
- **`alternatives`** — 함께 검토한 다른 카탈로그 라인과 점수
- **`certificateUrl`** — 평가액이 있을 때의 공식 SIBGA PDF
- **`runtSource`** — 대응에 사용한 RUNT 제조사, 라인, 연식, 차종, 배기량
- Verifik **서명** 응답

## API 참조

### Endpoint

```
GET https://api.verifik.co/v2/co/sibga/valuation
```

**`plate`**를 쿼리 매개변수로 보냅니다. **`documentType`**과 **`documentNumber`**는 선택이며 함께 보내야 합니다. **`period`**는 **2016**년부터 현재 연도까지의 과세 연도이며, 생략하면 현재 연도입니다. 응답에는 상업 평가액, 연식별 표, 대응된 SIBGA 레코드, 사람이 확인해야 할 때의 검토 표시가 포함됩니다.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | 예 | 콜롬비아 번호판, 영숫자 **5–9**자. | `CUT984` |
| `documentType` | string | 아니요 | 소유자 문서 유형. **`CC`**, **`CE`**, **`PA`**, **`NIT`** 중 하나. `documentNumber`와 함께 필수. | `CC` |
| `documentNumber` | string | 아니요 | 공백과 문장 부호 없는 소유자 문서 번호. `documentType`과 함께 필수. | `63535790` |
| `period` | number | 아니요 | **2016**년부터 현재 연도까지의 과세 연도. 생략하면 현재 연도. | `2026` |

### Notes

- AppFeature 코드는 **`colombia_api_vehicle_valuation_sibga`**입니다.
- **`valuation: null`**인 본문도 **HTTP 200**입니다. **`reviewReason`**을 읽으십시오. `model_not_valued_in_period`, `low_confidence_match`, `no_matching_line`, `sibga_search_rejected`.
- **`documentType`**과 **`documentNumber`**는 함께 보내거나 둘 다 생략해야 합니다.
- 세미트레일러처럼 지원하지 않는 차종은 **404**를 반환합니다.
- 샌드박스 번호판 **`AA123BA`–`AA123BF`**, **`AA123BH`**, **`AA123BI`**는 서로 다른 평가 차량을 반환합니다. **`AA123BG`**는 `reviewReason: model_not_valued_in_period`인 **200**을 반환합니다. **`AA123BJ`**와 **`ERR40401`**은 **404**입니다. 문서 **`90040401`**은 **404**, **`90050001`**은 **500**입니다.
- 관련 RUNT 조회: [번호판으로 차량](/verifik-ko/vehicle-validation/colombia/runt-vehicle-by-plate), [번호판만으로 차량](/verifik-ko/vehicle-validation/colombia/runt-vehicle-by-plate-only).
