# 페루 - 차량 압류 명령 (SAT 리마)

### 엔드포인트

```
GET https://api.verifik.co/v2/pe/vehiculo/captura-lima
```

리마 세무 기관(**SAT**)에서 차량 **`plate`** 가 리마 주에 압류 명령이 있는지 조회합니다. 명령이 없는 번호판도 성공 응답입니다. `hasCaptureOrder`는 `false`이고 `orders`는 비어 있습니다. 명령이 있으면 `message`에 SAT 공식 문구가 오고, `orders`의 각 항목에는 `concept`, 솔 금액 `amount`, `period`, `documentNumber`가 있습니다. `status`는 SAT가 보낼 때만 채워집니다. 공개 양식에 열 이름이 있으면 `columns`가 원래 라벨을 유지합니다.

### 헤더

| 이름          | 값              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### 매개변수

| 이름    | 유형   | 필수 | 설명                                                                 | 예시  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | 예      | 차량 번호판. 5~8자의 영문 또는 숫자, 공백 없음. `F1E120`에는 명령이 있고 `V0R660`에는 없습니다.  | `F1E120` |
| `force` | boolean | 아니요      | 선택. `true` 또는 `1`을 보내면 저장된 결과를 건너뛰고 SAT를 다시 조회합니다.  | `true` |

### 참고

- 조회 범위는 리마 주뿐입니다.
- `plate`는 공백이나 하이픈 없이 5~8자의 영숫자로 보내세요.
- 압류 명령이 없는 번호판도 **HTTP 200**입니다. **404**는 5~8자의 영숫자가 아닌 번호판만 해당합니다.
- `amount`는 솔 표기입니다 (`S/ 505.86`). SAT가 상태를 보내지 않으면 `status`는 비어 있습니다.
- `F1E120`에는 압류 명령이 있습니다. `V0R660`에는 없습니다.
- SAT를 조회할 수 없으면 **409**와 `Endpoint_out_of_service`를 반환합니다.
- **샌드박스**에서 `ABC10001`에는 명령이 있고 `ABC10002`에는 없습니다.
