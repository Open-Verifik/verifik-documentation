# 페루 — 차량 정보 (v3)

### 엔드포인트

```
GET https://api.verifik.co/v3/pe/vehiculo/placa
```

페루 차량 정보 v3 서비스는 번호판(**`plate`**)으로 등록 차량 정보와 사용 가능한 경우 제원 시트 `technicalSheet` (`engine`, `performance`, 길이·너비·높이·축거·공차중량·연료탱크·도어·승차정원을 포함한 `dimensions`)를 반환합니다.

### 헤더 (Headers)

| 이름          | 값                 |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### 매개변수

| 이름    | 형식   | 필수   | 설명                                           | 예시     |
| ------- | ------ | ------ | ---------------------------------------------- | -------- |
| `plate` | string | **예** | 공백이나 마침표 없이 조회할 차량 번호판입니다. | `ABC123` |

### 요청 (Request)

<Tabs>
<TabItem value="javascript" label="JavaScript">

```javascript
import axios from 'axios';

const { data } = await axios.get('https://api.verifik.co/v3/pe/vehiculo/placa', {
  params: { plate: 'ABC123' },
  headers: { Accept: 'application/json', Authorization: 'Bearer <귀하의_토큰>' },
});
console.log(data);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import http.client

conn = http.client.HTTPSConnection("api.verifik.co")
headers = {"Accept": "application/json", "Authorization": "Bearer <귀하의_토큰>"}
conn.request("GET", "/v3/pe/vehiculo/placa?plate=ABC123", headers=headers)
print(conn.getresponse().read().decode("utf-8"))
```

### 참고

- 일치하는 제원 데이터가 없는 경우 `technicalSheet`(`dimensions`: `length`, `width`, `height`, `wheelbase`, `curbWeight`, `fuelTank`, `doors`, `occupants`)는 `null`이거나 일부만 채워질 수 있습니다.
- **샌드박스 모드**에서는 `ABC10001`–`ABC10010` 번호판이 안정적인 데모 프로필을 반환합니다.
