# 페루 - 차량 기술검사 증명서 (CITV)

### 엔드포인트

```
GET https://api.verifik.co/v2/pe/vehiculo/inspeccion-tecnica
```

페루 교통부(**MTC**)에 등록된 차량 기술검사 증명서(**CITV**)를 번호판 **`plate`** 로 조회합니다. 증명서 존재 여부(`found`), 유효한 증명서 여부(`hasValidCertificate`), 가장 최근 증명서(`latestCertificate`), 소스가 반환한 모든 증명서(`certificates`)를 포함합니다.

### 헤더

| 이름          | 값              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### 매개변수

| 이름    | 유형   | 필수 | 설명                                                                 | 예시  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | 예      | 차량 번호판. 5~8자의 영문 또는 숫자, 공백 없음. 예: `V0R660`.  | `V0R660` |
| `force` | boolean | 아니요      | 선택. `true` 또는 `1`을 보내면 저장된 결과를 건너뛰고 MTC를 다시 조회합니다.  | `true` |

### 참고

- `plate`는 공백이나 하이픈 없이 5~8자의 영숫자로 보내세요.
- `hasValidCertificate`는 하나 이상의 상태가 `VIGENTE`일 때 `true`입니다.
- `latestCertificate`는 MTC가 반환한 첫 증명서입니다. `certificates`는 해당 번호판의 전체 기록입니다. `V0R660`은 현재 유효한 증명서가 2건입니다.
- 증명서가 없는 번호판이거나 5~8자의 영숫자가 아니면 **404**를 반환합니다.
- MTC 소스를 사용할 수 없으면 **409**와 `Endpoint_out_of_service`를 반환합니다.
- **샌드박스**에서 `ABC10001`은 유효(`VIGENTE`) 증명서, `ABC10002`는 만료(`VENCIDO`) 증명서를 반환합니다.
