# 페루 — SETARE 아레키파 택시 면허

### 엔드포인트

```
GET https://api.verifik.co/v2/pe/vehiculo/setare-arequipa
```

페루 아레키파의 공식 시 기록에서 차량 번호판(**`plate`**)으로 **SETARE** 택시 운행 허가 여부를 확인하고 `hasActivePermit`, `latestPermit`, `permits`를 반환합니다.

### 헤더 (Headers)

| 이름          | 값                 |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### 매개변수

| 이름    | 형식   | 필수   | 설명                                                       | 예시     |
| ------- | ------ | ------ | ---------------------------------------------------------- | -------- |
| `plate` | string | **예** | 조회할 차량 번호판 (공백·하이픈 없는 6자리 영숫자, 예: `V3D236`). | `V3D236` |

### 요청 (Request)

<Tabs>
<TabItem value="javascript" label="JavaScript">

```javascript
import axios from 'axios';

const { data } = await axios.get('https://api.verifik.co/v2/pe/vehiculo/setare-arequipa', {
  params: { plate: 'V3D236' },
  headers: { Accept: 'application/json', Authorization: 'Bearer <귀하의_토큰>' },
});
console.log(data);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import http.client

conn = http.client.HTTPSConnection("api.verifik.co")
headers = {"Accept": "application/json", "Authorization": "Bearer <귀하의_토큰>"}
conn.request("GET", "/v2/pe/vehiculo/setare-arequipa?plate=V3D236", headers=headers)
print(conn.getresponse().read().decode("utf-8"))
```

### 참고

- `plate`는 공백이나 하이픈 없이 6자리 영숫자로 전달하세요.
- **샌드박스 모드**에서는 `ABC10001`이 유효 허가(`Vigente`), `ABC10002`가 만료 허가(`Vencido`) 예시를 반환합니다.
