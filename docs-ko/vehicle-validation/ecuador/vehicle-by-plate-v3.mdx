# 에콰도르 — 번호판 차량 (v3)

**에콰도르 차량 v3** 조회는 `GET /v3/ec/vehiculo/placa`입니다. `plate`는 필수입니다. 본문에는 식별 필드(`vin`, `brand`, `model`, `year`, `color` 및 번호판 데이터), 검사 날짜가 있는 `revision`, 엔진·성능·치수의 `technicalSheet`가 있습니다.

## 응답에 포함되는 값

- 식별: `vin`, `brand`, `model`, `year`, `color`
- 검사가 있는 `revision`
- `technicalSheet.engine`, `performance`, `dimensions`

## 사용 사례

- 보험 전에 차량을 확인합니다.
- 마지막 검사 연도를 읽습니다.
- VIN을 번호판과 함께 보관합니다.

---

## API 레퍼런스

### Endpoint

```http
GET https://api.verifik.co/v3/ec/vehiculo/placa
```

`plate`, 식별 필드, `revision`, `technicalSheet`를 기대합니다. 알 수 없는 번호판은 404 `NotFound`입니다.

### Headers

| 이름 | 값 | 설명 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | 요청 형식 |
| Accept | `application/json` | 응답 형식 |
| Authorization | `Bearer <token>` | 클라이언트 JWT |

### Parameters

| 이름 | 유형 | 필수 | 예시 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **예** | `ABC1234` | 에콰도르 번호판. 필수. |

### 참고

- 경로는 버전 3입니다: `/v3/ec/vehiculo/placa`.
- `plate`만 필수 쿼리입니다.
- 알 수 없는 번호판은 404 `NotFound`입니다.
- `Authorization` 헤더에 Bearer JWT를 보냅니다.
- JSON 예시는 필드 모양입니다. 실제 호출은 보낸 값의 레코드를 반환합니다.
- 캐시 우회 플래그는 보내지 않습니다. 이 페이지는 클라이언트 파라미터만 설명합니다.

## 샌드박스

| 시나리오 | 파라미터 | 결과 |
| :--- | :--- | :--- |
| 원천에 기록 있음 | `plate: "ABC1234"` | 식별, revision, technicalSheet가 있는 200. |
| 필수 값 누락 | Omit `plate` | 409 MissingParameter. |
| 알 수 없는 값 | `plate: "ZZZ0000"` | 번호판을 모르면 404 NotFound. |

401 when the bearer token is missing or rejected.
