# コロンビア — 登録番号で COPNIA 免許を照会

Verifik は単一の **`licenseNumber`**（matrícula）で **COPNIA**（*Consejo Profesional Nacional de Ingeniería*）を照会します。登録番号が既にあり、名義人と状態が必要なときに使います。

## この API が返す内容

- **身元** フィールド: `documentType`, `documentNumber`, `firstName`, `lastName`, `fullName`, `arrayName`
- 平坦化した免許フィールド: **`licenseNumber`**, **`licenseStatus`**, **`licenseType`**, **`profession`**, **`resolutionDate`**, **`resolutionNumber`**
- **署名付き** Verifik レスポンス（`licenses[]` 配列なし）

### Endpoint

```
GET https://api.verifik.co/v2/co/copnia/matricula
```

**`licenseNumber`** を **クエリ** で送ってください。ハンドラは人物と 6 つの免許フィールドを同じオブジェクトで返します。典型値は `091132-0839078 CNDC`（6–40 文字）です。

### ヘッダー

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### パラメーター

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `licenseNumber` | string | はい | COPNIA 登録番号（matrícula）、**6–40** 文字。空白可。 | `091132-0839078 CNDC` |

## 機能

- 書類番号なしで **登録番号** から照会
- **GET** クエリのみ
- **サンドボックス** はサンプル免許に固定の COPNIA ペイロードを返します
- レスポンスは **署名** され、`apiRequest` ハイブリッド機能として課金されます

## ユースケース

- **印刷・提出済み** の COPNIA 登録番号を確認
- オンボーディング中に **状態**（`VIGENTE` など）を再確認
- [書類番号で COPNIA を照会](/verifik-ja/legal/colombia-copnia) で見つけた免許と突合

### 備考

- サンドボックス例: **`091132-0839078 CNDC`**。対応する人物は **`CC` / `80176161`** です。
- 正規化後が空文字になると **`409`**（`invalid_license_number`）になります。
- ソースまたはセッション障害は `timeout_data_source` の **`409`** になることがあります。
- レスポンスは **機微な個人データ** として扱ってください。
