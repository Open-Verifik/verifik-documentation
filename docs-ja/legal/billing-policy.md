# クレジット請求・消費ポリシー

**API 照会の請求規則と動的価格**

**バージョン 1.0 | 公開日: 2026年10月26日**

本ポリシーは、ここに特定するサービスに適用される請求およびクレジット消費の一般規則を定めます。料金および個別条件は、各お客様と明示的に合意したものです。本ポリシーの変更を公開すること自体は、既に効力を有する契約を一方的に変更しません。

## 1. smartCHECK（DB Screening）の請求方式

### 1.1. 一般的な請求規則

請求方式は、政府データベースを照会する smartCHECK（DB Screening）ソリューションに適用されます。

**一般規則。** HTTP 200 の応答は請求されます。HTTP 403、412、422 および 500、タイムアウト、ならびに HTTP 409（情報源の利用不能および接続障害を含みます）は請求されません。HTTP 404 は、第 1.2 条に明示された場合にのみ請求されます。

| 請求あり | 請求なし |
| --- | --- |
| 200 | 403 |
|  | 404 |
|  | 409 |
|  | 412 |
|  | 422 |
|  | 500 |
|  | タイムアウト |

コロンビア国外のエンドポイントは HTTP 404 では請求されません。第 1.2 条に含まれないエンドポイントも、HTTP 404 では請求されません。

### 1.2. コロンビア: HTTP 404 の請求例外

本条は、smartCHECK における HTTP 404 の料金の唯一の根拠です。以下の経路はいずれもコロンビアの API です。タイムアウトおよび HTTP 409 の情報源障害は請求されません。

**RUNT**（応答コードが `NotFound` の HTTP 404 のみ）。HTTP 409 の応答（例えば、情報源がサービス停止中である場合、または RUNT ワーカーを利用できない場合）は請求されません。

| 製品名 | 経路 |
| --- | --- |
| コロンビア RUNT 運転者照会 | `GET /v2/co/runt/conductor` |
| コロンビア RUNT 運転者照会（v3） | `GET /v3/co/runt/conductor` |
| コロンビア RUNT 車両照会 | `GET /v2/co/runt/vehiculo` |
| コロンビア RUNT 車両完全記録 | `GET /v2/co/runt/vehiculo-completo` |
| コロンビア RUNT 車両 SOAT | `GET /v2/co/runt/vehiculo-soat` |
| コロンビア RUNT ナンバープレート別車両 | `GET /v2/co/runt/vehicle-by-plate` |
| コロンビア RUNT VIN 別車両 | `GET /v2/co/runt/vehicle-by-vin` |
| コロンビア RUNT ナンバープレート別車両（簡易） | `GET /v2/co/runt/vehicle-by-plate-simplified` |
| コロンビア RUNT ナンバープレートのみの車両 | `GET /v2/co/runt/vehicle-by-plate-only` |

**社会保障の加入。** 次の経路の HTTP 404 は、メッセージが誤った発行日を示す場合を含め、すべて請求対象です。HTTP 409 を返す接続障害は請求されません。

| 製品名 | 経路 |
| --- | --- |
| コロンビア社会保障加入 | `GET /v2/co/afiliaciones` |

**SIBGA 車両評価**（応答コードが `NotFound` の HTTP 404 のみ）。

| 製品名 | 経路 |
| --- | --- |
| コロンビア SIBGA 車両評価 | `GET /v2/co/sibga/valuation` |

**コロンビアの市民権カード（cédula）。** メッセージが `CEDULA NO EXISTE` である HTTP 404 のみを、有効性確認の料金で請求します。次の経路のその他の HTTP 404 は請求しません。`GET`/`POST /v2/co/cedula/vigencia` は、自身の HTTP 404 応答を請求しません。

| 製品名 | 経路 |
| --- | --- |
| コロンビア市民権カード照会 | `GET` / `POST /v2/co/cedula` |

**HTTP 404 で請求しないもの:** コロンビアのその他の RUNT 経路（所有者照会を含みます）、コロンビア国外のすべてのエンドポイント、および本条に列挙されていないすべての経路。顔のライブネスは、ライブネス失敗について HTTP 409 を請求することがあります。HTTP 404 では請求しません。smartBatch は、行を成功として印付けるためにのみ HTTP 404 を用い、それらの応答についてクレジットを請求しません。

## 2. smartCHECK の動的クエリ

動的クエリの技術的な説明は、[サービスレベル契約の第 5 条](/verifik-ja/legal/service-level-agreement#dynamic-query)にあります。本ポリシーはこれを繰り返しません。

請求の目的上、対応するエンドポイントでは、主たる情報源が十分な結果を返さない場合、Verifik は代替の情報源を自動的かつ順次に照会できます。動的クエリは連続した照会を要するため、応答時間が長くなることがあります。Verifik は、サービスを最適化するため、用いる情報源を変更、優先または置換できます。これは、合意済み料金の一方的な変更を認めるものではありません。

## 3. コロンビア市民権カード照会の動的価格 {#dynamic-pricing-billing}

お客様は、`GET`/`POST /v2/co/cedula` エンドポイントによる照会が、用いられた情報源、および[サービスレベル契約の第 5 条](/verifik-ja/legal/service-level-agreement#dynamic-query)に記載され本ポリシー第 2 条で参照する動的クエリにより得られた結果に応じて、動的価格の対象となり得ることを認め、これに同意します。

### 3.1. 標準料金とプレミアム料金

標準の情報源により照会が正常に解決された場合（HTTP 200）、コロンビア国民 ID 照会サービスの標準料金が適用されます。

標準の情報源が十分な一致を返さず、動的クエリが拡張またはプレミアムの検証情報源により成功応答（HTTP 200）を得た場合、お客様が標準エンドポイントを用いたときでも、対応するプレミアム料金が適用されます。

標準料金およびプレミアム料金は、各お客様との契約、または双方が受諾した料金表で明示的に合意した料金です。

### 3.2. 契約料金との関係

`GET`/`POST /v2/co/cedula` エンドポイントについて、標準またはプレミアムの区分は、適用契約が本規則を明示的に組み込んでいる場合に、本ポリシーに従って決定します。照会ごとの一般料金と抵触する場合、区分選択に関する特定の規則は、契約がそう定めるときに限り優先します。

本規則は、Verifik が既に合意された料金の金額を一方的に変更することを認めるものではありません。

### 3.3. 不十分な応答と請求の例外

HTTP 404 の応答は、第 1.2 条の例外およびそこで定める料金に従ってのみ請求されます。

その他の請求対象外の応答は、第 1.1 条に従います。

### 3.4. 請求の透明性 {#include-cost}

お客様は、対象となるリクエストでパラメータ `includeCost=true` を用い、請求されたクレジットの情報を取得できます。

API リクエスト履歴では、消費記録および対応する請求調整（動的クエリによりプレミアム料金が適用された場合を含みます）を確認できます。

### 3.5. 直接のプレミアム照会

エンドポイント `/v2/co/cedula/premium` により直接行った照会は、自動エスカレーションの仕組みを用いたか否かにかかわらず、対応するプレミアム料金の対象となります。

本条の定めは、ここに特定したエンドポイントにのみ適用され、その他の契約サービスの料金または請求条件を変更しません。

API の詳細は、[コロンビア国民 ID（基本照会）](/identity-validation/colombia/colombian-citizen)を参照してください。

**効力と個別条件。** 相違がある場合、商業契約で明示的に受諾された経済条件が優先します。ただし、当該契約が具体的に組み込む動的価格の例外を除きます。
