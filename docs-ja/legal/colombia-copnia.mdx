# コロンビア — 書類番号で COPNIA 専門免許を照会

Verifik は **`documentType`** と **`documentNumber`** で **COPNIA**（*Consejo Profesional Nacional de Ingeniería*）を照会します。ライブソースは COPNIA の有効証明書ポータルです。コロンビアのエンジニアの **採用**、**資格確認**、**コンプライアンス** に使います。

## この API が返す内容

- **身元** フィールド: `documentType`, `documentNumber`, `firstName`, `lastName`, `fullName`, `arrayName`
- **`licenses[]`** — その人物に紐づく専門登録
- 各免許には **`licenseNumber`**, **`licenseStatus`**, **`licenseType`**, **`profession`**, **`resolutionDate`**, **`resolutionNumber`** が含まれることがあります
- **署名付き** Verifik レスポンス

### Endpoint

```
GET https://api.verifik.co/v2/co/copnia
```

**`documentType`** と **`documentNumber`** を **クエリ** で送ってください。ハンドラは人物と `licenses` 配列を返します。詳細フィールド（`licenseStatus`, `licenseType`, `resolutionDate`, `resolutionNumber`）は最大 **10** 件まで補完されます。それ以外の行は `licenseNumber` と `profession` のみ残します。

### ヘッダー

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### パラメーター

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `documentType` | string | はい | **`CC`**, **`CE`**, **`PA`**, **`PEP`**, **`PE`**, **`PPT`**, **`TI`**, **`NIT`** のいずれか。 | `CC` |
| `documentNumber` | string | はい | 空白・記号なしの書類番号（最低 **5** 文字）。 | `80176161` |

## 機能

- 受け付ける書類種別: **CC**, **CE**, **PA**, **PEP**, **PE**, **PPT**, **TI**, **NIT**
- **GET** クエリのみ
- **サンドボックス** はテスト書類に COPNIA 形式のペイロードを返します
- レスポンスは **署名** され、`apiRequest` ハイブリッド機能として課金されます

## ユースケース

- エンジニアの **採用** と資格確認
- 契約前の **コンプライアンス**
- COPNIA 登録が必要な **オンボーディング**

### 備考

- サンドボックス例: **`CC` / `80176161`**。サンドボックス免許番号は **`091132-0839078 CNDC`** です。
- 詳細補完は最大 **10** 件です。追加行は `licenseNumber` と `profession` のみ残します。詳細取得の失敗は静かに無視されます（一覧行は残ります）。
- ソースまたはセッション障害は `timeout_data_source` の **`409`** になることがあります。
- レスポンスは **機微な個人データ** として扱ってください。
- 登録番号で 1 件を照会するには [免許番号で COPNIA を照会](/verifik-ja/legal/colombia-copnia-license) を使います。
