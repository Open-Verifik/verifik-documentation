# SMS メッセージ

**SMS メッセージ**は GET ではなく **POST** `https://api.verifik.co/v2/communication/sms` です。本文には `phone` と `+` で始まる `countryCode` が必要です。経路が `phoneGateway` を `sms` に固定するのでその項目は送りません。任意の `title` は 1–15 文字で、`language` が文言を選びます。アカウント所有者のトークンで呼べます。スタッフには Smart Tools の実行権限が必要です。

## 応答に含まれる項目

- `phone` と `countryCode`
- `sms` に固定された `phoneGateway`
- `status`

## 用途

- SMS でログインコードを送ります。
- 国内番号と国番号を使います。
- 経路に SMS ゲートウェイを選ばせます。

---

## API リファレンス

### Endpoint

```http
POST https://api.verifik.co/v2/communication/sms
```

成功した送信は `phoneGateway` `sms` と状態 `sent` を返します。OTP が届いたときに課金されます。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `phone` | string | **はい** | `3001234567` | 国内番号だけ。国番号は入れません。 |
| `countryCode` | string | **はい** | `+57` | `+` で始まる国番号。 |
| `title` | string | いいえ | `ACME` | 任意の送信者名 1–15文字。 |
| `language` | string | いいえ | `es` | 任意のテンプレート言語。 |

### 注意

- この経路は GET ではなく POST です。
- `phone` と `countryCode` は必須です。`countryCode` は `+` で始まります。
- `phoneGateway` は送りません。経路が `sms` に固定します。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。
