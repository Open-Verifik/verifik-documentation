# メール OTP

**メール OTP** はワンタイムコードを送ります。実際のメソッドは GET ではなく **POST** `https://api.verifik.co/v2/communication/email` です。本文には `project`、`validationMethod`（`manual` または `verificationCode`）、`email`、`type`（`validation`、`login`、`onboarding`、`oneTimeLink`）が必要です。任意項目は `expiresAt`、`redirectUrl`、`webhookUrl`、`identityUrl`、`requires2FA`、`ipAddress`、`language` です。

## 応答に含まれる項目

- `email` と `status`
- `type` と `validationMethod`

## 用途

- メールボックスへログインコードを送ります。
- メールで続く受付を始めます。
- 配信状態のウェブフックを付けます。

---

## API リファレンス

### Endpoint

```http
POST https://api.verifik.co/v2/communication/email
```

成功した送信は状態 `sent` のメール検証を返します。プロジェクトがすでに使うメール検証エンドポイントでコードを確認します。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `project` | string | **はい** | `project_id` | メール OTP を所有するプロジェクト id。 |
| `validationMethod` | string | **はい** | `verificationCode` | `manual` または `verificationCode`。 |
| `email` | string | **はい** | `person@example.com` | コードを受け取るメールボックス。不正なアドレスは 409 です。 |
| `type` | string | **はい** | `validation` | `validation`、`login`、`onboarding`、`oneTimeLink`。 |

### 注意

- この経路は GET ではなく POST です。
- `project`、`validationMethod`、`email`、`type` は必須です。
- メールでないアドレスは 409 です。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | the example body | コードが送られると 200。 |
| 必須値が無い | Omit `project` | 409 MissingParameter。 |
| 不明な値 | `email: "not-an-email"` | メール形式が不正だと 409。 |

401 when the bearer token is missing or rejected.
