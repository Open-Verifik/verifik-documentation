# WhatsApp メッセージ

**WhatsApp メッセージ**は GET ではなく **POST** `https://api.verifik.co/v2/communication/whatsapp` です。本文には `phone` と `countryCode` が必要です。経路が `phoneGateway` を `whatsapp` に固定します。任意の `whatsappTemplate` は `authentication`（既定）または `flow2` です。`flow2` では `language` が `flow2_es` または `flow2_en` を選び、任意の `title`（1–15文字）がブランド欄です。

## 応答に含まれる項目

- `phone` と `countryCode`
- `whatsapp` に固定された `phoneGateway`
- `status`

## 用途

- WhatsApp でログインコードを送ります。
- ブランドテンプレートが必要なら flow2 を選びます。
- 既定テンプレートは authentication です。

---

## API リファレンス

### Endpoint

```http
POST https://api.verifik.co/v2/communication/whatsapp
```

成功した送信は `phoneGateway` `whatsapp` と状態 `sent` を返します。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `phone` | string | **はい** | `3001234567` | 国内番号だけ。 |
| `countryCode` | string | **はい** | `+57` | `+` で始まる国番号。 |
| `whatsappTemplate` | string | いいえ | `authentication` | 任意。`authentication`（既定）または `flow2`。 |
| `language` | string | いいえ | `es` | 任意。`flow2` のとき `flow2_es` または `flow2_en` を選びます。 |

### 注意

- この経路は GET ではなく POST です。
- `whatsappTemplate` は任意です。`authentication` または `flow2`。
- 経路が `phoneGateway` を `whatsapp` に固定します。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | `phone: "3001234567"`, `countryCode: "+57"` | WhatsApp OTP が送られると 200。 |
| 必須値が無い | Omit `countryCode` | 409 MissingParameter。 |
| 不明な値 | `whatsappTemplate: "flow2"`, `language: "es"` | language が es なら flow2 テンプレートで 200。 |

401 when the bearer token is missing or rejected.
