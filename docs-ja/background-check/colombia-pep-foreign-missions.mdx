# コロンビア — PEP 在外公館

コロンビアの在外公館と領事館の職員を照合します。

## 応答に含まれる項目

- `isPEP`
- `isForeignMissionOfficial`
- `fullName` と `documentNumber`
- 単なる未検出では空の `matches`

## 用途

- 受付の前にコロンビアの PEP 名簿を照合します。
- 未掲載の人物を HTTP 200 として保存します。
- 氏名または文書番号で検索します。

---

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/co/pep/misiones-exterior
```

一致すると `isPEP` は true で `isForeignMissionOfficial` も true です。この名簿に無い人は HTTP 200 で `isPEP` は false、`matches` は空です。404 ではありません。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **条件付き** | `MARIA LOPEZ` | 氏名だけで足ります。名簿にあれば `partyName`、`entityName`、`country` も受けます。 |
| `documentNumber` | string | **条件付き** | `80123456` | 識別子 4–30文字。 |
| `documentType` | string | いいえ | `CC` | 任意: `CC`、`NIT`、`CE`、`PAS`、`TI`、`CD`。 |

### 注意

- 単なる未検出は `isPEP` が false の HTTP 200 です。
- 検索値を一つ以上送ります。
- その 200 を 404 に割り当てないでください。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | `fullName: "MARIA LOPEZ"` | 一致すると isPEP が true の 200。 |
| 必須値が無い | Omit every search value | 検索値が無いと 409。 |
| 不明な値 | `fullName: "CLEAN NAME"` | isPEP が false の 200。単なる未検出は 404 ではありません。 |

401 when the bearer token is missing or rejected.
