# ベネズエラ — 政治的要人（PEP）照会

**ベネズエラ**の人物を**セドゥラ番号**（`documentNumber`）または**法的氏名**（`fullName`）で公式な政治的要人（PEP）名簿と照合します。**FATF 勧告 12** と下記の国内 AML 枠組みに従い、公職終了後 **5 年の照合期間**を保持します。

- **根拠:** Ley Orgánica Contra la Delincuencia Organizada y Financiamiento al Terrorismo y Normativa SUDEBAN / UNIF sobre PEP
- **当局:** Unidad Nacional de Inteligencia Financiera (UNIF) / Contraloría General de la República
- **主な情報源:** Asamblea Nacional / Gaceta Oficial de la República Bolivariana de Venezuela / OpenSanctions PEP (VE)（`https://djp.cgr.gob.ve/`）

- 国内 PEP の顧客オンボーディングと強化デューデリジェンス。
- 任期の開始、変更、終了に合わせた定期再照会。
- 国内文書番号がまだない場合の氏名検索。

---

## API リファレンス

### エンドポイント

```http
GET https://api.verifik.co/v2/ve/politically-exposed-persons
```

成功時の応答には `country`、`jurisdiction`、`documentType`、`documentNumber`、`fullName`、`isPEP`、`isActivePep`、`isFormerPep`、`totalMatches`、`matchCount`、`categories`、`includeFormer`、`lookbackYears`（5）、`matches`、`checkedSources`、`regulation`、`dateTime` が含まれます。各一致には `position`、`entity`、`category`、`categoryDescription`、`status`（`ACTIVE` または `FORMER_PEP`）、`source`、`sourceUrl` があります。ルートの判定フラグは `isPEP` です。各一致は `isPep` を使います。PEP でない場合も HTTP 200 で、`isPEP` は false、`totalMatches` は 0 です。

### ヘッダー

| 名前 | 値 |
| :--- | :--- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <your_token>` |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| :--- | :--- | :--- | :--- |
| `documentNumber` | string | 条件付き | セドゥラ番号。3〜40 文字。`fullName` を省略する場合は必須。別名: `id`、`dni`、`cedula`。例: `VE-V-5892464`。 |
| `fullName` | string | 条件付き | 法的氏名。3〜160 文字。`documentNumber` を省略する場合は必須。別名: `name`。例: `NICOLAS MADURO MOROS`。 |
| `documentType` | string | いいえ | 文書種別。2〜20 文字。既定値は `CEDULA` で、応答にそのまま返ります。 |
| `includeFormer` | boolean | いいえ | 5 年の照合期間内に任期が終わった公職者を含めます。既定値は `true` です。`false` を渡すと `ACTIVE` の役職だけが残ります。元公職だけの一致は `isPEP` が false になり、`matches` は空配列です。 |

---

## PEP 区分

各一致は役職名から次のいずれかに分類されます。

| 区分 | 説明 |
| :--- | :--- |
| `HEAD_OF_STATE_OR_GOVERNMENT` | 国家元首、政府の長、または内閣の執行権限 |
| `SENIOR_EXECUTIVE` | 行政府の高官または閣僚 |
| `LEGISLATIVE` | 国会または立法議会の議員 |
| `JUDICIAL_OR_OVERSIGHT` | 上級の司法、憲法、または最高監査機関 |
| `DIPLOMATIC_MILITARY_OR_CENTRAL_BANK` | 上級の外交、軍事、または中央銀行の職員 |
| `PUBLIC_OFFICIAL_PEP` | FATF 勧告 12 に基づく政治的要人 |

## サンドボックス照会

アカウントがサンドボックスモードのとき、次の値は決定的です。

| 文書番号 | 氏名 | includeFormer | 結果 |
| :--- | :--- | :--- | :--- |
| `VE-V-5892464` | `NICOLAS MADURO MOROS` | `true` | 現職 PEP（`isPEP` true、区分 `HEAD_OF_STATE_OR_GOVERNMENT`） |
| `10000001` | `NICOLAS MADURO MOROS` | `true` | 現職 PEP（文書 `10000001` と同じフィクスチャ） |
| `10000002` | `PEP FORMER MINISTER` | `true` | `includeFormer` が true のときの元 PEP（`isFormerPep` true） |
| `10000002` | `PEP FORMER MINISTER` | `false` | `includeFormer` が false のときの非該当 |
| `55555555` | `JUAN CARLOS CIUDADANO NO PEP` | `true` | 非 PEP（`isPEP` false、`totalMatches` 0） |
| `99999404` | `—` | `true` | 404 `NotFound`（サンドボックスプローブのみ） |

### 備考

- `documentNumber` または `fullName` を送ります。文書の別名は `id`、`dni`、`cedula`、氏名の別名は `name` です。いずれも無い場合、API は 409 `MissingParameter` とメッセージ `Either documentNumber or fullName must be provided.` を返します。
- `includeFormer` の既定値は true です。5 年以内の元公職は `status` が `FORMER_PEP`、`isFormerPep` が true、`isPEP` が true で返ります。`false` はその行を除き、現職だけを残します。
- `documentType` の既定値は `CEDULA` です。応答の `jurisdiction` はレジストリラベル `Venezuela` です。`regulation.lookbackYears` は 5 です。
- サンドボックスの現職一致: 文書 `VE-V-5892464` または氏名 `NICOLAS MADURO MOROS`、および文書 `10000001`。元公職: 文書 `10000002`、または `PEP FORMER`、`EX MINISTRO`、`FORMER MINISTER` を含む氏名。非該当: 文書 `55555555` と氏名 `JUAN CARLOS CIUDADANO NO PEP`。`99999404` を含む文書番号、または `NOTFOUND` を含む氏名はサンドボックスで 404 です。本番の不一致は 404 ではなく、`isPEP` が false の HTTP 200 です。
- この経路は ベネズエラ（`VE`）だけを照会します。越境検索は [グローバル PEP](/verifik-ja/background-check/world-politically-exposed-persons) を使います。
- `checkedSources` はこの管轄で照会したレジストリキーです。`regulation.framework` と `regulation.authority` は結果とともに返る AML の根拠です。
