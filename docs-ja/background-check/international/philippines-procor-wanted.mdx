# フィリピン最重要手配 – コルディリェラ地域

人物または組織が**フィリピン最重要手配 – コルディリェラ地域**に掲載されているかを照会します。フィリピン国家警察コルディリェラ地域がフィリピン向けにこのリストを公開しています。

コルディリェラ地域警察は、その地域の最重要手配リストを公開します。一致は、照会した氏名がその公開手配リストにあることを意味します。

`fullName`、`documentNumber`、またはその両方を送信します。少なくとも一方は必須です。照会が公開記録と一致すると `foundInPhilippinesProcorWanted` は `true`、一致しないと `false` です。一致時の `details` には掲載名、公開機関、通知の種類、備考が含まれます。KYC、AML/CFT、取引先登録、支払い審査に使います。結果を用いる前に一致を確認してください。この呼び出しは公式リストの代わりではなく、法的判断でもありません。

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/philippines-procor-wanted
```

成功レスポンスには `data.fullName`、原資料が氏名を分ける場合の `data.firstName` と `data.lastName`、送信した場合の `data.documentNumber`、`data.foundInPhilippinesProcorWanted`、`data.details` が含まれます。一致時の `details` には掲載名、公開機関、通知の種類、備考が含まれます。`signature` には `dateTime` とメッセージ `Certified by Verifik.co` が含まれます。`foundInPhilippinesProcorWanted` が `false` のとき `details` は空のオブジェクトです。

### Headers

| 名前            | 値                  | 説明            |
| ------------- | ------------------ | ------------- |
| Content-Type  | `application/json` | リクエスト形式       |
| Accept        | `application/json` | レスポンス形式       |
| Authorization | `Bearer <token>`   | Verifik の JWT |

### Parameters

| パラメータ            | 型      | 必須   | 例                        | 説明                                                 |
| ---------------- | ------ | ---- | ------------------------ | -------------------------------------------------- |
| `fullName`       | string | 条件付き | `SAMPLE DESIGNATED NAME` | 個人の法的氏名、または組織の登録名です。`documentNumber` を送らない場合は必須です。 |
| `documentNumber` | string | 条件付き | `A1234567`               | 空白を含まない識別番号または法人登録番号です。`fullName` を送らない場合は必須です。    |

### 用途

- **指名手配の照会:** この機関が公開している被疑者・手配対象かどうかを確認します。
- **強化デューデリジェンス:** 公開手配に一致する氏名は、先に進む前に確認します。
- **記録:** 認証済みレスポンスをスクリーニング記録に残します。

### Notes

- `fullName` または `documentNumber` を送ってください。少なくとも一方は必須です。両方がない場合、API は HTTP 409、コード `MissingParameter`、メッセージ `Either fullName or documentNumber must be provided` を返します。
- `foundInPhilippinesProcorWanted` は、このリストの記録と一致すると `true`、一致しないと `false` です。不一致のとき `details` は空のオブジェクトです。
- 一致例はレスポンスの形を示します。実際の一致では、このリストに公開されているその記録の属性が返ります。
- 一致はコンプライアンス審査のためのスクリーニング結果です。法的判断ではなく、公式の情報源に代わるものでもありません。
- `Authorization` ヘッダーの Bearer JWT で認証してください。
- 結果は呼び出し時点のリストを反映します。後の結果が必要なときは、改めてリクエストしてください。
