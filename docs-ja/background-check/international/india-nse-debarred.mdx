# インドNSEの排除対象

人物または組織が**インドNSEの排除対象**に掲載されているかを照会します。インド国立証券取引所（NSE）がインド向けにこのリストを公開しています。

インド国立証券取引所は、証券市場または特定の市場活動から排除された団体と個人を公開します。

`fullName`、`documentNumber`、またはその両方を送信します。少なくとも一方は必須です。照会が公開記録と一致すると `foundInIndiaNseDebarred` は `true`、一致しないと `false` です。一致時の `details` には当事者名、当局、不適格期間、記載された理由が含まれます。KYC、AML/CFT、取引先登録、支払い審査に使います。結果を用いる前に一致を確認してください。この呼び出しは公式リストの代わりではなく、法的判断でもありません。

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/india-nse-debarred
```

成功レスポンスには `data.fullName`、原資料が氏名を分ける場合の `data.firstName` と `data.lastName`、送信した場合の `data.documentNumber`、`data.foundInIndiaNseDebarred`、`data.details` が含まれます。一致時の `details` には当事者名、当局、不適格期間、記載された理由が含まれます。`signature` には `dateTime` とメッセージ `Certified by Verifik.co` が含まれます。`foundInIndiaNseDebarred` が `false` のとき `details` は空のオブジェクトです。

### Headers

| 名前            | 値                  | 説明            |
| ------------- | ------------------ | ------------- |
| Content-Type  | `application/json` | リクエスト形式       |
| Accept        | `application/json` | レスポンス形式       |
| Authorization | `Bearer <token>`   | Verifik の JWT |

### Parameters

| パラメータ            | 型      | 必須   | 例                        | 説明                                                 |
| ---------------- | ------ | ---- | ------------------------ | -------------------------------------------------- |
| `fullName`       | string | 条件付き | `SAMPLE DESIGNATED NAME` | 個人の法的氏名、または組織の登録名です。`documentNumber` を送らない場合は必須です。 |
| `documentNumber` | string | 条件付き | `A1234567`               | 空白を含まない識別番号または法人登録番号です。`fullName` を送らない場合は必須です。    |

### 用途

- **調達スクリーニング:** 落札や支払いの前に、供給者や受注者を照会します。
- **市場参加:** このリストが対象とする活動から排除されていないか確認します。
- **記録:** 認証済みレスポンスを調達ファイルに残します。

### Notes

- `fullName` または `documentNumber` を送ってください。少なくとも一方は必須です。両方がない場合、API は HTTP 409、コード `MissingParameter`、メッセージ `Either fullName or documentNumber must be provided` を返します。
- `foundInIndiaNseDebarred` は、このリストの記録と一致すると `true`、一致しないと `false` です。不一致のとき `details` は空のオブジェクトです。
- 一致例はレスポンスの形を示します。実際の一致では、このリストに公開されているその記録の属性が返ります。
- 一致はコンプライアンス審査のためのスクリーニング結果です。法的判断ではなく、公式の情報源に代わるものでもありません。
- `Authorization` ヘッダーの Bearer JWT で認証してください。
- 結果は呼び出し時点のリストを反映します。後の結果が必要なときは、改めてリクエストしてください。
