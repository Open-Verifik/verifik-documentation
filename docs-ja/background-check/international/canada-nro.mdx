# カナダの指定研究機関

人物または組織が**カナダの指定研究機関**に掲載されているかを照会します。カナダ政府がカナダ向けにこのリストを公開しています。

カナダの指定研究機関リストは、特定の機微技術に関する研究提携が制限される研究機関を識別します。

`fullName`、`documentNumber`、またはその両方を送信します。少なくとも一方は必須です。照会が公開記録と一致すると `foundInCanadaNro` は `true`、一致しないと `false` です。一致時の `details` には会社名、当局、除外理由、状態、関連する日付が含まれます。KYC、AML/CFT、取引先登録、支払い審査に使います。結果を用いる前に一致を確認してください。この呼び出しは公式リストの代わりではなく、法的判断でもありません。

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/canada-nro
```

成功レスポンスには `data.fullName`、原資料が氏名を分ける場合の `data.firstName` と `data.lastName`、送信した場合の `data.documentNumber`、`data.foundInCanadaNro`、`data.details` が含まれます。一致時の `details` には会社名、当局、除外理由、状態、関連する日付が含まれます。`signature` には `dateTime` とメッセージ `Certified by Verifik.co` が含まれます。`foundInCanadaNro` が `false` のとき `details` は空のオブジェクトです。

### Headers

| 名前            | 値                  | 説明            |
| ------------- | ------------------ | ------------- |
| Content-Type  | `application/json` | リクエスト形式       |
| Accept        | `application/json` | レスポンス形式       |
| Authorization | `Bearer <token>`   | Verifik の JWT |

### Parameters

| パラメータ            | 型      | 必須   | 例                        | 説明                                                 |
| ---------------- | ------ | ---- | ------------------------ | -------------------------------------------------- |
| `fullName`       | string | 条件付き | `SAMPLE DESIGNATED NAME` | 個人の法的氏名、または組織の登録名です。`documentNumber` を送らない場合は必須です。 |
| `documentNumber` | string | 条件付き | `A1234567`               | 空白を含まない識別番号または法人登録番号です。`fullName` を送らない場合は必須です。    |

### 用途

- **除外スクリーニング:** 会社がこのリストで除外、観察、またはその他の制限対象かを確認します。
- **投資とサプライチェーン:** 保有、委任、契約の前に結果を使います。
- **記録:** 認証済みレスポンスを投資または取引先ファイルに残します。

### Notes

- `fullName` または `documentNumber` を送ってください。少なくとも一方は必須です。両方がない場合、API は HTTP 409、コード `MissingParameter`、メッセージ `Either fullName or documentNumber must be provided` を返します。
- `foundInCanadaNro` は、このリストの記録と一致すると `true`、一致しないと `false` です。不一致のとき `details` は空のオブジェクトです。
- 一致例はレスポンスの形を示します。実際の一致では、このリストに公開されているその記録の属性が返ります。
- 一致はコンプライアンス審査のためのスクリーニング結果です。法的判断ではなく、公式の情報源に代わるものでもありません。
- `Authorization` ヘッダーの Bearer JWT で認証してください。
- 結果は呼び出し時点のリストを反映します。後の結果が必要なときは、改めてリクエストしてください。
