# ウォッチリスト — ブラジル TCU 公職欠格

ブラジル TCU の公職欠格者一覧を照合します。

## 応答に含まれる項目

- `foundInBrTcuDisqualified`
- 一致時の `details`
- `fullName`

## 用途

- 支払いや受付の前に照合します。
- false のフラグをきれいな 200 として扱います。
- 名前、または文書種別と番号を送ります。

---

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/br/tcu-disqualified
```

一致すると `foundInBrTcuDisqualified` は true で `details` が埋まります。一覧に無い対象は HTTP 200 で `foundInBrTcuDisqualified` は false、`details` は空です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **条件付き** | `SAMPLE NAME` | 名前。ウォレット一覧なら住所。これだけで足ります。 |
| `documentType` | string | **条件付き** | `CPF` | `fullName` を省くと `documentNumber` とセットで必須です。氏名のない CPF は `dateOfBirth` も必要です。 |
| `documentNumber` | string | **条件付き** | `12345678901` | `fullName` を省くとき `documentType` と一緒に送る 5文字以上の識別子。 |
| `dateOfBirth` | string | **条件付き** | `1990-01-15` | `fullName` を省き CPF、CI、CCPA、DUI、CCUY のとき必須です。 |

### 注意

- `fullName`、または `documentType` と `documentNumber` を送ります。
- 未掲載は `foundInBrTcuDisqualified` が false の HTTP 200 です。
- 氏名のない CPF は `dateOfBirth` も必要です。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | `fullName: "SAMPLE NAME"` | 一覧が一致すると foundInBrTcuDisqualified が true の 200。 |
| 必須値が無い | Omit fullName and the document pair | fullName と文書の組が無いと 409。 |
| 不明な値 | `fullName: "CLEAN SAMPLE"` | 単に無ければ foundInBrTcuDisqualified が false の 200。 |

401 when the bearer token is missing or rejected.
