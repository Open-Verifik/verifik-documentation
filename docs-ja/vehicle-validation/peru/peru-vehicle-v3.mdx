# ペルー — 車両情報 (v3)

### エンドポイント

```
GET https://api.verifik.co/v3/pe/vehiculo/placa
```

ペルー車両情報 v3 サービスは、ナンバープレート（**`plate`**）に基づき登録車両詳細および技術諸元 `technicalSheet`（`engine`、`performance`、全長・全幅・全高・ホイールベース・車両重量・燃料タンク・ドア数・乗車定員を含む `dimensions`）を返します。

### ヘッダー (Headers)

| 名前          | 値                 |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### パラメータ

| 名前    | 型     | 必須     | 説明                                                   | 例       |
| ------- | ------ | -------- | ------------------------------------------------------ | -------- |
| `plate` | string | **はい** | スペースやピリオドを含まない車両ナンバープレート。     | `ABC123` |

### リクエスト (Request)

<Tabs>
<TabItem value="javascript" label="JavaScript">

```javascript
import axios from 'axios';

const { data } = await axios.get('https://api.verifik.co/v3/pe/vehiculo/placa', {
  params: { plate: 'ABC123' },
  headers: { Accept: 'application/json', Authorization: 'Bearer <あなたのトークン>' },
});
console.log(data);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import http.client

conn = http.client.HTTPSConnection("api.verifik.co")
headers = {"Accept": "application/json", "Authorization": "Bearer <あなたのトークン>"}
conn.request("GET", "/v3/pe/vehiculo/placa?plate=ABC123", headers=headers)
print(conn.getresponse().read().decode("utf-8"))
```

### 備考

- 一致する技術データがない場合、`technicalSheet`（`dimensions`：`length`、`width`、`height`、`wheelbase`、`curbWeight`、`fuelTank`、`doors`、`occupants`）は `null` または部分的に返却されることがあります。
- **サンドボックスモード**では、`ABC10001`–`ABC10010` などのナンバーで安定したデモプロフィールが返されます。
