# ペルー - 車両差押命令（SATリマ）

### エンドポイント

```
GET https://api.verifik.co/v2/pe/vehiculo/captura-lima
```

リマの税務機関（**SAT**）に、車両 **`plate`** がリマ県で差押命令を受けているかを照会します。命令がないプレートも成功レスポンスです。`hasCaptureOrder` は `false`、`orders` は空です。命令があるとき、`message` は SAT の公式文で、`orders` の各要素には `concept`、ソル建て `amount`、`period`、`documentNumber` が含まれます。`status` は SAT が送ったときだけ入ります。公開フォームに列名があるとき、`columns` は元の見出しを保持します。

### ヘッダー

| 名前          | 値              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### パラメータ

| 名前    | 型   | 必須 | 説明                                                                 | 例  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | はい      | 車両ナンバー。5〜8文字の英数字、スペースなし。`F1E120` には命令があり、`V0R660` にはありません。  | `F1E120` |
| `force` | boolean | いいえ      | 任意。`true` または `1` を送ると保存済みの結果を使わず、SAT を再照会します。  | `true` |

### 注意

- 照会範囲はリマ県のみです。
- `plate` はスペースやハイフンなしの 5〜8 文字の英数字で送ってください。
- 差押命令がないプレートも **HTTP 200** です。**404** は 5〜8 文字の英数字でないプレートだけです。
- `amount` はソル表記です（`S/ 505.86`）。SAT が状態を送らないとき `status` は空です。
- `F1E120` には差押命令があります。`V0R660` にはありません。
- SAT を照会できないときは **409** と `Endpoint_out_of_service` を返します。
- **サンドボックス**では、`ABC10001` に命令があり、`ABC10002` にはありません。
