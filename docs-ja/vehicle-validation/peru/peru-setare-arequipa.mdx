# ペルー — アレキパ SETARE タクシー許可

### エンドポイント

```
GET https://api.verifik.co/v2/pe/vehiculo/setare-arequipa
```

ペルー・アレキパの公式自治体記録に基づき、車両ナンバー（**`plate`**）から **SETARE** タクシー運行許可の有無を確認し、`hasActivePermit`、`latestPermit`、`permits` を返します。

### ヘッダー (Headers)

| 名前          | 値                 |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### パラメータ

| 名前    | 型     | 必須     | 説明                                                       | 例       |
| ------- | ------ | -------- | ---------------------------------------------------------- | -------- |
| `plate` | string | **はい** | 照会する車両ナンバー（スペース・ハイフンなしの6桁英数字、例: `V3D236`）。 | `V3D236` |

### リクエスト (Request)

<Tabs>
<TabItem value="javascript" label="JavaScript">

```javascript
import axios from 'axios';

const { data } = await axios.get('https://api.verifik.co/v2/pe/vehiculo/setare-arequipa', {
  params: { plate: 'V3D236' },
  headers: { Accept: 'application/json', Authorization: 'Bearer <あなたのトークン>' },
});
console.log(data);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import http.client

conn = http.client.HTTPSConnection("api.verifik.co")
headers = {"Accept": "application/json", "Authorization": "Bearer <あなたのトークン>"}
conn.request("GET", "/v2/pe/vehiculo/setare-arequipa?plate=V3D236", headers=headers)
print(conn.getresponse().read().decode("utf-8"))
```

### 備考

- `plate` はスペースやハイフンを含まない6桁の英数字で指定してください。
- **サンドボックスモード**では、`ABC10001` が有効な許可（`Vigente`）、`ABC10002` が失効した許可（`Vencido`）を返します。
