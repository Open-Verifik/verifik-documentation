# ペルー - 車両技術検査証明書 (CITV)

### エンドポイント

```
GET https://api.verifik.co/v2/pe/vehiculo/inspeccion-tecnica
```

ペルー運輸省（**MTC**）に登録された車両技術検査証明書（**CITV**）をナンバー **`plate`** で照会します。証明書の有無（`found`）、有効な証明書の有無（`hasValidCertificate`）、最新の証明書（`latestCertificate`）、ソースが返すすべての証明書（`certificates`）を含みます。

### ヘッダー

| 名前          | 値              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### パラメータ

| 名前    | 型   | 必須 | 説明                                                                 | 例  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | はい      | 車両ナンバー。5〜8文字の英数字、スペースなし。例: `V0R660`。  | `V0R660` |
| `force` | boolean | いいえ      | 任意。`true` または `1` を送ると保存済みの結果を使わず、MTC を再照会します。  | `true` |

### 注意

- `plate` はスペースやハイフンなしの 5〜8 文字の英数字で送ってください。
- `hasValidCertificate` は、少なくとも 1 件の状態が `VIGENTE` のときに `true` です。
- `latestCertificate` は MTC が返す最初の証明書です。`certificates` はそのプレートの全件です。`V0R660` には現在、有効な証明書が 2 件あります。
- 証明書がないプレート、または 5〜8 文字の英数字でないプレートは **404** です。
- MTC のソースが使えないときは **409** と `Endpoint_out_of_service` を返します。
- **サンドボックス**では、`ABC10001` が有効（`VIGENTE`）、`ABC10002` が期限切れ（`VENCIDO`）の証明書を返します。
