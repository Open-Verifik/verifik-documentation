# エクアドル — ナンバーの車両（v3）

**エクアドル車両 v3** 照会は `GET /v3/ec/vehiculo/placa` です。`plate` は必須です。本文には識別項目（`vin`、`brand`、`model`、`year`、`color` とナンバー情報）、検査日のある `revision`、エンジン・性能・寸法の `technicalSheet` があります。

## 応答に含まれる項目

- 識別: `vin`、`brand`、`model`、`year`、`color`
- 検査のある `revision`
- `technicalSheet.engine`、`performance`、`dimensions`

## 用途

- 保険の前に車両を確認します。
- 最後の検査年を読みます。
- VIN をナンバーと一緒に保存します。

---

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v3/ec/vehiculo/placa
```

`plate`、識別項目、`revision`、`technicalSheet` を期待します。不明なナンバーは 404 `NotFound` です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **はい** | `ABC1234` | エクアドルのナンバー。必須。 |

### 注意

- 経路はバージョン 3 です: `/v3/ec/vehiculo/placa`。
- 必須クエリは `plate` だけです。
- 不明なナンバーは 404 `NotFound` です。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | `plate: "ABC1234"` | 識別、revision、technicalSheet のある 200。 |
