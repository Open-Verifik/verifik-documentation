# 🇪🇨 エクアドル — 車両検証

このサービスは、ナンバープレート（**`plate`**）を指定してエクアドルに登録された車両情報を返します：メーカー、モデル、年式、車種、VIN、エンジン番号、点検メタデータ、および利用可能な場合の技術仕様フィールド。

### Endpoint

```
GET https://api.verifik.co/v3/ec/vehiculo/placa
```

**`plate`**（スペースや句点なし）でエクアドル車両を照会します。応答には、利用可能な場合に `brand`、`model`、`year`、`vin`、`engineNumber`、`vehicleClass`、`vehicleType`、`color`、`serviceType`、`revision`、`technicalSheet`（`engine`、`performance`、`dimensions`）が含まれることがあります。**検証**、**保険**、**フリート**、**コンプライアンス**に利用できます。

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Accept | `application/json` |
| Authorization | `Bearer <token>`   |

### Parameters

| Name | Type | Required | Description | Example |
| ---- | ---- | -------- | ----------- | ------- |
| `plate` | string | **Yes** | 照会するナンバープレート（スペースや句点なし）。 | `PBB3239` |

### Request

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
import axios from 'axios';

const { data } = await axios.get('https://api.verifik.co/v3/ec/vehiculo/placa', {
  params: { plate: 'PBB3239' },
  headers: {
    Accept: 'application/json',
    Authorization: `Bearer ${process.env.VERIFIK_TOKEN}`,
  },
});
console.log(data);
```

  <TabItem value="python" label="Python">

```python
import os

url = "https://api.verifik.co/v3/ec/vehiculo/placa"
```

### Notes

- 一致する技術データがない場合、`technicalSheet` は `null` または部分的にしか埋まらないことがあります。
- `revision` は可用性に応じて `null` または部分的に埋まることがあります。
