# 🇨🇱 チリ — 盗難車両

チリ車両に有効な **盗難・窃盗届出**（*encargo por robo o hurto*）があるかを照会します。

照会が成功すると署名付きペイロードを返します。

- **`plate`** — チリナンバー（Patente）、**4–7** 文字の英数字
- **`hasTheftReport`** — 有効な届出がある場合 `true`、それ以外は `false`
- **`description`** — ステータス文言（例: `NO REGISTRA ENCARGO Vigentes`）
- **`theftReport`** — 届出オブジェクト: **`typeCode`**, **`plateOriginal`**, **`plateFormatted`**, **`reportDate`**, **`partiallyResolved`**, **`items`**
- **`items[]`** — 盗難部品: **`name`**, **`description`**, **`serial`**, **`resolvedDate`**, **`delivered`**, **`deliveryDate`**, **`type`**
- Verifik **署名**付きレスポンス

チリ車両の登録・融資前の**保険引受**、**フリートオンボーディング**、**デューデリジェンス**に使用します。

### エンドポイント

```
GET v2/cl/vehicle-stolen
```

主なフィールド: **`plate`**, **`hasTheftReport`**, **`description`**, ネストされた **`theftReport`**。有効な届出がなくても **HTTP 200** を返します。

### ヘッダー

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### パラメータ

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | **Yes** | チリナンバー（Patente）、4–7 文字の英数字。 | `PTKX93` |

### 注記

- **有効な盗難届出なし**は **`hasTheftReport: false`** の **HTTP 200** です。404 ではありません。
- **サンドボックス:** **`PTKX93`** は届出なし、**`NG8245`** は盗難届出の安定プロファイルを返します。
- 無効なナンバー形式は **409** `invalid_plate_format` を返します。
- レジストリの**可用性**は環境依存です。障害時は **409** タイムアウトになる場合があります。
