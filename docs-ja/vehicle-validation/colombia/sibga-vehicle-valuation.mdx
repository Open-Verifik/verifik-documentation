# SIBGA - 車両の商業評価額

コロンビア車両の**運輸省（SIBGA）**公式商業評価額を返します。Verifikはナンバーを**RUNT**で照会し、メーカー、ライン、クラス、燃料、排気量をSIBGAカタログへ自動で対応付けます。対照表を別途維持する必要はありません。

ナンバーだけを送るか、所有者の書類と一緒に送ります。書類がある場合は[ナンバーによる車両照会（詳細）](/verifik-ja/vehicle-validation/colombia/runt-vehicle-by-plate)と同様に、ナンバーと所有者でRUNTを照会します。書類がない場合は[ナンバーのみの車両照会](/verifik-ja/vehicle-validation/colombia/runt-vehicle-by-plate-only)と同じ経路です。

課税標準をSIBGAから取る必要がある保険引受、与信、フリート評価に使います。

## このAPIが返す内容

- **`valuation`** — 年式に対する**COP**の商業評価額。SIBGAがその年式を評価しないときは`null`（課税年度より新しい車両は請求書で評価）
- **`valuesByModel`** — 課税年度の前年まで、およそ**25**年式の評価額
- **`matched`** — SIBGAの車両種別、クラス、メーカー、ライン、排気量、証明書の**`avalId`**
- **`confidence`** — ライン、メーカー、クラスの対応の強さ（`exact`、`high`、`medium`、`low`、`none`）
- **`needsReview`** / **`reviewReason`** — 対応が弱い、SIBGAが検索を拒否した、ラインがない、年式が未評価のときに設定
- **`alternatives`** — 検討した他のカタログ行とスコア
- **`certificateUrl`** — 評価額があるときの公式SIBGA PDF
- **`runtSource`** — 対応に使ったRUNTのメーカー、ライン、年式、クラス、排気量
- Verifikの**署名**付き応答

## APIリファレンス

### Endpoint

```
GET https://api.verifik.co/v2/co/sibga/valuation
```

**`plate`**をクエリパラメータで送ります。**`documentType`**と**`documentNumber`**は任意で、セットで送る必要があります。**`period`**は**2016**年から当年までの課税年度で、省略すると当年です。応答には商業評価額、年式表、対応したSIBGAレコード、人が確認すべきときのレビュー表示が含まれます。

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | はい | コロンビアのナンバー。英数字**5–9**文字。 | `CUT984` |
| `documentType` | string | いいえ | 所有者の書類種別。**`CC`**、**`CE`**、**`PA`**、**`NIT`**のいずれか。`documentNumber`とセットで必須。 | `CC` |
| `documentNumber` | string | いいえ | 空白や記号を除いた所有者の書類番号。`documentType`とセットで必須。 | `63535790` |
| `period` | number | いいえ | **2016**年から当年までの課税年度。省略すると当年。 | `2026` |

### Notes

- AppFeatureコードは**`colombia_api_vehicle_valuation_sibga`**です。
- **`valuation: null`**の本体も**HTTP 200**です。**`reviewReason`**を確認してください。`model_not_valued_in_period`、`low_confidence_match`、`no_matching_line`、`sibga_search_rejected`。
- **`documentType`**と**`documentNumber`**はセットで送るか、両方省略します。
- セミトレーラーのように未対応のクラスは**404**を返します。
- サンドボックスのナンバー**`AA123BA`–`AA123BF`**、**`AA123BH`**、**`AA123BI`**はそれぞれ別の評価済み車両を返します。**`AA123BG`**は`reviewReason: model_not_valued_in_period`の**200**です。**`AA123BJ`**と**`ERR40401`**は**404**です。書類**`90040401`**は**404**、**`90050001`**は**500**です。
- 関連するRUNT照会: [ナンバーによる車両](/verifik-ja/vehicle-validation/colombia/runt-vehicle-by-plate)、[ナンバーのみの車両](/verifik-ja/vehicle-validation/colombia/runt-vehicle-by-plate-only)。
