# ナンバープレートによる車両価格照会 - Fasecolda

Verifik の Fasecolda ナンバー別車両価格 API は、ナンバープレートのみでコロンビア登録車両の公式商業評価額および技術仕様を取得します。乗用車、SUV、ピックアップ、商用車、オートバイ全体で高い照会成功率を実現するため、このエンドポイントは **2つの補完的な公式車両データソースを連携**させています：

1. **一次解決（ナンバー・コード直接インデックス）**：ナンバープレートが主要評価インデックスで Fasecolda コードに直接紐付いている場合、カタログの正確なエントリを即座に返します。
2. **二次解決（複数ソース間の技術仕様クロスマッチング）**：オートバイや新規登録車両など、ナンバーに直接コードが紐付いていない場合、Verifik は公式の二次車両登録データから検証済みの技術仕様（`brand`、`line`、`cylinderCapacity`、`year`、`vehicleClass`）を取得し、Fasecolda 評価カタログとクロスマッチングします（`matchSource: "runt_fallback"`）。

クロスマッチングによって解決されたレスポンスには、トレーサビリティとスコアの内訳（`matchSource`、`matchConfidence`、`matchNote`、`matchDetails`、`runtVehicle`）が含まれ、どのように評価コードが特定され、どの要素でスコアが減点されたかを正確に把握できます。

## この API で検証できる内容

- **ナンバーによる四輪・二輪車両情報の照会**：コロンビアの乗用車、SUV、ピックアップ、トラック、オートバイのナンバー（`ABC123`、`ABC12D`、`ABC12`）に対応しています。スペース、ハイフン、ピリオドは自動的に除去され、大文字に正規化されます。
- **包括的な技術仕様と評価データ**：Fasecolda コード（`code` / `homoloCode`）、メーカー（`marke`）、モデルライン（`line1`、`line2`、`line3`）、クラス（`class`）、カテゴリ（`category`）、排気量（`cylinderCapacity`）、燃料（`fuel`）、トランスミッション（`transmission`）、基準商業価格（`bcpp`）、年式別価格履歴（`valueModel`）を返します。
- **マルチソースの透明性と信頼度スコア内訳**：クロスマッチング時には加重信頼度スコア（`0.60`〜`1.00`）と減点理由（`matchDetails.penalties`）を詳細に返します。

### Endpoint

```
GET https://api.verifik.co/v2/co/fasecolda/values-by-plate
```

コロンビア登録車両の公式評価額および技術仕様（`code`、`marke`、`line1`、`line2`、`line3`、`class`、`cylinderCapacity`、`bcpp`、`valueModel`）を取得し、クロスマッチング時には `matchSource`、`matchConfidence`、`matchNote`、`matchDetails`、`runtVehicle` も返します。**ナンバー**を **クエリ** パラメータ **`plate`** で指定してください。

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | Yes | 照会するコロンビアの車両またはオートバイのナンバープレート（スペース・ハイフン・句点は自動除去）。 | `ABC123` |

### Notes

- **デュアルソースによる高い網羅性（四輪・二輪）**：ナンバーが一次評価インデックスに登録されている場合は直接 Fasecolda レコードを返し（`matchSource` は省略）、未登録の場合（オートバイや一部の軽車両で一般的）は公式の二次車両登録データから仕様を検証して Fasecolda カタログと照合します（`matchSource: "runt_fallback"`）。
- **信頼度スコア計算式（`matchConfidence` と `matchDetails`）**：`0.55 * textScore + 0.25 * ccScore + 0.20 * yearScore` によって `0.00`〜`1.00` で算出され、最小閾値は `0.60` です。
- **`matchConfidence` が減点される理由（`matchDetails.penalties`）**：
  - **カタログ側の追加グレード・仕様トークン（`textPoints` / 最大 `0.55`）**：車両登録原簿にはベースライン名（`"VERSA"` や `"TRK 502X"` など）のみが記載される一方、Fasecolda カタログにはグレードや変速機・ABS（`"ADVANCE AT 1600CC 2AB ABS"`）が含まれます。これらの追加トークンは `extraGuideTokens` に記載されます。
  - **型式認定コードと商用名の違い**：`"FZN250 A"`（商用名 `"FZ25 250"`）などの差異は `unmatchedRuntTokens` に記録されます。
  - **排気量の公称丸め差（`ccPoints` / 最大 `0.25`）**：5% 以内の差（`199cc` vs `200cc`）は満点（`0.25/0.25`）となり、より大きい公称差（`373cc` vs `400cc`）は `-0.07` 減点として `penalties` に明記されます。
- **通貨単位**：`valueModel` はモデル年別の履歴価格配列であり、`bcpp` はコロンビアペソ（COP）建ての基準商業価格です。
