Verifik の Fasecolda ナンバー別車両価格 API は、ナンバープレートからコロンビア登録車両の公式商業評価額と技術仕様を取得します。乗用車、SUV、ピックアップ、トラック、オートバイ全体で高い成功率を実現するため、**2つの補完的な公式データソースを接続**しています：

1. **一次解決（ナンバー・コード直接インデックス）**：ナンバープレートに紐付く Fasecolda コードを直接解決します。
2. **二次解決（複数ソース間の技術仕様クロスマッチング）**：直接コードがない場合、公式車両登録データから仕様（`brand`、`line`、`cylinderCapacity`、`year`、`vehicleClass`）を検証し、Fasecolda カタログと照合（`matchSource: "runt_fallback"`）して `matchConfidence`、`matchNote`、`matchDetails`、`runtVehicle` を返します。

### Endpoint

```
GET https://api.verifik.co/v2/co/fasecolda/values-by-plate
```

コロンビア登録車両の `code`、`marke`、`line1`、`line2`、`line3`、`class`、`year`、`bcpp`、`valueModel`、`cylinderCapacity`、`fuel`、およびクロスマッチング時の `matchDetails` を返します。

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | Yes | 照会するコロンビアの車両またはオートバイのナンバープレート（スペース・ハイフン・句点は自動除去）。 | `ABC123` |

import axios from "axios";

### Notes

- **デュアルソース網羅性**：ナンバー直接インデックスと公式技術仕様クロスマッチング（`matchSource: "runt_fallback"`）を組み合わせます。
- **信頼度計算式（`matchConfidence` と `matchDetails`）**：`0.55 * textScore + 0.25 * ccScore + 0.20 * yearScore`（最小閾値 `0.60`）で算出され、減点理由は `matchDetails.penalties` に記載されます。
- **通貨単位**：`valueModel` はモデル年別の価格配列、`bcpp` はコロンビアペソ（COP）建ての基準商業価格です。
