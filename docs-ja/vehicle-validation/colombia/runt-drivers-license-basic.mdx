### エンドポイント

```
GET https://api.verifik.co/v3/co/runt/conductor
```

[Premium v2](/vehicle-validation/colombia/runt-drivers-license) と同じ RUNT 照会で、**現行の運転者料金**です。`primerApellido` は**必須**です。未指定は `409 MissingParameter`。

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `documentType` | string | はい | **`CC`**, **`CE`**, **`PA`**, **`PPT`**. |
| `documentNumber` | string | はい | 空白なしの番号。 |
| `primerApellido` | string | **はい** | 最初の姓（2文字以上）。 |
