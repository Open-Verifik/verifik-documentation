# コスタリカ — 交通違反

**コスタリカの交通違反**照会は 1 枚のナンバーの COSEVI 反則を読みます。`plate` は必須で 3–6 文字です。検証失敗は `MissingParameter` ではなくコード `409:invalid_params` の HTTP 409 です。反則の無いナンバーは 404 `NotFound` です。

## 応答に含まれる項目

- `plate` と `totalRecords`
- 状態と金額のある `infractions[]`

## 用途

- 車両登録の前に反則を確認します。
- 3–6文字でないナンバーを拒否します。
- 各反則の合計額を読みます。

---

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/cr/traffic-infractions
```

一致には `plate`、`totalRecords`、および系列、番号、日付、状態、機関、金額を持つ `infractions` があります。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **はい** | `123456` | ナンバー。3–6文字、空白なし。無い、または長さが違うとコード `409:invalid_params` です。 |

### 注意

- `plate` は 3–6 文字です。
- 不正なナンバーはコード `409:invalid_params` です。
- そのナンバーに反則が無いと 404 `NotFound` です。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | `plate: "123456"` | 反則のある 200。 |
| 必須値が無い | Omit `plate` | コード `409:invalid_params` の 409。 |
| 不明な値 | `plate: "ABC"` | COSEVI に反則が無いと 404 NotFound。 |

401 when the bearer token is missing or rejected.
