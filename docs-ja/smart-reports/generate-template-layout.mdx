Gemini（temperature `0.2`）を使用して、自然言語の `prompt` から構造化された `ReportSection` 定義を生成、追加、または編集します。`previewData` にサンプルの検証データを渡すことで、モデルがセクションの `dataPath` バインディングや列レイアウトを実際のペイロード構造に合わせます。

ヘッドレスレポートビルダーや AI エージェントパイプラインでは、セクション JSON を手書きすることなく、完全なレイアウトのひな形作成（`"create"`）、既存テンプレートへの後続セクションの追加（`"append"`）、または単一セクションの調整（`"edit"`）にこのエンドポイントを使用します。この呼び出しと [テンプレート HTML をプレビューする](/verifik-ja/smart-reports/preview-template-html) を組み合わせてレンダリング出力を確認したうえで、[レポートテンプレートを作成する](/verifik-ja/smart-reports/create-a-report-template) または [レポートテンプレートを更新する](/verifik-ja/smart-reports/update-a-report-template) で永続化してください。

### エンドポイント

```
POST https://api.verifik.co/v2/smart-report-templates/generate-layout
```

Smart-Agent プロキシ（`https://ai.verifik.co`）も同じ `/v2/...` パスを公開しており、お客様自身の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーが必要です。

### ヘッダー

| 名前 | 値 |
| --- | --- |
| Content-Type | `application/json` |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### ボディ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `prompt` | string | **はい** | 作成するレイアウト、追加するセクション、または編集モードで適用する変更内容を説明する自然言語の指示文。 |
| `mode` | string | **はい** | 生成モード: `"create"`、`"edit"`、または `"append"`。 |
| `previewData` | object | いいえ | 生成される `dataPath` 式や列を実際のデータ構造に合わせるためのサンプル検証 JSON（例: `inputData`、`results`、`batchName`）。 |
| `currentSections` | object[] | いいえ | 既存の `ReportSection` 配列。新しく生成されたセクションが既存の `order` 連番を引き継ぐように、`"append"` モードでの指定を推奨します。 |
| `selectedSection` | object / null | いいえ | `mode` が `"edit"` のときに変更対象となる `ReportSection` オブジェクト。`"edit"` モードで `null` または省略された場合、動作は `"create"` にフォールバックします。 |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func main() {
	body, _ := json.Marshal(map[string]interface{}{
		"prompt": "Create a clean 2-column driver summary section followed by a table of traffic citations.",
		"mode":   "create",
		"previewData": map[string]interface{}{
			"batchName": "Driver Onboarding",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{"fullName": "Mateo Rojas", "status": "active"},
				"fines": []map[string]interface{}{
					{"code": "C02", "amount": 580000, "status": "pending"},
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/generate-layout", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### 注記

- `"create"` および `"append"` モードでは `{ "data": [ ...ReportSection ] }`（配列）を返し、`selectedSection` が null 以外の `"edit"` モードでは `{ "data": { ...ReportSection } }`（単一オブジェクト）を返します。
- `selectedSection: null` または `selectedSection` を省略して `"edit"` を呼び出すと、`"create"` モードにフォールバックして配列を返します。
- このエンドポイントはデータベースへの書き込みを行いません。返された `sections` を [テンプレート HTML をプレビューする](/verifik-ja/smart-reports/preview-template-html) に渡して HTML を確認するか、[レポートテンプレートを作成する](/verifik-ja/smart-reports/create-a-report-template) に渡して保存してください。
