`sampleData` の検証ペイロードを検査し、フィールドパス、値の形状、推奨される `sectionType` の選択肢、代替セクション種別、推奨テーブル列、およびバインディング提案を含む構造化マップを取得します。

ヘッドレスでのレポート作成や AI エージェントのパイプラインでは、[シミュレートレスポンスを取得する](/verifik-ja/smart-reports/retrieve-simulated-response) からペイロードを取得した直後、または `SmartBatch` の行データを取得した直後にこのエンドポイントを呼び出します。`dataPath` 文字列を推測したり脆い JSON 走査ロジックを書いたりする代わりに、UI やエージェントはイントロスペクトされた `nodes` と `batch` メタデータを使用して有効な `sections` を直接構築したり、[テンプレートレイアウトを生成する](/verifik-ja/smart-reports/generate-template-layout) の `prompt` コンテキストを補強したりできます。ウォーカーは深さ `5` まで、最大 `600` ノードを検査します。

### エンドポイント

```
POST https://api.verifik.co/v2/smart-report-templates/introspect
```

Smart-Agent プロキシ（`https://ai.verifik.co`）も同じ `/v2/...` パスを公開しており、お客様自身の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーが必要です。

### ヘッダー

| 名前 | 値 |
| --- | --- |
| Content-Type | `application/json` |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### ボディ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `sampleData` | object | **はい** | 任意の `batchName`（string）、`rowIndex`（number）、`inputData`（object）、および `results`（object）を含むサンプル検証ペイロード。 |

package main

import (
	"bytes"

	"fmt"

	body, _ := json.Marshal(map[string]interface{}{
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",

			"results": map[string]interface{}{

				},

					{"code": "C02", "amount": 580000, "status": "pending"},
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/introspect", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)

### 注記

- 走査は深さ `5` で停止し、上限は `600` ノードです。非常に大きなペイロードで上限に達した場合、`truncated` が `true` になります。
- このエンドポイントは読み取り専用かつステートレスであり、テンプレートの保存や検証クレジットの消費は行いません。
