ID を指定して単一の `SmartReport` を取得します。レスポンスでは `template`、`smartBatch`、および `client` が展開（populate）され、すぐに使用できる `downloadUrl`（`/v2/smart-reports/{id}/download`）および `htmlUrl`（`/v2/smart-reports/{id}/html`）パスが付与されます。

このエンドポイントは、`POST /v2/smart-reports/run` が `"async"` モードで実行された場合や 90 秒の同期期限を超過して `202 Accepted` にフォールバックした際に返されるポーリング先（`pollUrl`）でもあります。レポート ID が存在しない、または別のクライアントに属している場合、このエンドポイントは `{ "data": null }` とともに HTTP `200 OK` を返します。

### エンドポイント

```
GET https://api.verifik.co/v2/smart-reports/{id}
```

このエンドポイントは、お客様自身のクライアント別 `Authorization: Bearer <VERIFIK_JWT>` を使用して Smart-Agent プロキシ経由の `https://ai.verifik.co/v2/smart-reports/{id}` からも利用できます。共有 x402 による実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --- | --- | --- |
| `Content-Type` | `application/json` | リクエストペイロードの形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアント単位の JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string | **はい** | `POST /v2/smart-reports/run`、`POST /v2/smart-reports`、または `GET /v2/smart-reports` によって返された `SmartReport` ObjectId。 |

### Webhook と MCP 統合

- **ポーリングと Webhook の使い分け**: 非同期実行の場合、`data.status` が確定（`"generated"`、`"sent"`、または `"failed"`）するまで `GET /v2/smart-reports/{id}` をポーリングするか、Webhook イベント（`smart_batch_report_generated`、`smart_batch_report_generation_failed`、`smart_batch_report_sent`、`smart_batch_report_delivery_failed`）を購読できます。詳細は [SmartReports Webhook](/verifik-ja/resources/smart-reports-webhooks) を参照してください。
- **MCP 相当ツール**: AI エージェントは `smart_report_get` MCP ツールを使用してレポートレコードを取得できます。詳細は [MCP と AI エージェント](/verifik-ja/smart-reports/mcp-and-ai-agents) を参照してください。

### 注記

- レポートが存在しない場合や別のクライアントに属している場合は、`404` ではなく `{ "data": null }` とともに `200 OK` が返されます。
- `downloadUrl` および `htmlUrl` は、`https://api.verifik.co`（または `https://ai.verifik.co`）に連結してそのまま利用できる相対 API パスです。
