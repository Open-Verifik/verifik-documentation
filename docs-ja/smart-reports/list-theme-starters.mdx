Verifik 組み込みのテーマ付きスターターテンプレートを取得します（任意で `theme` によるフィルタが可能）。各スターターには事前設定済みの `sections`、`reportTheme`、`sampleData`、ページレイアウトプロパティ、およびカラーが含まれているため、セクションツリーを一から組み立てることなく本番品質のレポートデザインを迅速に立ち上げられます。

ヘッドレスのオンボーディングフローや AI エージェントでは、このエンドポイントを呼び出して洗練されたビジュアルの出発点を選択し、[テンプレート HTML をプレビューする](/verifik-ja/smart-reports/preview-template-html) で即座にプレビューしたうえで、ブランドカラーやロゴをカスタマイズして [レポートテンプレートを作成する](/verifik-ja/smart-reports/create-a-report-template) で編集可能な自社テンプレートとして保存します。

### エンドポイント

```
GET https://api.verifik.co/v2/smart-report-templates/theme-starters
```

Smart-Agent プロキシ（`https://ai.verifik.co`）も同じ `/v2/...` パスを公開しており、お客様自身の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーが必要です。

### ヘッダー

| 名前 | 値 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `theme` | string | いいえ | 任意のテーマフィルタ: `"premium_dark"`、`"light_cards"`、`"editorial"`、`"dashboard"`、または `"smart_enroll_v2"`（`"light_cards"` のエイリアス。正規名の `"light_cards"` の使用を推奨します）。 |

### 注記

- `"smart_enroll_v2"` は `"light_cards"` のエイリアスとして受け付けられますが、正規のテーマ ID である `"light_cards"` でフィルタすることを推奨します。
- ここで返されるスターター項目は参照用に `type: "System"` を持ちます。[レポートテンプレートを作成する](/verifik-ja/smart-reports/create-a-report-template) 経由でカスタマイズしたコピーを保存する際は、`name` とデザインフィールド（`sections`、`reportTheme`、`sampleData`、カラー、および PDF 設定）のみを送信してください。
