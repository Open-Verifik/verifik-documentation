[シミュレートレスポンス一覧を取得する](/verifik-ja/smart-reports/list-simulated-responses) で検出したカタログエンドポイント `code` に対して、シミュレートされたサンドボックスレスポンス、フィールドの `outline`、`dataSample`、および `emptySample` を取得します。返却される `sample` の状態は、レコードあり（`"data"`）、一致なし（`"empty"`）、データ欠損（`"missing"`）の間で切り替えられ、`listSize` によって配列の行数を制御できます。

ヘッドレスでのテンプレート設計や自動 QA ワークフローでは、本番の `SmartBatch` パイプライン向けにテンプレートを保存・出荷する前に、空のテーブル、任意フィールドの欠損、複数ページの配列（`listSize` は `2`〜`30`）といったエッジケースがテンプレート上でどのようにレンダリングされるかをこのエンドポイントで検証できます。

### エンドポイント

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses/{code}
```

Smart-Agent プロキシ（`https://ai.verifik.co`）も同じ `/v2/...` パスを公開しており、お客様自身の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーが必要です。

### ヘッダー

| 名前 | 値 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### パラメータ

| 名前 | 型 | 場所 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| `code` | string | パス | **はい** | [シミュレートレスポンス一覧を取得する](/verifik-ja/smart-reports/list-simulated-responses) から取得したカタログエンドポイントコード。 |
| `availability` | string | クエリ | いいえ | `sample` に配置するシミュレート状態: `"data"`、`"empty"`、または `"missing"`。デフォルトは `"data"` です。 |
| `listSize` | integer | クエリ | いいえ | 配列/リストフィールド用に生成する合成アイテム数。有効範囲: `2`〜`30`。 |

async function run() {

    `https://api.verifik.co/v2/smart-report-templates/simulated-responses/${code}?${params.toString()}`,
    {
      method: "GET",
      headers: {
        Accept: "application/json",
        Authorization: `Bearer ${process.env.VERIFIK_JWT}`,
      },
    }
  );

  console.log(await res.json());
}

### 注記

- `{code}` がサンドボックスインベントリに存在しない場合、このエンドポイントは `found: false`、空の `outline` と `sample` オブジェクト、および説明の `note` を含めて HTTP `200` を返します。
- `listSize` は `2` から `30` までの整数を受け付け、[テンプレートサンプルをダウンロードする](/verifik-ja/smart-reports/download-template-sample) を介した複数ページ PDF のページ送りテストに便利です。
- このエンドポイントはライブ検証を実行せず、クレジットも消費しません。
