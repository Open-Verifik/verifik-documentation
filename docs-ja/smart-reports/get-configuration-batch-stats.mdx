認証済みクライアントアカウント上で、特定の `BatchConfiguration` に属するすべての `SmartBatch` レコード全体の集計実行統計を取得します。レスポンスでは、バッチ数、行完了合計、および `"draft"`、`"pending"`、`"processing"`、`"completed"`、`"failed"`、`"cancelled"` ごとのステータス内訳が返されます。

設定の統計情報を読み取ってもチェックは実行されず、クレジットも消費されません。

### エンドポイント

```text
GET https://api.verifik.co/v2/smart-batches/stats/{configId}
```

このエンドポイントは、クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` を使用することで Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batches/stats/{configId}`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type` | `application/json` | リクエストペイロード形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアントスコープの JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| ---------- | ------ | ---- | ----------- |
| `configId` | string | はい | バッチ統計を集計する `BatchConfiguration` の ObjectId。 |

### 補足

- 統計情報は認証済みクライアント（JWT 上の `clientId`）にスコープされます。
- `pendingRows` は `totalRows - completedRows - failedRows - partialRows` として計算されます。
- この設定に属する個別のバッチを確認するには、[Smart Batch 一覧](/verifik-ja/smart-reports/list-smart-batches)に `batchConfiguration` を指定してください。
