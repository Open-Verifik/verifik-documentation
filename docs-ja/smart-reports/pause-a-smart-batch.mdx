すでに完了した行に書き込まれた結果を失うことなく、アクティブな `SmartBatch`（および関連付けられたすべての `FeatureRunner` 実行）を一時停止します。ワーカーはバッチが再開されるまで残りの行の取得を停止します。

キュー実行およびブラウザ実行のバッチは、`"processing"` または `"pending"` ステータスである必要があります（それ以外は `400 batch_not_pausable`）。`FeatureRunner` 実行に基づくバッチは、その実行が `"queued"` または `"processing"` ステータスである必要があります（それ以外は `400 run_not_pausable`）。一時停止してもクレジットは消費されません。

### エンドポイント

```text
POST https://api.verifik.co/v2/smart-batches/{id}/pause
```

このエンドポイントは、クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` を使用することで Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batches/{id}/pause`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type` | `application/json` | リクエストペイロード形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアントスコープの JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| ---- | ------ | ---- | ----------- |
| `id` | string | はい | 一時停止する `SmartBatch` の ObjectId。 |

### 補足

- プログラムからバッチを一時停止するには、（`"paused"` を受け付けない）`PUT /v2/smart-batches/{id}` ではなく、常にこのエンドポイントを使用してください。
- `FeatureRunner` ベースのバッチでは、その実行が `"queued"` または `"processing"` ステータスでない場合に `400 BadRequest` とともに `run_not_pausable` が返されます。
- 後から実行を続ける場合は[Smart Batch を再開する](/verifik-ja/smart-reports/resume-a-smart-batch)を、完全に終了させる場合は[Smart Batch をキャンセルする](/verifik-ja/smart-reports/cancel-a-smart-batch)を使用してください。
