認証済みクライアントアカウントに属する `SmartBatch` レコードを一覧表示します。結果は既定で新しい順（`-createdAt`）となり、明示的に `includeRows=true` を渡さない限り `rows` 配列は除外されるため、一覧レスポンスを軽量に保てます。

`total`、`limit`、`page`、`pages` メタデータを含むページネーション出力を有効にするには `page` を送信してください。ページネーションフィールドなしで一致するバッチ配列を `{ data }` として受け取る場合は `page` を省略します。バッチの一覧取得はチェックを実行せず、クレジットも消費しません。

### エンドポイント

```text
GET https://api.verifik.co/v2/smart-batches
```

このエンドポイントは、クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` を使用することで Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batches`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type` | `application/json` | リクエストペイロード形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアントスコープの JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| -------------------- | ------- | ---- | ----------- |
| `batchConfiguration` | string | いいえ | `BatchConfiguration` の ObjectId でバッチを絞り込みます。 |
| `status` | string | いいえ | バッチステータスで絞り込みます: `"draft"`、`"pending"`、`"processing"`、`"paused"`、`"completed"`、`"failed"`、または `"cancelled"`。 |
| `page` | number | いいえ | ページ番号（`>= 1`）。ページネーションを有効にし、レスポンスに `total`、`limit`、`page`、`pages` を追加します。 |
| `limit` | number | いいえ | 1 レスポンスあたりの最大件数（`1`〜`200`）。 |
| `perPage` | number | いいえ | `page` 指定時のページサイズ（`1`〜`200`）。既定値は `20`。 |
| `includeRows` | boolean | いいえ | 返される各バッチに `rows` を含める場合は `true` を指定します。省略または `false` の場合、`rows` は除外されます。 |
| `search` | string | いいえ | バッチ `name` に対する大文字・小文字を区別しない正規表現検索。 |
| `sort` | string | いいえ | ソート対象フィールドおよび方向。既定値は `"-createdAt"`。 |
| `sortBy` | string | いいえ | `sortOrder` と組み合わせて使うソート対象フィールド名。 |
| `sortOrder` | string | いいえ | `sortBy` のソート方向: `"asc"` または `"desc"`。 |

不明なクエリパラメータは Joi バリデーションにより `409 MissingParameter` で拒否されます。

### 補足

- 結果は認証済みクライアント（JWT 上の `clientId`）にスコープされます。
- `includeRows` を省略するか `false` のままにすることで一覧レスポンスを小さく保てます。1 つのバッチの完全な `rows` を取得するには[Smart Batch を取得する](/verifik-ja/smart-reports/retrieve-a-smart-batch)を使用してください。
- 無効なクエリ値や不明なクエリキーは Joi バリデーションにより `409 MissingParameter` で失敗します。
- `page` が指定された場合（`>= 1`）、`perPage` の既定値は `20` となり、`1`〜`200` をサポートします。
