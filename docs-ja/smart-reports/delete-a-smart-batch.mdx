認証済みクライアントが所有する `SmartBatch` を削除します。バッチが存在し、ご自身のクライアントアカウントに属している場合、サーバーはそれを削除し、削除された `SmartBatch` ドキュメントを `data` に返します。

バッチ ID が存在しないか別クライアントに属している場合、エンドポイントは `404`（`not_found`）を返します。バッチを削除しても、すでに消費されたクレジットは返金されません。

### エンドポイント

```text
DELETE https://api.verifik.co/v2/smart-batches/{id}
```

このエンドポイントは、クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` を使用することで Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batches/{id}`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type` | `application/json` | リクエストペイロード形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアントスコープの JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| ---- | ------ | ---- | ----------- |
| `id` | string | はい | 削除する `SmartBatch` の ObjectId。 |

### リクエスト

  <TabItem value="node" label="Node.js">

```javascript
import axios from "axios";

const run = async () => {
  const batchId = "6801a2b3c4d5e6f7a8b9c0d3";

  const { data } = await axios.delete(`https://api.verifik.co/v2/smart-batches/${batchId}`, {
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${process.env.VERIFIK_JWT}`,
    },
  });

  console.log(data);
};

run();
```

### 補足

- 履歴の行データや出力を保持したまま実行中のバッチを停止するには、削除ではなく[Smart Batch をキャンセルする](/verifik-ja/smart-reports/cancel-a-smart-batch)を使用してください。
- 別クライアントアカウントに属するバッチは `404`（`not_found`）を返します。
