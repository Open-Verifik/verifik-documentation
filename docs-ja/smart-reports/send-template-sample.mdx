保存済みの Smart Report テンプレート（`{id}`）を `sampleData` でレンダリングし、生成された PDF を 1 名以上の `recipients` へ直接メール送信します。任意で `printHtml` を指定して HTML 生成をバイパスしたり、`pdfBase64` を指定して事前レンダリング済みの PDF バッファを添付したりすることもできます。

ヘッドレス CI/CD パイプライン、テンプレート承認ワークフロー、および AI エージェントの自動化では、独自のメール基盤を構築することなくコンプライアンス担当者やプロダクト関係者へフォーマット済みレポートのプレビューを配布するためにこのエンドポイントを使用します。埋め込みフォント、ロゴ、事前レンダリング済み HTML、または base64 PDF に対応するため、最大 `64MB` の JSON リクエストボディを受け付けます。

### エンドポイント

```
POST https://api.verifik.co/v2/smart-report-templates/{id}/send-sample
```

Smart-Agent プロキシ（`https://ai.verifik.co`）も同じ `/v2/...` パスを公開しており、お客様自身の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーが必要です。

### ヘッダー

| 名前 | 値 |
| --- | --- |
| Content-Type | `application/json` |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string | **はい** | Smart Report テンプレートの ObjectId。 |

### ボディ

最大 `64MB` の JSON ペイロードをサポートします。

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `recipients` | string[] | **はい** | 有効な受信者メールアドレスの配列（最小 `1` 件）。 |
| `sampleData` | object | **はい** | `inputData`、`results`、`batchName`、および `rowIndex` を含むサンプルペイロード。 |
| `subject` | string | いいえ | カスタムメール件名。デフォルトはテンプレートの `name` を使用した `` `Sample Report: <name>` `` です。 |
| `language` | string | いいえ | メール文面の言語: `"en"` または `"es"`。デフォルトは `"es"` です。 |
| `printHtml` | string | いいえ | テンプレートの `sections` からレンダリングする代わりに PDF へ変換する、任意の事前レンダリング済み HTML ドキュメント。 |
| `pdfBase64` | string | いいえ | サーバー側での PDF 生成を行わずに直接送信する、任意の base64 エンコード済み PDF 添付ファイル。 |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func main() {
	id := "67c1f94b2d8a1c0012a4b301"
	body, _ := json.Marshal(map[string]interface{}{
		"recipients": []string{"compliance@acme.example"},
		"subject":    "Sample Report: Colombia Driver Onboarding",
		"language":   "en",
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding Sample",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{
					"fullName": "Mateo Rojas",
					"status":   "active",
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/"+id+"/send-sample", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### 注記

- ペイロードを `{ "data": ... }` でラップする他のテンプレートエンドポイントとは異なり、`send-sample` はトップレベルの `success`、`message`、`recipients`、`messageId`、および `delivery` フィールドを返します。
- `language` を省略した場合、メールのデフォルトは `"es"` になります。英語の関係者向け通知には `"en"` を渡してください。
- レンダリングした PDF をメール送信せずにローカルへ保存する場合は、[テンプレートサンプルをダウンロードする](/verifik-ja/smart-reports/download-template-sample) を使用してください。
