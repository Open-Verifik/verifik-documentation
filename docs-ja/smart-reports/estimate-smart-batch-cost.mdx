`SmartBatch` 上に残っている終了状態ではないすべての行について、実行前のクレジット見積もりを計算します。レスポンスでは、バッチの `BatchConfiguration` で有効になっているステップごとの内訳を示し、予測コストとクライアントアカウントの利用可能クレジット残高を比較します。

このエンドポイントを呼び出してもカタログ照会は実行されず、クレジットも一切消費されません。

### エンドポイント

```text
GET https://api.verifik.co/v2/smart-batches/{id}/estimate
```

このエンドポイントは、クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` を使用することで Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batches/{id}/estimate`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type` | `application/json` | リクエストペイロード形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアントスコープの JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| ---- | ------ | ---- | ----------- |
| `id` | string | はい | 見積もり対象の `SmartBatch` ObjectId。 |

### 補足

- `itemCount` と `pendingRows` には、まだ終了状態の行ステータス（`completed`、`failed`、または `partial`）になっていない行のみが反映されます。
- `availableCredits` はクライアントアカウントの `credits` と `extraCredits` を合算した値です。`sufficientCredits` が `false` の場合、`shortfall` は追加で必要なクレジット数を示します。
- ステップごとの価格計算では、該当する場合にクライアントアカウントの `ClientFeature` スナップショット価格が使用されます。
