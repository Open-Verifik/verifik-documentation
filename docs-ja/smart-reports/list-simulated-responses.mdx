テンプレート設計インベントリに事前構築済みのサンドボックス・シミュレートレスポンスが用意されている Verifik カタログエンドポイントを一覧取得します。`country` または検索クエリ（`q`）でフィルタリングして、エンドポイントの `code` 識別子と想定される `inputs` を検出できます。

ヘッドレスレポートビルダーや AI エージェントのパイプラインでは、課金対象の本番照会を実行したり本番 PII を取り扱ったりすることなくリアルなモックデータセットを選択するために、このカタログ検出エンドポイントを使用します。返却された任意の `code` を [シミュレートレスポンスを取得する](/verifik-ja/smart-reports/retrieve-simulated-response) に渡すことで、[サンプルデータをイントロスペクトする](/verifik-ja/smart-reports/introspect-sample-data)、[テンプレートレイアウトを生成する](/verifik-ja/smart-reports/generate-template-layout)、または [テンプレート HTML をプレビューする](/verifik-ja/smart-reports/preview-template-html) 用のサンプルペイロードを取得できます。

### エンドポイント

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses
```

Smart-Agent プロキシ（`https://ai.verifik.co`）も同じ `/v2/...` パスを公開しており、お客様自身の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーが必要です。

### ヘッダー

| 名前 | 値 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `country` | string | いいえ | シミュレートされたエンドポイントを国でフィルタします。 |
| `q` | string | いいえ | 名前、コード、またはメタデータでエンドポイントをフィルタする検索文字列。 |

const fetch = require("node-fetch");

async function run() {
  const params = new URLSearchParams({

    {
      method: "GET",
      headers: {
        Accept: "application/json",
        Authorization: `Bearer ${process.env.VERIFIK_JWT}`,

    }
  );

}

### 注記

- シミュレートレスポンスの照会ではライブのカタログ検索は実行されず、クレジットも消費されません。
- 各項目の `code` を [シミュレートレスポンスを取得する](/verifik-ja/smart-reports/retrieve-simulated-response) で使用して、完全な `dataSample` および `emptySample` ペイロードを取得してください。
