ObjectId（`{id}`）を指定して単一の Smart Report テンプレートを取得します。`sections`、`reportTheme`、`sampleData`、ページレイアウト設定、および展開（populate）された `batchConfiguration`・`client` 参照を含むテンプレートの全仕様が返されます。

ヘッドレスおよび AI ワークフローでは、`append` または `edit` モードで [テンプレートレイアウトを生成する](/verifik-ja/smart-reports/generate-template-layout) を呼び出す前に現在の `sections` 配列を読み込んだり、[テンプレート HTML をプレビューする](/verifik-ja/smart-reports/preview-template-html) 用に保存済みの `sampleData` を取得したり、`PUT` 更新を実行する前にテンプレートを確認したりするためにこのエンドポイントを使用します。セキュリティおよびペイロードサイズの効率化のため、このエンドポイントでは `security.password` と `thumbnail.image` は除外されます。

### エンドポイント

```
GET https://api.verifik.co/v2/smart-report-templates/{id}
```

Smart-Agent プロキシ（`https://ai.verifik.co`）も同じ `/v2/...` パスを公開しており、お客様自身の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーが必要です。

### ヘッダー

| 名前 | 値 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string | **はい** | Smart Report テンプレートの ObjectId。 |

### 注記

- テンプレートが存在しない場合や別のクライアントに属している場合、このエンドポイントは `404` ではなく `{ "data": null }` とともに HTTP `200` を返します。
- 返却されるドキュメントからは `security.password` と `thumbnail.image` が除外されます。テンプレートのサムネイルをレンダリングまたは確認するには、[レポートテンプレート一覧を取得する](/verifik-ja/smart-reports/list-report-templates) を使用してください。
