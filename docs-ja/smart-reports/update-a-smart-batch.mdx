認証済みクライアントが所有する既存の `SmartBatch` のフィールドを更新します。`name`、`status`、`executor` の更新、または `rows` の置き換えが可能です。`rows` が指定された場合、サーバーは `totalRows`、`completedRows`、`failedRows`、`partialRows` を再計算し、外部の行スナップショットを同期します。

バッチを `"paused"` に遷移させるには専用の[Smart Batch を一時停止する](/verifik-ja/smart-reports/pause-a-smart-batch)エンドポイントを使用してください。`executor` の変更は、バッチが現在 `"draft"`、`"pending"`、または `"cancelled"` ステータスの場合にのみ有効になります。

### エンドポイント

```text
PUT https://api.verifik.co/v2/smart-batches/{id}
```

このエンドポイントは、クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` を使用することで Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batches/{id}`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type` | `application/json` | リクエストペイロード形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアントスコープの JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| ---- | ------ | ---- | ----------- |
| `id` | string | はい | 更新する `SmartBatch` の ObjectId。 |

### リクエストボディ

| 名前 | 型 | 必須 | 説明 |
| ---------- | -------- | ---- | ----------- |
| `name` | string | いいえ | 更新後のバッチ表示名。最大 `150` 文字。 |
| `status` | string | いいえ | 許可値: `"draft"`、`"pending"`、`"processing"`、`"completed"`、`"failed"`、または `"cancelled"`。`"paused"` には `POST /v2/smart-batches/{id}/pause` を使用してください。 |
| `executor` | string | いいえ | 許可値: `"queue"`、`"featureRunner"`、または `"browser"`。現在のバッチステータスが `"draft"`、`"pending"`、または `"cancelled"` の場合にのみ有効になります。 |
| `rows` | object[] | いいえ | 置き換え用の行リスト。ラップ形式には `rowIndex` と `inputData` が必須で、任意で `status`、`results`、`errors`、`processedAt` を受け付けます。フラットな行は自動的に正規化されます。 |

不明なボディキーは Joi バリデーションにより `409 MissingParameter` で拒否されます。

### 補足

- `"paused"` は `PUT /v2/smart-batches/{id}` では受け付けられません。代わりに[Smart Batch を一時停止する](/verifik-ja/smart-reports/pause-a-smart-batch)を呼び出してください。
- `executor` の更新は、バッチが現在 `"draft"`、`"pending"`、または `"cancelled"` ステータスでない限り無視されます。
- 既存の行を置き換えることなく既存バッチに新しい行を追加するには、[Smart Batch に行を追加する](/verifik-ja/smart-reports/append-smart-batch-rows)を使用してください。
