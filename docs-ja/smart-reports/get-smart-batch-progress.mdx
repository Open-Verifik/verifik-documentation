`rows` 配列全体を転送することなく、`SmartBatch` の軽量な進捗サマリーを取得します。レスポンスには行カウンター（`totalRows`、`completedRows`、`failedRows`、`partialRows`、`pendingRows`）、実行タイムスタンプ、`creditsSpent`、および（`FeatureRunner` 実行に支えられている場合は）ネストされた `run` と台帳の `spend` 詳細が含まれます。

サーバー側の `FeatureRunner` 実行では、`batchConfiguration.notification.webhookUrl` が設定されている場合、完了時に `smart_batch_batch_completed` Webhook イベント（`runId` と `creditsSpent` を含む）も送信されます。このエンドポイントをポーリングしてもクレジットは消費されません。

### エンドポイント

```text
GET https://api.verifik.co/v2/smart-batches/{id}/progress
```

このエンドポイントは、クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` を使用することで Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batches/{id}/progress`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type` | `application/json` | リクエストペイロード形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアントスコープの JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| ---- | ------ | ---- | ----------- |
| `id` | string | はい | ポーリング対象の `SmartBatch` ObjectId。 |

### 補足

- バッチに関連する `FeatureRunner` 実行がある場合に `run` と `spend` が含まれます（参照先の実行レコードが返されない場合、`run` は `null` になります）。
- サーバー側の `FeatureRunner` 実行では、`batchConfiguration.notification.webhookUrl` が設定されている場合、終了時に `smart_batch_batch_completed` Webhook イベント（`runId` と `creditsSpent` 付き）を送信します。[Smart Reports Webhook](/verifik-ja/resources/smart-reports-webhooks)を参照してください。
- バッチが終了ステータスに達したら、[Smart Batch を取得する](/verifik-ja/smart-reports/retrieve-a-smart-batch)を使用して行レベルの `results` と `errors` を確認してください。
