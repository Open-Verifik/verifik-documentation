CSV、XLSX、または JSONL ペイロードを新しい `SmartBatch` に取り込みます。サーバーは生テキストまたは Base64 データ URL をデコードし、`MAX_ROWS`（既定は `20000`）を適用し、`BatchConfiguration` のステップ依存関係に対して列ヘッダーおよびキャメルケースエイリアスを解決した上で、クレジットコスト見積もりを算出します。

受理された行は `pending` ステータスでバッチに保存され、不正な行は `rejectedRows` で返されます。アカウントのエンドポイント権限を検証してすぐに処理を開始するには `autoStart: true` を渡してください。それ以外の場合はチェックは実行されず、クレジットも消費されません。

### エンドポイント

```text
POST https://api.verifik.co/v2/smart-batches/from-file
```

このエンドポイントは、クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` を使用することで Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batches/from-file`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type` | `application/json` | リクエストペイロード形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアントスコープの JWT（`authUser.clientId`）。 |

### リクエストボディ

| 名前 | 型 | 必須 | 説明 |
| -------------------- | ------- | ---- | ----------- |
| `batchConfiguration` | string | はい | 認証済みクライアントが所有する `BatchConfiguration` の ObjectId。 |
| `name` | string | はい | バッチの表示名。最大 `150` 文字。 |
| `content` | string | はい | 生の CSV/JSONL テキスト、または Base64 データ URL（`data:<mime>;base64,<payload>`）。 |
| `format` | string | いいえ | 入力形式: `"csv"`、`"xlsx"`、または `"jsonl"`。既定値は `batchConfiguration.inputFormat` または `"csv"`。 |
| `autoStart` | boolean | いいえ | 取り込み後に作成されたバッチを即座に開始する場合は `true` を指定します。 |

不明なボディキーは Joi バリデーションにより `409 MissingParameter` で拒否されます。

### 補足

- ファイル解析では `MAX_ROWS`（既定 `20000`）が適用され、`Document Number` のような列が `documentNumber` に解決されるようキャメルケースのヘッダーエイリアスが自動生成されます。
- `.xlsx` ワークブックの場合は、`format: "xlsx"` とともに Base64 データ URL（`data:application/vnd.openxmlformats-officedocument.spreadsheetml.sheet;base64,<payload>`）を渡してください。
- `409 Conflict` エラーには、`batch_file_has_no_sheets`、`batch_file_is_empty`、`batch_file_has_no_rows`、`batch_file_has_no_usable_rows`、`batch_jsonl_parse_failed_on_line_<N>`、`batch_configuration_has_no_steps`、および `endpoints_not_in_account` が含まれます。
- 無効な行バリデーション（有効行が `0` 件）、未対応の形式エラー、および `MAX_ROWS` 上限エラーは HTTP `500` を返します。
