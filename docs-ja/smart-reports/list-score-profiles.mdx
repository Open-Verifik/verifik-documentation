Smart Report テンプレート（`reportTheme.scoreProfile`）に設定できる、または [テンプレート HTML をプレビューする](/verifik-ja/smart-reports/preview-template-html)（`scoreProfile`）に渡せる、サポート済みのすべての検証スコアプロファイルを一覧取得します。

ヘッドレス設定 UI や AI エージェントのワークフローでは、スコアリングを有効にする前にこのエンドポイントに照会することで、アプリケーションが `scoreProfile` 識別子を動的に検証でき、HTML プレビューやレポートレンダリング時の `409`（`unknown_score_profile`）エラーを回避できます。利用可能なプロファイルは、ドライバー、本人確認、法人、フリート、車両、融資、医療、生体認証のワークフローをカバーしています。

- `cabify_driver`
- `kyc`
- `kyb`
- `fleet`
- `vehicle_purchase`
- `identity_lookup`
- `background_check`
- `lending`
- `healthcare_professional`
- `biometrics`

### エンドポイント

```
GET https://api.verifik.co/v2/smart-report-templates/score-profiles
```

Smart-Agent プロキシ（`https://ai.verifik.co`）も同じ `/v2/...` パスを公開しており、お客様自身の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーが必要です。

### ヘッダー

| 名前 | 値 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### パラメータ

クエリパラメータおよびパスパラメータは不要です。

### 注記

- テンプレートの作成または更新時には返却された `id` 値を `reportTheme.scoreProfile` に指定し、[テンプレート HTML をプレビューする](/verifik-ja/smart-reports/preview-template-html) では `scoreProfile` として指定してください。
- 認識されない `scoreProfile` を `POST /v2/smart-report-templates/preview-html` に送信すると `409`（`unknown_score_profile`）が返ります。
