精選されたシステム Smart Report プリセットをご自身のクライアントアカウントへ複製します。この操作により `BatchConfiguration` とリンクされた `SmartReportTemplate` の両方が返され、すぐに実行することも、さらにカスタマイズすることもできます。

このエンドポイントはクライアントアカウントに対して**べき等（idempotent）**です。`{systemKey}` から複製された有効なクライアントテンプレートがすでに存在する場合、サーバーはその設定とテンプレートを再利用し（必要に応じてステップの順序を再マッピングし）、`reused: true` を返します。存在しない場合は、新しい `BatchConfiguration`（`inputFormat: "csv"`、`outputFormat: "csv"`、`mergeStrategy: "sequential"`）と、`preferredReportTemplate` でリンクされた新しいクライアント用 `SmartReportTemplate`（`clonedFromSystemKey` に `{systemKey}` を設定）を作成し、`reused: false` を返します。このエンドポイントは `smart_report_clone_preset` MCP ツールとしても公開されています。

### エンドポイント

```
POST https://api.verifik.co/v2/smart-batch-presets/{systemKey}/clone
```

クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーを使用することで、Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batch-presets/{systemKey}/clone`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

トークンは **クライアント JWT** である必要があります。認証情報がないか無効な場合は `401 Unauthorized` を返します。

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| ---- | ---- | ---- | ----------- |
| `systemKey` | string | はい | [レポートプリセット一覧](/verifik-ja/smart-reports/list-report-presets)から取得したプリセットキー。トリム済みで最大 `120` 文字、`/^[a-z0-9][a-z0-9._-]{1,118}$/i` に一致する必要があります。 |

### リクエストボディ

このエンドポイントではリクエストボディは不要です。

### 補足

- プリセットを複製しても照会は実行されず、クレジットも消費されません。
- クライアントアカウントに対して同じ `{systemKey}` でこのエンドポイントを繰り返し呼び出しても安全かつべき等であり、既存の複製済み設定とテンプレートが `reused: true` とともに返されます。
- `{systemKey}` が Joi のパスバリデーションに失敗した場合（例: `120` 文字を超える、または許可されていない文字を含む）は `409 MissingParameter` が返されます。一致したプリセットにステップが設定されていない場合は `409` とともに `preset_has_no_steps` が返されます。
- プリセットに必要な機能がアカウントで利用できない場合、`500 InternalServerError` が発生することがあります。
- 複製後、行を送信する前に `batchConfiguration._id` を指定して[バッチ設定の入力スキーマを取得する](/verifik-ja/smart-reports/retrieve-configuration-input-schema)を呼び出すか、`smart_report_clone_preset` MCP ツールをご利用ください。
