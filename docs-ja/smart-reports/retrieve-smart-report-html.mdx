`SmartReport` のレンダリング済み HTML を、リンクされた `batchId`、`templateId`、`rowIndex`、任意の `verificationScore`、および対応する `row` ペイロード（`rowIndex`、`status`、`inputData`、`results`、`errors`）とともに取得します。

**重要**: このエンドポイントは `Content-Type: application/json` で応答し、生の `text/html` ドキュメントではなく、`data.html` 内に HTML 文字列を返します。

### エンドポイント

```
GET https://api.verifik.co/v2/smart-reports/{id}/html
```

このエンドポイントは、お客様自身のクライアント別 `Authorization: Bearer <VERIFIK_JWT>` を使用して Smart-Agent プロキシ経由の `https://ai.verifik.co/v2/smart-reports/{id}/html` からも利用できます。共有 x402 による実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --- | --- | --- |
| `Accept` | `application/json` | JSON エンベロープ形式のレスポンス。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアント単位の JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 場所 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| `id` | `path` | string | **はい** | `SmartReport` ObjectId。 |
| `rowIndex` | `query` | integer | いいえ | 0 始まりの行インデックス（`>= 0`）。 |
| `preview` | `query` | boolean | いいえ | `true` の場合はプレビューモードでレンダリングします。 |
| `score` | `query` | boolean | いいえ | `verificationScore` を計算して `data` に含めるかどうか。 |
| `scoreProfile` | `query` | string | いいえ | `score` が有効な場合に使用するスコアリングプロファイル識別子（最大 `64` 文字）。 |

```javascript
import axios from "axios";

const run = async () => {
  const id = "6801a2b3c4d5e6f7a8b9c0d1";

      score: true,

    htmlLength: data.data.html.length,

  });
```

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	id := "6801a2b3c4d5e6f7a8b9c0d1"
	params := url.Values{}
	params.Set("rowIndex", "0")
	params.Set("preview", "false")
	params.Set("score", "true")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-reports/"+id+"/html?"+params.Encode(), nil)
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}
```

#### エラーコード

| ステータス | エラーコード / 種別 | 原因 |
| --- | --- | --- |
| `401` | `Unauthorized` | JWT が欠落または無効です。 |
| `403` | `Forbidden` | 共有 x402 による実行が試行されました。クライアント別 JWT を使用してください。 |
| `404` | `not_found` | レポート ID が存在しないか、別のクライアントに属しています。 |
| `404` | `template_not_found` | リンクされたテンプレートが見つかりませんでした。 |
| `409` | `MissingParameter` | クエリまたはパスパラメータで Joi 検証に失敗しました。 |
| `409` | `row_not_found` | 要求された `rowIndex` がバッチ内に存在しません。 |
| `409` | `unknown_score_profile` | 指定された `scoreProfile` が認識されません。 |
| `422` | `UnprocessableEntity` | Mongoose 検証エラーです。 |

### Webhook と MCP 統合

- **MCP 相当ツール**: AI エージェントは `smart_report_get_html` MCP ツール経由でレンダリング済みのレポート HTML と行構造を取得できます。詳細は [MCP と AI エージェント](/verifik-ja/smart-reports/mcp-and-ai-agents) を参照してください。
- **Webhook**: `htmlUrl` パス（`/v2/smart-reports/{id}/html`）は [Smart Report を実行する](/verifik-ja/smart-reports/run-a-smart-report)、[Smart Report を取得する](/verifik-ja/smart-reports/retrieve-a-smart-report)、および [Smart Report PDF を生成する](/verifik-ja/smart-reports/generate-smart-report-pdf) のレスポンスに含まれています。詳細は [SmartReports Webhook](/verifik-ja/resources/smart-reports-webhooks) を参照してください。

### 注記

- HTTP レスポンスは `application/json` を使用するため、WebView、iframe、または PDF レンダラーに埋め込む前に JSON ペイロードから `data.html` を抽出してください。
- `score=true` が渡された場合、`data.verificationScore` が返されます。
- コンテキストにバッチ行オブジェクトが紐付いていない場合、`data.row` は `null` になります。
