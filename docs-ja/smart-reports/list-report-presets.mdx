ご自身のアカウントで利用可能な、精選されたシステム Smart Report プリセットを一覧表示します。各プリセットには、`systemKey`、メタデータ（`country`、`category`、`tier`）、アカウントでの利用可否（`available`）、順序付き `presetSteps`、およびヘッドレス実行や AI エージェント向けに準備された `exampleInput` 付きの解決済み `inputSchema` が含まれます。

解決済みの `inputSchema` では、内部実行パラメータおよび連鎖した `visitaFlow` 依存関係によってすでに供給されるステップ入力が自動的に除外されるため、呼び出し元が提供する必要のあるフィールドのみが残ります。プリセットの一覧取得は読み取り専用のディスカバリー呼び出しであり、クレジットを消費しません。このエンドポイントは `smart_report_list_presets` MCP ツールとしても公開されています。

### エンドポイント

```
GET https://api.verifik.co/v2/smart-batch-presets
```

クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーを使用することで、Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batch-presets`）経由でもアクセスできます。共有 x402 実行はこのルートでは `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

トークンは **クライアント JWT** である必要があります。認証情報がないか無効な場合は `401 Unauthorized` を返します。

### パラメータ

すべてのクエリパラメータは任意です。組み合わせて指定することで、法域、エンティティカテゴリ、ティア、またはキーワードでプリセットを絞り込めます。

| 名前 | 型 | 必須 | 説明 |
| ---- | ---- | ---- | ----------- |
| `country` | string | いいえ | 国コードフィルター。サーバー側でトリムおよび大文字化されます（例: `CO`）。 |
| `category` | string | いいえ | プリセットカテゴリフィルター。許可値: `citizen`、`company`、または `vehicle`。 |
| `tier` | string | いいえ | プリセット深度フィルター。許可値: `essential` または `comprehensive`。 |
| `search` | string | いいえ | `name`、`description`、および `systemKey` に対する大文字・小文字を区別しない正規表現一致。 |
| `text` | string | いいえ | `search` のエイリアス。 |

### 補足

- `country` はフィルター処理の前にトリムおよび大文字化されます（例: `co` は `CO` に一致します）。
- `search` と `text` はどちらも、`name`、`description`、および `systemKey` に対して大文字・小文字を区別しない同じ正規表現一致を実行します。
- `inputSchema.estimatedCreditsPerRow` は、プリセットの有効化されたステップ全体における 1 行あたりの予想クレジットコストを見積もります。
- `available` が `true` の場合、`presetSteps` 内のすべての機能が環境で有効になっており、[レポートプリセットを複製する](/verifik-ja/smart-reports/clone-a-report-preset)でそのまま複製できます。
- AI エージェント連携では、このエンドポイントは `smart_report_list_presets` MCP ツールに対応します。
