`SmartBatch` の単一行（`rowIndex`）に対する構造化された行レポートモデルを構成します。このエンドポイントは、該当行に保存されたステップ出力に対して Verifik の組み込みレポートコンポーザー（`colombia_vehicle`）を実行し、`score` または `scoreProfile` が渡された場合には任意で `verificationScore` を付与します。

バッチの `BatchConfiguration` が組み込みコンポーザーに一致しない場合、このエンドポイントは `409 Conflict`（`no_report_composer_for_configuration`）を返します。任意のカスタムレポートテンプレートについては、代わりに `POST /v2/smart-reports/run`、`GET /v2/smart-reports/{id}/html`、または `/generate` を使用してください。このエンドポイントを読み取ってもクレジットは消費されません。

### エンドポイント

```text
GET https://api.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report
```

このエンドポイントは、クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` を使用することで Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type` | `application/json` | リクエストペイロード形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアントスコープの JWT（`authUser.clientId`）。 |

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
| ---------- | ------ | ---- | ----------- |
| `id` | string | はい | `SmartBatch` の ObjectId。 |
| `rowIndex` | number | はい | バッチ内の行の `0` 始まりインデックス。 |

### クエリパラメータ

| 名前 | 型 | 必須 | 説明 |
| -------------- | ----------------- | ---- | ----------- |
| `score` | boolean または string | いいえ | `true` または `"1"` を渡すと、`verificationScore` を算出してレスポンスに含めます。 |
| `scoreProfile` | string | いいえ | スコアリングプロファイル識別子。`scoreProfile` を指定すると `score` も有効になります。 |

  <TabItem value="node" label="Node.js">

```javascript
import axios from "axios";

const run = async () => {
  const batchId = "6801a2b3c4d5e6f7a8b9c0d3";
  const rowIndex = 0;

  const { data } = await axios.get(
    `https://api.verifik.co/v2/smart-batches/${batchId}/rows/${rowIndex}/report`,
    {
      params: {
        score: true,
        scoreProfile: "fleet_standard",
      },
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${process.env.VERIFIK_JWT}`,
      },
    }
  );

  console.log(data);
};

run();
```

  <TabItem value="go" label="Go">

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	rowIndex := "0"
	params := url.Values{}
	params.Set("score", "true")
	params.Set("scoreProfile", "fleet_standard")

	endpoint := fmt.Sprintf("https://api.verifik.co/v2/smart-batches/%s/rows/%s/report?%s", batchID, rowIndex, params.Encode())
	req, _ := http.NewRequest("GET", endpoint, nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}
```

### 補足

- このエンドポイントは組み込みの構成行レポート（`colombia_vehicle`）のみを提供します。その他の設定では `409 Conflict`（`no_report_composer_for_configuration`）が返されます。
- 任意の設定でカスタムテンプレート、テーマ付き HTML レンダリング、または PDF ドシエを利用する場合は、`POST /v2/smart-reports/run`、`GET /v2/smart-reports/{id}/html`、または `/generate` を使用してください（[Smart Report を実行する](/verifik-ja/smart-reports/run-a-smart-report)を参照）。
- `score=true`、`score=1`、または `scoreProfile` を指定しない限り、`verificationScore` は省略されます。
