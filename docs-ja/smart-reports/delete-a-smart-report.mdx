認証済みクライアントに属する `SmartReport` レコードを削除します。成功すると、API は削除された `SmartReport` ドキュメントを `{ "data": ... }` 内に返します。

レポート ID が存在しない、または別のクライアントに属している場合、このエンドポイントは `404 Not Found`（`{ "message": "not_found", "code": "NotFound" }`）を返します。レポートを削除すると `SmartReport` ドキュメントが削除されますが、基盤となる `SmartBatch` の検証データは削除されません。

### エンドポイント

```
DELETE https://api.verifik.co/v2/smart-reports/{id}
```

このエンドポイントは、お客様自身のクライアント別 `Authorization: Bearer <VERIFIK_JWT>` を使用して Smart-Agent プロキシ経由の `https://ai.verifik.co/v2/smart-reports/{id}` からも利用できます。共有 x402 による実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --- | --- | --- |
| `Content-Type` | `application/json` | リクエストペイロードの形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアント単位の JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string | **はい** | 削除対象の `SmartReport` ObjectId。 |

### 注記

- 削除後の `GET /v2/smart-reports/{id}` 呼び出しは `{ "data": null }` を返し、`PUT`、`DELETE`、`/generate`、`/download`、`/html`、および `/send-email` は `404`（`not_found`）を返します。
- `SmartReport` を削除しても、レポート配信または生成の Webhook は発行されません。ライフサイクルの自動化の詳細については、[SmartReports Webhook](/verifik-ja/resources/smart-reports-webhooks) および [MCP と AI エージェント](/verifik-ja/smart-reports/mcp-and-ai-agents) を参照してください。
