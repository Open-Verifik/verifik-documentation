行を送信する前に、保存済み `BatchConfiguration` の正確な入力コントラクトを解決します。このエンドポイントは、`preferredReportTemplate`（未設定の場合は設定にリンクされた最新の有効な `SmartReportTemplate` にフォールバック）、`webhookUrl`、`stepCount`、`estimatedCreditsPerRow`、`requiredFields`、`optionalFields`、標準の `jsonSchema`、およびすぐに送信できる `exampleInput` ペイロードを返します。

リゾルバーは無効化されたステップ、非アクティブな `dependencyGroup` オプション、内部フラグ、および `parameterDefaults` や `visitaFlow` ステップ連鎖（`{{results.N.field}}`）によってすでに供給されているフィールドを自動的にスキップし、`inputFieldMapping` に従って列名を再マッピングします。このルートは `/{id}` より前に登録されているため `/input-schema` が直接解決され、`smart_report_get_input_schema` MCP ツールとしても利用できます。

### エンドポイント

```
GET https://api.verifik.co/v2/batch-configurations/{id}/input-schema
```

クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーを使用することで、Smart-Agent プロキシ（`https://ai.verifik.co/v2/batch-configurations/{id}/input-schema`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

トークンは **クライアント JWT** である必要があります。認証情報がないか無効な場合は `401 Unauthorized` を返します。

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| ---- | ---- | ---- | ----------- |
| `id` | string | はい | 確認する `BatchConfiguration` の ObjectId。 |

### 補足

- 入力スキーマを確認しても照会は実行されず、クレジットも消費されません。
- 設定上で `preferredReportTemplate` が未設定の場合、サーバーは `{id}` にリンクされた最新の有効な `SmartReportTemplate` にフォールバックします（存在しない場合は `null`）。
- `inputFieldMapping` によって入力列が API パラメータにマッピングされている場合、`requiredFields`、`optionalFields`、`jsonSchema`、および `exampleInput` は生の API パラメータ名ではなくマッピング後の入力列名を公開します。
- 存在しない `{id}` や他クライアントの `{id}` を指定した場合、HTTP `200` と `data: null` を返す[バッチ設定を取得する](/verifik-ja/smart-reports/retrieve-a-batch-configuration)とは異なり、`404`（`not_found`）が返されます。
- AI エージェントおよびヘッドレスパイプラインでは、このエンドポイントは `smart_report_get_input_schema` MCP ツールに対応します。
