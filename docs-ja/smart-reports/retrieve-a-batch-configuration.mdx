ObjectId（`{id}`）によって単一の `BatchConfiguration` を取得します。検索は認証済みクライアント JWT にスコープされ、アカウントの `ClientFeature` 価格情報が付与された展開済みの `steps.appFeature` 詳細を返します。

一致する設定が存在しないか、ID が別のクライアントアカウントに属している場合、エンドポイントは HTTP `200` と `data: null` を返します。設定の読み取りは照会を実行せず、クレジットも消費しません。

### エンドポイント

```
GET https://api.verifik.co/v2/batch-configurations/{id}
```

クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーを使用することで、Smart-Agent プロキシ（`https://ai.verifik.co/v2/batch-configurations/{id}`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

トークンは **クライアント JWT** である必要があります。認証情報がないか無効な場合は `401 Unauthorized` を返します。

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| ---- | ---- | ---- | ----------- |
| `id` | string | はい | 作成・複製・一覧取得から得た `BatchConfiguration` の ObjectId。 |

### 補足

- `{id}` が存在しないか、別のクライアントアカウントに属している場合、このエンドポイントは HTTP `200` と `{ "data": null }` を返します。
- 統合コードでは `data` のプロパティを読み取る前に `data !== null` を確認してください。
- 設定の解決済み必須／任意入力および `exampleInput` ペイロードを確認するには、[バッチ設定の入力スキーマを取得する](/verifik-ja/smart-reports/retrieve-configuration-input-schema)を呼び出してください。
