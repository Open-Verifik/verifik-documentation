クライアントアカウントが所有する `BatchConfiguration` を削除します。このエンドポイントは設定ドキュメントを削除し、削除されたドキュメントを `data` に返します。

`{id}` が存在しないか別のクライアントアカウントに属している場合、エンドポイントは `404`（`not_found`）を返します。設定を削除しても照会は実行されず、クレジットも消費されません。

### エンドポイント

```
DELETE https://api.verifik.co/v2/batch-configurations/{id}
```

クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーを使用することで、Smart-Agent プロキシ（`https://ai.verifik.co/v2/batch-configurations/{id}`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

トークンは **クライアント JWT** である必要があります。認証情報がないか無効な場合は `401 Unauthorized` を返します。

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| ---- | ---- | ---- | ----------- |
| `id` | string | はい | 削除する `BatchConfiguration` の ObjectId。 |

### 補足

- 設定を削除すると、`data` 内に削除されたドキュメントが返されます。その後同じ `{id}` に対して `GET`、`PUT`、または `DELETE` リクエストを行ってもレコードは見つかりません（`GET` は `data: null` を返し、`GET /input-schema`、`PUT`、`DELETE` は `404` `not_found` を返します）。
- 設定を削除してもクレジットは消費されません。
