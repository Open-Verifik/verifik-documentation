クライアントアカウントが所有するカスタム Smart Report テンプレートを更新します。更新可能なメタデータ、レイアウト `sections`、`reportTheme`、`sampleData`、または PDF レンダリングオプションの任意のサブセットを送信してください。ペイロードから省略されたフィールドは既存の値が維持されます。

ヘッドレスおよび AI パイプラインでは、[テンプレートレイアウトを生成する](/verifik-ja/smart-reports/generate-template-layout) で生成したレイアウトの反復調整、ブランドアセット（`logo`、`primaryColor`、`customFonts`）の更新、`SmartBatch` バインディングの更新、または `isActive` の切り替えにこのエンドポイントを使用します。組み込みの `"System"` テンプレートは読み取り専用であり、対象として指定すると `403`（`system_template_readonly`）が返されます。

### エンドポイント

```
PUT https://api.verifik.co/v2/smart-report-templates/{id}
```

Smart-Agent プロキシ（`https://ai.verifik.co`）も同じ `/v2/...` パスを公開しており、お客様自身の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーが必要です。

### ヘッダー

| 名前 | 値 |
| --- | --- |
| Content-Type | `application/json` |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string | **はい** | Smart Report テンプレートの ObjectId。 |

### ボディ

更新時、すべてのボディフィールドは任意です。

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `name` | string | いいえ | 更新後のテンプレート表示名。最大 `150` 文字。 |
| `description` | string | いいえ | 更新後のテンプレート説明。最大 `500` 文字。 |
| `batchConfiguration` | string | いいえ | 関連付ける `SmartBatch` 設定の ObjectId。 |
| `country` | string | いいえ | 国の識別子またはラベル。最大 `60` 文字。 |
| `category` | string | いいえ | 検証ドメイン: `"citizen"`、`"company"`、または `"vehicle"`。 |
| `isActive` | boolean | いいえ | テンプレートを有効または無効にします。 |
| `logo` | string | いいえ | ブランドロゴの URL または base64 データ URI。 |
| `primaryColor` | string | いいえ | メインブランドアクセントの 16 進カラーコード。 |
| `identityColor` | string | いいえ | セカンダリ/アイデンティティアクセントの 16 進カラーコード。 |
| `pageBackgroundColor` | string | いいえ | ページ背景の 16 進カラーコード。 |
| `header` | object | いいえ | カスタムヘッダーのレイアウトおよびコンテンツ設定。 |
| `footer` | object | いいえ | カスタムフッターのレイアウトおよびコンテンツ設定。 |
| `legend` | string | いいえ | フッターの凡例またはコンプライアンス注記テキスト。最大 `2000` 文字。 |
| `legendPosition` | string | いいえ | 凡例の配置: `"left"`、`"center"`、または `"right"`。 |
| `termsAndConditions` | string | いいえ | 法的利用規約テキスト。最大 `4000` 文字。 |
| `termsPosition` | string | いいえ | 利用規約の配置: `"left"`、`"center"`、または `"right"`。 |
| `sections` | object[] | いいえ | `ReportSection` オブジェクトの配列（`id`、`type`、`order`、`dataPath`、`label`、`staticContent`、`columns`、`columnsPerRow`、`keyOverrides`、`valueRules`、`chartKind`、`style`、`condition`、`frame` など）。 |
| `pageSize` | string | いいえ | PDF 用紙サイズ: `"A4"`、`"Letter"`、または `"Legal"`。 |
| `layoutVersion` | integer | いいえ | レイアウトレンダラーバージョン: `1` または `2`。 |
| `orientation` | string | いいえ | ページの向き: `"portrait"` または `"landscape"`。 |
| `margins` | object | いいえ | 余白オブジェクト `` `{ "top": 40, "right": 40, "bottom": 40, "left": 40 }` ``。 |
| `pdfEngine` | string | いいえ | PDF レンダリングエンジン: `"puppeteer"` または `"pdfkit"`。 |
| `showPageNumbers` | boolean | いいえ | レンダリングされた PDF にページ番号を表示します。 |
| `pageNumberPosition` | string | いいえ | ページ番号の位置: `"top-left"`、`"top-center"`、`"top-right"`、`"bottom-left"`、`"bottom-center"`、または `"bottom-right"`。 |
| `pageNumberDivider` | boolean / string | いいえ | ページ番号の区切り線設定。 |
| `watermark` | object | いいえ | 透かしオーバーレイの設定。 |
| `security` | object | いいえ | PDF 保護設定 `` `{ "enabled": true, "password": "..." }` ``。`"******"` を渡すか `password` を省略すると、既存の暗号化済みパスワードが保持されます。 |
| `signature` | object | いいえ | 署名ブロックの設定。 |
| `logoSettings` | object | いいえ | ロゴのサイズおよび配置設定。 |
| `sheetImages` | object[] | いいえ | 埋め込みテンプレート画像アセット。最大 `12` 件。 |
| `customFonts` | object[] | いいえ | カスタムフォント定義（Google Fonts、外部 URL、またはアップロード済みファイル）。最大 `6` 件。 |
| `headerLogos` | object[] | いいえ | ヘッダーに表示する追加ロゴ。最大 `16` 件。 |
| `bodyTopPadding` | number | いいえ | ドキュメント本文の上部パディング（`0`〜`600`）。 |
| `sampleData` | object | いいえ | プレビューやサンプルダウンロード用にテンプレートと一緒に保存されるサンプル検証ペイロード。 |
| `endpointDesign` | object | いいえ | エンドポイント固有のプレゼンテーションメタデータ。 |
| `reportTheme` | string / object | いいえ | テーマプリセット ID（`"premium_dark"`、`"light_cards"`、`"editorial"`、`"dashboard"`）または設定オブジェクト（`id`、`scoreScale`、`scoreEnabled`、`scoreProfile`、`locale`、`density`、`eyebrow`、`coverTitle`、`headlines`、`legalNote`、`showVerifiedBadge`、`showWeights`、`showDeductions`、`showFields`、`showHowItWorks`、`blocks`、`tokens`）。 |

### 注記

- `security.password: "******"` を渡すか `password` を省略すると、上書きする代わりにテンプレートの既存の暗号化済みパスワードが保持されます。
- 組み込みの `"System"` テンプレートは更新できません（`403` `system_template_readonly`）。システムスターターをカスタマイズする場合は、[レポートテンプレートを作成する](/verifik-ja/smart-reports/create-a-report-template) を使用してカスタムコピーを作成してください。
- 変更を保存する際は、プレビュー用ヘルパー（`scoreScale`、`themeTokens`、`scoreSettings`）を `reportTheme` 配下（`scoreScale`、`tokens`、`scoreEnabled`/`scoreProfile`）に格納してください。
