認証済みクライアントが所有するカスタム Smart Report テンプレートを作成します。必須項目は `name` のみです。すべてのブランディング、レイアウト `sections`、`reportTheme`、`sampleData`、および PDF エンジンオプションは任意であり、後から [レポートテンプレートを更新する](/verifik-ja/smart-reports/update-a-report-template) で更新できます。

ヘッドレスおよび AI 駆動のパイプラインでは、[テンプレートレイアウトを生成する](/verifik-ja/smart-reports/generate-template-layout) で生成したレイアウトを永続化したり、[テーマスターター一覧を取得する](/verifik-ja/smart-reports/list-theme-starters) の組み込みスターターを複製してブランド設定を行ったり、コードから `SmartBatch` パイプライン向けの環境別 PDF テンプレートをプロビジョニングしたりするためにこのエンドポイントを使用します。テンプレートを保存すると非同期のサムネイル生成がトリガーされ、作成されたドキュメントを `{ "data": ... }` 内に含めて **HTTP `200`**（`201` ではありません）が返されます。

### エンドポイント

```
POST https://api.verifik.co/v2/smart-report-templates
```

Smart-Agent プロキシ（`https://ai.verifik.co`）も同じ `/v2/...` パスを公開しており、お客様自身の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーが必要です。

### ヘッダー

| 名前 | 値 |
| --- | --- |
| Content-Type | `application/json` |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### ボディ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `name` | string | **はい** | テンプレートの表示名。最大 `150` 文字。 |
| `description` | string | いいえ | テンプレートの人間可読な説明。最大 `500` 文字。 |
| `batchConfiguration` | string | いいえ | 関連付ける `SmartBatch` 設定の ObjectId。 |
| `country` | string | いいえ | 国の識別子またはラベル。最大 `60` 文字。 |
| `category` | string | いいえ | 検証ドメイン: `"citizen"`、`"company"`、または `"vehicle"`。 |
| `isActive` | boolean | いいえ | テンプレートを有効にするかどうか。デフォルトは `true` です。 |
| `logo` | string | いいえ | ブランドロゴの URL または base64 データ URI。 |
| `primaryColor` | string | いいえ | メインブランドアクセントの 16 進カラーコード。デフォルトは `"#4F46E5"` です。 |
| `identityColor` | string | いいえ | セカンダリ/アイデンティティアクセントの 16 進カラーコード。デフォルトは `"#000000"` です。 |
| `pageBackgroundColor` | string | いいえ | ページ背景の 16 進カラーコード。デフォルトは `"#ffffff"` です。 |
| `header` | object | いいえ | カスタムヘッダーのレイアウトおよびコンテンツ設定。 |
| `footer` | object | いいえ | カスタムフッターのレイアウトおよびコンテンツ設定。 |
| `legend` | string | いいえ | フッターの凡例またはコンプライアンス注記テキスト。最大 `2000` 文字。 |
| `legendPosition` | string | いいえ | 凡例の配置: `"left"`、`"center"`、または `"right"`。 |
| `termsAndConditions` | string | いいえ | 法的利用規約テキスト。最大 `4000` 文字。 |
| `termsPosition` | string | いいえ | 利用規約の配置: `"left"`、`"center"`、または `"right"`。 |
| `sections` | object[] | いいえ | コンテンツブロックとデータバインディングを定義する `ReportSection` オブジェクトの順序付き配列（[`ReportSection` のプロパティ](#reportsection-のプロパティ) を参照）。 |
| `pageSize` | string | いいえ | PDF 用紙サイズ: `"A4"`、`"Letter"`、または `"Legal"`。デフォルトは `"A4"` です。 |
| `layoutVersion` | integer | いいえ | レイアウトレンダラーバージョン: `1` または `2`。 |
| `orientation` | string | いいえ | ページの向き: `"portrait"` または `"landscape"`。デフォルトは `"portrait"` です。 |
| `margins` | object | いいえ | 余白オブジェクト `` `{ "top": 40, "right": 40, "bottom": 40, "left": 40 }` ``。デフォルトは四辺すべて `40` です。 |
| `pdfEngine` | string | いいえ | PDF レンダリングエンジン: `"puppeteer"` または `"pdfkit"`。デフォルトは `"puppeteer"` です。 |
| `showPageNumbers` | boolean | いいえ | レンダリングされた PDF にページ番号を表示します。 |
| `pageNumberPosition` | string | いいえ | ページ番号の位置: `"top-left"`、`"top-center"`、`"top-right"`、`"bottom-left"`、`"bottom-center"`、または `"bottom-right"`。 |
| `pageNumberDivider` | boolean / string | いいえ | ページ番号の区切り線設定。 |
| `watermark` | object | いいえ | 透かしオーバーレイの設定。 |
| `security` | object | いいえ | PDF 暗号化設定 `` `{ "enabled": true, "password": "..." }` ``。 |
| `signature` | object | いいえ | 署名ブロックの設定。 |
| `logoSettings` | object | いいえ | ロゴのサイズおよび配置設定。 |
| `sheetImages` | object[] | いいえ | 埋め込みテンプレート画像アセット。最大 `12` 件。 |
| `customFonts` | object[] | いいえ | カスタムフォント定義（Google Fonts、外部 URL、またはアップロード済みファイル）。最大 `6` 件。 |
| `headerLogos` | object[] | いいえ | ヘッダーに表示する追加ロゴ。最大 `16` 件。 |
| `bodyTopPadding` | number | いいえ | ドキュメント本文の上部パディング（`0`〜`600`）。 |
| `sampleData` | object | いいえ | プレビューやサンプルダウンロードのフォールバックデータセットとして使用されるサンプル検証ペイロード（`inputData`、`results`、`batchName`、`rowIndex`）。 |
| `endpointDesign` | object | いいえ | エンドポイント固有のプレゼンテーションメタデータ。 |
| `reportTheme` | string / object | いいえ | テーマプリセット ID（`"premium_dark"`、`"light_cards"`、`"editorial"`、`"dashboard"`）または完全なテーマ設定オブジェクト（[テーマ設定](#テーマ設定) を参照）。 |

#### `ReportSection` のプロパティ

`sections` の各要素はレポート内の 1 つのブロックを表します。共通プロパティには `id`、`type`、`order`、`dataPath`、`label`、`staticContent`、`columns`、`columnsPerRow`、`keyOverrides`、`valueRules`、`chartKind`、`style`、`condition`、および `frame` があります。

サポートされる `type` の値：

- **基本レイアウト**: `header`、`text`、`table`、`field`、`image`、`divider`、`spacer`、`shape`
- **構造化ブロック**: `dataTable`、`card`、`badge`、`keyValueGrid`、`repeater`、`reportBlocks`、`themeBlock`
- **テーマ付き検証ブロック**: `coverPage`、`scoreGauge`、`categoryBreakdown`、`checkTable`、`findings`、`sources`、`sourceCards`

#### テーマ設定

`reportTheme` はプリセット文字列（`"premium_dark"`、`"light_cards"`、`"editorial"`、`"dashboard"`）または以下のプロパティを含むオブジェクトを受け付けます：

`{ id, scoreScale, scoreEnabled, scoreProfile, locale, density, eyebrow, coverTitle, headlines, legalNote, showVerifiedBadge, showWeights, showDeductions, showFields, showHowItWorks, blocks, tokens }`

[テンプレート HTML をプレビューする](/verifik-ja/smart-reports/preview-template-html) でテストしたペイロードを移行する場合は、保存する前にトップレベルのプレビュー用ヘルパー（`scoreScale`、`themeTokens`、`scoreSettings`）を `reportTheme` 内（`reportTheme.scoreScale`、`reportTheme.tokens`、`reportTheme.scoreEnabled`、`reportTheme.scoreProfile`）へ移動してください。

### 注記

- 作成に成功すると HTTP **`200`**（`201` ではありません）が返され、バックグラウンドで非同期のサムネイル生成がトリガーされます。
- [テンプレート HTML をプレビューする](/verifik-ja/smart-reports/preview-template-html) で使用されるトップレベルのプレビュー用ヘルパー（`scoreScale`、`themeTokens`、`scoreSettings`）は、トップレベルのテンプレートフィールドとしては保存されません。テンプレートを永続化する際は、これらを `reportTheme` 内（`scoreScale`、`tokens`、`scoreEnabled`/`scoreProfile`）に配置してください。
- 返された `_id` を保存しておくと、サンプル PDF のレンダリング、関係者へのプレビュー送信、自動化された `SmartBatch` ジョブへのテンプレート紐付けに使用できます。
