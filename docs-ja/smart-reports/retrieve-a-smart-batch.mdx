認証済みクライアント向けに ID で単一の `SmartBatch` ドキュメントを取得します。ペイロードを返す前に、サーバーは外部に保存されたすべての `smartbatchrows` 出力を `rows[].results` にマージし、`healIncompleteRows()` を実行して、有効化された設定ステップが欠落している `completed` マーク済みの行を再オープンします。

バッチが存在しないか別のクライアントアカウントに属している場合、エンドポイントは `200` と `{ "data": null }` を返します。バッチの読み取りはチェックを実行せず、クレジットも消費しません。

### エンドポイント

```text
GET https://api.verifik.co/v2/smart-batches/{id}
```

このエンドポイントは、クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` を使用することで Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batches/{id}`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type` | `application/json` | リクエストペイロード形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアントスコープの JWT（`authUser.clientId`）。 |

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
| ---- | ------ | ---- | ----------- |
| `id` | string | はい | `SmartBatch` の ObjectId。 |

### クエリパラメータ

| 名前 | 型 | 必須 | 説明 |
| ------------- | -------- | ---- | ----------- |
| `select` | string | いいえ | フィールド射影式（例: 行ペイロードを除外する `"-rows"`）。 |
| `columns` | string | いいえ | 返されるドキュメントに含めるフィールドのサブセット。 |
| `populates[]` | string[] | いいえ | 展開する関連ドキュメント: `"batchConfiguration"` および／または `"client"`。 |

package main

import (

func main() {

	resp, _ := http.DefaultClient.Do(req)

}

### 補足

- 外部の `smartbatchrows` ステップ結果は、バッチの読み取り時に `rows[].results` へ自動的にマージされます。
- `healIncompleteRows()` は、有効化された `batchConfiguration` ステップに対して各 `completed` 行を検査し、ステップ出力またはエラーが欠落している行を `pending` へ再オープンします。
- 頻繁なステータスポーリングを行う場合は、完全な行ペイロードを繰り返し取得するのを避けるため、[Smart Batch の進捗を取得する](/verifik-ja/smart-reports/get-smart-batch-progress)を優先して使用してください。
