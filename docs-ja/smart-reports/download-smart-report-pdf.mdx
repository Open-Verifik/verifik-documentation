`SmartReport` のレンダリング済み PDF ファイルをバイナリストリーム（`Content-Type: application/pdf`）としてダウンロードします。バックエンド、ポータル、または統合システムで、[Smart Report PDF を生成する](/verifik-ja/smart-reports/generate-smart-report-pdf) が返す base64 JSON エンベロープではなく生の PDF バイト列が必要な場合にこのエンドポイントを使用してください。

任意の `rowIndex` クエリパラメータにより、リンクされた `SmartBatch` 内のどの行をレンダリングまたはダウンロードするかを選択できます。`rowIndex` を省略した場合、エンドポイントは `SmartReport` 上の `dataSnapshot.rowIndex` にフォールバックし、さらに `0` にフォールバックします。

### エンドポイント

```
GET https://api.verifik.co/v2/smart-reports/{id}/download
```

このエンドポイントは、お客様自身のクライアント別 `Authorization: Bearer <VERIFIK_JWT>` を使用して Smart-Agent プロキシ経由の `https://ai.verifik.co/v2/smart-reports/{id}/download` からも利用できます。共有 x402 による実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --- | --- | --- |
| `Accept` | `application/pdf` | バイナリ PDF レスポンスストリーム。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアント単位の JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 場所 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| `id` | `path` | string | **はい** | `SmartReport` ObjectId。 |
| `rowIndex` | `query` | number | いいえ | ダウンロードする 0 始まりの行インデックス。`dataSnapshot.rowIndex`、次いで `0` にフォールバックします。 |

### リクエスト

このエンドポイントは JSON ではなく生のバイナリ PDF バイト列をストリーム配信するため、HTTP クライアントは JSON としてパースせずバイナリバッファとして読み取るように設定してください。

  <TabItem value="node" label="Node.js">

```javascript
import fs from "fs";
import axios from "axios";

const run = async () => {
  const id = "6801a2b3c4d5e6f7a8b9c0d1";
  const response = await axios.get(`https://api.verifik.co/v2/smart-reports/${id}/download`, {
    params: { rowIndex: 0 },
    responseType: "arraybuffer",
    headers: {
      Accept: "application/pdf",
      Authorization: `Bearer ${process.env.VERIFIK_JWT}`,
    },
  });

  fs.writeFileSync("report.pdf", Buffer.from(response.data));
  console.log(`Saved report.pdf (${response.data.byteLength} bytes)`);
};

run();
```

import os
import requests

report_id = "6801a2b3c4d5e6f7a8b9c0d1"
url = f"https://api.verifik.co/v2/smart-reports/{report_id}/download"
headers = {
    "Accept": "application/pdf",
    "Authorization": f"Bearer {os.getenv('VERIFIK_JWT')}",

params = {"rowIndex": 0}

resp = requests.get(url, params=params, headers=headers)
resp.raise_for_status()

with open("report.pdf", "wb") as f:
    f.write(resp.content)

print(f"Saved report.pdf ({len(resp.content)} bytes)")

  <TabItem value="go" label="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"os"
)

func main() {
	id := "6801a2b3c4d5e6f7a8b9c0d1"
	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-reports/"+id+"/download?rowIndex=0", nil)
	req.Header.Set("Accept", "application/pdf")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	pdfBytes, err := io.ReadAll(resp.Body)
	if err != nil {
		panic(err)
	}

	if resp.StatusCode != http.StatusOK {
		fmt.Printf("Download failed (%d): %s\n", resp.StatusCode, string(pdfBytes))
		return
	}

	if err := os.WriteFile("report.pdf", pdfBytes, 0644); err != nil {
		panic(err)
	}
	fmt.Printf("Saved report.pdf (%d bytes)\n", len(pdfBytes))
}
```

#### レスポンスヘッダー（`200 OK`）

| ヘッダー | 値 / 形式 | 説明 |
| --- | --- | --- |
| `Content-Type` | `application/pdf` | バイナリ PDF の MIME タイプ。 |
| `Content-Disposition` | `attachment; filename="Consulta_<rowIndex+1>.pdf"` | 1 始まりの行番号を使用した添付ファイル名（例: `rowIndex: 0` の場合は `Consulta_1.pdf`）。 |
| `Content-Length` | 整数のバイト長 | ストリーム配信される PDF の正確なバイトサイズ。 |

#### エラーコード

| ステータス | エラーコード / 種別 | 原因 |
| --- | --- | --- |
| `401` | `Unauthorized` | JWT が欠落または無効です。 |
| `403` | `Forbidden` | 共有 x402 による実行が試行されました。クライアント別 JWT を使用してください。 |
| `404` | `not_found` | レポート ID が存在しないか、別のクライアントに属しています。 |
| `404` | `template_not_found` | リンクされたテンプレートが見つかりませんでした。 |
| `409` | `MissingParameter` | クエリまたはパスパラメータで Joi 検証に失敗しました。 |
| `409` | `row_not_found` | 解決された `rowIndex` がバッチ内に存在しません。 |
| `422` | `UnprocessableEntity` | Mongoose 検証エラーです。 |
