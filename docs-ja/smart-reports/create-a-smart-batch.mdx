既存の `BatchConfiguration` にリンクされた `SmartBatch` を作成します。表示用の `name` と、`rows` に少なくとも 1 行の入力行を指定します。バッチを作成すると入力行が `status: "draft"` で永続化され、実行が開始されるまでカタログステップの実行やクレジット消費は行われません。

`rows` の各エントリは、ラップされたオブジェクト（`{ rowIndex?, inputData }`）またはフラットなオブジェクト（`{ rowIndex?, ...inputFields }`）のいずれかを受け付け、バリデーション層が `{ rowIndex, inputData }` に正規化します。作成時には `status`、`results`、`errors` を**含めないでください**。

### エンドポイント

```text
POST https://api.verifik.co/v2/smart-batches
```

このエンドポイントは、クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` を使用することで Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batches`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type` | `application/json` | リクエストペイロード形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアントスコープの JWT（`authUser.clientId`）。 |

### リクエストボディ

| 名前 | 型 | 必須 | 説明 |
| -------------------- | -------- | ---- | ----------- |
| `batchConfiguration` | string | はい | ワークフローステップを定義する `BatchConfiguration` の ObjectId。 |
| `name` | string | はい | バッチの表示名。最大 `150` 文字。 |
| `executor` | string | いいえ | 実行モード: `"queue"`、`"featureRunner"`、または `"browser"`。`batchConfiguration` から導出される場合は `"queue"` または `"browser"` に正規化されます。 |
| `source` | string | いいえ | 呼び出し元プロダクト識別子: `"smart_batch"`（既定）または `"smart_fleet"`。 |
| `rows` | object[] | はい | 少なくとも `1` 行を含む配列（`min 1`）。ラップ形式 `{ rowIndex?, inputData }` またはフラット形式 `{ rowIndex?, ...inputFields }` を受け付けます。作成時に `status`、`results`、`errors` を送信**しないでください**。 |

不明なキーや許可されていない行プロパティ（`status`、`results`、`errors`）は Joi バリデーションにより `409 MissingParameter` で拒否されます。

### 補足

- バッチ作成時に `rows` 内に `status`、`results`、`errors` を絶対に渡さないでください。新しく作成された行は常に `pending` ステータスで開始します。
- `executor` を省略した場合、`batchConfiguration.executor` から解決され、`"queue"` または `"browser"` に正規化されます。
- 作成後は、[Smart Batch のコストを見積もる](/verifik-ja/smart-reports/estimate-smart-batch-cost)を呼び出してクレジット請求額を事前確認し、[Smart Batch を開始する](/verifik-ja/smart-reports/start-a-smart-batch)で処理を開始してください。
- 依存関係バリデーションや任意の即時実行を伴う CSV、XLSX、または JSONL の一括インポートには、[ファイルから Smart Batch を作成する](/verifik-ja/smart-reports/create-smart-batch-from-file)をご利用ください。
