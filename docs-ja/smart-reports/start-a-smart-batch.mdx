既存の `SmartBatch` の実行を開始します。バッチは現在 `"draft"`、`"pending"`、または `"cancelled"` ステータスである必要があり、それ以外のステータスの場合は `400 BadRequest`（`batch_not_in_startable_state`）で失敗します。

開始前に、サーバーはリンクされた `BatchConfiguration` 内の有効化されたすべてのステップがクライアントアカウントに付与されているか検証し（いずれかの機能が不足している場合は `409 endpoints_not_in_account`）、`status: "processing"` と `startedAt` を設定して更新された `SmartBatch` を返します。

### エンドポイント

```text
POST https://api.verifik.co/v2/smart-batches/{id}/start
```

このエンドポイントは、クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` を使用することで Smart-Agent プロキシ（`https://ai.verifik.co/v2/smart-batches/{id}/start`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --------------- | ---------------------- | ---------------------------------------- |
| `Content-Type` | `application/json` | リクエストペイロード形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアントスコープの JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| ---- | ------ | ---- | ----------- |
| `id` | string | はい | 開始する `SmartBatch` の ObjectId。 |

### 補足

- `"draft"`、`"pending"`、または `"cancelled"` ステータスのバッチのみ開始できます。一時停止されたバッチには[Smart Batch を再開する](/verifik-ja/smart-reports/resume-a-smart-batch)を使用してください。
- `"cancelled"` のバッチを再開始すると、`completedAt` がクリアされ、`"processing"` のまま残っていた行は `"pending"` にリセットされます。
- 事前に[Smart Batch のコストを見積もる](/verifik-ja/smart-reports/estimate-smart-batch-cost)で予想クレジット請求額を確認し、[Smart Batch の進捗を取得する](/verifik-ja/smart-reports/get-smart-batch-progress)で実行を監視してください。
