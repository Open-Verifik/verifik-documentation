認証済みクライアントに属する既存の `SmartReport` を更新します。変更したいフィールドのみを送信してください。リクエストから省略されたフィールドは変更されずに保持されます。

レポート ID が存在しない、または別のクライアントに属している場合、このエンドポイントは `404 Not Found`（`{ "message": "not_found", "code": "NotFound" }`）を返します。

### エンドポイント

```
PUT https://api.verifik.co/v2/smart-reports/{id}
```

このエンドポイントは、お客様自身のクライアント別 `Authorization: Bearer <VERIFIK_JWT>` を使用して Smart-Agent プロキシ経由の `https://ai.verifik.co/v2/smart-reports/{id}` からも利用できます。共有 x402 による実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --- | --- | --- |
| `Content-Type` | `application/json` | リクエストペイロードの形式。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアント単位の JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string | **はい** | 更新対象の `SmartReport` ObjectId。 |

### ボディ

ボディのフィールドはすべて任意です。更新したい属性のみを指定してください。

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `name` | string | いいえ | レポートの表示名。 |
| `status` | string | いいえ | レポートのステータス: `"draft"`、`"generating"`、`"generated"`、`"sent"`、または `"failed"`。 |
| `pdfUrl` | string | いいえ | 生成された PDF アーティファクトの保存先 URL。 |
| `pdfSize` | number | いいえ | 生成された PDF のサイズ（バイト）。 |
| `htmlSnapshot` | string | いいえ | レンダリングされたレポートの保存済み HTML スナップショット。 |
| `pageCount` | number | いいえ | 生成された PDF のページ数。 |
| `pdfEngine` | string | いいえ | レンダリングエンジン: `"pdfkit"` または `"puppeteer"`。 |
| `generatedAt` | string | いいえ | レポートが生成された日時の ISO 8601 タイムスタンプ。 |
| `generationDurationMs` | number | いいえ | PDF 生成にかかった時間（ミリ秒）。 |
| `dataSnapshot` | object | いいえ | レポートに使用された行データまたは入力データのスナップショット。 |
| `externalRefId` | string | いいえ | 呼び出し元の相関識別子。 |
| `webhookUrl` | string | いいえ | レポート単位の `http` または `https` Webhook 上書き URL。 |
| `rowIndex` | number | いいえ | このレポートに関連付けられた 0 始まりの行インデックス。 |
| `createdByChannel` | string | いいえ | 発生元チャネル: `"portal"`、`"api"`、`"mcp"`、`"x402"`、または `"webhook"`。 |
| `verificationScoreSummary` | object | いいえ | 検証スコアリングのサマリーメタデータ。 |
| `error` | object or string | いいえ | 失敗状態に対して記録されたエラーペイロードまたはメッセージ。 |

### Webhook と MCP 統合

- `webhookUrl` または `externalRefId` を更新すると、後続の [Smart Report PDF を生成する](/verifik-ja/smart-reports/generate-smart-report-pdf) および [Smart Report をメールで送信する](/verifik-ja/smart-reports/send-smart-report-email) の呼び出しで使用されるターゲットコールバック URL と相関 ID が更新されます。詳細は [SmartReports Webhook](/verifik-ja/resources/smart-reports-webhooks) を参照してください。
- AI エージェント経由で更新後のレコードを確認したりヘッドレスのレポート操作を実行したりするには、[MCP と AI エージェント](/verifik-ja/smart-reports/mcp-and-ai-agents) を参照してください。

### 注記

- `SmartReport` を更新しても保存済みのレポートフィールドが変更されるだけで、PDF の再生成やメールの送信は自動的には行われません。再レンダリングや配信を行いたい場合は、[Smart Report PDF を生成する](/verifik-ja/smart-reports/generate-smart-report-pdf) または [Smart Report をメールで送信する](/verifik-ja/smart-reports/send-smart-report-email) を呼び出してください。
