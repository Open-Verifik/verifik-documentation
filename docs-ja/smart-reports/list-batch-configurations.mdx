認証済みクライアントアカウントが所有するバッチ設定（`BatchConfiguration`）を一覧表示します。結果は JWT 上のクライアントにスコープされ、新しい順（`createdAt` 降順）でソートされ、展開された `steps.appFeature` メタデータおよびクライアント固有の `ClientFeature` 価格情報とともに返されます。

`total`、`limit`、`page`、`pages` メタデータを含むページネーション結果が必要な場合は `page` を指定してください。一致する配列を `data` で直接受け取る場合は `page` を省略します。設定の一覧取得は照会を実行せず、クレジットも消費しません。

### エンドポイント

```
GET https://api.verifik.co/v2/batch-configurations
```

クライアント単位の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーを使用することで、Smart-Agent プロキシ（`https://ai.verifik.co/v2/batch-configurations`）経由でもアクセスできます。共有 x402 実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

トークンは **クライアント JWT** である必要があります。認証情報がないか無効な場合は `401 Unauthorized` を返します。

### パラメータ

すべてのクエリパラメータは任意です。

| 名前 | 型 | 必須 | 説明 |
| ---- | ---- | ---- | ----------- |
| `search` | string | いいえ | 保存済み設定に適用される大文字・小文字を区別しない名前フィルター。 |
| `text` | string | いいえ | `search` のエイリアス。 |
| `page` | integer | いいえ | ページ番号（`1` 始まり）。指定すると、レスポンスにページネーションメタデータ（`total`、`limit`、`page`、`pages`）が含まれます。 |
| `limit` | integer | いいえ | 1 ページあたりに返す設定の最大件数。 |
| `perPage` | integer | いいえ | `limit` のエイリアス。 |

import (

func main() {

    resp, _ := http.DefaultClient.Do(req)
    defer resp.Body.Close()

    var out map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&out)

}

### 補足

- 結果は認証済みクライアント JWT に自動的にスコープされ、新しい順（`-createdAt`）でソートされます。
- 各ステップの `steps.appFeature` が展開され、設定されている場合はアカウントの `ClientFeature` 価格が付与されます。
- `perPage` は `limit` のエイリアス、`text` は `search` のエイリアスです。
- ページネーションメタデータ（`total`、`limit`、`page`、`pages`）は、クエリ文字列に `page` が指定された場合にのみ含まれます。
