既存の `SmartReport` に対して `"puppeteer"` または `"pdfkit"` を使用して PDF をレンダリングし、任意で `verificationScore` を算出して、`downloadUrl` と `htmlUrl` とともに base64 エンコードされた PDF バッファを受け取ります。

成功すると、このエンドポイントはレポートを `status: "generated"` にマークし、スコアリングが有効な場合は `verificationScoreSummary` を保存して、`smart_batch_report_generated` Webhook を発火させます。PDF 生成が失敗した場合、レポートは `status: "failed"` にマークされ、`smart_batch_report_generation_failed` Webhook が発火されます。

### エンドポイント

```
POST https://api.verifik.co/v2/smart-reports/{id}/generate
```

このエンドポイントは（カスタム `printHtml` ドキュメントに対応するため）最大 **64 MB** の JSON ペイロードを受け付けます。お客様自身のクライアント別 `Authorization: Bearer <VERIFIK_JWT>` を使用して Smart-Agent プロキシ経由の `https://ai.verifik.co/v2/smart-reports/{id}/generate` からも利用できます。共有 x402 による実行は `403 Forbidden` でブロックされます。

### ヘッダー

| 名前 | 値 | 説明 |
| --- | --- | --- |
| `Content-Type` | `application/json` | リクエストペイロードの形式（上限 64 MB）。 |
| `Authorization` | `Bearer <VERIFIK_JWT>` | クライアント単位の JWT（`authUser.clientId`）。 |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string | **はい** | `SmartReport` ObjectId。 |

### ボディ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `engine` | string | いいえ | PDF レンダリングエンジン: `"pdfkit"` または `"puppeteer"`。 |
| `rowIndex` | number | いいえ | リンクされた `SmartBatch` からの 0 始まりの行インデックス。デフォルトは行 `0` です。 |
| `printHtml` | string | いいえ | `<html` を含むテーマなしテンプレートで使用する完全な HTML 文字列（最大 `64000000` 文字）。 |
| `score` | boolean | いいえ | `verificationScore` を計算し、レポートに `verificationScoreSummary` を保存するかどうか。 |
| `scoreProfile` | string | いいえ | `score` が有効な場合に使用するスコアリングプロファイル識別子。最大 `64` 文字。 |

#### レンダリングとスコアリングの動作

- **デフォルトの行選択**: `rowIndex` を省略すると、生成は行 `0` がデフォルトになります。範囲外の行をリクエストすると `409 Conflict`（`row_not_found`）が返ります。
- **カスタム HTML（`printHtml`）**: 完全な `<html` マークアップを提供するテーマなしテンプレートを扱う場合は、`printHtml`（最大 `64000000` 文字）を渡します。
- **検証スコアリング**: `score: true`（および任意で `scoreProfile`）を設定すると、`verificationScore` を計算してレスポンスのトップレベルに返し、`SmartReport` に `verificationScoreSummary` を保存します。不明なプロファイルは `409 Conflict`（`unknown_score_profile`）で失敗します。

#### エラーコード

| ステータス | エラーコード / 種別 | 原因 |
| --- | --- | --- |
| `401` | `Unauthorized` | JWT が欠落または無効です。 |
| `403` | `Forbidden` | 共有 x402 による実行が試行されました。クライアント別 JWT を使用してください。 |
| `404` | `not_found` | レポート ID が存在しないか、別のクライアントに属しています。 |
| `404` | `template_not_found` | リンクされたテンプレートが見つかりませんでした。 |
| `404` | `batch_not_found` | リンクされた `SmartBatch` が見つかりませんでした。 |
| `409` | `MissingParameter` | 1 つ以上のフィールドで Joi 検証に失敗しました。 |
| `409` | `row_not_found` | 要求された `rowIndex` がバッチ内に存在しません。 |
| `409` | `unknown_score_profile` | 要求された `scoreProfile` が認識されません。 |
| `422` | `UnprocessableEntity` | Mongoose 検証エラーです。 |
| `500` | `InternalServerError` | PDF レンダリングまたは内部処理の失敗（レポートを `"failed"` にマークし `smart_batch_report_generation_failed` を発火します）。 |

### Webhook と MCP 統合

- **Webhook**: PDF 作成が成功すると `smart_batch_report_generated` を発火し、レンダリングエラーが発生すると `smart_batch_report_generation_failed` を発火します（同時に `status` を `"failed"` に更新します）。詳細は [SmartReports Webhook](/verifik-ja/resources/smart-reports-webhooks) を参照してください。
- **MCP 相当ツール**: AI エージェントは `smart_report_generate_pdf` MCP ツールを使用してレポート PDF を直接レンダリングできます。詳細は [MCP と AI エージェント](/verifik-ja/smart-reports/mcp-and-ai-agents) を参照してください。

### 注記

- `pdf.buffer` には base64 エンコードされた PDF バイト列が JSON レスポンス内に直接含まれます。バイナリ PDF ストリームをご希望の場合は、[Smart Report PDF をダウンロードする](/verifik-ja/smart-reports/download-smart-report-pdf) を呼び出してください。
- `score` が有効な場合、レスポンスに `verificationScore` が含まれます。
