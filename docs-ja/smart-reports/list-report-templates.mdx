認証済みクライアントが利用できる Smart Report テンプレートを一覧取得します。デフォルトでは、クライアント所有のカスタムテンプレートと Verifik 組み込みの `"System"` テンプレートの両方を返すため、再利用可能なテンプレート ID（`_id`）の検索、レイアウトやテーマ設定の確認、`SmartBatch` 実行やサンプルレンダリング前のテンプレート選択を行えます。

ヘッドレス検証パイプラインや AI エージェントのワークフローでは、まずこのエンドポイントを呼び出して `batchConfiguration` に紐付いた既存テンプレートを見つけたり、組み込み `"System"` テンプレートを `country`・`category`・`tier` でフィルタリングしたり、クローンや更新の前にカスタムテンプレートが有効かどうかを確認したりします。テンプレートの一覧取得では PDF のレンダリングやクレジットの消費は行われません。

### エンドポイント

```
GET https://api.verifik.co/v2/smart-report-templates
```

Smart-Agent プロキシ（`https://ai.verifik.co`）も同じ `/v2/...` パスを公開しており、お客様自身の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーが必要です。

レスポンスでは `batchConfiguration` と `client` が展開（populate）され、`+thumbnail.image` が選択されるため、ダッシュボードやヘッドレスプレビューは追加のリクエストなしでテンプレートのサムネイルを取得できます。

### ヘッダー

| 名前 | 値 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### パラメータ

すべてのクエリパラメータは任意です。

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `batchConfiguration` | string | いいえ | 特定の `SmartBatch` 設定 ObjectId にリンクされたテンプレートでフィルタします。 |
| `type` | string | いいえ | 作成元でフィルタします: `"client"` または `"System"`。省略すると、クライアント自身のテンプレートと組み込み `"System"` テンプレートの両方が返されます。 |
| `country` | string | いいえ | 国フィルタ。サーバー上で自動的に大文字へ変換されます（例: `CO`、`MX`、`COLOMBIA`）。 |
| `category` | string | いいえ | ドメインカテゴリフィルタ: `"citizen"`、`"company"`、または `"vehicle"`。 |
| `tier` | string | いいえ | テンプレートティアフィルタ: `"essential"` または `"comprehensive"`。 |
| `isActive` | boolean | いいえ | 有効状態（`true` または `false`）でフィルタします。 |
| `search` | string | いいえ | `name` と `systemKey` に対する大文字・小文字を区別しない正規表現検索。`type` を指定せずに `search` を送信すると、自社テンプレートと `"System"` テンプレートの両方に一致します。 |
| `page` | integer | いいえ | ページ番号（1 始まり）。このモジュールでページネーションを有効にするには、`page` と `limit` の両方を同時に指定する必要があります。 |
| `limit` | integer | いいえ | ページサイズ。結果をページネーションするには `page` とともに指定する必要があります。 |
| `sort` | string | いいえ | ソート指定。デフォルトは `type: 1, createdAt: -1`（テンプレート種別順、新しい順）です。 |

### 注記

- 結果をページネーションするには、`page` と `limit` の両方を一緒に指定する必要があります。片方のみを送信してもページネーションは有効になりません。
- 一覧で返される組み込みの `"System"` テンプレートは読み取り専用です。これらを変更または削除しようとすると `403`（`system_template_readonly`）が返されます。スターターをカスタマイズするには、そのレイアウトを [レポートテンプレートを作成する](/verifik-ja/smart-reports/create-a-report-template) に渡してください。
- `reportTheme` ごとに整理されたクリーンなスターターブループリントを取得したい場合は、[テーマスターター一覧を取得する](/verifik-ja/smart-reports/list-theme-starters) を使用してください。
