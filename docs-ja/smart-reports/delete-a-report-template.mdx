認証済みクライアントが所有するカスタム Smart Report テンプレートを削除します。削除されたテンプレートドキュメントは `{ "data": ... }` 内に返されます。

ヘッドレスワークフローや自動テストパイプラインでは、一時テンプレートのクリーンアップや廃止されたレポートデザインの削除にこのエンドポイントを使用します。組み込みの `"System"` テンプレートは削除できず、`403`（`system_template_readonly`）を返します。テンプレートを削除してもクレジットは消費されず、過去に生成された `SmartBatch` レポートも削除されません。

### エンドポイント

```
DELETE https://api.verifik.co/v2/smart-report-templates/{id}
```

Smart-Agent プロキシ（`https://ai.verifik.co`）も同じ `/v2/...` パスを公開しており、お客様自身の `Authorization: Bearer <VERIFIK_JWT>` ヘッダーが必要です。

### ヘッダー

| 名前 | 値 |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

### パラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string | **はい** | Smart Report テンプレートの ObjectId。 |

### 注記

- 組み込みの `"System"` テンプレートは削除できません（`403` `system_template_readonly`）。
- 削除後は、同じ `{id}` を対象とする後続の `GET`、`PUT`、または `DELETE` リクエストは `{ "data": null }`（`GET` の場合）または `404` `not_found`（`PUT`/`DELETE` の場合）を返します。
