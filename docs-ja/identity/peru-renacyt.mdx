# ペルー — SUNEDU の学位と CONCYTEC RENACYT

**RENACYT** 照会は SUNEDU の学位と CONCYTEC の研究者登録を読みます。`documentNumber`（別名 `dni`）、`codigoRegistro`、`orcid`、`fullName` の少なくとも一つを送ります。文書番号を送ると `documentType` の既定は `DNI` です。

## 応答に含まれる項目

- 学位と研究者の項目
- あれば `codigoRegistro` と `orcid`
- `fullName` と `documentNumber`

## 用途

- 助成の前に研究者を確認します。
- ORCID を DNI と突き合わせます。
- 採用ファイル用の RENACYT コードを読みます。

---

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/pe/education/renacyt
```

一致には学位、RENACYT コード、ORCID があり得ます。行が無いと 404 `NotFound` です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **条件付き** | `12345678` | DNI または他の番号。別名 `dni`。既定の `documentType` は `DNI`。`CE`、`PASAPORTE`、`PTP` も可。 |
| `codigoRegistro` | string | **条件付き** | `REN-100` | RENACYT 登録コード。これだけで足ります。 |
| `orcid` | string | **条件付き** | `0000-0002-1825-0097` | ORCID 10–30文字。これだけで足ります。 |
| `fullName` | string | **条件付き** | `LUCIA QUISPE` | 研究者の氏名。これだけで足ります。 |

### 注意

- 文書、RENACYT コード、ORCID、または氏名を送ります。
- 文書番号の既定種別は `DNI` です。
- 登録の行が無いと 404 `NotFound` です。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |

| 情報源に記録あり | `documentType: "DNI"`, `documentNumber: "12345678"` | 学位または研究者項目のある 200。 |
