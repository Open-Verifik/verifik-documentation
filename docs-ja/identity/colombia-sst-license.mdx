# コロンビア — 労働安全衛生の免許（SST）

**SST 免許**照会はコロンビアの身元番号の労働安全免許と技術適用者資格証を読みます。`documentNumber` は必須です。一致すると種別、決議または資格証番号、発行日を列挙します。

## 応答に含まれる項目

- `licenseType`、決議または資格証番号、`issueDate` を持つ `licenses[]`
- `totalLicenses`
- `status` と `isRegistered`

## 用途

- 請負が現場に入る前に SST 免許を確認します。
- 個人免許と技術資格証の両方を見ます。
- 取引先ファイルに決議番号を保存します。

---

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/co/sst/licencia
```

応答には `fullName`、`profession`、`totalLicenses`、`licenses` があります。免許も資格証も無いと 404 `NotFound` です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **はい** | `52111222` | SST 免許と技術資格証を読むコロンビアの身元番号。5–15文字。 |

### 注意

- `documentNumber` は必須です。
- SST 免許も技術資格証も無いと HTTP 404 です。
- 任意の `documentType` は `CC`、`CE`、`TI`、`PEP`、`PPT` を受けます。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | `documentNumber: "52111222"` | 免許が 1 件以上の 200。 |
| 必須値が無い | Omit `documentNumber` | 409 MissingParameter。 |
| 不明な値 | `documentNumber: "000000000"` | どちらの情報源にも行が無いと 404 NotFound。 |

401 when the bearer token is missing or rejected.
