# グローバル — 電話番号照会

## API リファレンス

### Endpoint

```
https://api.verifik.co/v2/look-ups/phone
```

電話番号照会サービスは、世界の携帯電話または固定電話番号を **掲載されている名義人名** および関連プロファイル項目に紐づけます。**`countryCode`**（数字の国番号）と **`phone`**（国番号を除いた国内番号）を **GET**（クエリ）または **POST**（JSON 本文）で送信します。成功時の `data` には `name`、`phone`、`countryCode` が含まれ、`score`、`gender`、`about`、`jobTitle`、`companyName`、`phones`、`addresses`、`internetAddresses`、`imId`、`access`、`enhanced` が含まれる場合があります。オンボーディング、不正検知、連絡先確認に利用してください。端末所有の OTP 証明ではありません。

SMS または WhatsApp のワンタイムコードを送る場合は [電話検証](/verifik-ja/resources/phone-validations) を参照してください。

### ヘッダー (Headers)

| 名前          | 値                 |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

### パラメーター (Parameters)

| 名前            | 型     | 必須 | 説明                                                                       |
| --------------- | ------ | ---- | -------------------------------------------------------------------------- |
| `countryCode`   | string | はい | 数字の国番号であり、ISO2 ではありません。例: コロンビア `57`、米国 `1`。 |
| `phone`         | string | はい | 照会対象回線の国内番号。国番号、スペース、句読点は含めないでください。 |

### リクエスト (Request)

<TabItem value="javascript" label="JavaScript">

```javascript
import axios from "axios";

const options = {
  method: "GET",
  url: "https://api.verifik.co/v2/look-ups/phone",

    Accept: "application/json",
    Authorization: "Bearer <your_token>",
  },

  const { data } = await axios.request(options);

} catch (error) {
  console.error(error);
}
```

### 注意事項 (Notes)

- **GET** と **POST** の両方に対応しています。POST は同じフィールドを JSON 本文で送ります。
- `countryCode` は **数字の国番号**（例: `57`）であり、`CO` のような ISO2 ではありません。
- `phone` は **国内番号のみ** を送ってください。国番号を重ねて付けないでください。
- `name`、`phone`、`countryCode` 以外のプロファイル項目は任意です。ソースが省略することがあります。
- このルートにサンドボックス用フィクスチャはありません。照会はライブソースに届きます。一時障害は **409** と `Endpoint out of service.` を返します。
- **404** は掲載がない（または国番号が不明）ことを意味します。有料クライアントの 404 は **課金されません**。
- このエンドポイントは、発信者が端末を所有していることを **証明しません**。OTP 検証は [電話検証](/verifik-ja/resources/phone-validations) を使用してください。
