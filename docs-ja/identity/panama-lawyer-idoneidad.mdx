# パナマ — 弁護士の適格

**弁護士の適格**照会は番号でパナマの弁護士証を読みます。`idoneidad` または別名 `licenseNumber` を 1–10 桁で送ります。任意の `issueDate` は `DD-MM-YYYY` です。番号が無いと 409 `MissingParameter` です。

## 応答に含まれる項目

- 適格番号と氏名
- `status`

## 用途

- 書面の前に弁護士を確認します。
- 発行日があれば突き合わせます。
- 数字でない適格番号を拒否します。

---

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/pa/lawyer/idoneidad
```

一致には氏名、適格番号、状態があります。不明な番号は 404 `NotFound` です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `idoneidad` | string | **条件付き** | `12345` | 弁護士の適格番号。1–10桁。別名 `licenseNumber`。どちらかは必須です。 |
| `issueDate` | string | いいえ | `01-02-2010` | 任意の発行日 `DD-MM-YYYY`。 |

### 注意

- `idoneidad` または `licenseNumber` を送ります。
- 数字だけ 1–10 桁。
- 不明な番号は 404 `NotFound` です。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。
