# LATAM — 教育と免許の統合スコア

**教育スコア**は `CO`、`PE`、`PA`、`MX`、`CL`（英語の国名も可）の大学学位と専門免許を一つの点数にまとめます。`country` は必須です。身元も一つ送ります。`documentNumber`、`licenseNumber`、`fullName`、または `firstName` と `lastName`。409 の本文は `MissingParameter` ではなく `{ "validationError": "..." }` です。未対応の国も 409 です。

## 応答に含まれる項目

- `educationScore` と `educationTier`
- `highestLevel` と `hasActiveLicense`
- `credentials` と `checkedSources`

## 用途

- 学位と免許の情報源で採用を順位付けします。
- 採点の前に国を要求します。
- 制裁を点数の低下として読みます。

---

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/score/education
```

応答には 0–100 の `educationScore`、`educationTier`、`highestLevel`、`hasActiveLicense`、`hasSanctions`、`credentials` があります。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `country` | string | **はい** | `CO` | 必須。`CO`、`PE`、`PA`、`MX`、`CL`、または英語名 `COLOMBIA`、`PERU`、`PANAMA`、`MEXICO`、`CHILE`。 |
| `documentNumber` | string | **条件付き** | `80123456` | 身元が一つ必要です。この番号、`licenseNumber`、`fullName`、または `firstName` と `lastName`。 |
| `licenseNumber` | string | **条件付き** | `AN205-27910` | 専門免許。必須の身元として数えます。 |
| `fullName` | string | **条件付き** | `ANA PEREZ` | 氏名。必須の身元として数えます。 |

### 注意

- `country` は必須です。
- 409 は `MissingParameter` ではなく `validationError` を使います。
- 対応国は CO、PE、PA、MX、CL です。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | `country: "CO"`, `documentNumber: "80123456"` | educationScore と等級のある 200。 |
| 必須値が無い | Omit `country` | country または身元が無いと 409 `{ validationError }`。 |
| 不明な値 | `country: "US"`, `documentNumber: "1"` | 国コードが未対応だと 409。 |

401 when the bearer token is missing or rejected.
