# コロンビア — 市民証の状態（CC）

**コロンビア市民証の状態**照会は Registraduría の有効状態を読みます。`documentNumber` を送ります。応答は番号の有無、生存記録、登録機関が公開する状態文言を含みます。より広い本人確認の前に現在の CC 状態が必要なときに使います。

## 応答に含まれる項目

- `documentType` — CC
- `documentNumber` — 送った市民証番号
- `exists` — 登録に番号があるか
- `isAlive` — true、false、または null
- `documentStatus` — 登録機関の有効状態文言

## 用途

- 口座開設の前に CC が登録にあることを確認します。
- KYC で死亡記録と有効な市民証を分けます。
- 文書番号の横に状態文言を保存します。

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/co/cedula/vigencia
```

成功時の応答には `documentType`（CC）、`documentNumber`、`exists`、`isAlive`、`documentStatus` があります。登録に番号が無いと `exists` は false です。情報源がその点を確定しないとき `isAlive` は true、false、または null です。現在の有効状態が必要な KYC ファイルで使います。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **はい** | `1121329661` | コロンビアの市民証番号。5桁から10桁の数字で、空白や記号は付けません。 |

### 注意

- `documentNumber` は必須で、5文字から10文字です。
- 登録が生死を確定しない状態を返すと `isAlive` は null になり得ます。
- この経路は有効状態の照会です。完全な市民プロファイルの代わりにはなりません。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。
