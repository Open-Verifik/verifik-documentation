# コロンビア — 電気・機械工学の免許

**電気・機械工学の免許**照会は Consejo Profesional Nacional de Ingenierías Eléctrica, Mecánica y Profesiones Afines を読みます。`documentNumber`、`licenseNumber`、`fullName` のいずれかを送ります。応答には免許、専門、状態、制裁の有無があります。

## 応答に含まれる項目

- `licenseNumber` と `specialty`
- VIGENTE などの `status`
- `isRegistered` と `hasSanctions`
- 行が複数なら `registrations`

## 用途

- 現場作業の前に電気または機械の技術者を確認します。
- 免許の横の懲戒を読みます。
- 契約の氏名を評議会の行と突き合わせます。

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/co/consejo-profesional
```

一致には `fullName`、`licenseNumber`、`specialty`、`status`、`isRegistered`、`hasSanctions` があります。評議会に行が無いと 404 `NotFound` です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **条件付き** | `80123456` | コロンビアの身分番号。5文字から15文字。`documentType` は `CC`、`CE`、`TI`、`PEP`、`PPT` です。 |
| `licenseNumber` | string | **条件付き** | `AN205-27910` | 専門免許番号。例: AN205-27910。これだけで足ります。 |
| `fullName` | string | **条件付き** | `ANA PEREZ` | 技術者の氏名または姓。3文字から160文字。これだけで足ります。 |

### 注意

- `documentNumber`、`licenseNumber`、`fullName` の少なくとも一つを送ります。
- 評議会に行が無いときは空の 200 ではなく HTTP 404 です。
- `documentType` は任意です。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。
