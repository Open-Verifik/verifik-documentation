# エクアドル — 投票所

**エクアドルの投票所**照会は CNE の名簿を読みます。`documentType` は `CCEC`、`documentNumber` は県コードが 01–24 または 30 で検査数字が正しい 10 桁の市民証です。応答には氏名と県、カントン、教区、フンタ（`pollingTable`）があります。

## 応答に含まれる項目

- `province`、`canton`、`parish`
- `pollingTable` — フンタ
- `fullName`

## 用途

- 有権者に投票所を示します。
- 検査数字が合わない市民証を拒否します。
- 本人ファイルと一緒にフンタを保存します。

---

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/ec/votacion
```

項目には `fullName`、`province`、`canton`、`parish`、`pollingTable` があります。不明な市民証は 404 `NotFound` です。検査数字が違うと 409 `InvalidDocumentNumber` です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentType` | string | **はい** | `CCEC` | `CCEC` でなければなりません。 |
| `documentNumber` | string | **はい** | `1700000019` | 検査数字を含む 10 桁のエクアドル市民証。県コードは 01–24 または 30。不正な番号は 409 `InvalidDocumentNumber` です。 |

### 注意

- `documentType` は `CCEC` です。
- 市民証は有効な県と検査数字を持つ 10 桁です。
- 不明な番号は 404 `NotFound` です。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。
