# コロンビア — 化学工学の免許（CPIQ）

**CPIQ 免許**照会は Consejo Profesional de Ingeniería Química を読みます。`documentNumber` または `licenseNumber` を送ります。モジュールは氏名では検索しません。`fullName` だけだと HTTP 409 `MissingParameter` とメッセージ `Either documentNumber or licenseNumber must be provided` が返ります。一致には免許、決議、状態、制裁の項目があります。

## 応答に含まれる項目

- `licenseNumber` と `resolutionNumber`
- `status` と `isActive`
- `sanctionType` と `hasSanctions`

## 用途

- 市民証または CPIQ 免許で化学技術者を確認します。
- 評議会の前に氏名だけの検索を拒否します。
- 評議会が公開する制裁日を読みます。

---

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpiq
```

一致には `fullName`、`licenseNumber`、`resolutionNumber`、`status`、`sanctionType`、`isRegistered`、`hasSanctions` があります。CPIQ に行が無いと 404 `NotFound` です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **条件付き** | `79876543` | 身元番号。`licenseNumber` を省くと必須です。`fullName` だけでは 409 です。 |
| `licenseNumber` | string | **条件付き** | `PQ-10293` | CPIQ の専門免許番号。`documentNumber` を省くと必須です。 |

### 注意

- この経路で `fullName` は検索キーではありません。氏名だけは 409 です。
- `documentNumber` または `licenseNumber` を送ります。
- CPIQ に行が無いと HTTP 404 です。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | `documentNumber: "79876543"` | 免許と制裁項目付きの 200。 |

401 when the bearer token is missing or rejected.
