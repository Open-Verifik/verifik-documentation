# スロバキア — 本人確認と個人事業主の照会 (KYC)

**スロバキアの本人確認と個人事業主の照会**は、この識別子（ICOSK）の公式情報源で個人または個人事業主を確認します。その番号を `documentNumber` として送ってください。受付に法的氏名、登録状態、情報源が公開する本人属性が必要なときに使います。

`documentNumber` は必須です。`documentType` の既定値は `ICOSK` です。既定値のままにするなら省略し、明示するなら `ICOSK` を送ってください。

## レジストリが返す項目

- 個人または個人事業主の法的氏名
- 登録状態
- 照会した識別子
- 情報源が公開する公式の本人属性

## 用途

- 受付のときに スロバキアの個人事業主または登録された個人を確認します。
- ファイル上の法的氏名を公式の識別子と突き合わせます。
- 登録状態と、公式情報源が公開する本人属性を保管します。

## API リファレンス

### エンドポイント

```http
GET https://api.verifik.co/v2/sk/citizen
```

`documentNumber` で スロバキア の公式な本人・個人事業主の情報源を照会します。`documentType` は識別子の種類（ICOSK）を選びます。成功時のペイロードには法的氏名、登録状態、送った識別子、情報源が公開する公式の本人属性が含まれます。個人または個人事業主の KYC 受付に使ってください。下の例はこれらの項目です。実際の値は公式情報源から返ります。

### ヘッダー

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <your_token>` | クライアント JWT 認証トークン |

### パラメータ

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **はい** | `31333532` | 個人または個人事業主の公式な本人番号または納税番号（ICOSK）。 |
| `documentType` | string | いいえ | `ICOSK` | 書類種別の識別子。既定値は `ICOSK` です。 |

### 備考

- **識別子の形式.** IČO は 8 桁です。空白を入れず数字だけを送ってください。
- 書類種別の識別子。既定値は `ICOSK` です。
- 例の状態ラベルは項目を示す値です。実際の登記は独自の表記を返し、現地語の場合があります。
- このルートのクライアントパラメータは `documentNumber` と、識別子の種類を示す必要があるときの `documentType` です。
- JSON の例は上記の項目の形です。実際の呼び出しは、送った識別子に対する登記記録を返します。

## サンドボックス

アカウントがサンドボックスモードのとき、同じパラメータでこのルートを呼び出します。表は各ケースで文書化されている応答です。

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| **登録済みの識別子** | `documentType: "ICOSK"`, `documentNumber: "31333532"` | 情報源に番号がある場合は 200 とともに法的氏名、状態、識別子、住所または本人属性を返します。 |
| **documentNumber なし** | 省略 `documentNumber` | `documentNumber` を省くと 409 `MissingParameter`。 |
| **不明な番号** | `documentNumber: "000000000"` | 登記にその番号の記録がない場合は 404 `NotFound`。 |

bearer トークンがない、または拒否された場合は 401。
