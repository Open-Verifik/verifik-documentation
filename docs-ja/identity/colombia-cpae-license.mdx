# コロンビア — 経営学の免許（CPAE）

**CPAE 免許**照会は Consejo Profesional de Administración de Empresas を読みます。`documentNumber` は必須です。任意の `documentType` は `CC`、`CE`、`TI`、`PEP`、`PPT` を受けます。一致すると氏名、職種、登録と有効の有無を返します。

## 応答に含まれる項目

- `fullName` と `profession`
- `entity` — CPAE
- `status`、`isRegistered`、`isActive`

## 用途

- 採用時に経営学の資格証を確認します。
- 資格証がまだ有効か確認します。
- KYC ファイルに CPAE の職種文言を保存します。

---

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpae
```

応答には `fullName`、`profession`、`entity`、`status`、`isRegistered`、`isActive` があります。不明な番号は 404 `NotFound` です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **はい** | `80123456` | コロンビアの身分番号。5文字から15文字。`documentType` は `CC`、`CE`、`TI`、`PEP`、`PPT` です。 |

### 注意

- `documentNumber` は必須です。
- 番号に専門証が無いと CPAE は 404 を返します。
- 文書番号の代わりに氏名は送りません。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | `documentNumber: "52987654"` | 職種と有効フラグ付きの 200。 |
| 必須値が無い | Omit `documentNumber` | 409 MissingParameter。 |
| 不明な値 | `documentNumber: "000000000"` | CPAE に資格証が無いと 404 NotFound。 |

401 when the bearer token is missing or rejected.
