# 🇨🇱 チリ — 運転免許停止・失効登録簿

**Servicio de Registro Civil e Identificación**の全国運転免許ブロック・停止登録簿をRUN番号で照会します。

特定の自治体（コムーナ）のみを対象とする地方自治体ポータルとは異なり、本エンドポイントは裁判所や行政機関が発令した運転免許停止・ブロック情報を**チリ全国規模**でカバーします。

### エンドポイント

```
GET https://api.verifik.co/v2/cl/driver-license/block
```

### ヘッダー

| 名前          | 値                 |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### パラメーター

| 名前 | 型 | 必須 | 説明 | 例 |
| ---- | ---- | ---- | ---- | ---- |
| `documentNumber` | string | **はい** | チェックディジット（DV）を含むチリのRUN番号。ドットやハイフンは省略可能です（`18.347.440-5` または `18347440-5`）。正しいチェックディジットを指定してください。 | `18347440-5` |
| `force` | boolean | いいえ | サーバーキャッシュをバイパスして公式ソースへ直接照会するオプション。 | `false` |

## 主な機能

- **全国登録簿データ**: チリRegistro Civil e Identificaciónの公式データを提供。
- **即時ステータス確認**: `hasBlock: true/false` による停止状態の即時判定。
- **名義人氏名照合**: 運転資格に登録されている正式氏名を返却。
- **停止命令メタデータ**: 裁判所命令日、停止種別、事由を網羅。
- **チェックディジット保護**: 事前のモジュロ11検証により誤入力を検知し、クレジット浪費を防止。
