# Scan Agent

**Scan Agent** は文書画像から構造化項目を抽出します。**POST** `https://api.verifik.co/v2/ocr/scan-gpt` を呼びます。`image` は必須です。`documentType`、`backImage`、`template` は任意です。この本文に `country` 項目はありません。保存された抽出は `validationMethod` を `SCAN_AGENT` にします。

## 応答に含まれる項目

- 抽出された `documentType`、`documentNumber`、氏名
- `validationMethod` — `SCAN_AGENT`

## 用途

- 1 枚の画像から本人文書を読みます。
- カードに裏面があれば裏面画像を足します。
- レイアウトが分かっていればテンプレートを固定します。

---

## API リファレンス

### Endpoint

```http
POST https://api.verifik.co/v2/ocr/scan-gpt
```

一致には抽出された文書項目と `validationMethod` `SCAN_AGENT` があります。URL は `/v2/ocr/scan-gpt` のままです。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `image` | string | **はい** | `data:image/jpeg;base64,AAAA` | 表面画像の base64 または data URI。必須。 |
| `documentType` | string | いいえ | `CC` | 任意の文書種別。例: `CC`、`DNI`。 |
| `backImage` | string | いいえ | `data:image/jpeg;base64,BBBB` | 任意の裏面画像。 |
| `template` | string | いいえ | `template_id` | 任意のテンプレート id。 |

### 注意

- `image` は必須です。`documentType`、`backImage`、`template` は任意です。
- 国の項目は送りません。この本文は受けません。
- 記録されるメソッドは `SCAN_AGENT` で、URL は `/v2/ocr/scan-gpt` のままです。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | `image` plus `documentType: "CC"` | 抽出項目と validationMethod SCAN_AGENT のある 200。 |
| 必須値が無い | Omit `image` | 409 MissingParameter。 |
| 不明な値 | `image` and `backImage` | 裏面画像も送ると 200。 |

401 when the bearer token is missing or rejected.
