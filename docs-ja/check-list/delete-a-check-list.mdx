自分が所有する Check List を削除します。API は削除したドキュメントを `{ data }` で返します。無効な ObjectId、存在しないリスト、他のクライアントのリストは `404` を返します。

削除は照会を実行せず、クレジットも消費しません。同じフィーチャーコードを使ったカタログ履歴と SmartBatch ジョブは削除されません。

### Endpoint

```
DELETE https://api.verifik.co/v2/check-lists/{id}
```

クライアントのコレクションからリストを削除し、削除されたドキュメントを返します。この呼び出しのあと、同じ id への GET / PUT / DELETE は `404` を返します。

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

トークンは **クライアント JWT** である必要があります。`clientId` のないトークンは `403` を返します。

### Parameters

| Name | Type   | Required | Description                          |
| ---- | ------ | -------- | ------------------------------------ |
| `id` | string | Yes      | 作成または一覧から得た Check List の ObjectId。 |

### Notes

- `200` の本文は削除されたドキュメントであり、空のオブジェクトではありません。
- 無効な ObjectId と他のクライアントのリストは、どちらも `404`（`check_list_not_found`）です。
- 削除はクレジットを消費せず、カタログや SmartBatch の作業もキャンセルしません。
- チェックリスト実行エンドポイントはありません。[Check List](/verifik-ja/check-list) と [SmartBatch](/verifik-ja/smart-batch) を見てください。
