# 顔検出

**顔検出**は検出エンジンの別名である `POST /v2/face-recognition/face-validation` です。`image` は必須です。省略するとこの経路が `min_score` を `0.5`、`search_mode` を `FAST` にします。実際のペイロードは `face_count`、`faces`（`score` と `bbox`）、`imageDimensions`、`engine` です。

## 応答に含まれる項目

- `face_count`
- `faces[].score` と `faces[].bbox`
- `imageDimensions` と `engine`

## 用途

- ライブネスの前に顔の数を数えます。
- 主顔の箱を読みます。
- 画像しか無ければ既定の点数とモードを使います。

---

## API リファレンス

### Endpoint

```http
POST https://api.verifik.co/v2/face-recognition/face-validation
```

まず `face_count` を読みます。`faces` の各要素には `score` と `bbox` があります。`imageDimensions` は復号した幅と高さです。`engine` は検出器の名前です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `image` | string | **はい** | `data:image/jpeg;base64,AAAA` | base64 または data URI の顔画像。必須。 |
| `min_score` | number | いいえ | `0.5` | 任意。この経路は既定で `0.5` を入れます。 |
| `search_mode` | string | いいえ | `FAST` | 任意。この経路は既定で `FAST` を入れます。もう一つの値は `ACCURATE` です。 |

### 注意

- 必須は `image` だけです。
- 省いた `min_score` は `0.5`、省いた `search_mode` は `FAST` になります。
- 応答は別のランドマークではなく `bbox` を使います。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | `image` only | face_count、faces、imageDimensions、engine のある 200。 |
| 必須値が無い | Omit `image` | 409 MissingParameter。 |
| 不明な値 | `min_score: 0.8`, `search_mode: "ACCURATE"` | 送った点数とモードで 200。 |

401 when the bearer token is missing or rejected.
