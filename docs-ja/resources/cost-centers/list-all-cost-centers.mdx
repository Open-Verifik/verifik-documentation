### エンドポイント

**GET** `https://api.verifik.co/v2/cost-centers`

アカウントのコストセンターを返します。国、次に名前の順です。

#### ヘッダー

| 名前          | 値                 |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### クエリパラメータ

#### `active`

**型:** boolean  
**必須:** いいえ

`true` は有効のみ、`false` は無効のみです。省略すると両方を返します。

#### `country`

**型:** string  
**必須:** いいえ

ISO-2 の国コード。例: `ES`。

#### `page`

**型:** number  
**必須:** いいえ

ページ番号。1 から。

#### `limit`

**型:** number  
**必須:** いいえ

1 ページの件数。既定 50、最大 100。

### リクエスト例

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash

  -H "Authorization: Bearer $VERIFIK_TOKEN"
```

## エラーレスポンス

無効なクエリです。たとえば `limit` が 100 を超える、または `country` が 2 文字でない場合です。

```json
{
  "message": "\"limit\" must be less than or equal to 100",
  "code": "MissingParameter"
}
```
