# コストセンターを一覧する

```
GET https://api.verifik.co/v2/cost-centers
```

| 名前      | 型      | 必須   | 説明                                              |
| --------- | ------- | ------ | ------------------------------------------------- |
| `active`  | boolean | いいえ | `true` は有効のみ、`false` は無効のみ。           |
| `country` | string  | いいえ | ISO-2 の国コード。                                |
| `page`    | number  | いいえ | ページ番号。1 から。                              |
| `limit`   | number  | いいえ | 1 ページの件数。既定 50、最大 100。               |

```json
{
	"data": [
		{
			"_id": "6acfbdda92451bac5d0a7ebe",
			"name": "スペイン運用",
			"code": "SPAIN-OPS",
			"country": "ES",
			"active": true
		}
	],
	"total": 1,
	"page": 1,
	"pages": 1,
	"limit": 50
}
```
