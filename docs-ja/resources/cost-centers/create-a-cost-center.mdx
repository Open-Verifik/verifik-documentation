### エンドポイント

**POST** `https://api.verifik.co/v2/cost-centers`

アカウントにコストセンターを作成します。管理ではクレジットを消費しません。

#### ヘッダー

| 名前          | 値                 |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### ボディパラメータ

#### `name`

**型:** string  
**必須:** はい

表示名。120 文字まで。

#### `code`

**型:** string  
**必須:** はい

`x-cost-center` に送る値。文字、数字、`.`、`-`、`_`。60 文字まで。アカウントごとに一意。

#### `country`

**型:** string  
**必須:** はい

ISO-2 の国コード。例: `ES`。

#### `active`

**型:** boolean  
**必須:** いいえ

既定は `true`。

### リクエスト例

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X POST "https://api.verifik.co/v2/cost-centers" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"スペイン運用","code":"SPAIN-OPS","country":"ES"}'
```

</TabItem>

## エラーレスポンス

アカウントにすでにあるコード:

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```

`name`、`code`、`country` のように欠けている、または無効なフィールド:

```json
{
  "message": "\"name\" is required",
  "code": "MissingParameter"
}
```
