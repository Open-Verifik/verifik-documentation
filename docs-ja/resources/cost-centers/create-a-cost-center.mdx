# コストセンターを作成する

```
POST https://api.verifik.co/v2/cost-centers
```

| 名前      | 型      | 必須   | 説明                              |
| --------- | ------- | ------ | --------------------------------- |
| `name`    | string  | はい   | 表示名。                          |
| `code`    | string  | はい   | ヘッダーの値。アカウントごとに一意。 |
| `country` | string  | はい   | ISO-2 の国コード。                |
| `active`  | boolean | いいえ | 既定は `true`。                   |

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X POST "https://api.verifik.co/v2/cost-centers" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"スペイン運用","code":"SPAIN-OPS","country":"ES"}'
```

</TabItem>
<TabItem value="nodejs" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.post(
	"https://api.verifik.co/v2/cost-centers",
	{ name: "スペイン運用", code: "SPAIN-OPS", country: "ES" },
	{ headers: { Authorization: `Bearer ${process.env.VERIFIK_TOKEN}` } }
);

console.log(data.data._id);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.post(
    "https://api.verifik.co/v2/cost-centers",
    headers={"Authorization": f"Bearer {os.environ['VERIFIK_TOKEN']}"},
    json={"name": "スペイン運用", "code": "SPAIN-OPS", "country": "ES"},
)

print(response.json()["data"]["_id"])
```

</TabItem>
</Tabs>

応答の `data` の中に新しい[コストセンターオブジェクト](/verifik-ja/resources/the-cost-center-object)があります。すでにあるコードは次を返します。

```json
{
	"code": "Conflict",
	"message": "cost_center_code_taken"
}
```
