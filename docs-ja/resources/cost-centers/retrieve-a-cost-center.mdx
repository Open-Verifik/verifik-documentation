### エンドポイント

**GET** `https://api.verifik.co/v2/cost-centers/{id}`

アカウントのコストセンターを 1 件返します。コード、国、有効かどうかが含まれます。

#### ヘッダー

| 名前          | 値                 |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### パスパラメータ

#### `id`

**型:** string  
**必須:** はい

作成時に返されたコストセンターの id です。

### リクエスト例

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl "https://api.verifik.co/v2/cost-centers/6acfbdda92451bac5d0a7ebe" \
  -H "Authorization: Bearer $VERIFIK_TOKEN"
```

</TabItem>
<TabItem value="node" label="Node.js">

```javascript
const axios = require("axios");

const config = {
  method: "get",
  url: "https://api.verifik.co/v2/cost-centers/6acfbdda92451bac5d0a7ebe",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer YOUR_ACCESS_TOKEN"
  }
};

axios.request(config)
.then((response) => {
  console.log(JSON.stringify(response.data));
})
.catch((error) => {
  console.log(error);
});
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.get(
    "https://api.verifik.co/v2/cost-centers/6acfbdda92451bac5d0a7ebe",
    headers={"Authorization": f"Bearer {os.environ['VERIFIK_TOKEN']}"},
)

print(response.json())
```
