# コストセンターを更新する

```
PUT https://api.verifik.co/v2/cost-centers/{id}
```

`name`、`code`、`country`、`active` のいずれかを送ります。`active: true` で再び有効にします。すでに記録されたリクエストは、当時のコストセンターのままです。
