### エンドポイント

**PUT** `https://api.verifik.co/v2/cost-centers/{id}`

コストセンターを 1 件更新します。変えるフィールドだけを送ります。すでに記録されたリクエストは、当時のコストセンターのままです。

#### ヘッダー

| 名前          | 値                 |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### パスパラメータ

#### `id`

**型:** string  
**必須:** はい

コストセンターの id です。

#### ボディパラメータ

#### `name`

**型:** string  
**必須:** いいえ

表示名。120 文字まで。

#### `code`

**型:** string  
**必須:** いいえ

新しいヘッダー値。文字、数字、`.`、`-`、`_`。60 文字まで。アカウントごとに一意。

#### `country`

**型:** string  
**必須:** いいえ

ISO-2 の国コード。

#### `active`

**型:** boolean  
**必須:** いいえ

`true` で再び有効にします。`false` で新しいリクエストに割り当てないようにします。

### リクエスト例

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash

  -H "Content-Type: application/json" \
  -d '{"name":"スペイン運用","active":true}'
```

## エラーレスポンス

不明な id:

```json
{
  "message": "cost_center_not_found",
  "code": "NotFound"
}
```

アカウントの別のセンターがすでに使っている `code`:

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```
