# コストセンターオブジェクト

```json
{
	"_id": "6acfbdda92451bac5d0a7ebe",
	"client": "69c2b824295cd7d276e478ad",
	"name": "スペイン運用",
	"code": "SPAIN-OPS",
	"country": "ES",
	"active": true,
	"createdAt": "2026-10-14T17:37:30.469Z",
	"updatedAt": "2026-10-14T17:37:30.469Z"
}
```

| フィールド | 型      | 説明                                                                                          |
| ---------- | ------- | --------------------------------------------------------------------------------------------- |
| `name`     | string  | 表示名。120 文字まで。                                                                        |
| `code`     | string  | `x-cost-center` に送る値。文字、数字、`.`、`-`、`_`。60 文字まで。アカウントごとに一意。      |
| `country`  | string  | このコストセンターが通常担当する ISO-2 の国。                                                 |
| `active`   | boolean | 無効なセンターは履歴を残しますが、新しいリクエストには割り当てられません。                    |
