### 概要

コストセンターオブジェクトは、チーム、国、または事業単位について Verifik が保存するレコードです。リクエストは `_id` で参照します。`code` は `x-cost-center` ヘッダーで送ります。

```json
{
  "_id": "6acfbdda92451bac5d0a7ebe",
  "client": "69c2b824295cd7d276e478ad",
  "name": "スペイン運用",
  "code": "SPAIN-OPS",
  "country": "ES",
  "active": true,
  "createdAt": "2026-10-14T17:37:30.469Z",
  "updatedAt": "2026-10-14T17:37:30.469Z"
}
```

### 属性

#### `_id`

**型:** string  
**必須:** はい

一意の識別子。取得、更新、無効化、およびプロジェクトの既定値に使います。

#### `client`

**型:** string  
**必須:** はい

このコストセンターを所有するアカウントです。

#### `name`

**型:** string  
**必須:** はい

表示名。120 文字まで。

#### `code`

**型:** string  
**必須:** はい

`x-cost-center` に送る値。文字、数字、`.`、`-`、`_`。60 文字まで。アカウントごとに一意。

#### `country`

**型:** string  
**必須:** はい

このセンターが通常担当する ISO-2 の国。大文字で保存されます。

#### `active`

**型:** boolean  
**必須:** はい

無効なセンターは履歴を残しますが、新しいリクエストには割り当てられません。既定は `true`。

#### `createdAt`

**型:** string  
**必須:** はい

作成日時。ISO-8601。

#### `updatedAt`

**型:** string  
**必須:** はい

最終更新日時。ISO-8601。
