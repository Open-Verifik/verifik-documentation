# コロンビア — 連帯部門の制裁

**連帯制裁**照会は Supersolidaria の制裁掲示を読みます。番号または名称を送ります。制裁があるときだけ `isSanctioned` は true です。単なる未検出は HTTP 200 で `isSanctioned` は false、`sanctionsCount` は 0、状態は `SIN SANCIONES REGISTRADAS` です。この経路はその未検出に 404 を使いません。

## 応答に含まれる項目

- `isSanctioned` と `sanctionsCount`
- `status`
- `matches`

## 用途

- 資金を出す前に協同組合を照合します。
- きれいな連帯照会を 200 として記録します。
- NIT または制裁された名称で検索します。

---

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersolidaria/sanciones
```

一致には `sanctionsCount` と `matches` があります。単なる未検出は `isSanctioned` が false の HTTP 200 です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **条件付き** | `900123456` | NIT または番号。別名 `nit`。 |
| `businessName` | string | **条件付き** | `EJEMPLO SAS` | 名称。別名 `companyName` と `fullName`。 |
| `documentType` | string | いいえ | `NIT` | 任意: `NIT`、`CC`、`CE`、`PAS`、`TI`。 |

### 注意

- 単なる未検出は `isSanctioned` が false の HTTP 200 です。
- 検索値を一つ以上送ります。
- その 200 を 404 に割り当てないでください。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

## サンドボックス

| シナリオ | パラメータ | 結果 |
| :--- | :--- | :--- |
| 情報源に記録あり | `documentNumber: "900555111"` | 一致すると isSanctioned が true の 200。 |
| 必須値が無い | Omit number and name | 検索値が無いと 409。 |
| 不明な値 | `documentNumber: "800000111"` | isSanctioned が false の 200。単なる未検出は 404 ではありません。 |

401 when the bearer token is missing or rejected.
