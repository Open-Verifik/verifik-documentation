# コロンビア — 架空または支払不能の供給者（DIAN）

**架空または支払不能の供給者**照会は DIAN 671 条を照合します。`documentNumber`（別名 `nit`）または `businessName`（別名 `companyName` と `fullName`）を送ります。掲載されると `isFictitiousSupplier` は true で決議を含みます。単に無ければ HTTP 200 で `isFictitiousSupplier` は false です。この経路は単なる未検出に 404 を使いません。

## 応答に含まれる項目

- `isFictitiousSupplier` — DIAN が掲載するときだけ true
- 一致時の `resolutionNumber`、`resolutionDate`、`publicationDate`
- 掲載が無いと空の `matches`
- `status` — 一覧の文言または未掲載の文

## 用途

- DIAN が架空または支払不能と印した供給者を止めます。
- 単なる未検出をフラグ false の 200 として記録します。
- NIT または法人名で検索します。

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/co/dian/proveedores-ficticios
```

一致すると `isFictitiousSupplier` は true で、`matches` に決議番号、日付、税務署があります。単に無ければ `isFictitiousSupplier` は false です。どちらも HTTP 200 です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **条件付き** | `900123456` | NIT または個人番号。4–25文字。別名 `nit`。名前を送らないときは必須です。 |
| `businessName` | string | **条件付き** | `INDUSTRIAS EJEMPLO SAS` | 商号または法人名。2–200文字。別名 `companyName` と `fullName`。番号を送らないときは必須です。 |
| `documentType` | string | いいえ | `NIT` | 任意。値: `NIT`、`CC`、`CE`、`PAS`、`TI`。 |

### 注意

- 番号または名前を送ります。少なくとも一つは必須です。
- 一覧に無い対象は `isFictitiousSupplier` が false の HTTP 200 です。
- その 200 を 404 として扱わないでください。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。
