# コロンビア — 金融の和議と清算

**金融の和議**照会は Superintendencia Financiera の和議・清算の行を読みます。NIT または名称を送ります。手続があるときだけ `inConcordatoOrLiquidation` は true です。手続が無くても HTTP 200 でフラグは false です。この経路はその単なる未検出に 404 を使いません。

## 応答に含まれる項目

- `inConcordatoOrLiquidation`
- `status` と `entityType`
- 単なる未検出では空の `matches`

## 用途

- すでに清算中の金融会社の受付を止めます。
- きれいな金融照会を 200 として保存します。
- NIT または法人名で検索します。

## API リファレンス

### Endpoint

```http
GET https://api.verifik.co/v2/co/superfinanciera/concordatos
```

一致には `status`、`entityType`、true の `inConcordatoOrLiquidation` があります。単なる未検出は HTTP 200 でフラグは false です。

### Headers

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| Content-Type | `application/json` | リクエスト形式 |
| Accept | `application/json` | レスポンス形式 |
| Authorization | `Bearer <token>` | クライアント JWT |

### Parameters

| 名前 | 型 | 必須 | 例 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **条件付き** | `900123456` | NIT または番号。別名 `nit`。名前が無いと必須。 |
| `businessName` | string | **条件付き** | `EJEMPLO SAS` | 名称。別名 `companyName` と `fullName`。番号が無いと必須。 |
| `documentType` | string | いいえ | `NIT` | 任意: `NIT`、`CC`、`CE`、`PAS`、`TI`。 |

### 注意

- 単なる未検出は `inConcordatoOrLiquidation` が false の HTTP 200 です。
- 番号または名前を送ります。
- その 200 を 404 に割り当てないでください。
- `Authorization` ヘッダーに Bearer JWT を付けます。
- JSON サンプルは項目の形を示します。実呼出しは送った値のレコードを返します。
- キャッシュ迂回フラグは送りません。このページはクライアント向けパラメータだけを説明します。

| 情報源に記録あり | `documentNumber: "860000001"` | 一致すると inConcordatoOrLiquidation が true の 200。 |
