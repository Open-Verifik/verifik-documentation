# Mensageria SMS

**Mensageria SMS** é **POST** `https://api.verifik.co/v2/communication/sms`, não GET. O corpo exige `phone` e `countryCode` (um indicativo que começa com `+`). A rota fixa `phoneGateway` em `sms`, então não envie esse campo. `title` opcional tem de 1 a 15 caracteres e `language` escolhe o texto. Tokens do dono da conta podem chamá-la. Um usuário staff precisa da permissão de execução do Smart Tools.

## O que a chamada devolve

- `phone` e `countryCode`
- `phoneGateway` em `sms`
- `status`

## Casos de uso

- Envie um código de acesso por SMS.
- Use um número nacional mais o indicativo.
- Deixe a rota escolher o gateway SMS.

---

## Referência da API

### Endpoint

```http
POST https://api.verifik.co/v2/communication/sms
```

Um envio bem-sucedido devolve `phoneGateway` `sms` e estado `sent`. A cobrança ocorre quando o OTP é entregue.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `phone` | string | **Sim** | `3001234567` | Só o número nacional. Não inclua o indicativo. |
| `countryCode` | string | **Sim** | `+57` | Indicativo que começa com `+`. |
| `title` | string | Não | `ACME` | Nome de remetente opcional, de 1 a 15 caracteres. |
| `language` | string | Não | `es` | Idioma opcional do modelo. |

<TabItem value="javascript" label="Node.js / JavaScript">

```javascript
import axios from "axios";

const options = {
  method: "POST",
  url: "https://api.verifik.co/v2/communication/sms",
  headers: {
    "Content-Type": "application/json",
    Accept: "application/json",
    Authorization: "Bearer <your_token>",
  },
  data: {
    "phone": "3001234567",
    "countryCode": "+57"
  },

try {
  const { data } = await axios.request(options);

  console.error(error.response ? error.response.data : error.message);
}
```

### Notas

- Esta rota é POST, não GET.
- `phone` e `countryCode` são obrigatórios. `countryCode` deve começar com `+`.
- Não envie `phoneGateway`; a rota o fixa em `sms`.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `phone: "3001234567"`, `countryCode: "+57"` | 200 quando o OTP SMS é enviado. |
| Valor obrigatório ausente | Omit `phone` | 409 MissingParameter. |
| Valor desconhecido | `countryCode: "57"` | 409 se countryCode não começar com +. |

401 when the bearer token is missing or rejected.
