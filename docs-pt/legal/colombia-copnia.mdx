# Colômbia — Licenças COPNIA por documento

A Verifik consulta o **COPNIA** (*Consejo Profesional Nacional de Ingeniería*) com **`documentType`** e **`documentNumber`**. A fonte ao vivo é o portal de Certificado de Vigência do COPNIA. Use este endpoint para **contratação**, **credenciamento** e **conformidade** de engenheiros na Colômbia.

## O que a API retorna

- Campos de **identidade**: `documentType`, `documentNumber`, `firstName`, `lastName`, `fullName`, `arrayName`
- **`licenses[]`** — matrículas profissionais encontradas para essa pessoa
- Cada licença pode incluir **`licenseNumber`**, **`licenseStatus`**, **`licenseType`**, **`profession`**, **`resolutionDate`**, **`resolutionNumber`**
- Resposta Verifik **assinada**

### Endpoint

```
GET https://api.verifik.co/v2/co/copnia
```

Envie **`documentType`** e **`documentNumber`** como **query**. O handler devolve a pessoa e um array `licenses`. Os campos de detalhe (`licenseStatus`, `licenseType`, `resolutionDate`, `resolutionNumber`) são hidratados para no máximo **10** licenças; as demais linhas mantêm apenas `licenseNumber` e `profession`.

### Cabeçalhos

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parâmetros

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `documentType` | string | Sim | Um de **`CC`**, **`CE`**, **`PA`**, **`PEP`**, **`PE`**, **`PPT`**, **`TI`**, **`NIT`**. | `CC` |
| `documentNumber` | string | Sim | Número do documento sem espaços ou pontuação (mínimo **5** caracteres). | `80176161` |

## Recursos

- Tipos aceitos: **CC**, **CE**, **PA**, **PEP**, **PE**, **PPT**, **TI**, **NIT**
- Apenas **GET** com parâmetros de consulta
- O **sandbox** devolve um payload no formato COPNIA para documentos de teste
- Respostas **assinadas**, cobradas como feature híbrida `apiRequest`

## Casos de uso

- **Contratação** e credenciamento de engenheiros
- **Conformidade** antes de adjudicar contratos
- **Onboarding** quando a matrícula COPNIA é exigida

### Observações

- Exemplo sandbox: **`CC` / `80176161`**. A licença sandbox é **`091132-0839078 CNDC`**.
- No máximo **10** licenças são hidratadas. As linhas extras mantêm `licenseNumber` e `profession`. Falha de detalhe é silenciosa (a linha da lista permanece).
- Falha de sessão ou da fonte pode devolver **`409`** com `timeout_data_source`.
- Trate a resposta como **dado pessoal sensível**.
- Para uma matrícula única, use [COPNIA por licença](/verifik-pt/legal/colombia-copnia-license).
