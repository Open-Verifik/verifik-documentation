# Colômbia — Licença COPNIA por matrícula

A Verifik consulta o **COPNIA** (*Consejo Profesional Nacional de Ingeniería*) com um único **`licenseNumber`** (matrícula). Use quando você já tem o número de registro e precisa do titular e do status.

## O que a API retorna

- Campos de **identidade**: `documentType`, `documentNumber`, `firstName`, `lastName`, `fullName`, `arrayName`
- Campos da licença no mesmo objeto: **`licenseNumber`**, **`licenseStatus`**, **`licenseType`**, **`profession`**, **`resolutionDate`**, **`resolutionNumber`**
- Resposta Verifik **assinada** (sem array `licenses[]`)

### Endpoint

```
GET https://api.verifik.co/v2/co/copnia/matricula
```

Envie **`licenseNumber`** como **query**. O handler devolve a pessoa e os seis campos da licença no mesmo objeto. Um valor típico é `091132-0839078 CNDC` (6–40 caracteres).

### Cabeçalhos

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parâmetros

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `licenseNumber` | string | Sim | Número de matrícula COPNIA, **6–40** caracteres. Espaços são permitidos. | `091132-0839078 CNDC` |

## Recursos

- Consulta por **matrícula** sem número de documento
- Apenas **GET** com parâmetros de consulta
- O **sandbox** devolve um payload COPNIA fixo para a licença de exemplo
- Respostas **assinadas**, cobradas como feature híbrida `apiRequest`

## Casos de uso

- Confirmar uma matrícula **impressa ou enviada**
- Revalidar o **status** (`VIGENTE` ou outro valor da fonte) no onboarding
- Cruzar uma licença encontrada em [COPNIA por documento](/verifik-pt/legal/colombia-copnia)

### Observações

- Exemplo sandbox: **`091132-0839078 CNDC`**. A pessoa associada é **`CC` / `80176161`**.
- Valor que normaliza para vazio retorna **`409`** (`invalid_license_number`).
- Falha de sessão ou da fonte pode devolver **`409`** com `timeout_data_source`.
- Trate a resposta como **dado pessoal sensível**.
