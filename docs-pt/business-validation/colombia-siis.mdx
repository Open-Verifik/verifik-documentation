# Colômbia — Sistema integrado de informação societária (SIIS)

A consulta **SIIS** lê os registros societários supervisionados pela Supersociedades. Envie um NIT ou uma razão social. `found` é true se houver registro e false se a sociedade simplesmente não estiver no SIIS. Essa ausência limpa é HTTP 200, com estado `NO REGISTRADA EN SIIS SUPERSOCIEDADES`. Use `inLiquidationOrReorganization` para um alerta concursal.

## O que a chamada devolve

- `found` e `inLiquidationOrReorganization`
- `ciiu`, setor e cidade
- `financialSummary` se houver registro
- `filings` — vazio numa ausência limpa

## Casos de uso

- Traga o último registro SIIS antes de estender crédito.
- Marque uma sociedade já em reorganização.
- Registre um fora-do-SIIS como 200, não como página ausente.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersociedades/siis
```

Um registro inclui `status`, `ciiu`, endereço, `financialSummary` e `filings`. `found` false significa que a sociedade não está no SIIS. Ambos são HTTP 200.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `900123456` | NIT ou número. Alias `nit`. Obrigatório sem nome. |
| `businessName` | string | **Condicional** | `INDUSTRIAS EJEMPLO SAS` | Nome, de 2 a 200 caracteres. Alias `companyName` e `fullName`. Obrigatório sem número. |
| `documentType` | string | Não | `NIT` | Opcional: `NIT`, `CC`, `CE`, `PAS` ou `TI`. |

### Notas

- Envie um NIT ou um nome.
- `found` false é uma ausência limpa bem-sucedida.
- Não mapeie esse corpo para HTTP 404.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `documentNumber: "900673447"` | 200 e found é true num acerto. |
| Valor obrigatório ausente | Omit number and name | 409 se nenhum valor for enviado. |
| Valor desconhecido | `documentNumber: "800000111"` | 200 e found é false numa ausência limpa. Isso não é 404. |

401 when the bearer token is missing or rejected.
