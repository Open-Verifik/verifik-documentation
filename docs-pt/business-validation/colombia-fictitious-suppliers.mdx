# Colômbia — Fornecedores fictícios ou insolventes (DIAN)

A consulta de **fornecedores fictícios ou insolventes** filtra o artigo 671 da DIAN. Envie `documentNumber` (ou o alias `nit`) ou `businessName` (alias `companyName` e `fullName`). Um fornecedor listado põe `isFictitiousSupplier` em true e inclui a resolução. Uma ausência limpa continua HTTP 200 com `isFictitiousSupplier` false. Esta rota não responde 404 numa ausência limpa.

## O que a chamada devolve

- `isFictitiousSupplier` — true só se a DIAN listar o sujeito
- `resolutionNumber`, `resolutionDate` e `publicationDate` num acerto
- `matches` — vazio se nada estiver listado
- `status` — rótulo da lista ou frase de não listado

## Casos de uso

- Bloqueie um fornecedor que a DIAN marcou como fictício ou insolvente.
- Registre uma ausência limpa como 200 com a bandeira false.
- Busque por NIT ou por razão social.

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/co/dian/proveedores-ficticios
```

Num acerto, `isFictitiousSupplier` é true e `matches` traz o número da resolução, as datas e a direção seccional. Numa ausência limpa, `isFictitiousSupplier` é false. Os dois resultados são HTTP 200.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `900123456` | NIT ou número da pessoa, de 4 a 25 caracteres. Alias: `nit`. Obrigatório se nenhum nome for enviado. |
| `businessName` | string | **Condicional** | `INDUSTRIAS EJEMPLO SAS` | Razão ou nome comercial, de 2 a 200 caracteres. Alias: `companyName` e `fullName`. Obrigatório se nenhum número for enviado. |
| `documentType` | string | Não | `NIT` | Opcional. Valores: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### Notas

- Envie um número ou um nome. Pelo menos um é obrigatório.
- Quem não está na lista é HTTP 200 com `isFictitiousSupplier` false.
- Não trate esse 200 como 404.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `documentNumber: "900123456"` | 200 com isFictitiousSupplier true quando a fonte lista o sujeito. |
| Valor obrigatório ausente | Omit every search value | 409 MissingParameter se nenhum valor de busca for enviado. |
| Valor desconhecido | `documentNumber: "00000000"` | 200 com isFictitiousSupplier false. Uma ausência limpa continua HTTP 200 e não é 404. |

401 when the bearer token is missing or rejected.
