# Colômbia — Concordatas e liquidações financeiras

A consulta de **insolvência financeira** lê concordatas e liquidações da Superintendencia Financiera. Envie um NIT ou um nome. `inConcordatoOrLiquidation` é true só se houver um processo. Uma sociedade sem processo continua HTTP 200, com a bandeira false. Esta rota não usa 404 nessa ausência limpa.

## O que a chamada devolve

- `inConcordatoOrLiquidation`
- `status` e `entityType`
- `matches` vazio numa ausência limpa

## Casos de uso

- Interrompa a admissão de uma entidade já em liquidação.
- Guarde uma triagem limpa como 200.
- Busque por NIT ou razão social.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/co/superfinanciera/concordatos
```

Um acerto inclui `status`, `entityType` e `inConcordatoOrLiquidation` true. Uma ausência limpa mantém HTTP 200 e a bandeira false.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `900123456` | NIT ou número. Alias `nit`. Obrigatório sem nome. |
| `businessName` | string | **Condicional** | `EJEMPLO SAS` | Nome. Alias `companyName` e `fullName`. Obrigatório sem número. |
| `documentType` | string | Não | `NIT` | Opcional: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### Notas

- Uma ausência limpa é HTTP 200 com `inConcordatoOrLiquidation` false.
- Envie um número ou um nome.
- Não mapeie esse 200 para 404.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `documentNumber: "860000001"` | 200 com inConcordatoOrLiquidation true num acerto. |

| Valor desconhecido | `documentNumber: "800000111"` | 200 com inConcordatoOrLiquidation false. Uma ausência limpa não é 404. |

401 when the bearer token is missing or rejected.
