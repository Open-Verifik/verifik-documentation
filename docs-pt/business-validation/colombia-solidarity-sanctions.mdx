# Colômbia — Sanções do setor solidário

A consulta de **sanções solidárias** lê o boletim de sancionados da Supersolidaria. Envie um número ou um nome. `isSanctioned` é true só se houver sanção. Uma ausência limpa é HTTP 200 com `isSanctioned` false, `sanctionsCount` 0 e estado `SIN SANCIONES REGISTRADAS`. Esta rota não responde 404 nessa ausência.

## O que a chamada devolve

- `isSanctioned` e `sanctionsCount`
- `status`
- `matches`

## Casos de uso

- Filtre uma cooperativa antes de financiá-la.
- Registre uma checagem limpa como 200.
- Busque por NIT ou pelo nome sancionado.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/co/supersolidaria/sanciones
```

Um acerto inclui `sanctionsCount` e `matches`. Uma ausência limpa é HTTP 200 com `isSanctioned` false.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `900123456` | NIT ou número. Alias `nit`. |
| `businessName` | string | **Condicional** | `EJEMPLO SAS` | Nome. Alias `companyName` e `fullName`. |
| `documentType` | string | Não | `NIT` | Opcional: `NIT`, `CC`, `CE`, `PAS`, `TI`. |

### Notas

- Uma ausência limpa é HTTP 200 com `isSanctioned` false.
- Envie pelo menos um valor de busca.
- Não mapeie esse 200 para 404.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `documentNumber: "900555111"` | 200 com isSanctioned true num acerto. |
| Valor obrigatório ausente | Omit number and name | 409 se nenhum valor for enviado. |
| Valor desconhecido | `documentNumber: "800000111"` | 200 com isSanctioned false. A ausência limpa não é 404. |

401 when the bearer token is missing or rejected.
