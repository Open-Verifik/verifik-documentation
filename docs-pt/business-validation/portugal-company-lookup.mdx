# Portugal — Consulta ao registro empresarial (KYB)

A **consulta ao registro empresarial de Portugal** verifica uma pessoa jurídica no registro oficial de empresas. Envie o número de registro ou o identificador fiscal (NIF / NIPC) em `documentNumber`. Use para onboarding KYB, diligência de fornecedores e triagem de contrapartes.

`documentNumber` é obrigatório. `documentType` é opcional. Quando o enviar, use a família do identificador (por exemplo `NIPC`) para distinguir países com mais de um número.

## O que o registro devolve

- Razão social
- Status de registro
- Data de constituição
- Identificador fiscal ou de registro
- Endereço registrado

## Casos de uso

- Cadastrar um fornecedor ou uma contraparte em Portugal antes do primeiro pagamento.
- Confirmar a razão social e o status de registro impressos em um contrato ou fatura.
- Reunir a data de constituição, o identificador fiscal e o endereço para um dossiê KYB.

## Referência da API

### Ponto de acesso

```http
GET https://api.verifik.co/v2/pt/company
```

Consulte o registro oficial de empresas de Portugal com `documentNumber` e um `documentType` opcional. Uma resposta bem-sucedida inclui a razão social, o status de registro, a data de constituição, o identificador fiscal (NIF / NIPC) e o endereço registrado. Use em um onboarding KYB ou na diligência de um fornecedor. O exemplo mostra esses campos. Os valores ao vivo, inclusive o texto de `status`, vêm do registro.

### Cabeçalhos

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da requisição |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | Token JWT de autenticação do cliente |

### Parâmetros

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Sim** | `500100144` | Número oficial de registro empresarial ou identificador fiscal (NIF / NIPC). |
| `documentType` | string | Não | `NIPC` | Tipo de documento societário ou prefixo de registro. Exemplos aceitos: `NIF`, `NIPC`. Omita-o para enviar apenas o número oficial. |

### Observações

- **Formato do identificador.** O NIF e o NIPC têm 9 dígitos. Envie apenas dígitos, sem espaços.
- Tipo de documento societário ou prefixo de registro. Exemplos aceitos: `NIF`, `NIPC`. Omita-o para enviar apenas o número oficial.
- O rótulo de status do exemplo ilustra o campo. O registro ao vivo devolve o próprio rótulo, que pode estar no idioma local.
- Envie `documentNumber` e, quando precisar nomear a família do identificador, `documentType`. Esses são os parâmetros de cliente desta rota.
- O JSON de exemplo ilustra os campos acima. Uma chamada ao vivo devolve a ficha do registro para o identificador enviado.

## Testes no sandbox

Com a conta em modo sandbox, os mesmos parâmetros exercitam esta rota. A tabela descreve a resposta documentada para cada caso.

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| **Identificador existente** | `documentType: "NIPC"`, `documentNumber: "500100144"` | 200 com nome legal, status, identificador e endereço ou atributos de identidade quando a fonte possui o número. |
| **Sem documentNumber** | Omitir `documentNumber` | 409 `MissingParameter` quando `documentNumber` é omitido. |
| **Número desconhecido** | `documentNumber: "000000000"` | 404 `NotFound` quando o registro não tem ficha para esse número. |

401 quando o token bearer está ausente ou é recusado.
