# Detecção facial

**Detecção facial** é `POST /v2/face-recognition/face-validation`, um alias do motor de detecção. `image` é obrigatória. Se os omitir, esta rota põe `min_score` em `0.5` e `search_mode` em `FAST`. A carga real é `face_count`, `faces` (cada um com `score` e `bbox`), `imageDimensions` e `engine`.

## O que a chamada devolve

- `face_count`
- `faces[].score` e `faces[].bbox`
- `imageDimensions` e `engine`

## Casos de uso

- Conte rostos antes da prova de vida.
- Leia a caixa do rosto principal.
- Use a pontuação e o modo padrão se só tiver a imagem.

---

## Referência da API

### Endpoint

```http
POST https://api.verifik.co/v2/face-recognition/face-validation
```

Leia primeiro `face_count`. Cada item de `faces` tem `score` e `bbox`. `imageDimensions` é a largura e a altura decodificadas. `engine` nomeia o detector.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `image` | string | **Sim** | `data:image/jpeg;base64,AAAA` | Imagem do rosto em base64 ou data URI. Obrigatória. |
| `min_score` | number | Não | `0.5` | Opcional. Esta rota o deixa em `0.5` por padrão. |
| `search_mode` | string | Não | `FAST` | Opcional. Esta rota o deixa em `FAST` por padrão. O outro valor é `ACCURATE`. |

### Notas

- `image` é o único campo obrigatório.
- Um `min_score` omitido vira `0.5` e um `search_mode` omitido vira `FAST`.
- A resposta usa `bbox`, não um objeto de pontos separado.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `image` only | 200 com face_count, faces, imageDimensions e engine. |
| Valor obrigatório ausente | Omit `image` | 409 MissingParameter. |
| Valor desconhecido | `min_score: 0.8`, `search_mode: "ACCURATE"` | 200 com a pontuação e o modo enviados. |

401 when the bearer token is missing or rejected.
