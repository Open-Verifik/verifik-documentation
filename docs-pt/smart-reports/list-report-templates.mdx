Liste os templates de Smart Report disponíveis para o cliente autenticado. Por padrão, este endpoint retorna tanto os templates personalizados pertencentes ao seu cliente quanto os templates `"System"` integrados da Verifik para que você possa descobrir IDs de templates reutilizáveis (`_id`), inspecionar configurações de layout e tema e escolher um template antes de disparar execuções `SmartBatch` ou renderizações de amostra.

Em pipelines de verificação headless e fluxos com agentes de IA, chame este endpoint primeiro para localizar um template existente vinculado a uma `batchConfiguration`, filtrar templates `"System"` integrados por `country`, `category` ou `tier`, ou verificar se um template personalizado está ativo antes de cloná-lo ou atualizá-lo. Listar templates não renderiza PDFs nem consome créditos.

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates
```

O proxy do Smart-Agent (`https://ai.verifik.co`) expõe os mesmos caminhos `/v2/...` e exige o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>`.

As respostas populam `batchConfiguration` e `client` e selecionam `+thumbnail.image` para que dashboards e pré-visualizações headless possam inspecionar miniaturas dos templates sem uma requisição adicional.

### Cabeçalhos

| Nome          | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parâmetros

Todos os parâmetros de consulta são opcionais.

| Nome                 | Tipo    | Obrigatório | Descrição                                                                                                                                                   |
| -------------------- | ------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `batchConfiguration` | string  | Não         | Filtra templates vinculados a um ObjectId específico de configuração `SmartBatch`.                                                                          |
| `type`               | string  | Não         | Filtra por origem: `"client"` ou `"System"`. Quando omitido, retorna os templates do próprio cliente junto com os templates `"System"` integrados.           |
| `country`            | string  | Não         | Filtro de país. Convertido automaticamente para maiúsculas no servidor (por exemplo, `CO`, `MX` ou `COLOMBIA`).                                             |
| `category`           | string  | Não         | Filtro de categoria de domínio: `"citizen"`, `"company"` ou `"vehicle"`.                                                                                    |
| `tier`               | string  | Não         | Filtro de nível do template: `"essential"` ou `"comprehensive"`.                                                                                            |
| `isActive`           | boolean | Não         | Filtra pelo estado ativo (`true` ou `false`).                                                                                                               |
| `search`             | string  | Não         | Busca regex sem distinção entre maiúsculas e minúsculas em `name` e `systemKey`. Quando `search` é enviado sem `type`, busca nos seus templates e nos templates `"System"`. |
| `page`               | integer | Não         | Número da página (base 1). Tanto `page` quanto `limit` devem ser fornecidos juntos para habilitar a paginação neste módulo.                                 |
| `limit`              | integer | Não         | Tamanho da página. Deve ser fornecido junto com `page` para paginar os resultados.                                                                          |
| `sort`               | string  | Não         | Especificação de ordenação. O padrão é `type: 1, createdAt: -1` (ordenando por tipo de template e mais recentes primeiro).                                  |

### Notas

- Tanto `page` quanto `limit` devem ser fornecidos juntos para paginar os resultados. Enviar apenas um parâmetro sem o outro não ativa a paginação.
- Templates `"System"` integrados retornados na lista são somente leitura. Tentar modificá-los ou excluí-los retorna `403` (`system_template_readonly`). Para personalizar um modelo inicial, envie o layout dele para [Criar um template de relatório](/verifik-pt/smart-reports/create-a-report-template).
- Use [Listar temas iniciais](/verifik-pt/smart-reports/list-theme-starters) quando quiser modelos iniciais limpos agrupados por `reportTheme`.
