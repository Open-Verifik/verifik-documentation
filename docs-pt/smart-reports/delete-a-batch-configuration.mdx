Exclua uma `BatchConfiguration` pertencente à sua conta de cliente. O endpoint remove o documento de configuração e retorna o documento excluído em `data`.

Se `{id}` não existir ou pertencer a outra conta de cliente, o endpoint retorna `404` (`not_found`). Excluir uma configuração não executa consultas e não consome créditos.

### Endpoint

```
DELETE https://api.verifik.co/v2/batch-configurations/{id}
```

Também acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/batch-configurations/{id}` usando seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome | Valor |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

O token deve ser um **JWT de cliente**. Credenciais ausentes ou inválidas retornam `401 Unauthorized`.

### Parâmetros

| Nome | Tipo | Obrigatório | Descrição |
| ---- | ---- | ----------- | --------- |
| `id` | string | Sim | ObjectId da `BatchConfiguration` a excluir. |

### Notas

- Excluir uma configuração retorna o documento excluído dentro de `data`. Requisições `GET`, `PUT` ou `DELETE` subsequentes usando o mesmo `{id}` não encontrarão mais o registro (`GET` retorna `data: null`; `GET /input-schema`, `PUT` e `DELETE` retornam `404` `not_found`).
- Excluir uma configuração não consome créditos.
