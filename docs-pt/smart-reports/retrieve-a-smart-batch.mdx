Obtenha um único documento `SmartBatch` por ID para o cliente autenticado. Antes de retornar o payload, o servidor mescla quaisquer saídas armazenadas externamente em `smartbatchrows` dentro de `rows[].results` e executa `healIncompleteRows()` para reabrir linhas marcadas como `completed` que estejam sem etapas habilitadas da configuração.

Se o lote não existir ou pertencer a outra conta de cliente, o endpoint retorna `200` com `{ "data": null }`. Ler um lote não executa verificações nem consome créditos.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/{id}
```

Este endpoint também é acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batches/{id}` usando seu próprio `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                      |
| --------------- | ---------------------- | ---------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros de caminho

| Nome | Tipo   | Obrigatório | Descrição |
| ---- | ------ | ----------- | --------- |
| `id` | string | Sim         | ObjectId do `SmartBatch`. |

### Parâmetros de consulta

| Nome          | Tipo     | Obrigatório | Descrição |
| ------------- | -------- | ----------- | --------- |
| `select`      | string   | Não         | Expressão de projeção de campos (por exemplo, `"-rows"` para excluir payloads de linhas). |
| `columns`     | string   | Não         | Subconjunto de campos a incluir no documento retornado. |
| `populates[]` | string[] | Não         | Documentos relacionados a popular: `"batchConfiguration"` e/ou `"client"`. |

### Notas

- Os resultados externos de etapas em `smartbatchrows` são mesclados automaticamente em `rows[].results` ao ler o lote.
- `healIncompleteRows()` inspeciona cada linha `completed` em relação às etapas habilitadas da `batchConfiguration` e reabre qualquer linha sem saída de etapa ou erros de volta para `pending`.
- Para consultas frequentes de status (polling), dê preferência a [Obter progresso do Smart Batch](/verifik-pt/smart-reports/get-smart-batch-progress) para evitar baixar repetidamente os payloads completos das linhas.
