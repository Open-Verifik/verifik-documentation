Atualize um template de Smart Report personalizado pertencente à sua conta de cliente. Envie qualquer subconjunto de metadados atualizáveis, `sections` de layout, `reportTheme`, `sampleData` ou opções de renderização de PDF; os campos omitidos no payload mantêm seus valores atuais.

Em pipelines headless e de IA, use este endpoint para iterar sobre layouts gerados por [Gerar layout do template](/verifik-pt/smart-reports/generate-template-layout), atualizar ativos da marca (`logo`, `primaryColor`, `customFonts`), atualizar vínculos do `SmartBatch` ou alternar `isActive`. Templates `"System"` integrados são somente leitura e retornam `403` (`system_template_readonly`) caso sejam alvo de atualização.

### Endpoint

```
PUT https://api.verifik.co/v2/smart-report-templates/{id}
```

O proxy do Smart-Agent (`https://ai.verifik.co`) expõe os mesmos caminhos `/v2/...` e exige o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>`.

### Cabeçalhos

| Nome          | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição                             |
| ---- | ------ | ----------- | ------------------------------------- |
| `id` | string | Sim         | ObjectId do template de Smart Report. |

### Corpo

Todos os campos do corpo são opcionais na atualização.

| Nome                  | Tipo             | Obrigatório | Descrição                                                                                                                                        |
| --------------------- | ---------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `name`                | string           | Não         | Nome de exibição atualizado do template. Máximo de `150` caracteres.                                                                             |
| `description`         | string           | Não         | Descrição atualizada do template. Máximo de `500` caracteres.                                                                                    |
| `batchConfiguration`  | string           | Não         | ObjectId de uma configuração `SmartBatch` associada.                                                                                             |
| `country`             | string           | Não         | Identificador ou rótulo do país. Máximo de `60` caracteres.                                                                                      |
| `category`            | string           | Não         | Domínio de verificação: `"citizen"`, `"company"` ou `"vehicle"`.                                                                                 |
| `isActive`            | boolean          | Não         | Ativa ou desativa o template.                                                                                                                    |
| `logo`                | string           | Não         | URL do logotipo da marca ou data URI em base64.                                                                                                  |
| `primaryColor`        | string           | Não         | Cor hexadecimal de destaque principal da marca.                                                                                                  |
| `identityColor`       | string           | Não         | Cor hexadecimal de destaque secundário/identidade.                                                                                               |
| `pageBackgroundColor` | string           | Não         | Cor hexadecimal do fundo da página.                                                                                                              |
| `header`              | object           | Não         | Configuração personalizada de layout e conteúdo do cabeçalho.                                                                                    |
| `footer`              | object           | Não         | Configuração personalizada de layout e conteúdo do rodapé.                                                                                       |
| `legend`              | string           | Não         | Texto de legenda no rodapé ou aviso de conformidade. Máximo de `2000` caracteres.                                                                |
| `legendPosition`      | string           | Não         | Alinhamento da legenda: `"left"`, `"center"` ou `"right"`.                                                                                       |
| `termsAndConditions`  | string           | Não         | Texto dos termos e condições legais. Máximo de `4000` caracteres.                                                                                |
| `termsPosition`       | string           | Não         | Alinhamento dos termos: `"left"`, `"center"` ou `"right"`.                                                                                       |
| `sections`            | object[]         | Não         | Array de objetos `ReportSection` (`id`, `type`, `order`, `dataPath`, `label`, `staticContent`, `columns`, `columnsPerRow`, `keyOverrides`, `valueRules`, `chartKind`, `style`, `condition`, `frame`, etc.). |
| `pageSize`            | string           | Não         | Tamanho do papel do PDF: `"A4"`, `"Letter"` ou `"Legal"`.                                                                                        |
| `layoutVersion`       | integer          | Não         | Versão do renderizador de layout: `1` ou `2`.                                                                                                    |
| `orientation`         | string           | Não         | Orientação da página: `"portrait"` ou `"landscape"`.                                                                                             |
| `margins`             | object           | Não         | Objeto de margens `` `{ "top": 40, "right": 40, "bottom": 40, "left": 40 }` ``.                                                                  |
| `pdfEngine`           | string           | Não         | Motor de renderização de PDF: `"puppeteer"` ou `"pdfkit"`.                                                                                       |
| `showPageNumbers`     | boolean          | Não         | Exibe números de página nos PDFs renderizados.                                                                                                   |
| `pageNumberPosition`  | string           | Não         | Posição do número de página: `"top-left"`, `"top-center"`, `"top-right"`, `"bottom-left"`, `"bottom-center"` ou `"bottom-right"`.                |
| `pageNumberDivider`   | boolean / string | Não         | Configuração do divisor do número de página.                                                                                                     |
| `watermark`           | object           | Não         | Configurações da camada de marca d'água.                                                                                                         |
| `security`            | object           | Não         | Configurações de proteção do PDF `` `{ "enabled": true, "password": "..." }` ``. Enviar `"******"` ou omitir `password` preserva a senha criptografada existente. |
| `signature`           | object           | Não         | Configuração do bloco de assinatura.                                                                                                             |
| `logoSettings`        | object           | Não         | Configuração de tamanho e posicionamento do logotipo.                                                                                            |
| `sheetImages`         | object[]         | Não         | Recursos de imagem incorporados ao template. Máximo de `12` itens.                                                                               |
| `customFonts`         | object[]         | Não         | Declarações de fontes personalizadas (Google Fonts, URL externa ou arquivo enviado). Máximo de `6` itens.                                        |
| `headerLogos`         | object[]         | Não         | Logotipos adicionais exibidos no cabeçalho. Máximo de `16` itens.                                                                                |
| `bodyTopPadding`      | number           | Não         | Espaçamento superior aplicado ao corpo do documento, de `0` a `600`.                                                                             |
| `sampleData`          | object           | Não         | Payload de verificação de exemplo armazenado com o template para pré-visualizações e downloads de amostra.                                       |
| `endpointDesign`      | object           | Não         | Metadados de apresentação específicos do endpoint.                                                                                               |
| `reportTheme`         | string / object  | Não         | ID da predefinição de tema (`"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"`) ou objeto (`id`, `scoreScale`, `scoreEnabled`, `scoreProfile`, `locale`, `density`, `eyebrow`, `coverTitle`, `headlines`, `legalNote`, `showVerifiedBadge`, `showWeights`, `showDeductions`, `showFields`, `showHowItWorks`, `blocks`, `tokens`). |

### Notas

- Passar `security.password: "******"` ou omitir `security.password` preserva a senha criptografada existente do template em vez de sobrescrevê-la.
- Templates `"System"` integrados não podem ser atualizados (`403` `system_template_readonly`). Crie uma cópia personalizada via [Criar um template de relatório](/verifik-pt/smart-reports/create-a-report-template) ao personalizar um modelo inicial de sistema.
- Armazene auxiliares de pré-visualização (`scoreScale`, `themeTokens`, `scoreSettings`) dentro de `reportTheme` (`scoreScale`, `tokens`, `scoreEnabled`/`scoreProfile`) ao salvar alterações.
