Reenfileire linhas no status `"failed"` ou `"partial"` em um `SmartBatch` sem afetar as linhas que já foram concluídas. Opcionalmente, envie `rowIndexes` para tentar novamente apenas um subconjunto específico de linhas; omita `rowIndexes` para tentar novamente todas as linhas `"failed"` e `"partial"` do lote.

A requisição falha com `409 Conflict` (`batch_is_processing`) se o lote estiver atualmente no status `"processing"`. Retornar `retried: 0` indica que nenhuma linha elegível com falha ou parcial correspondeu.

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/{id}/retry-failed
```

Este endpoint também é acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batches/{id}/retry-failed` usando seu próprio `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                      |
| --------------- | ---------------------- | ---------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição |
| ---- | ------ | ----------- | --------- |
| `id` | string | Sim         | ObjectId do `SmartBatch`. |

### Corpo

| Nome         | Tipo      | Obrigatório | Descrição |
| ------------ | --------- | ----------- | --------- |
| `rowIndexes` | integer[] | Não         | Índices de linha específicos baseados em `0` (`>= 0`, máximo de `10000` itens) para tentar novamente. Omita para tentar novamente todas as linhas `"failed"` e `"partial"`. |

Chaves desconhecidas no corpo são rejeitadas pela validação Joi com `409 MissingParameter`.

### Notas

- Envie `{}` (ou omita `rowIndexes`) para tentar novamente todas as linhas `"failed"` e `"partial"` de uma só vez.
- Quando `rowIndexes` é fornecido, linhas nos status `"completed"` ou `"pending"` são ignoradas mesmo que seus índices estejam incluídos.
- Para reexecutar apenas sequências de etapas específicas em uma única linha preservando os resultados de outras etapas, use [Tentar novamente etapas da linha do Smart Batch](/verifik-pt/smart-reports/retry-batch-row-steps).
