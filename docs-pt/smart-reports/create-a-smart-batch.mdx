Crie um `SmartBatch` vinculado a uma `BatchConfiguration` existente. Você fornece um `name` de exibição e pelo menos uma linha de entrada em `rows`. Criar o lote persiste as linhas de entrada com `status: "draft"` e não executa etapas do catálogo nem consome créditos até que a execução seja iniciada.

Cada entrada em `rows` aceita um objeto encapsulado (`{ rowIndex?, inputData }`) ou um objeto plano (`{ rowIndex?, ...inputFields }`), que a camada de validação normaliza para `{ rowIndex, inputData }`. **Não** inclua `status`, `results` ou `errors` na criação.

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches
```

Este endpoint também é acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batches` usando seu próprio `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                      |
| --------------- | ---------------------- | ---------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Corpo

| Nome                 | Tipo     | Obrigatório | Descrição |
| -------------------- | -------- | ----------- | --------- |
| `batchConfiguration` | string   | Sim         | ObjectId da `BatchConfiguration` que define as etapas do fluxo de trabalho. |
| `name`               | string   | Sim         | Nome de exibição do lote. Máximo de `150` caracteres. |
| `executor`           | string   | Não         | Modo de execução: `"queue"`, `"featureRunner"` ou `"browser"`. Quando derivado de `batchConfiguration`, é normalizado para `"queue"` ou `"browser"`. |
| `source`             | string   | Não         | Identificador do produto de origem: `"smart_batch"` (padrão) ou `"smart_fleet"`. |
| `rows`               | object[] | Sim         | Array com pelo menos `1` linha (`min 1`). Aceita `{ rowIndex?, inputData }` encapsulado ou `{ rowIndex?, ...inputFields }` plano. **Não** envie `status`, `results` ou `errors` na criação. |

Chaves desconhecidas e propriedades de linha não permitidas (`status`, `results`, `errors`) são rejeitadas pela validação Joi com `409 MissingParameter`.

### Notas

- Nunca passe `status`, `results` ou `errors` dentro de `rows` ao criar um lote; linhas recém-criadas sempre começam no status `pending`.
- Se `executor` for omitido, ele é resolvido a partir de `batchConfiguration.executor` e normalizado para `"queue"` ou `"browser"`.
- Após a criação, chame [Estimar custo do Smart Batch](/verifik-pt/smart-reports/estimate-smart-batch-cost) para pré-visualizar as cobranças de créditos e [Iniciar um Smart Batch](/verifik-pt/smart-reports/start-a-smart-batch) para iniciar o processamento.
- Para importações em massa de CSV, XLSX ou JSONL com validação de dependências e execução imediata opcional, use [Criar um Smart Batch a partir de arquivo](/verifik-pt/smart-reports/create-smart-batch-from-file).
