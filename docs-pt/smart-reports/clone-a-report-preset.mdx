Clone um preset de sistema selecionado do Smart Report para a sua conta de cliente. A operação retorna tanto uma `BatchConfiguration` quanto um `SmartReportTemplate` vinculado, prontos para executar imediatamente ou personalizar posteriormente.

Este endpoint é **idempotente** para contas de cliente. Se já existir um template de cliente ativo clonado de `{systemKey}`, o servidor reutiliza essa configuração e esse template (remapeando as sequências de etapas se necessário) e retorna `reused: true`. Caso contrário, cria uma nova `BatchConfiguration` (com `inputFormat: "csv"`, `outputFormat: "csv"`, `mergeStrategy: "sequential"`) e um novo `SmartReportTemplate` do cliente (`clonedFromSystemKey` definido como `{systemKey}`) vinculado via `preferredReportTemplate` com `reused: false`. Este endpoint também é exposto como a ferramenta MCP `smart_report_clone_preset`.

### Endpoint

```
POST https://api.verifik.co/v2/smart-batch-presets/{systemKey}/clone
```

Também acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batch-presets/{systemKey}/clone` usando seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome | Valor |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

O token deve ser um **JWT de cliente**. Credenciais ausentes ou inválidas retornam `401 Unauthorized`.

### Parâmetros

| Nome | Tipo | Obrigatório | Descrição |
| ---- | ---- | ----------- | --------- |
| `systemKey` | string | Sim | Chave do preset obtida em [Listar presets de relatório](/verifik-pt/smart-reports/list-report-presets). Aparada, máximo de `120` caracteres, deve corresponder a `/^[a-z0-9][a-z0-9._-]{1,118}$/i`. |

### Corpo

Nenhum corpo de requisição é obrigatório para este endpoint.

### Notas

- Clonar um preset não executa consultas e não consome créditos.
- Chamar este endpoint repetidamente com o mesmo `{systemKey}` é seguro e idempotente para uma conta de cliente: a configuração e o template clonados existentes são retornados com `reused: true`.
- `409 MissingParameter` é retornado quando `{systemKey}` falha na validação de caminho do Joi (por exemplo, exceder `120` caracteres ou conter caracteres não suportados). `409` com `preset_has_no_steps` é retornado se o preset correspondente não tiver etapas configuradas.
- `500 InternalServerError` pode ocorrer se um recurso obrigatório do preset não estiver disponível na sua conta.
- Após clonar, chame [Obter schema de entrada da configuração](/verifik-pt/smart-reports/retrieve-configuration-input-schema) com `batchConfiguration._id` antes de enviar linhas, ou use a ferramenta MCP `smart_report_clone_preset`.
