Cancele um `SmartBatch` (e qualquer execução `FeatureRunner` anexada). O lote faz a transição para `status: "cancelled"` e define `completedAt`.

Lotes que já estão em um status terminal (`"completed"`, `"failed"` ou `"cancelled"`) não podem ser cancelados e retornam `400 BadRequest` (`batch_already_terminal`).

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/{id}/cancel
```

Este endpoint também é acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batches/{id}/cancel` usando seu próprio `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                      |
| --------------- | ---------------------- | ---------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição |
| ---- | ------ | ----------- | --------- |
| `id` | string | Sim         | ObjectId do `SmartBatch` a cancelar. |

### Notas

- Lotes cancelados preservam todos os resultados de linhas coletados anteriormente e podem ser reiniciados mais tarde via [Iniciar um Smart Batch](/verifik-pt/smart-reports/start-a-smart-batch).
- Se você quiser interromper o processamento temporariamente e continuar depois sem reiniciar, use [Pausar um Smart Batch](/verifik-pt/smart-reports/pause-a-smart-batch).
