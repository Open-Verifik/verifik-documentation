Consulte um único template de Smart Report pelo seu ObjectId (`{id}`). Isso retorna a especificação completa do template, incluindo `sections`, `reportTheme`, `sampleData`, configurações de layout de página e referências populadas de `batchConfiguration` e `client`.

Em fluxos de trabalho headless e de IA, use este endpoint para carregar o array `sections` atual antes de chamar [Gerar layout do template](/verifik-pt/smart-reports/generate-template-layout) no modo `append` ou `edit`, buscar o `sampleData` armazenado para [Pré-visualizar HTML do template](/verifik-pt/smart-reports/preview-template-html) ou inspecionar um template antes de executar uma atualização `PUT`. Por segurança e eficiência no tamanho do payload, `security.password` e `thumbnail.image` são removidos da seleção neste endpoint.

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/{id}
```

O proxy do Smart-Agent (`https://ai.verifik.co`) expõe os mesmos caminhos `/v2/...` e exige o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>`.

### Cabeçalhos

| Nome          | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição                             |
| ---- | ------ | ----------- | ------------------------------------- |
| `id` | string | Sim         | ObjectId do template de Smart Report. |

### Notas

- Quando o template não existe ou pertence a outro cliente, este endpoint retorna HTTP `200` com `{ "data": null }` em vez de `404`.
- `security.password` e `thumbnail.image` são excluídos do documento retornado. Para renderizar ou inspecionar a miniatura do template, use [Listar templates de relatório](/verifik-pt/smart-reports/list-report-templates).
