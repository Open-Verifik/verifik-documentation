Crie um template de Smart Report personalizado pertencente ao cliente autenticado. Apenas `name` é obrigatório; todas as opções de identidade visual, `sections` de layout, `reportTheme`, `sampleData` e motor de PDF são opcionais e podem ser atualizadas posteriormente com [Atualizar um template de relatório](/verifik-pt/smart-reports/update-a-report-template).

Em pipelines headless e orientados por IA, use este endpoint para persistir layouts produzidos por [Gerar layout do template](/verifik-pt/smart-reports/generate-template-layout), clonar e personalizar um modelo inicial integrado de [Listar temas iniciais](/verifik-pt/smart-reports/list-theme-starters) ou provisionar templates PDF específicos por ambiente para pipelines `SmartBatch` via código. Salvar um template dispara a geração assíncrona de miniatura e retorna **HTTP `200`** (não `201`) com o documento criado em `{ "data": ... }`.

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates
```

O proxy do Smart-Agent (`https://ai.verifik.co`) expõe os mesmos caminhos `/v2/...` e exige o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>`.

### Cabeçalhos

| Nome          | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Corpo

| Nome                  | Tipo             | Obrigatório | Descrição                                                                                                                                        |
| --------------------- | ---------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `name`                | string           | Sim         | Nome de exibição do template. Máximo de `150` caracteres.                                                                                        |
| `description`         | string           | Não         | Descrição legível do template. Máximo de `500` caracteres.                                                                                       |
| `batchConfiguration`  | string           | Não         | ObjectId de uma configuração `SmartBatch` associada.                                                                                             |
| `country`             | string           | Não         | Identificador ou rótulo do país. Máximo de `60` caracteres.                                                                                      |
| `category`            | string           | Não         | Domínio de verificação: `"citizen"`, `"company"` ou `"vehicle"`.                                                                                 |
| `isActive`            | boolean          | Não         | Se o template está ativo. O padrão é `true`.                                                                                                     |
| `logo`                | string           | Não         | URL do logotipo da marca ou data URI em base64.                                                                                                  |
| `primaryColor`        | string           | Não         | Cor hexadecimal de destaque principal da marca. O padrão é `"#4F46E5"`.                                                                          |
| `identityColor`       | string           | Não         | Cor hexadecimal de destaque secundário/identidade. O padrão é `"#000000"`.                                                                       |
| `pageBackgroundColor` | string           | Não         | Cor hexadecimal do fundo da página. O padrão é `"#ffffff"`.                                                                                      |
| `header`              | object           | Não         | Configuração personalizada de layout e conteúdo do cabeçalho.                                                                                    |
| `footer`              | object           | Não         | Configuração personalizada de layout e conteúdo do rodapé.                                                                                       |
| `legend`              | string           | Não         | Texto de legenda no rodapé ou aviso de conformidade. Máximo de `2000` caracteres.                                                                |
| `legendPosition`      | string           | Não         | Alinhamento da legenda: `"left"`, `"center"` ou `"right"`.                                                                                       |
| `termsAndConditions`  | string           | Não         | Texto dos termos e condições legais. Máximo de `4000` caracteres.                                                                                |
| `termsPosition`       | string           | Não         | Alinhamento dos termos: `"left"`, `"center"` ou `"right"`.                                                                                       |
| `sections`            | object[]         | Não         | Array ordenado de objetos `ReportSection` que definem blocos de conteúdo e vinculações de dados (veja [Propriedades de ReportSection](#reportsection-properties)). |
| `pageSize`            | string           | Não         | Tamanho do papel do PDF: `"A4"`, `"Letter"` ou `"Legal"`. O padrão é `"A4"`.                                                                     |
| `layoutVersion`       | integer          | Não         | Versão do renderizador de layout: `1` ou `2`.                                                                                                    |
| `orientation`         | string           | Não         | Orientação da página: `"portrait"` ou `"landscape"`. O padrão é `"portrait"`.                                                                    |
| `margins`             | object           | Não         | Objeto de margens `` `{ "top": 40, "right": 40, "bottom": 40, "left": 40 }` ``. O padrão é `40` nos quatro lados.                                |
| `pdfEngine`           | string           | Não         | Motor de renderização de PDF: `"puppeteer"` ou `"pdfkit"`. O padrão é `"puppeteer"`.                                                             |
| `showPageNumbers`     | boolean          | Não         | Exibe números de página nos PDFs renderizados.                                                                                                   |
| `pageNumberPosition`  | string           | Não         | Posição do número de página: `"top-left"`, `"top-center"`, `"top-right"`, `"bottom-left"`, `"bottom-center"` ou `"bottom-right"`.                |
| `pageNumberDivider`   | boolean / string | Não         | Configuração do divisor do número de página.                                                                                                     |
| `watermark`           | object           | Não         | Configurações da camada de marca d'água.                                                                                                         |
| `security`            | object           | Não         | Configurações de criptografia de PDF `` `{ "enabled": true, "password": "..." }` ``.                                                             |
| `signature`           | object           | Não         | Configuração do bloco de assinatura.                                                                                                             |
| `logoSettings`        | object           | Não         | Configuração de tamanho e posicionamento do logotipo.                                                                                            |
| `sheetImages`         | object[]         | Não         | Recursos de imagem incorporados ao template. Máximo de `12` itens.                                                                               |
| `customFonts`         | object[]         | Não         | Declarações de fontes personalizadas (Google Fonts, URL externa ou arquivo enviado). Máximo de `6` itens.                                        |
| `headerLogos`         | object[]         | Não         | Logotipos adicionais exibidos no cabeçalho. Máximo de `16` itens.                                                                                |
| `bodyTopPadding`      | number           | Não         | Espaçamento superior aplicado ao corpo do documento, de `0` a `600`.                                                                             |
| `sampleData`          | object           | Não         | Payload de verificação de exemplo (`inputData`, `results`, `batchName`, `rowIndex`) usado como conjunto de dados de fallback para pré-visualizações e downloads de amostra. |
| `endpointDesign`      | object           | Não         | Metadados de apresentação específicos do endpoint.                                                                                               |
| `reportTheme`         | string / object  | Não         | ID da predefinição de tema (`"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"`) ou objeto completo de configuração do tema (veja [Configuração de tema](#theme-configuration)). |

#### Propriedades de `ReportSection` {/* #reportsection-properties */}

Cada elemento em `sections` descreve um bloco no relatório. Propriedades comuns incluem `id`, `type`, `order`, `dataPath`, `label`, `staticContent`, `columns`, `columnsPerRow`, `keyOverrides`, `valueRules`, `chartKind`, `style`, `condition` e `frame`.

Valores de `type` suportados incluem:

- **Layout principal**: `header`, `text`, `table`, `field`, `image`, `divider`, `spacer`, `shape`
- **Blocos estruturados**: `dataTable`, `card`, `badge`, `keyValueGrid`, `repeater`, `reportBlocks`, `themeBlock`
- **Blocos de verificação com tema**: `coverPage`, `scoreGauge`, `categoryBreakdown`, `checkTable`, `findings`, `sources`, `sourceCards`

#### Configuração de tema {/* #theme-configuration */}

`reportTheme` aceita uma string de predefinição (`"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"`) ou um objeto contendo:

`{ id, scoreScale, scoreEnabled, scoreProfile, locale, density, eyebrow, coverTitle, headlines, legalNote, showVerifiedBadge, showWeights, showDeductions, showFields, showHowItWorks, blocks, tokens }`

Ao migrar um payload testado em [Pré-visualizar HTML do template](/verifik-pt/smart-reports/preview-template-html), mova os auxiliares de pré-visualização de nível superior (`scoreScale`, `themeTokens`, `scoreSettings`) para dentro de `reportTheme` (`reportTheme.scoreScale`, `reportTheme.tokens`, `reportTheme.scoreEnabled` e `reportTheme.scoreProfile`) antes de salvar.

### Notas

- A criação bem-sucedida retorna HTTP **`200`** (não `201`) e dispara a geração assíncrona de miniatura em segundo plano.
- Os auxiliares de pré-visualização de nível superior (`scoreScale`, `themeTokens`, `scoreSettings`) usados por [Pré-visualizar HTML do template](/verifik-pt/smart-reports/preview-template-html) não são armazenados como campos de nível superior do template. Coloque-os dentro de `reportTheme` (`scoreScale`, `tokens`, `scoreEnabled`/`scoreProfile`) ao persistir um template.
- Salve o `_id` retornado para renderizar PDFs de amostra, enviar pré-visualizações às partes interessadas ou anexar o template a tarefas automatizadas de `SmartBatch`.
