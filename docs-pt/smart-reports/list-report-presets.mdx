Liste os presets de sistema selecionados do Smart Report disponíveis para a sua conta. Cada preset inclui seu `systemKey`, metadados (`country`, `category`, `tier`), disponibilidade na conta (`available`), `presetSteps` ordenados e um `inputSchema` resolvido com `exampleInput` pronto para execução headless ou agentes de IA.

O `inputSchema` resolvido exclui automaticamente parâmetros internos de execução e entradas de etapas já fornecidas por meio de dependências encadeadas do `visitaFlow`, deixando apenas os campos que o chamador precisa enviar. Listar presets é uma chamada de descoberta somente leitura e não consome créditos. Este endpoint também é exposto como a ferramenta MCP `smart_report_list_presets`.

### Endpoint

```
GET https://api.verifik.co/v2/smart-batch-presets
```

Também acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batch-presets` usando seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada nesta rota com `403 Forbidden`.

### Cabeçalhos

| Nome | Valor |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

O token deve ser um **JWT de cliente**. Credenciais ausentes ou inválidas retornam `401 Unauthorized`.

### Parâmetros

Todos os parâmetros de consulta são opcionais. Combine-os para filtrar presets por jurisdição, categoria de entidade, nível ou palavra-chave.

| Nome | Tipo | Obrigatório | Descrição |
| ---- | ---- | ----------- | --------- |
| `country` | string | Não | Filtro de código de país. Aparado e convertido para maiúsculas pelo servidor (por exemplo, `CO`). |
| `category` | string | Não | Filtro de categoria do preset. Valores permitidos: `citizen`, `company` ou `vehicle`. |
| `tier` | string | Não | Filtro de profundidade do preset. Valores permitidos: `essential` ou `comprehensive`. |
| `search` | string | Não | Correspondência regex sem distinção entre maiúsculas e minúsculas em `name`, `description` e `systemKey`. |
| `text` | string | Não | Alias para `search`. |

package main

import (
    "encoding/json"
    "fmt"
    "net/http"
    "net/url"
    "os"

func main() {
    u, _ := url.Parse("https://api.verifik.co/v2/smart-batch-presets")
    q := u.Query()
    q.Set("country", "CO")
    q.Set("category", "citizen")
    q.Set("tier", "essential")
    u.RawQuery = q.Encode()

    req, _ := http.NewRequest("GET", u.String(), nil)
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

    resp, _ := http.DefaultClient.Do(req)
    defer resp.Body.Close()

    var out map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&out)
    fmt.Println(out)
}

### Notas

- `country` é aparado e convertido para maiúsculas antes da filtragem (por exemplo, `co` corresponde a `CO`).
- `search` e `text` executam a mesma correspondência de expressão regular sem distinção entre maiúsculas e minúsculas em `name`, `description` e `systemKey`.
- `inputSchema.estimatedCreditsPerRow` estima o custo de créditos por linha entre as etapas habilitadas do preset.
- Quando `available` é `true`, todos os recursos em `presetSteps` estão ativos para o ambiente e prontos para clonar com [Clonar um preset de relatório](/verifik-pt/smart-reports/clone-a-report-preset).
- Para integrações com agentes de IA, este endpoint corresponde à ferramenta MCP `smart_report_list_presets`.
