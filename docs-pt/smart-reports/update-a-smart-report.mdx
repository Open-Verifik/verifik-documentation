Atualize um `SmartReport` existente pertencente ao cliente autenticado. Envie apenas os campos que deseja modificar; os campos omitidos na requisição permanecem inalterados.

Se o ID do relatório não existir ou pertencer a outro cliente, o endpoint retorna `404 Not Found` (`{ "message": "not_found", "code": "NotFound" }`).

### Endpoint

```
PUT https://api.verifik.co/v2/smart-reports/{id}
```

Este endpoint também pode ser acessado pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-reports/{id}` usando o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                        |
| --------------- | ---------------------- | ------------------------------------------------ |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.                |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição |
| ---- | ------ | ----------- | --------- |
| `id` | string | **Sim**     | ObjectId do `SmartReport` a atualizar. |

### Corpo

Todos os campos do corpo são opcionais; forneça apenas os atributos que deseja atualizar.

| Nome                       | Tipo             | Obrigatório | Descrição |
| -------------------------- | ---------------- | ----------- | --------- |
| `name`                     | string           | Não         | Nome de exibição do relatório. |
| `status`                   | string           | Não         | Status do relatório: `"draft"`, `"generating"`, `"generated"`, `"sent"` ou `"failed"`. |
| `pdfUrl`                   | string           | Não         | URL armazenada para o artefato PDF gerado. |
| `pdfSize`                  | number           | Não         | Tamanho do PDF gerado em bytes. |
| `htmlSnapshot`             | string           | Não         | Snapshot HTML salvo do relatório renderizado. |
| `pageCount`                | number           | Não         | Contagem de páginas do PDF gerado. |
| `pdfEngine`                | string           | Não         | Motor de renderização: `"pdfkit"` ou `"puppeteer"`. |
| `generatedAt`              | string           | Não         | Carimbo de data/hora ISO 8601 de quando o relatório foi gerado. |
| `generationDurationMs`     | number           | Não         | Duração da geração do PDF em milissegundos. |
| `dataSnapshot`             | object           | Não         | Snapshot da linha ou dos dados de entrada usados para o relatório. |
| `externalRefId`            | string           | Não         | Identificador de correlação do chamador. |
| `webhookUrl`               | string           | Não         | URL de substituição de webhook `http` ou `https` por relatório. |
| `rowIndex`                 | number           | Não         | Índice da linha em base zero associado a este relatório. |
| `createdByChannel`         | string           | Não         | Canal de origem: `"portal"`, `"api"`, `"mcp"`, `"x402"` ou `"webhook"`. |
| `verificationScoreSummary` | object           | Não         | Metadados de resumo da pontuação de verificação. |
| `error`                    | object ou string | Não         | Payload ou mensagem de erro registrada para estados com falha. |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"

	id := "6801a2b3c4d5e6f7a8b9c0d1"

	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)

}

### Webhooks e integração MCP

- Atualizar `webhookUrl` ou `externalRefId` atualiza a URL de callback de destino e o ID de correlação usados por chamadas subsequentes de [Gerar PDF de Smart Report](/verifik-pt/smart-reports/generate-smart-report-pdf) e [Enviar Smart Report por e-mail](/verifik-pt/smart-reports/send-smart-report-email). Veja [Webhooks do SmartReports](/verifik-pt/resources/smart-reports-webhooks).
- Para inspecionar o registro atualizado ou executar operações headless de relatório por meio de um agente de IA, veja [MCP e Agentes de IA](/verifik-pt/smart-reports/mcp-and-ai-agents).

### Notas

- Atualizar um `SmartReport` modifica apenas os campos armazenados no relatório; isso não regenera automaticamente um PDF nem envia e-mails. Chame [Gerar PDF de Smart Report](/verifik-pt/smart-reports/generate-smart-report-pdf) ou [Enviar Smart Report por e-mail](/verifik-pt/smart-reports/send-smart-report-email) quando quiser renderizar novamente ou enviar.
