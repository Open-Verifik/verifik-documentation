Componha o modelo estruturado de relatório de linha para uma única linha (`rowIndex`) de um `SmartBatch`. Este endpoint executa o compositor de relatório integrado da Verifik (`colombia_vehicle`) sobre as saídas de etapas armazenadas da linha e opcionalmente anexa um `verificationScore` quando `score` ou `scoreProfile` é informado.

Se a `BatchConfiguration` do lote não corresponder a um compositor integrado, este endpoint retorna `409 Conflict` (`no_report_composer_for_configuration`). Para templates de relatório personalizados arbitrários, use `POST /v2/smart-reports/run`, `GET /v2/smart-reports/{id}/html` ou `/generate` em vez disso. Ler este endpoint não consome créditos.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report
```

Este endpoint também é acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batches/{id}/rows/{rowIndex}/report` usando seu próprio `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                      |
| --------------- | ---------------------- | ---------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros de caminho

| Nome       | Tipo   | Obrigatório | Descrição |
| ---------- | ------ | ----------- | --------- |
| `id`       | string | Sim         | ObjectId do `SmartBatch`. |
| `rowIndex` | number | Sim         | Índice baseado em `0` da linha dentro do lote. |

### Parâmetros de consulta

| Nome           | Tipo              | Obrigatório | Descrição |
| -------------- | ----------------- | ----------- | --------- |
| `score`        | boolean ou string | Não         | Passe `true` ou `"1"` para calcular e incluir `verificationScore` na resposta. |
| `scoreProfile` | string            | Não         | Identificador do perfil de pontuação. Informar `scoreProfile` também habilita `score`. |

  <TabItem value="go" label="Go">

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	rowIndex := "0"
	params := url.Values{}
	params.Set("score", "true")
	params.Set("scoreProfile", "fleet_standard")

	endpoint := fmt.Sprintf("https://api.verifik.co/v2/smart-batches/%s/rows/%s/report?%s", batchID, rowIndex, params.Encode())
	req, _ := http.NewRequest("GET", endpoint, nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}
```

### Notas

- Este endpoint serve apenas relatórios de linha compostos integrados (`colombia_vehicle`). Qualquer outra configuração retorna `409 Conflict` (`no_report_composer_for_configuration`).
- Para templates personalizados, renderização de HTML com tema ou dossiês em PDF para qualquer configuração, use `POST /v2/smart-reports/run`, `GET /v2/smart-reports/{id}/html` ou `/generate` (veja [Executar um Smart Report](/verifik-pt/smart-reports/run-a-smart-report)).
- `verificationScore` é omitido, a menos que `score=true`, `score=1` ou `scoreProfile` seja fornecido.
