Crie um registro `SmartReport` em rascunho (`status: "draft"`) vinculado a um `template` e `smartBatch` existentes. Use este endpoint quando você já tiver um `SmartBatch` concluído ou em andamento e quiser gerenciar a criação do relatório, geração de PDF, obtenção de HTML e entrega por e-mail em etapas separadas.

A criação de um registro em rascunho retorna HTTP **`200 OK`** com o novo `SmartReport` em `{ data }`. Isso não executa etapas de verificação nem renderiza um PDF por si só — continue com [Gerar PDF de Smart Report](/verifik-pt/smart-reports/generate-smart-report-pdf) ou [Enviar Smart Report por e-mail](/verifik-pt/smart-reports/send-smart-report-email). Se quiser executar etapas de verificação e produzir um relatório em uma única requisição, use [Executar um Smart Report](/verifik-pt/smart-reports/run-a-smart-report).

### Endpoint

```
POST https://api.verifik.co/v2/smart-reports
```

Este endpoint também pode ser acessado pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-reports` usando o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                        |
| --------------- | ---------------------- | ------------------------------------------------ |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.                |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Corpo

| Nome               | Tipo    | Obrigatório | Descrição |
| ------------------ | ------- | ----------- | --------- |
| `template`         | string  | **Sim**     | ObjectId do template para renderizar este relatório. |
| `smartBatch`       | string  | **Sim**     | ObjectId do `SmartBatch` que fornece os resultados das linhas de verificação. |
| `name`             | string  | Não         | Nome de exibição do relatório. Máximo de `150` caracteres. |
| `externalRefId`    | string  | Não         | Identificador de correlação do chamador. Máximo de `200` caracteres. |
| `webhookUrl`       | string  | Não         | URL de substituição de webhook `http` ou `https` por relatório. Máximo de `2048` caracteres. |
| `rowIndex`         | integer | Não         | Índice da linha em base zero (`>= 0`) do `SmartBatch` vinculado. |
| `createdByChannel` | string  | Não         | Canal de origem: `"portal"`, `"api"`, `"mcp"`, `"x402"` ou `"webhook"`. Padrão `"portal"`. |

#### Fluxo passo a passo vs execução headless

- Use `POST /v2/smart-reports` quando o seu fluxo de trabalho já executou um `SmartBatch` (por exemplo, pela interface do SmartBatch ou pela API de fila) e você deseja criar primeiro um `SmartReport` em rascunho (`status: "draft"`), pré-visualizar o HTML com [Obter HTML do Smart Report](/verifik-pt/smart-reports/retrieve-smart-report-html), renderizar o PDF com [Gerar PDF de Smart Report](/verifik-pt/smart-reports/generate-smart-report-pdf) e enviá-lo com [Enviar Smart Report por e-mail](/verifik-pt/smart-reports/send-smart-report-email).
- Observe que `createdByChannel` assume `"portal"` por padrão nesta rota, portanto integrações via API devem definir `createdByChannel: "api"` ao rastrear a atribuição de canal.

### Webhooks e integração MCP

- **Webhooks**: Armazenar `webhookUrl` e `externalRefId` no rascunho do `SmartReport` garante que chamadas subsequentes de geração (`smart_batch_report_generated`, `smart_batch_report_generation_failed`) e envio por e-mail (`smart_batch_report_sent`, `smart_batch_report_delivery_failed`) herdem seu destino de callback e identificador de correlação por relatório. Veja [Webhooks do SmartReports](/verifik-pt/resources/smart-reports-webhooks).
- **Integração MCP**: Para execução de relatório headless em uma única chamada por agentes de IA, use `smart_report_run`. Veja [MCP e Agentes de IA](/verifik-pt/smart-reports/mcp-and-ai-agents).

### Notas

- A criação bem-sucedida retorna HTTP `200` (não `201`) com `status: "draft"`.
- Guarde `data._id` para chamadas subsequentes a [Consultar um Smart Report](/verifik-pt/smart-reports/retrieve-a-smart-report), [Gerar PDF de Smart Report](/verifik-pt/smart-reports/generate-smart-report-pdf), [Baixar PDF do Smart Report](/verifik-pt/smart-reports/download-smart-report-pdf), [Obter HTML do Smart Report](/verifik-pt/smart-reports/retrieve-smart-report-html) e [Enviar Smart Report por e-mail](/verifik-pt/smart-reports/send-smart-report-email).
