Liste as Configurações de Lote pertencentes à sua conta de cliente autenticada. Os resultados são restritos ao cliente do seu JWT, ordenados do mais recente para o mais antigo (`createdAt` decrescente) e retornados com metadados `steps.appFeature` preenchidos e preços `ClientFeature` específicos do cliente.

Envie `page` quando precisar de resultados paginados com metadados `total`, `limit`, `page` e `pages`. Omita `page` para receber o array correspondente diretamente em `data`. Listar configurações não executa consultas e não consome créditos.

### Endpoint

```
GET https://api.verifik.co/v2/batch-configurations
```

Também acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/batch-configurations` usando seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome | Valor |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

O token deve ser um **JWT de cliente**. Credenciais ausentes ou inválidas retornam `401 Unauthorized`.

### Parâmetros

Todos os parâmetros de consulta são opcionais.

| Nome | Tipo | Obrigatório | Descrição |
| ---- | ---- | ----------- | --------- |
| `search` | string | Não | Filtro de nome sem distinção entre maiúsculas e minúsculas aplicado às configurações salvas. |
| `text` | string | Não | Alias para `search`. |
| `page` | integer | Não | Número da página (baseado em `1`). Quando fornecido, habilita os metadados de paginação (`total`, `limit`, `page`, `pages`) na resposta. |
| `limit` | integer | Não | Número máximo de configurações a retornar por página. |
| `perPage` | integer | Não | Alias para `limit`. |

package main

import (
    "encoding/json"
    "fmt"
    "net/http"
    "net/url"
    "os"
)

func main() {
    u, _ := url.Parse("https://api.verifik.co/v2/batch-configurations")
    q := u.Query()
    q.Set("search", "Colombia")
    q.Set("page", "1")
    q.Set("limit", "20")
    u.RawQuery = q.Encode()

    req, _ := http.NewRequest("GET", u.String(), nil)
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

    resp, _ := http.DefaultClient.Do(req)
    defer resp.Body.Close()

    var out map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&out)
    fmt.Println(out)
}

### Notas

- Os resultados são automaticamente restritos ao JWT de cliente autenticado e ordenados do mais recente para o mais antigo (`-createdAt`).
- O campo `steps.appFeature` de cada etapa é preenchido e enriquecido com os preços `ClientFeature` da sua conta quando configurados.
- `perPage` é um alias para `limit`, e `text` é um alias para `search`.
- Os metadados de paginação (`total`, `limit`, `page`, `pages`) só são incluídos quando `page` é fornecido na query string.
