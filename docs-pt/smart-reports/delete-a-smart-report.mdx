Exclua um registro `SmartReport` pertencente ao cliente autenticado. Em caso de sucesso, a API retorna o documento `SmartReport` removido dentro de `{ "data": ... }`.

Se o ID do relatório estiver ausente ou pertencer a um cliente diferente, o endpoint retorna `404 Not Found` (`{ "message": "not_found", "code": "NotFound" }`). Excluir um relatório remove o documento `SmartReport` sem excluir os dados de verificação do `SmartBatch` subjacente.

### Endpoint

```
DELETE https://api.verifik.co/v2/smart-reports/{id}
```

Este endpoint também pode ser acessado pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-reports/{id}` usando o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                        |
| --------------- | ---------------------- | ------------------------------------------------ |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.                |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição |
| ---- | ------ | ----------- | --------- |
| `id` | string | **Sim**     | ObjectId do `SmartReport` a excluir. |

### Notas

- Chamadas subsequentes a `GET /v2/smart-reports/{id}` retornam `{ "data": null }`, enquanto `PUT`, `DELETE`, `/generate`, `/download`, `/html` e `/send-email` retornam `404` (`not_found`).
- Excluir um `SmartReport` não emite webhooks de entrega nem de geração de relatório; veja [Webhooks do SmartReports](/verifik-pt/resources/smart-reports-webhooks) e [MCP e Agentes de IA](/verifik-pt/smart-reports/mcp-and-ai-agents) para detalhes da automação do ciclo de vida.
