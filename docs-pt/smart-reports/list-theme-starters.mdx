Obtenha os templates iniciais com tema integrados da Verifik, opcionalmente filtrados por `theme`. Cada modelo inicial inclui `sections`, `reportTheme`, `sampleData`, propriedades de layout de página e cores pré-configuradas para que você possa lançar designs de relatório prontos para produção sem montar árvores de seções do zero.

Em fluxos de onboarding headless e agentes de IA, chame este endpoint para escolher um ponto de partida visual selecionado, pré-visualizá-lo imediatamente via [Pré-visualizar HTML do template](/verifik-pt/smart-reports/preview-template-html), personalizar cores da marca ou logotipos e salvar o seu próprio template editável via [Criar um template de relatório](/verifik-pt/smart-reports/create-a-report-template).

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/theme-starters
```

O proxy do Smart-Agent (`https://ai.verifik.co`) expõe os mesmos caminhos `/v2/...` e exige o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>`.

### Cabeçalhos

| Nome          | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parâmetros

| Nome    | Tipo   | Obrigatório | Descrição                                                                                                                                                     |
| ------- | ------ | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `theme` | string | Não         | Filtro opcional de tema: `"premium_dark"`, `"light_cards"`, `"editorial"`, `"dashboard"` ou `"smart_enroll_v2"` (alias de `"light_cards"`; recomenda-se usar o canônico `"light_cards"`). |

### Notas

- `"smart_enroll_v2"` é aceito como alias para `"light_cards"`, embora seja recomendado filtrar pelo ID de tema canônico `"light_cards"`.
- Os itens iniciais retornados aqui trazem `type: "System"` para referência. Ao salvar uma cópia personalizada via [Criar um template de relatório](/verifik-pt/smart-reports/create-a-report-template), envie apenas seu `name` e os campos de design (`sections`, `reportTheme`, `sampleData`, cores e configurações de PDF).
