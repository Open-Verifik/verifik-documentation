Liste todos os perfis de pontuação de verificação suportados que podem ser anexados a um template de Smart Report (`reportTheme.scoreProfile`) ou passados para [Pré-visualizar HTML do template](/verifik-pt/smart-reports/preview-template-html) (`scoreProfile`).

Em interfaces de configuração headless e fluxos de trabalho de agentes de IA, consulte este endpoint antes de habilitar a pontuação para que sua aplicação valide os identificadores de `scoreProfile` dinamicamente e evite erros `409` (`unknown_score_profile`) durante a pré-visualização HTML ou renderização de relatórios. Os perfis disponíveis cobrem fluxos de motoristas, identidade, empresas, frotas, veículos, crédito, saúde e biometria:

- `cabify_driver`
- `kyc`
- `kyb`
- `fleet`
- `vehicle_purchase`
- `identity_lookup`
- `background_check`
- `lending`
- `healthcare_professional`
- `biometrics`

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/score-profiles
```

O proxy do Smart-Agent (`https://ai.verifik.co`) expõe os mesmos caminhos `/v2/...` e exige o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>`.

### Cabeçalhos

| Nome          | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parâmetros

Nenhum parâmetro de consulta ou de caminho é obrigatório.

### Notas

- Use o valor de `id` retornado em `reportTheme.scoreProfile` ao criar ou atualizar um template, ou como `scoreProfile` em [Pré-visualizar HTML do template](/verifik-pt/smart-reports/preview-template-html).
- Enviar um `scoreProfile` não reconhecido para `POST /v2/smart-report-templates/preview-html` retorna `409` (`unknown_score_profile`).
