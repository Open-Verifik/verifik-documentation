Obtenha estatísticas agregadas de execução entre todos os registros `SmartBatch` pertencentes a uma `BatchConfiguration` específica na conta de cliente autenticada. A resposta retorna contagens de lotes, totais de conclusão de linhas e um detalhamento por status entre `"draft"`, `"pending"`, `"processing"`, `"completed"`, `"failed"` e `"cancelled"`.

Ler as estatísticas da configuração não executa verificações e não consome créditos.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/stats/{configId}
```

Este endpoint também é acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batches/stats/{configId}` usando seu próprio `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                      |
| --------------- | ---------------------- | ---------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome       | Tipo   | Obrigatório | Descrição |
| ---------- | ------ | ----------- | --------- |
| `configId` | string | Sim         | ObjectId da `BatchConfiguration` para a qual agregar as estatísticas de lotes. |

### Notas

- As estatísticas são restritas ao cliente autenticado (`clientId` no seu JWT).
- `pendingRows` é calculado como `totalRows - completedRows - failedRows - partialRows`.
- Para inspecionar lotes individuais pertencentes a esta configuração, passe `batchConfiguration` para [Listar Smart Batches](/verifik-pt/smart-reports/list-smart-batches).
