Atualize campos de um `SmartBatch` existente pertencente ao cliente autenticado. Você pode atualizar `name`, `status`, `executor` ou substituir `rows`. Quando `rows` é fornecido, o servidor recalcula `totalRows`, `completedRows`, `failedRows` e `partialRows` e sincroniza os snapshots externos de linhas.

Use o endpoint dedicado [Pausar um Smart Batch](/verifik-pt/smart-reports/pause-a-smart-batch) para fazer a transição de um lote para `"paused"`. Alterar `executor` só tem efeito quando o lote está atualmente no status `"draft"`, `"pending"` ou `"cancelled"`.

### Endpoint

```text
PUT https://api.verifik.co/v2/smart-batches/{id}
```

Este endpoint também é acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batches/{id}` usando seu próprio `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                      |
| --------------- | ---------------------- | ---------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição |
| ---- | ------ | ----------- | --------- |
| `id` | string | Sim         | ObjectId do `SmartBatch` a atualizar. |

### Corpo

| Nome       | Tipo     | Obrigatório | Descrição |
| ---------- | -------- | ----------- | --------- |
| `name`     | string   | Não         | Nome de exibição atualizado do lote. Máximo de `150` caracteres. |
| `status`   | string   | Não         | Valores permitidos: `"draft"`, `"pending"`, `"processing"`, `"completed"`, `"failed"` ou `"cancelled"`. Use `POST /v2/smart-batches/{id}/pause` para `"paused"`. |
| `executor` | string   | Não         | Valores permitidos: `"queue"`, `"featureRunner"` ou `"browser"`. Só tem efeito quando o status atual do lote é `"draft"`, `"pending"` ou `"cancelled"`. |
| `rows`     | object[] | Não         | Lista de linhas de substituição. O formato encapsulado exige `rowIndex` e `inputData` e aceita opcionalmente `status`, `results`, `errors` e `processedAt`; linhas planas são normalizadas automaticamente. |

Chaves desconhecidas no corpo são rejeitadas pela validação Joi com `409 MissingParameter`.

package main

import (

	"os"

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	body, _ := json.Marshal(map[string]interface{}{
		"name":     "Colombia Onboarding — Updated",
		"executor": "queue",
		"rows": []map[string]interface{}{
			{
				"rowIndex": 0,
				"inputData": map[string]string{
					"documentType":   "CC",
					"documentNumber": "1032386359",
				},
				"status": "pending",
			},
		},
	})

	req, _ := http.NewRequest("PUT", "https://api.verifik.co/v2/smart-batches/"+batchID, bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notas

- `"paused"` não é aceito em `PUT /v2/smart-batches/{id}`; chame [Pausar um Smart Batch](/verifik-pt/smart-reports/pause-a-smart-batch) em vez disso.
- A atualização de `executor` é ignorada, a menos que o lote esteja atualmente no status `"draft"`, `"pending"` ou `"cancelled"`.
- Para adicionar novas linhas a um lote existente sem substituir as existentes, use [Adicionar linhas a um Smart Batch](/verifik-pt/smart-reports/append-smart-batch-rows).
