Obtenha uma única `BatchConfiguration` pelo seu ObjectId (`{id}`). A consulta é restrita ao JWT de cliente autenticado e retorna os detalhes de `steps.appFeature` preenchidos e enriquecidos com os preços `ClientFeature` da sua conta.

Se não existir nenhuma configuração correspondente ou se o ID pertencer a outra conta de cliente, o endpoint retorna HTTP `200` com `data: null`. Ler uma configuração não executa consultas e não consome créditos.

### Endpoint

```
GET https://api.verifik.co/v2/batch-configurations/{id}
```

Também acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/batch-configurations/{id}` usando seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome | Valor |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

O token deve ser um **JWT de cliente**. Credenciais ausentes ou inválidas retornam `401 Unauthorized`.

### Parâmetros

| Nome | Tipo | Obrigatório | Descrição |
| ---- | ---- | ----------- | --------- |
| `id` | string | Sim | ObjectId da `BatchConfiguration` obtido na criação, clonagem ou listagem. |

### Notas

- Se `{id}` não existir ou pertencer a outra conta de cliente, este endpoint retorna HTTP `200` com `{ "data": null }`.
- Verifique `data !== null` na sua integração antes de ler propriedades de `data`.
- Para inspecionar os campos de entrada obrigatórios/opcionais resolvidos e um payload `exampleInput` de uma configuração, chame [Obter schema de entrada da configuração](/verifik-pt/smart-reports/retrieve-configuration-input-schema).
