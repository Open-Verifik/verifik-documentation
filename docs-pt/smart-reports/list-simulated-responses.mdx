Liste os endpoints do catálogo da Verifik que possuem respostas simuladas de sandbox pré-construídas no inventário de design de templates. Filtre por `country` ou consulta de busca (`q`) para descobrir os identificadores `code` dos endpoints e as `inputs` esperadas.

Em construtores de relatórios headless e pipelines de agentes de IA, use este endpoint de descoberta de catálogo para selecionar conjuntos de dados simulados realistas sem executar consultas reais faturáveis nem manipular dados pessoais (PII) de produção. Passe qualquer `code` retornado para [Consultar uma resposta simulada](/verifik-pt/smart-reports/retrieve-simulated-response) para obter payloads de exemplo para [Inspecionar dados de exemplo](/verifik-pt/smart-reports/introspect-sample-data), [Gerar layout do template](/verifik-pt/smart-reports/generate-template-layout) ou [Pré-visualizar HTML do template](/verifik-pt/smart-reports/preview-template-html).

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses
```

O proxy do Smart-Agent (`https://ai.verifik.co`) expõe os mesmos caminhos `/v2/...` e exige o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>`.

### Cabeçalhos

| Nome          | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parâmetros

| Nome      | Tipo   | Obrigatório | Descrição                                                           |
| --------- | ------ | ----------- | ------------------------------------------------------------------- |
| `country` | string | Não         | Filtra endpoints simulados por país.                                |
| `q`       | string | Não         | Texto de busca para filtrar endpoints por nome, código ou metadados. |

### Notas

- Consultar respostas simuladas não executa consultas reais de catálogo e não consome créditos.
- Use o `code` de cada item com [Consultar uma resposta simulada](/verifik-pt/smart-reports/retrieve-simulated-response) para buscar payloads completos `dataSample` e `emptySample`.
