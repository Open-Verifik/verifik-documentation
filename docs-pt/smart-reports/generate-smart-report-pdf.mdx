Renderize um PDF para um `SmartReport` existente usando `"puppeteer"` ou `"pdfkit"`, calcule opcionalmente `verificationScore` e receba o buffer do PDF codificado em base64 junto com `downloadUrl` e `htmlUrl`.

Em caso de sucesso, este endpoint marca o relatório com `status: "generated"`, persiste `verificationScoreSummary` quando a pontuação está habilitada e emite o webhook `smart_batch_report_generated`. Se a geração do PDF falhar, o relatório é marcado com `status: "failed"` e o webhook `smart_batch_report_generation_failed` é emitido.

### Endpoint

```
POST https://api.verifik.co/v2/smart-reports/{id}/generate
```

Este endpoint aceita payloads JSON de até **64 MB** (para acomodar documentos `printHtml` personalizados). Ele também pode ser acessado pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-reports/{id}/generate` usando o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                                   |
| --------------- | ---------------------- | ----------------------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição (limite de 64 MB).         |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`).            |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição |
| ---- | ------ | ----------- | --------- |
| `id` | string | **Sim**     | ObjectId do `SmartReport`. |

### Corpo

| Nome           | Tipo    | Obrigatório | Descrição |
| -------------- | ------- | ----------- | --------- |
| `engine`       | string  | Não         | Motor de renderização de PDF: `"pdfkit"` ou `"puppeteer"`. |
| `rowIndex`     | number  | Não         | Índice da linha em base zero do `SmartBatch` vinculado. Assume a linha `0` por padrão. |
| `printHtml`    | string  | Não         | String HTML completa (máx. `64000000` caracteres) usada para templates sem tema contendo `<html`. |
| `score`        | boolean | Não         | Se deve calcular `verificationScore` e armazenar `verificationScoreSummary` no relatório. |
| `scoreProfile` | string  | Não         | Identificador do perfil de pontuação usado quando `score` está habilitado. Máximo de `64` caracteres. |

#### Comportamento de renderização e pontuação

- **Seleção de linha padrão**: Quando `rowIndex` é omitido, a geração assume a linha `0`. Solicitar uma linha fora do intervalo retorna `409 Conflict` (`row_not_found`).
- **HTML personalizado (`printHtml`)**: Ao trabalhar com templates sem tema que fornecem marcação `<html` completa, passe `printHtml` (até `64000000` caracteres).
- **Pontuação de verificação**: Defina `score: true` (e opcionalmente `scoreProfile`) para calcular `verificationScore`, retorná-lo no nível superior da resposta e salvar `verificationScoreSummary` no `SmartReport`. Perfis desconhecidos falham com `409 Conflict` (`unknown_score_profile`).

#### Códigos de erro

| Status | Código / Tipo de erro | Causa |
| ------ | --------------------- | ----- |
| `401` | `Unauthorized` | JWT ausente ou inválido. |
| `403` | `Forbidden` | Tentativa de execução compartilhada via x402; use o seu próprio JWT por cliente. |
| `404` | `not_found` | O ID do relatório não existe ou pertence a outro cliente. |
| `404` | `template_not_found` | O template vinculado não foi encontrado. |
| `404` | `batch_not_found` | O `SmartBatch` vinculado não foi encontrado. |
| `409` | `MissingParameter` | A validação Joi falhou em um ou mais campos. |
| `409` | `row_not_found` | O `rowIndex` solicitado não existe no lote. |
| `409` | `unknown_score_profile` | O `scoreProfile` solicitado não é reconhecido. |
| `422` | `UnprocessableEntity` | Erro de validação do Mongoose. |
| `500` | `InternalServerError` | Falha na renderização do PDF ou processamento interno (marca o relatório como `"failed"` e emite `smart_batch_report_generation_failed`). |

### Webhooks e integração MCP

- **Webhooks**: Emite `smart_batch_report_generated` na criação bem-sucedida do PDF, ou `smart_batch_report_generation_failed` se ocorrerem erros de renderização (e atualiza `status` para `"failed"`). Veja [Webhooks do SmartReports](/verifik-pt/resources/smart-reports-webhooks).
- **Equivalente MCP**: Agentes de IA podem renderizar o PDF de um relatório diretamente por meio da ferramenta MCP `smart_report_generate_pdf`. Veja [MCP e Agentes de IA](/verifik-pt/smart-reports/mcp-and-ai-agents).

### Notas

- `pdf.buffer` contém os bytes do PDF codificados em base64 diretamente na resposta JSON; se preferir um fluxo binário de PDF, chame [Baixar PDF do Smart Report](/verifik-pt/smart-reports/download-smart-report-pdf).
- `verificationScore` é incluído na resposta quando `score` está habilitado.
