Exclua um `SmartBatch` pertencente ao cliente autenticado. Se o lote existir e pertencer à sua conta de cliente, o servidor o exclui e retorna o documento `SmartBatch` removido em `data`.

Se o ID do lote não existir ou pertencer a outro cliente, o endpoint retorna `404` (`not_found`). Excluir um lote não reembolsa créditos gastos anteriormente.

### Endpoint

```text
DELETE https://api.verifik.co/v2/smart-batches/{id}
```

Este endpoint também é acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batches/{id}` usando seu próprio `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                      |
| --------------- | ---------------------- | ---------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição |
| ---- | ------ | ----------- | --------- |
| `id` | string | Sim         | ObjectId do `SmartBatch` a excluir. |

### Notas

- Para interromper um lote ativo mantendo seu histórico de linhas e saídas, use [Cancelar um Smart Batch](/verifik-pt/smart-reports/cancel-a-smart-batch) em vez de excluí-lo.
- Lotes pertencentes a outra conta de cliente retornam `404` (`not_found`).
