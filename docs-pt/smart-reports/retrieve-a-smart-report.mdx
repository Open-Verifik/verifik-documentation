Consulte um único `SmartReport` pelo seu ID. A resposta popula `template`, `smartBatch` e `client`, e anexa os caminhos prontos para uso `downloadUrl` (`/v2/smart-reports/{id}/download`) e `htmlUrl` (`/v2/smart-reports/{id}/html`).

Este endpoint também é o destino de polling (`pollUrl`) retornado quando `POST /v2/smart-reports/run` é executado no modo `"async"` ou faz fallback para `202 Accepted` após o prazo síncrono de 90 segundos. Se o ID do relatório não existir ou pertencer a um cliente diferente, o endpoint retorna HTTP `200 OK` com `{ "data": null }`.

### Endpoint

```
GET https://api.verifik.co/v2/smart-reports/{id}
```

Este endpoint também pode ser acessado pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-reports/{id}` usando o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                        |
| --------------- | ---------------------- | ------------------------------------------------ |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.                |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição |
| ---- | ------ | ----------- | --------- |
| `id` | string | **Sim**     | ObjectId do `SmartReport` retornado por `POST /v2/smart-reports/run`, `POST /v2/smart-reports` ou `GET /v2/smart-reports`. |

### Webhooks e integração MCP

- **Polling vs Webhooks**: Para execuções assíncronas, você pode fazer polling em `GET /v2/smart-reports/{id}` até que `data.status` estabilize (`"generated"`, `"sent"` ou `"failed"`), ou assinar os eventos de webhook (`smart_batch_report_generated`, `smart_batch_report_generation_failed`, `smart_batch_report_sent`, `smart_batch_report_delivery_failed`). Veja [Webhooks do SmartReports](/verifik-pt/resources/smart-reports-webhooks).
- **Equivalente MCP**: Agentes de IA podem obter um registro de relatório usando a ferramenta MCP `smart_report_get`. Veja [MCP e Agentes de IA](/verifik-pt/smart-reports/mcp-and-ai-agents).

### Notas

- Relatórios inexistentes ou pertencentes a outro cliente retornam `200 OK` com `{ "data": null }` em vez de `404`.
- `downloadUrl` e `htmlUrl` são caminhos relativos da API que podem ser anexados a `https://api.verifik.co` (ou `https://ai.verifik.co`).
