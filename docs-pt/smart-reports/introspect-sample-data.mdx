Inspecione um payload de verificação `sampleData` e receba um mapa estruturado de caminhos de campos, formatos de valores, escolhas recomendadas de `sectionType`, tipos de seção alternativos, colunas de tabela sugeridas e sugestões de vinculação.

Em autoria de relatórios headless e pipelines de agentes de IA, chame este endpoint logo após buscar um payload em [Consultar uma resposta simulada](/verifik-pt/smart-reports/retrieve-simulated-response) ou capturar uma linha de `SmartBatch`. Em vez de adivinhar strings de `dataPath` ou escrever lógica frágil de travessia de JSON, sua interface ou agente pode usar os metadados inspecionados de `nodes` e `batch` para montar `sections` válidas diretamente ou enriquecer o contexto de `prompt` para [Gerar layout do template](/verifik-pt/smart-reports/generate-template-layout). O inspetor percorre até a profundidade `5` e até `600` nós.

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates/introspect
```

O proxy do Smart-Agent (`https://ai.verifik.co`) expõe os mesmos caminhos `/v2/...` e exige o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>`.

### Cabeçalhos

| Nome          | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Corpo

| Nome         | Tipo   | Obrigatório | Descrição                                                                                                                               |
| ------------ | ------ | ----------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `sampleData` | object | Sim         | Payload de verificação de exemplo com `batchName` (string), `rowIndex` (number), `inputData` (object) e `results` (object) opcionais. |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func main() {
	body, _ := json.Marshal(map[string]interface{}{
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{
					"fullName": "Mateo Rojas",
					"status":   "active",
				},
				"fines": []map[string]interface{}{
					{"code": "C02", "amount": 580000, "status": "pending"},
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/introspect", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notas

- A travessia para na profundidade `5` e tem limite de `600` nós. Quando um payload muito grande atinge o limite, `truncated` é `true`.
- Este endpoint é somente leitura e sem estado; ele não salva um template nem consome créditos de verificação.
