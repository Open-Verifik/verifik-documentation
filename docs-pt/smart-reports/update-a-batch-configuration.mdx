Atualize uma `BatchConfiguration` existente pertencente à sua conta de cliente. Envie apenas os campos que deseja alterar; os campos omitidos mantêm seus valores atuais.

Quando `steps` é fornecido, o servidor normaliza valores de `sequence` ausentes para `index + 1` e limita `retryDelayBaseSeconds` (`>= 1`) e `timeoutSeconds` (`>= 5`). Atualizar `notification` sincroniza automaticamente o Webhook Verifik associado, e alterar `executor` propaga o novo executor para lotes filhos não terminais. Atualizar uma configuração não executa consultas e não consome créditos.

### Endpoint

```
PUT https://api.verifik.co/v2/batch-configurations/{id}
```

Também acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/batch-configurations/{id}` usando seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome | Valor |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

O token deve ser um **JWT de cliente**. Credenciais ausentes ou inválidas retornam `401 Unauthorized`.

### Parâmetros

| Nome | Tipo | Obrigatório | Descrição |
| ---- | ---- | ----------- | --------- |
| `id` | string | Sim | ObjectId da `BatchConfiguration` a atualizar. |

### Corpo

Todos os campos do corpo são opcionais. Inclua apenas as propriedades que deseja atualizar.

| Nome | Tipo | Obrigatório | Descrição |
| ---- | ---- | ----------- | --------- |
| `name` | string | Não | Nome de exibição da configuração. Aparado, máximo de `150` caracteres. |
| `description` | string | Não | Resumo opcional do fluxo de trabalho. Máximo de `800` caracteres. |
| `country` | string | Não | Escopo de país. Aparado e convertido para maiúsculas pelo servidor. |
| `steps` | object[] | Não | Substitui o array ordenado de etapas. `sequence` ausente assume `index + 1`; `retryDelayBaseSeconds` é limitado a `>= 1` e `timeoutSeconds` é limitado a `>= 5`. |
| `inputFormat` | string | Não | Formato padrão de entrada: `csv`, `jsonl` ou `xlsx`. |
| `outputFormat` | string | Não | Formato padrão de saída: `csv`, `jsonl` ou `xlsx`. |
| `mergeStrategy` | string | Não | Estratégia de execução de etapas: `sequential`, `parallel-independent` ou `parallel-with-fallback`. |
| `notification` | object | Não | Configurações de notificação de conclusão (`webhookUrl` e `emailOnCompletion`). Sincroniza automaticamente um Webhook Verifik ativo quando `webhookUrl` é definido. |
| `scheduleExpression` | string | Não | Expressão de agendamento para execuções automatizadas. |
| `preferredReportTemplate` | string | Não | ObjectId do `SmartReportTemplate` vinculado a esta configuração. |
| `visitaFlow` | object | Não | Grafo visual de nós que define o encadeamento de etapas (expressões `{{results.N.field}}` são excluídas das entradas manuais no schema de entrada derivado). |
| `isActive` | boolean | Não | Se a configuração está ativa. |
| `executor` | string | Não | Alvo de execução: `queue`, `featureRunner` ou `browser` (`featureRunner` é persistido como `browser`). Sincroniza lotes filhos não terminais quando alterado. |

### Notas

- Enviar `steps` substitui todo o array `steps` na configuração; não aplica patch em etapas individuais no local.
- Valores `sequence` ausentes dentro de `steps` são normalizados para `index + 1`, `retryDelayBaseSeconds` é limitado a `>= 1` e `timeoutSeconds` é limitado a `>= 5`.
- Alterar `executor` sincroniza quaisquer lotes filhos não terminais pertencentes a esta configuração.
- IDs ausentes ou de outro cliente retornam `404` (`not_found`), enquanto erros de validação de schema do Mongoose retornam `422` (`UnprocessableEntity`).
