Resolva o contrato exato de entrada de uma `BatchConfiguration` salva antes de enviar linhas. Este endpoint retorna `preferredReportTemplate` (fazendo fallback para o `SmartReportTemplate` ativo mais recente vinculado à configuração), `webhookUrl`, `stepCount`, `estimatedCreditsPerRow`, `requiredFields`, `optionalFields`, um `jsonSchema` padrão e um payload `exampleInput` pronto para envio.

O resolvedor ignora automaticamente etapas desabilitadas, opções de `dependencyGroup` inativas, flags internas e campos já fornecidos por meio de `parameterDefaults` ou encadeamento de etapas do `visitaFlow` (`{{results.N.field}}`), enquanto remapeia nomes de colunas de acordo com `inputFieldMapping`. Esta rota é registrada antes de `/{id}` para que `/input-schema` seja resolvido diretamente, e também está disponível como a ferramenta MCP `smart_report_get_input_schema`.

### Endpoint

```
GET https://api.verifik.co/v2/batch-configurations/{id}/input-schema
```

Também acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/batch-configurations/{id}/input-schema` usando seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome | Valor |
| ---- | ----- |
| Content-Type | `application/json` |
| Authorization | `Bearer <VERIFIK_JWT>` |

O token deve ser um **JWT de cliente**. Credenciais ausentes ou inválidas retornam `401 Unauthorized`.

### Parâmetros

| Nome | Tipo | Obrigatório | Descrição |
| ---- | ---- | ----------- | --------- |
| `id` | string | Sim | ObjectId da `BatchConfiguration` a inspecionar. |

### Notas

- Inspecionar o schema de entrada não executa consultas e não consome créditos.
- Se `preferredReportTemplate` não estiver definido na configuração, o servidor faz fallback para o `SmartReportTemplate` ativo mais recente vinculado a `{id}` (ou `null` se nenhum existir).
- Quando `inputFieldMapping` mapeia uma coluna de entrada para um parâmetro da API, `requiredFields`, `optionalFields`, `jsonSchema` e `exampleInput` expõem o nome da coluna de entrada mapeada em vez do nome bruto do parâmetro da API.
- Valores de `{id}` ausentes ou de outro cliente retornam `404` (`not_found`), diferentemente de [Obter uma configuração de lote](/verifik-pt/smart-reports/retrieve-a-batch-configuration), que retorna `200` com `data: null`.
- Para agentes de IA e pipelines headless, este endpoint corresponde à ferramenta MCP `smart_report_get_input_schema`.
