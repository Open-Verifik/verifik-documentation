Renderize um template de Smart Report salvo (`{id}`) com `sampleData` e envie o PDF resultante por e-mail diretamente para um ou mais `recipients`. Opcionalmente, forneça `printHtml` para ignorar a geração de HTML ou `pdfBase64` para anexar um buffer de PDF pré-renderizado.

Em pipelines de CI/CD headless, fluxos de aprovação de templates e automações com agentes de IA, use este endpoint para distribuir pré-visualizações formatadas de relatórios a revisores de conformidade ou partes interessadas do produto sem precisar configurar sua própria infraestrutura de e-mail. Corpos de requisição JSON de até `64MB` são aceitos para acomodar fontes incorporadas, logotipos, HTML pré-renderizado ou PDFs em base64.

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates/{id}/send-sample
```

O proxy do Smart-Agent (`https://ai.verifik.co`) expõe os mesmos caminhos `/v2/...` e exige o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>`.

### Cabeçalhos

| Nome          | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição                             |
| ---- | ------ | ----------- | ------------------------------------- |
| `id` | string | Sim         | ObjectId do template de Smart Report. |

### Corpo

Suporta payloads JSON de até `64MB`.

| Nome         | Tipo     | Obrigatório | Descrição                                                                                                                               |
| ------------ | -------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `recipients` | string[] | Sim         | Array de endereços de e-mail válidos dos destinatários (mínimo de `1`).                                                                 |
| `sampleData` | object   | Sim         | Payload de exemplo contendo `inputData`, `results`, `batchName` e `rowIndex`.                                                           |
| `subject`    | string   | Não         | Linha de assunto personalizada do e-mail. Assume `` `Sample Report: <name>` `` como padrão usando o `name` do template.                 |
| `language`   | string   | Não         | Idioma do texto do e-mail: `"en"` ou `"es"`. O padrão é `"es"`.                                                                         |
| `printHtml`  | string   | Não         | Documento HTML pré-renderizado opcional para converter em PDF em vez de renderizar a partir das `sections` do template.                |
| `pdfBase64`  | string   | Não         | Anexo PDF codificado em base64 opcional para enviar diretamente sem geração de PDF no servidor.                                         |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func main() {
	id := "67c1f94b2d8a1c0012a4b301"
	body, _ := json.Marshal(map[string]interface{}{
		"recipients": []string{"compliance@acme.example"},
		"subject":    "Sample Report: Colombia Driver Onboarding",
		"language":   "en",
		"sampleData": map[string]interface{}{
			"batchName": "Driver Onboarding Sample",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",
			},
			"results": map[string]interface{}{
				"identity": map[string]interface{}{
					"fullName": "Mateo Rojas",
					"status":   "active",
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/"+id+"/send-sample", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notas

- Diferente de outros endpoints de template que encapsulam payloads em `{ "data": ... }`, `send-sample` retorna os campos `success`, `message`, `recipients`, `messageId` e `delivery` no nível superior.
- Se `language` for omitido, o e-mail assume `"es"` por padrão. Passe `"en"` para notificações em inglês às partes interessadas.
- Para salvar o PDF renderizado localmente em vez de enviá-lo por e-mail, use [Baixar amostra do template](/verifik-pt/smart-reports/download-template-sample).
