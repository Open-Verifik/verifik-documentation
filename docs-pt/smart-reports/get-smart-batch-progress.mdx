Busque um resumo leve de progresso para um `SmartBatch` sem transferir todo o array `rows`. A resposta inclui contadores de linhas (`totalRows`, `completedRows`, `failedRows`, `partialRows`, `pendingRows`), timestamps de execução, `creditsSpent` e — quando apoiado por uma execução `FeatureRunner` — detalhes aninhados de `run` e do razão `spend`.

Execuções `FeatureRunner` no servidor também emitem um evento de webhook `smart_batch_batch_completed` (incluindo `runId` e `creditsSpent`) após a conclusão quando `batchConfiguration.notification.webhookUrl` está configurado. Consultar este endpoint não consome créditos.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches/{id}/progress
```

Este endpoint também é acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batches/{id}/progress` usando seu próprio `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                      |
| --------------- | ---------------------- | ---------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição |
| ---- | ------ | ----------- | --------- |
| `id` | string | Sim         | ObjectId do `SmartBatch` a consultar. |

### Notas

- `run` e `spend` são incluídos quando o lote possui uma execução `FeatureRunner` associada (`run` é `null` se o registro de execução referenciado não for retornado).
- Execuções `FeatureRunner` no servidor emitem o evento de webhook `smart_batch_batch_completed` (com `runId` e `creditsSpent`) quando finalizadas se `batchConfiguration.notification.webhookUrl` estiver definido. Veja [Webhooks do Smart Reports](/verifik-pt/resources/smart-reports-webhooks).
- Assim que o lote atingir um status terminal, use [Obter um Smart Batch](/verifik-pt/smart-reports/retrieve-a-smart-batch) para inspecionar `results` e `errors` por linha.
