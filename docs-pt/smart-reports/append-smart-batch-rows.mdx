Adicione novas linhas de entrada a um `SmartBatch` existente sem sobrescrever as linhas atuais nem os resultados armazenados. Tanto linhas encapsuladas (`{ rowIndex?, inputData }`) quanto linhas planas (`{ rowIndex?, ...inputFields }`) são aceitas, e o servidor atribui índices de linha sequenciais a partir de `maxExisting + 1`.

A adição de linhas é proibida enquanto o lote estiver em `"processing"` (`400 batch_append_not_allowed_while_processing`). Se o lote estava anteriormente em `"completed"` ou `"failed"`, adicionar linhas redefine `status` para `"pending"` e limpa `completedAt` para que as novas linhas possam ser executadas.

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/{id}/rows/append
```

Este endpoint também é acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batches/{id}/rows/append` usando seu próprio `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                      |
| --------------- | ---------------------- | ---------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição |
| ---- | ------ | ----------- | --------- |
| `id` | string | Sim         | ObjectId do `SmartBatch` ao qual adicionar linhas. |

### Corpo

| Nome   | Tipo     | Obrigatório | Descrição |
| ------ | -------- | ----------- | --------- |
| `rows` | object[] | Sim         | Array não vazio (`min 1`) de linhas de entrada encapsuladas (`{ rowIndex?, inputData }`) ou planas (`{ rowIndex?, ...inputFields }`). O servidor atribui `rowIndex = maxExisting + 1` sequencial. |

Chaves desconhecidas no corpo ou arrays `rows` vazios são rejeitados pela validação Joi com `409 MissingParameter`.

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func main() {
	batchID := "6801a2b3c4d5e6f7a8b9c0d3"
	body, _ := json.Marshal(map[string]interface{}{
		"rows": []map[string]interface{}{
			{
				"inputData": map[string]string{
					"documentType":   "CC",
					"documentNumber": "1020304050",
				},
			},
			{
				"documentType":   "CC",
				"documentNumber": "1098765432",
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-batches/"+batchID+"/rows/append", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notas

- Adicionar linhas não executa verificações nem consome créditos; inicie o lote em seguida com [Iniciar um Smart Batch](/verifik-pt/smart-reports/start-a-smart-batch).
- Qualquer `rowIndex` fornecido pelo cliente é ignorado em favor da numeração sequencial atribuída pelo servidor a partir de `maxExisting + 1`.
- Se o lote estava em `"completed"` ou `"failed"`, seu `status` é redefinido para `"pending"` e `completedAt` é limpo.
