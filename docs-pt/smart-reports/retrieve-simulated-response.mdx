Obtenha a resposta simulada de sandbox, o `outline` de campos, `dataSample` e `emptySample` para um `code` de endpoint do catálogo descoberto via [Listar respostas simuladas](/verifik-pt/smart-reports/list-simulated-responses). Você pode alternar o estado retornado em `sample` entre registros preenchidos (`"data"`), correspondências vazias (`"empty"`) ou dados ausentes (`"missing"`), e controlar a quantidade de linhas em arrays com `listSize`.

Em design de templates headless e fluxos de trabalho automatizados de QA, este endpoint permite validar como seu template renderiza casos extremos — como tabelas vazias, campos opcionais ausentes ou arrays com várias páginas (`listSize` de `2` a `30`) — antes de salvar ou publicar um template para pipelines `SmartBatch` em produção.

### Endpoint

```
GET https://api.verifik.co/v2/smart-report-templates/simulated-responses/{code}
```

O proxy do Smart-Agent (`https://ai.verifik.co`) expõe os mesmos caminhos `/v2/...` e exige o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>`.

### Cabeçalhos

| Nome          | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parâmetros

| Nome           | Tipo    | Localização | Obrigatório | Descrição                                                                                            |
| -------------- | ------- | ----------- | ----------- | ---------------------------------------------------------------------------------------------------- |
| `code`         | string  | Path        | Sim         | Código do endpoint do catálogo obtido em [Listar respostas simuladas](/verifik-pt/smart-reports/list-simulated-responses). |
| `availability` | string  | Query       | Não         | Estado simulado a retornar em `sample`: `"data"`, `"empty"` ou `"missing"`. O padrão é `"data"`.     |
| `listSize`     | integer | Query       | Não         | Quantidade de itens sintéticos a gerar para campos de array/lista. Intervalo válido: `2` a `30`.     |

async function run() {
  const code = "co_cedula";
  const params = new URLSearchParams({

    listSize: "5",

  const res = await fetch(

      method: "GET",
      headers: {
        Accept: "application/json",
        Authorization: `Bearer ${process.env.VERIFIK_JWT}`,
      },
    }
  );

  console.log(await res.json());
}

run();

### Notas

- Se `{code}` não estiver presente no inventário do sandbox, o endpoint retorna HTTP `200` com `found: false`, objetos `outline` e `sample` vazios e um campo explicativo `note`.
- `listSize` aceita inteiros de `2` a `30` e é útil para testar paginação de PDFs multipágina via [Baixar amostra do template](/verifik-pt/smart-reports/download-template-sample).
- Este endpoint não executa verificações ao vivo e não consome créditos.
