Gere, adicione ou edite definições estruturadas de `ReportSection` a partir de um `prompt` em linguagem natural usando o Gemini (temperatura `0.2`). Passe dados de verificação de exemplo em `previewData` para que o modelo alinhe as vinculações de `dataPath` e os layouts de coluna das seções com a estrutura real do seu payload.

Em construtores de relatórios headless e pipelines de agentes de IA, use este endpoint para criar layouts completos (`"create"`), acrescentar novas seções a um template existente (`"append"`) ou refinar uma única seção (`"edit"`) sem escrever o JSON da seção manualmente. Combine esta chamada com [Pré-visualizar HTML do template](/verifik-pt/smart-reports/preview-template-html) para inspecionar o resultado renderizado antes de persistir com [Criar um template de relatório](/verifik-pt/smart-reports/create-a-report-template) ou [Atualizar um template de relatório](/verifik-pt/smart-reports/update-a-report-template).

### Endpoint

```
POST https://api.verifik.co/v2/smart-report-templates/generate-layout
```

O proxy do Smart-Agent (`https://ai.verifik.co`) expõe os mesmos caminhos `/v2/...` e exige o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>`.

### Cabeçalhos

| Nome          | Valor                  |
| ------------- | ---------------------- |
| Content-Type  | `application/json`     |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Corpo

| Nome              | Tipo          | Obrigatório | Descrição                                                                                                                                      |
| ----------------- | ------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`          | string        | Sim         | Instruções em linguagem natural descrevendo o layout a criar, as seções a adicionar ou as alterações a aplicar no modo de edição.             |
| `mode`            | string        | Sim         | Modo de geração: `"create"`, `"edit"` ou `"append"`.                                                                                           |
| `previewData`     | object        | Não         | JSON de verificação de exemplo (por exemplo, `inputData`, `results`, `batchName`) usado para embasar as expressões `dataPath` e as colunas geradas. |
| `currentSections` | object[]      | Não         | Array `ReportSection` existente. Recomendado no modo `"append"` para que as novas seções geradas continuem a sequência atual de `order`.       |
| `selectedSection` | object / null | Não         | Objeto `ReportSection` de destino a modificar quando `mode` é `"edit"`. Se for `null` ou omitido no modo `"edit"`, o comportamento recorre ao modo `"create"`. |

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"

	body, _ := json.Marshal(map[string]interface{}{
		"prompt": "Create a clean 2-column driver summary section followed by a table of traffic citations.",
		"mode":   "create",
		"previewData": map[string]interface{}{
			"batchName": "Driver Onboarding",
			"rowIndex":  0,
			"inputData": map[string]interface{}{
				"documentType":   "CC",
				"documentNumber": "1020304050",

			"results": map[string]interface{}{
				"identity": map[string]interface{}{"fullName": "Mateo Rojas", "status": "active"},
				"fines": []map[string]interface{}{
					{"code": "C02", "amount": 580000, "status": "pending"},
				},
			},
		},
	})

	req, _ := http.NewRequest("POST", "https://api.verifik.co/v2/smart-report-templates/generate-layout", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)

### Notas

- Os modos `"create"` e `"append"` retornam `{ "data": [ ...ReportSection ] }` (um array), enquanto o modo `"edit"` com um `selectedSection` não nulo retorna `{ "data": { ...ReportSection } }` (um único objeto).
- Chamar `"edit"` com `selectedSection: null` ou omitir `selectedSection` recorre ao modo `"create"` e retorna um array.
- Este endpoint não grava no banco de dados. Passe as `sections` retornadas para [Pré-visualizar HTML do template](/verifik-pt/smart-reports/preview-template-html) para inspecionar o HTML ou para [Criar um template de relatório](/verifik-pt/smart-reports/create-a-report-template) para salvá-las.
