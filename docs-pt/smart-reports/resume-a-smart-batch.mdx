Retome um `SmartBatch` pausado (e qualquer execução `FeatureRunner` subjacente). O servidor verifica se a sua conta de cliente ainda possui permissões para todas as etapas configuradas (`409 endpoints_not_in_account` se algum acesso a endpoint tiver sido revogado), confirma que o lote está no status `"paused"` e faz a transição dele de volta para `"processing"`.

Se o lote não estiver atualmente em `"paused"`, a requisição falha com `400 BadRequest` (`batch_not_paused`, ou `run_not_paused` quando uma execução `FeatureRunner` subjacente não estiver pausada).

### Endpoint

```text
POST https://api.verifik.co/v2/smart-batches/{id}/resume
```

Este endpoint também é acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batches/{id}/resume` usando seu próprio `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                      |
| --------------- | ---------------------- | ---------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição |
| ---- | ------ | ----------- | --------- |
| `id` | string | Sim         | ObjectId do `SmartBatch` a retomar. |

### Notas

- A retomada revalida as permissões de recursos do cliente e rejeita a requisição com `409 endpoints_not_in_account` se qualquer endpoint de etapa não estiver mais habilitado na sua conta.
- Linhas concluídas mantêm seus resultados armazenados e não são reexecutadas nem cobradas em duplicidade ao retomar.
- Se o lote estava em `"draft"`, `"pending"` ou `"cancelled"`, use [Iniciar um Smart Batch](/verifik-pt/smart-reports/start-a-smart-batch) em vez disso.
