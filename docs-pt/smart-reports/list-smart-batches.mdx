Liste os registros `SmartBatch` pertencentes à conta de cliente autenticada. Os resultados vêm ordenados por padrão do mais recente para o mais antigo (`-createdAt`) e excluem o array `rows`, a menos que você envie explicitamente `includeRows=true`, mantendo as respostas de listagem compactas.

Envie `page` para habilitar a saída paginada com os metadados `total`, `limit`, `page` e `pages`. Omita `page` para receber `{ data }` contendo o array de lotes correspondente sem campos de paginação. Listar lotes não executa verificações e não consome créditos.

### Endpoint

```text
GET https://api.verifik.co/v2/smart-batches
```

Este endpoint também é acessível pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-batches` usando seu próprio `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                      |
| --------------- | ---------------------- | ---------------------------------------------- |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.              |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome                 | Tipo    | Obrigatório | Descrição |
| -------------------- | ------- | ----------- | --------- |
| `batchConfiguration` | string  | Não         | Filtra lotes pelo ObjectId da `BatchConfiguration`. |
| `status`             | string  | Não         | Filtra pelo status do lote: `"draft"`, `"pending"`, `"processing"`, `"paused"`, `"completed"`, `"failed"` ou `"cancelled"`. |
| `page`               | number  | Não         | Número da página (`>= 1`). Habilita a paginação e adiciona `total`, `limit`, `page` e `pages` à resposta. |
| `limit`              | number  | Não         | Máximo de itens por resposta (`1` a `200`). |
| `perPage`            | number  | Não         | Tamanho da página (`1` a `200`) quando `page` é definido. O padrão é `20`. |
| `includeRows`        | boolean | Não         | Defina como `true` para incluir `rows` em cada lote retornado. Quando omitido ou `false`, `rows` é excluído. |
| `search`             | string  | Não         | Busca regex sem distinção entre maiúsculas e minúsculas no campo `name` do lote. |
| `sort`               | string  | Não         | Campo e direção de ordenação. O padrão é `"-createdAt"`. |
| `sortBy`             | string  | Não         | Nome do campo de ordenação quando combinado com `sortOrder`. |
| `sortOrder`          | string  | Não         | Direção de ordenação para `sortBy`: `"asc"` ou `"desc"`. |

Parâmetros de consulta desconhecidos são rejeitados pela validação Joi com `409 MissingParameter`.

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	params := url.Values{}
	params.Set("status", "processing")
	params.Set("page", "1")
	params.Set("perPage", "20")
	params.Set("search", "Colombia")
	params.Set("sort", "-createdAt")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-batches?"+params.Encode(), nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notas

- Os resultados são restritos ao cliente autenticado (`clientId` no seu JWT).
- Deixar `includeRows` omitido ou `false` mantém as respostas de listagem pequenas; busque os `rows` completos de um lote usando [Obter um Smart Batch](/verifik-pt/smart-reports/retrieve-a-smart-batch).
- Valores de consulta inválidos ou chaves de consulta desconhecidas falham na validação Joi com `409 MissingParameter`.
- Quando `page` é fornecido (`>= 1`), `perPage` assume o padrão `20` e aceita de `1` a `200`.
