Liste os registros `SmartReport` pertencentes ao cliente autenticado. Os resultados populam `template`, `smartBatch` e `client`, e podem ser filtrados por `smartBatch`, `template`, `externalRefId` e `createdByChannel`, com paginação e ordenação opcionais.

Quando você passa `page`, a resposta inclui metadados de paginação (`total`, `limit`, `page` e `pages`). Omita `page` para receber a lista correspondente dentro de `{ data: [...] }` sem metadados de paginação.

### Endpoint

```
GET https://api.verifik.co/v2/smart-reports
```

Este endpoint também pode ser acessado pelo proxy do Smart-Agent em `https://ai.verifik.co/v2/smart-reports` usando o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>` por cliente. A execução compartilhada via x402 é bloqueada com `403 Forbidden`.

### Cabeçalhos

| Nome            | Valor                  | Descrição                                        |
| --------------- | ---------------------- | ------------------------------------------------ |
| `Content-Type`  | `application/json`     | Formato do payload da requisição.                |
| `Authorization` | `Bearer <VERIFIK_JWT>` | JWT com escopo de cliente (`authUser.clientId`). |

### Parâmetros

| Nome               | Tipo   | Obrigatório | Descrição |
| ------------------ | ------ | ----------- | --------- |
| `smartBatch`       | string | Não         | Filtra relatórios vinculados a um ObjectId de `SmartBatch` específico. |
| `template`         | string | Não         | Filtra relatórios vinculados a um ObjectId de template específico. |
| `status`           | string | Não         | Valores permitidos: `"draft"`, `"pending"`, `"generating"`, `"generated"`, `"failed"`, `"sent"`. Aceito pela validação Joi para compatibilidade futura; a filtragem atual da listagem opera sobre `smartBatch`, `template`, `externalRefId` e `createdByChannel`. |
| `externalRefId`    | string | Não         | Filtra pelo seu identificador externo de correlação. Máximo de `200` caracteres. |
| `createdByChannel` | string | Não         | Filtra pelo canal de origem: `"portal"`, `"api"`, `"mcp"`, `"x402"` ou `"webhook"`. |
| `page`             | number | Não         | Número da página a recuperar. Fornecer `page` habilita saída paginada com `total`, `limit`, `page` e `pages`. |
| `limit`            | number | Não         | Quantidade máxima de itens por página. Assume `20` como padrão quando `page` é definido. |
| `sort`             | string | Não         | Campo e direção de ordenação. Assume `"-updatedAt"` como padrão quando `page` é definido. |

#### Notas sobre filtragem e paginação

- **Parâmetro `status` compatível com futuras versões**: O Joi valida `status` contra `"draft"`, `"pending"`, `"generating"`, `"generated"`, `"failed"` e `"sent"`, enquanto a consulta de listagem subjacente atualmente filtra por `smartBatch`, `template`, `externalRefId` e `createdByChannel`.
- **Dois formatos de resposta `200`**: Envie `page` sempre que seu dashboard ou tarefa de sincronização precisar de `total` e `pages`; omita `page` para obter um payload `{ data: [...] }` mais simples.

package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"os"
)

func main() {
	params := url.Values{}
	params.Set("createdByChannel", "api")
	params.Set("externalRefId", "applicant-42")
	params.Set("page", "1")
	params.Set("limit", "20")
	params.Set("sort", "-updatedAt")

	req, _ := http.NewRequest("GET", "https://api.verifik.co/v2/smart-reports?"+params.Encode(), nil)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+os.Getenv("VERIFIK_JWT"))

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	var out map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&out)
	fmt.Println(out)
}

### Notas

- `GET /v2/smart-reports` popula `template`, `smartBatch` e `client` em cada `SmartReport` retornado.
- Valores inválidos de parâmetros de consulta falham na validação Joi com `409 MissingParameter`.
- Para inspecionar um único relatório com os campos prontos `downloadUrl` e `htmlUrl`, use [Consultar um Smart Report](/verifik-pt/smart-reports/retrieve-a-smart-report).
- Para executar um novo relatório de ponta a ponta sem gerenciar registros `SmartBatch` e `SmartReport` separadamente, use [Executar um Smart Report](/verifik-pt/smart-reports/run-a-smart-report).
