Exclua um template de Smart Report personalizado pertencente ao cliente autenticado. O documento do template excluído é retornado em `{ "data": ... }`.

Em fluxos de trabalho headless e pipelines de testes automatizados, use este endpoint para limpar templates temporários ou desativar designs de relatório obsoletos. Templates `"System"` integrados não podem ser excluídos e retornam `403` (`system_template_readonly`). Excluir um template não consome créditos e não remove relatórios de `SmartBatch` gerados anteriormente.

### Endpoint

```
DELETE https://api.verifik.co/v2/smart-report-templates/{id}
```

O proxy do Smart-Agent (`https://ai.verifik.co`) expõe os mesmos caminhos `/v2/...` e exige o seu próprio cabeçalho `Authorization: Bearer <VERIFIK_JWT>`.

### Cabeçalhos

| Nome          | Valor                  |
| ------------- | ---------------------- |
| Accept        | `application/json`     |
| Authorization | `Bearer <VERIFIK_JWT>` |

### Parâmetros

| Nome | Tipo   | Obrigatório | Descrição                             |
| ---- | ------ | ----------- | ------------------------------------- |
| `id` | string | Sim         | ObjectId do template de Smart Report. |

### Notas

- Templates `"System"` integrados não podem ser excluídos (`403` `system_template_readonly`).
- Após a exclusão, requisições subsequentes de `GET`, `PUT` ou `DELETE` para o mesmo `{id}` retornam `{ "data": null }` (em `GET`) ou `404` `not_found` (em `PUT`/`DELETE`).
