# Colômbia — PEP missões no exterior

Filtre funcionários de missões e consulados da Colômbia no exterior.

## O que a chamada devolve

- `isPEP`
- `isForeignMissionOfficial`
- `fullName` e `documentNumber`
- `matches` vazio numa ausência limpa

## Casos de uso

- Filtre um diretório PEP da Colômbia antes da admissão.
- Guarde quem não está listado como HTTP 200.
- Busque por nome ou por número.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/co/pep/misiones-exterior
```

Um acerto põe `isPEP` em true e `isForeignMissionOfficial` em true. Quem simplesmente não está neste diretório é HTTP 200 com `isPEP` false e `matches` vazio. Isso não é 404.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **Condicional** | `MARIA LOPEZ` | Nome. Basta sozinho. `partyName`, `entityName` ou `country` também são aceitos quando o diretório os tem. |
| `documentNumber` | string | **Condicional** | `80123456` | Identificador de 4 a 30 caracteres. |
| `documentType` | string | Não | `CC` | Opcional: `CC`, `NIT`, `CE`, `PAS`, `TI`, `CD`. |

### Notas

- Uma ausência limpa é HTTP 200 com `isPEP` false.
- Envie pelo menos um valor de busca.
- Não mapeie esse 200 para 404.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `fullName: "MARIA LOPEZ"` | 200 com isPEP true num acerto. |
| Valor obrigatório ausente | Omit every search value | 409 se nenhum valor for enviado. |
| Valor desconhecido | `fullName: "CLEAN NAME"` | 200 com isPEP false. A ausência limpa não é 404. |

401 when the bearer token is missing or rejected.
