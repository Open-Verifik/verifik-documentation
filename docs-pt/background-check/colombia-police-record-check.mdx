# Antecedentes na Polícia Nacional da Colômbia

## Referência da API

### Endpoint

```
https://api.verifik.co/v2/co/policia/consultar
```

O serviço de consulta de antecedentes na Polícia Nacional da Colômbia verifica se uma pessoa tem assuntos pendentes com as autoridades judiciais colombianas, conforme o artigo 248 da Constituição. Envie **`documentType`** e **`documentNumber`** por **GET** (query) ou **POST** (corpo JSON). Um `data` bem-sucedido inclui `documentType`, `documentNumber`, `firstName`, `lastName`, `fullName`, `arrayName` e `details`. Ideal para contratação, onboarding e diligência prévia.

### Cabeçalhos (Headers)

| Nome          | Valor              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

### Parâmetros

:::info
Para a lista completa de **tipos de documento** suportados e seus parâmetros obrigatórios específicos, consulte o guia [Tipos de documento](/background-check/document-types).
:::

| Nome             | Tipo   | Obrigatório | Descrição                                                                 |
| ---------------- | ------ | ----------- | ------------------------------------------------------------------------- |
| `documentType`   | string | Sim         | Tipo de documento. Valores válidos: **CC**, **CE**, **PPT**, **PA**, **DP**. **DP** é Documento Diplomático. **PPT** é aceito; o portal da Policía o trata como passaporte. |
| `documentNumber` | string | Sim         | Número do documento da pessoa a ser consultada, sem espaços ou pontos.    |

Este endpoint **não** recebe o parâmetro `date` (diferente do [RNMC](/verifik-pt/background-check/colombia-police-compliance-corrective-measures)).

### Observações (Notes)

- **GET** e **POST** são suportados. O POST envia os mesmos campos no corpo JSON.
- O portal da Policía imprime **apellidos e depois nombres**. A Verifik devolve primeiro os prenomes: `firstName` `LILIA MANUELA`, `lastName` `LESPORT FERNANDEZ`, `fullName` `LILIA MANUELA LESPORT FERNANDEZ` e `arrayName` com prenomes e depois sobrenomes.
- Em produção, `data.details` é apenas a frase **NO TIENE** / **REGISTRA ASUNTOS**. A legenda constitucional é removida.
- O sandbox pode incluir também `legend`. Não trate `legend` como campo garantido em produção.
- Os `documentType` permitidos são **CC**, **CE**, **PPT**, **PA** e **DP** (Documento Diplomático). **PPT** é aceito; o portal o trata como passaporte.
- Esta rota não exige `date` de expedição (o RNMC exige).
- Falhas temporárias da origem ou do captcha retornam **409** com `Endpoint_out_of_service` ou `captcha_failed`.
- Para medidas corretivas pendentes, use [Colômbia - RNMC / medidas corretivas](/verifik-pt/background-check/colombia-police-compliance-corrective-measures) (`GET /v2/co/policia/rnmc`).
