# Exclusões legislativas especiais dos EUA

Consulte se uma pessoa ou organização consta em **Exclusões legislativas especiais dos EUA**. O System for Award Management (SAM) publica esta lista para os Estados Unidos.

As exclusões legislativas especiais identificam partes excluídas de adjudicações federais por uma lei específica, e não por suspensão ou inabilitação ordinária de compras.

Envie `fullName`, `documentNumber` ou ambos. Pelo menos um dos dois é obrigatório. A resposta define `foundInSamSpecialExclusions` como `true` quando a consulta corresponde a um registro publicado e como `false` quando não corresponde. Em uma correspondência, `details` inclui a parte excluída, o tipo de exclusão, a agência e as datas de vigência. Use o resultado em KYC, PLD/CFT, cadastro de fornecedores e triagem de pagamentos. Revise cada correspondência antes de depender dela. Esta chamada não substitui a lista oficial e não é uma determinação legal.

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/sam-special-exclusions
```

Uma resposta bem-sucedida devolve `data.fullName`, `data.firstName` e `data.lastName` quando a fonte separa o nome, `data.documentNumber` se você o enviou, `data.foundInSamSpecialExclusions` e `data.details`. Em uma correspondência, `details` inclui a parte excluída, o tipo de exclusão, a agência e as datas de vigência. O objeto `signature` inclui `dateTime` e a mensagem `Certified by Verifik.co`. Quando `foundInSamSpecialExclusions` é `false`, `details` é um objeto vazio.

### Headers

| Nome          | Valor              | Descrição              |
| ------------- | ------------------ | ---------------------- |
| Content-Type  | `application/json` | Formato da solicitação |
| Accept        | `application/json` | Formato da resposta    |
| Authorization | `Bearer <token>`   | JWT da Verifik         |

### Parameters

| Parâmetro        | Tipo   | Obrigatório | Exemplo                  | Descrição                                                                                                       |
| ---------------- | ------ | ----------- | ------------------------ | --------------------------------------------------------------------------------------------------------------- |
| `fullName`       | string | Condicional | `SAMPLE DESIGNATED NAME` | Nome legal completo da pessoa ou denominação da organização. Obrigatório quando `documentNumber` não é enviado. |
| `documentNumber` | string | Condicional | `A1234567`               | Número de identificação ou de registro societário, sem espaços. Obrigatório quando `fullName` não é enviado.    |

### Casos de uso

- **Triagem de adjudicação:** Consulte um licitante ou beneficiário antes de uma adjudicação ou pagamento federal.
- **Status de exclusão:** Leia o tipo de exclusão e as datas devolvidas para a parte consultada.
- **Registro:** Guarde a resposta certificada no processo de adjudicação.

### Notes

- Envie `fullName` ou `documentNumber`. Pelo menos um é obrigatório. Se ambos faltarem, a API retorna HTTP 409 com o código `MissingParameter` e a mensagem `Either fullName or documentNumber must be provided`.
- `foundInSamSpecialExclusions` é `true` quando a consulta corresponde a um registro desta lista e `false` quando não corresponde. `details` é um objeto vazio quando não há correspondência.
- O exemplo de correspondência mostra a forma da resposta. Uma correspondência real devolve os atributos publicados para esse registro nesta lista.
- Uma correspondência é um resultado de triagem para revisão de conformidade. Não é uma determinação legal e não substitui a fonte oficial.
- Autentique com um JWT Bearer no cabeçalho `Authorization`.
- O resultado reflete a lista no momento da chamada. Faça uma nova solicitação quando precisar de um resultado posterior.
