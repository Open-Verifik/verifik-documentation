# Foragidos procurados pelo BKA da Alemanha

Consulte se uma pessoa ou organização consta em **Foragidos procurados pelo BKA da Alemanha**. O Departamento Federal de Investigação Criminal (BKA) publica esta lista para a Alemanha.

O Departamento Federal de Investigação Criminal publica pessoas procuradas pela polícia alemã. Uma correspondência significa que o nome consultado aparece nessa lista pública.

Envie `fullName`, `documentNumber` ou ambos. Pelo menos um dos dois é obrigatório. A resposta define `foundInBkaWanted` como `true` quando a consulta corresponde a um registro publicado e como `false` quando não corresponde. Em uma correspondência, `details` inclui o nome listado, a autoridade que publica, o tipo de aviso e as observações. Use o resultado em KYC, PLD/CFT, cadastro de fornecedores e triagem de pagamentos. Revise cada correspondência antes de depender dela. Esta chamada não substitui a lista oficial e não é uma determinação legal.

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/bka-wanted
```

Uma resposta bem-sucedida devolve `data.fullName`, `data.firstName` e `data.lastName` quando a fonte separa o nome, `data.documentNumber` se você o enviou, `data.foundInBkaWanted` e `data.details`. Em uma correspondência, `details` inclui o nome listado, a autoridade que publica, o tipo de aviso e as observações. O objeto `signature` inclui `dateTime` e a mensagem `Certified by Verifik.co`. Quando `foundInBkaWanted` é `false`, `details` é um objeto vazio.

### Headers

| Nome          | Valor              | Descrição              |
| ------------- | ------------------ | ---------------------- |
| Content-Type  | `application/json` | Formato da solicitação |
| Accept        | `application/json` | Formato da resposta    |
| Authorization | `Bearer <token>`   | JWT da Verifik         |

### Parameters

| Parâmetro        | Tipo   | Obrigatório | Exemplo                  | Descrição                                                                                                       |
| ---------------- | ------ | ----------- | ------------------------ | --------------------------------------------------------------------------------------------------------------- |
| `fullName`       | string | Condicional | `SAMPLE DESIGNATED NAME` | Nome legal completo da pessoa ou denominação da organização. Obrigatório quando `documentNumber` não é enviado. |
| `documentNumber` | string | Condicional | `A1234567`               | Número de identificação ou de registro societário, sem espaços. Obrigatório quando `fullName` não é enviado.    |

### Casos de uso

- **Triagem policial:** Verifique se uma pessoa consta como procurada por esta autoridade.
- **Diligência reforçada:** Revise um nome que coincida com um aviso público de procura antes de seguir.
- **Registro:** Guarde a resposta certificada no arquivo de triagem.

### Notes

- Envie `fullName` ou `documentNumber`. Pelo menos um é obrigatório. Se ambos faltarem, a API retorna HTTP 409 com o código `MissingParameter` e a mensagem `Either fullName or documentNumber must be provided`.
- `foundInBkaWanted` é `true` quando a consulta corresponde a um registro desta lista e `false` quando não corresponde. `details` é um objeto vazio quando não há correspondência.
- O exemplo de correspondência mostra a forma da resposta. Uma correspondência real devolve os atributos publicados para esse registro nesta lista.
- Uma correspondência é um resultado de triagem para revisão de conformidade. Não é uma determinação legal e não substitui a fonte oficial.
- Autentique com um JWT Bearer no cabeçalho `Authorization`.
- O resultado reflete a lista no momento da chamada. Faça uma nova solicitação quando precisar de um resultado posterior.
