# Lista — Pessoas inabilitadas do BCB do Brasil

Filtre o registro do Banco Central do Brasil de pessoas inabilitadas para cargos superiores.

## O que a chamada devolve

- `foundInBrBcbDisqualified`
- `details` numa correspondência
- `fullName`

## Casos de uso

- Filtre antes de pagar ou admitir.
- Trate uma bandeira false como um 200 limpo.
- Envie um nome, ou tipo e número.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/br/bcb-disqualified
```

Uma correspondência põe `foundInBrBcbDisqualified` em true e preenche `details`. Quem não está na lista é HTTP 200 com `foundInBrBcbDisqualified` false e `details` vazio.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `fullName` | string | **Condicional** | `SAMPLE NAME` | Nome ou, numa lista de carteiras, o endereço. Basta sozinho. |
| `documentType` | string | **Condicional** | `CPF` | Obrigatório com `documentNumber` se omitir `fullName`. Um CPF sem nome também exige `dateOfBirth`. |
| `documentNumber` | string | **Condicional** | `12345678901` | Identificador de pelo menos 5 caracteres, com `documentType`, se omitir `fullName`. |
| `dateOfBirth` | string | **Condicional** | `1990-01-15` | Obrigatória para CPF, CI, CCPA, DUI ou CCUY se omitir `fullName`. |

### Notas

- Envie `fullName`, ou `documentType` e `documentNumber`.
- Quem não está listado é HTTP 200 com `foundInBrBcbDisqualified` false.
- Um CPF sem nome também exige `dateOfBirth`.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `fullName: "SAMPLE NAME"` | 200 com foundInBrBcbDisqualified true se a lista coincidir. |
| Valor obrigatório ausente | Omit fullName and the document pair | 409 se faltarem fullName e o par de documento. |
| Valor desconhecido | `fullName: "CLEAN SAMPLE"` | 200 com foundInBrBcbDisqualified false se o sujeito simplesmente não estiver. |

401 when the bearer token is missing or rejected.
