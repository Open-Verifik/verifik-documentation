# Listar centros de custo

```
GET https://api.verifik.co/v2/cost-centers
```

| Nome      | Tipo    | Obrigatório | Descrição                                                    |
| --------- | ------- | ----------- | ------------------------------------------------------------ |
| `active`  | boolean | Não         | `true` só para os ativos, `false` para os inativos.          |
| `country` | string  | Não         | Código de país ISO-2.                                        |
| `page`    | number  | Não         | Número da página, a partir de 1.                             |
| `limit`   | number  | Não         | Itens por página. 50 por padrão, até 100.                    |

```json
{
	"data": [
		{
			"_id": "6acfbdda92451bac5d0a7ebe",
			"name": "Operação Espanha",
			"code": "SPAIN-OPS",
			"country": "ES",
			"active": true
		}
	],
	"total": 1,
	"page": 1,
	"pages": 1,
	"limit": 50
}
```
