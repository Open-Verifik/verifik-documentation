### Endpoint

**GET** `https://api.verifik.co/v2/cost-centers`

Devolve os centros de custo da sua conta, ordenados por país e depois por nome.

#### cabeçalhos

| Nome          | Valor              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### parâmetros de consulta

#### `active`

**Tipo:** boolean  
**Obrigatório:** Não

`true` devolve só os ativos. `false` devolve os inativos. Omita para devolver ambos.

#### `country`

**Tipo:** string  
**Obrigatório:** Não

Código de país ISO-2, por exemplo `ES`.

#### `page`

**Tipo:** number  
**Obrigatório:** Não

Número da página, a partir de 1.

#### `limit`

**Tipo:** number  
**Obrigatório:** Não

Itens por página. 50 por padrão, no máximo 100.

### Exemplo de solicitação

<Tabs groupId="language">

```bash
  -H "Authorization: Bearer $VERIFIK_TOKEN"
```

</TabItem>

## Respostas de erro

Uma consulta inválida, por exemplo `limit` acima de 100 ou um `country` que não tem duas letras:

```json
{
  "message": "\"limit\" must be less than or equal to 100",
  "code": "MissingParameter"
}
```
