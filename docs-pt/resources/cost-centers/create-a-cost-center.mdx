### Endpoint

**POST** `https://api.verifik.co/v2/cost-centers`

Cria um centro de custo na sua conta. Gerir centros de custo não consome créditos.

#### cabeçalhos

| Nome          | Valor              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### parâmetros do corpo

#### `name`

**Tipo:** string  
**Obrigatório:** Sim

Nome exibido, até 120 caracteres.

#### `code`

**Tipo:** string  
**Obrigatório:** Sim

Valor que você enviará em `x-cost-center`. Letras, números, `.`, `-` e `_`, até 60 caracteres. Único por conta.

#### `country`

**Tipo:** string  
**Obrigatório:** Sim

Código de país ISO-2, por exemplo `ES`.

#### `active`

**Tipo:** boolean  
**Obrigatório:** Não

Padrão `true`.

### Exemplo de solicitação

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X POST "https://api.verifik.co/v2/cost-centers" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Operação Espanha","code":"SPAIN-OPS","country":"ES"}'
```

</TabItem>

## Respostas de erro

Um código que já existe na conta:

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```

Um campo ausente ou inválido, como `name`, `code` ou `country`:

```json
{
  "message": "\"name\" is required",
  "code": "MissingParameter"
}
```
