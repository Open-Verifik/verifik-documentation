# Criar um centro de custo

```
POST https://api.verifik.co/v2/cost-centers
```

| Nome      | Tipo    | Obrigatório | Descrição                          |
| --------- | ------- | ----------- | ---------------------------------- |
| `name`    | string  | Sim         | Nome exibido.                      |
| `code`    | string  | Sim         | Valor do header. Único por conta.  |
| `country` | string  | Sim         | Código de país ISO-2.              |
| `active`  | boolean | Não         | Padrão `true`.                     |

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X POST "https://api.verifik.co/v2/cost-centers" \
  -H "Authorization: Bearer $VERIFIK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Operação Espanha","code":"SPAIN-OPS","country":"ES"}'
```

</TabItem>
<TabItem value="nodejs" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.post(
	"https://api.verifik.co/v2/cost-centers",
	{ name: "Operação Espanha", code: "SPAIN-OPS", country: "ES" },
	{ headers: { Authorization: `Bearer ${process.env.VERIFIK_TOKEN}` } }
);

console.log(data.data._id);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.post(
    "https://api.verifik.co/v2/cost-centers",
    headers={"Authorization": f"Bearer {os.environ['VERIFIK_TOKEN']}"},
    json={"name": "Operação Espanha", "code": "SPAIN-OPS", "country": "ES"},
)

print(response.json()["data"]["_id"])
```

</TabItem>
</Tabs>

A resposta é o novo [objeto centro de custo](/verifik-pt/resources/the-cost-center-object) dentro de `data`. Reutilizar um código devolve:

```json
{
	"code": "Conflict",
	"message": "cost_center_code_taken"
}
```
