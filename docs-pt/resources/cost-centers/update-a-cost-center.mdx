### Endpoint

**PUT** `https://api.verifik.co/v2/cost-centers/{id}`

Atualiza um centro de custo. Envie só os campos que quer mudar. As solicitações já gravadas mantêm o centro que tinham.

#### cabeçalhos

| Nome          | Valor              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### parâmetros de rota

#### `id`

**Tipo:** string  
**Obrigatório:** Sim

O id do centro de custo.

#### parâmetros do corpo

#### `name`

**Tipo:** string  
**Obrigatório:** Não

Nome exibido, até 120 caracteres.

#### `code`

**Tipo:** string  
**Obrigatório:** Não

Novo valor do header. Letras, números, `.`, `-` e `_`, até 60 caracteres. Único por conta.

#### `country`

**Tipo:** string  
**Obrigatório:** Não

Código de país ISO-2.

#### `active`

**Tipo:** boolean  
**Obrigatório:** Não

`true` para reativar, `false` para não atribuir a novas solicitações.

## Respostas de erro

Id desconhecido:

```json
{
  "message": "cost_center_not_found",
  "code": "NotFound"
}
```

Um `code` que outro centro da conta já usa:

```json
{
  "message": "cost_center_code_taken",
  "code": "Conflict"
}
```
