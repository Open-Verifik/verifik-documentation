# Atualizar um centro de custo

```
PUT https://api.verifik.co/v2/cost-centers/{id}
```

Envie `name`, `code`, `country` ou `active`. Use `active: true` para reativar um centro. As solicitações já gravadas mantêm o centro de custo que tinham.
