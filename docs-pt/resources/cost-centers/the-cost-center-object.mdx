# O objeto centro de custo

```json
{
	"_id": "6acfbdda92451bac5d0a7ebe",
	"client": "69c2b824295cd7d276e478ad",
	"name": "Operação Espanha",
	"code": "SPAIN-OPS",
	"country": "ES",
	"active": true,
	"createdAt": "2026-10-14T17:37:30.469Z",
	"updatedAt": "2026-10-14T17:37:30.469Z"
}
```

| Campo     | Tipo    | Descrição                                                                                                         |
| --------- | ------- | ----------------------------------------------------------------------------------------------------------------- |
| `name`    | string  | Nome exibido, até 120 caracteres.                                                                                 |
| `code`    | string  | Valor enviado em `x-cost-center`. Letras, números, `.`, `-` e `_`, até 60 caracteres. Único por conta.            |
| `country` | string  | País ISO-2 que este centro de custo costuma atender.                                                              |
| `active`  | boolean | Um centro inativo guarda o histórico, mas não pode ser atribuído a novas solicitações.                            |
