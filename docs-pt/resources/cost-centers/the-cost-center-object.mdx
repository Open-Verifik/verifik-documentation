### Visão geral

O objeto centro de custo é o registro que a Verifik guarda para uma equipe, um país ou uma unidade. As solicitações o referenciam por `_id`. Você envia `code` no header `x-cost-center`.

```json
{
  "_id": "6acfbdda92451bac5d0a7ebe",
  "client": "69c2b824295cd7d276e478ad",
  "name": "Operação Espanha",
  "code": "SPAIN-OPS",
  "country": "ES",
  "active": true,
  "createdAt": "2026-10-14T17:37:30.469Z",
  "updatedAt": "2026-10-14T17:37:30.469Z"
}
```

### Atributos

#### `_id`

**Tipo:** string  
**Obrigatório:** Sim

Identificador único. Use-o para consultar, atualizar e desativar, e no padrão de um projeto.

#### `client`

**Tipo:** string  
**Obrigatório:** Sim

A conta dona deste centro de custo.

#### `name`

**Tipo:** string  
**Obrigatório:** Sim

Nome exibido, até 120 caracteres.

#### `code`

**Tipo:** string  
**Obrigatório:** Sim

Valor enviado em `x-cost-center`. Letras, números, `.`, `-` e `_`, até 60 caracteres. Único por conta.

#### `country`

**Tipo:** string  
**Obrigatório:** Sim

País ISO-2 que este centro costuma atender, em maiúsculas.

#### `active`

**Tipo:** boolean  
**Obrigatório:** Sim

Um centro inativo guarda o histórico, mas não pode ser atribuído a novas solicitações. Padrão `true`.

#### `createdAt`

**Tipo:** string  
**Obrigatório:** Sim

Quando o centro foi criado, em ISO-8601.

#### `updatedAt`

**Tipo:** string  
**Obrigatório:** Sim

Quando mudou pela última vez, em ISO-8601.
