### Endpoint

**DELETE** `https://api.verifik.co/v2/cost-centers/{id}`

Desativa um centro de custo. O registro não é apagado: `active` passa a `false` e o histórico de uso continua ligado a ele. Novas solicitações não podem mais usar este centro.

#### cabeçalhos

| Nome          | Valor              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

#### parâmetros de rota

#### `id`

**Tipo:** string  
**Obrigatório:** Sim

O id do centro de custo a desativar.

### Exemplo de solicitação

<Tabs groupId="language">
<TabItem value="curl" label="cURL">

```bash
curl -X DELETE "https://api.verifik.co/v2/cost-centers/6acfbdda92451bac5d0a7ebe" \
  -H "Authorization: Bearer $VERIFIK_TOKEN"
```
