### Endpoint

```
GET https://api.verifik.co/v2/face-recognition/persons/lookup
```

Encontra pessoas já armazenadas para o seu cliente por **nome** (obrigatório) e **data de nascimento** opcional. Use quando a criação retornar `412 person_already_set`, ou antes do enroll, para obter o **`_id` da pessoa** e os **`code`** da coleção sem uma busca facial 1:N.

Esta é uma consulta de **metadados Mongo**, não um match de rosto. Os dígitos em `name` são removidos como na criação (`"Maria 123"` vira `"Maria"`). A correspondência é **contains** e não diferencia maiúsculas (`Maria` encontra `Maria Perez Gonzalez`). Use pelo menos 3 caracteres.

Use `collections[].code` (UUID de 36 caracteres) como `collection_id` na busca facial. Não envie o `_id` Mongo da coleção.

### Headers

| Name | Value |
| --- | --- |
| Content-Type | `application/json` |
| Authorization | `Bearer <token>` |

### Params

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Nome parcial ou completo (mínimo 3 caracteres após remover dígitos). Contains, sem diferenciar maiúsculas. |
| `date_of_birth` | string | No | `YYYY-MM-DD`. Se enviado, restringe àquele dia. |
| `page` | number | No | Número da página (padrão: `1`). |
| `limit` | number | No | Tamanho da página (padrão: `20`, máximo: `100`). |

### Notes

- Prefira este helper (ou o objeto `data` de `412 person_already_set`) a uma busca 1:N quando você conhece parte do nome e, opcionalmente, a data de nascimento.
- Só o primeiro nome já basta (`name=Maria`). Adicione `date_of_birth` quando muitas pessoas compartilham esse nome.
- A unicidade de `POST /v2/face-recognition/persons` também é **nome + data de nascimento** em uma coleção, não similaridade facial.
- `collections[].code` é o valor que o OpenCV espera como `collection_id`.
