# 🇨🇱 Chile — Registro de Bloqueio de Carteira de Motorista

Consulte o registro nacional de bloqueio de carteira de motorista do **Servicio de Registro Civil e Identificación** por RUN.

Diferente dos portais municipais que cobrem apenas uma comuna, este endpoint oferece **cobertura nacional** sobre bloqueios e suspensões de habilitação determinadas por tribunais ou autoridades civis em todo o Chile.

### Endpoint

```
GET https://api.verifik.co/v2/cl/driver-license/block
```

### Cabeçalhos

| Nome          | Valor              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parâmetros

| Nome | Tipo | Obrigatório | Descrição | Exemplo |
| --- | ---- | ----------- | --------- | ------- |
| `documentNumber` | string | **Sim** | RUN chileno com dígito verificador (DV). Pontos e traços opcionais (`18.347.440-5` ou `18347440-5`). O dígito verificador deve ser válido. | `18347440-5` |
| `force` | boolean | Não | Booleano opcional ou `1`/`true` para ignorar o cache do servidor e consultar a fonte oficial. | `false` |

## Recursos

- **Registro Nacional**: Dados oficiais do Registro Civil e Identificación do Chile.
- **Status imediato de bloqueio**: Confirmação direta sobre suspensões (`hasBlock: true/false`).
- **Verificação do titular**: Retorna o nome completo registrado na habilitação.
- **Metadados de bloqueio**: Data do processo judicial, tipo e motivo da restrição.
- **Proteção por dígito verificador**: Validação prévia por Módulo 11 evitando consultas incorretas sem descontar créditos.
