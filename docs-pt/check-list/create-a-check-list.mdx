Crie uma Check List no cliente autenticado. `name` é obrigatório. Países, domínios e códigos de feature são opcionais na criação — você pode adicionar serviços depois com [Atualizar uma checklist](/verifik-pt/check-list/update-a-check-list).

Guardar a lista não executa consultas e não gasta créditos. No Smart-Agent, criar leva você de volta ao painel; esta API devolve o documento novo de imediato.

### Endpoint

```
POST https://api.verifik.co/v2/check-lists
```

Cria uma lista do cliente do JWT. O objeto `data` da resposta inclui `_id` — guarde-o para as chamadas GET, PUT e DELETE posteriores. O `status` padrão é `draft`.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

O token deve ser um **JWT de cliente**. Um token sem `clientId` devolve `403`.

### Body

| Name           | Type     | Required | Description                                                                 |
| -------------- | -------- | -------- | --------------------------------------------------------------------------- |
| `name`         | string   | Yes      | Nome visível. Recortado, 1–150 caracteres.                                  |
| `countries`    | string[] | No       | Nomes dos países onde você opera (por exemplo `Colombia`). Duplicados são removidos. Padrão `[]`. |
| `domains`      | string[] | No       | Abas opcionais: `people`, `vehicles`, `businesses`. Padrão `[]`.            |
| `featureCodes` | string[] | No       | Valores `code` de AppFeature a guardar na lista. Padrão `[]`.               |
| `status`       | string   | No       | `draft` (padrão) ou `active`. Só rótulo de organização — as duas funcionam igual. |

`featureCodes` desconhecidos falham. Um serviço cujo país não coincide com `countries` falha, salvo se o serviço for mundial ou `countries` estiver vazio.

### Notes

- `name` é o único campo obrigatório. Você pode criar uma lista vazia e adicionar `featureCodes` depois.
- Os países são guardados como você os envia (por exemplo `Colombia`). Não são códigos ISO.
- `status` não altera o comportamento do servidor. Listas em rascunho e ativas funcionam igual.
- Valores de `domains` desconhecidos falham na validação. Valores permitidos: `people`, `vehicles`, `businesses`.
- Criar uma lista não gasta créditos. Executar um serviço guardado é uma chamada normal ao catálogo.
- Não existe um endpoint para executar a checklist. Veja [Check List](/verifik-pt/check-list) e [SmartBatch](/verifik-pt/smart-batch).
