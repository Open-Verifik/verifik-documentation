Apague uma Check List sua. A API devolve o documento apagado em `{ data }`. Um ObjectId inválido, uma lista inexistente ou uma lista de outro cliente devolve `404`.

Apagar não executa consultas e não gasta créditos. O histórico do catálogo e os trabalhos SmartBatch que usaram os mesmos códigos de feature não são removidos.

### Endpoint

```
DELETE https://api.verifik.co/v2/check-lists/{id}
```

Remove a lista da coleção do cliente e devolve o documento que foi apagado. Depois desta chamada, GET / PUT / DELETE no mesmo id devolvem `404`.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

O token deve ser um **JWT de cliente**. Um token sem `clientId` devolve `403`.

### Parameters

| Name | Type   | Required | Description                          |
| ---- | ------ | -------- | ------------------------------------ |
| `id` | string | Yes      | ObjectId da Check List da criação ou da listagem. |

### Notes

- O corpo `200` é o documento apagado, não um objeto vazio.
- ObjectIds inválidos e listas de outros clientes devolvem `404` (`check_list_not_found`).
- Apagar não gasta créditos e não cancela trabalhos do catálogo ou do SmartBatch.
- Não existe um endpoint para executar a checklist. Veja [Check List](/verifik-pt/check-list) e [SmartBatch](/verifik-pt/smart-batch).
