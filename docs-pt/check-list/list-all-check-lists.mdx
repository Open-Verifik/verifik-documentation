Liste as Check Lists guardadas no cliente autenticado. Os resultados pertencem a esse cliente e são ordenados por `updatedAt` descendente (as mais recentes primeiro). Esta chamada não executa consultas e não gasta créditos.

Use `search` (ou `text`) para filtrar por nome. Envie `page` quando quiser metadados de paginação. Omita `page` para receber o array correspondente em `data` sem os campos `total` / `pages`.

### Endpoint

```
GET https://api.verifik.co/v2/check-lists
```

Devolve as listas guardadas do cliente. Cada item inclui `name`, `countries`, `domains`, `featureCodes` e `status`. Quando `page` está presente, a resposta também inclui `total`, `limit`, `page` e `pages`.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

O token deve ser um **JWT de cliente**. Um token sem `clientId` devolve `403`.

### Parameters

| Name      | Type    | Required | Description                                                                 |
| --------- | ------- | -------- | --------------------------------------------------------------------------- |
| `page`    | integer | No       | Quando enviado, a API pagina e devolve `total`, `limit`, `page` e `pages`. Omita-o para receber só o array correspondente. |
| `perPage` | integer | No       | Tamanho da página. Alias de `limit`. Aplica-se mesmo quando `page` é omitido. |
| `limit`   | integer | No       | Tamanho da página. Alias de `perPage`.                                      |
| `search`  | string  | No       | Filtro de nome sem distinguir maiúsculas.                                   |
| `text`    | string  | No       | Alias de `search`.                                                          |

### Notes

- As listas pertencem ao cliente do JWT. Você não pode ler as listas de outro cliente.
- A ordenação é sempre pelo `updatedAt` mais recente primeiro.
- `search` e `text` fazem o mesmo filtro de nome sem distinguir maiúsculas.
- `perPage` e `limit` são aliases. Se você enviar `limit` sem `page`, o array ainda é limitado.
- Este endpoint não gasta créditos e não executa os serviços guardados.
- Percurso de produto: [Check List](/verifik-pt/check-list). Criar: [Criar uma checklist](/verifik-pt/check-list/create-a-check-list).
