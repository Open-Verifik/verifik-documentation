Atualize uma Check List sua. Envie só os campos que quer alterar. Os campos omitidos mantêm os valores atuais. O documento resultante é revalidado, por isso `name` ainda deve estar presente depois da fusão.

Guardar as alterações não executa consultas e não gasta créditos. No Smart-Agent, os países ficam bloqueados depois da criação — esta API ainda aceita um novo array `countries` se você o enviar.

### Endpoint

```
PUT https://api.verifik.co/v2/check-lists/{id}
```

Devolve a lista atualizada. Use isto quando o utilizador adicionar ou remover serviços (`featureCodes`), alterar o nome ou definir `status`. Ids inválidos e listas de outros clientes devolvem `404`.

### Headers

| Name          | Value              |
| ------------- | ------------------ |
| Content-Type  | `application/json` |
| Authorization | `Bearer <token>`   |

O token deve ser um **JWT de cliente**. Um token sem `clientId` devolve `403`.

### Parameters

| Name | Type   | Required | Description                          |
| ---- | ------ | -------- | ------------------------------------ |
| `id` | string | Yes      | ObjectId da Check List da criação ou da listagem. |

### Body

Todos os campos são opcionais no pedido. Depois da fusão, `name` continua obrigatório.

| Name           | Type     | Required | Description                                                                 |
| -------------- | -------- | -------- | --------------------------------------------------------------------------- |
| `name`         | string   | No       | Nome visível. Recortado, 1–150 caracteres.                                  |
| `countries`    | string[] | No       | Nomes dos países. Substitui a lista guardada quando enviado.                |
| `domains`      | string[] | No       | `people`, `vehicles` e/ou `businesses`. Substitui a lista guardada quando enviado. |
| `featureCodes` | string[] | No       | Valores `code` de AppFeature. Substitui a lista guardada quando enviado.    |
| `status`       | string   | No       | `draft` ou `active`. Só rótulo de organização.                              |

`featureCodes` desconhecidos falham. Um serviço cujo país não coincide com o `countries` resultante falha, salvo se o serviço for mundial ou `countries` estiver vazio.

### Notes

- Os campos omitidos mantêm os valores atuais. Enviar `featureCodes` substitui o array inteiro — não é uma fusão parcial dos códigos.
- Depois da fusão, o Joi ainda exige `name`. Limpar o nome falha com `ValidationError`.
- `featureCodes` desconhecidos devolvem `409` (`check_list_invalid_feature`).
- Uma feature cujo país está fora do `countries` resultante devolve `409` (`check_list_feature_country_mismatch`), salvo se a feature for mundial ou `countries` estiver vazio.
- As atualizações não gastam créditos. Executar um código guardado é uma chamada ao catálogo. O SmartBatch é um produto separado.
- Percurso de produto: [Check List](/verifik-pt/check-list).
