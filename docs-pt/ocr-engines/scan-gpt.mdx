# Scan Agent

**Scan Agent** extrai campos estruturados da imagem de um documento. Chame **POST** `https://api.verifik.co/v2/ocr/scan-gpt`. `image` é obrigatória. `documentType`, `backImage` e `template` são opcionais. Este corpo não tem um campo `country`. A extração gravada põe `validationMethod` em `SCAN_AGENT`.

## O que a chamada devolve

- `documentType`, `documentNumber` e nome extraídos
- `validationMethod` — `SCAN_AGENT`

## Casos de uso

- Leia um documento de identidade a partir de uma imagem.
- Acrescente a imagem do verso se o cartão tiver o outro lado.
- Fixe um modelo se o layout for conhecido.

---

## Referência da API

### Endpoint

```http
POST https://api.verifik.co/v2/ocr/scan-gpt
```

Um acerto inclui os campos extraídos e `validationMethod` `SCAN_AGENT`. A URL continua `/v2/ocr/scan-gpt`.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `image` | string | **Sim** | `data:image/jpeg;base64,AAAA` | Imagem da frente em base64 ou data URI. Obrigatória. |
| `documentType` | string | Não | `CC` | Família de documento opcional, como `CC` ou `DNI`. |
| `backImage` | string | Não | `data:image/jpeg;base64,BBBB` | Imagem do verso opcional. |
| `template` | string | Não | `template_id` | Id de modelo opcional. |

### Notas

- `image` é obrigatória. `documentType`, `backImage` e `template` são opcionais.
- Não envie um campo de país. Este corpo não o aceita.
- O método gravado é `SCAN_AGENT` e a URL continua `/v2/ocr/scan-gpt`.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `image` plus `documentType: "CC"` | 200 com campos extraídos e validationMethod SCAN_AGENT. |
| Valor obrigatório ausente | Omit `image` | 409 MissingParameter. |
| Valor desconhecido | `image` and `backImage` | 200 se a imagem do verso também for enviada. |

401 when the bearer token is missing or rejected.
