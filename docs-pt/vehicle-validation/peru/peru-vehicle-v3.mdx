# Peru — Informações de Veículo (v3)

### Endpoint

```
GET https://api.verifik.co/v3/pe/vehiculo/placa
```

O serviço v3 de Informações de Veículos do Peru retorna os dados cadastrais do veículo por **`plate`**, além da ficha técnica `technicalSheet` (`engine`, `performance` e `dimensions`, incluindo comprimento, largura, altura, entre-eixos, peso, tanque, portas e ocupantes) quando disponível.

### Cabeçalhos (Headers)

| Nome          | Valor              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parâmetros

| Nome    | Tipo   | Obrigatório | Descrição                                                     | Exemplo  |
| ------- | ------ | ----------- | ------------------------------------------------------------- | -------- |
| `plate` | string | **Sim**     | Número da placa a consultar, sem espaços ou pontos.           | `ABC123` |

### Requisição (Request)

<Tabs>
<TabItem value="javascript" label="JavaScript">

```javascript
import axios from 'axios';

const { data } = await axios.get('https://api.verifik.co/v3/pe/vehiculo/placa', {
  params: { plate: 'ABC123' },
  headers: { Accept: 'application/json', Authorization: 'Bearer <seu_token>' },
});
console.log(data);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import http.client

conn = http.client.HTTPSConnection("api.verifik.co")
headers = {"Accept": "application/json", "Authorization": "Bearer <seu_token>"}
conn.request("GET", "/v3/pe/vehiculo/placa?plate=ABC123", headers=headers)
print(conn.getresponse().read().decode("utf-8"))
```

</TabItem>
</Tabs>

### Notas

- `technicalSheet` (incluindo `dimensions`: `length`, `width`, `height`, `wheelbase`, `curbWeight`, `fuelTank`, `doors` e `occupants`) pode retornar `null` ou parcial caso não haja ficha técnica correspondente.
- Em **modo sandbox**, placas `ABC10001`–`ABC10010` retornam perfis estáveis de exemplo.
