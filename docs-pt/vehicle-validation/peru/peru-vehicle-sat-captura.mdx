# Peru - Ordem de captura veicular (SAT Lima)

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/captura-lima
```

Consulte no SAT de Lima se uma **`placa`** tem ordem de captura na província de Lima. Uma placa sem ordem é uma resposta bem-sucedida: `hasCaptureOrder` é `false` e `orders` fica vazio. Quando há ordem, `message` traz o texto oficial do SAT e cada item de `orders` inclui `concept`, `amount` em soles, `period` e `documentNumber`. `status` só é preenchido quando o SAT o envia. `columns` conserva os rótulos originais da fonte quando o formulário público os traz.

### Cabeçalhos

| Nome          | Valor              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parâmetros

| Nome    | Tipo   | Obrigatório | Descrição                                                                 | Exemplo  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | Sim      | Placa do veículo, de 5 a 8 letras ou dígitos, sem espaços. `F1E120` tem ordem. `V0R660` não.  | `F1E120` |
| `force` | boolean | Não      | Opcional. Envie `true` ou `1` para ignorar o resultado armazenado e consultar o SAT novamente.  | `true` |

### Notas

- A consulta cobre apenas a província de Lima.
- Envie `plate` sem espaços nem hífens (de 5 a 8 caracteres alfanuméricos).
- Uma placa sem ordem de captura ainda retorna **HTTP 200**. O **404** é apenas para uma placa que não tenha de 5 a 8 letras ou dígitos.
- `amount` é formatado em soles (`S/ 505.86`). `status` fica vazio quando o SAT não envia um estado.
- `F1E120` tem ordem de captura. `V0R660` não.
- Quando o SAT não pode ser consultado, a API retorna **409** com `Endpoint_out_of_service`.
- No **modo sandbox**, `ABC10001` tem ordem de captura e `ABC10002` não.
