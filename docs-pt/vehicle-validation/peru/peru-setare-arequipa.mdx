# Peru — Permissão de Táxi SETARE Arequipa

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/setare-arequipa
```

Valida se um veículo possui autorização **SETARE** de táxi em Arequipa (Peru) a partir da placa (**`plate`**), retornando `hasActivePermit`, `latestPermit` e `permits` dos registros municipais oficiais.

### Cabeçalhos (Headers)

| Nome          | Valor              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parâmetros

| Nome    | Tipo   | Obrigatório | Descrição                                                                    | Exemplo  |
| ------- | ------ | ----------- | ---------------------------------------------------------------------------- | -------- |
| `plate` | string | **Sim**     | Número da placa a consultar (6 caracteres alfanuméricos, ex. `V3D236`).      | `V3D236` |

### Requisição (Request)

<Tabs>
<TabItem value="javascript" label="JavaScript">

```javascript
import axios from 'axios';

const { data } = await axios.get('https://api.verifik.co/v2/pe/vehiculo/setare-arequipa', {
  params: { plate: 'V3D236' },
  headers: { Accept: 'application/json', Authorization: 'Bearer <seu_token>' },
});
console.log(data);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import http.client

conn = http.client.HTTPSConnection("api.verifik.co")

conn.request("GET", "/v2/pe/vehiculo/setare-arequipa?plate=V3D236", headers=headers)
```

### Notas

- Envie `plate` sem espaços ou hifens (6 caracteres alfanuméricos).
- Em **modo sandbox**, `ABC10001` retorna uma permissão ativa (`Vigente`) e `ABC10002` retorna uma permissão vencida (`Vencido`).
