# Peru - Certificado de inspeção técnica veicular (CITV)

### Endpoint

```
GET https://api.verifik.co/v2/pe/vehiculo/inspeccion-tecnica
```

Consulte os certificados de inspeção técnica veicular (**CITV**) registrados no Ministério de Transportes do Peru (**MTC**) para uma **`placa`**. A resposta indica se um certificado foi encontrado (`found`), se algum está vigente (`hasValidCertificate`), o certificado mais recente (`latestCertificate`) e todos os certificados devolvidos pela fonte (`certificates`).

### Cabeçalhos

| Nome          | Valor              |
| ------------- | ------------------ |
| Accept        | `application/json` |
| Authorization | `Bearer <token>`   |

### Parâmetros

| Nome    | Tipo   | Obrigatório | Descrição                                                                 | Exemplo  |
| ------- | ------ | -------- | --------------------------------------------------------------------------- | -------- |
| `plate` | string | Sim      | Placa do veículo, de 5 a 8 letras ou dígitos, sem espaços. Exemplo: `V0R660`.  | `V0R660` |
| `force` | boolean | Não      | Opcional. Envie `true` ou `1` para ignorar o resultado armazenado e consultar o MTC novamente.  | `true` |

### Notas

- Envie `plate` sem espaços nem hífens (de 5 a 8 caracteres alfanuméricos).
- `hasValidCertificate` é `true` quando pelo menos um certificado tem estado `VIGENTE`.
- `latestCertificate` é o primeiro certificado devolvido pelo MTC. `certificates` lista todos os registros dessa placa. `V0R660` tem hoje dois certificados vigentes.
- Uma placa sem certificado, ou uma placa que não tenha de 5 a 8 letras ou dígitos, retorna **404**.
- Quando a fonte do MTC está indisponível, a API retorna **409** com `Endpoint_out_of_service`.
- No **modo sandbox**, `ABC10001` retorna um certificado vigente (`VIGENTE`) e `ABC10002` um certificado vencido (`VENCIDO`).
