Consulte os dados básicos de um veículo colombiano e seus registros de propriedade usando somente a placa. O serviço é indicado para verificar titularidade, integrar veículos e realizar diligência prévia.

### Endpoint

```
GET https://api.verifik.co/v2/co/runt/vehiculo/owners
```

A resposta inclui `plate`, `brand`, `line`, `model` e um array `owners` com identidade, período de propriedade, financiamento, gravame e registro quando disponíveis. Diferentemente de **`GET /v2/co/runt/propietarios`**, este endpoint começa pela placa e retorna dados normalizados do veículo e dos proprietários.

### Cabeçalhos

| Nome | Valor |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parâmetros

| Nome | Tipo | Obrigatório | Descrição | Exemplo |
| --- | --- | --- | --- | --- |
| `plate` | string | Sim | Placa colombiana com 5 a 9 caracteres alfanuméricos. | `CRL299` |

### Requisição

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
import axios from "axios";

const { data } = await axios.get("https://api.verifik.co/v2/co/runt/vehiculo/owners", {
	params: { plate: "CRL299" },
	headers: {
		Accept: "application/json",
		Authorization: `Bearer ${process.env.VERIFIK_TOKEN}`,
	},
});
console.log(data);
```

### Observações

- O código AppFeature é **`colombia_api_vehicle_owners`**.
- Use **`CRL299`** no sandbox.
- Os campos do proprietário podem ser `null`, e `owners` pode conter vários registros históricos.
- **`GET /v2/co/runt/propietarios`** tem outro fluxo de consulta; não é um alias deste endpoint baseado em placa.
