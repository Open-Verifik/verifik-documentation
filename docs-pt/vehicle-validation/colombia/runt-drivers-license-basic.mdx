### Endpoint

```
GET https://api.verifik.co/v3/co/runt/conductor
```

Mesma consulta RUNT que [Premium v2](/vehicle-validation/colombia/runt-drivers-license), na **tarifa atual de condutor**. `primerApellido` é **obrigatório**. Sem o campo: `409 MissingParameter`.

### Parâmetros

| Nome | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `documentType` | string | Sim | **`CC`**, **`CE`**, **`PA`**, **`PPT`**. |
| `documentNumber` | string | Sim | Número sem espaços. |
| `primerApellido` | string | **Sim** | Primeiro sobrenome (mín. 2). |

### Requisição

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
const { data } = await axios.get("https://api.verifik.co/v3/co/runt/conductor", {
	params: { documentType: "CC", documentNumber: "123456789", primerApellido: "GARCIA" },
	headers: { Accept: "application/json", Authorization: `Bearer ${process.env.VERIFIK_TOKEN}` },
});
```
