# SIBGA - Avaliação comercial do veículo

Devolve o valor comercial oficial do **Ministerio de Transporte (SIBGA)** para um veículo colombiano. A Verifik consulta a placa no **RUNT** e homologa marca, linha, classe, combustível e cilindrada com o catálogo SIBGA. Não é preciso manter uma tabela de equivalências.

Envie só a placa, ou a placa com o documento do proprietário. Com documento, o RUNT é consultado por placa e proprietário, como em [Veículo por placa (completo)](/verifik-pt/vehicle-validation/colombia/runt-vehicle-by-plate). Sem documento, a consulta segue [Veículo somente pela placa](/verifik-pt/vehicle-validation/colombia/runt-vehicle-by-plate-only).

Use para subscrição de seguros, crédito e avaliação de frotas quando a base tributável tiver de vir do SIBGA.

## O que esta API devolve

- **`valuation`** — valor comercial em **COP** para o ano-modelo. `null` quando o SIBGA não avalia esse ano (veículos mais novos que o período são avaliados pela fatura)
- **`valuesByModel`** — valor comercial de cerca de **25** anos-modelo, até o ano anterior ao período
- **`matched`** — tipo, classe, marca, linha, cilindrada SIBGA e o **`avalId`** do certificado
- **`confidence`** — força da homologação da linha, da marca e da classe (`exact`, `high`, `medium`, `low` ou `none`)
- **`needsReview`** / **`reviewReason`** — quando a homologação é fraca, o SIBGA rejeitou a busca, nenhuma linha correspondeu ou o ano-modelo não está avaliado
- **`alternatives`** — outras linhas do catálogo consideradas, com pontuação
- **`certificateUrl`** — PDF oficial do SIBGA quando há valor
- **`runtSource`** — marca, linha, modelo, classe e cilindrada do RUNT usados na homologação
- Uma resposta **assinada** pela Verifik

## Referência da API

### Endpoint

```
GET https://api.verifik.co/v2/co/sibga/valuation
```

Envie **`plate`** como parâmetro de consulta. **`documentType`** e **`documentNumber`** são opcionais e devem ser enviados juntos. **`period`** é o ano tributável, de **2016** até o ano corrente, e assume o ano corrente se for omitido. A resposta inclui o valor comercial, a tabela por ano-modelo, o registro SIBGA homologado e um sinal de revisão quando uma pessoa deve confirmar o resultado.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `plate` | string | Sim | Placa colombiana, **5–9** caracteres alfanuméricos. | `CUT984` |
| `documentType` | string | Não | Tipo de documento do proprietário. Um de **`CC`**, **`CE`**, **`PA`**, **`NIT`**. Obrigatório junto com `documentNumber`. | `CC` |
| `documentNumber` | string | Não | Número do documento do proprietário, sem espaços nem pontuação. Obrigatório junto com `documentType`. | `63535790` |
| `period` | number | Não | Ano tributável, de **2016** até o ano corrente. Se omitido, usa-se o ano corrente. | `2026` |

### Notes

- O código do AppFeature é **`colombia_api_vehicle_valuation_sibga`**.
- Um corpo com **`valuation: null`** continua sendo **HTTP 200**. Leia **`reviewReason`**: `model_not_valued_in_period`, `low_confidence_match`, `no_matching_line` ou `sibga_search_rejected`.
- **`documentType`** e **`documentNumber`** devem ser enviados juntos, ou ambos omitidos.
- Classes não suportadas, como um semirreboque, devolvem **404**.
- No sandbox, as placas **`AA123BA`–`AA123BF`**, **`AA123BH`** e **`AA123BI`** devolvem veículos distintos com valor. **`AA123BG`** devolve **200** com `reviewReason: model_not_valued_in_period`. **`AA123BJ`** e **`ERR40401`** devolvem **404**. O documento **`90040401`** devolve **404** e **`90050001`** devolve **500**.
- Consultas RUNT relacionadas: [veículo por placa](/verifik-pt/vehicle-validation/colombia/runt-vehicle-by-plate) e [veículo somente pela placa](/verifik-pt/vehicle-validation/colombia/runt-vehicle-by-plate-only).
