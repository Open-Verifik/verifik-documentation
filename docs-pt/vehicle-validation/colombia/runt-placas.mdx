# RUNT — Veículo somente pela placa

Consulte informações oficiais de um veículo no RUNT usando **somente** a placa. Diferente de [Veículo por placa (completo)](/verifik-pt/vehicle-validation/colombia/runt-vehicle-by-plate), este endpoint **não exige** `documentType` nem `documentNumber` do titular.

Use-o quando precisar dos blocos de identidade, técnicos e de status de uma placa colombiana sem o documento do proprietário.

## O que a API retorna

- **`informacionGeneral`** — placa, marca, linha, modelo, classe, serviço, status e campos de registro quando presentes
- **`datosTecnicos`** — campos técnicos quando presentes
- Blocos temporais como **`soat[]`** e **`tecnoMecanica[]`** quando presentes
- Outros blocos RUNT (`solicitudes`, `polizasResponsabilidadCivil` e semelhantes) quando a resposta os inclui
- **`documentType`** e **`documentNumber`** podem ser `null`
- Resposta **assinada** pela Verifik

## Referência da API

### Endpoint

```
GET https://api.verifik.co/v2/co/runt/placas
```

Envie **`plate`** como **parâmetro de consulta**. O handler devolve a forma completa do veículo RUNT. As seções de identidade, técnicas e de status entram quando disponíveis. Os campos de documento do titular não são obrigatórios e podem voltar como `null`.

### Cabeçalhos

| Nome | Valor |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parâmetros

| Nome | Tipo | Obrigatório | Descrição | Exemplo |
| --- | --- | --- | --- | --- |
| `plate` | string | Sim | Placa colombiana com **5 a 9** caracteres alfanuméricos. | `AA123BA` |

### Notas

- O código AppFeature é **`colombia_api_runt_placas`**.
- Esta rota é a irmã somente-placa de [GET `/v2/co/runt/vehicle-by-plate`](/verifik-pt/vehicle-validation/colombia/runt-vehicle-by-plate). Ela não aceita `documentType` nem `documentNumber` do titular.
- `documentType` e `documentNumber` no payload podem ser `null`.
- Os blocos de identidade, técnicos e de status voltam quando existem; arrays ou objetos vazios significam que a seção não tinha linhas.
- No sandbox, **`AA123BA`** e **`ABC10001`–`ABC10010`** devolvem 200 estáveis. **`ERR40401`** devolve **404** `NotFound`.
- **409** é usado para erros de validação e quando o serviço está temporariamente indisponível.
