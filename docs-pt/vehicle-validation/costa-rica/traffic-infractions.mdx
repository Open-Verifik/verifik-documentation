# Costa Rica — Infrações de trânsito

A consulta de **infrações de trânsito da Costa Rica** lê multas COSEVI de uma placa. `plate` é obrigatória e deve ter de 3 a 6 caracteres. Uma falha de validação responde HTTP 409 com o código `409:invalid_params`, não `MissingParameter`. Uma placa sem multas é 404 `NotFound`.

## O que a chamada devolve

- `plate` e `totalRecords`
- `infractions[]` com estado e valores

## Casos de uso

- Revise multas antes de registrar um veículo.
- Rejeite uma placa que não tenha de 3 a 6 caracteres.
- Leia o valor total de cada multa.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/cr/traffic-infractions
```

Um acerto inclui `plate`, `totalRecords` e `infractions` com série, número, data, estado, autoridade e valores.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **Sim** | `123456` | Placa, de 3 a 6 caracteres, sem espaços. Uma placa ausente ou com tamanho errado responde com o código `409:invalid_params`. |

### Notas

- `plate` deve ter de 3 a 6 caracteres.
- Placas inválidas respondem com o código `409:invalid_params`.
- Sem multas para essa placa é 404 `NotFound`.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `plate: "123456"` | 200 com infrações. |
| Valor obrigatório ausente | Omit `plate` | 409 com o código `409:invalid_params`. |
| Valor desconhecido | `plate: "ABC"` | 404 NotFound se o COSEVI não tiver multa. |

401 when the bearer token is missing or rejected.
