# Equador — Veículo por placa (v3)

A consulta de **veículo v3 do Equador** é `GET /v3/ec/vehiculo/placa`. `plate` é obrigatória. O corpo inclui campos de identificação (`vin`, `brand`, `model`, `year`, `color` e dados da placa), um objeto `revision` com datas de inspeção e um `technicalSheet` com motor, desempenho e dimensões.

## O que a chamada devolve

- Identificação: `vin`, `brand`, `model`, `year`, `color`
- `revision` com inspeções
- `technicalSheet.engine`, `performance` e `dimensions`

## Casos de uso

- Confirme um veículo antes do seguro.
- Leia o último ano de inspeção.
- Guarde o VIN com a placa.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v3/ec/vehiculo/placa
```

Espere `plate`, campos de identificação, `revision` e `technicalSheet`. Uma placa desconhecida é 404 `NotFound`.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `plate` | string | **Sim** | `ABC1234` | Placa equatoriana. Obrigatória. |

### Notas

- O caminho é versão 3: `/v3/ec/vehiculo/placa`.
- `plate` é o único parâmetro obrigatório.
- Uma placa desconhecida é 404 `NotFound`.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `plate: "ABC1234"` | 200 com identificação, revision e technicalSheet. |
| Valor obrigatório ausente | Omit `plate` | 409 MissingParameter. |
| Valor desconhecido | `plate: "ZZZ0000"` | 404 NotFound se a placa for desconhecida. |

401 when the bearer token is missing or rejected.
