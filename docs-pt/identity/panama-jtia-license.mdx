# Panamá — Licença de engenharia e arquitetura (JTIA)

A consulta de **licença JTIA** lê a idoneidade de engenheiros, arquitetos e técnicos. Envie `documentNumber` (ou `cedula`), `licenseNumber` (ou `idoneidad`) ou `fullName`. Uma cédula que não se normaliza responde 409. Sem linha na junta é 404 `NotFound`.

## O que a chamada devolve

- Cédula normalizada
- `licenseNumber` e `fullName`
- `status`

## Casos de uso

- Verifique um engenheiro antes de um alvará.
- Busque por cédula se não tiver a licença.
- Busque por nome se só tiver o contrato.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/pa/professional/jtia
```

Um acerto inclui a cédula normalizada, o nome, a licença e o estado.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `8-224-2444` | Cédula panamenha, também como `cedula`. A API a normaliza (por exemplo `8-224-2444`). |
| `licenseNumber` | string | **Condicional** | `JTIA-100` | Idoneidade ou licença. Alias: `idoneidad`. |
| `fullName` | string | **Condicional** | `ANA RUIZ` | Nome, de 3 a 160 caracteres. Basta sozinho. |

### Notas

- Envie uma cédula, uma licença ou um nome.
- Uma cédula com forma inválida é 409.
- Sem linha JTIA é 404 `NotFound`.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `documentNumber: "8-224-2444"` | 200 com a cédula normalizada e a licença. |
| Valor obrigatório ausente | Omit cédula, license, and name | 409 MissingParameter. |
| Valor desconhecido | `documentNumber: "1-1-1"` | 409 se a cédula não se normalizar, ou 404 se a JTIA não tiver linha. |

401 when the bearer token is missing or rejected.
