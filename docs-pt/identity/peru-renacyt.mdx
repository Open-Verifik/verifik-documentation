# Peru — Graus SUNEDU e RENACYT do CONCYTEC

A consulta **RENACYT** lê graus SUNEDU e o registro de pesquisadores do CONCYTEC. Envie pelo menos um de `documentNumber` (alias `dni`), `codigoRegistro`, `orcid` ou `fullName`. Se enviar um número, `documentType` padrão é `DNI`.

## O que a chamada devolve

- Campos de grau e pesquisador
- `codigoRegistro` e `orcid` se existirem
- `fullName` e `documentNumber`

## Casos de uso

- Confirme um pesquisador antes de uma bolsa.
- Cruze um ORCID com um DNI.
- Leia o código RENACYT para um dossiê de contratação.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/pe/education/renacyt
```

Um acerto pode incluir o grau, o código RENACYT e o ORCID. Sem linha é 404 `NotFound`.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `12345678` | DNI ou outro número. Alias: `dni`. `documentType` padrão é `DNI`. Também `CE`, `PASAPORTE`, `PTP`. |
| `codigoRegistro` | string | **Condicional** | `REN-100` | Código de registro RENACYT. Basta sozinho. |
| `orcid` | string | **Condicional** | `0000-0002-1825-0097` | ORCID, de 10 a 30 caracteres. Basta sozinho. |
| `fullName` | string | **Condicional** | `LUCIA QUISPE` | Nome do pesquisador. Basta sozinho. |

### Notas

- Envie um documento, um código RENACYT, um ORCID ou um nome.
- Números de documento usam por padrão o tipo `DNI`.
- Sem linha no registro é 404 `NotFound`.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `documentType: "DNI"`, `documentNumber: "12345678"` | 200 com campos de grau ou pesquisador. |
| Valor obrigatório ausente | Omit every search value | 409 MissingParameter. |
| Valor desconhecido | `documentNumber: "00000000"` | 404 NotFound se nem SUNEDU nem RENACYT tiverem linha. |

401 when the bearer token is missing or rejected.
