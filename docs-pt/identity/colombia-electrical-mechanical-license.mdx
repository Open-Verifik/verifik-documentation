# Colômbia — Matrícula de engenharia elétrica e mecânica

A consulta de **matrícula de engenharia elétrica e mecânica** lê o Consejo Profesional Nacional de Ingenierías Eléctrica, Mecánica y Profesiones Afines. Envie `documentNumber`, `licenseNumber` ou `fullName`. A resposta inclui a licença, a especialidade, o estado e se o conselho reporta sanções.

## O que a chamada devolve

- `licenseNumber` e `specialty`
- `status`, por exemplo VIGENTE
- `isRegistered` e `hasSanctions`
- `registrations` se a pessoa tiver mais de uma linha

## Casos de uso

- Confirme um engenheiro elétrico ou mecânico antes da obra.
- Leia sanções disciplinares junto da licença.
- Cruze o nome do contrato com a linha do conselho.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/co/consejo-profesional
```

Uma correspondência inclui `fullName`, `licenseNumber`, `specialty`, `status`, `isRegistered` e `hasSanctions`. Se o conselho não tiver linha, a API responde 404 `NotFound`.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `80123456` | Número de identidade colombiano, de 5 a 15 caracteres. `documentType` pode ser `CC`, `CE`, `TI`, `PEP` ou `PPT`. |
| `licenseNumber` | string | **Condicional** | `AN205-27910` | Matrícula profissional, por exemplo AN205-27910. Basta sozinha. |
| `fullName` | string | **Condicional** | `ANA PEREZ` | Nome ou sobrenomes do engenheiro, de 3 a 160 caracteres. Basta sozinho. |

### Notas

- Envie pelo menos um de `documentNumber`, `licenseNumber` ou `fullName`.
- Uma linha ausente no conselho é HTTP 404, não um 200 vazio.
- `documentType` é opcional.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.
