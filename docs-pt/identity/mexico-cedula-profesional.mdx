# México — Licença profissional

Confirma que uma pessoa possui uma licença profissional (cédula profissional) no registro oficial de profissionais. Trata-se de verificação de credencial, não de prova de identidade.

Envie **um documento** ou **um nome**:

- **CURP** (recomendado). O registro é consultado primeiro pelas licenças vinculadas a esse CURP.
- **Número da licença.** Correspondência exata do número da cédula.
- **Nome.** Correspondência exata, sem diferenciar acentos, dos nomes próprios mais os dois sobrenomes.

Uma pessoa pode ter várias licenças, por isso `cedulas` é um array. Para o registro civil do titular do CURP, consulte [Cidadão mexicano (CURP)](/verifik-pt/identity/mexico). Para uma credencial de eleitor, consulte [Validação INE](/verifik-pt/identity/mexico-ine). Para licenças apenas da área da saúde, consulte [Licença de profissional de saúde](/verifik-pt/identity/mexico-health-worker).

## API reference

### Endpoint

```
https://api.verifik.co/v2/mx/cedula-profesional
```

Uma correspondência retorna `fullName`, `matchMethod`, `ambiguous` e `cedulas[]` com `licenseNumber`, `title`, `profession`, `institution` e `registrationYear`.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

Envie `documentType` + `documentNumber`, ou `firstName` + `lastName`. Não misture os dois modos.

| Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `documentType` | string | Modo documento | `CURP` ou `CEDULA` (sem diferenciar maiúsculas). | `CURP` |
| `documentNumber` | string | Com `documentType` | Um CURP de 17–18 caracteres (convertido automaticamente para maiúsculas) ou um número de licença. | `LOPE900501HDFGRN01` |
| `firstName` | string | Modo nome | Nomes próprios. 2–80 caracteres. | `ANA` |
| `lastName` | string | Modo nome | Os dois sobrenomes, o paterno primeiro. 2–80 caracteres. | `LOPEZ RUIZ` |

### How matching works

- **CURP.** As licenças vinculadas a esse CURP são retornadas primeiro (`matchMethod: "curp"`). Se nenhuma estiver vinculada diretamente, a Verifik resolve o nome oficial do titular do CURP e busca uma correspondência exata do nome completo. Essa etapa não tem custo adicional (`matchMethod: "curp_to_name"`, com `matchNote`). Prevalecem as linhas que trazem o mesmo CURP. Caso contrário, são retornadas as linhas sem CURP que correspondem ao nome exato.
- **`ambiguous: true`** significa que essas linhas pertencem a mais de um grupo de instituição e ano de registro, então um homônimo é possível. Revise as linhas ou solicite o número da licença.
- **CEDULA.** Correspondência exata do número da licença (`matchMethod: "license"`).
- **Nome.** Correspondência exata do nome completo, sem diferenciar acentos nem maiúsculas (`matchMethod: "name"`). `ambiguous` usa a mesma regra de instituição e ano. Prefira o CURP.

### Notes

- Um CURP válido cujo titular não tem licença retorna **404**, inclusive no sandbox. Um array `cedulas` vazio não é uma resposta de sucesso.
- `ambiguous: true` significa que as linhas abrangem mais de uma instituição e ano de registro. Revise-as ou consulte o número da licença.
- Os resultados ficam em cache por até 7 dias, então uma consulta repetida é rápida.
- Persona de sandbox `ANA LOPEZ RUIZ`. Qualquer CURP, exceto os gatilhos abaixo, retorna uma correspondência direta com duas licenças.
- Um CURP que contém `000003` (por exemplo `LOPE000003MDFRRN03`) retorna `matchMethod: "curp_to_name"` e `cedulas[].curp: null`.
- Um CURP que contém `000002` (por exemplo `LOPE000002MDFRRN02`) retorna **404** (CURP válido, sem licença).
- O CURP `LOPE900404HDFNTF01`, a licença `90040401` ou `lastName=NOTFOUND` retornam **404**.
- `documentType=CEDULA` e `documentNumber=10000001` retornam uma licença de direito. `firstName=ANA` e `lastName=AMBIGUA` retornam `ambiguous: true`.
- Um CURP com menos de 17 ou mais de 18 caracteres, ou um `documentType` inválido, retorna **409** `MissingParameter`.
- Quando o registro não puder ser consultado, a resposta é **409** `Endpoint_out_of_service`. Tente novamente mais tarde.
