# Colômbia — Matrícula de engenharia química (CPIQ)

A consulta de **licença CPIQ** lê o Consejo Profesional de Ingeniería Química. Envie `documentNumber` ou `licenseNumber`. O módulo não busca por nome: só `fullName` responde HTTP 409 com `MissingParameter` e a mensagem `Either documentNumber or licenseNumber must be provided`. Um acerto inclui licença, resolução, estado e sanções.

## O que a chamada devolve

- `licenseNumber` e `resolutionNumber`
- `status` e `isActive`
- `sanctionType` e `hasSanctions`

## Casos de uso

- Verifique um engenheiro químico por cédula ou licença CPIQ.
- Rejeite buscas só por nome antes do conselho.
- Leia datas de sanção quando o conselho as publica.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpiq
```

Uma correspondência inclui `fullName`, `licenseNumber`, `resolutionNumber`, `status`, `sanctionType`, `isRegistered` e `hasSanctions`. Sem linha no CPIQ é 404 `NotFound`.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Condicional** | `79876543` | Número de identidade. Obrigatório se omitir `licenseNumber`. Um pedido só com `fullName` responde 409. |
| `licenseNumber` | string | **Condicional** | `PQ-10293` | Número da matrícula profissional do CPIQ. Obrigatório se omitir `documentNumber`. |

### Notas

- `fullName` não é chave de busca nesta rota. Só o nome responde 409.
- Envie `documentNumber` ou `licenseNumber`.
- Uma linha ausente no CPIQ é HTTP 404.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `documentNumber: "79876543"` | 200 com licença e campos de sanção. |
| Valor obrigatório ausente | `fullName: "LUIS GOMEZ"` only | 409 porque um nome sozinho não é aceito. |
| Valor desconhecido | `documentNumber: "000000000"` | 404 NotFound se o CPIQ não tiver linha. |

401 when the bearer token is missing or rejected.
