# LATAM — Score unificado de educação e licença

O **score de educação** junta graus universitários e licenças profissionais num pontuação para `CO`, `PE`, `PA`, `MX` ou `CL` (nomes de país em inglês são aceitos). `country` é obrigatório. Também deve enviar uma identidade: `documentNumber`, `licenseNumber`, `fullName`, ou `firstName` e `lastName`. Um 409 traz `{ "validationError": "..." }`, não `MissingParameter`. Um país não suportado também é 409.

## O que a chamada devolve

- `educationScore` e `educationTier`
- `highestLevel` e `hasActiveLicense`
- `credentials` e `checkedSources`

## Casos de uso

- Ordene uma contratação entre fontes de grau e licença.
- Exija um país antes de pontuar.
- Leia sanções como uma redução do score.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/score/education
```

A resposta inclui `educationScore` de 0 a 100, `educationTier`, `highestLevel`, `hasActiveLicense`, `hasSanctions` e `credentials`.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `country` | string | **Sim** | `CO` | Obrigatório. `CO`, `PE`, `PA`, `MX`, `CL`, ou o nome em inglês `COLOMBIA`, `PERU`, `PANAMA`, `MEXICO`, `CHILE`. |
| `documentNumber` | string | **Condicional** | `80123456` | Uma identidade é obrigatória: este número, `licenseNumber`, `fullName`, ou `firstName` e `lastName` juntos. |
| `licenseNumber` | string | **Condicional** | `AN205-27910` | Licença profissional. Conta como a identidade obrigatória. |
| `fullName` | string | **Condicional** | `ANA PEREZ` | Nome completo. Conta como a identidade obrigatória. |

### Notas

- `country` é obrigatório.
- O 409 usa `validationError`, não `MissingParameter`.
- Os países suportados são CO, PE, PA, MX e CL.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `country: "CO"`, `documentNumber: "80123456"` | 200 com educationScore e nível. |
| Valor obrigatório ausente | Omit `country` | 409 `{ validationError }` se faltar country ou a identidade. |
| Valor desconhecido | `country: "US"`, `documentNumber: "1"` | 409 se o código do país não for suportado. |

401 when the bearer token is missing or rejected.
