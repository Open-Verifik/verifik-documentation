# Colômbia — Consulta de cidadão via Procuraduría

Valide um número de documento colombiano e extraia **nomes** da **Procuraduría General de la Nación**. Esta fonte oficial suporta *Cédula de ciudadanía* (**CC**), *Cédula de extranjería* (**CE**), *Permiso Especial de Permanencia* (**PEP**), *NIT* e *Permiso por Protección Temporal* (**PPT**).

Diferente de [cidadão por documento](/identity-validation/colombia/colombian-citizen) (`/v2/co/cedula`), este endpoint usa **somente Procuraduría** — não tenta DIAN, ADRES nem Registraduría. Diferente dos [antecedentes disciplinares](/verifik-pt/background-check/colombia-disciplinary-records-attorneys-office) (`/v2/co/procuraduria/antecedentes`), **não** devolve `antecedentes` nem `legend`.

## O que esta API devolve

- **`documentNumber`**, **`documentType`**
- **`firstName`**, **`lastName`**, **`fullName`**, **`arrayName`**
- Resposta Verifik **assinada**

## Referência da API

### Endpoint

```
GET https://api.verifik.co/v2/co/procuraduria
```

Use este endpoint para **extração de nomes apenas** na Procuraduría, incluindo tipos de documento que outras fontes de `/cedula` não cobrem. A mesma integração está disponível como **`POST`** com corpo JSON. **`GET`** usa **parâmetros de consulta**.

Campos típicos: `documentType`, `documentNumber`, `firstName`, `lastName`, `fullName`, `arrayName`. Use `/v2/co/cedula` para consolidar várias fontes. Use `/v2/co/procuraduria/antecedentes` para histórico disciplinar.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| name | type | required | description | Examples |
| --- | --- | --- | --- | --- |
| `documentType` | string | yes | Um de **`CC`**, **`CE`**, **`PPT`**, **`NIT`**, **`PEP`** | `CE` |
| `documentNumber` | string | yes | Número do documento, apenas dígitos | `688925` |

## Recursos

- Consulta de **nomes** direta na Procuraduría
- Suporta **CC**, **CE**, **PPT**, **NIT**, **PEP**
- Sem antecedentes disciplinares (`antecedentes`, `legend`)
- **GET** e **POST** compartilham o mesmo handler

## Casos de uso

- Validar uma cédula de extranjería ou um NIT quando só precisa do nome registrado
- Isolar Procuraduría da consolidação multi-fonte de `/cedula`
- Preferir um produto dedicado quando não quiser faturar antecedentes em separado

### Notes

- Extração de nomes apenas — a resposta **não** inclui `antecedentes` nem `legend`.
- Para antecedentes disciplinares, veja [antecedentes Colômbia](/verifik-pt/background-check/colombia-disciplinary-records-attorneys-office).
- `/v2/co/cedula` ainda consolida Procuraduría com outras fontes para os mesmos tipos de documento.
- O documento sandbox reservado `90040401` retorna **404**.
- Relacionado: [Cidadão por documento](/identity-validation/colombia/colombian-citizen).
