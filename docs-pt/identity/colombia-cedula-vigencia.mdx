# Colômbia — Estado da cédula (CC)

A consulta de **estado da cédula na Colômbia** lê a vigência da Registraduría. Envie `documentNumber`. A resposta diz se o número existe e se o titular consta como vivo, com o texto de estado publicado pelo registro. Use-a quando a admissão precisa do estado atual da CC antes de uma consulta de identidade mais ampla.

## O que a chamada devolve

- `documentType` — CC
- `documentNumber` — a cédula enviada
- `exists` — se o registro tem o número
- `isAlive` — true, false ou null
- `documentStatus` — o texto de vigência do registro

## Casos de uso

- Confirme que a CC está no registro antes de abrir uma conta.
- Separe um registro de pessoa falecida de uma cédula vigente no KYC.
- Guarde o texto de estado junto do número do documento.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/co/cedula/vigencia
```

Uma resposta bem-sucedida inclui `documentType` (CC), `documentNumber`, `exists`, `isAlive` e `documentStatus`. `exists` é false quando o registro diz que o número não consta. `isAlive` é true, false ou null se a fonte não resolver essa pergunta. Use-a num dossiê KYC que precise da vigência atual.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Sim** | `1121329661` | Cédula de ciudadanía colombiana, de 5 a 10 dígitos, sem espaços nem pontuação. |

### Notas

- `documentNumber` é obrigatório e deve ter de 5 a 10 caracteres.
- `isAlive` pode ser null se o registro devolver um estado que não define vida ou morte.
- Esta rota é a consulta de vigência. Não substitui um perfil completo do cidadão.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.
