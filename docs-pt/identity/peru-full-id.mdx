# 🇵🇪 Peru — DNI (dados estendidos)

A API de verificação de identidade da Verifik permite realizar verificação de identidade estendida para cidadãos peruanos usando o número do DNI (*Documento Nacional de Identidad*). Foi projetada para automatizar seus processos de KYC (Know Your Customer), prevenir fraudes e garantir o cumprimento de todos os requisitos regulatórios sem esforço.

Construímos esta integração para empresas que precisam de uma forma rápida, segura e automatizada de acessar informações pessoais estendidas, incluindo nome completo, estado civil, data de nascimento, detalhamento do endereço (província, área, distrito de residência) e outros campos de identidade relacionados.

**O cabeçalho Authorization é obrigatório para autenticar o acesso a essas informações com segurança.**

## O que esta API valida?

Nossa API conecta-se diretamente aos registros oficiais peruanos para validar:

-   **Nome completo e número do DNI**: suporta documentos do tipo *Documento Nacional de Identidad* (DNI).
-   **Correspondência de identidade**: confirma que o nome informado corresponde ao número do DNI.
-   **Dados pessoais estendidos**: retorna estado civil, data de nascimento, sexo, endereço, província, área e distrito de residência.
-   **Componentes do nome**: retorna `firstName`, `lastName`, `paternalLastName`, `maternalLastName` e `arrayName`.
-   **Informações do documento**: retorna tipo e número do documento.

Alguns campos estão sempre presentes na resposta, mas atualmente retornam a string `not_available` (não são omitidos): `photo`, `expeditionDate`, `expirationDate`, `ubigeoReniec` e `verificationDigit`. A foto não é oferecida atualmente neste endpoint.

Ao validar esses elementos, você pode confiar que a pessoa com quem está negociando é real e possui um documento válido, reduzindo significativamente os riscos de personificação e fraude.

### Endpoint

```
GET https://api.verifik.co/v3/pe/cedula/extra
```

Retorna **dados DNI RENIEC estendidos** para cidadãos peruanos: nome completo, estado civil, data de nascimento, endereço (província, área, distrito de residência) e outros campos de identidade relacionados. Envie `documentType=DNI` e o `documentNumber` de 8 dígitos.

`photo`, `expeditionDate`, `expirationDate`, `ubigeoReniec` e `verificationDigit` estão incluídos na estrutura da resposta, mas atualmente retornam `not_available`.

### Cabeçalhos (Headers)

| Nome           | Valor               |
| -------------- | ------------------- |
| Content-Type   | `application/json`  |
| Authorization  | `Bearer <token>`    |

### Parâmetros

| Nome | Tipo | Obrigatório | Descrição | Exemplo |
| ---- | ---- | ----------- | --------- | ------- |
| `documentType` | string | **Sim** | Tipo de documento. Valor permitido: `DNI`. | `DNI` |
| `documentNumber` | string | **Sim** | Número de DNI de 8 dígitos (sem espaços). | `44868598` |
