# Colômbia — Matrícula de administração de empresas (CPAE)

A consulta de **licença CPAE** lê o Consejo Profesional de Administración de Empresas. `documentNumber` é obrigatório. `documentType` opcional aceita `CC`, `CE`, `TI`, `PEP` ou `PPT`. Um acerto devolve o nome, a profissão e se o cartão está registrado e ativo.

## O que a chamada devolve

- `fullName` e `profession`
- `entity` — CPAE
- `status`, `isRegistered` e `isActive`

## Casos de uso

- Revise o cartão de administração na contratação.
- Confirme que o cartão segue ativo.
- Guarde o texto da profissão do CPAE no dossiê KYC.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/co/cpae
```

A resposta inclui `fullName`, `profession`, `entity`, `status`, `isRegistered` e `isActive`. Um número desconhecido é 404 `NotFound`.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Sim** | `80123456` | Número de identidade colombiano, de 5 a 15 caracteres. `documentType` pode ser `CC`, `CE`, `TI`, `PEP` ou `PPT`. |

### Notas

- `documentNumber` é obrigatório.
- O CPAE responde 404 se o número não tiver cartão profissional.
- Não envie um nome no lugar do número do documento.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `documentNumber: "52987654"` | 200 com profissão e bandeira ativa. |
| Valor obrigatório ausente | Omit `documentNumber` | 409 MissingParameter. |
| Valor desconhecido | `documentNumber: "000000000"` | 404 NotFound se o CPAE não tiver cartão. |

401 when the bearer token is missing or rejected.
