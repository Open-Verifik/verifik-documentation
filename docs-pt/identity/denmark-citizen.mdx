# Dinamarca — Verificação de identidade e empresário individual (KYC)

A **verificação de identidade e de empresário individual de Dinamarca** consulta uma pessoa ou empresário individual na fonte oficial deste identificador (CVR). Envie esse número em `documentNumber`. Use quando o onboarding precisa do nome legal, do status de registro e dos atributos de identidade que a fonte publica.

`documentNumber` é obrigatório. `documentType` tem o padrão `CVR`. Omita-o para manter esse padrão ou envie `CVR` de forma explícita.

## O que o registro devolve

- Nome legal da pessoa ou do empresário individual
- Status de registro
- Identificador consultado
- Atributos oficiais de identidade publicados pela fonte

## Casos de uso

- Confirmar um empresário individual ou uma pessoa registrada em Dinamarca durante o onboarding.
- Cruzar o nome legal do cadastro com o identificador oficial.
- Guardar o status de registro e os atributos de identidade que a fonte oficial publica.

## Referência da API

### Ponto de acesso

```http
GET https://api.verifik.co/v2/dk/citizen
```

Consulte a fonte oficial de identidade e de empresário individual de Dinamarca com `documentNumber`. `documentType` escolhe a família do identificador (CVR). Uma resposta bem-sucedida inclui o nome legal, o status de registro, o identificador enviado e os atributos oficiais de identidade que a fonte publica. Serve para o KYC de uma pessoa ou empresário individual. O exemplo mostra esses campos. Os valores ao vivo vêm da fonte oficial.

### Cabeçalhos

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da requisição |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | Token JWT de autenticação do cliente |

### Parâmetros

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Sim** | `10103940` | Número oficial de identidade ou de contribuinte da pessoa ou do empresário individual (CVR). |
| `documentType` | string | Não | `CVR` | Identificador do tipo de documento. O padrão é `CVR`. |

### Observações

- **Formato do identificador.** O número CVR tem 8 dígitos. Envie apenas dígitos, sem espaços.
- Identificador do tipo de documento. O padrão é `CVR`.
- O rótulo de status do exemplo ilustra o campo. O registro ao vivo devolve o próprio rótulo, que pode estar no idioma local.
- Envie `documentNumber` e, quando precisar nomear a família do identificador, `documentType`. Esses são os parâmetros de cliente desta rota.
- O JSON de exemplo ilustra os campos acima. Uma chamada ao vivo devolve a ficha do registro para o identificador enviado.

## Testes no sandbox

Com a conta em modo sandbox, os mesmos parâmetros exercitam esta rota. A tabela descreve a resposta documentada para cada caso.

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| **Identificador existente** | `documentType: "CVR"`, `documentNumber: "10103940"` | 200 com nome legal, status, identificador e endereço ou atributos de identidade quando a fonte possui o número. |
| **Sem documentNumber** | Omitir `documentNumber` | 409 `MissingParameter` quando `documentNumber` é omitido. |
| **Número desconhecido** | `documentNumber: "000000000"` | 404 `NotFound` quando o registro não tem ficha para esse número. |

401 quando o token bearer está ausente ou é recusado.
