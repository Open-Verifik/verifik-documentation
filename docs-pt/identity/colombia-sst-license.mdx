# Colômbia — Licença de segurança e saúde no trabalho (SST)

A consulta de **licença SST** lê licenças de segurança no trabalho e carnês de aplicador técnico para um número de identidade colombiano. `documentNumber` é obrigatório. Um acerto lista cada licença com tipo, resolução ou número do carnê e data.

## O que a chamada devolve

- `licenses[]` com `licenseType`, resolução ou número do carnê e `issueDate`
- `totalLicenses`
- `status` e `isRegistered`

## Casos de uso

- Revise a licença SST antes de um contratado entrar na obra.
- Veja a licença de pessoa natural e o carnê técnico.
- Guarde o número da resolução no dossiê do fornecedor.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/co/sst/licencia
```

A resposta inclui `fullName`, `profession`, `totalLicenses` e `licenses`. Sem licença nem carnê é 404 `NotFound`.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentNumber` | string | **Sim** | `52111222` | Número de identidade colombiano, de 5 a 15 caracteres, para ler licenças SST e carnês técnicos. |

### Notas

- `documentNumber` é obrigatório.
- Uma identidade sem licença SST nem carnê técnico é HTTP 404.
- `documentType` opcional aceita `CC`, `CE`, `TI`, `PEP` ou `PPT`.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.
