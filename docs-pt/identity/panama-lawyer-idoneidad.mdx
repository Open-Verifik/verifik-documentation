# Panamá — Idoneidade de advogado

A consulta de **idoneidade de advogado** lê o certificado da ordem panamenha pelo número. Envie `idoneidad` ou o alias `licenseNumber` com 1 a 10 dígitos. `issueDate` opcional usa `DD-MM-YYYY`. Sem número é 409 `MissingParameter`.

## O que a chamada devolve

- Número de idoneidade e nome
- `status`

## Casos de uso

- Confirme um advogado antes de uma petição.
- Cruze a data de emissão se a tiver.
- Rejeite uma idoneidade não numérica.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/pa/lawyer/idoneidad
```

Um acerto inclui o nome, o número de idoneidade e o estado. Um número desconhecido é 404 `NotFound`.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `idoneidad` | string | **Condicional** | `12345` | Número de idoneidade do advogado, de 1 a 10 dígitos. Alias: `licenseNumber`. Um dos dois é obrigatório. |
| `issueDate` | string | Não | `01-02-2010` | Data de emissão opcional em `DD-MM-YYYY`. |

### Notas

- Envie `idoneidad` ou `licenseNumber`.
- Só dígitos, de 1 a 10.
- Números desconhecidos são 404 `NotFound`.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.
