# Equador — Local de votação

A consulta de **local de votação do Equador** lê o padrón do CNE. `documentType` deve ser `CCEC` e `documentNumber` deve ser uma cédula de 10 dígitos cuja província seja 01–24 ou 30 e cujo dígito verificador seja válido. A resposta inclui o nome mais província, cantão, paróquia e junta (`pollingTable`).

## O que a chamada devolve

- `province`, `canton` e `parish`
- `pollingTable` — a junta
- `fullName`

## Casos de uso

- Mostre ao eleitor o local.
- Rejeite uma cédula cujo dígito falha.
- Guarde a junta com o dossiê de identidade.

---

## Referência da API

### Endpoint

```http
GET https://api.verifik.co/v2/ec/votacion
```

Os campos incluem `fullName`, `province`, `canton`, `parish` e `pollingTable`. Uma cédula desconhecida é 404 `NotFound`. Um dígito ruim é 409 `InvalidDocumentNumber`.

### Headers

| Nome | Valor | Descrição |
| :--- | :--- | :--- |
| Content-Type | `application/json` | Formato da solicitação |
| Accept | `application/json` | Formato da resposta |
| Authorization | `Bearer <seu_token>` | JWT do cliente |

### Parameters

| Nome | Tipo | Obrigatório | Exemplo | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| `documentType` | string | **Sim** | `CCEC` | Deve ser `CCEC`. |
| `documentNumber` | string | **Sim** | `1700000019` | Cédula equatoriana de 10 dígitos, com o dígito verificador. A província deve ser 01–24 ou 30. Um número ruim responde 409 `InvalidDocumentNumber`. |

### Notas

- `documentType` deve ser `CCEC`.
- A cédula tem 10 dígitos com província e dígito válidos.
- Números desconhecidos são 404 `NotFound`.
- Envie um JWT Bearer no cabeçalho `Authorization`.
- O JSON de exemplo ilustra os campos. Uma chamada real devolve o registro dos valores enviados.
- Não envie um indicador de bypass de cache. Esta página documenta apenas os parâmetros de cliente.

## Sandbox

| Cenário | Parâmetros | Resultado |
| :--- | :--- | :--- |
| Registro na fonte | `documentType: "CCEC"`, `documentNumber: "1700000019"` | 200 com província, cantão, paróquia e junta. |
| Valor obrigatório ausente | Omit `documentType` | 409 MissingParameter. |
| Valor desconhecido | `documentNumber: "1700000092"` | 404 NotFound se o padrón não tiver linha. |

401 when the bearer token is missing or rejected.
